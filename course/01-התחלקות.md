# שיעור 1: התחלקות וחלוקה עם שארית

**מה נלמד:** מה פירוש "a מחלק את b", התכונות הבסיסיות של יחס ההתחלקות, משפט החלוקה עם שארית, וכללי התחלקות ב-2, 3, 9 ו-11. נשתמש גם בשתי שיטות הוכחה שילוו אותנו בכל הקורס: הוכחה ישירה ו[אינדוקציה מתמטית](https://he.wikipedia.org/wiki/%D7%90%D7%99%D7%A0%D7%93%D7%95%D7%A7%D7%A6%D7%99%D7%94_%D7%9E%D7%AA%D7%9E%D7%98%D7%99%D7%AA).

**ידע קודם:** חשבון עם מספרים שלמים בלבד.

---

## 1. הגדרה: התחלקות

יהיו $`a`$ ו-$`b`$ מספרים שלמים, ו-$`a \neq 0`$. אומרים ש-**$`a`$ מחלק את $`b`$**, וכותבים $`a \mid b`$, אם קיים מספר שלם $`k`$ כך ש-

```math
b = k \cdot a .
```

במקרה כזה אומרים גם ש-$`a`$ הוא **מחלק** של $`b`$, ושה-$`b`$ הוא **כפולה** של $`a`$. אם $`a`$ אינו מחלק את $`b`$, כותבים $`a \nmid b`$.

**דוגמאות מהירות:**
* $`3 \mid 12`$, כי $`12 = 4 \cdot 3`$.
* $`5 \nmid 12`$, כי אין שלם $`k`$ כך ש-$`5k = 12`$.
* $`-4 \mid 20`$, כי $`20 = (-5)\cdot(-4)`$. כלומר, גם מספרים שליליים יכולים להיות מחלקים.
* $`7 \mid 0`$, כי $`0 = 0 \cdot 7`$. כל מספר שונה מאפס מחלק את 0.
* $`1 \mid b`$ ו-$`b \mid b`$ לכל $`b \neq 0`$.

> **שימו לב:** $`a \mid b`$ הוא **טענה** (נכונה או לא נכונה), ולא מספר. אל תבלבלו עם השבר $`a/b`$.

---

## 2. תכונות בסיסיות

**משפט 1.1.** לכל שלמים $`a, b, c`$ (עם $`a \neq 0`$ ובמידת הצורך $`b \neq 0`$):
1. **טרנזיטיביות:** אם $`a \mid b`$ ו-$`b \mid c`$, אז $`a \mid c`$.
2. **צירוף ליניארי:** אם $`a \mid b`$ ו-$`a \mid c`$, אז $`a \mid (xb + yc)`$ לכל שלמים $`x, y`$. בפרט $`a \mid b + c`$ ו-$`a \mid b - c`$.
3. **גודל:** אם $`a \mid b`$ ו-$`b \neq 0`$, אז $`|a| \le |b|`$.
4. **אנטי-סימטריה (עד כדי סימן):** אם $`a \mid b`$ ו-$`b \mid a`$, אז $`a = \pm b`$.

**הוכחה.**
1. מההנחות יש שלמים $`k, m`$ כך ש-$`b = ka`$ ו-$`c = mb`$. נציב: $`c = m(ka) = (mk)a`$, ו-$`mk`$ שלם. לכן $`a \mid c`$.
2. יש שלמים $`k, m`$ כך ש-$`b = ka`$ ו-$`c = ma`$. אז $`xb + yc = xka + yma = (xk + ym)a`$, ו-$`xk+ym`$ שלם.
3. $`b = ka`$ עם $`k`$ שלם, ו-$`k \neq 0`$ כי $`b \neq 0`$. לכן $`|k| \ge 1`$, ומכאן $`|b| = |k|\cdot|a| \ge |a|`$.
4. לפי סעיף 3, $`|a| \le |b|`$ וגם $`|b| \le |a|`$, ולכן $`|a| = |b|`$, כלומר $`a = \pm b`$. ∎

סעיף 2 הוא הכלי השימושי ביותר: **מחלק של שני מספרים מחלק כל צירוף שלהם.** נשתמש בו שוב ושוב.

---

## 3. חלוקה עם שארית

**משפט 1.2 (משפט החלוקה עם שארית).** לכל שלם $`a`$ ולכל שלם חיובי $`b`$ קיימים שלמים **יחידים** $`q`$ (המנה) ו-$`r`$ (השארית) כך ש-

```math
a = qb + r, \qquad 0 \le r < b .
```

**הוכחה.**

*קיום.* נבחר $`q = \lfloor a/b \rfloor`$, כלומר השלם הגדול ביותר שאינו גדול מ-$`a/b`$, ונגדיר $`r = a - qb`$. מההגדרה $`q \le a/b < q+1`$. נכפול ב-$`b > 0`$: $`qb \le a < qb + b`$. נחסר $`qb`$: $`0 \le a - qb < b`$, כלומר $`0 \le r < b`$.

*יחידות.* נניח ש-$`a = qb + r = q'b + r'`$, כאשר $`0 \le r, r' < b`$. אז $`(q - q')b = r' - r`$, כלומר $`b \mid r' - r`$. אבל $`-b < r' - r < b`$, והכפולה היחידה של $`b`$ בתחום זה היא 0. לכן $`r = r'`$, ומכאן גם $`q = q'`$. ∎

**קשר להתחלקות:** $`b \mid a`$ אם ורק אם השארית בחלוקת $`a`$ ב-$`b`$ היא 0.

> **מלכודת נפוצה — מספרים שליליים:** בחלוקת $`-17`$ ב-5, השארית היא **3** ולא $`-2`$: $`-17 = (-4)\cdot 5 + 3`$. השארית תמיד בין 0 ל-$`b-1`$.

## 4. דוגמאות פתורות

### דוגמה 1: מנה ושארית
**שאלה:** מצאו את המנה והשארית בחלוקת $`a = 2026`$ ב-$`b = 17`$, ובחלוקת $`a = -2026`$ ב-17.

**פתרון.**
1. נחשב $`2026 / 17 \approx 119.18`$, ולכן $`q = 119`$.
2. $`r = 2026 - 119 \cdot 17 = 2026 - 2023 = 3`$.
3. בדיקה: $`2026 = 119 \cdot 17 + 3`$ ו-$`0 \le 3 < 17`$. ✓
4. עבור $`-2026`$: $`-2026/17 \approx -119.18`$, ולכן $`q = \lfloor -119.18 \rfloor = -120`$.
5. $`r = -2026 - (-120)\cdot 17 = -2026 + 2040 = 14`$.
6. בדיקה: $`-2026 = (-120)\cdot 17 + 14`$, ו-$`0 \le 14 < 17`$. ✓

**שימו לב** ש-$`14 = 17 - 3`$: כשהופכים את הסימן של $`a`$ (ו-$`a`$ אינו מתחלק ב-$`b`$), השארית הופכת ל-$`b - r`$.

### דוגמה 2: הוכחה בעזרת צירוף ליניארי
**שאלה:** הוכיחו שאם $`d \mid 3n + 5`$ וגם $`d \mid 2n + 3`$, אז $`d = \pm 1`$.

**פתרון.**
1. לפי משפט 1.1 (2), $`d`$ מחלק כל צירוף של שני המספרים.
2. נבחר צירוף שמבטל את $`n`$: נכפול את הראשון ב-2 ואת השני ב-3:
```math
2(3n+5) - 3(2n+3) = 6n + 10 - 6n - 9 = 1 .
```
3. לכן $`d \mid 1`$, ומכאן $`d = \pm 1`$. ∎

**הרעיון הכללי:** כדי להראות שמחלק משותף חייב להיות קטן, מחפשים צירוף שמבטל את המשתנה. הרעיון יחזור באלגוריתם אוקלידס (שיעור 2).

### דוגמה 3: התחלקות בעזרת פירוק
**שאלה:** הוכיחו שלכל שלם $`n`$, המספר $`n^3 - n`$ מתחלק ב-6.

**פתרון.**
1. נפרק: $`n^3 - n = n(n^2 - 1) = (n-1)\,n\,(n+1)`$.
2. זו מכפלה של שלושה מספרים שלמים **עוקבים**.
3. בין כל שני מספרים עוקבים יש מספר זוגי, ולכן 2 מחלק את המכפלה.
4. בין כל שלושה מספרים עוקבים יש אחד שמתחלק ב-3 (השאריות שלהם בחלוקה ב-3 הן 0, 1, 2 בסדר כלשהו), ולכן 3 מחלק את המכפלה.
5. המכפלה מתחלקת ב-2 וב-3. כדי להסיק שהיא מתחלקת ב-6 נכתוב אותה כ-$`3m`$ (סעיף 4). מאחר שהיא זוגית ו-3 אי-זוגי, גם $`m`$ זוגי (אם $`m`$ היה אי-זוגי, $`3m`$ היה אי-זוגי). לכן $`m = 2t`$ והמכפלה היא $`6t`$. ∎

> **הערה:** בשלב 5 לא הסתפקנו ב"מתחלק ב-2 וב-3 ולכן ב-6". זה נכון כי 2 ו-3 זרים, ונוכיח את הכלל הכללי בשיעור 2. למשל, מספר שמתחלק ב-4 וב-6 אינו חייב להתחלק ב-24 (דוגמה: 12).

### דוגמה 4: הוכחה באינדוקציה
**שאלה:** הוכיחו שלכל $`n \ge 0`$, המספר $`7^n - 1`$ מתחלק ב-6.

**פתרון.**
1. **בסיס:** עבור $`n = 0`$: $`7^0 - 1 = 0`$, ו-$`6 \mid 0`$. ✓
2. **הנחת האינדוקציה:** נניח ש-$`6 \mid 7^n - 1`$ עבור $`n`$ מסוים.
3. **צעד:** נכתוב את המספר הבא בעזרת הקודם:
```math
7^{n+1} - 1 = 7\cdot 7^n - 1 = 7\,(7^n - 1) + 6 .
```
4. $`6 \mid 7(7^n - 1)`$ לפי ההנחה, ו-$`6 \mid 6`$. לפי משפט 1.1 (2), $`6`$ מחלק את הסכום. ∎

**הטריק:** בשלב 3 "הוספנו והחסרנו" כדי שהביטוי מהנחת האינדוקציה יופיע. זה הצעד המרכזי כמעט בכל הוכחת התחלקות באינדוקציה.

## 5. כללי התחלקות

כל מספר טבעי בבסיס עשר הוא $`N = a_k 10^k + \dots + a_1 \cdot 10 + a_0`$, כאשר $`a_i`$ הן הספרות.

**משפט 1.3.**
1. $`2 \mid N`$ אם ורק אם $`2 \mid a_0`$ (ספרת האחדות זוגית).
2. $`3 \mid N`$ אם ורק אם 3 מחלק את סכום הספרות; ובאותו אופן עבור 9.
3. $`11 \mid N`$ אם ורק אם 11 מחלק את הסכום המתחלף $`a_0 - a_1 + a_2 - \dots`$.

**הוכחה (סעיף 2).** 
1. לכל $`i \ge 0`$, המספר $`10^i - 1 = 99\dots9`$ מתחלק ב-9 (ולכן גם ב-3). אפשר לוודא זאת באינדוקציה, בדיוק כמו בדוגמה 4.
2. לכן $`N - (a_0 + a_1 + \dots + a_k) = \sum_i a_i (10^i - 1)`$ מתחלק ב-9.
3. $`N`$ וסכום הספרות נבדלים בכפולה של 9, ולכן לפי משפט 1.1 (2) אחד מתחלק ב-9 (או ב-3) אם ורק אם השני מתחלק. ∎

**הוכחה (סעיף 3).** כאן $`10^i - (-1)^i`$ מתחלק ב-11 (שוב באינדוקציה: $`10^{i+1} - (-1)^{i+1} = 10\,(10^i - (-1)^i) + 11\cdot(-1)^i`$), ולכן $`N`$ נבדל מהסכום המתחלף בכפולה של 11. ∎

### דוגמה 5
**שאלה:** האם $`N = 918{,}082`$ מתחלק ב-3, ב-9 וב-11?

**פתרון.**
1. סכום הספרות: $`9+1+8+0+8+2 = 28`$. 28 אינו מתחלק ב-3, ולכן $`N`$ אינו מתחלק ב-3 ולא ב-9.
2. הסכום המתחלף מספרת האחדות: $`2 - 8 + 0 - 8 + 1 - 9 = -22`$.
3. $`11 \mid -22`$, ולכן $`11 \mid N`$. בדיקה: $`918082 = 11 \cdot 83462`$. ✓

## 6. תרגילים

נסו לפתור לבד לפני שתפתחו את הפתרון.

**תרגיל 1.** מצאו מנה ושארית בחלוקת $`-100`$ ב-7.

<details><summary>פתרון</summary>

$`-100/7 \approx -14.29`$, ולכן $`q = -15`$ ו-$`r = -100 + 105 = 5`$. בדיקה: $`-100 = (-15)\cdot 7 + 5`$, $`0 \le 5 < 7`$.
</details>

**תרגיל 2.** הוכיחו שאם $`a \mid b`$ אז $`a^2 \mid b^2`$. האם הכיוון ההפוך נכון?

<details><summary>פתרון</summary>

אם $`b = ka`$ אז $`b^2 = k^2 a^2`$, ולכן $`a^2 \mid b^2`$. הכיוון ההפוך נכון גם הוא, אבל ההוכחה דורשת את המשפט היסודי של האריתמטיקה (שיעור 3): אם $`a^2 \mid b^2`$, אז בכל ראשוני החזקה ב-$`a^2`$ (שהיא $`2\alpha`$) אינה גדולה מזו ב-$`b^2`$ ($`2\beta`$), ולכן $`\alpha \le \beta`$, כלומר $`a \mid b`$.
</details>

**תרגיל 3.** הוכיחו שמכפלה של ארבעה מספרים שלמים עוקבים מתחלקת ב-24.

<details><summary>פתרון</summary>

1. בין ארבעה עוקבים יש בדיוק שני זוגיים עוקבים, ואחד מהם מתחלק ב-4. לכן המכפלה מתחלקת ב-$`2 \cdot 4 = 8`$.
2. בין ארבעה עוקבים יש לפחות אחד שמתחלק ב-3.
3. המכפלה היא $`8m`$, ו-$`3 \mid 8m`$. מאחר ש-3 אינו מחלק את 8, והשאריות של $`8m`$ ושל $`2m`$ בחלוקה ב-3 שוות ($`8m - 2m = 6m`$), נקבל $`3 \mid 2m`$, ולכן $`3 \mid m`$ (בדקו את שלוש השאריות האפשריות של $`m`$). לכן המכפלה היא $`24t`$.
</details>

**תרגיל 4.** הוכיחו באינדוקציה ש-$`3 \mid 4^n + 5`$ לכל $`n \ge 0`$.

<details><summary>פתרון</summary>

בסיס: $`4^0 + 5 = 6`$. צעד: $`4^{n+1} + 5 = 4(4^n + 5) - 15`$. לפי ההנחה $`3 \mid 4(4^n+5)`$, ו-$`3 \mid 15`$, ולכן 3 מחלק את ההפרש.
</details>

**תרגיל 5.** מצאו את כל השלמים $`n`$ שעבורם $`n + 1 \mid n^2 + 1`$.

<details><summary>פתרון</summary>

1. $`n^2 + 1 = (n+1)(n-1) + 2`$.
2. $`n+1`$ מחלק את $`(n+1)(n-1)`$, ולכן $`n+1 \mid n^2+1`$ אם ורק אם $`n+1 \mid 2`$.
3. המחלקים של 2 הם $`\pm1, \pm2`$, ולכן $`n+1 \in \{1, -1, 2, -2\}`$, כלומר $`n \in \{0, -2, 1, -3\}`$.
4. בדיקה: $`n=1`$: $`2 \mid 2`$ ✓; $`n=0`$: $`1 \mid 1`$ ✓; $`n=-2`$: $`-1 \mid 5`$ ✓; $`n=-3`$: $`-2 \mid 10`$ ✓.
</details>

**תרגיל 6.** בלי מחשבון, קבעו אם $`123{,}456{,}789`$ מתחלק ב-9 וב-11.

<details><summary>פתרון</summary>

סכום הספרות $`1+2+\dots+9 = 45`$ מתחלק ב-9, ולכן המספר מתחלק ב-9. הסכום המתחלף מהאחדות: $`9-8+7-6+5-4+3-2+1 = 5`$, שאינו מתחלק ב-11, ולכן המספר אינו מתחלק ב-11.
</details>

## סיכום
* $`a \mid b`$ פירושו $`b = ka`$ עבור שלם $`k`$.
* מחלק של שני מספרים מחלק כל צירוף ליניארי שלהם — הכלי החשוב ביותר בשיעור.
* לכל $`a`$ ולכל $`b > 0`$ יש מנה ושארית יחידות עם $`0 \le r < b`$.
* כללי התחלקות נובעים מכך ש-$`10^i - 1`$ מתחלק ב-9 ו-$`10^i - (-1)^i`$ מתחלק ב-11.
