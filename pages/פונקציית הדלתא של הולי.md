# פונקציית הדלתא של הולי

ב[מתמטיקה](https://he.wikipedia.org/wiki/%D7%9E%D7%AA%D7%9E%D7%98%D7%99%D7%A7%D7%94), **פונקציית הדלתא של הולי** (ב[אנגלית](https://he.wikipedia.org/wiki/%D7%90%D7%A0%D7%92%D7%9C%D7%99%D7%AA): Hooley's delta function), הנקראת גם **פונקציית הדלתא של ארדש–הולי**, מחזירה עבור $`n`$ את המספר המרבי של [מחלקים](https://he.wikipedia.org/wiki/%D7%9E%D7%97%D7%9C%D7%A7) של $`n`$ הנמצאים בקטע $`[u, eu]`$, על פני כל הערכים של $`u`$, כאשר $`e`$ הוא [המספר e](https://he.wikipedia.org/wiki/E_%28%D7%A7%D7%91%D7%95%D7%A2_%D7%9E%D7%AA%D7%9E%D7%98%D7%99%29). מסמנים אותה בדרך כלל $`\Delta(n)`$:



```math
\Delta(n) = \max_{u > 0}\ \#\{d : d \mid n,\ u \le d \le eu\}.
```

 האיברים הראשונים של הסדרה הם



```math
1, 2, 1, 2, 1, 2, 1, 2, 1, 2, 1, 3, 1, 2, 2, 2, 1, 2, 1, 3, 2, 2, 1, 4, \dots
```

 (סדרה [A226898](https://oeis.org/A226898) ב-OEIS).

לדוגמה, המחלקים של 24 הם 1, 2, 3, 4, 6, 8, 12, 24. בקטע $`[3, 3e] \approx [3, 8.15]`$ נמצאים ארבעה מהם: 3, 4, 6, 8, ואין קטע כזה עם חמישה מחלקים, ולכן $`\Delta(24) = 4`$. לעומת זאת, למספר ראשוני $`p`$ יש רק שני מחלקים, 1 ו-$`p`$, והיחס ביניהם גדול מ-$`e`$ (עבור $`p \geq 3`$), ולכן $`\Delta(p) = 1`$.

## היסטוריה

את הסדרה הציג לראשונה [פאול ארדש](https://he.wikipedia.org/wiki/%D7%A4%D7%90%D7%95%D7%9C_%D7%90%D7%A8%D7%93%D7%A9) ב-1974,[^1] ולאחר מכן חקר אותה כריסטופר הולי ב-1979.[^2]

ב-2023 הוכיחו דימיטריס קוקולופולוס ו[טרנס טאו](https://he.wikipedia.org/wiki/%D7%98%D7%A8%D7%A0%D7%A1_%D7%98%D7%90%D7%95) ש-



```math
\sum_{k=1}^n \Delta(k) \ll n (\log \log n)^{11/4}
```

 עבור $`n \ge 100`$.[^3] בפרט, ה[סדר הממוצע](%D7%A1%D7%93%D7%A8%20%D7%9E%D7%9E%D7%95%D7%A6%D7%A2%20%D7%A9%D7%9C%20%D7%A4%D7%95%D7%A0%D7%A7%D7%A6%D7%99%D7%94%20%D7%90%D7%A8%D7%99%D7%AA%D7%9E%D7%98%D7%99%D7%AA.md) של $`\Delta(n)`$ קטן מכל חזקה חיובית של $`\log n`$.

ב-2024 הוכיחו [קווין פורד](https://he.wikipedia.org/wiki/%D7%A7%D7%95%D7%95%D7%99%D7%9F_%D7%A4%D7%95%D7%A8%D7%93), קוקולופולוס וטאו את החסם התחתון



```math
\sum_{k=1}^n \Delta(k) \gg n (\log \log n)^{1+\eta-\epsilon},
```

 כאשר $`\epsilon > 0`$ קבוע, $`\eta=0.3533227\ldots`$, ו-$`n \geq 100`$.[^4]

## שימוש

הפונקציה מודדת את הנטייה של המחלקים של מספר להתקבץ זה ליד זה.

הגידול של הסדרה מוגבל על ידי $`\Delta(mn) \leq \Delta(n)\, d(m)`$, כאשר $`d(m)`$ הוא [מספר המחלקים](https://he.wikipedia.org/wiki/%D7%A4%D7%95%D7%A0%D7%A7%D7%A6%D7%99%D7%99%D7%AA_%D7%9E%D7%97%D7%9C%D7%A7%D7%99%D7%9D) של $`m`$.[^5]
