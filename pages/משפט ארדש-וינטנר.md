# משפט ארדש-וינטנר

ב[מתמטיקה](https://he.wikipedia.org/wiki/%D7%9E%D7%AA%D7%9E%D7%98%D7%99%D7%A7%D7%94), ובפרט ב[תורת המספרים ההסתברותית](https://he.wikipedia.org/wiki/%D7%AA%D7%95%D7%A8%D7%AA_%D7%94%D7%9E%D7%A1%D7%A4%D7%A8%D7%99%D7%9D_%D7%94%D7%94%D7%A1%D7%AA%D7%91%D7%A8%D7%95%D7%AA%D7%99%D7%AA), [פונקציה ממשית](https://he.wikipedia.org/wiki/%D7%A4%D7%95%D7%A0%D7%A7%D7%A6%D7%99%D7%94_%D7%9E%D7%9E%D7%A9%D7%99%D7%AA) $`f(n)`$ על המספרים השלמים נקראת [אדיטיבית](https://he.wikipedia.org/wiki/%D7%A4%D7%95%D7%A0%D7%A7%D7%A6%D7%99%D7%94_%D7%90%D7%93%D7%99%D7%98%D7%99%D7%91%D7%99%D7%AA) אם $`f(mn)=f(m)+f(n)`$ לכל $`m`$, $`n`$ [זרים](https://he.wikipedia.org/wiki/%D7%9E%D7%A1%D7%A4%D7%A8%D7%99%D7%9D_%D7%96%D7%A8%D7%99%D7%9D). **משפט ארדש–וינטנר** (ב[אנגלית](https://he.wikipedia.org/wiki/%D7%90%D7%A0%D7%92%D7%9C%D7%99%D7%AA): Erdős–Wintner theorem) נותן תנאי שבו לפונקציה אדיטיבית ממשית יש התפלגות גבולית



```math
F(y)=\lim_{N\to\infty}\frac{1}{N} \#\{n\lt N:f(n)\leq y\}.
```

 בפרט, המשפט קובע שפונקציית הגבול קיימת אם שלושת הטורים הבאים, על פני ה[מספרים הראשוניים](https://he.wikipedia.org/wiki/%D7%9E%D7%A1%D7%A4%D7%A8_%D7%A8%D7%90%D7%A9%D7%95%D7%A0%D7%99), מתכנסים:



```math
\sum_{|f(p)|>1}\frac{1}{p}, \quad\sum_{|f(p)|\leq 1}\frac{f(p)}{p}, \quad\sum_{|f(p)|\leq 1}\frac{f(p)^2}{p}.
```

 במקרה זה, הפונקציה האופיינית $`v(t)`$ של ההתפלגות הגבולית $`F`$ שווה ל-



```math
v(t)=\prod_{p}\left(1-\frac{1}{p}\right)\left(1+\sum^{\infty}_{m=1}p^{-m}e^{itf(p^m)}\right),
```

 כאשר $`i`$ היא היחידה המדומה. יתרה מזו, ההתפלגות הגבולית [רציפה](https://he.wikipedia.org/wiki/%D7%A4%D7%95%D7%A0%D7%A7%D7%A6%D7%99%D7%94_%D7%A8%D7%A6%D7%99%D7%A4%D7%94_%28%D7%90%D7%A0%D7%9C%D7%99%D7%96%D7%94%29) אם ורק אם הטור



```math
\sum_{f(p)\neq 0}\frac{1}{p}
```

 מתבדר; אחרת ההתפלגות [בדידה](https://he.wikipedia.org/wiki/%D7%94%D7%AA%D7%A4%D7%9C%D7%92%D7%95%D7%AA_%D7%91%D7%93%D7%99%D7%93%D7%94) לחלוטין.[^1]

המשפט הוא אנלוגי ל[משפט שלושת הטורים של קולמוגורוב](https://he.wikipedia.org/wiki/%D7%9E%D7%A9%D7%A4%D7%98_%D7%A9%D7%9C%D7%95%D7%A9%D7%AA_%D7%94%D7%98%D7%95%D7%A8%D7%99%D7%9D_%D7%A9%D7%9C_%D7%A7%D7%95%D7%9C%D7%9E%D7%95%D7%92%D7%95%D7%A8%D7%95%D7%91).

## דוגמה

עבור $`f(n) = \log(\varphi(n)/n)`$, כאשר $`\varphi`$ היא [פונקציית אוילר](https://he.wikipedia.org/wiki/%D7%A4%D7%95%D7%A0%D7%A7%D7%A6%D7%99%D7%99%D7%AA_%D7%90%D7%95%D7%99%D7%9C%D7%A8), מתקיים $`f(p^m) = \log(1 - 1/p)`$, ולכן $`|f(p)| \leq 1`$ לכל $`p \geq 2`$, וגם $`|f(p)| \approx 1/p`$. הטור השני והשלישי מתכנסים כמו $`\sum 1/p^2`$, והטור הראשון ריק. לכן ל-$`\varphi(n)/n`$ יש התפלגות גבולית. מכיוון ש-$`f(p) \neq 0`$ לכל $`p`$ והטור $`\sum 1/p`$ מתבדר, ההתפלגות רציפה. לעומת זאת, עבור $`f(n) = \omega(n)`$, מספר הגורמים הראשוניים השונים, $`f(p) = 1`$ והטור השני $`\sum 1/p`$ מתבדר; ואכן ל-$`\omega(n)`$ אין התפלגות גבולית, ויש לנרמל אותה, כפי שעושה [משפט ארדש-קאץ](%D7%9E%D7%A9%D7%A4%D7%98%20%D7%90%D7%A8%D7%93%D7%A9-%D7%A7%D7%90%D7%A5.md).
