# משפט הערך הממוצע של וינוגרדוב

ב[מתמטיקה](https://he.wikipedia.org/wiki/%D7%9E%D7%AA%D7%9E%D7%98%D7%99%D7%A7%D7%94), **משפט הערך הממוצע של וינוגרדוב** (ב[אנגלית](https://he.wikipedia.org/wiki/%D7%90%D7%A0%D7%92%D7%9C%D7%99%D7%AA): Vinogradov's mean value theorem) הוא הערכה למספר השוויונות בין סכומי חזקות. זהו אי-שוויון חשוב ב[תורת המספרים האנליטית](%D7%AA%D7%95%D7%A8%D7%AA%20%D7%94%D7%9E%D7%A1%D7%A4%D7%A8%D7%99%D7%9D%20%D7%94%D7%90%D7%A0%D7%9C%D7%99%D7%98%D7%99%D7%AA.md), הקרוי על שם [איוואן וינוגרדוב](https://he.wikipedia.org/wiki/%D7%90%D7%99%D7%95%D7%95%D7%90%D7%9F_%D7%95%D7%99%D7%A0%D7%95%D7%92%D7%A8%D7%93%D7%95%D7%91).

ליתר דיוק, יהי $`J_{s,k}(X)`$ מספר הפתרונות של מערכת של $`k`$ [משוואות דיופנטיות](https://he.wikipedia.org/wiki/%D7%9E%D7%A9%D7%95%D7%95%D7%90%D7%94_%D7%93%D7%99%D7%95%D7%A4%D7%A0%D7%98%D7%99%D7%AA) בו-זמניות ב-$`2s`$ משתנים:



```math
x_1^j+x_2^j+\cdots+x_s^j=y_1^j+y_2^j+\cdots+y_s^j\quad (1\le j\le k),
```

 עם



```math
1\le x_i,y_i\le X \quad (1\le i\le s).
```

 כלומר, $`J_{s,k}(X)`$ סופר את השוויונות בין סכומים של חזקות עם אותו מספר איברים ($`s`$) ואותם מעריכים ($`j`$), עד חזקות $`k`$-יות ועד $`X`$. ביטוי אנליטי חלופי ל-$`J_{s,k}(X)`$ הוא



```math
J_{s,k}(X)=\int_{[0,1)^k}|f_k(\boldsymbol\alpha;X)|^{2s}\,d\boldsymbol\alpha,
```

 כאשר



```math
f_k(\boldsymbol\alpha;X)=\sum_{1\le x\le X}\exp(2\pi i(\alpha_1x+\cdots+\alpha_kx^k)).
```

 (השוויון נובע מאורתוגונליות: פותחים את $`|f_k|^{2s} = f_k^s \overline{f_k}^s`$, והאינטגרל של $`e^{2\pi i(\alpha_1 m_1 + \dots + \alpha_k m_k)}`$ הוא 1 רק כאשר כל ה-$`m_j`$ מתאפסים, כלומר כאשר כל $`k`$ המשוואות מתקיימות.) משפט הערך הממוצע של וינוגרדוב נותן חסם עליון לערך $`J_{s,k}(X)`$.

הערכה חזקה ל-$`J_{s,k}(X)`$ היא רכיב חשוב ב[שיטת המעגל של הארדי וליטלווד](%D7%A9%D7%99%D7%98%D7%AA%20%D7%94%D7%9E%D7%A2%D7%92%D7%9C%20%D7%A9%D7%9C%20%D7%94%D7%90%D7%A8%D7%93%D7%99%20%D7%95%D7%9C%D7%99%D7%98%D7%9C%D7%95%D7%95%D7%93.md) לטיפול ב[בעיית וארינג](https://he.wikipedia.org/wiki/%D7%91%D7%A2%D7%99%D7%99%D7%AA_%D7%95%D7%90%D7%A8%D7%99%D7%A0%D7%92), וגם בהוכחת קיומו של תחום ללא אפסים ל[פונקציית זטא של רימן](https://he.wikipedia.org/wiki/%D7%A4%D7%95%D7%A0%D7%A7%D7%A6%D7%99%D7%99%D7%AA_%D7%96%D7%98%D7%90_%D7%A9%D7%9C_%D7%A8%D7%99%D7%9E%D7%9F) ברצועה הקריטית.[^1] הוכחו חסמים שונים ל-$`J_{s,k}(X)`$, התקפים בתחומים יחסיים שונים של $`s`$ ו-$`k`$. הצורה הקלאסית של המשפט חלה כאשר $`s`$ גדול מאוד ביחס ל-$`k`$.

ניתוח של ההוכחות של השערת הערך הממוצע של וינוגרדוב אפשר למצוא בהרצאה בסמינר בורבקי של ליליאן פירס.[^2]

## חסמים תחתונים

אם מתבוננים ב-$`X^s`$ הפתרונות שבהם



```math
x_i=y_i \quad (1\le i\le s),
```

 רואים ש-$`J_{s,k}(X)\gg X^s`$.

ניתוח זהיר יותר (ראו ווהן,[^3] משוואה 7.4) נותן את החסם התחתון



```math
J_{s,k}\gg X^s+X^{2s-\frac12k(k+1)}.
```

 (האיבר השני: יש $`X^{2s}`$ בחירות של $`\mathbf x, \mathbf y`$, ולכל $`j`$ ההפרש $`\sum x_i^j - \sum y_i^j`$ נע בתחום באורך מסדר $`X^j`$; לכן אחד מכל $`X^{1 + 2 + \dots + k} = X^{k(k+1)/2}`$ בערך מקיים את כל המשוואות.)

## הוכחת ההשערה המרכזית

ההשערה המרכזית של משפט הערך הממוצע של וינוגרדוב הייתה שהחסם העליון קרוב לחסם התחתון הזה. ליתר דיוק, שלכל $`\epsilon>0`$ מתקיים



```math
J_{s,k}(X)\ll X^{s+\epsilon}+X^{2s-\frac12k(k+1)+\epsilon}.
```

 את ההשערה הוכיחו ז'אן בורגן, צ'יפריאן דמטר ולארי גות'[^4] (בשיטת ה-decoupling מאנליזה הרמונית), ובשיטה אחרת טרבור וולי.[^5]

אם



```math
s\ge \tfrac12k(k+1),
```

 זה שקול לחסם



```math
J_{s,k}(X)\ll X^{2s-\frac12k(k+1)+\epsilon}.
```

 באופן דומה, אם $`s\le \tfrac12k(k+1)`$, הצורה המשוערת שקולה לחסם



```math
J_{s,k}(X)\ll X^{s+\epsilon}.
```



צורות חזקות יותר של המשפט מובילות לביטוי אסימפטוטי ל-$`J_{s,k}`$, ובפרט, עבור $`s`$ גדול ביחס ל-$`k`$, מתקיים



```math
J_{s,k}\sim \mathcal C(s,k)X^{2s-\frac12k(k+1)},
```

 כאשר $`\mathcal C(s,k)`$ מספר חיובי קבוע התלוי לכל היותר ב-$`s`$ וב-$`k`$; ראו משפט 1.2 אצל וולי (2012).[^6]

## היסטוריה

המשפט המקורי של וינוגרדוב מ-1935[^7] הראה שעבור $`s,k`$ קבועים המקיימים



```math
s\ge k^2\log (k^2+k)+\tfrac14k^2+\tfrac54 k+1
```

 יש קבוע חיובי $`D(s,k)`$ כך ש-



```math
J_{s,k}(X)\le D(s,k)(\log X)^{2s}X^{2s-\frac12k(k+1)+\frac12}.
```

 אף שזו הייתה תוצאה פורצת דרך, היא אינה מגיעה לצורה המשוערת המלאה. היא מוכיחה את הצורה המשוערת רק כאשר $`\epsilon>\tfrac12`$.

הגישה של וינוגרדוב שופרה על ידי קרצובה[^8] וסטצ'קין,[^9] שהראו שעבור $`s\ge k`$ יש קבוע חיובי $`D(s,k)`$ כך ש-



```math
J_{s,k}(X)\le D(s,k)X^{2s-\frac12k(k+1)+\eta_{s,k} },
```

 כאשר



```math
\eta_{s,k}=\frac12 k^2\left(1-\frac1k\right)^{\left[\frac sk\right]}\le k^2e^{-s/k^2}.
```

 מכיוון שעבור



```math
s>k^2(2\log k-\log\epsilon)
```

 מתקיים



```math
\eta_{s,k}\lt \epsilon,
```

 הדבר מוכיח שהצורה המשוערת נכונה עבור $`s`$ בגודל זה.

אפשר לחדד את השיטה עוד ולהוכיח את ההערכה האסימפטוטית



```math
J_{s,k}\sim \mathcal C(s,k)X^{2s-\frac12k(k+1)}
```

 עבור $`s`$ גדול ביחס ל-$`k`$.

ב-2012 הרחיב וולי[^10] את תחום ה-$`s`$ שבו הצורה המשוערת נכונה. הוא הוכיח שעבור



```math
k\ge 2
```

 ו-$`s\ge k(k+1)`$ ולכל $`\epsilon>0`$ מתקיים



```math
J_{s,k}(X)\ll X^{2s-\frac12k(k+1)+\epsilon}.
```



פורד ווולי[^11] הראו שהצורה המשוערת מוכחת עבור $`s`$ קטן ביחס ל-$`k`$. במפורש, הם הראו שעבור



```math
k\ge 4
```

 ו-$`1\le s\le \tfrac14(k+1)^2`$ ולכל $`\epsilon>0`$ מתקיים



```math
J_{s,k}(X)\ll X^{s+\epsilon}.
```
