# השיטה של ואן דר קורפוט

ב[מתמטיקה](https://he.wikipedia.org/wiki/%D7%9E%D7%AA%D7%9E%D7%98%D7%99%D7%A7%D7%94), **השיטה של ואן דר קורפוט** (ב[אנגלית](https://he.wikipedia.org/wiki/%D7%90%D7%A0%D7%92%D7%9C%D7%99%D7%AA): van der Corput's method) מייצרת הערכות ל[סכומים אקספוננציאליים](%D7%A1%D7%9B%D7%95%D7%9D%20%D7%90%D7%A7%D7%A1%D7%A4%D7%95%D7%A0%D7%A0%D7%A6%D7%99%D7%90%D7%9C%D7%99.md). השיטה מפעילה שני תהליכים, **תהליכי ואן דר קורפוט A ו-B**, שמקשרים את הסכומים לסכומים פשוטים יותר שקל יותר להעריך.

התהליכים חלים על סכומים אקספוננציאליים מהצורה



```math
\sum_{n=a}^b e(f(n)),
```

 כאשר $`f`$ היא [פונקציה חלקה](https://he.wikipedia.org/wiki/%D7%A4%D7%95%D7%A0%D7%A7%D7%A6%D7%99%D7%94_%D7%97%D7%9C%D7%A7%D7%94) מספיק, ו-$`e(x)`$ מסמן את $`\exp(2\pi i x)`$.

## תהליך A

כדי להפעיל את תהליך A, כותבים $`f_h(x) = f(x+h)-f(x)`$ (ההפרש הראשון), ומניחים שיש $`H \le b-a`$ כך ש-



```math
\sum_{h=1}^H \left| \sum_{n=a}^{b-h} e(f_h(n)) \right| \le b-a.
```

 אז



```math
\left| \sum_{n=a}^b e(f(n)) \right| \ll \frac{b-a}{\sqrt H}.
```



**הרעיון (נוסף בתרגום).** תהליך A מבוסס על אי-השוויון של ואן דר קורפוט (גרסה של [אי-שוויון קושי-שוורץ](https://he.wikipedia.org/wiki/%D7%90%D7%99-%D7%A9%D7%95%D7%95%D7%99%D7%95%D7%9F_%D7%A7%D7%95%D7%A9%D7%99-%D7%A9%D7%95%D7%95%D7%A8%D7%A5)): מעלים את הסכום בריבוע ומתבוננים בהפרשים $`f(n+h) - f(n)`$. ההפרש מוריד את "המעלה" של $`f`$ באחד; למשל, אם $`f`$ פולינום ממעלה 2, אז $`f_h`$ ליניארית, וסכום מהצורה $`\sum_n e(\alpha n + \beta)`$ הוא [טור הנדסי](https://he.wikipedia.org/wiki/%D7%A1%D7%93%D7%A8%D7%94_%D7%94%D7%A0%D7%93%D7%A1%D7%99%D7%AA) שקל לחסום. זה אותו רעיון כמו ב"הפרשי ויל" (Weyl differencing).

## תהליך B

תהליך B הופך את הסכום על $`f`$ לסכום על פונקציה $`g`$ המוגדרת בעזרת הנגזרת של $`f`$. נניח ש-$`f'`$ עולה מונוטונית, עם $`f'(a) = \alpha`$ ו-$`f'(b) = \beta`$. אז $`f'`$ הפיכה על $`[\alpha,\beta]`$; תהי $`u`$ ההופכית שלה. נניח עוד ש-$`f'' \ge \lambda > 0`$. נכתוב



```math
g(y) = f(u(y)) - y\, u(y).
```

 אז



```math
\left| \sum_{n=a}^b e(f(n)) \right| \ll \frac{1}{\sqrt \lambda} \max_{\alpha \le \gamma \le \beta} \left| \sum_{\nu=\alpha}^\gamma e(g(\nu)) \right|.
```

 הפעלת תהליך B שוב על הסכום עם $`g`$ מחזירה לסכום על $`f`$, ולכן אינה נותנת מידע נוסף.

(תהליך B הוא בעצם נוסחת הסכימה של פואסון יחד עם שיטת הפאזה הסטציונרית: $`g`$ היא [התמרת לז'נדר](https://he.wikipedia.org/wiki/%D7%94%D7%AA%D7%9E%D7%A8%D7%AA_%D7%9C%D7%96%27%D7%A0%D7%93%D7%A8) של $`f`$, ובאופן גס סכום ארוך עם פאזה $`f`$ שווה לסכום קצר יותר עם פאזה $`g`$.)

## זוגות מעריכים

שיטת **זוגות המעריכים** נותנת מחלקה של הערכות לפונקציות בעלות תכונת חלקות מסוימת. נקבע פרמטרים $`N, R, T, s, \delta`$. נתבונן בפונקציות $`f`$ המוגדרות בקטע $`[N, 2N]`$, שהן גזירות ברציפות $`R`$ פעמים, ומקיימות



```math
\left| f^{(r+1)}(x) - (-1)^r s(s+1)\cdots(s+r)T x^{-s-r} \right| \le \delta\, s(s+1)\cdots(s+r)T x^{-s-r}
```

 באופן אחיד ב-$`[a, b]`$, עבור $`0 \le r \lt R`$.

אומרים שזוג מספרים ממשיים $`(k, l)`$ עם $`0 \le k \le 1/2 \le l \le 1`$ הוא **זוג מעריכים** אם לכל $`\sigma > 0`$ יש $`\delta`$ ו-$`R`$, התלויים ב-$`k, l, \sigma`$, כך ש-



```math
\left| \sum_{n=a}^b e(f(n)) \right| \ll \left(\frac{T}{N^\sigma}\right)^k N^l
```

 באופן אחיד ב-$`f`$.

לפי תהליך A, אם $`(k, l)`$ זוג מעריכים, אז גם $`\left(\frac{k}{2k+2},\frac{k+l+1}{2k+2}\right)`$ זוג מעריכים. לפי תהליך B, גם $`\left(l-1/2,\ k+1/2\right)`$ זוג מעריכים.

חסם טריוויאלי מראה ש-$`(0, 1)`$ הוא זוג מעריכים.

קבוצת זוגות המעריכים קמורה.

ידוע שאם $`(k, l)`$ זוג מעריכים, אז [פונקציית זטא של רימן](https://he.wikipedia.org/wiki/%D7%A4%D7%95%D7%A0%D7%A7%D7%A6%D7%99%D7%99%D7%AA_%D7%96%D7%98%D7%90_%D7%A9%D7%9C_%D7%A8%D7%99%D7%9E%D7%9F) על הישר הקריטי מקיימת



```math
\zeta(1/2+i t) \ll t^\theta \log t,
```

 כאשר $`\theta = (k+l-1/2)/2`$.

**דוגמה (נוספה בתרגום).** מתחילים מהזוג הטריוויאלי $`(0, 1)`$. תהליך B נותן $`(1/2, 1/2)`$, ואחריו תהליך A נותן



```math
\left(\frac{1/2}{3},\ \frac{1/2 + 1/2 + 1}{3}\right) = \left(\frac16, \frac23\right).
```

 עבור הזוג הזה $`\theta = (1/6 + 2/3 - 1/2)/2 = 1/6`$, כלומר $`\zeta(1/2+it) \ll t^{1/6}\log t`$, החסם הקלאסי של ויל–הארדי–ליטלווד. (הזוג הטריוויאלי עצמו נותן $`\theta = 1/4`$.)

**השערת זוגות המעריכים** קובעת שלכל $`\varepsilon > 0`$, הזוג $`(\varepsilon, 1/2+\varepsilon)`$ הוא זוג מעריכים. השערה זו גוררת את [השערת לינדלף](%D7%94%D7%A9%D7%A2%D7%A8%D7%AA%20%D7%9C%D7%99%D7%A0%D7%93%D7%9C%D7%A3.md) (כי היא נותנת $`\theta = \varepsilon`$).
