# סכום גאוס

ב[תורת המספרים האלגברית](https://he.wikipedia.org/wiki/%D7%AA%D7%95%D7%A8%D7%AA_%D7%94%D7%9E%D7%A1%D7%A4%D7%A8%D7%99%D7%9D_%D7%94%D7%90%D7%9C%D7%92%D7%91%D7%A8%D7%99%D7%AA), **סכום גאוס** הוא סוג מסוים של [סכום](https://he.wikipedia.org/wiki/%D7%98%D7%95%D7%A8_%28%D7%9E%D7%AA%D7%9E%D7%98%D7%99%D7%A7%D7%94%29) סופי של [שורשי יחידה](https://he.wikipedia.org/wiki/%D7%A9%D7%95%D7%A8%D7%A9_%D7%99%D7%97%D7%99%D7%93%D7%94), בדרך כלל מהצורה



```math
G(\chi) := G(\chi, \psi) = \sum \chi(r)\cdot\psi(r),
```

 כאשר הסכום הוא על האיברים $`r`$ של [חוג חילופי](https://he.wikipedia.org/wiki/%D7%97%D7%95%D7%92_%D7%97%D7%99%D7%9C%D7%95%D7%A4%D7%99) סופי $`R`$, $`\psi`$ הוא הומומורפיזם של חבורות מהחבורה החיבורית $`R^+`$ ל[מעגל היחידה](https://he.wikipedia.org/wiki/%D7%9E%D7%A2%D7%92%D7%9C_%D7%94%D7%99%D7%97%D7%99%D7%93%D7%94), ו-$`\chi`$ הוא הומומורפיזם של חבורות מחבורת היחידות $`R^\times`$ למעגל היחידה, שמורחב לאיברים $`r`$ שאינם יחידות על ידי הערך 0. סכומי גאוס הם המקבילות לשדות סופיים של [פונקציית גמא](https://he.wikipedia.org/wiki/%D7%A4%D7%95%D7%A0%D7%A7%D7%A6%D7%99%D7%99%D7%AA_%D7%92%D7%9E%D7%90).[^1]

סכומים כאלה נפוצים מאוד ב[תורת המספרים](https://he.wikipedia.org/wiki/%D7%AA%D7%95%D7%A8%D7%AA_%D7%94%D7%9E%D7%A1%D7%A4%D7%A8%D7%99%D7%9D). הם מופיעים, למשל, במשוואות הפונקציונליות של [פונקציות L של דיריכלה](https://he.wikipedia.org/wiki/%D7%A4%D7%95%D7%A0%D7%A7%D7%A6%D7%99%D7%99%D7%AA_L_%D7%A9%D7%9C_%D7%93%D7%99%D7%A8%D7%99%D7%9B%D7%9C%D7%94): עבור [קרקטר דיריכלה](https://he.wikipedia.org/wiki/%D7%A7%D7%A8%D7%A7%D7%98%D7%A8_%D7%93%D7%99%D7%A8%D7%99%D7%9B%D7%9C%D7%94) $`\chi`$, המשוואה שמקשרת בין $`L(s, \chi)`$ לבין $`L(1 - s, \bar\chi)`$ (כאשר $`\bar\chi`$ הקרקטר הצמוד המרוכב של $`\chi`$) מכילה את הגורם



```math
\frac{G(\chi)}{|G(\chi)|}
```

 (שנקרא "מספר השורש" של המשוואה הפונקציונלית).

## היסטוריה

המקרה שבו עסק במקור [קרל פרידריך גאוס](https://he.wikipedia.org/wiki/%D7%A7%D7%A8%D7%9C_%D7%A4%D7%A8%D7%99%D7%93%D7%A8%D7%99%D7%9A_%D7%92%D7%90%D7%95%D7%A1) הוא [סכום גאוס הריבועי](https://he.wikipedia.org/wiki/%D7%A1%D7%9B%D7%95%D7%9D_%D7%92%D7%90%D7%95%D7%A1_%D7%A8%D7%99%D7%91%D7%95%D7%A2%D7%99), שבו $`R`$ הוא שדה השאריות מודולו [מספר ראשוני](https://he.wikipedia.org/wiki/%D7%9E%D7%A1%D7%A4%D7%A8_%D7%A8%D7%90%D7%A9%D7%95%D7%A0%D7%99) $`p`$ ו-$`\chi`$ הוא [סמל לז'נדר](https://he.wikipedia.org/wiki/%D7%A1%D7%99%D7%9E%D7%9F_%D7%9C%D7%96%27%D7%A0%D7%93%D7%A8). במקרה הזה גאוס הוכיח ש-$`G(\chi) = \sqrt p`$ או $`i\sqrt p`$, לפי ש-$`p`$ שקול ל-1 או ל-3 מודולו 4 (את סכום גאוס הריבועי אפשר לחשב גם בעזרת [אנליזת פורייה](https://he.wikipedia.org/wiki/%D7%90%D7%A0%D7%9C%D7%99%D7%96%D7%AA_%D7%A4%D7%95%D7%A8%D7%99%D7%99%D7%94) וגם בעזרת אינטגרציה קווית).

צורה חלופית של סכום גאוס הזה היא



```math
\sum_{r=0}^{p-1} e^{2\pi i r^2/p}.
```

 (השוויון נובע מכך שכל שארית ריבועית שונה מאפס מופיעה בדיוק פעמיים כ-$`r^2`$, ו-$`\sum_{a} e^{2\pi i a/p} = 0`$.)

**בדיקה מספרית.** חישוב ישיר נותן $`G = 2.2360\ldots = \sqrt5`$ ל-$`p = 5`$, $`G = 3.6055\ldots = \sqrt{13}`$ ל-$`p = 13`$ (שניהם $`\equiv 1 \pmod 4`$), ו-$`G = 2.6457\ldots\, i = i\sqrt7`$ ל-$`p = 7`$, $`G = 3.3166\ldots\, i = i\sqrt{11}`$ ל-$`p = 11`$ (שניהם $`\equiv 3 \pmod 4`$).

סכומי גאוס ריבועיים קשורים הדוקות לתורת [פונקציות התטא](https://he.wikipedia.org/wiki/%D7%A4%D7%95%D7%A0%D7%A7%D7%A6%D7%99%D7%99%D7%AA_%D7%AA%D7%98%D7%90).

התורה הכללית של סכומי גאוס פותחה בתחילת המאה ה-19, בעזרת [סכומי יעקובי](%D7%A1%D7%9B%D7%95%D7%9D%20%D7%99%D7%A2%D7%A7%D7%95%D7%91%D7%99.md) והפירוק שלהם לראשוניים ב[שדות ציקלוטומיים](%D7%A9%D7%93%D7%94%20%D7%A6%D7%99%D7%A7%D7%9C%D7%95%D7%98%D7%95%D7%9E%D7%99.md). סכומי גאוס מעל חוג השאריות של השלמים מודולו $`N`$ הם צירופים לינאריים של סכומים קרובים שנקראים [מחזורי גאוס](%D7%9E%D7%97%D7%96%D7%95%D7%A8%20%D7%92%D7%90%D7%95%D7%A1%D7%99.md).

את הערך המוחלט של סכומי גאוס מוצאים בדרך כלל כיישום של משפט פלנשרל על חבורות סופיות. במקרה ש-$`R`$ שדה בן $`p`$ איברים ו-$`\chi`$ אינו טריוויאלי, הערך המוחלט הוא $`\sqrt p`$. קביעת הערך המדויק של סכומי גאוס כלליים, בעקבות התוצאה של גאוס במקרה הריבועי, היא בעיה ותיקה. (למקרים מסוימים ראו **סכום קומר**: כבר לסכומי גאוס של קרקטר מסדר 3, ידוע ש-$`G(\chi)^3 = pJ(\chi, \chi)`$, אבל בחירת השורש השלישי הנכון היא בעיה עמוקה.)

## תכונות של סכומי גאוס של קרקטרי דיריכלה

סכום גאוס של [קרקטר דיריכלה](https://he.wikipedia.org/wiki/%D7%A7%D7%A8%D7%A7%D7%98%D7%A8_%D7%93%D7%99%D7%A8%D7%99%D7%9B%D7%9C%D7%94) מודולו $`N`$ הוא



```math
G(\chi) = \sum_{a=1}^N \chi(a)e^{2\pi ia/N}.
```

 אם $`\chi`$ גם [פרימיטיבי](https://he.wikipedia.org/wiki/%D7%A7%D7%A8%D7%A7%D7%98%D7%A8_%D7%93%D7%99%D7%A8%D7%99%D7%9B%D7%9C%D7%94), אז



```math
|G(\chi)| = \sqrt N,
```

 ובפרט הוא שונה מאפס. באופן כללי יותר, אם $`N_0`$ הוא המוליך של $`\chi`$ ו-$`\chi_0`$ הקרקטר הפרימיטיבי מודולו $`N_0`$ שמשרה את $`\chi`$, אז סכום הגאוס של $`\chi`$ קשור לזה של $`\chi_0`$ על ידי



```math
G(\chi) = \mu\left(\frac{N}{N_0}\right)\chi_0\left(\frac{N}{N_0}\right)G(\chi_0),
```

 כאשר $`\mu`$ [פונקציית מביוס](https://he.wikipedia.org/wiki/%D7%A4%D7%95%D7%A0%D7%A7%D7%A6%D7%99%D7%99%D7%AA_%D7%9E%D7%91%D7%99%D7%95%D7%A1). כתוצאה, $`G(\chi)`$ שונה מאפס בדיוק כאשר $`N/N_0`$ [חופשי מריבועים](%D7%9E%D7%A1%D7%A4%D7%A8%20%D7%97%D7%95%D7%A4%D7%A9%D7%99%20%D7%9E%D7%A8%D7%99%D7%91%D7%95%D7%A2%D7%99%D7%9D.md) וזר ל-$`N_0`$.[^2]

**דוגמה.** יהי $`\chi_{-4}`$ הקרקטר הפרימיטיבי מודולו 4 ($`\chi_{-4}(1) = 1`$, $`\chi_{-4}(3) = -1`$), כך ש-$`G(\chi_{-4}) = i - (-i) = 2i`$, עם $`|G| = 2 = \sqrt4`$. יהי $`\chi`$ הקרקטר מודולו 12 שהוא משרה. כאן $`N/N_0 = 3`$, $`\mu(3) = -1`$ ו-$`\chi_{-4}(3) = -1`$, ולכן $`G(\chi) = (-1)(-1)\cdot 2i = 2i`$ – וחישוב ישיר של $`\sum_{a \in \{1, 5, 7, 11\} }\chi(a)e^{2\pi ia/12}`$ אכן נותן $`2i`$. כאן $`|G(\chi)| = 2 \ne \sqrt{12}`$, כי $`\chi`$ אינו פרימיטיבי.

יחסים נוספים בין $`G(\chi)`$ לבין סכומי גאוס של קרקטרים אחרים:



```math
G(\bar\chi) = \chi(-1)\overline{G(\chi)},
```

 כאשר $`\bar\chi`$ קרקטר הדיריכלה הצמוד; ואם $`\chi'`$ קרקטר דיריכלה מודולו $`N'`$ כך ש-$`N`$ ו-$`N'`$ זרים, אז



```math
G(\chi\chi') = \chi(N')\chi'(N)G(\chi)G(\chi').
```

 היחס בין $`G(\chi\chi')`$, $`G(\chi)`$ ו-$`G(\chi')`$ כש-$`\chi`$ ו-$`\chi'`$ מאותו מודולוס (ו-$`\chi\chi'`$ פרימיטיבי) נמדד על ידי [סכום יעקובי](%D7%A1%D7%9B%D7%95%D7%9D%20%D7%99%D7%A2%D7%A7%D7%95%D7%91%D7%99.md) $`J(\chi, \chi')`$:



```math
G(\chi\chi') = \frac{G(\chi)G(\chi')}{J(\chi, \chi')}.
```



## תכונות נוספות

- אפשר להשתמש בסכומי גאוס כדי להוכיח את [חוק ההדדיות הריבועית](https://he.wikipedia.org/wiki/%D7%97%D7%95%D7%A7_%D7%94%D7%94%D7%93%D7%93%D7%99%D7%95%D7%AA_%D7%94%D7%A8%D7%99%D7%91%D7%95%D7%A2%D7%99%D7%AA), [ההדדיות ממעלה שלישית](%D7%94%D7%93%D7%93%D7%99%D7%95%D7%AA%20%D7%9E%D7%9E%D7%A2%D7%9C%D7%94%20%D7%A9%D7%9C%D7%99%D7%A9%D7%99%D7%AA.md) ו[ההדדיות ממעלה רביעית](%D7%94%D7%93%D7%93%D7%99%D7%95%D7%AA%20%D7%9E%D7%9E%D7%A2%D7%9C%D7%94%20%D7%A8%D7%91%D7%99%D7%A2%D7%99%D7%AA.md). (הרעיון בהדדיות הריבועית: $`G^2 = \left(\tfrac{-1}{p}\right)p = p^*`$, ולכן $`\sqrt{p^*} \in \mathbb Q(\zeta_p)`$; מחשבים את $`G^q`$ מודולו $`q`$ בשתי דרכים.)
- אפשר להשתמש בסכומי גאוס כדי לחשב את מספר הפתרונות של משוואות פולינומיות מעל שדות סופיים, ולכן גם כדי לחשב פונקציות זטא מסוימות (ראו [סכום יעקובי](%D7%A1%D7%9B%D7%95%D7%9D%20%D7%99%D7%A2%D7%A7%D7%95%D7%91%D7%99.md) ו[יחס האסה–דבנפורט](%D7%99%D7%97%D7%A1%20%D7%94%D7%90%D7%A1%D7%94%E2%80%93%D7%93%D7%91%D7%A0%D7%A4%D7%95%D7%A8%D7%98.md)).
