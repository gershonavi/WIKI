# משפט פרידלנדר-איוואניץ

ב[תורת המספרים האנליטית](%D7%AA%D7%95%D7%A8%D7%AA%20%D7%94%D7%9E%D7%A1%D7%A4%D7%A8%D7%99%D7%9D%20%D7%94%D7%90%D7%A0%D7%9C%D7%99%D7%98%D7%99%D7%AA.md), **משפט פרידלנדר–איוואניץ** (ב[אנגלית](https://he.wikipedia.org/wiki/%D7%90%D7%A0%D7%92%D7%9C%D7%99%D7%AA): Friedlander–Iwaniec theorem) קובע שיש אינסוף [מספרים ראשוניים](https://he.wikipedia.org/wiki/%D7%9E%D7%A1%D7%A4%D7%A8_%D7%A8%D7%90%D7%A9%D7%95%D7%A0%D7%99) מהצורה $`a^2 + b^4`$. הראשוניים הראשונים מהצורה הזו הם

  
2, 5, 17, 37, 41, 97, 101, 137, 181, 197, 241, 257, 277, 281, 337, 401, 457, 577, 617, 641, 661, 677, 757, 769, 821, 857, 881, 977, … (סדרה [A028916](https://oeis.org/A028916) ב-OEIS).

הקושי בטענה נובע מהדלילות הרבה של הסדרה: מספר המספרים השלמים מהצורה $`a^2+b^4`$ הקטנים מ-$`X`$ הוא בערך מסדר גודל של $`X^{3/4}`$. (יש בערך $`\sqrt X`$ בחירות ל-$`a`$ ו-$`X^{1/4}`$ בחירות ל-$`b`$.) לשם השוואה, ראשוניים מהצורה $`a^2 + b^2`$ – כלומר כל הראשוניים החופפים ל-1 מודולו 4 – מוכרים מאז פרמה, אבל במקרה זה מספר הערכים עד $`X`$ הוא מסדר $`X`$, ושיטות הנפה הרגילות מתמודדות איתו.

## היסטוריה

את המשפט הוכיחו ב-1997 ג'ון פרידלנדר והנריק איוואניץ.[^1][^2] איוואניץ זכה ב-2001 ב[פרס אוסטרובסקי](https://he.wikipedia.org/wiki/%D7%A4%D7%A8%D7%A1_%D7%90%D7%95%D7%A1%D7%98%D7%A8%D7%95%D7%91%D7%A1%D7%A7%D7%99), בין השאר בזכות תרומתו לעבודה זו.[^3] כפי שמרמזת כותרת המאמר הראשון, ההוכחה משתמשת בנפה שמסוגלת להבחין בזוגיות של מספר הגורמים הראשוניים – וכך לעקוף את "בעיית הזוגיות" שמונעת מנפות רגילות לספור ראשוניים.

למעשה הם הוכיחו נוסחה אסימפטוטית: אם סופרים את הראשוניים $`a^2 + b^4 \le x`$ עם ריבוי, על פני כל הזוגות $`(a, b)`$ של מספרים שלמים (חיוביים ושליליים), אז המספר שלהם הוא



```math
f(x) \sim v \frac{x^{3/4} }{\log{x} },
```

 כאשר



```math
v=2 \sqrt{\pi} \frac{\Gamma(5/4)}{\Gamma(7/4)} \prod_{p \equiv 1\bmod 4} \frac{p-2}{p-1} \prod_{p \equiv 3\bmod 4} \frac{p}{p-1} \approx 4.80.
```

 (בערך האנגלי הנוסחה מיוחסת לעידון של הית'-בראון ולי, שבו $`b`$ ראשוני. בדיקה מספרית מראה שהיא מתאימה לספירה שבה $`b`$ הוא מספר שלם כלשהו: עבור $`x = 10^8`$ יש 65,162 זוגות $`(a, b)`$ עם $`a, b \geq 1`$, כלומר $`4 \cdot 65{,}162 = 260{,}648`$ זוגות של שלמים, ואילו הנוסחה נותנת כ-260,486.)

## עידונים

את המשפט עידנו רוג'ר הית'-בראון ושיאננן לי ב-2017.[^4] בפרט, הם הוכיחו שהפולינום $`a^2 + b^4`$ מקבל אינסוף ערכים ראשוניים גם כאשר דורשים שגם המשתנה $`b`$ יהיה ראשוני.

ב-2024 הכליל מאמר של סטנלי יאו שיאו[^5] את המשפטים של פרידלנדר–איוואניץ ושל הית'-בראון–לי ל[תבניות ריבועיות בינאריות](https://he.wikipedia.org/wiki/%D7%AA%D7%91%D7%A0%D7%99%D7%AA_%D7%A8%D7%99%D7%91%D7%95%D7%A2%D7%99%D7%AA_%D7%91%D7%99%D7%A0%D7%90%D7%A8%D7%99%D7%AA) כלליות, כולל תבניות לא מוגדרות. בפרט, עבור $`f(x,y) \in \mathbb{Z}[x,y]`$ תבנית ריבועית בינארית מוגדרת חיובית המקיימת $`f(x,1) \not \equiv x(x+1) \pmod{2}`$, נסמן ב-$`\lambda`$ את ה[פונקציה המציינת](https://he.wikipedia.org/wiki/%D7%A4%D7%95%D7%A0%D7%A7%D7%A6%D7%99%D7%94_%D7%9E%D7%A6%D7%99%D7%99%D7%A0%D7%AA) של הראשוניים, ונגדיר



```math
\mathfrak{S}_f = \mathrm{Area} \{(x,y) \in \mathbb{R}^2 : f(x,y^2) \leq 1\}
```

 ו-



```math
\nu_f = \prod_{p \nmid \Delta(f)} \left(1 - \frac{\rho_f(p)}{p} \right) \left(1 - \frac{1}{p} \right)^{-1} \prod_{p \mid \Delta(f)} \left(1 - \frac{1}{p} \right)^{-1},
```

 כאשר $`\rho_f(m) = \# \{x \bmod m : f(x,1) \equiv 0 \pmod{m}\}`$. אז מתקיימת הנוסחה האסימפטוטית



```math
\sum_{\substack{m, \ell \in \mathbb{Z}\\ f(m,\ell^2) \leq X} } \lambda(f(m, \ell^2)) = \frac{\nu_f \mathfrak{S}_f X^{3/4} }{\log X}\left(1 + O \left(\frac{\log \log X}{\log X} \right) \right).
```

 כאן $`\Delta(f)`$ היא ה[דיסקרימיננטה](https://he.wikipedia.org/wiki/%D7%93%D7%99%D7%A1%D7%A7%D7%A8%D7%99%D7%9E%D7%99%D7%A0%D7%A0%D7%98%D7%94) של התבנית הריבועית $`f`$.

עבור תבניות לא מוגדרות ואי-פריקות $`f(x,y) \in \mathbb{Z}[x,y]`$ המקיימות $`f(x,1) \not \equiv x(x+1) \pmod{2}`$, נגדיר



```math
\mathfrak{S}_f = \lim_{X \rightarrow \infty} \frac{\mathrm{Area}\{(x,y) \in \mathbb{R}^2 : 0< f(x,y^2) \leq X,\ 0 < y < X^{1/4} \} }{X^{3/4} }.
```

 אז מתקיימת הנוסחה האסימפטוטית



```math
\sum_{\substack{m, \ell \in \mathbb{Z}\\ f(m,\ell^2) \leq X \\ 0 < \ell \leq X^{3/4} } } \lambda (f(m, \ell^2)) = \frac{\nu_f \mathfrak{S}_f X^{3/4} }{\log X} \left(1 + O \left(\frac{\log \log X}{\log X} \right) \right).
```



## מקרה פרטי

כאשר $`b = 1`$, ראשוני פרידלנדר–איוואניץ הם מהצורה $`a^2+1`$, והם יוצרים את הקבוצה

  
2, 5, 17, 37, 101, 197, 257, 401, 577, 677, 1297, 1601, 2917, 3137, 4357, 5477, 7057, 8101, 8837, 12101, 13457, 14401, 15377, … (סדרה [A002496](https://oeis.org/A002496) ב-OEIS).

לפי השערה (אחת מ[בעיות לנדאו](https://he.wikipedia.org/wiki/%D7%91%D7%A2%D7%99%D7%95%D7%AA_%D7%9C%D7%A0%D7%93%D7%90%D7%95)) הקבוצה הזו אינסופית. אולם זה אינו נובע ממשפט פרידלנדר–איוואניץ.
