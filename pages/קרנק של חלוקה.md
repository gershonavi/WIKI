# קרנק של חלוקה

ב[תורת המספרים](https://he.wikipedia.org/wiki/%D7%AA%D7%95%D7%A8%D7%AA_%D7%94%D7%9E%D7%A1%D7%A4%D7%A8%D7%99%D7%9D), **הקרנק** (ב[אנגלית](https://he.wikipedia.org/wiki/%D7%90%D7%A0%D7%92%D7%9C%D7%99%D7%AA): crank) של [חלוקה של מספר שלם](https://he.wikipedia.org/wiki/%D7%97%D7%9C%D7%95%D7%A7%D7%94_%28%D7%A7%D7%95%D7%9E%D7%91%D7%99%D7%A0%D7%98%D7%95%D7%A8%D7%99%D7%A7%D7%94%29) הוא מספר מסוים הקשור לחלוקה. [פרימן דייסון](https://he.wikipedia.org/wiki/%D7%A4%D7%A8%D7%99%D7%9E%D7%9F_%D7%93%D7%99%D7%99%D7%A1%D7%95%D7%9F) הציג אותו לראשונה בלי הגדרה, כשהשער את קיומו במאמר מ-1944.[^1] דייסון נתן רשימה של תכונות שהגודל הזה, שעדיין לא הוגדר, אמור לקיים. ב-1988 גילו ג'ורג' אנדרוז ופרנק גרבן הגדרה לקרנק שמקיימת את התכונות שדייסון שיער.[^2]

## הקרנק של דייסון

יהי $`n`$ שלם אי-שלילי, ויהי $`p(n)`$ מספר החלוקות של $`n`$ (מגדירים $`p(0) = 1`$). [סריניוואסה רמנוג'אן](https://he.wikipedia.org/wiki/%D7%A1%D7%A8%D7%99%D7%A0%D7%99%D7%95%D7%95%D7%90%D7%A1%D7%94_%D7%A8%D7%9E%D7%A0%D7%95%D7%92%27%D7%90%D7%9F) ניסח והוכיח במאמר[^3] את החפיפות הבאות של [פונקציית החלוקה](https://he.wikipedia.org/wiki/%D7%A4%D7%95%D7%A0%D7%A7%D7%A6%D7%99%D7%99%D7%AA_%D7%94%D7%97%D7%9C%D7%95%D7%A7%D7%94) $`p(n)`$, הידועות מאז כחפיפות רמנוג'אן:

- $`p(5n + 4) \equiv 0 \pmod 5`$
- $`p(7n + 5) \equiv 0 \pmod 7`$
- $`p(11n + 6) \equiv 0 \pmod{11}`$

מהחפיפות האלה נובע שאפשר לחלק את החלוקות של מספרים מהצורה $`5n + 4`$ (בהתאמה, מהצורות $`7n + 5`$ ו-$`11n + 6`$) ל-5 (בהתאמה, 7 ו-11) תת-מחלקות שוות בגודלן. ההוכחות של החפיפות שהיו ידועות אז התבססו על רעיון הפונקציות היוצרות, ולא נתנו שיטה לחלוקת החלוקות לתת-מחלקות שוות בגודלן.

במאמרו ב-Eureka הציע דייסון את מושג [הדרגה של חלוקה](%D7%93%D7%A8%D7%92%D7%94%20%D7%A9%D7%9C%20%D7%97%D7%9C%D7%95%D7%A7%D7%94.md). דרגת חלוקה היא השלם המתקבל מחיסור מספר החלקים בחלוקה מהחלק הגדול ביותר. למשל, הדרגה של החלוקה $`\lambda = \{4, 2, 1, 1, 1\}`$ של 9 היא $`4 - 5 = -1`$. דייסון סימן ב-$`N(m, q, n)`$ את מספר החלוקות של $`n`$ שדרגתן חופפת ל-$`m`$ מודולו $`q`$, והתבונן ב-$`N(m, 5, 5n + 4)`$ וב-$`N(m, 7, 7n + 5)`$ לערכים שונים של $`n`$ ו-$`m`$. על סמך עדויות אמפיריות ניסח דייסון את ההשערות הבאות, הידועות כ*השערות הדרגה*. לכל שלם אי-שלילי $`n`$:

- $`N(0, 5, 5n + 4) = N(1, 5, 5n + 4) = N(2, 5, 5n + 4) = N(3, 5, 5n + 4) = N(4, 5, 5n + 4)`$.
- $`N(0, 7, 7n + 5) = N(1, 7, 7n + 5) = \dots = N(6, 7, 7n + 5)`$.

בהנחה שההשערות האלה נכונות, הן נותנות דרך לחלק את כל החלוקות של מספרים מהצורה $`5n + 4`$ לחמש מחלקות שוות בגודלן: שמים במחלקה אחת את כל החלוקות שדרגותיהן חופפות זו לזו מודולו 5. אפשר להפעיל אותו רעיון כדי לחלק את החלוקות של שלמים מהצורה $`7n + 5`$ לשבע מחלקות שוות בגודלן. אבל הרעיון נכשל בחלוקת החלוקות של שלמים מהצורה $`11n + 6`$ ל-11 מחלקות שוות, כפי שמראה הטבלה הבאה.

**החלוקות של המספר 6 ($`11n + 6`$ עם $`n = 0`$), מחולקות למחלקות לפי הדרגה מודולו 11**

| ≡ 0 (mod 11) | ≡ 1 (mod 11) | ≡ 2 (mod 11) | ≡ 3 (mod 11) | ≡ 4 (mod 11) | ≡ 5 (mod 11) | ≡ 6 (mod 11)         | ≡ 7 (mod 11) | ≡ 8 (mod 11)      | ≡ 9 (mod 11)   | ≡ 10 (mod 11)  |
|--------------|--------------|--------------|--------------|--------------|--------------|----------------------|--------------|-------------------|----------------|----------------|
| { 3, 2, 1 }  | { 4, 1, 1 }  | { 4, 2 }     | { 5, 1 }     |              | { 6 }        | { 1, 1, 1, 1, 1, 1 } |              | { 2, 1, 1, 1, 1 } | { 2, 2, 1, 1 } | { 3, 1, 1, 1 } |
|              | { 3, 3 }     |              |              |              |              |                      |              |                   |                | { 2, 2, 2 }    |

לכן אי אפשר להשתמש בדרגה כדי להוכיח את המשפט בדרך קומבינטורית. אבל דייסון כתב (בתרגום חופשי):

  
*אני טוען למעשה:*

- *שקיים מקדם אריתמטי, דומה לדרגה של חלוקה אבל נסתר ממנה; אקרא למקדם ההיפותטי הזה "הקרנק" של החלוקה, ואסמן ב-$`M(m, q, n)`$ את מספר החלוקות של $`n`$ שהקרנק שלהן חופף ל-$`m`$ מודולו $`q`$;*
- *ש-$`M(m, q, n) = M(q - m, q, n)`$;*
- *ש-$`M(0, 11, 11n + 6) = M(1, 11, 11n + 6) = M(2, 11, 11n + 6) = M(3, 11, 11n + 6) = M(4, 11, 11n + 6)`$;*
- *ש...*

*אם הניחושים האלה מוצדקים על ידי העדויות, אני משאיר לקורא להחליט. מה שלא יהיה פסק הדין הסופי של הדורות הבאים, אני מאמין שה"קרנק" הוא יחיד במינו בין הפונקציות האריתמטיות בכך שקיבל שם לפני שהתגלה. מי ייתן וישמר מהגורל המביש של כוכב הלכת וולקן.*

## הגדרת הקרנק

במאמר שפורסם ב-1988[^4] הגדירו ג'ורג' אנדרוז ופ. ג. גרבן את הקרנק של חלוקה כך:

  
עבור חלוקה $`\lambda`$, יהי $`\ell(\lambda)`$ החלק הגדול ביותר של $`\lambda`$, יהי $`\omega(\lambda)`$ מספר האחדות ב-$`\lambda`$, ויהי $`\mu(\lambda)`$ מספר החלקים של $`\lambda`$ הגדולים מ-$`\omega(\lambda)`$. הקרנק $`c(\lambda)`$ נתון על ידי

  
$`c(\lambda)=\begin{cases} \ell(\lambda), & \omega(\lambda)=0, \\ \mu(\lambda)-\omega(\lambda), & \omega(\lambda)>0.\end{cases}`$

הקרנקים של החלוקות של המספרים 4, 5 ו-6 מחושבים בטבלאות הבאות. (כל הטבלאות בערך חושבו מחדש ונמצאו זהות לאלה שבמקור.)

## סימונים

לכל שלם $`n \ge 0`$ ולכל שלם $`m`$, מספר החלוקות של $`n`$ שהקרנק שלהן שווה ל-$`m`$ מסומן $`M(m,n)`$, פרט ל-$`n = 1`$, שעבורו $`M(-1,1) = -M(0,1) = M(1,1) = 1`$, כפי שנותנת הפונקציה היוצרת שלהלן. מספר החלוקות של $`n`$ שהקרנק שלהן חופף ל-$`m`$ מודולו $`q`$ מסומן $`M(m,q,n)`$.

הפונקציה היוצרת של $`M(m,n)`$ היא:



```math
\sum_{n=0}^{\infty}\sum_{m=-\infty}^\infty M(m,n) z^mq^n = \prod_{n=1}^\infty \frac{1-q^n}{(1-zq^n)(1-z^{-1}q^n)}.
```

 (הסבר למקרה $`n = 1`$: המקדם של $`q`$ במכפלה הוא $`z + z^{-1} - 1`$. לחלוקה היחידה $`\{1\}`$ לפי ההגדרה יש קרנק $`0 - 1 = -1`$, ולכן $`n = 1`$ הוא מקרה חריג.)

## התוצאה הבסיסית

אנדרוז וגרבן הוכיחו את התוצאה הבאה,[^5] המראה שהקרנק כפי שהוגדר למעלה אכן מקיים את התנאים שנתן דייסון.

- $`M(0, 5, 5n + 4) = M(1, 5, 5n + 4) = \dots = M(4, 5, 5n + 4) = p(5n + 4) / 5`$
- $`M(0, 7, 7n + 5) = M(1, 7, 7n + 5) = \dots = M(6, 7, 7n + 5) = p(7n + 5) / 7`$
- $`M(0, 11, 11n + 6) = M(1, 11, 11n + 6) = \dots = M(10, 11, 11n + 6) = p(11n + 6) / 11`$

(בדיקה מספרית: עבור $`4, 9, 14`$ ומודולו 5 כל מחלקה מכילה 1, 6 ו-27 חלוקות; עבור $`5, 12`$ ומודולו 7 – 1 ו-11; עבור $`6, 17`$ ומודולו 11 – 1 ו-27.)

אפשר להשתמש גם בדרגה וגם בקרנק כדי לסווג חלוקות של שלמים מסוימים לתת-מחלקות שוות בגודלן. אבל שני המושגים נותנים תת-מחלקות שונות. זה מודגם בשתי הטבלאות הבאות; החלוקות המודגשות הן אלה שהקרנק שלהן $`\equiv 0 \pmod 5`$, וניתן לראות שלפי הדרגה הן מתפזרות על פני כמה מחלקות.

## רמנוג'אן והקרנקים

עבודות מהשנים האחרונות של ברוס ברנדט ושותפיו טוענות שרמנוג'אן ידע על הקרנק, אם כי לא בצורה שהגדירו אנדרוז וגרבן. במחקר שיטתי של "המחברת האבודה" של רמנוג'אן, נתנו ברנדט ושותפיו עדויות משמעותיות לכך שרמנוג'אן הכיר את הפירוקים של הפונקציה היוצרת של הקרנק.[^6][^7]
