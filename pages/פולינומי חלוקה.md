# פולינומי חלוקה

ב[מתמטיקה](https://he.wikipedia.org/wiki/%D7%9E%D7%AA%D7%9E%D7%98%D7%99%D7%A7%D7%94), **פולינומי חלוקה** (division polynomials) נותנים דרך לחשב כפולות של נקודות על [עקומים אליפטיים](https://he.wikipedia.org/wiki/%D7%A2%D7%A7%D7%95%D7%9D_%D7%90%D7%9C%D7%99%D7%A4%D7%98%D7%99), ולחקור את השדות שנוצרים על ידי נקודות פיתול. יש להם תפקיד מרכזי ב[ספירת נקודות על עקומים אליפטיים](%D7%A1%D7%A4%D7%99%D7%A8%D7%AA%20%D7%A0%D7%A7%D7%95%D7%93%D7%95%D7%AA%20%D7%A2%D7%9C%20%D7%A2%D7%A7%D7%95%D7%9E%D7%99%D7%9D%20%D7%90%D7%9C%D7%99%D7%A4%D7%98%D7%99%D7%99%D7%9D.md), ב[אלגוריתם של סחוף](%D7%94%D7%90%D7%9C%D7%92%D7%95%D7%A8%D7%99%D7%AA%D7%9D%20%D7%A9%D7%9C%20%D7%A1%D7%97%D7%95%D7%A3.md).

## הגדרה

פולינומי החלוקה הם סדרה של [פולינומים](https://he.wikipedia.org/wiki/%D7%A4%D7%95%D7%9C%D7%99%D7%A0%D7%95%D7%9D) ב-$`\mathbb{Z}[x,y,A,B]`$, כאשר $`x, y, A, B`$ משתנים חופשיים, שמוגדרת ברקורסיה:



```math
\psi_{0} = 0
```





```math
\psi_{1} = 1
```





```math
\psi_{2} = 2y
```





```math
\psi_{3} = 3x^{4} + 6Ax^{2} + 12Bx - A^{2}
```





```math
\psi_{4} = 4y(x^{6} + 5Ax^{4} + 20Bx^{3} - 5A^{2}x^{2} - 4ABx - 8B^{2} - A^{3})
```





```math
\vdots
```





```math
\psi_{2m+1} = \psi_{m+2} \psi_{m}^{3} - \psi_{m-1} \psi^{3}_{m+1} \quad (m \geq 2)
```





```math
\psi_{2m} = \left( \frac{\psi_{m} }{2y} \right) \cdot ( \psi_{m+2}\psi^{2}_{m-1} - \psi_{m-2} \psi^{2}_{m+1}) \quad (m \geq 3)
```

 הפולינום $`\psi_n`$ נקרא פולינום החלוקה ה-$`n`$-י.

## תכונות

- בפועל מציבים $`y^2=x^3+Ax+B`$, ואז $`\psi_{2m+1}\in\mathbb{Z}[x,A,B]`$ ו-$`\psi_{2m}\in 2y\,\mathbb{Z}[x,A,B]`$. כפולינום ב-$`x`$, ל-$`n`$ אי-זוגי $`\deg\psi_n = \tfrac{n^2 - 1}{2}`$ (למשל 4, 12, 24 ל-$`n = 3, 5, 7`$).
- פולינומי החלוקה יוצרים [סדרת התחלקות אליפטית](%D7%A1%D7%93%D7%A8%D7%AA%20%D7%94%D7%AA%D7%97%D7%9C%D7%A7%D7%95%D7%AA%20%D7%90%D7%9C%D7%99%D7%A4%D7%98%D7%99%D7%AA.md) גנרית מעל החוג $`\mathbb{Q}[x,y,A,B]/(y^2-x^3-Ax-B)`$.
- אם [עקום אליפטי](https://he.wikipedia.org/wiki/%D7%A2%D7%A7%D7%95%D7%9D_%D7%90%D7%9C%D7%99%D7%A4%D7%98%D7%99) $`E`$ נתון בצורת ויירשטראס $`y^2=x^3+Ax+B`$ מעל שדה $`K`$, כלומר $`A, B\in K`$, אפשר להציב את הערכים האלה ולהתבונן בפולינומי החלוקה בחוג הקואורדינטות של $`E`$. השורשים של $`\psi_{2n+1}`$ הם קואורדינטות ה-$`x`$ של הנקודות ב-$`E[2n+1]\setminus \{O\}`$, כאשר $`E[2n+1]`$ תת-חבורת הפיתול מסדר $`2n+1`$ של $`E`$. באופן דומה, השורשים של $`\psi_{2n}/y`$ הם קואורדינטות ה-$`x`$ של הנקודות ב-$`E[2n]\setminus E[2]`$.
- בהינתן נקודה $`P=(x_P,y_P)`$ על העקום $`E:y^2=x^3+Ax+B`$ מעל שדה $`K`$, אפשר לבטא את הקואורדינטות של הכפולה ה-$`n`$-ית של $`P`$ בעזרת פולינומי החלוקה:



```math
nP= \left( \frac{\phi_{n}(x)}{\psi_{n}^{2}(x)}, \frac{\omega_{n}(x,y)}{\psi^{3}_{n}(x,y)} \right) = \left( x - \frac {\psi_{n-1} \psi_{n+1} }{\psi^{2}_{n}(x)}, \frac{\psi_{2 n}(x,y)}{2\psi^{4}_{n}(x)} \right)
```



  
כאשר



```math
\phi_{n}=x\psi_{n}^{2} - \psi_{n+1}\psi_{n-1},
```





```math
\omega_{n}=\frac{\psi_{n+2}\psi_{n-1}^{2}-\psi_{n-2}\psi_{n+1}^{2} }{4y}.
```



בעזרת הקשר בין $`\psi_{2m}`$ ל-$`\psi _{2m + 1}`$, ומשוואת העקום, הפונקציות $`\psi_{n}^{2}`$, $`\psi_{2n}/y`$, $`\psi_{2n + 1}`$ ו-$`\phi_{n}`$ כולן ב-$`K[x]`$.

### דוגמה

לעקום $`y^2 = x^3 - 2`$ (כלומר $`A = 0`$, $`B = -2`$) ולנקודה $`P = (3, 5)`$: $`\psi_2 = 10`$, $`\psi_3 = 3\cdot 81 - 24\cdot 3 = 171`$, ולכן $`x(2P) = 3 - \frac{\psi_1\psi_3}{\psi_2^2} = 3 - \frac{171}{100} = \frac{129}{100}`$, בהתאם לחישוב בחוק החיבור. מהנוסחאות מקבלים גם $`3P = \left(\tfrac{164323}{29241}, -\tfrac{66234835}{5000211}\right)`$ (שימו לב: $`29241 = 171^2`$), וכך הלאה; בדקנו בחישוב את הנוסחאות עד $`5P`$.

## מעל שדות סופיים

יהי $`p\gt 3`$ ראשוני ו-$`E:y^2=x^3+Ax+B`$ עקום אליפטי מעל השדה הסופי $`\mathbb{F}_p`$. חבורת ה-$`\ell`$-פיתול של $`E`$ מעל $`\overline{\mathbb{F} }_p`$ איזומורפית ל-$`\mathbb{Z}/\ell \times \mathbb{Z}/\ell`$ אם $`\ell\neq p`$, ול-$`\mathbb{Z}/\ell`$ או $`\{0\}`$ אם $`\ell=p`$ (העקום **רגיל** או [על-סינגולרי](%D7%A2%D7%A7%D7%95%D7%9D%20%D7%90%D7%9C%D7%99%D7%A4%D7%98%D7%99%20%D7%A2%D7%9C-%D7%A1%D7%99%D7%A0%D7%92%D7%95%D7%9C%D7%A8%D7%99.md), בהתאמה). לכן, ל-$`\ell`$ ראשוני אי-זוגי, ל-$`\psi_\ell`$ יש $`\tfrac{1}{2}(\ell^2-1)`$ שורשים שונים כש-$`\ell \ne p`$, ו-$`\tfrac12(p - 1)`$ או 0 שורשים שונים כש-$`\ell = p`$.[^1]

רנה סחוף הבחין שעבודה מודולו פולינום החלוקה ה-$`\ell`$-י מאפשרת לטפל בכל נקודות ה-$`\ell`$-פיתול בבת אחת: פרובניוס $`\phi`$ מקיים $`\phi^2 - a\phi + p = 0`$ על $`E[\ell]`$, ומחשבים את $`a \bmod \ell`$ על ידי בדיקת הזהות הזו בחוג $`\mathbb F_p[x, y]/(\psi_\ell, y^2 - x^3 - Ax - B)`$. אחרי מספיק ראשוניים $`\ell`$ (עד שמכפלתם עולה על $`4\sqrt p`$), [משפט השאריות הסיני](https://he.wikipedia.org/wiki/%D7%9E%D7%A9%D7%A4%D7%98_%D7%94%D7%A9%D7%90%D7%A8%D7%99%D7%95%D7%AA_%D7%94%D7%A1%D7%99%D7%A0%D7%99) ו[חסם האסה](%D7%9E%D7%A9%D7%A4%D7%98%20%D7%94%D7%90%D7%A1%D7%94%20%D7%A2%D7%9C%20%D7%A2%D7%A7%D7%95%D7%9E%D7%99%D7%9D%20%D7%90%D7%9C%D7%99%D7%A4%D7%98%D7%99%D7%99%D7%9D.md) קובעים את $`a`$. זה הבסיס ל[אלגוריתם של סחוף](%D7%94%D7%90%D7%9C%D7%92%D7%95%D7%A8%D7%99%D7%AA%D7%9D%20%D7%A9%D7%9C%20%D7%A1%D7%97%D7%95%D7%A3.md) לספירת נקודות על עקומים אליפטיים.

## הערות שוליים



[^1]: בערך האנגלי נכתב שהמעלה של $`\psi_\ell`$ שווה ל-$`\tfrac12(\ell^2 - 1)`$, ל-$`\tfrac12(\ell - 1)`$ או ל-0. במקרה $`\ell = p`$ זה נכון למספר השורשים ה**שונים**, אבל לא למעלה: הכפל ב-$`p`$ אינו ספרבילי, וכל שורש של $`\psi_p`$ מופיע בריבוי $`p`$, כך שלעקום רגיל המעלה היא $`\tfrac12p(p-1)`$. למשל ל-$`y^2 = x^3 - x`$ מעל $`\mathbb F_5`$ (רגיל, $`a_5 = -2`$): $`\psi_5 \equiv -2x^{10} + 1 = -2(x^2 - 3)^5 \pmod 5`$, ממעלה 10 עם שני שורשים שונים. ול-$`y^2 = x^3 + 1`$ מעל $`\mathbb F_5`$ (על-סינגולרי): $`\psi_5 \equiv -1`$. בדקנו בחישוב.
