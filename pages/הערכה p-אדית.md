# הערכה p-אדית

ב[תורת המספרים](https://he.wikipedia.org/wiki/%D7%AA%D7%95%D7%A8%D7%AA_%D7%94%D7%9E%D7%A1%D7%A4%D7%A8%D7%99%D7%9D), **ההערכה ה-$`p`$-אדית** או **הסדר ה-$`p`$-אדי** של [מספר שלם](https://he.wikipedia.org/wiki/%D7%9E%D7%A1%D7%A4%D7%A8_%D7%A9%D7%9C%D7%9D) $`n`$ הוא המעריך של החזקה הגבוהה ביותר של ה[מספר הראשוני](https://he.wikipedia.org/wiki/%D7%9E%D7%A1%D7%A4%D7%A8_%D7%A8%D7%90%D7%A9%D7%95%D7%A0%D7%99) $`p`$ שמחלקת את $`n`$. מסמנים אותה $`\nu_p(n)`$. באופן שקול, $`\nu_p(n)`$ הוא המעריך שבו $`p`$ מופיע בפירוק לגורמים ראשוניים של $`n`$.

ההערכה ה-$`p`$-אדית היא [הערכה](https://he.wikipedia.org/wiki/%D7%94%D7%A2%D7%A8%D7%9B%D7%94_%28%D7%90%D7%9C%D7%92%D7%91%D7%A8%D7%94%29), והיא נותנת מקבילה ל[ערך המוחלט](https://he.wikipedia.org/wiki/%D7%A2%D7%A8%D7%9A_%D7%9E%D7%95%D7%97%D7%9C%D7%98) הרגיל; אבל בניגוד לערך המוחלט הרגיל, הערך המוחלט ה-$`p`$-אדי אינו ארכימדי. ההשלמה של המספרים הרציונליים ביחס לערך המוחלט הרגיל נותנת את ה[מספרים הממשיים](https://he.wikipedia.org/wiki/%D7%9E%D7%A1%D7%A4%D7%A8_%D7%9E%D7%9E%D7%A9%D7%99) $`\mathbb R`$, ואילו ההשלמה של המספרים הרציונליים ביחס לערך המוחלט ה-$`p`$-אדי נותנת את ה[מספרים ה-$`p`$-אדיים](https://he.wikipedia.org/wiki/%D7%9E%D7%A1%D7%A4%D7%A8_p-%D7%90%D7%93%D7%99) $`\mathbb Q_p`$.[^1]

## הגדרה ותכונות

יהי $`p`$ מספר ראשוני.

### מספרים שלמים

**ההערכה ה-$`p`$-אדית** של מספר שלם $`n`$ מוגדרת כ-



```math
\nu_p(n)=
\begin{cases}
\max\{k \in \mathbb{N}_0 : p^k \mid n\} & n \neq 0,\\
\infty & n=0,
\end{cases}
```

 כאשר $`\mathbb{N}_0`$ היא קבוצת המספרים הטבעיים (כולל אפס) ו-$`m \mid n`$ פירושו ש-$`m`$ מחלק את $`n`$. בפרט, $`\nu_p`$ היא פונקציה $`\nu_p \colon \mathbb{Z} \to \mathbb{N}_0 \cup\{\infty\}`$.[^2]

לדוגמה, $`\nu_2(-12) = 2`$, $`\nu_3(-12) = 1`$ ו-$`\nu_5(-12) = 0`$, משום ש-$`|{-12}| = 12 = 2^2 \cdot 3^1 \cdot 5^0`$.

לפעמים משתמשים בסימון $`p^k \parallel n`$ כדי לומר ש-$`k = \nu_p(n)`$.[^3]

אם $`n`$ מספר שלם חיובי, אז $`\nu_p(n) \leq \log_p n`$; זה נובע ישירות מכך ש-$`n \geq p^{\nu_p(n)}`$.

### מספרים רציונליים

אפשר להרחיב את ההערכה ה-$`p`$-אדית למספרים ה[רציונליים](https://he.wikipedia.org/wiki/%D7%9E%D7%A1%D7%A4%D7%A8_%D7%A8%D7%A6%D7%99%D7%95%D7%A0%D7%9C%D7%99), כפונקציה



```math
\nu_p : \mathbb{Q} \to \mathbb{Z} \cup\{\infty\}
```

[^4] המוגדרת על ידי



```math
\nu_p\left(\frac{r}{s}\right)=\nu_p(r)-\nu_p(s).
```

 לדוגמה, $`\nu_2 \bigl(\tfrac{9}{8}\bigr) = -3`$ ו-$`\nu_3 \bigl(\tfrac{9}{8}\bigr) = 2`$, משום ש-$`\tfrac{9}{8} = 2^{-3}\cdot 3^2`$.

כמה תכונות:



```math
\nu_p(r\cdot s) = \nu_p(r) + \nu_p(s),
```





```math
\nu_p(r+s) \geq \min\bigl\{ \nu_p(r), \nu_p(s)\bigr\}.
```

 יתרה מזו, אם $`\nu_p(r) \neq \nu_p(s)`$, אז



```math
\nu_p(r+s)= \min\bigl\{ \nu_p(r), \nu_p(s)\bigr\}.
```

 **דוגמאות.** $`\nu_2(4 + 6) = \nu_2(10) = 1 = \min\{2, 1\}`$, כמו שמבטיחה התכונה האחרונה. לעומת זאת, כשההערכות שוות ההערכה של הסכום יכולה לגדול: $`\nu_2(4 + 4) = \nu_2(8) = 3 \gt 2`$, ו-$`\nu_3(1 + 2) = 1 \gt 0`$.

### נוסחה להערכה ה-$`p`$-אדית של מספרים שלמים

[נוסחת לז'נדר](https://he.wikipedia.org/wiki/%D7%A0%D7%95%D7%A1%D7%97%D7%AA_%D7%9C%D7%96%27%D7%A0%D7%93%D7%A8) קובעת ש-



```math
\nu_p(n!)=\sum_{i=1}^{\infty}{\left\lfloor{\frac{n}{p^i} }\right\rfloor}.
```

 לדוגמה, $`\nu_5(100!) = \lfloor 100/5\rfloor + \lfloor 100/25\rfloor = 20 + 4 = 24`$, ולכן $`100!`$ מסתיים ב-24 אפסים (בבסיס 10 מספר האפסים נקבע על ידי $`\min\{\nu_2, \nu_5\} = \nu_5`$).

לכל מספר שלם חיובי $`n`$ מתקיים $`n = \frac{n!}{(n-1)!}`$, ולכן $`\nu_p(n)=\nu_p(n!)-\nu_p((n-1)!)`$. מכאן



```math
\nu_p(n)=\sum_{i=1}^{\infty}{\bigg(\left\lfloor{\frac{n}{p^i} }\right\rfloor-\left\lfloor{\frac{n-1}{p^i} }\right\rfloor\bigg)}.
```

 את הטור האינסופי הזה אפשר לקצר ל-$`\sum_{i=1}^{\lfloor\log_p n\rfloor}{\bigg(\left\lfloor{\frac{n}{p^i} }\right\rfloor-\left\lfloor{\frac{n-1}{p^i} }\right\rfloor\bigg)}`$ (כל מחובר הוא 1 אם $`p^i \mid n`$ ו-0 אחרת). את הנוסחה אפשר להרחיב גם לשלמים שליליים:



```math
\nu_p(n) =\sum_{i=1}^{\lfloor\log_p |n|\rfloor}{\bigg(\left\lfloor{\frac{|n|}{p^i} }\right\rfloor-\left\lfloor{\frac{|n|-1}{p^i} }\right\rfloor\bigg)}.
```



**הרמת המעריך.** לחישוב ההערכה של הפרשים של חזקות יש כלל נוח: אם $`p`$ ראשוני אי-זוגי שמחלק את $`a - b`$ ואינו מחלק את $`ab`$, אז $`\nu_p(a^n - b^n) = \nu_p(a - b) + \nu_p(n)`$. לדוגמה, $`\nu_3(10^9 - 1) = \nu_3(9) + \nu_3(9) = 4`$, ואכן $`999999999 = 3^4\cdot 37\cdot 333667`$.

## הערך המוחלט ה-$`p`$-אדי

**הערך המוחלט ה-$`p`$-אדי** (או **הנורמה ה-$`p`$-אדית**,[^5] אף על פי שאינה נורמה במובן של האנליזה) על $`\mathbb Q`$ הוא הפונקציה



```math
|\cdot|_p \colon \mathbb Q \to \mathbb R_{\ge 0}
```

 המוגדרת על ידי



```math
|r|_p = p^{-\nu_p(r)}.
```

 לכן $`|0|_p = p^{-\infty} = 0`$ לכל $`p`$, ולדוגמה $`|{-12}|_2 = 2^{-2} = \tfrac{1}{4}`$ ו-$`\bigl|\tfrac{9}{8}\bigr|_2 = 2^{-(-3)} = 8`$. מספר "קטן" $`p`$-אדית אם הוא מתחלק בחזקה גבוהה של $`p`$: למשל $`|3^{10}|_3 = 3^{-10}`$.

לערך המוחלט ה-$`p`$-אדי יש התכונות הבאות:

  
{\| class="wikitable"

\|- \| אי-שליליות \|\| $`|r|_p \geq 0`$ \|- \| חיוביות מוגדרת \|\| $`|r|_p = 0 \iff r = 0`$ \|- \| כפליות \|\| $`|r s|_p = |r|_p|s|_p`$ \|- \| אי-ארכימדיות \|\| $`|r+s|_p \leq \max\left(|r|_p, |s|_p\right)`$ \|} מהכפליות נובע ש-$`|1|_p=1=|{-1}|_p`$, ולכן גם $`|{-r}|_p = |r|_p`$. התת-אדיטיביות $`|r+s|_p \leq |r|_p + |s|_p`$ נובעת מ[אי-שוויון המשולש](https://he.wikipedia.org/wiki/%D7%90%D7%99-%D7%A9%D7%95%D7%95%D7%99%D7%95%D7%9F_%D7%94%D7%9E%D7%A9%D7%95%D7%9C%D7%A9) האי-ארכימדי $`|r+s|_p \leq \max\left(|r|_p, |s|_p\right)`$.

### נוסחת המכפלה

לבחירת הבסיס $`p`$ בחזקה $`p^{-\nu_p(r)}`$ אין השפעה על רוב התכונות, אבל היא מאפשרת את **נוסחת המכפלה**:



```math
\prod_{0, p} |r|_p = 1
```

 לכל $`r \in \mathbb Q^\times`$, כאשר המכפלה היא על כל הראשוניים $`p`$ ועל הערך המוחלט הרגיל, שמסומן כאן $`|r|_0`$. זה נובע פשוט מהפירוק לגורמים ראשוניים: כל חזקת ראשוני $`p^k`$ תורמת את ההופכי שלה לערך המוחלט ה-$`p`$-אדי, והערך המוחלט הארכימדי הרגיל מבטל את כולם. לדוגמה, עבור $`r = -12`$: $`|{-12}|_0 \cdot |{-12}|_2 \cdot |{-12}|_3 = 12 \cdot \tfrac14 \cdot \tfrac13 = 1`$, ושאר הגורמים שווים ל-1. עבור $`r = \tfrac98`$: $`\tfrac98 \cdot 8 \cdot \tfrac19 = 1`$.

לפי [משפט אוסטרובסקי](https://he.wikipedia.org/wiki/%D7%9E%D7%A9%D7%A4%D7%98_%D7%90%D7%95%D7%A1%D7%98%D7%A8%D7%95%D7%91%D7%A1%D7%A7%D7%99), הערך המוחלט הרגיל והערכים המוחלטים ה-$`p`$-אדיים שמופיעים בנוסחה הם כל הערכים המוחלטים על המספרים הרציונליים, עד כדי שקילות. אפשר להשתמש בנוסחת מכפלה דומה כדי להגדיר באופן אקסיומטי [שדות גלובליים](https://he.wikipedia.org/wiki/%D7%A9%D7%93%D7%94_%D7%92%D7%9C%D7%95%D7%91%D7%9C%D7%99), שהמספרים הרציונליים הם הדוגמה הפשוטה ביותר להם.

### מטריקה והשלמה

אפשר להגדיר על הקבוצה $`\mathbb Q`$ [מטריקה](https://he.wikipedia.org/wiki/%D7%9E%D7%A8%D7%97%D7%91_%D7%9E%D7%98%D7%A8%D7%99) (לא ארכימדית ואינווריאנטית להזזות)



```math
d \colon \mathbb Q \times \mathbb Q \to \mathbb R_{\ge 0},\qquad d(r,s) = |r-s|_p.
```

 ה[השלמה](https://he.wikipedia.org/wiki/%D7%9E%D7%A8%D7%97%D7%91_%D7%9E%D7%98%D7%A8%D7%99_%D7%A9%D7%9C%D7%9D) של $`\mathbb Q`$ ביחס למטריקה הזו נותנת את הקבוצה $`\mathbb Q_p`$ של המספרים ה-$`p`$-אדיים. כמו המספרים הרציונליים, הם יוצרים שדה, ואפשר להרחיב אליהם את ההערכה ה-$`p`$-אדית ואת הערך המוחלט ה-$`p`$-אדי, כך ש-$`\mathbb Q_p`$ הוא שדה שלם עם הערכה.

**דוגמה: טור שמתכנס $`p`$-אדית.** בערך המוחלט ה-3-אדי, הסכומים החלקיים $`s_n = 1 + 3 + 9 + \cdots + 3^{n-1} = \tfrac{3^n - 1}{2}`$ מתכנסים ל-$`-\tfrac12`$, משום ש-



```math
\left|s_n - \left(-\tfrac12\right)\right|_3 = \left|\tfrac{3^n}{2}\right|_3 = 3^{-n} \to 0.
```

 כלומר, ב-$`\mathbb Q_3`$ מתקיים $`1 + 3 + 9 + 27 + \cdots = -\tfrac12`$ – בהתאם לנוסחה לטור הנדסי $`\tfrac{1}{1-3}`$, שתקפה כאן משום ש-$`|3|_3 \lt 1`$.
