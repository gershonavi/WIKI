# מנת וילסון

**מנת וילסון** $`W(p)`$ מוגדרת כ-



```math
W(p) = \frac{(p-1)! + 1}{p}.
```

 אם $`p`$ [מספר ראשוני](https://he.wikipedia.org/wiki/%D7%9E%D7%A1%D7%A4%D7%A8_%D7%A8%D7%90%D7%A9%D7%95%D7%A0%D7%99), המנה היא [שלם](https://he.wikipedia.org/wiki/%D7%9E%D7%A1%D7%A4%D7%A8_%D7%A9%D7%9C%D7%9D) לפי [משפט וילסון](https://he.wikipedia.org/wiki/%D7%9E%D7%A9%D7%A4%D7%98_%D7%95%D7%99%D7%9C%D7%A1%D7%95%D7%9F); יתרה מזו, אם $`p`$ [פריק](https://he.wikipedia.org/wiki/%D7%9E%D7%A1%D7%A4%D7%A8_%D7%A4%D7%A8%D7%99%D7%A7), המנה אינה שלם. (אם $`p = ab`$ עם $`1 \lt a \lt p`$, אז $`a`$ מחלק את $`(p-1)!`$, ולכן אינו מחלק את $`(p-1)! + 1`$, ובוודאי $`p`$ אינו מחלק אותו.) אם $`p`$ מחלק את $`W(p)`$, הוא נקרא ראשוני וילסון. הערכים השלמים של $`W(p)`$ הם ((סדרה [A007619](https://oeis.org/A007619) ב-OEIS)):



```math
W(2) = 1
```





```math
W(3) = 1
```





```math
W(5) = 5
```





```math
W(7) = 103
```





```math
W(11) = 329891
```





```math
W(13) = 36846277
```





```math
W(17) = 1230752346353
```





```math
W(19) = 336967037143579
```



  
...

(את הערכים בדקנו בחישוב.)

*דוגמאות:* $`W(7) = (720 + 1)/7 = 721/7 = 103`$. ו-$`W(5) = (24 + 1)/5 = 5`$, שמתחלק ב-5 – לכן 5 הוא ראשוני וילסון. גם $`W(13) = 36846277 = 13\cdot2834329`$ מתחלק ב-13. ראשוני הוילסון הידועים היחידים הם 5, 13 ו-563 (בדקנו שאין אחרים מתחת ל-600). במונחים של קונגרואנציות: $`p`$ ראשוני וילסון בדיוק כש-$`(p-1)! \equiv -1 \pmod{p^2}`$.

ידוע ש-[^1]



```math
W(p)\equiv B_{2(p-1)}-B_{p-1}\pmod{p},
```





```math
p-1+ptW(p)\equiv pB_{t(p-1)}\pmod{p^2},
```

 כאשר $`B_k`$ הוא [מספר ברנולי](https://he.wikipedia.org/wiki/%D7%9E%D7%A1%D7%A4%D7%A8%D7%99_%D7%91%D7%A8%D7%A0%D7%95%D7%9C%D7%99) ה-$`k`$-י. שימו לב שהיחס הראשון מתקבל מהשני בחיסור, אחרי הצבת $`t=1`$ ו-$`t=2`$ וחלוקה ב-$`p`$.

כאן הקונגרואנציות מתפרשות $`p`$-אדית: לפי [משפט פון שטאודט–קלאוזן](%D7%9E%D7%A9%D7%A4%D7%98%20%D7%A4%D7%95%D7%9F%20%D7%A9%D7%98%D7%90%D7%95%D7%93%D7%98%E2%80%93%D7%A7%D7%9C%D7%90%D7%95%D7%96%D7%9F.md), ל-$`B_{p-1}`$ יש $`p`$ במכנה (פעם אחת), אבל $`pB_{t(p-1)}`$ והפרש $`B_{2(p-1)} - B_{p-1}`$ הם מספרים רציונליים שהמכנה שלהם זר ל-$`p`$, ולכן אפשר לצמצם אותם מודולו $`p`$ או $`p^2`$. *דוגמה עבור $`p = 5`$, $`t = 1`$:* $`B_4 = -\tfrac1{30}`$, ולכן $`5B_4 = -\tfrac16`$. מודולו 25, $`6^{-1} \equiv 21`$ (כי $`6\cdot21 = 126 \equiv 1`$), ולכן $`-\tfrac16 \equiv -21 \equiv 4`$. מצד שני, $`p - 1 + pW(p) = 4 + 25 = 29 \equiv 4 \pmod{25}`$. השוויון מתקיים. (את שני היחסים בדקנו לכל הראשוניים $`5 \le p \lt 80`$, ואת השני עבור $`t = 1, 2, 3, 4`$.)
