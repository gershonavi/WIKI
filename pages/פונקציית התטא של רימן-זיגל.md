# פונקציית התטא של רימן-זיגל

בחירת האינדקס $`n`$ מעט שרירותית. מבחינה היסטורית הוא נבחר כך שהאינדקס יהיה 0 בערך הראשון הגדול מהאפס החיובי הקטן ביותר (שהחלק המדומה שלו $`14.13472514\ldots`$) של פונקציית זטא על הישר הקריטי. פונקציית תטא מתנודדת עבור ארגומנטים ממשיים קטנים בערכם המוחלט, ולכן אינה הפיכה באופן יחיד בקטע $`[-24,24]`$; לכן לפונקציה האי-זוגית יש את נקודת הגרם הסימטרית עם הערך 0 באינדקס $`-3`$.

נקודות גרם שימושיות בחישוב האפסים של $`Z(t)`$. בנקודת גרם $`g_n`$



```math
\zeta\left(\frac{1}{2}+ig_n\right) = \cos(\theta(g_n))Z(g_n) = (-1)^n Z(g_n),
```

 ואם ביטוי זה *חיובי* בשתי נקודות גרם עוקבות, ל-$`Z(t)`$ חייב להיות אפס בקטע שביניהן.

לפי **חוק גרם**, החלק הממשי *בדרך כלל* חיובי, ואילו החלק המדומה מתחלף בנקודות הגרם בין ערכים חיוביים לשליליים במרווחים סדירים למדי:



```math
(-1)^n Z(g_n) > 0.
```

 את מספר השורשים $`N(T)`$ ברצועה מ-0 עד $`T`$ אפשר למצוא בעזרת



```math
N(T) = \frac{\theta(T)}{\pi} + 1+S(T),
```

 כאשר $`S(T)`$ הוא איבר שגיאה הגדל אסימפטוטית כמו $`\log T`$ (ראו [נוסחת רימן-פון מנגולדט](%D7%A0%D7%95%D7%A1%D7%97%D7%AA%20%D7%A8%D7%99%D7%9E%D7%9F-%D7%A4%D7%95%D7%9F%20%D7%9E%D7%A0%D7%92%D7%95%D7%9C%D7%93%D7%98.md)). אילו $`g_n`$ היו מקיימים את חוק גרם, מציאת מספר השורשים ברצועה הייתה מסתכמת ב-



```math
N(g_n) = n + 1.
```

 כיום ידוע שבטווח הארוך, חוק גרם נכשל בכרבע מקטעי גרם, כלומר הם אינם מכילים בדיוק אפס אחד של פונקציית זטא. גרם חשש שהחוק עלול להיכשל עבור אינדקסים גדולים (הכישלון הראשון הוא באינדקס 126, לפני האפס ה-127), ולכן טען אותו רק עבור אינדקסים לא גבוהים מדי. מאוחר יותר טבע האצ'ינסון את הביטוי "חוק גרם" לטענה (השגויה) שכל האפסים על הישר הקריטי מופרדים על ידי נקודות גרם.
