# ערכים מיוחדים של פונקציית זטא של רימן

<img src="https://commons.wikimedia.org/wiki/Special:FilePath/Riemann-Zeta-Func.png" alt="פונקציית זטא של רימן במישור המרוכב, בשיטת צביעת התחום." width="320">

ב[מתמטיקה](https://he.wikipedia.org/wiki/%D7%9E%D7%AA%D7%9E%D7%98%D7%99%D7%A7%D7%94), [פונקציית זטא של רימן](https://he.wikipedia.org/wiki/%D7%A4%D7%95%D7%A0%D7%A7%D7%A6%D7%99%D7%99%D7%AA_%D7%96%D7%98%D7%90_%D7%A9%D7%9C_%D7%A8%D7%99%D7%9E%D7%9F) היא פונקציה ב[אנליזה מרוכבת](https://he.wikipedia.org/wiki/%D7%90%D7%A0%D7%9C%D7%99%D7%96%D7%94_%D7%9E%D7%A8%D7%95%D7%9B%D7%91%D7%AA), שיש לה חשיבות גם ב[תורת המספרים](https://he.wikipedia.org/wiki/%D7%AA%D7%95%D7%A8%D7%AA_%D7%94%D7%9E%D7%A1%D7%A4%D7%A8%D7%99%D7%9D). היא מסומנת לרוב $`\zeta(s)`$, וקרויה על שם המתמטיקאי [ברנהרד רימן](https://he.wikipedia.org/wiki/%D7%91%D7%A8%D7%A0%D7%94%D7%A8%D7%93_%D7%A8%D7%99%D7%9E%D7%9F). כאשר הארגומנט $`s`$ הוא [מספר ממשי](https://he.wikipedia.org/wiki/%D7%9E%D7%A1%D7%A4%D7%A8_%D7%9E%D7%9E%D7%A9%D7%99) גדול מ-1, פונקציית זטא מקיימת את המשוואה



```math
\zeta(s) = \sum_{n=1}^\infty\frac{1}{n^s} .
```

 לכן היא נותנת את הסכום של [טורים אינסופיים](https://he.wikipedia.org/wiki/%D7%98%D7%95%D7%A8_%28%D7%9E%D7%AA%D7%9E%D7%98%D7%99%D7%A7%D7%94%29) מתכנסים שונים, כמו $`\zeta(2) = \frac{1}{1^2} + \frac{1}{2^2} + \frac{1}{3^2} + \ldots`$ יש נוסחאות מפורשות או יעילות לחישוב מספרי של $`\zeta(s)`$ בארגומנטים שלמים, וכל הערכים האלה ממשיים, כולל הדוגמה הזו. ערך זה מפרט את הנוסחאות האלה, יחד עם טבלאות ערכים. הוא כולל גם נגזרות וכמה טורים שבנויים מערכי פונקציית זטא בארגומנטים שלמים.

אותה משוואה ב-$`s`$ מתקיימת גם כאשר $`s`$ הוא [מספר מרוכב](https://he.wikipedia.org/wiki/%D7%9E%D7%A1%D7%A4%D7%A8_%D7%9E%D7%A8%D7%95%D7%9B%D7%91) שחלקו הממשי גדול מ-1, ואז הסכום האינסופי עדיין מתכנס. אפשר להרחיב את פונקציית זטא לכל ה[מישור המרוכב](https://he.wikipedia.org/wiki/%D7%94%D7%9E%D7%99%D7%A9%D7%95%D7%A8_%D7%94%D7%9E%D7%A8%D7%95%D7%9B%D7%91) באמצעות [המשכה אנליטית](https://he.wikipedia.org/wiki/%D7%94%D7%9E%D7%A9%D7%9B%D7%94_%D7%90%D7%A0%D7%9C%D7%99%D7%98%D7%99%D7%AA), פרט ל[קוטב](https://he.wikipedia.org/wiki/%D7%A7%D7%95%D7%98%D7%91_%28%D7%90%D7%A0%D7%9C%D7%99%D7%96%D7%94_%D7%9E%D7%A8%D7%95%D7%9B%D7%91%D7%AA%29) פשוט ב-$`s=1`$. הנגזרת המרוכבת קיימת בתחום הכללי הזה, ולכן פונקציית זטא היא [פונקציה מרומורפית](https://he.wikipedia.org/wiki/%D7%A4%D7%95%D7%A0%D7%A7%D7%A6%D7%99%D7%94_%D7%9E%D7%A8%D7%95%D7%9E%D7%95%D7%A8%D7%A4%D7%99%D7%AA). המשוואה שלמעלה אינה תקפה עוד עבור הערכים המורחבים של $`s`$, שעבורם הטור המתאים מתבדר. לדוגמה, פונקציית זטא המלאה מוגדרת ב-$`s=-1`$ (וערכה שם סופי), אבל הטור המתאים הוא $`1 + 2 + 3 + \ldots`$, שהסכומים החלקיים שלו גדלים ללא חסם.

ערכי פונקציית זטא שבהמשך כוללים את ערכי הפונקציה במספרים הזוגיים השליליים ($`s=-2,-4`$ וכן הלאה), שבהם $`\zeta(s)=0`$, והם נקראים **האפסים הטריוויאליים**. האפיון של האפסים הלא-טריוויאליים במישור המרוכב חשוב בתורת המספרים, בגלל [השערת רימן](https://he.wikipedia.org/wiki/%D7%94%D7%A9%D7%A2%D7%A8%D7%AA_%D7%A8%D7%99%D7%9E%D7%9F).

## פונקציית זטא של רימן ב-0 וב-1

באפס מתקיים



```math
\zeta(0)= {B^-_1}=-{B^+_1}=-\tfrac{1}{2},
```

 כאשר $`B^\pm_1 = \pm\tfrac12`$ הם שתי המוסכמות המקובלות ל[מספר ברנולי](https://he.wikipedia.org/wiki/%D7%9E%D7%A1%D7%A4%D7%A8%D7%99_%D7%91%D7%A8%D7%A0%D7%95%D7%9C%D7%99) $`B_1`$.

ב-1 יש קוטב, ולכן $`\zeta(1)`$ אינו סופי, אבל הגבולות משמאל ומימין הם



```math
\lim_{\varepsilon\to 0^\pm}\zeta(1+\varepsilon) = \pm\infty .
```

 מאחר שזה קוטב מסדר ראשון, השארית שלו היא



```math
\lim_{\varepsilon\to 0} \varepsilon \zeta(1+\varepsilon) = 1 .
```



## מספרים שלמים חיוביים

### מספרים זוגיים חיוביים

עבור מספרים זוגיים חיוביים $`n`$ יש קשר ל[מספרי ברנולי](https://he.wikipedia.org/wiki/%D7%9E%D7%A1%D7%A4%D7%A8%D7%99_%D7%91%D7%A8%D7%A0%D7%95%D7%9C%D7%99) $`B_n`$:



```math
\zeta(n) = (-1)^{\tfrac{n}{2}+1}\frac{(2\pi)^{n}B_n}{2(n!)} .
```



החישוב של $`\zeta(2)`$ ידוע בשם [בעיית בזל](https://he.wikipedia.org/wiki/%D7%91%D7%A2%D7%99%D7%99%D7%AA_%D7%91%D7%96%D7%9C). הערך של $`\zeta(4)`$ קשור ל[חוק סטפן-בולצמן](https://he.wikipedia.org/wiki/%D7%97%D7%95%D7%A7_%D7%A1%D7%98%D7%A4%D7%9F-%D7%91%D7%95%D7%9C%D7%A6%D7%9E%D7%9F) ולקירוב של וין בפיזיקה. הערכים הראשונים הם:



```math
\begin{align}

\zeta(4) & = 1 + \frac{1}{2^4} + \frac{1}{3^4} + \cdots = \frac{\pi^4}{90} \\[4pt]
\zeta(6) & = 1 + \frac{1}{2^6} + \frac{1}{3^6} + \cdots = \frac{\pi^6}{945} \\[4pt]
\zeta(8) & = 1 + \frac{1}{2^8} + \frac{1}{3^8} + \cdots = \frac{\pi^8}{9450} \\[4pt]
\zeta(10) & = 1 + \frac{1}{2^{10} } + \frac{1}{3^{10} } + \cdots = \frac{\pi^{10} }{93555} \\[4pt]
\zeta(12) & = 1 + \frac{1}{2^{12} } + \frac{1}{3^{12} } + \cdots = \frac{691\pi^{12} }{638512875} \\[4pt]
```

מקדמים

אם נסמן $`\eta_n=b_n/a_n`$ את המקדם של $`\pi^{2n}`$ כמו למעלה,



```math
\zeta(2n) = \sum_{\ell=1}^{\infty}\frac{1}{\ell^{2n} }=\eta_n\pi^{2n},
```

 אז מתקבלת נוסחת הנסיגה



```math
\begin{align}
\eta_1 &= 1/6, \\
\eta_n &= \sum_{\ell=1}^{n-1}(-1)^{\ell-1}\frac{\eta_{n-\ell} }{(2\ell+1)!}+(-1)^{n+1}\frac{n}{(2n+1)!} .
\end{align}
```

 את נוסחת הנסיגה הזו אפשר לגזור מנוסחת הנסיגה של מספרי ברנולי.

יש גם נוסחת נסיגה נוספת:



```math
\zeta(2n)=\frac{1}{n+\frac{1}{2} } \sum_{k=1}^{n-1} \zeta(2k)\zeta(2n-2k) \quad \text{ for } \quad n>1 ,
```

 שאפשר להוכיח בעזרת הזהות $`\frac{d}{dx} \cot(x) = -1-\cot^{2} (x)`$.

ל[פונקציה היוצרת](https://he.wikipedia.org/wiki/%D7%A4%D7%95%D7%A0%D7%A7%D7%A6%D7%99%D7%94_%D7%99%D7%95%D7%A6%D7%A8%D7%AA) של ערכי פונקציית זטא במספרים הזוגיים האי-שליליים יש הצורה



```math
\sum_{n=0}^\infty \zeta(2n) x^{2n} = -\frac{\pi x}{2} \cot(\pi x) = -\frac{1}{2} + \frac{\pi^2}{6} x^2 + \frac{\pi^4}{90} x^4+\frac{\pi^6}{945}x^6 + \cdots
```

 מאחר ש-$`\lim_{n\rightarrow\infty} \zeta(2n)=1`$, הנוסחה מראה גם שעבור $`n\rightarrow\infty`$



```math
\left|B_{2n}\right| \sim \frac{2\,(2n)!}{(2\pi)^{2n} } .
```

ערכים נבחרים במספרים אי-זוגיים

ידוע ש-$`\zeta(3)`$ אי-רציונלי ([משפט אפרי](https://he.wikipedia.org/wiki/%D7%9E%D7%A9%D7%A4%D7%98_%D7%90%D7%A4%D7%A8%D7%99)), ושאינסוף מהמספרים $`\zeta(2n+1)`$ אי-רציונליים.[^1] יש גם תוצאות על אי-רציונליות של ערכי פונקציית זטא בתת-קבוצות מסוימות של המספרים האי-זוגיים החיוביים; למשל, לפחות אחד מהמספרים $`\zeta(5), \zeta(7), \zeta(9)`$ או $`\zeta(11)`$ אי-רציונלי.[^2]

ערכי פונקציית זטא במספרים האי-זוגיים החיוביים מופיעים בפיזיקה, בפרט בפונקציות המתאם של שרשרת הספינים האנטי-פרומגנטית XXX (מודל הייזנברג).[^3]

רוב הזהויות שבהמשך מקורן בסיימון פלאף. הן בולטות בכך שהן מתכנסות מהר מאוד, ונותנות כמעט שלוש ספרות של דיוק בכל איבר, ולכן הן שימושיות לחישובים ברמת דיוק גבוהה. פלאף ניסח את הזהויות בלי הוכחה,[^4] והוכחות ניתנו מאוחר יותר על ידי מחברים אחרים.[^5][^6]

#### ζ(5)



```math
\begin{align}
\zeta(5)&=\frac{1}{294}\pi^5 -\frac{72}{35} \sum_{n=1}^\infty \frac{1}{n^5 (e^{2\pi n} -1)}-\frac{2}{35} \sum_{n=1}^\infty \frac{1}{n^5 (e^{2\pi n} +1)}\\
\zeta(5)&=12 \sum_{n=1}^\infty \frac{1}{n^5 \sinh (\pi n)} -\frac{39}{20} \sum_{n=1}^\infty \frac{1}{n^5 (e^{2\pi n} -1)}+\frac{1}{20} \sum_{n=1}^\infty \frac{1}{n^5 (e^{2\pi n} +1)}
\end{align}
```

 לאחרונה פורסמו גרסאות נוספות, למשל:[^7]



```math
\zeta(5)=\frac{\pi^5}{270}-\frac{32}{15}\sum_{n=1}^\infty\frac{1}{n^5(e^{\pi n}+(-1)^n)} .
```



בספטמבר 2026 פרסם אביר פאוזן (Aabir Fauzan) כתב יד שבו הוכחה לכך ש-$`\zeta(5)`$ אי-רציונלי, בשיטה של דטרמיננטות הנקל; ההוכחה נוסחה ונבדקה פורמלית במערכת ההוכחות Lean, ועבודות המשך כבר מסתמכות עליה.[^8][^9][^10]

#### ζ(7)



```math
\zeta(7)=\frac{19}{56700}\pi^7 - 2 \sum_{n=1}^\infty \frac{1}{n^7 (e^{2\pi n} -1)} .
```

 הסכום הוא מהצורה של טור למברט.


מקדמים

את הקבועים השלמים האלה אפשר לבטא כסכומים של מספרי ברנולי, כפי שמופיע אצל (Vepstas, 2006).

אלגוריתם מהיר לחישוב פונקציית זטא של רימן בכל ארגומנט שלם נתנה יקטרינה קרצובה.[^11]

## מספרים שלמים שליליים

באופן כללי, עבור מספרים שלמים שליליים מתקיים



```math
\zeta(-n)= - \frac{B_{n+1} }{n+1}
```

 (במוסכמה $`B_1 = +\tfrac12`$; עבור $`n \ge 1`$ אין הבדל בין המוסכמות).

האפסים ה"טריוויאליים" מתקבלים במספרים הזוגיים השליליים:



```math
\zeta(-2n)=0 .
```



הערכים הראשונים במספרים האי-זוגיים השליליים הם



```math
\begin{align}
\zeta(-1) &=-\frac{1}{12} \\[4pt]
\zeta(-3) &=\frac{1}{120} \\[4pt]
\zeta(-5) &=-\frac{1}{252} \\[4pt]
\zeta(-7) &=\frac{1}{240} \\[4pt]
\zeta(-9) &= -\frac{1}{132} \\[4pt]
\zeta(-11)&= \frac{691}{32760} \\[4pt]
\zeta(-13)&= -\frac{1}{12}
\end{align}
```

 לכן אפשר להשתמש בערכים $`\zeta(m)`$ כהגדרה של מספרי ברנולי.

עם זאת, בדיוק כמו מספרי ברנולי, ערכים אלה אינם נשארים קטנים ככל שהמספרים האי-זוגיים השליליים גדלים בערכם המוחלט. על הערך $`\zeta(-1)`$ ראו הערך על הטור $`1 + 2 + 3 + 4 + \cdots`$ (באנגלית: "1 + 2 + 3 + 4 + ⋯").

## נגזרות

הנגזרת של פונקציית זטא במספרים הזוגיים השליליים נתונה על ידי



```math
\zeta^{\prime}(-2n) = (-1)^n \frac {(2n)!} {2 (2\pi)^{2n} } \zeta (2n+1) .
```

 הערכים הראשונים הם



```math
\begin{align}
\zeta^{\prime}(-2) & = -\frac{\zeta(3)}{4\pi^2} \\[4pt]
\zeta^{\prime}(-4) & = \frac{3}{4\pi^4} \zeta(5) \\[4pt]
\zeta^{\prime}(-6) & = -\frac{45}{8\pi^6} \zeta(7) \\[4pt]
\zeta^{\prime}(-8) & = \frac{315}{4\pi^8} \zeta(9) .
\end{align}
```



מתקיים גם



```math
\begin{align}
\zeta^{\prime}(0) & = -\frac{1}{2}\ln(2\pi) \\[4pt]
\zeta^{\prime}(-1) & = \frac{1}{12}-\ln A \\[4pt]
\zeta^{\prime}(2) & = \frac{1}{6}\pi^2(\gamma +\ln 2-12\ln A+\ln \pi)
\end{align}
```

 כאשר $`A`$ הוא קבוע גלישר–קינקלין. הזהות הראשונה גוררת שהמכפלה המרוגלרת של ההופכיים של המספרים השלמים החיוביים היא $`1/\sqrt{2\pi}`$, ומכאן ה"משוואה" המשעשעת $`\infty!=\sqrt{2\pi}`$.[^12]

מהנגזרת הלוגריתמית של משוואת הפונקציה מתקבל



```math
2\frac{\zeta'(1/2)}{\zeta(1/2)} = \log(2\pi)+\frac{\pi\cos(\pi/4)}{2\sin(\pi/4)}-\frac{\Gamma'(1/2)}{\Gamma(1/2)}=\log(2\pi)+\frac{\pi}{2}+2\log 2+\gamma .
```

## טורים שמערבים את ζ(n)

את הסכומים הבאים אפשר לגזור מהפונקציה היוצרת



```math
\sum_{k=2}^\infty \zeta(k) x^{k-1}=-\psi_0(1-x)-\gamma ,
```

 כאשר $`\psi_0`$ היא [פונקציית דיגמא](https://he.wikipedia.org/wiki/%D7%A4%D7%95%D7%A0%D7%A7%D7%A6%D7%99%D7%99%D7%AA_%D7%93%D7%99%D7%92%D7%9E%D7%90):



```math
\begin{align}
\sum_{k=2}^\infty (\zeta(k) -1) & = 1 \\[4pt]
\sum_{k=1}^\infty (\zeta(2k) -1) & = \frac{3}{4} \\[4pt]
\sum_{k=1}^\infty (\zeta(2k+1) -1) & = \frac{1}{4} \\[4pt]
\sum_{k=2}^\infty (-1)^k(\zeta(k) -1) & = \frac{1}{2}
\end{align}
```



טורים הקשורים ל[קבוע אוילר-מסקרוני](https://he.wikipedia.org/wiki/%D7%A7%D7%91%D7%95%D7%A2_%D7%90%D7%95%D7%99%D7%9C%D7%A8-%D7%9E%D7%A1%D7%A7%D7%A8%D7%95%D7%A0%D7%99) (המסומן $`\gamma`$) הם



```math
\begin{align}
\sum_{k=2}^\infty (-1)^k \frac{\zeta(k)}{k} & = \gamma \\[4pt]
\sum_{k=2}^\infty \frac{\zeta(k) - 1}{k} & = 1 - \gamma \\[4pt]
\sum_{k=2}^\infty (-1)^k \frac{\zeta(k)-1}{k} & = \ln2 + \gamma - 1
\end{align}
```

 ואם משתמשים בערך העיקרי



```math
\zeta(k) = \lim_{\varepsilon \to 0} \frac{\zeta(k+\varepsilon)+\zeta(k-\varepsilon)}{2},
```

 שמשפיע כמובן רק על הערך ב-1, אפשר לנסח את הנוסחאות האלה כך:



```math
\begin{align}
\sum_{k=1}^\infty (-1)^k \frac{\zeta(k)}{k} & = 0 \\[4pt]
\sum_{k=1}^\infty \frac{\zeta(k) - 1}{k} & = 0 \\[4pt]
\sum_{k=1}^\infty (-1)^k \frac{\zeta(k)-1}{k} & = \ln2
\end{align}
```

 והן מראות שהתוצאות תלויות בערך העיקרי $`\zeta(1)=\gamma`$.

## יחסים

אף שקשה לחשב ערכים מסוימים של פונקציית זטא, לעיתים קרובות אפשר למצוא יחסים מסוימים על ידי הצבת ערכים מיוחדים של [פונקציית גמא](https://he.wikipedia.org/wiki/%D7%A4%D7%95%D7%A0%D7%A7%D7%A6%D7%99%D7%99%D7%AA_%D7%92%D7%9E%D7%90) במשוואת הפונקציה



```math
\zeta(s) = 2^s\pi^{s-1}\sin\left(\frac{\pi s}{2}\right)\Gamma(1-s)\zeta(1-s) .
```

 יש קשרים פשוטים בארגומנטים של חצי-שלם:



```math
\begin{align}
\frac{\zeta(3/2)}{\zeta(-1/2)} &= -4\pi \\
\frac{\zeta(5/2)}{\zeta(-3/2)} &= -\frac{16\pi^2}{3} \\
\frac{\zeta(7/2)}{\zeta(-5/2)} &= \frac{64\pi^3}{15} \\
\frac{\zeta(9/2)}{\zeta(-7/2)} &= \frac{256\pi^4}{105}
\end{align}
```

 דוגמאות נוספות נובעות מקשרים מורכבים יותר של פונקציית גמא. לדוגמה, מהקשר



```math
\Gamma\left(\tfrac{3}{4}\right) =\left(\tfrac{\pi} {2}\right) ^{\tfrac{1}{4} } {\mathrm{AGM}\left(\sqrt 2, 1\right)}^{\tfrac{1}{2} }
```

 נובע היחס



```math
\frac{\zeta(3/4)}{\zeta(1/4)} = 2\sqrt{\frac{\pi}{(2-\sqrt{2})\mathrm{AGM}\left(\sqrt 2, 1\right)} },
```

 כאשר AGM הוא [הממוצע האריתמטי-גאומטרי](https://he.wikipedia.org/wiki/%D7%9E%D7%9E%D7%95%D7%A6%D7%A2_%D7%90%D7%A8%D7%99%D7%AA%D7%9E%D7%98%D7%99-%D7%92%D7%90%D7%95%D7%9E%D7%98%D7%A8%D7%99). באופן דומה אפשר לקבל קשרים עם שורשים; למשל, מ-



```math
\frac{\Gamma\left(\frac{1}{5}\right)^2}{\Gamma\left(\frac{1}{10}\right)\Gamma\left(\frac{3}{10}\right)} = \frac{\sqrt{1+\sqrt{5} } }{2^{\tfrac{7}{10} }\sqrt[4]{5} }
```

 נובע הקשר



```math
\frac{\zeta(1/5)^2\zeta(7/10)\zeta(9/10)}{\zeta(1/10)\zeta(3/10)\zeta(4/5)^2} = \frac{(5-\sqrt{5})\left(\sqrt{10}+\sqrt{5+\sqrt{5} }\right)}{10\cdot2^{\tfrac{3}{10} } } .
```
