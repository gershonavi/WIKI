# משוואת ליונגרן

**משוואת ליונגרן** היא ה[משוואה דיופנטית](https://he.wikipedia.org/wiki/%D7%9E%D7%A9%D7%95%D7%95%D7%90%D7%94_%D7%93%D7%99%D7%95%D7%A4%D7%A0%D7%98%D7%99%D7%AA)



```math
X^2 = 2Y^4 - 1,
```

 או באופן שקול $`X^2 + 1 = 2Y^4`$. וילהלם ליונגרן הוכיח ב-1942, בהוכחה קשה, שהפתרונות היחידים שלה בשלמים חיוביים הם $`(X, Y) = (1, 1)`$ ו-$`(239, 13)`$.[^1] ואכן $`239^2 = 57121 = 2\cdot28561 - 1 = 2\cdot13^4 - 1`$. (חיפוש שלנו עם $`Y \lt 10^6`$ לא מצא פתרונות נוספים.)

## קשר למשוואת פל

אם $`(X, Y)`$ פתרון, אז $`(X, Y^2)`$ הוא פתרון של [משוואת פל](https://he.wikipedia.org/wiki/%D7%9E%D7%A9%D7%95%D7%95%D7%90%D7%AA_%D7%A4%D7%9C) השלילית



```math
X^2 - 2Z^2 = -1.
```

 הפתרונות של משוואת פל הזו נתונים על ידי $`X + Z\sqrt2 = (1 + \sqrt2)^{2k+1}`$, וערכי $`Z`$ הם



```math
1, 5, 29, 169, 985, 5741, 33461, 195025, 1136689, \ldots
```

 (כל אחד מתקבל מקודמו ב-$`Z' = 2X + 3Z`$, $`X' = 3X + 4Z`$). משוואת ליונגרן שואלת אילו מאלה ריבועים. התשובה: רק $`1 = 1^2`$ ו-$`169 = 13^2`$ (הסדרה גדלה מעריכית, והשאלה היא אם ריבוע נוסף מופיע בה אי פעם). זו דוגמה טיפוסית לשאלה "אילו איברים בסדרה רקורסיבית לינארית הם ריבועים", שבדרך כלל קשה מאוד לענות עליה.

## מספרי סטלה אוקטנגולה

**מספר סטלה אוקטנגולה** הוא מספר צורני שמבוסס על הסטלה אוקטנגולה (כוכב בעל שמונה קודקודים, איחוד של שני טטרהדרים), מהצורה $`n(2n^2 - 1)`$.[^2] סדרת מספרי הסטלה אוקטנגולה היא

  
0, 1, 14, 51, 124, 245, 426, 679, 1016, 1449, 1990, …

רק שניים מהם הם ריבועים חיוביים: 1, ו-$`9653449 = 3107^2 = (13\times239)^2`$, שמתאימים ל-$`n = 1`$ ול-$`n = 169`$ בהתאמה.[^3][^4]

ה[עקום אליפטי](https://he.wikipedia.org/wiki/%D7%A2%D7%A7%D7%95%D7%9D_%D7%90%D7%9C%D7%99%D7%A4%D7%98%D7%99) שמתאר את מספרי הסטלה אוקטנגולה הריבועיים,



```math
m^2 = n(2n^2 - 1),
```

 אפשר להעביר לצורת ויירשטראס השקולה



```math
x^2 = y^3 - 2y
```

 בעזרת החלפת המשתנים $`x = 2m`$, $`y = 2n`$ (כי $`4n(2n^2 - 1) = 8n^3 - 4n = y^3 - 2y`$). כיוון ששני הגורמים $`n`$ ו-$`2n^2 - 1`$ של המספר הריבועי $`m^2`$ [זרים](https://he.wikipedia.org/wiki/%D7%9E%D7%A1%D7%A4%D7%A8%D7%99%D7%9D_%D7%96%D7%A8%D7%99%D7%9D), כל אחד מהם חייב להיות ריבוע בעצמו, והחלפת המשתנים השנייה $`X = m/\sqrt n`$ ו-$`Y = \sqrt n`$ מובילה למשוואת ליונגרן $`X^2 = 2Y^4 - 1`$.[^5] למשל, עבור $`n = 169`$: $`Y = 13`$, ו-$`X = 3107/13 = 239`$.

## היסטוריה

לפי משפט של [זיגל](https://he.wikipedia.org/wiki/%D7%A7%D7%A8%D7%9C_%D7%9C%D7%95%D7%93%D7%95%D7%95%D7%99%D7%92_%D7%96%D7%99%D7%92%D7%9C) ([משפט זיגל על נקודות שלמות](%D7%9E%D7%A9%D7%A4%D7%98%20%D7%96%D7%99%D7%92%D7%9C%20%D7%A2%D7%9C%20%D7%A0%D7%A7%D7%95%D7%93%D7%95%D7%AA%20%D7%A9%D7%9C%D7%9E%D7%95%D7%AA.md)), לכל עקום אליפטי יש רק מספר סופי של נקודות שלמות, אבל ההוכחה אינה נותנת שיטה למצוא אותן. ליונגרן מצא ב-1942 הוכחה קשה לכך שהפתרונות השלמים היחידים של המשוואה שלו הם $`(1, 1)`$ ו-$`(239, 13)`$, שמתאימים לשני מספרי הסטלה אוקטנגולה הריבועיים.[^6] לואיס מורדל שיער שאפשר לפשט את ההוכחה, וכמה מחברים מאוחרים יותר פרסמו פישוטים.[^7][^8] ההוכחה של שטיינר וצנאקיס משתמשת בצורות לינאריות בלוגריתמים ובצמצום סריגים.

## יישומים נוספים

מספרי הסטלה אוקטנגולה מופיעים במשפחה פרמטרית של מקרים של בעיית הסולמות המצטלבים, שבהם האורכים והגבהים של הסולמות וגובה נקודת ההצטלבות כולם שלמים. במקרים האלה, היחס בין הגבהים של שני הסולמות הוא מספר סטלה אוקטנגולה.[^9]

המספר 239 מופיע גם בנוסחת מאצ'ין $`\frac\pi4 = 4\arctan\frac15 - \arctan\frac1{239}`$, וזה לא מקרי: הזהות נובעת מכך ש-$`(5 + i)^4(-239 + i)`$ הוא כפולה ממשית של $`1 + i`$, וזה שקול ל-$`239^2 + 1 = 2\cdot13^4`$ – בדיוק הפתרון של משוואת ליונגרן.
