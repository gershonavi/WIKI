# משפט האידיאלים הראשוניים של לנדאו

ב[תורת המספרים האלגברית](https://he.wikipedia.org/wiki/%D7%AA%D7%95%D7%A8%D7%AA_%D7%94%D7%9E%D7%A1%D7%A4%D7%A8%D7%99%D7%9D_%D7%94%D7%90%D7%9C%D7%92%D7%91%D7%A8%D7%99%D7%AA), **משפט האידיאלים הראשוניים** (או **משפט האידיאלים הראשוניים של לנדאו**) הוא ההכללה של [משפט המספרים הראשוניים](https://he.wikipedia.org/wiki/%D7%9E%D7%A9%D7%A4%D7%98_%D7%94%D7%9E%D7%A1%D7%A4%D7%A8%D7%99%D7%9D_%D7%94%D7%A8%D7%90%D7%A9%D7%95%D7%A0%D7%99%D7%99%D7%9D) ל[שדות מספרים](https://he.wikipedia.org/wiki/%D7%A9%D7%93%D7%94_%D7%9E%D7%A1%D7%A4%D7%A8%D7%99%D7%9D). הוא נותן נוסחה אסימפטוטית למספר ה[אידיאלים הראשוניים](https://he.wikipedia.org/wiki/%D7%90%D7%99%D7%93%D7%99%D7%90%D7%9C_%D7%A8%D7%90%D7%A9%D7%95%D7%A0%D7%99) של שדה מספרים $`K`$ שה[נורמה](https://he.wikipedia.org/wiki/%D7%A0%D7%95%D7%A8%D7%9E%D7%94_%28%D7%90%D7%9C%D7%92%D7%91%D7%A8%D7%94%29) שלהם לכל היותר $`X`$.

## דוגמה

את התוצאה הצפויה אפשר לראות כבר ב[חוג השלמים של גאוס](https://he.wikipedia.org/wiki/%D7%97%D7%95%D7%92_%D7%94%D7%A9%D7%9C%D7%9E%D7%99%D7%9D_%D7%A9%D7%9C_%D7%92%D7%90%D7%95%D7%A1). שם, כל ראשוני $`p`$ מהצורה $`4n + 1`$ מתפרק למכפלה של שני ראשוניים גאוסיים בעלי נורמה $`p`$, ואילו ראשוניים מהצורה $`4n + 3`$ נשארים ראשוניים, ונותנים ראשוני גאוסי בעל נורמה $`p^2`$. לכן יש להעריך את



```math
2r(X)+r'(\sqrt{X}),
```



כאשר $`r`$ סופרת ראשוניים בסדרה החשבונית $`4n + 1`$ ו-$`r'`$ בסדרה $`4n + 3`$. לפי הצורה הכמותית של [משפט דיריכלה](https://he.wikipedia.org/wiki/%D7%9E%D7%A9%D7%A4%D7%98_%D7%93%D7%99%D7%A8%D7%99%D7%9B%D7%9C%D7%94), כל אחת מ-$`r(Y)`$ ו-$`r'(Y)`$ שקולה אסימפטוטית ל-



```math
\frac{Y}{2\log Y}.
```



לכן האיבר $`2r(X)`$ דומיננטי, והוא שקול אסימפטוטית ל-



```math
\frac{X}{\log X}.
```



## שדות מספרים כלליים

דפוס זה מתקיים בכל שדות המספרים: במשפט האידיאלים הראשוניים, האידיאלים שהנורמה שלהם היא מספר ראשוני הם הדומיננטיים. כפי ש[אדמונד לנדאו](https://he.wikipedia.org/wiki/%D7%90%D7%93%D7%9E%D7%95%D7%A0%D7%93_%D7%9C%D7%A0%D7%93%D7%90%D7%95) הוכיח בשנת 1903,[^1] עבור נורמה של לכל היותר $`X`$ מתקיימת תמיד אותה נוסחה אסימפטוטית



```math
\frac{X}{\log X}.
```



מבחינה היוריסטית, הסיבה היא שלנגזרת הלוגריתמית של [פונקציית זטא של דדקינד](https://he.wikipedia.org/wiki/%D7%A4%D7%95%D7%A0%D7%A7%D7%A6%D7%99%D7%99%D7%AA_%D7%96%D7%98%D7%90_%D7%A9%D7%9C_%D7%93%D7%93%D7%A7%D7%99%D7%A0%D7%93) של $`K`$ יש תמיד קוטב פשוט עם שארית $`-1`$ בנקודה $`s = 1`$.

כמו במשפט המספרים הראשוניים, אפשר לתת הערכה מדויקת יותר באמצעות [פונקציית האינטגרל הלוגריתמי](https://he.wikipedia.org/wiki/%D7%A4%D7%95%D7%A0%D7%A7%D7%A6%D7%99%D7%99%D7%AA_%D7%94%D7%90%D7%99%D7%A0%D7%98%D7%92%D7%A8%D7%9C_%D7%94%D7%9C%D7%95%D7%92%D7%A8%D7%99%D7%AA%D7%9E%D7%99): מספר האידיאלים הראשוניים בעלי נורמה שאינה גדולה מ-$`X`$ הוא



```math
\mathrm{Li}(X) + O_K\left(X \exp\left(-c_K \sqrt{\log X}\right)\right),
```



כאשר $`c_K`$ קבוע התלוי ב-$`K`$.[^2]
