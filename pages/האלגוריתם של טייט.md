# האלגוריתם של טייט

בתורת ה[עקומים האליפטיים](https://he.wikipedia.org/wiki/%D7%A2%D7%A7%D7%95%D7%9D_%D7%90%D7%9C%D7%99%D7%A4%D7%98%D7%99), **האלגוריתם של טייט** מקבל כקלט מודל שלם של עקום אליפטי $`E`$ מעל $`\mathbb Q`$ (או באופן כללי יותר מעל [שדה מספרים](https://he.wikipedia.org/wiki/%D7%A9%D7%93%D7%94_%D7%9E%D7%A1%D7%A4%D7%A8%D7%99%D7%9D)) וראשוני או [אידיאל ראשוני](https://he.wikipedia.org/wiki/%D7%90%D7%99%D7%93%D7%99%D7%90%D7%9C_%D7%A8%D7%90%D7%A9%D7%95%D7%A0%D7%99) $`p`$. הוא מחזיר את המעריך $`f_p`$ של $`p`$ ב[מוליך](%D7%9E%D7%95%D7%9C%D7%99%D7%9A%20%D7%A9%D7%9C%20%D7%A2%D7%A7%D7%95%D7%9D%20%D7%90%D7%9C%D7%99%D7%A4%D7%98%D7%99.md) של $`E`$, את טיפוס הרדוקציה ב-$`p`$, ואת האינדקס המקומי



```math
c_p = [E(\mathbb Q_p) : E^0(\mathbb Q_p)],
```

 כאשר $`E^0(\mathbb Q_p)`$ חבורת הנקודות מעל $`\mathbb Q_p`$ שהרדוקציה שלהן מודולו $`p`$ היא נקודה לא סינגולרית ($`c_p`$ נקרא **[מספר טמגאווה](%D7%9E%D7%A1%D7%A4%D7%A8%20%D7%98%D7%9E%D7%92%D7%90%D7%95%D7%95%D7%94.md)** המקומי, ומופיע ב[השערת בירץ' וסווינרטון-דייר](https://he.wikipedia.org/wiki/%D7%94%D7%A9%D7%A2%D7%A8%D7%AA_%D7%91%D7%99%D7%A8%D7%A5%27_%D7%95%D7%A1%D7%95%D7%95%D7%99%D7%A0%D7%A8%D7%98%D7%95%D7%9F-%D7%93%D7%99%D7%99%D7%A8)). בנוסף, האלגוריתם קובע אם המודל השלם הנתון מינימלי ב-$`p`$, ואם לא, מחזיר מודל עם מקדמים שלמים שבו ההערכה ב-$`p`$ של הדיסקרימיננטה מינימלית.

האלגוריתם של טייט נותן גם את מבנה הסיבים הסינגולריים, שמתואר על ידי **סמל קודאירה** או **סמל נרון** (ראו משטח אליפטי); זה בתורו קובע את המעריך $`f_p`$ של המוליך של $`E`$.

אפשר לפשט מאוד את האלגוריתם של טייט אם המאפיין של שדה השאריות אינו 2 או 3; במקרה הזה את הטיפוס, את $`c`$ ואת $`f`$ אפשר לקרוא מההערכות של $`j`$ ושל $`\Delta`$ (שמוגדרות להלן).

האלגוריתם של טייט הוצג על ידי ג'ון טייט (1975), כשיפור של התיאור של **[מודל נרון](%D7%9E%D7%95%D7%93%D7%9C%20%D7%A0%D7%A8%D7%95%D7%9F.md)** של עקום אליפטי שנתן אנדרה נרון (1964).

## סימונים

נניח שכל המקדמים של משוואת העקום נמצאים בחוג הערכה בדידה שלם $`R`$, עם שדה שאריות משוכלל $`K`$, ו[אידיאל מקסימלי](https://he.wikipedia.org/wiki/%D7%90%D7%99%D7%93%D7%99%D7%90%D7%9C_%D7%9E%D7%A7%D7%A1%D7%99%D7%9E%D7%9C%D7%99) שנוצר על ידי ראשוני $`\pi`$. העקום האליפטי נתון על ידי המשוואה



```math
y^2 + a_1xy + a_3y = x^3 + a_2x^2 + a_4x + a_6.
```

 נגדיר:



```math
v(\Delta)
```

 – ה[הערכה](%D7%94%D7%A2%D7%A8%D7%9B%D7%94%20p-%D7%90%D7%93%D7%99%D7%AA.md) של $`\Delta`$ ביחס ל-$`\pi`$, כלומר המעריך של $`\pi`$ בפירוק של $`\Delta`$, או אינסוף אם $`\Delta = 0`$;



```math
a_{i,m} = a_i/\pi^m;
```





```math
b_2 = a_1^2 + 4a_2,\quad b_4 = a_1a_3 + 2a_4,\quad b_6 = a_3^2 + 4a_6,
```





```math
b_8 = a_1^2a_6 - a_1a_3a_4 + 4a_2a_6 + a_2a_3^2 - a_4^2,
```





```math
c_4 = b_2^2 - 24b_4,\quad c_6 = -b_2^3 + 36b_2b_4 - 216b_6,
```





```math
\Delta = -b_2^2b_8 - 8b_4^3 - 27b_6^2 + 9b_2b_4b_6,\quad j = c_4^3/\Delta.
```



## האלגוריתם

- **צעד 1.** אם $`\pi`$ אינו מחלק את $`\Delta`$, הטיפוס הוא $`I_0`$ (רדוקציה טובה), $`c = 1`$ ו-$`f = 0`$.
- **צעד 2.** אם $`\pi`$ מחלק את $`\Delta`$ אבל לא את $`c_4`$, הטיפוס הוא $`I_v`$ עם $`v = v(\Delta)`$ (רדוקציה כפלית), $`c = v`$ (במקרה המתפצל; במקרה הלא מתפצל $`c`$ הוא 1 או 2, לפי זוגיות $`v`$), ו-$`f = 1`$.
- **צעד 3.** אחרת, מחליפים קואורדינטות כך ש-$`\pi`$ מחלק את $`a_3, a_4, a_6`$. אם $`\pi^2`$ אינו מחלק את $`a_6`$, הטיפוס הוא $`II`$, $`c = 1`$ ו-$`f = v(\Delta)`$.
- **צעד 4.** אחרת, אם $`\pi^3`$ אינו מחלק את $`b_8`$, הטיפוס הוא $`III`$, $`c = 2`$ ו-$`f = v(\Delta) - 1`$.
- **צעד 5.** אחרת, יהי $`Q_1(Y) = Y^2 + a_{3,1}Y - a_{6,2}`$. אם $`\pi^3`$ אינו מחלק את $`b_6`$, הטיפוס הוא $`IV`$, $`c = 3`$ אם ל-$`Q_1(Y)`$ שני שורשים ב-$`K`$ ו-1 אם יש לו שני שורשים מחוץ ל-$`K`$, ו-$`f = v(\Delta) - 2`$.
- **צעד 6.** אחרת, מחליפים קואורדינטות כך ש-$`\pi`$ מחלק את $`a_1`$ ואת $`a_2`$, $`\pi^2`$ מחלק את $`a_3`$ ואת $`a_4`$, ו-$`\pi^3`$ מחלק את $`a_6`$. יהי $`P(T) = T^3 + a_{2,1}T^2 + a_{4,2}T + a_{6,3}`$. אם ל-$`P(T)`$ שלושה שורשים שונים מודולו $`\pi`$, הטיפוס הוא $`I_0^*`$, $`f = v(\Delta) - 4`$, ו-$`c = 1 + {}`$(מספר השורשים של $`P`$ ב-$`K`$).
- **צעד 7.** אם ל-$`P`$ שורש פשוט אחד ושורש כפול אחד, הטיפוס הוא $`I_\nu^*`$ עבור $`\nu \gt 0`$ כלשהו, $`f = v(\Delta) - 4 - \nu`$, ו-$`c = 2`$ או 4; יש "תת-אלגוריתם" לטיפול במקרה הזה.
- **צעד 8.** אם ל-$`P`$ שורש משולש, מחליפים משתנים כך שהשורש המשולש הוא 0, ואז $`\pi^2`$ מחלק את $`a_2`$, $`\pi^3`$ מחלק את $`a_4`$ ו-$`\pi^4`$ מחלק את $`a_6`$. יהי $`Q_2(Y) = Y^2 + a_{3,2}Y - a_{6,4}`$. אם ל-$`Q_2(Y)`$ שני שורשים שונים מודולו $`\pi`$, הטיפוס הוא $`IV^*`$, $`f = v(\Delta) - 6`$, ו-$`c`$ הוא 3 אם השורשים ב-$`K`$, ו-1 אחרת.
- **צעד 9.** אם ל-$`Q_2(Y)`$ שורש כפול, מחליפים משתנים כך שהשורש הכפול הוא 0. אז $`\pi^3`$ מחלק את $`a_3`$ ו-$`\pi^5`$ מחלק את $`a_6`$. אם $`\pi^4`$ אינו מחלק את $`a_4`$, הטיפוס הוא $`III^*`$, $`f = v(\Delta) - 7`$ ו-$`c = 2`$.
- **צעד 10.** אחרת, אם $`\pi^6`$ אינו מחלק את $`a_6`$, הטיפוס הוא $`II^*`$, $`f = v(\Delta) - 8`$ ו-$`c = 1`$.
- **צעד 11.** אחרת המשוואה אינה מינימלית. מחלקים כל $`a_n`$ ב-$`\pi^n`$ וחוזרים לצעד 1.

(בכל הטיפוסים החיבוריים, $`f = v(\Delta) + 1 - n`$, כאשר $`n`$ מספר הרכיבים של הסיב – זו [נוסחת אוג](%D7%9E%D7%95%D7%9C%D7%99%D7%9A%20%D7%A9%D7%9C%20%D7%A2%D7%A7%D7%95%D7%9D%20%D7%90%D7%9C%D7%99%D7%A4%D7%98%D7%99.md): לטיפוס II יש רכיב אחד, ל-III שניים, ל-IV שלושה, ל-$`I_0^*`$ חמישה וכן הלאה.)

## דוגמאות

- **$`y^2 + y = x^3 - x^2`$, $`p = 11`$.** כאן $`a_1 = 0, a_2 = -1, a_3 = 1, a_4 = a_6 = 0`$, ולכן $`b_2 = -4`$, $`b_4 = 0`$, $`c_4 = 16`$ ו-$`\Delta = -11`$. 11 מחלק את $`\Delta`$ אבל לא את $`c_4 = 16`$, ולכן לפי צעד 2 הטיפוס $`I_1`$, $`f = 1`$: המוליך הוא 11.
- **$`y^2 = x^3 - 2`$, $`p = 3`$.** $`\Delta = -1728 = -2^6\cdot3^3`$, ו-$`c_4 = 0`$, כך שהרדוקציה ב-3 חיבורית. מודולו 3, $`x^3 - 2 \equiv (x + 1)^3`$, והנקודה הסינגולרית היא $`(-1, 0)`$. ההזזה $`x \mapsto x - 1`$ נותנת $`y^2 = x^3 - 3x^2 + 3x - 3`$, עם $`a_4 = 3`$, $`a_6 = -3`$; 3 מחלק את $`a_4, a_6`$ אבל 9 אינו מחלק את $`a_6`$. לכן לפי צעד 3 הטיפוס הוא $`II`$, $`c_3 = 1`$ ו-$`f_3 = v_3(\Delta) = 3`$. (חישוב דומה ב-2 נותן $`f_2 = 6`$, והמוליך הוא $`2^6\cdot3^3 = 1728`$.)
- **$`y^2 = x^3 - x`$, $`p = 2`$.** $`v_2(\Delta) = 6`$, והמוליך הוא $`2^5`$; כלומר $`f = v(\Delta) - 1`$, טיפוס $`III`$ עם שני רכיבים, כפי שנוסחת אוג מנבאת.
