# נפת סלברג

ב[תורת המספרים](https://he.wikipedia.org/wiki/%D7%AA%D7%95%D7%A8%D7%AA_%D7%94%D7%9E%D7%A1%D7%A4%D7%A8%D7%99%D7%9D), **נפת סלברג** היא טכניקה להערכת גודלן של "קבוצות מנופות" של מספרים שלמים חיוביים, המקיימים מערכת תנאים המבוטאים באמצעות קונגרואנציות. את השיטה פיתח [אטלה סלברג](https://he.wikipedia.org/wiki/%D7%90%D7%98%D7%9C%D7%94_%D7%A1%D7%9C%D7%91%D7%A8%D7%92) בשנות ה-40 של המאה ה-20.[^1]

## תיאור

במונחי [תורת הנפה](%D7%AA%D7%95%D7%A8%D7%AA%20%D7%94%D7%A0%D7%A4%D7%94.md), נפת סלברג היא נפה מהסוג הקומבינטורי, כלומר היא נשענת על שימוש זהיר ב[עקרון ההכלה וההפרדה](https://he.wikipedia.org/wiki/%D7%A2%D7%A7%D7%A8%D7%95%D7%9F_%D7%94%D7%94%D7%9B%D7%9C%D7%94_%D7%95%D7%94%D7%94%D7%A4%D7%A8%D7%93%D7%94). סלברג החליף את ערכי [פונקציית מביוס](https://he.wikipedia.org/wiki/%D7%A4%D7%95%D7%A0%D7%A7%D7%A6%D7%99%D7%99%D7%AA_%D7%9E%D7%91%D7%99%D7%95%D7%A1) המופיעים בעקרון זה במערכת של משקלים, שאותם מבצעים אופטימיזציה כדי שיתאימו לבעיה הנתונה. התוצאה היא **חסם עליון** לגודל הקבוצה המנופה.

תהי $`A`$ קבוצה של שלמים חיוביים $`\le x`$, ותהי $`P`$ קבוצה של ראשוניים. כאשר $`d`$ הוא מכפלה של ראשוניים שונים מ-$`P`$, נסמן ב-$`A_d`$ את קבוצת האיברים של $`A`$ המתחלקים ב-$`d`$, ונגדיר $`A_1 = A`$. יהי $`z`$ מספר ממשי חיובי, ונסמן ב-$`P(z)`$ את מכפלת הראשוניים ב-$`P`$ שהם $`\le z`$. מטרת הנפה היא להעריך את



```math
S(A,P,z) = \left\vert A \setminus \bigcup_{p \mid P(z)} A_p \right\vert .
```

 נניח שאפשר להעריך את $`|A_d|`$ על ידי



```math
\left\vert A_d \right\vert = \frac{1}{f(d)} X + R_d ,
```

 כאשר $`f`$ היא פונקציה כפלית ו-$`X = |A|`$. תהי $`g`$ הפונקציה המתקבלת מ-$`f`$ באמצעות [היפוך מביוס](https://he.wikipedia.org/wiki/%D7%A0%D7%95%D7%A1%D7%97%D7%AA_%D7%94%D7%94%D7%99%D7%A4%D7%95%D7%9A_%D7%A9%D7%9C_%D7%9E%D7%91%D7%99%D7%95%D7%A1), כלומר



```math
g(n) = \sum_{d \mid n} \mu(d) f(n/d), \qquad f(n) = \sum_{d \mid n} g(d),
```

 כאשר $`\mu`$ היא פונקציית מביוס. נסמן



```math
V(z) = \sum_{d < z,\ d \mid P(z)} \frac{1}{g(d)}.
```

 אז



```math
S(A,P,z) \le \frac{X}{V(z)} + O\left(\sum_{d_1,d_2 < z,\ d_1,d_2 \mid P(z)} \left\vert R_{[d_1,d_2]} \right\vert \right),
```

 כאשר $`[d_1,d_2]`$ היא ה[כפולה המשותפת המינימלית](https://he.wikipedia.org/wiki/%D7%9B%D7%A4%D7%95%D7%9C%D7%94_%D7%9E%D7%A9%D7%95%D7%AA%D7%A4%D7%AA_%D7%9E%D7%99%D7%A0%D7%99%D7%9E%D7%9C%D7%99%D7%AA) של $`d_1`$ ו-$`d_2`$. לעיתים קרובות מועיל להעריך את $`V(z)`$ באמצעות החסם



```math
V(z) \ge \sum_{d \le z} \frac{1}{f(d)} .
```



## יישומים

- משפט ברון-טיצ'מרש על מספר הראשוניים בסדרה חשבונית;
- מספר השלמים $`n \le x`$ כך ש-$`n`$ [זר](https://he.wikipedia.org/wiki/%D7%9E%D7%A1%D7%A4%D7%A8%D7%99%D7%9D_%D7%96%D7%A8%D7%99%D7%9D) ל-$`\varphi(n)`$ (כאשר $`\varphi`$ היא [פונקציית אוילר](https://he.wikipedia.org/wiki/%D7%A4%D7%95%D7%A0%D7%A7%D7%A6%D7%99%D7%99%D7%AA_%D7%90%D7%95%D7%99%D7%9C%D7%A8)) שקול אסימפטוטית ל-$`e^{-\gamma} x / \log\log\log x`$.
