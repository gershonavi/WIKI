# משוואת ארדש–מוזר

ב[תורת המספרים](https://he.wikipedia.org/wiki/%D7%AA%D7%95%D7%A8%D7%AA_%D7%94%D7%9E%D7%A1%D7%A4%D7%A8%D7%99%D7%9D), **משוואת ארדש–מוזר** היא



```math
1^k + 2^k + \cdots + (m - 1)^k = m^k,
```

 כאשר $`m`$ ו-$`k`$ מוגבלים ל[שלמים](https://he.wikipedia.org/wiki/%D7%9E%D7%A1%D7%A4%D7%A8_%D7%A9%D7%9C%D7%9D) חיוביים – כלומר, מתייחסים אליה כאל [משוואה דיופנטית](https://he.wikipedia.org/wiki/%D7%9E%D7%A9%D7%95%D7%95%D7%90%D7%94_%D7%93%D7%99%D7%95%D7%A4%D7%A0%D7%98%D7%99%D7%AA). הפתרון היחיד הידוע הוא $`1^1 + 2^1 = 3^1`$, ו[פול ארדש](https://he.wikipedia.org/wiki/%D7%A4%D7%95%D7%9C_%D7%90%D7%A8%D7%93%D7%A9) שיער שאין פתרונות נוספים. לכל פתרון נוסף חייב להיות $`m \gt 10^{10^9}`$.[^1]

בכל הערך, $`p`$ מסמן אך ורק [מספרים ראשוניים](https://he.wikipedia.org/wiki/%D7%9E%D7%A1%D7%A4%D7%A8_%D7%A8%D7%90%D7%A9%D7%95%D7%A0%D7%99).

(בחיפוש ישיר עם $`m \lt 300`$ ו-$`k \lt 3m`$ נמצא רק הפתרון $`(m, k) = (3, 1)`$. כמו שנראה למטה, תמיד $`k + 1 \lt m \lt 3(k + 1)/2`$, כך שהחיפוש הזה ממצה לטווח.)

## אילוצים על פתרונות

ב-1953 הוכיח [ליאו מוזר](https://he.wikipedia.org/wiki/%D7%9C%D7%99%D7%90%D7%95_%D7%9E%D7%95%D7%96%D7%A8) שבכל פתרון נוסף:[^2]

1.  $`k`$ זוגי;
2.  $`p \mid m - 1`$ גורר $`(p - 1) \mid k`$;
3.  $`p \mid m + 1`$ גורר $`(p - 1) \mid k`$;
4.  $`p \mid 2m + 1`$ גורר $`(p - 1) \mid k`$;
5.  $`m - 1`$ [חופשי מריבועים](%D7%9E%D7%A1%D7%A4%D7%A8%20%D7%97%D7%95%D7%A4%D7%A9%D7%99%20%D7%9E%D7%A8%D7%99%D7%91%D7%95%D7%A2%D7%99%D7%9D.md);
6.  $`m + 1`$ חופשי מריבועים, או פי 4 ממספר אי-זוגי חופשי מריבועים;
7.  $`2m - 1`$ חופשי מריבועים;
8.  $`2m + 1`$ חופשי מריבועים;
9.  $`\sum_{p\mid(m-1)}\frac{m-1}p \equiv -1 \pmod{m - 1}`$;
10. $`\sum_{p\mid(m+1)}\frac{m+1}p \equiv -2 \pmod{m + 1}`$ (אם $`m + 1`$ זוגי);
11. $`\sum_{p\mid(2m-1)}\frac{2m-1}p \equiv -2 \pmod{2m - 1}`$;
12. $`\sum_{p\mid(2m+1)}\frac{2m+1}p \equiv -4 \pmod{2m + 1}`$;
13. $`m \gt 10^{10^6}`$.

ב-1966 הוכח בנוסף ש:[^3]

1.  $`6 \le k + 2 \lt m \lt 3(k + 1)/2`$;
2.  $`m - 1`$ אינו ראשוני.

ב-1994 הוכח ש:[^4]

1.  [$`\mathrm{lcm}(1, 2, \ldots, 200)`$](https://he.wikipedia.org/wiki/%D7%9B%D7%A4%D7%95%D7%9C%D7%94_%D7%9E%D7%A9%D7%95%D7%AA%D7%A4%D7%AA_%D7%9E%D7%99%D7%A0%D7%99%D7%9E%D7%9C%D7%99%D7%AA) מחלק את $`k`$;
2.  $`m \equiv 3 \pmod{2^{\mathrm{ord}_2(k) + 3} }`$, כאשר $`\mathrm{ord}_2(n)`$ היא [ההערכה ה-2-אדית](%D7%94%D7%A2%D7%A8%D7%9B%D7%94%20p-%D7%90%D7%93%D7%99%D7%AA.md) של $`n`$; באופן שקול, $`\mathrm{ord}_2(m - 3) = \mathrm{ord}_2(k) + 3`$;
3.  לכל ראשוני אי-זוגי $`p`$ שמחלק את $`m`$, $`k \not\equiv 0, 2 \pmod{p - 1}`$;
4.  כל גורם ראשוני של $`m`$ חייב להיות [לא רגולרי](https://he.wikipedia.org/wiki/%D7%A8%D7%90%D7%A9%D7%95%D7%A0%D7%99_%D7%9C%D7%90_%D7%A8%D7%92%D7%95%D7%9C%D7%A8%D7%99) וגדול מ-10000.

ב-1999 שוכללה השיטה של מוזר, והתקבל $`m \gt 1.485\times10^{9{,}321{,}155}`$.[^5]

ב-2002 הוכח[^6] ש-$`k`$ חייב להיות כפולה של $`2^3\cdot3\#\cdot5\#\cdot7\#\cdot19\#\cdot1000\#`$, כאשר $`n\#`$ מסמן [פרימוריאל](%D7%A4%D7%A8%D7%99%D7%9E%D7%95%D7%A8%D7%99%D7%90%D7%9C.md) – מכפלת כל הראשוניים עד $`n`$. המספר הזה גדול מ-$`5.7462\times10^{427}`$ (בדקנו: יש לו 428 ספרות, והוא מתחיל ב-$`5.74621\ldots`$).

ב-2009 הוכח ש-$`2k/(2m - 3)`$ חייב להיות [מנה מתקרבת](https://he.wikipedia.org/wiki/%D7%A9%D7%91%D7%A8_%D7%9E%D7%A9%D7%95%D7%9C%D7%91) של $`\ln 2`$; במה שהמחברים כינו אחד המקרים הנדירים שבהם לחישוב בקנה מידה גדול של קבוע מספרי יש יישום, הם קבעו ש-$`m \gt 2.7139\times10^{1{,}667{,}658{,}416}`$.[^7]

ב-2010 הוכח ש:[^8]

1.  $`m \equiv 3 \pmod 8`$ ו-$`m \equiv \pm1 \pmod 3`$;
2.  ל-$`(m^2 - 1)(4m^2 - 1)/12`$ יש לפחות 4,990,906 גורמים ראשוניים, שאף אחד מהם אינו חוזר.

המספר 4,990,906 נובע מכך ש-$`\sum_{n=1}^{4990905}\frac1{p_n} \lt \frac{19}6 \lt \sum_{n=1}^{4990906}\frac1{p_n}`$, כאשר $`p_n`$ הוא הראשוני ה-$`n`$-י. (בדקנו בנפה עד $`9\cdot10^7`$: הסכום חוצה את $`19/6`$ בדיוק בראשוני ה-4,990,906, שהוא 85,861,889.)

## השיטה של מוזר

יהי $`p`$ גורם ראשוני של $`m - 1`$. ליאו מוזר הראה שמכאן נובע ש-$`p - 1`$ מחלק את $`k`$ וש-



```math
1 + \frac{m - 1}p \equiv 0 \pmod p. \qquad (1)
```

 (הסיבה: מודולו $`p`$, $`m \equiv 1`$, כך שאגף ימין שקול ל-1, ואגף שמאל מורכב מ-$`(m - 1)/p`$ "בלוקים" מלאים של שאריות מודולו $`p`$; סכום החזקות ה-$`k`$ של בלוק מלא הוא $`-1`$ אם $`(p - 1) \mid k`$ ו-0 אחרת.) הכפלה ב-$`p`$ נותנת



```math
p + m - 1 \equiv 0 \pmod{p^2}.
```

 מכאן ש-$`m - 1`$ חייב להיות חופשי מריבועים (אילו $`p^2 \mid m - 1`$, היה נובע $`p^2 \mid p`$). יתרה מזו, כיוון שבפתרונות לא טריוויאליים $`m - 1 \gt 2`$, ולכל מספר חופשי מריבועים בטווח הזה יש גורם ראשוני אי-זוגי, ההנחה ש-$`p - 1`$ מחלק את $`k`$ גוררת ש-$`k`$ זוגי.

לכל גורם ראשוני $`p`$ של $`m - 1`$ יש קונגרואנציה מהצורה (1). הכפלת כולן נותנת



```math
\prod_{p\mid(m-1)}\left(1 + \frac{m - 1}p\right) \equiv 0 \pmod{m - 1}.
```

 פתיחת המכפלה נותנת



```math
1 + \sum_{p\mid(m-1)}\frac{m - 1}p + (\text{איברים מסדר גבוה}) \equiv 0 \pmod{m - 1},
```

 כאשר האיברים מסדר גבוה הם מכפלות של כמה גורמים מהצורה $`(m - 1)/p`$, עם ערכים שונים של $`p`$ בכל גורם. כל האיברים האלה מתחלקים ב-$`m - 1`$ (כי $`m - 1`$ חופשי מריבועים), ולכן הם נעלמים מהקונגרואנציה:



```math
1 + \sum_{p\mid(m-1)}\frac{m - 1}p \equiv 0 \pmod{m - 1}.
```

 חלוקה במודולוס נותנת



```math
\frac1{m - 1} + \sum_{p\mid(m-1)}\frac1p \equiv 0 \pmod 1. \qquad (2)
```

 נימוק דומה נותן את הקונגרואנציות



```math
\frac2{m + 1} + \sum_{p\mid(m+1)}\frac1p \equiv 0 \pmod 1 \quad (\text{אם } m + 1 \text{ זוגי}), \qquad (3)
```





```math
\frac2{2m - 1} + \sum_{p\mid(2m-1)}\frac1p \equiv 0 \pmod 1, \qquad (4)
```





```math
\frac4{2m + 1} + \sum_{p\mid(2m+1)}\frac1p \equiv 0 \pmod 1. \qquad (5)
```



הקונגרואנציות (2)–(5) מגבילות מאוד. למשל, הערכים היחידים של $`m \lt 1000`$ שמקיימים את (2) הם 3, 7 ו-43 (שימו לב: אלה המספרים $`m`$ שעבורם $`m - 1 = 2, 6, 42`$ – "המספרים הפסאודו-מושלמים הראשיים"; למשל $`\frac1{42} + \frac12 + \frac13 + \frac17 = 1`$), ושלושתם נשללים על ידי (4). (בדקנו זאת בחישוב.)

מכאן מתפצלים לשני מקרים: $`m + 1`$ זוגי או אי-זוגי.

אם $`m + 1`$ זוגי, סכום האגפים השמאליים של (2), (3), (4) ו-(5) חייב להיות שלם, ושלם זה הוא לפחות 4. יתרה מזו, [אלגוריתם אוקלידס](https://he.wikipedia.org/wiki/%D7%90%D7%9C%D7%92%D7%95%D7%A8%D7%99%D7%AA%D7%9D_%D7%90%D7%95%D7%A7%D7%9C%D7%99%D7%93%D7%A1) מראה שאף ראשוני $`p \gt 3`$ אינו יכול לחלק יותר ממספר אחד בקבוצה $`\{m - 1, m + 1, 2m - 1, 2m + 1\}`$, ו-2 ו-3 יכולים לחלק לכל היותר שניים מהם. אם $`M = (m - 1)(m + 1)(2m - 1)(2m + 1)`$, מקבלים



```math
\frac1{m - 1} + \frac2{m + 1} + \frac2{2m - 1} + \frac4{2m + 1} + \sum_{p\mid M}\frac1p \ge 4 - \frac12 - \frac13 = 3.1666\ldots \qquad (6)
```

 כיוון שאין פתרונות לא טריוויאליים עם $`m \lt 1000`$, החלק של אגף שמאל של (6) מחוץ לסכום אינו יכול לעלות על $`0.006`$, ולכן



```math
\sum_{p\mid M}\frac1p \gt 3.16.
```

 לכן, אם $`\sum_{p\le x}\frac1p \lt 3.16`$, אז $`M \gt \prod_{p\le x}p`$. במאמר המקורי של מוזר משתמשים בחסמים על [פונקציית ספירת הראשוניים](https://he.wikipedia.org/wiki/%D7%A4%D7%95%D7%A0%D7%A7%D7%A6%D7%99%D7%99%D7%AA_%D7%A1%D7%A4%D7%99%D7%A8%D7%AA_%D7%94%D7%A8%D7%90%D7%A9%D7%95%D7%A0%D7%99%D7%99%D7%9D) כדי להראות ש-



```math
\sum_{p\le10^7}\frac1p \lt 3.16.
```

 לכן $`M`$ חייב להיות גדול ממכפלת 10,000,000 הראשוניים הראשונים, ומכאן $`m \gt 10^{10^6}`$ במקרה הזה.

אם $`m + 1`$ אי-זוגי, אי אפשר להשתמש ב-(3), ולכן במקום (6) מקבלים



```math
\frac1{m - 1} + \frac2{2m - 1} + \frac4{2m + 1} + \sum_{p\mid N}\frac1p \ge 3 - \frac13 = 2.666\ldots,
```

 כאשר $`N = (m - 1)(2m - 1)(2m + 1)`$. במבט ראשון זה נראה תנאי חלש מ-(6), אבל כיוון ש-$`m + 1`$ אי-זוגי, הראשוני 2 אינו יכול להופיע באגף הגדול של אי-השוויון, ומתברר שזו הגבלה חזקה יותר על $`m`$ מאשר במקרה השני.

לכן לכל פתרון לא טריוויאלי $`m \gt 10^{10^6}`$. ב-1999 שוכללה השיטה בעזרת מחשבים, שהחליפו את ההערכות של פונקציית ספירת הראשוניים בחישובים מדויקים; זה נתן את החסם $`m \gt 1.485\times10^{9{,}321{,}155}`$.[^9]

## חסימת היחס m/(k + 1)

נסמן $`S_k(m) = 1^k + 2^k + \cdots + (m - 1)^k`$. אז משוואת ארדש–מוזר היא $`S_k(m) = m^k`$.

### שיטה 1: השוואה לאינטגרלים

השוואה של הסכום $`S_k(m)`$ לאינטגרלים מסוימים של הפונקציה $`x^k`$ נותנת את החסמים $`1 \lt m/(k + 1) \lt 3`$.[^10]

הסכום $`S_k(m)`$ הוא [סכום רימן העליון](https://he.wikipedia.org/wiki/%D7%A1%D7%9B%D7%95%D7%9D_%D7%A8%D7%99%D7%9E%D7%9F) של האינטגרל $`\int_0^{m-1}x^k\,dx`$, עם חלוקה בערכים השלמים של $`x`$, ולכן



```math
S_k(m) \gt \int_0^{m-1}x^k\,dx.
```

 לפי ההנחה $`S_k(m) = m^k`$, ולכן $`m^k \gt \frac{(m - 1)^{k+1} }{k + 1}`$, ומכאן



```math
\frac m{k + 1} \lt \left(1 + \frac1{m - 1}\right)^{k+1}. \qquad (7)
```

 באופן דומה, $`S_k(m)`$ הוא סכום רימן התחתון של $`\int_1^mx^k\,dx`$, ולכן $`S_k(m) \le \int_1^mx^k\,dx`$, כלומר $`m^k \le \frac{m^{k+1} - 1}{k + 1} \lt \frac{m^{k+1} }{k + 1}`$, ולכן



```math
k + 1 \lt m. \qquad (8)
```

 הפעלה של זה על (7) נותנת



```math
\frac m{k + 1} \lt \left(1 + \frac1{m - 1}\right)^m = \left(1 + \frac1{m - 1}\right)^{m-1}\cdot\frac m{m - 1} \lt e\cdot\frac m{m - 1}.
```

 חישוב מראה שאין פתרונות לא טריוויאליים עם $`m \le 10`$, ולכן $`\frac m{k + 1} \lt e\cdot\frac{11}{10} \lt 3`$. יחד עם (8) מקבלים $`1 \lt m/(k + 1) \lt 3`$.

### שיטה 2: מניפולציות אלגבריות

את החסם העליון $`m/(k + 1) \lt 3`$ אפשר לשפר ל-$`m/(k + 1) \lt 3/2`$ בשיטה אלגברית.[^11] מ[הבינום של ניוטון](https://he.wikipedia.org/wiki/%D7%94%D7%91%D7%99%D7%A0%D7%95%D7%9D_%D7%A9%D7%9C_%D7%A0%D7%99%D7%95%D7%98%D7%95%D7%9F), $`(\ell + 1)^{r+1} = \sum_{i=0}^{r+1}\binom{r + 1}i\ell^{r+1-i}`$; סכימה על $`\ell = 1, \ldots, m - 1`$ ומעבר לסכומים $`S`$ נותנים, לכל שלם חיובי $`r`$,



```math
m^{r+1} = 1 + (r + 1)S_r(m) + \sum_{i=2}^{r+1}\binom{r + 1}iS_{r+1-i}(m). \qquad (9)
```

 עם $`r = k`$ ו-$`S_k(m) = m^k`$:



```math
m^k\big(m - (k + 1)\big) = 1 + \sum_{i=2}^{k+1}\binom{k + 1}iS_{k+1-i}(m). \qquad (10)
```

 אגף ימין חיובי, ולכן שוב $`k + 1 \lt m`$. עם $`r = k - 1`$, (9) נותנת $`m^k = 1 + \sum_{s=1}^k\binom ksS_{k-s}(m)`$. הצבה ב-(10) כדי לבטל את $`m^k`$, ושימוש ב-$`\binom{k + 1}{s + 1} = \frac{k + 1}{s + 1}\binom ks`$, נותנים



```math
m - k - 2 = \sum_{s=1}^k\left(\frac{k + 1}{s + 1} - m + (k + 1)\right)\binom ksS_{k-s}(m). \qquad (12)
```

 אם $`m = k + 2`$, אגף שמאל אפס, והמקדם בסוגריים הוא $`\frac{k - s}{s + 1}`$, שהוא חיובי לכל $`s \lt k`$ – ולכן אגף ימין חיובי לכל $`k \gt 1`$, סתירה. לכן $`k + 2 \lt m`$, ואגף שמאל של (12) חיובי. המקדמים $`\frac{k + 1}{s + 1} - m + (k + 1)`$ יורדים ב-$`s`$, ולכן הראשון שבהם ($`s = 1`$) חייב להיות חיובי – אחרת כל האיברים בסכום אי-חיוביים. כלומר



```math
0 \lt \frac{k + 1}2 - m + (k + 1) \quad\Longrightarrow\quad \frac m{k + 1} \lt \frac32.
```



## שברים משולבים

כל פתרון אפשרי של המשוואה חייב לבוא מ[השבר המשולב](https://he.wikipedia.org/wiki/%D7%A9%D7%91%D7%A8_%D7%9E%D7%A9%D7%95%D7%9C%D7%91) של [הלוגריתם הטבעי של 2](https://he.wikipedia.org/wiki/%D7%94%D7%9C%D7%95%D7%92%D7%A8%D7%99%D7%AA%D7%9D_%D7%94%D7%98%D7%91%D7%A2%D7%99_%D7%A9%D7%9C_2): ליתר דיוק, $`2k/(2m - 3)`$ חייב להיות מנה מתקרבת של $`\ln 2`$.[^12]

הרעיון: המשוואה שקולה ל-



```math
1 = \sum_{j=1}^{m-1}\left(1 - \frac jm\right)^k.
```

 כש-$`m`$ ו-$`k`$ גדולים, $`\left(1 - \frac jm\right)^k \approx e^{-jk/m} = z^j`$ עם $`z = e^{-k/m}`$, ואגף ימין קרוב לטור הנדסי $`\frac z{1 - z}`$. התנאי $`\frac z{1 - z} \approx 1`$ נותן $`z \approx \frac12`$, כלומר $`k/m \approx \ln 2`$. ניתוח מדויק יותר, עם איברי תיקון מפיתוח טיילור של $`(1 - y)^ke^{ky}`$, נותן



```math
\frac km = \ln 2\left(1 - \frac3{2m} - \frac{\frac{25}{12} - 3\ln 2}{m^2} + O\left(\frac1{m^3}\right)\right) \qquad (m \to \infty),
```

 ואחרי חסימה אפקטיבית של איבר השגיאה (שמשתמשת בכך ש-$`m \gt 10^9`$, כפי שמוזר הראה) מתקבל



```math
0 \lt \ln 2 - \frac{2k}{2m - 3} \lt \frac{0.0111}{(2m - 3)^2}.
```

 לפי [משפט לז'נדר על שברים משולבים](https://he.wikipedia.org/wiki/%D7%9E%D7%A9%D7%A4%D7%98_%D7%9C%D7%96%27%D7%A0%D7%93%D7%A8_%D7%A2%D7%9C_%D7%A9%D7%91%D7%A8%D7%99%D7%9D_%D7%9E%D7%A9%D7%95%D7%9C%D7%91%D7%99%D7%9D), כל שבר $`p/q`$ עם $`|\alpha - p/q| \lt \frac1{2q^2}`$ הוא מנה מתקרבת של $`\alpha`$, ולכן $`2k/(2m - 3)`$ הוא מנה מתקרבת של $`\ln 2`$. בעזרת התוצאה הזו, 31 מיליארד ספרות עשרוניות של $`\ln 2`$ מספיקות כדי לשלול כל פתרון לא טריוויאלי מתחת ל-$`10^{10^9}`$.[^13]

**הפתרון הטריוויאלי מקיים זאת.** עבור $`(m, k) = (3, 1)`$: $`\frac{2k}{2m - 3} = \frac23`$, ואכן $`\ln 2 = [0; 1, 2, 3, 1, 6, \ldots]`$ והמנות המתקרבות שלו הן $`0, 1, \frac23, \frac7{10}, \frac9{13}, \ldots`$.
