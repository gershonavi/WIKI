# קבוע לנדאו-רמנוג'אן

ב[מתמטיקה](https://he.wikipedia.org/wiki/%D7%9E%D7%AA%D7%9E%D7%98%D7%99%D7%A7%D7%94), ובפרט ב[תורת המספרים](https://he.wikipedia.org/wiki/%D7%AA%D7%95%D7%A8%D7%AA_%D7%94%D7%9E%D7%A1%D7%A4%D7%A8%D7%99%D7%9D), **קבוע לנדאו–רמנוג'אן** (ב[אנגלית](https://he.wikipedia.org/wiki/%D7%90%D7%A0%D7%92%D7%9C%D7%99%D7%AA): Landau–Ramanujan constant) הוא המספר הממשי החיובי $`b`$ המופיע במשפט שהוכיח [אדמונד לנדאו](https://he.wikipedia.org/wiki/%D7%90%D7%93%D7%9E%D7%95%D7%A0%D7%93_%D7%9C%D7%A0%D7%93%D7%90%D7%95) ב-1908,[^1] שלפיו עבור $`x`$ גדול, מספר ה[מספרים השלמים החיוביים](https://he.wikipedia.org/wiki/%D7%9E%D7%A1%D7%A4%D7%A8_%D7%98%D7%91%D7%A2%D7%99) הקטנים מ-$`x`$ שהם סכום של שני [ריבועים](https://he.wikipedia.org/wiki/%D7%9E%D7%A1%D7%A4%D7%A8_%D7%A8%D7%99%D7%91%D7%95%D7%A2%D7%99) מתנהג אסימפטוטית כמו



```math
\frac{bx}{\sqrt{\log x} }.
```



את הקבוע $`b`$ גילה מחדש ב-1913 [סריניוואסה רמנוג'אן](https://he.wikipedia.org/wiki/%D7%A1%D7%A8%D7%99%D7%A0%D7%99%D7%95%D7%95%D7%90%D7%A1%D7%94_%D7%A8%D7%9E%D7%A0%D7%95%D7%92%27%D7%90%D7%9F), במכתב הראשון שכתב ל[גודפרי הרולד הארדי](https://he.wikipedia.org/wiki/%D7%92%D7%95%D7%93%D7%A4%D7%A8%D7%99_%D7%94%D7%A8%D7%95%D7%9C%D7%93_%D7%94%D7%90%D7%A8%D7%93%D7%99).[^2]

## סכומים של שני ריבועים

לפי [משפט שני הריבועים](https://he.wikipedia.org/wiki/%D7%A1%D7%9B%D7%95%D7%9D_%D7%A9%D7%9C_%D7%A9%D7%A0%D7%99_%D7%A8%D7%99%D7%91%D7%95%D7%A2%D7%99%D7%9D), המספרים שאפשר להציג כסכום של שני ריבועים של מספרים שלמים הם בדיוק אלה שבפירוק שלהם ל[גורמים ראשוניים](https://he.wikipedia.org/wiki/%D7%9E%D7%A1%D7%A4%D7%A8_%D7%A8%D7%90%D7%A9%D7%95%D7%A0%D7%99) כל ראשוני החופף ל-3 מודולו 4 מופיע בחזקה זוגית. לדוגמה, $`45 = 9 + 36`$ הוא סכום של שני ריבועים; בפירוק שלו, $`3^2 \cdot 5`$, הראשוני 3 מופיע בחזקה זוגית, והראשוני 5 חופף ל-1 מודולו 4, ולכן החזקה שלו יכולה להיות אי-זוגית.

המשפט של לנדאו קובע שאם $`N(x)`$ הוא מספר השלמים החיוביים הקטנים מ-$`x`$ שהם סכום של שני ריבועים, אז



```math
\lim_{x\rightarrow\infty} \frac{N(x)}{x/\sqrt{\log x} }=b\approx 0.764223653589220662990698731250092328116790541
```

 (סדרה [A064533](https://oeis.org/A064533) ב-OEIS), כאשר $`b`$ הוא קבוע לנדאו–רמנוג'אן.

אפשר לכתוב את קבוע לנדאו–רמנוג'אן גם כמכפלה אינסופית:



```math
b = \frac{1}{\sqrt{2} }\prod_{p\equiv 3 \pmod{4} } \left(1 - \frac{1}{p^2}\right)^{-1/2} = \frac{\pi}{4} \prod_{p\equiv 1 \pmod{4} } \left(1 - \frac{1}{p^2}\right)^{1/2}.
```



## היסטוריה

לנדאו ניסח את הקבוע בצורת הגבול שלמעלה; רמנוג'אן, לעומתו, קירב את $`N(x)`$ באמצעות אינטגרל, עם אותו קבוע פרופורציה ועם איבר שגיאה שגדל לאט.[^3]
