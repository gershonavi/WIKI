# פונקציית זטא של בארנס

ב[מתמטיקה](https://he.wikipedia.org/wiki/%D7%9E%D7%AA%D7%9E%D7%98%D7%99%D7%A7%D7%94), **פונקציית זטא של בארנס** (ב[אנגלית](https://he.wikipedia.org/wiki/%D7%90%D7%A0%D7%92%D7%9C%D7%99%D7%AA): Barnes zeta function) היא הכללה של [פונקציית זטא של רימן](https://he.wikipedia.org/wiki/%D7%A4%D7%95%D7%A0%D7%A7%D7%A6%D7%99%D7%99%D7%AA_%D7%96%D7%98%D7%90_%D7%A9%D7%9C_%D7%A8%D7%99%D7%9E%D7%9F) שהציג ארנסט ויליאם בארנס ב-1901.[^1] היא מוכללת עוד יותר על ידי פונקציית הזטא של שינטני.

## הגדרה

פונקציית הזטא של בארנס מוגדרת על ידי



```math
\zeta_N(s,w\mid a_1,\ldots,a_N)=\sum_{n_1,\dots,n_N\ge 0}\frac{1}{(w+n_1a_1+\cdots+n_Na_N)^s},
```

 כאשר ל-$`w`$ ול-$`a_j`$ יש חלק ממשי חיובי, ול-$`s`$ יש חלק ממשי גדול מ-$`N`$.

יש לה [המשכה מרומורפית](https://he.wikipedia.org/wiki/%D7%94%D7%9E%D7%A9%D7%9B%D7%94_%D7%90%D7%A0%D7%9C%D7%99%D7%98%D7%99%D7%AA) לכל $`s`$ מרוכב, שהסינגולריות היחידות שלה הן קטבים פשוטים (לכל היותר) ב-$`s = 1, 2, \ldots, N`$. עבור $`N = w = a_1 = 1`$ היא פונקציית זטא של רימן. באופן כללי יותר, עבור $`N = 1`$ ו-$`a_1 = 1`$ מתקבלת [פונקציית זטא של הורוויץ](%D7%A4%D7%95%D7%A0%D7%A7%D7%A6%D7%99%D7%99%D7%AA%20%D7%96%D7%98%D7%90%20%D7%A9%D7%9C%20%D7%94%D7%95%D7%A8%D7%95%D7%95%D7%99%D7%A5.md) $`\zeta(s,w)`$.

== דוגמה: N = 2 (נוסף בתרגום) == עבור $`N = 2`$ ו-$`a_1 = a_2 = 1`$, מספר הזוגות $`(n_1, n_2)`$ עם $`n_1 + n_2 = m`$ הוא $`m + 1`$, ולכן



```math
\zeta_2(s, w \mid 1, 1) = \sum_{m \ge 0}\frac{m+1}{(w+m)^s} = \zeta(s-1, w) + (1-w)\,\zeta(s, w),
```

 כי $`m + 1 = (w + m) + (1 - w)`$. מכאן רואים את הקטבים: $`\zeta(s-1,w)`$ תורם קוטב ב-$`s = 2`$ עם שארית 1, ו-$`(1-w)\zeta(s,w)`$ תורם קוטב ב-$`s = 1`$ עם שארית $`1 - w`$. בפרט, כאשר $`w = 1`$ הקוטב ב-$`s = 1`$ נעלם, ומתקבל $`\zeta_2(s,1\mid1,1) = \zeta(s-1)`$. (הזהות נבדקה מספרית, למשל עבור $`w = 0.6`$, $`s = 3.5`$.)
