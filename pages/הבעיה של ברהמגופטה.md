# הבעיה של ברהמגופטה

את הבעיה הזו הציג בהודו המתמטיקאי ברהמגופטה ב-628 לספירה, בחיבורו *ברהמה ספוטה סידהאנטה*:

  
פתרו את [משוואת פל](https://he.wikipedia.org/wiki/%D7%9E%D7%A9%D7%95%D7%95%D7%90%D7%AA_%D7%A4%D7%9C)



```math
x^2 - 92y^2 = 1
```



ב[מספרים שלמים](https://he.wikipedia.org/wiki/%D7%9E%D7%A1%D7%A4%D7%A8_%D7%A9%D7%9C%D7%9D) $`x, y \gt 0`$.

ברהמגופטה נתן את הפתרון הקטן ביותר:



```math
(x, y) = (1151, 120).
```

 ואכן $`1151^2 - 92\cdot120^2 = 1324801 - 1324800 = 1`$.

ברהמגופטה כתב, לפי המסורת, שמי שפותר את הבעיה הזו בתוך שנה הוא מתמטיקאי.

## הפתרון של ברהמגופטה

הפתרון משתמש ב"הרכבה" (*בהוונה*), כלומר בזהות ברהמגופטה:



```math
(x_1^2 - Ny_1^2)(x_2^2 - Ny_2^2) = (x_1x_2 + Ny_1y_2)^2 - N(x_1y_2 + x_2y_1)^2.
```



1.  **פתרון התחלתי עם $`k = 8`$.** $`10^2 - 92\cdot1^2 = 100 - 92 = 8`$.
2.  **הרכבה עם עצמו.** הרכבת $`(10, 1)`$ עם עצמו נותנת $`(10^2 + 92\cdot1^2,\ 2\cdot10\cdot1) = (192, 20)`$, עם $`192^2 - 92\cdot20^2 = 8^2 = 64`$.
3.  **חלוקה ב-8.** $`\left(\frac{192}8\right)^2 - 92\left(\frac{20}8\right)^2 = 1`$, כלומר $`24^2 - 92\left(\frac52\right)^2 = 576 - 575 = 1`$. זה פתרון רציונלי.
4.  **הרכבה נוספת.** הרכבת $`\left(24, \frac52\right)`$ עם עצמו נותנת

  
  
$`\left(24^2 + 92\cdot\frac{25}4,\ 2\cdot24\cdot\frac52\right) = (576 + 575,\ 120) = (1151, 120),`$

וזה הפתרון השלם.

באופן שקול, אפשר לחלק את $`(10, 1, 8)`$ ב-2 ולקבל את הפתרון הרציונלי $`5^2 - 92\left(\frac12\right)^2 = 2`$; הכלל של ברהמגופטה למקרה $`k = 2`$ (ראו [שיטת צ'קרוואלה](%D7%A9%D7%99%D7%98%D7%AA%20%D7%A6%27%D7%A7%D7%A8%D7%95%D7%95%D7%90%D7%9C%D7%94.md)), $`x = a^2 - 1`$, $`y = ab`$, נותן מיד את $`\left(24, \frac52\right)`$.

## דרך השברים המשולבים

[השבר המשולב](https://he.wikipedia.org/wiki/%D7%A9%D7%91%D7%A8_%D7%9E%D7%A9%D7%95%D7%9C%D7%91) של $`\sqrt{92}`$ הוא



```math
\sqrt{92} = [9;\ \overline{1, 1, 2, 4, 2, 1, 1, 18}],
```

 עם מחזור באורך 8 (זוגי), והמנה המתקרבת שלפני סוף המחזור הראשון נותנת את הפתרון היסודי: $`\frac{1151}{120} = 9.591666\ldots`$, בעוד ש-$`\sqrt{92} = 9.591663\ldots`$. (בדקנו את פיתוח השבר המשולב בחישוב.) כאן רואים את היתרון של שיטת ההרכבה של ברהמגופטה: שני צעדים במקום שמונה.
