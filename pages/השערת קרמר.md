# השערת קרמר

ב[תורת המספרים](https://he.wikipedia.org/wiki/%D7%AA%D7%95%D7%A8%D7%AA_%D7%94%D7%9E%D7%A1%D7%A4%D7%A8%D7%99%D7%9D), **השערת קרמר**, שניסח המתמטיקאי השוודי הראלד קרמר ב-1936,[^1] היא הערכה לגודלם של הרווחים בין מספרים ראשוניים עוקבים. באופן אינטואיטיבי, הרווחים בין ראשוניים עוקבים תמיד קטנים, וההשערה קובעת באופן אסימפטוטי עד כמה קטנים הם חייבים להיות. ההשערה קובעת ש



```math
p_{n+1}-p_n=O((\log p_n)^2),
```

 כאשר $`p_n`$ הוא ה[מספר הראשוני](https://he.wikipedia.org/wiki/%D7%9E%D7%A1%D7%A4%D7%A8_%D7%A8%D7%90%D7%A9%D7%95%D7%A0%D7%99) ה-$`n`$, $`O`$ הוא [סימון O גדולה](https://he.wikipedia.org/wiki/%D7%A1%D7%99%D7%9E%D7%95%D7%9F_%D7%90%D7%A1%D7%99%D7%9E%D7%A4%D7%98%D7%95%D7%98%D7%99), ו-$`\log`$ הוא הלוגריתם הטבעי. זו הטענה שקרמר שיער במפורש, אך הנימוק ההיוריסטי שלו תומך למעשה בטענה החזקה יותר



```math
\limsup_{n\rightarrow\infty} \frac{p_{n+1}-p_n}{(\log p_n)^2} = 1,
```

 או באופן שקול: לכל $`\epsilon > 0`$ קיים חסם $`B(\epsilon)`$ כך שלכל $`p_n \geq B(\epsilon)`$ מתקיים



```math
p_{n+1}-p_n < (1+\epsilon) (\log p_n)^2.
```

 לעיתים גם הניסוח הזה מכונה השערת קרמר. אולם מודלים היוריסטיים מדויקים יותר אינם תומכים בגרסה החזקה הזו, אך הם כן תומכים בגרסה הראשונה.

הצורה החזקה מכולן, שקרמר מעולם לא טען אותה אך היא המשמשת בבדיקות חישוביות, היא פשוט



```math
p_{n+1}-p_n < (\log p_n)^2.
```



אף אחת משלוש הצורות לא הוכחה ולא הופרכה עד כה.

## תוצאות מוכחות על רווחים בין ראשוניים

קרמר הוכיח, בהנחת [השערת רימן](https://he.wikipedia.org/wiki/%D7%94%D7%A9%D7%A2%D7%A8%D7%AA_%D7%A8%D7%99%D7%9E%D7%9F), את הטענה החלשה בהרבה



```math
p_{n+1}-p_n = O(\sqrt{p_n}\,\log p_n).
```

[^2] החסם העליון הבלתי מותנה הטוב ביותר הידוע הוא



```math
p_{n+1}-p_n = O(p_n^{0.525}),
```

 שהוכיחו בייקר, הרמן ופינץ.[^3]

בכיוון ההפוך, א' וסטסינתיוס הוכיח ב-1931 שהרווחים בין ראשוניים גדלים מהר יותר מאשר לוגריתמית, כלומר[^4]



```math
\limsup_{n\to\infty}\frac{p_{n+1}-p_n}{\log p_n}=\infty.
```



את התוצאה הזו שיפר רוברט רנקין,[^5] שהוכיח כי



```math
\limsup_{n\to\infty}\frac{p_{n+1}-p_n}{\log p_n}\cdot\frac{\left(\log^{\circ 3} p_n\right)^2}{\log^{\circ 2} p_n\,\log^{\circ 4} p_n}>0,
```

 כאשר $`\log^{\circ k}`$ הוא הלוגריתם המופעל $`k`$ פעמים ברציפות, למשל $`\log^{\circ 3}p_n = \log\log\log p_n`$.

פאול ארדש שיער שאגף שמאל בנוסחה האחרונה הוא אינסופי. את ההשערה הזו הוכיחו ב-2014 קווין פורד, בן גרין, סרגיי קוניאגין וטרנס טאו,[^6] ובאופן בלתי תלוי ג'יימס מיינרד.[^7] בהמשך שילבו פורד, גרין, קוניאגין, מיינרד וטאו את שתי הגישות,[^8] והראו שעבור אינסוף ערכי $`n`$ מתקיים



```math
p_{n+1}-p_n>\frac{c\,\log p_n\,\log^{\circ 2} p_n\,\log^{\circ 4} p_n}{\log^{\circ3} p_n},
```

 כאשר $`c>0`$ הוא קבוע מוחלט.

## ההצדקה ההיוריסטית

השערת קרמר מבוססת על מודל הסתברותי – במהותו היוריסטיקה – שבו ההסתברות שמספר בגודל $`x`$ הוא ראשוני היא $`1/\log x`$. המודל ידוע בשם **המודל האקראי של קרמר** או מודל קרמר לראשוניים.[^9]

במודל האקראי של קרמר מתקיים



```math
\limsup_{n\rightarrow\infty} \frac{p_{n+1}-p_n}{\log^2 p_n} = 1
```

 בהסתברות 1.[^10] אולם, כפי שהעיר אנדרו גרנוויל,[^11] משפט מאייר מראה שהמודל האקראי של קרמר אינו מתאר כראוי את התפלגות הראשוניים בקטעים קצרים. עידון של המודל, המביא בחשבון התחלקות בראשוניים קטנים, מרמז שהגבול אינו 1 אלא קבוע $`c \ge 2e^{-\gamma}\approx1.1229\ldots`$, כאשר $`\gamma`$ הוא [קבוע אוילר-מסקרוני](https://he.wikipedia.org/wiki/%D7%A7%D7%91%D7%95%D7%A2_%D7%90%D7%95%D7%99%D7%9C%D7%A8-%D7%9E%D7%A1%D7%A7%D7%A8%D7%95%D7%A0%D7%99). יאנוש פינץ העלה את האפשרות שהגבול העליון אינסופי.[^12]

בדומה לכך, לאונרד אדלמן וקווין מקרלי כתבו שבעקבות עבודתו של הלמוט מאייר הוטל ספק בניסוח המדויק של השערת קרמר, אך כנראה עדיין נכון שלכל קבוע $`c>2`$ קיים קבוע $`d>0`$ כך שיש מספר ראשוני בין $`x`$ ל-$`x+d(\log x)^c`$.[^13]

## השערות קשורות

דניאל שנקס שיער את השוויון האסימפטוטי הבא, החזק מהשערת קרמר, עבור הרווח המרבי $`G(x)`$ בין ראשוניים עוקבים עד $`x`$:[^14]



```math
G(x)\sim \log^2 x.
```



ג'יי אייץ' קדוול הציע עבור הרווחים המרביים את הנוסחה[^15]



```math
G(x)\sim \log^2 x - \log x\log\log x,
```

 הזהה פורמלית להשערת שנקס אך מציעה איבר מסדר נמוך יותר.

מרק וולף הציע נוסחה לרווחים המרביים במונחי [פונקציית המספרים הראשוניים](https://he.wikipedia.org/wiki/%D7%A4%D7%95%D7%A0%D7%A7%D7%A6%D7%99%D7%99%D7%AA_%D7%94%D7%9E%D7%A1%D7%A4%D7%A8%D7%99%D7%9D_%D7%94%D7%A8%D7%90%D7%A9%D7%95%D7%A0%D7%99%D7%99%D7%9D) $`\pi(x)`$:[^16]



```math
G(x)\sim \frac{x}{\pi(x)}(2\log\pi(x)-\log x+c),
```

 כאשר $`c=\log(2C_2)=0.2778769\ldots`$ ו-$`C_2=0.6601618\ldots`$ הוא קבוע הראשוניים התאומים. גם נוסחה זו שקולה פורמלית להשערת שנקס, אך מציעה איברים מסדר נמוך יותר:



```math
G(x) \sim \log^2 x - 2\log x\log\log x - (1-c)\log x.
```



תומאס נייסלי חישב רווחים גדולים רבים בין ראשוניים.[^17] את איכות ההתאמה להשערת קרמר הוא מודד באמצעות היחס



```math
R = \frac{\log p_n}{\sqrt{p_{n+1}-p_n} },
```

 ולדבריו, עבור הרווחים המרביים הגדולים ביותר הידועים נשאר $`R`$ קרוב ל-1.13.
