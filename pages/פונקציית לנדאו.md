# פונקציית לנדאו

ב[מתמטיקה](https://he.wikipedia.org/wiki/%D7%9E%D7%AA%D7%9E%D7%98%D7%99%D7%A7%D7%94), **פונקציית לנדאו** $`g(n)`$, הקרויה על שם [אדמונד לנדאו](https://he.wikipedia.org/wiki/%D7%90%D7%93%D7%9E%D7%95%D7%A0%D7%93_%D7%9C%D7%A0%D7%93%D7%90%D7%95), מוגדרת לכל [מספר טבעי](https://he.wikipedia.org/wiki/%D7%9E%D7%A1%D7%A4%D7%A8_%D7%98%D7%91%D7%A2%D7%99) $`n`$ כ[סדר](https://he.wikipedia.org/wiki/%D7%A1%D7%93%D7%A8_%28%D7%AA%D7%95%D7%A8%D7%AA_%D7%94%D7%97%D7%91%D7%95%D7%A8%D7%95%D7%AA%29) הגדול ביותר של איבר ב[חבורה הסימטרית](https://he.wikipedia.org/wiki/%D7%94%D7%97%D7%91%D7%95%D7%A8%D7%94_%D7%94%D7%A1%D7%99%D7%9E%D7%98%D7%A8%D7%99%D7%AA) $`S_n`$. באופן שקול, $`g(n)`$ היא [הכפולה המשותפת הקטנה ביותר](https://he.wikipedia.org/wiki/%D7%94%D7%9E%D7%9B%D7%A4%D7%9C%D7%94_%D7%94%D7%9E%D7%A9%D7%95%D7%AA%D7%A4%D7%AA_%D7%94%D7%9E%D7%99%D7%A0%D7%99%D7%9E%D7%9C%D7%99%D7%AA) הגדולה ביותר של [חלוקה](https://he.wikipedia.org/wiki/%D7%97%D7%9C%D7%95%D7%A7%D7%94_%28%D7%AA%D7%95%D7%A8%D7%AA_%D7%94%D7%9E%D7%A1%D7%A4%D7%A8%D7%99%D7%9D%29) כלשהי של $`n`$, או המספר המרבי של הפעמים שאפשר להפעיל [תמורה](https://he.wikipedia.org/wiki/%D7%AA%D7%9E%D7%95%D7%A8%D7%94) של $`n`$ איברים על עצמה לפני שהיא חוזרת לסדר ההתחלתי.

למשל, $`5 = 2 + 3`$ ו-$`\mathrm{lcm}(2,3) = 6`$. אף חלוקה אחרת של 5 אינה נותנת כפולה משותפת גדולה יותר, ולכן $`g(5) = 6`$. איבר מסדר 6 בחבורה $`S_5`$ הוא, בכתיב מחזורים, $`(1\ 2)(3\ 4\ 5)`$. אותו טיעון חל גם על המספר 6, כלומר $`g(6) = 6`$. קיימות סדרות ארוכות כרצוננו של מספרים עוקבים $`n, n+1, \ldots, n+m`$ שעליהן הפונקציה $`g`$ קבועה.[^1]

הסדרה $`g(0) = 1, g(1) = 1, g(2) = 2, g(3) = 3, g(4) = 4, g(5) = 6, g(6) = 6, g(7) = 12, g(8) = 15, \ldots`$ (סדרה [A000793](https://oeis.org/A000793) ב-OEIS) קרויה על שם לנדאו, שהוכיח בשנת 1902 כי[^2]



```math
\lim_{n\to\infty}\frac{\ln(g(n))}{\sqrt{n \ln(n)} } = 1,
```



כאשר $`\ln`$ הוא ה[לוגריתם הטבעי](https://he.wikipedia.org/wiki/%D7%9C%D7%95%D7%92%D7%A8%D7%99%D7%AA%D7%9D_%D7%98%D7%91%D7%A2%D7%99). באופן שקול, בסימון o קטנה, $`g(n) = e^{(1+o(1))\sqrt{n\ln n} }`$.

ליתר דיוק,[^3]



```math
\ln g(n)=\sqrt{n\ln n}\left(1+\frac{\ln\ln n-1}{2\ln n}-\frac{(\ln\ln n)^2-6\ln\ln n+9}{8(\ln n)^2}+O\left(\left(\frac{\ln\ln n}{\ln n}\right)^3\right)\right).
```



אם $`\pi(x)-\mathrm{Li}(x)=O(R(x))`$, כאשר $`\pi`$ היא [פונקציית המספרים הראשוניים](https://he.wikipedia.org/wiki/%D7%A4%D7%95%D7%A0%D7%A7%D7%A6%D7%99%D7%99%D7%AA_%D7%94%D7%9E%D7%A1%D7%A4%D7%A8%D7%99%D7%9D_%D7%94%D7%A8%D7%90%D7%A9%D7%95%D7%A0%D7%99%D7%99%D7%9D) ו-$`\mathrm{Li}`$ היא [פונקציית האינטגרל הלוגריתמי](https://he.wikipedia.org/wiki/%D7%A4%D7%95%D7%A0%D7%A7%D7%A6%D7%99%D7%99%D7%AA_%D7%94%D7%90%D7%99%D7%A0%D7%98%D7%92%D7%A8%D7%9C_%D7%94%D7%9C%D7%95%D7%92%D7%A8%D7%99%D7%AA%D7%9E%D7%99) עם ההופכית $`\mathrm{Li}^{-1}`$ (ולפי פורד אפשר לקחת $`R(x)=x\exp\bigl(-c(\ln x)^{3/5}(\ln\ln x)^{-1/5}\bigr)`$ עבור קבוע כלשהו $`c > 0`$[^4]), אז[^5]



```math
\ln g(n)=\sqrt{\mathrm{Li}^{-1}(n)}+O\bigl(R(\sqrt{n\ln n})\ln n\bigr).
```



הטענה שלכל $`n`$ גדול מספיק



```math
\ln g(n)<\sqrt{\mathrm{Li}^{-1}(n)}
```



שקולה ל[השערת רימן](https://he.wikipedia.org/wiki/%D7%94%D7%A9%D7%A2%D7%A8%D7%AA_%D7%A8%D7%99%D7%9E%D7%9F).

אפשר להראות ש-



```math
g(n)\le e^{n/e},
```



כאשר שוויון מתקיים רק עבור $`n = 0`$, ולמעשה[^6]



```math
g(n) \le \exp\left(1.05314\sqrt{n\ln n}\right).
```
