# פונקציית צ'בישב

<div class="image">

[תמונה: ChebyshevPsi.png](https://commons.wikimedia.org/wiki/Special:FilePath/ChebyshevPsi.png)

ב[מתמטיקה](https://he.wikipedia.org/wiki/%D7%9E%D7%AA%D7%9E%D7%98%D7%99%D7%A7%D7%94), **פונקציית צ'בישב** היא אחת משתי פונקציות קרובות זו לזו ב[תורת המספרים](https://he.wikipedia.org/wiki/%D7%AA%D7%95%D7%A8%D7%AA_%D7%94%D7%9E%D7%A1%D7%A4%D7%A8%D7%99%D7%9D), הקרויות על שמו של [פפנוטי צ'בישב](https://he.wikipedia.org/wiki/%D7%A4%D7%A4%D7%A0%D7%95%D7%98%D7%99_%D7%A6%27%D7%91%D7%99%D7%A9%D7%91). **פונקציית צ'בישב הראשונה**, המסומנת $`\vartheta(x)`$ או $`\theta(x)`$, מוגדרת על ידי



```math
\vartheta(x) = \sum_{p \le x} \log p,
```

 כאשר $`\log`$ הוא ה[לוגריתם הטבעי](https://he.wikipedia.org/wiki/%D7%9C%D7%95%D7%92%D7%A8%D7%99%D7%AA%D7%9D_%D7%98%D7%91%D7%A2%D7%99), והסכום הוא על כל ה[מספרים הראשוניים](https://he.wikipedia.org/wiki/%D7%9E%D7%A1%D7%A4%D7%A8_%D7%A8%D7%90%D7%A9%D7%95%D7%A0%D7%99) $`p`$ שאינם גדולים מ-$`x`$.

**פונקציית צ'בישב השנייה** $`\psi(x)`$ מוגדרת באופן דומה, אלא שהסכום הוא על כל חזקות הראשוניים שאינן גדולות מ-$`x`$:



```math
\psi(x) = \sum_{k \in \mathbb{N}}\sum_{p^k \le x}\log p = \sum_{n \leq x} \Lambda(n) = \sum_{p \le x}\left\lfloor\log_p x\right\rfloor\log p,
```

 כאשר $`\Lambda`$ היא [פונקציית פון מנגולד](https://he.wikipedia.org/wiki/%D7%A4%D7%95%D7%A0%D7%A7%D7%A6%D7%99%D7%99%D7%AA_%D7%A4%D7%95%D7%9F_%D7%9E%D7%A0%D7%92%D7%95%D7%9C%D7%93). פונקציות צ'בישב, ובעיקר השנייה, משמשות לעיתים קרובות ב[הוכחות](https://he.wikipedia.org/wiki/%D7%94%D7%95%D7%9B%D7%97%D7%94) הנוגעות למספרים ראשוניים, משום שבדרך כלל קל יותר לעבוד איתן מאשר עם [פונקציית המספרים הראשוניים](https://he.wikipedia.org/wiki/%D7%A4%D7%95%D7%A0%D7%A7%D7%A6%D7%99%D7%99%D7%AA_%D7%94%D7%9E%D7%A1%D7%A4%D7%A8%D7%99%D7%9D_%D7%94%D7%A8%D7%90%D7%A9%D7%95%D7%A0%D7%99%D7%99%D7%9D) $`\pi(x)`$ (ראו [הנוסחה המדויקת](https://he.wikipedia.org/wiki/) להלן). שתי הפונקציות אסימפטוטיות ל-$`x`$, וטענה זו שקולה ל[משפט המספרים הראשוניים](https://he.wikipedia.org/wiki/%D7%9E%D7%A9%D7%A4%D7%98_%D7%94%D7%9E%D7%A1%D7%A4%D7%A8%D7%99%D7%9D_%D7%94%D7%A8%D7%90%D7%A9%D7%95%D7%A0%D7%99%D7%99%D7%9D).

בשם "פונקציית צ'בישב" (Tchebycheff) נקראת גם פונקציית סקלריזציה המשמשת באופטימיזציה מרובת מטרות, כאשר רוצים לצמצם כמה פונקציות שיש למזער לפונקציה אחת:[^1]



```math
f_{Tchb}(x,w) = \max_i w_i f_i(x).
```

 מזעור פונקציה זו עבור ערכים שונים של $`w`$ נותן את כל הנקודות על חזית פארטו, גם בחלקיה הלא קמורים.[^2] לעיתים קרובות הפונקציות שיש למזער אינן $`f_i`$ אלא $`|f_i-z_i^*|`$ עבור סקלרים $`z_i^*`$, ואז $`f_{Tchb}(x,w) = \max_i w_i |f_i(x)-z_i^*|`$.[^3]

## קשרים בין הפונקציות

אפשר לראות את הקשר בין הפונקציה השנייה לראשונה אם כותבים



```math
\psi(x) = \sum_{p \le x}k \log p,
```

 כאשר $`k`$ הוא ה[שלם](https://he.wikipedia.org/wiki/%D7%9E%D7%A1%D7%A4%D7%A8_%D7%A9%D7%9C%D7%9D) היחיד המקיים $`p^k \le x < p^{k+1}`$. ערכי $`k`$ מופיעים בסדרה [A206722](https://oeis.org/A206722) ב-[OEIS](https://he.wikipedia.org/wiki/%D7%94%D7%90%D7%A0%D7%A6%D7%99%D7%A7%D7%9C%D7%95%D7%A4%D7%93%D7%99%D7%94_%D7%94%D7%9E%D7%A7%D7%95%D7%95%D7%A0%D7%AA_%D7%9C%D7%A1%D7%93%D7%A8%D7%95%D7%AA_%D7%A9%D7%9C_%D7%9E%D7%A1%D7%A4%D7%A8%D7%99%D7%9D_%D7%A9%D7%9C%D7%9E%D7%99%D7%9D). קשר ישיר יותר הוא



```math
\psi(x) = \sum_{n=1}^\infty \vartheta\big(x^{\frac{1}{n}}\big).
```

 בסכום זה רק מספר סופי של איברים שונים מאפס, שכן $`\vartheta\big(x^{\frac{1}{n}}\big) = 0`$ כאשר



```math
n>\log_2 x = \frac{\log x}{\log 2}.
```



פונקציית צ'בישב השנייה היא הלוגריתם של ה[כפולה המשותפת המינימלית](https://he.wikipedia.org/wiki/%D7%9B%D7%A4%D7%95%D7%9C%D7%94_%D7%9E%D7%A9%D7%95%D7%AA%D7%A4%D7%AA_%D7%9E%D7%99%D7%A0%D7%99%D7%9E%D7%9C%D7%99%D7%AA) של המספרים השלמים מ-1 עד $`n`$:



```math
\operatorname{lcm}(1,2,\dots,n) = e^{\psi(n)}.
```

 ערכי $`\operatorname{lcm}(1,2,\dots,n)`$ מופיעים בסדרה [A003418](https://oeis.org/A003418) ב-OEIS.

## הקשר בין ψ(x)/x ל-ϑ(x)/x

ה[משפט](https://he.wikipedia.org/wiki/%D7%9E%D7%A9%D7%A4%D7%98_%28%D7%9E%D7%AA%D7%9E%D7%98%D7%99%D7%A7%D7%94) "wikilink") הבא קושר בין שתי המנות $`\frac{\psi(x)}{x}`$ ו-$`\frac{\vartheta(x)}{x}`$.[^4]

**משפט:** לכל $`x>0`$ מתקיים



```math
0 \leq \frac{\psi(x)}{x}-\frac{\vartheta(x)}{x}\leq \frac{(\log x)^2}{2\sqrt{x}\log 2}.
```

 מאי-שוויון זה נובע



```math
\lim_{x\to\infty}\!\left(\frac{\psi(x)}{x}-\frac{\vartheta(x)}{x}\right)\! = 0.
```

 במילים אחרות, אם אחת המנות $`\psi(x)/x`$ או $`\vartheta(x)/x`$ שואפת ל[גבול](https://he.wikipedia.org/wiki/%D7%92%D7%91%D7%95%D7%9C_%D7%A9%D7%9C_%D7%A4%D7%95%D7%A0%D7%A7%D7%A6%D7%99%D7%94), גם השנייה שואפת לגבול, ושני הגבולות שווים.

**הוכחה:** מכיוון ש-$`\psi(x)=\sum_{n \leq \log_2 x}\vartheta(x^{1/n})`$, מתקבל



```math
0 \leq \psi(x)-\vartheta(x)=\sum_{2\leq n \leq \log_2 x}\vartheta(x^{1/n}).
```

 מהגדרת $`\vartheta(x)`$ נובע האי-שוויון הטריוויאלי



```math
\vartheta(x)\leq \sum_{p\leq x}\log x\leq x\log x,
```

 ולכן



```math
\begin{align}
0\leq\psi(x)-\vartheta(x)&\leq \sum_{2\leq n\leq \log_2 x}x^{1/n}\log(x^{1/n})\\
&\leq(\log_2 x)\sqrt{x}\log\sqrt{x}\\
&=\frac{\log x}{\log 2}\frac{\sqrt{x}}{2}\log x\\
&=\frac{\sqrt{x}\,(\log x)^2}{2\log 2}.
\end{align}
```

 חלוקה ב-$`x`$ נותנת את האי-שוויון שבמשפט.

## אסימפטוטיקה וחסמים

לפונקציות צ'בישב ידועים החסמים הבאים[^5][^6] (כאן $`p_k`$ הוא המספר הראשוני ה-$`k`$: $`p_1 = 2`$, $`p_2 = 3`$ וכן הלאה):



```math
\begin{align}
\vartheta(p_k) &\ge k\left( \log k+\log\log k-1+\frac{\log\log k-2.050735}{\log k}\right)&& (k\ge10^{11}), \\[8px]
\vartheta(p_k) &\le k\left( \log k+\log\log k-1+\frac{\log\log k-2}{\log k}\right)&& (k \ge 198), \\[8px]
|\vartheta(x)-x| &\le 0.006788\,\frac{x}{\log x}&& (x \ge 10\,544\,111), \\[8px]
|\psi(x)-x|&\le0.006409\,\frac{x}{\log x}&& (x \ge e^{22}),\\[8px]
0.9999\sqrt{x} &< \psi(x)-\vartheta(x)<1.00007\sqrt{x}+1.78\sqrt[3]{x}&& (x\ge121).
\end{align}
```



כמו כן, בהנחת [השערת רימן](https://he.wikipedia.org/wiki/%D7%94%D7%A9%D7%A2%D7%A8%D7%AA_%D7%A8%D7%99%D7%9E%D7%9F),



```math
\begin{align}
|\vartheta(x)-x| &= O\Big(x^{\frac12+\varepsilon}\Big) \\
|\psi(x)-x| &= O\Big(x^{\frac12+\varepsilon}\Big)
\end{align}
```

 לכל $`\varepsilon > 0`$.

קיימים חסמים עליונים ל-$`\vartheta(x)`$ ול-$`\psi(x)`$:[^7][^8]



```math
\begin{align} \vartheta(x)&<1.000028x \\ \psi(x)&<1.03883x \end{align}
```

 לכל $`x > 0`$. הסבר לקבוע 1.03883 מופיע בסדרה [A206431](https://oeis.org/A206431) ב-OEIS.

## הנוסחה המדויקת

בשנת 1895 הוכיח הנס פון מנגולד[^9] ביטוי מפורש ל-$`\psi(x)`$ כסכום על ה[אפסים](https://he.wikipedia.org/wiki/%D7%A9%D7%95%D7%A8%D7%A9_%28%D7%A9%D7%9C_%D7%A4%D7%95%D7%A0%D7%A7%D7%A6%D7%99%D7%94) "wikilink") הלא טריוויאליים של [פונקציית זטא של רימן](https://he.wikipedia.org/wiki/%D7%A4%D7%95%D7%A0%D7%A7%D7%A6%D7%99%D7%99%D7%AA_%D7%96%D7%98%D7%90_%D7%A9%D7%9C_%D7%A8%D7%99%D7%9E%D7%9F):



```math
\psi_0(x) = x - \sum_{\rho} \frac{x^{\rho}}{\rho} - \frac{\zeta'(0)}{\zeta(0)} - \tfrac{1}{2} \log (1-x^{-2}).
```

 (הערך המספרי של $`\tfrac{\zeta'(0)}{\zeta(0)}`$ הוא $`\log(2\pi)`$.) כאן $`\rho`$ עובר על האפסים הלא טריוויאליים של פונקציית זטא, ו-$`\psi_0`$ זהה ל-$`\psi`$, פרט לכך שב[נקודות הקפיצה](https://he.wikipedia.org/wiki/%D7%A0%D7%A7%D7%95%D7%93%D7%AA_%D7%90%D7%99_%D7%A8%D7%A6%D7%99%D7%A4%D7%95%D7%AA) שלה (חזקות הראשוניים) היא מקבלת את הערך האמצעי בין הערך משמאל לערך מימין:



```math
\psi_0(x) = \frac{1}{2}\!\left( \sum_{n \leq x} \Lambda(n)+\sum_{n < x} \Lambda(n)\right).
```

 כלומר, $`\psi_0(x) = \psi(x) - \tfrac{1}{2} \Lambda(x)`$ כאשר $`x`$ הוא חזקת ראשוני ($`x = 2,3,4,5,7,8,9,11,13,16,\dots`$), ו-$`\psi_0(x) = \psi(x)`$ בכל מקרה אחר.

לפי [טור טיילור](https://he.wikipedia.org/wiki/%D7%98%D7%95%D7%A8_%D7%98%D7%99%D7%99%D7%9C%D7%95%D7%A8) של הלוגריתם, אפשר לפרש את האיבר האחרון בנוסחה המפורשת כסכום של $`\tfrac{x^\omega}{\omega}`$ על האפסים הטריוויאליים של פונקציית זטא, $`\omega = -2, -4, -6, \ldots`$, כלומר



```math
\sum_{k=1}^{\infty} \frac{x^{-2k}}{-2k} = \tfrac{1}{2} \log \left( 1 - x^{-2} \right).
```

 באופן דומה, האיבר הראשון, $`x = \tfrac{x^1}{1}`$, מתאים ל[קוטב](https://he.wikipedia.org/wiki/%D7%A7%D7%95%D7%98%D7%91_%28%D7%90%D7%A0%D7%9C%D7%99%D7%96%D7%94_%D7%9E%D7%A8%D7%95%D7%9B%D7%91%D7%AA) "wikilink") הפשוט של פונקציית זטא בנקודה 1. העובדה שזהו קוטב ולא אפס מסבירה את הסימן ההפוך של האיבר.

## תכונות

לפי משפט של [ארהרד שמידט](https://he.wikipedia.org/wiki/%D7%90%D7%A8%D7%94%D7%A8%D7%93_%D7%A9%D7%9E%D7%99%D7%93%D7%98_%28%D7%9E%D7%AA%D7%9E%D7%98%D7%99%D7%A7%D7%90%D7%99) "wikilink"), קיים קבוע חיובי מפורש $`K`$ כך שיש אינסוף [מספרים טבעיים](https://he.wikipedia.org/wiki/%D7%9E%D7%A1%D7%A4%D7%A8_%D7%98%D7%91%D7%A2%D7%99) $`x`$ המקיימים



```math
\psi(x)-x < -K\sqrt{x}
```

 ואינסוף מספרים טבעיים $`x`$ המקיימים



```math
\psi(x)-x > K\sqrt{x}.
```

[^10][^11] ב[סימון o קטנה](https://he.wikipedia.org/wiki/%D7%A1%D7%99%D7%9E%D7%95%D7%9F_%D7%90%D7%A1%D7%99%D7%9E%D7%A4%D7%98%D7%95%D7%98%D7%99) אפשר לכתוב זאת כך:



```math
\psi(x)-x \ne o\left(\sqrt{x}\,\right).
```

 [הארדי](https://he.wikipedia.org/wiki/%D7%92%D7%95%D7%93%D7%A4%D7%A8%D7%99_%D7%94%D7%A8%D7%95%D7%9C%D7%93_%D7%94%D7%90%D7%A8%D7%93%D7%99) ו[ליטלווד](https://he.wikipedia.org/wiki/%D7%92%27%D7%95%D7%9F_%D7%90%D7%93%D7%A0%D7%96%D7%95%D7%A8_%D7%9C%D7%99%D7%98%D7%9C%D7%95%D7%95%D7%93)[^12] הוכיחו תוצאה חזקה יותר:



```math
\psi(x)-x \ne o\left(\sqrt{x}\,\log\log\log x\right).
```



## הקשר לפרימוריאל

פונקציית צ'בישב הראשונה היא הלוגריתם של הפרימוריאל של $`x`$, המסומן $`x\#`$:



```math
\vartheta(x) = \sum_{p \le x} \log p = \log \prod_{p\le x} p = \log\left(x\#\right).
```

 משפט המספרים הראשוניים שקול לטענה $`\lim_{x\to\infty} \vartheta (x)/x = 1`$. מהצורה השקולה $`\vartheta(x)=x(1+o(1))`$ כאשר $`x\rightarrow\infty`$ נובע מייד



```math
x\#=e^{(1+o(1))x}.
```



## הקשר לפונקציית המספרים הראשוניים

אפשר לקשור את פונקציית צ'בישב לפונקציית המספרים הראשוניים באופן הבא. נגדיר



```math
\Pi(x) = \sum_{n \leq x} \frac{\Lambda(n)}{\log n}.
```

 אז



```math
\Pi(x) = \sum_{n \leq x} \Lambda(n) \int_n^x \frac{dt}{t \log^2 t} + \frac{1}{\log x} \sum_{n \leq x} \Lambda(n) = \int_2^x \frac{\psi(t)\, dt}{t \log^2 t} + \frac{\psi(x)}{\log x}.
```

 המעבר מ-$`\Pi`$ לפונקציית המספרים הראשוניים $`\pi`$ נעשה בעזרת המשוואה



```math
\Pi(x) = \pi(x) + \tfrac{1}{2} \pi\left(\sqrt{x}\,\right) + \tfrac{1}{3} \pi\left(\sqrt[3]{x}\,\right) + \cdots
```

 מכיוון ש-$`\pi(x) \le x`$, לצורך קירוב אפשר לכתוב את הקשר האחרון בצורה



```math
\pi(x) = \Pi(x) + O\left(\sqrt{x}\,\right).
```



## השערת רימן

השערת רימן קובעת שלכל האפסים הלא טריוויאליים של פונקציית זטא יש חלק ממשי $`\tfrac{1}{2}`$. במקרה זה $`|x^\rho| = \sqrt{x}`$, ואפשר להראות ש-



```math
\sum_{\rho} \frac{x^{\rho}}{\rho} = O\!\left(\sqrt{x}\, \log^2 x\right).
```

 מכאן, לפי האמור לעיל, נובע



```math
\pi(x) = \operatorname{li}(x) + O\!\left(\sqrt{x}\, \log x\right).
```



## פונקציית ההחלקה

**פונקציית ההחלקה** מוגדרת על ידי



```math
\psi_1(x) = \int_0^x \psi(t)\,dt.
```

 קל להראות ש-$`\psi_1(x) \sim \frac{x^2}{2}`$.
