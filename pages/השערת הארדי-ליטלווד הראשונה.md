# השערת הארדי-ליטלווד הראשונה

ב[תורת המספרים](https://he.wikipedia.org/wiki/%D7%AA%D7%95%D7%A8%D7%AA_%D7%94%D7%9E%D7%A1%D7%A4%D7%A8%D7%99%D7%9D), **השערת הארדי–ליטלווד הראשונה** (ב[אנגלית](https://he.wikipedia.org/wiki/%D7%90%D7%A0%D7%92%D7%9C%D7%99%D7%AA): first Hardy–Littlewood conjecture)[^1] נותנת נוסחה אסימפטוטית למספר ה-$`k`$-יות של מספרים ראשוניים הקטנות מגודל נתון, ובכך מכלילה את [משפט המספרים הראשוניים](https://he.wikipedia.org/wiki/%D7%9E%D7%A9%D7%A4%D7%98_%D7%94%D7%9E%D7%A1%D7%A4%D7%A8%D7%99%D7%9D_%D7%94%D7%A8%D7%90%D7%A9%D7%95%D7%A0%D7%99%D7%99%D7%9D). את ההשערה הציעו לראשונה [גודפרי הרולד הארדי](https://he.wikipedia.org/wiki/%D7%92%D7%95%D7%93%D7%A4%D7%A8%D7%99_%D7%94%D7%A8%D7%95%D7%9C%D7%93_%D7%94%D7%90%D7%A8%D7%93%D7%99) ו[ג'ון אדנזור ליטלווד](https://he.wikipedia.org/wiki/%D7%92%27%D7%95%D7%9F_%D7%90%D7%93%D7%A0%D7%96%D7%95%D7%A8_%D7%9C%D7%99%D7%98%D7%9C%D7%95%D7%95%D7%93) ב-1923.[^2]

## ניסוח

יהיו $`m_1, m_2, \ldots, m_k`$ מספרים שלמים חיוביים זוגיים, כך שהמספרים בסדרה $`P = (p, p + m_1, p + m_2, \ldots , p + m_k)`$ אינם יוצרים מערכת שאריות שלמה מודולו אף ראשוני, ונסמן ב-$`\pi_{P}(n)`$ את מספר הראשוניים $`p`$ הקטנים מ-$`n`$ שעבורם $`p + m_1, p + m_2, \ldots , p + m_k`$ כולם ראשוניים. אז[^3][^4]



```math
\pi_P(n)\sim C_P\int_2^n \frac{dt}{\log^{k+1}t},
```

 כאשר



```math
C_P=2^k \prod_{q \text{ prime,} \atop q \ge 3}\frac{1-\frac{w(q; m_1, m_2, \ldots , m_k)}q}{\left(1-\frac{1}{q}\right)^{k+1} }
```

 היא מכפלה על הראשוניים האי-זוגיים, ו-$`w(q; m_1, m_2, \ldots , m_k)`$ הוא מספר השאריות השונות של $`0, m_1, m_2, \ldots , m_k`$ מודולו $`q`$.

המקרה $`k=1`$, $`m_1=2`$ קשור ל[השערת המספרים הראשוניים התאומים](https://he.wikipedia.org/wiki/%D7%94%D7%A9%D7%A2%D7%A8%D7%AA_%D7%94%D7%9E%D7%A1%D7%A4%D7%A8%D7%99%D7%9D_%D7%94%D7%A8%D7%90%D7%A9%D7%95%D7%A0%D7%99%D7%99%D7%9D_%D7%94%D7%AA%D7%90%D7%95%D7%9E%D7%99%D7%9D). ליתר דיוק, אם $`\pi_2(n)`$ הוא מספר הראשוניים התאומים הקטנים מ-$`n`$, אז



```math
\pi_2(n)\sim C_2 \int_2^n \frac{dt}{\log^2 t},
```

 כאשר



```math
C_2 = 2\prod_{\textstyle{q \text{ prime,}\atop q \ge 3} } \left(1 - \frac{1}{(q-1)^2} \right) \approx 1.320323632\ldots
```

 הוא קבוע הראשוניים התאומים.[^5]

## מספרי סקיוז

את [מספרי סקיוז](https://he.wikipedia.org/wiki/%D7%9E%D7%A1%D7%A4%D7%A8_%D7%A1%D7%A7%D7%99%D7%95%D7%96) אפשר להגדיר גם עבור $`k`$-יות של ראשוניים, על בסיס השערת הארדי–ליטלווד הראשונה. הראשוני הראשון $`p`$ שמפר את אי-השוויון של הארדי–ליטלווד עבור ה-$`k`$-יה $`P`$, כלומר שמקיים



```math
\pi_P(p)>C_P \mathrm{li}_P(p),
```

 (אם ראשוני כזה קיים), הוא מספר סקיוז של $`P`$. כאן $`\mathrm{li}_P(x) = \int_2^x \frac{dt}{\log^{k+1}t}`$.[^6]

## מסקנות

הוכח שההשערה אינה עקבית עם **השערת הארדי–ליטלווד השנייה**, שלפיה $`\pi(x+y) \le \pi(x) + \pi(y)`$ לכל $`x, y \ge 2`$.[^7]
