# הלמה של בהסקרה

**הלמה של בהסקרה** היא זהות שמשמשת כ[למה](https://he.wikipedia.org/wiki/%D7%9C%D7%9E%D7%94_%28%D7%9E%D7%AA%D7%9E%D7%98%D7%99%D7%A7%D7%94%29) ב[שיטת צ'קרוואלה](%D7%A9%D7%99%D7%98%D7%AA%20%D7%A6%27%D7%A7%D7%A8%D7%95%D7%95%D7%90%D7%9C%D7%94.md) לפתרון [משוואת פל](https://he.wikipedia.org/wiki/%D7%9E%D7%A9%D7%95%D7%95%D7%90%D7%AA_%D7%A4%D7%9C). היא נקראת על שם [בהסקרה השני](https://he.wikipedia.org/wiki/%D7%91%D7%94%D7%A1%D7%A7%D7%A8%D7%94_%D7%94%D7%A9%D7%A0%D7%99), והיא קובעת:



```math
Nx^2 + k = y^2 \implies N\left(\frac{mx + y}k\right)^2 + \frac{m^2 - N}k = \left(\frac{my + Nx}k\right)^2
```

 לכל [שלמים](https://he.wikipedia.org/wiki/%D7%9E%D7%A1%D7%A4%D7%A8_%D7%A9%D7%9C%D7%9D) $`m, x, y, N`$ ושלם שונה מאפס $`k`$.

במילים: אם $`(y, x)`$ פותר את $`y^2 - Nx^2 = k`$, אז לכל $`m`$ הזוג $`\left(\frac{my + Nx}k, \frac{mx + y}k\right)`$ פותר את $`Y^2 - NX^2 = \frac{m^2 - N}k`$. הנקודה בשיטת צ'קרוואלה היא לבחור $`m`$ כך שהשברים יהיו שלמים, ו-$`|m^2 - N|`$ קטן – כך מקבלים פתרון חדש עם "$`k`$" קטן.

## הוכחה

ההוכחה היא מניפולציה אלגברית פשוטה: כופלים את שני אגפי המשוואה ב-$`m^2 - N`$, מוסיפים $`N^2x^2 + 2Nmxy + Ny^2`$, מפרקים לגורמים, ומחלקים ב-$`k^2`$:



```math
Nx^2 + k = y^2 \implies Nm^2x^2 - N^2x^2 + k(m^2 - N) = m^2y^2 - Ny^2
```





```math
\implies Nm^2x^2 + 2Nmxy + Ny^2 + k(m^2 - N) = m^2y^2 + 2Nmxy + N^2x^2
```





```math
\implies N(mx + y)^2 + k(m^2 - N) = (my + Nx)^2
```





```math
\implies N\left(\frac{mx + y}k\right)^2 + \frac{m^2 - N}k = \left(\frac{my + Nx}k\right)^2.
```

 כל עוד $`k`$ ו-$`m^2 - N`$ שונים מאפס, הגרירה נכונה בשני הכיוונים. (הלמה נכונה גם למספרים ממשיים או מרוכבים, לא רק לשלמים.)

**הסבר מושגי.** זה מקרה פרטי של [זהות ברהמגופטה](https://he.wikipedia.org/wiki/%D7%96%D7%94%D7%95%D7%AA_%D7%91%D7%A8%D7%94%D7%9E%D7%92%D7%95%D7%A4%D7%98%D7%94): מרכיבים את הפתרון $`(y, x)`$ של $`y^2 - Nx^2 = k`$ עם הפתרון הטריוויאלי $`(m, 1)`$ של $`m^2 - N\cdot1^2 = m^2 - N`$, ומקבלים פתרון של $`Y^2 - NX^2 = k(m^2 - N)`$; אחר כך מחלקים ב-$`k^2`$. במונחי הנורמה ב-$`\mathbb Z[\sqrt N]`$: $`(y + x\sqrt N)(m + \sqrt N) = (my + Nx) + (mx + y)\sqrt N`$.

## דוגמה

עבור $`N = 61`$: $`61\cdot1^2 + 3 = 64 = 8^2`$, כלומר $`x = 1`$, $`y = 8`$, $`k = 3`$. כדי ש-$`\frac{mx + y}k = \frac{m + 8}3`$ יהיה שלם, צריך $`m \equiv 1 \pmod 3`$, ומבין הערכים האלה $`m = 7`$ ממזער את $`|m^2 - 61|`$. הלמה נותנת



```math
61\left(\frac{7 + 8}3\right)^2 + \frac{49 - 61}3 = \left(\frac{7\cdot8 + 61}3\right)^2, \quad\text{כלומר}\quad 61\cdot5^2 - 4 = 39^2,
```

 ואכן $`1525 - 4 = 1521 = 39^2`$. זה הצעד הראשון של שיטת צ'קרוואלה ל-$`x^2 - 61y^2 = 1`$.
