# הפונקציה האריתמטית של פילאי

ב[תורת המספרים](https://he.wikipedia.org/wiki/%D7%AA%D7%95%D7%A8%D7%AA_%D7%94%D7%9E%D7%A1%D7%A4%D7%A8%D7%99%D7%9D), **פונקציית סכום המחלקים המשותפים המקסימליים** (ב[אנגלית](https://he.wikipedia.org/wiki/%D7%90%D7%A0%D7%92%D7%9C%D7%99%D7%AA): gcd-sum function),[^1] הנקראת גם **הפונקציה האריתמטית של פילאי** (Pillai's arithmetical function),[^2] מוגדרת לכל $`n`$ על ידי



```math
P(n)=\sum_{k=1}^n\gcd(k,n),
```

 כלומר סכום ה[מחלקים המשותפים המקסימליים](https://he.wikipedia.org/wiki/%D7%9E%D7%97%D7%9C%D7%A7_%D7%9E%D7%A9%D7%95%D7%AA%D7%A3_%D7%9E%D7%A7%D7%A1%D7%99%D7%9E%D7%9C%D7%99) של $`n`$ עם כל אחד מהמספרים $`1, 2, \dots, n`$. באופן שקול,[^3]



```math
P(n) = \sum_{d\mid n} d\, \varphi(n/d),
```

 כאשר $`d`$ עובר על המחלקים של $`n`$ ו-$`\varphi`$ היא [פונקציית אוילר](https://he.wikipedia.org/wiki/%D7%A4%D7%95%D7%A0%D7%A7%D7%A6%D7%99%D7%99%D7%AA_%D7%90%D7%95%D7%99%D7%9C%D7%A8).

אפשר לכתוב אותה גם כך:



```math
P(n) = \sum_{d \mid n} d\, \tau(d)\, \mu(n/d),
```

 כאשר $`\tau`$ היא [פונקציית מספר המחלקים](https://he.wikipedia.org/wiki/%D7%A4%D7%95%D7%A0%D7%A7%D7%A6%D7%99%D7%99%D7%AA_%D7%9E%D7%97%D7%9C%D7%A7%D7%99%D7%9D) ו-$`\mu`$ היא [פונקציית מביוס](https://he.wikipedia.org/wiki/%D7%A4%D7%95%D7%A0%D7%A7%D7%A6%D7%99%D7%99%D7%AA_%D7%9E%D7%91%D7%99%D7%95%D7%A1).

את [הפונקציה האריתמטית](https://he.wikipedia.org/wiki/%D7%A4%D7%95%D7%A0%D7%A7%D7%A6%D7%99%D7%94_%D7%90%D7%A8%D7%99%D7%AA%D7%9E%D7%98%D7%99%D7%AA) ה[כפלית](https://he.wikipedia.org/wiki/%D7%A4%D7%95%D7%A0%D7%A7%D7%A6%D7%99%D7%94_%D7%9B%D7%A4%D7%9C%D7%99%D7%AA) הזו הציג המתמטיקאי ההודי סובאיה סיווסנקרנאראיאנה פילאי ב-1933.[^4][^5]

## דוגמה והסבר לנוסחה

עבור $`n = 6`$: המחלקים המשותפים המקסימליים של 6 עם 1, 2, 3, 4, 5, 6 הם 1, 2, 3, 2, 1, 6, ולכן $`P(6) = 15`$.

הנוסחה השנייה נובעת מקיבוץ האיברים לפי הערך של $`\gcd(k,n)`$: לכל מחלק $`d`$ של $`n`$, המספרים $`1 \le k \le n`$ שעבורם $`\gcd(k,n) = d`$ הם בדיוק $`k = d j`$ עם $`1 \le j \le n/d`$ ו-$`\gcd(j, n/d) = 1`$, ויש $`\varphi(n/d)`$ כאלה. עבור $`n = 6`$: $`1\cdot\varphi(6) + 2\cdot\varphi(3) + 3\cdot\varphi(2) + 6\cdot\varphi(1) = 2 + 4 + 3 + 6 = 15`$.

מכיוון ש-$`P`$ היא [קונבולוציית דיריכלה](https://he.wikipedia.org/wiki/%D7%A7%D7%95%D7%A0%D7%91%D7%95%D7%9C%D7%95%D7%A6%D7%99%D7%99%D7%AA_%D7%93%D7%99%D7%A8%D7%99%D7%9B%D7%9C%D7%94) של הפונקציות הכפליות $`d \mapsto d`$ ו-$`\varphi`$, היא כפלית. עבור חזקת ראשוני מתקבל $`P(p^k) = (k+1)p^k - k p^{k-1}`$; בפרט $`P(p) = 2p - 1`$.
