# קונגרואנציות קומר

ב[מתמטיקה](https://he.wikipedia.org/wiki/%D7%9E%D7%AA%D7%9E%D7%98%D7%99%D7%A7%D7%94), **קונגרואנציות קומר** (Kummer's congruences) הן [קונגרואנציות](https://he.wikipedia.org/wiki/%D7%97%D7%A9%D7%91%D7%95%D7%9F_%D7%9E%D7%95%D7%93%D7%95%D7%9C%D7%A8%D7%99) שמערבות את [מספרי ברנולי](https://he.wikipedia.org/wiki/%D7%9E%D7%A1%D7%A4%D7%A8%D7%99_%D7%91%D7%A8%D7%A0%D7%95%D7%9C%D7%99), ושגילה [ארנסט אדוארד קומר](https://he.wikipedia.org/wiki/%D7%90%D7%A8%D7%A0%D7%A1%D7%98_%D7%A7%D7%95%D7%9E%D7%A8).[^1]

קובוטה ולאופולדט (1964) השתמשו בקונגרואנציות של קומר כדי להגדיר את **פונקציית הזטא ה-$`p`$-אדית**.[^2]

## ניסוח

הצורה הפשוטה ביותר של קונגרואנציית קומר היא



```math
\frac{B_h}{h}\equiv \frac{B_k}{k} \pmod p
```

 בכל פעם ש-$`h\equiv k \pmod {p-1}`$, כאשר $`p`$ ראשוני, $`h`$ ו-$`k`$ שלמים חיוביים זוגיים שאינם מתחלקים ב-$`p-1`$, ו-$`B_h`$ הם [מספרי ברנולי](https://he.wikipedia.org/wiki/%D7%9E%D7%A1%D7%A4%D7%A8%D7%99_%D7%91%D7%A8%D7%A0%D7%95%D7%9C%D7%99). (התנאי ש-$`p - 1 \nmid h`$ מבטיח ש-$`B_h/h`$ הוא $`p`$-אינטגרלי: לפי [משפט פון שטאודט–קלאוזן](%D7%9E%D7%A9%D7%A4%D7%98%20%D7%A4%D7%95%D7%9F%20%D7%A9%D7%98%D7%90%D7%95%D7%93%D7%98%E2%80%93%D7%A7%D7%9C%D7%90%D7%95%D7%96%D7%9F.md), $`p`$ מופיע במכנה של $`B_h`$ בדיוק כש-$`p - 1 \mid h`$.)

באופן כללי יותר, אם $`h`$ ו-$`k`$ שלמים חיוביים זוגיים שאינם מתחלקים ב-$`p-1`$, אז



```math
(1-p^{h-1})\frac{B_h}{h}\equiv (1-p^{k-1})\frac{B_k}{k} \pmod {p^{a+1} }
```

 בכל פעם ש-



```math
h\equiv k\pmod {\varphi(p^{a+1})},
```

 כאשר $`\varphi(p^{a+1})`$ היא [פונקציית אוילר](https://he.wikipedia.org/wiki/%D7%A4%D7%95%D7%A0%D7%A7%D7%A6%D7%99%D7%99%D7%AA_%D7%90%D7%95%D7%99%D7%9C%D7%A8) ב-$`p^{a+1}`$, ו-$`a`$ שלם אי-שלילי. עבור $`a = 0`$ הביטוי מקבל את הצורה הפשוטה שלמעלה (כי $`p^{h-1} \equiv 0 \pmod p`$). שני האגפים של קונגרואנציית קומר הם בעצם ערכים של פונקציית הזטא ה-$`p`$-אדית (כי $`\zeta(1-h) = -B_h/h`$, והגורם $`1 - p^{h-1}`$ הוא הסרת גורם אוילר של $`p`$), והקונגרואנציות של קומר מראות שפונקציית הזטא ה-$`p`$-אדית רציפה על המספרים השליליים, ולכן אפשר להרחיב אותה ברציפות לכל השלמים ה-$`p`$-אדיים.

## דוגמאות

- $`p = 5`$: $`\tfrac{B_2}{2} = \tfrac1{12}`$, $`\tfrac{B_6}{6} = \tfrac{1}{252}`$, $`\tfrac{B_{10} }{10} = \tfrac{5/66}{10} = \tfrac{1}{132}`$. מודולו 5: $`12 \equiv 252 \equiv 132 \equiv 2`$, ולכן שלושתם $`\equiv 2^{-1} \equiv 3 \pmod 5`$.
- $`p = 37`$: המונה של $`B_{32}`$ מתחלק ב-37 (ולכן 37 [אי-רגולרי](https://he.wikipedia.org/wiki/%D7%9E%D7%A1%D7%A4%D7%A8_%D7%A8%D7%90%D7%A9%D7%95%D7%A0%D7%99_%D7%A8%D7%92%D7%95%D7%9C%D7%A8%D7%99)). לפי קומר, $`B_k/k \equiv 0 \pmod{37}`$ לכל $`k \equiv 32 \pmod{36}`$, למשל $`k = 68`$.

בדקנו בחישוב את הקונגרואנציה הכללית עבור $`p = 5, 7, 11, 13`$, $`a = 0, 1, 2`$ ולכל $`h \lt 60`$, $`k \lt 90`$ המתאימים.
