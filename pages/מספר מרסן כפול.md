# מספר מרסן כפול

ב[מתמטיקה](https://he.wikipedia.org/wiki/%D7%9E%D7%AA%D7%9E%D7%98%D7%99%D7%A7%D7%94), **מספר מרסן כפול** הוא [מספר מרסן](https://he.wikipedia.org/wiki/%D7%A8%D7%90%D7%A9%D7%95%D7%A0%D7%99_%D7%9E%D7%A8%D7%A1%D7%9F) מהצורה $`M_{M_p} = 2^{2^p-1}-1`$, כאשר $`p`$ [ראשוני](https://he.wikipedia.org/wiki/%D7%9E%D7%A1%D7%A4%D7%A8_%D7%A8%D7%90%D7%A9%D7%95%D7%A0%D7%99).

## דוגמאות

ארבעת האיברים הראשונים ב[סדרת](https://he.wikipedia.org/wiki/%D7%A1%D7%93%D7%A8%D7%94_%28%D7%9E%D7%AA%D7%9E%D7%98%D7%99%D7%A7%D7%94%29) מספרי מרסן הכפולים הם ((סדרה [A077586](https://oeis.org/A077586) ב-OEIS)):[^1]



```math
M_{M_2} = M_3 = 7,
```





```math
M_{M_3} = M_7 = 127,
```





```math
M_{M_5} = M_{31} = 2147483647,
```





```math
M_{M_7} = M_{127} = 170141183460469231731687303715884105727.
```



## ראשוני מרסן כפולים

מספר מרסן כפול ש[ראשוני](https://he.wikipedia.org/wiki/%D7%9E%D7%A1%D7%A4%D7%A8_%D7%A8%D7%90%D7%A9%D7%95%D7%A0%D7%99) נקרא **ראשוני מרסן כפול**. כיוון שמספר מרסן $`M_p`$ יכול להיות ראשוני רק אם $`p`$ ראשוני (אם $`p = ab`$, אז $`2^a - 1`$ מחלק את $`2^{ab} - 1`$), מספר מרסן כפול $`M_{M_p}`$ יכול להיות ראשוני רק אם $`M_p`$ עצמו ראשוני מרסן. מבין הערכים הראשונים של $`p`$ שעבורם $`M_p`$ ראשוני, ידוע ש-$`M_{M_p}`$ ראשוני עבור $`p = 2, 3, 5, 7`$, ונמצאו גורמים מפורשים של $`M_{M_p}`$ עבור $`p = 13, 17, 19, 31`$.

(בדקנו בחישוב שכל הגורמים בטבלה ראשוניים ומחלקים את $`M_{M_p}`$ – כלומר $`2^{M_p} \equiv 1 \pmod q`$ – ואת ראשוניות ארבעת הראשונים.) כש-$`p`$ אינו ראשוני מרסן, כמו $`p = 11`$ ($`M_{11} = 2047 = 23\cdot89`$), ה"מספר המרסן הכפול" פריק אוטומטית: $`2^{23} - 1 = 47\cdot178481`$ מחלק את $`2^{2047} - 1`$, ומכאן הגורמים 47 ו-178481 בשורה של 11.

הגורמים של $`M_{M_p}`$, כאשר $`M_p`$ ראשוני, חייבים להיות מהצורה $`2kM_p + 1`$ (כמו כל גורם של מספר מרסן $`M_q`$ עם $`q`$ ראשוני: הסדר של 2 מודולו הגורם הוא $`q`$, ולכן $`q`$ מחלק את הגורם פחות 1). למשל, עבור $`p = 17`$: $`231733529 = 2\cdot884\cdot131071 + 1`$.

לכן המועמד הקטן ביותר לראשוני מרסן כפול הבא הוא $`M_{M_{61} }`$, כלומר $`2^{2305843009213693951} - 1`$. הוא בערך $`1.714 \times 10^{694127911065419641}`$[^2] – גדול מדי לכל [מבחן ראשוניות](https://he.wikipedia.org/wiki/%D7%9E%D7%91%D7%97%D7%9F_%D7%A8%D7%90%D7%A9%D7%95%D7%A0%D7%99%D7%95%D7%AA) ידוע. אין לו גורם ראשוני מתחת ל-$`1 \times 10^{36}`$.[^3] כנראה אין ראשוני מרסן כפולים מלבד ארבעת הידועים.[^4][^5]

הגורמים הראשוניים הקטנים ביותר של $`M_{M_p}`$ (כאשר $`p`$ הוא הראשוני ה-$`n`$-י) הם

  
7, 127, 2147483647, 170141183460469231731687303715884105727, 47, 338193759479, 231733529, 62914441, 2351, 1399, 295257526626031, 18287, 106937, 863, 4703, 138863, 22590223644617, ... (האיבר הבא גדול מ-$`1 \times 10^{36}`$) ((סדרה [A309130](https://oeis.org/A309130) ב-OEIS)).

(בחיפוש עד $`3\cdot10^6`$ מצאנו בדיוק את הגורמים הקטנים 47, 2351, 1399, 18287, 106937, 863, 4703, 138863, ובשאר המקרים אין גורם בתחום הזה – בהתאם לרשימה.)

## השערת קטלן–מרסן

הסדרה המוגדרת [ברקורסיה](https://he.wikipedia.org/wiki/%D7%A8%D7%A7%D7%95%D7%A8%D7%A1%D7%99%D7%94)



```math
c_0 = 2,\qquad c_{n+1} = 2^{c_n}-1 = M_{c_n}
```

 נקראת סדרת **מספרי קטלן–מרסן**.[^6] האיברים הראשונים של הסדרה ((סדרה [A007013](https://oeis.org/A007013) ב-OEIS)) הם:



```math
c_0 = 2,
```





```math
c_1 = 2^2-1 = 3,
```





```math
c_2 = 2^3-1 = 7,
```





```math
c_3 = 2^7-1 = 127,
```





```math
c_4 = 2^{127}-1 = 170141183460469231731687303715884105727,
```





```math
c_5 = 2^{170141183460469231731687303715884105727}-1 \approx 5.45431 \times 10^{51217599719369681875006054625051616349} \approx 10^{10^{37.70942} }
```

 (בדקנו). קטלן גילה את הסדרה הזו אחרי ש[לוקאס](https://he.wikipedia.org/wiki/%D7%90%D7%93%D7%95%D7%90%D7%A8_%D7%9C%D7%95%D7%A7%D7%90%D7%A1) גילה ב-1876 ש-$`M_{127}=c_4`$ ראשוני.[^7][^8][^9] קטלן שיער שהם ראשוניים "עד גבול מסוים". אף שחמשת האיברים הראשונים ראשוניים, אין שיטה ידועה שיכולה להוכיח שאיבר נוסף כלשהו ראשוני (בזמן סביר), פשוט כי הם עצומים. אבל אם $`c_5`$ אינו ראשוני, יש סיכוי לגלות זאת בחישוב $`c_5`$ [מודולו](https://he.wikipedia.org/wiki/%D7%97%D7%A9%D7%91%D7%95%D7%9F_%D7%9E%D7%95%D7%93%D7%95%D7%9C%D7%A8%D7%99) ראשוני קטן $`p`$ כלשהו (בעזרת העלאה בחזקה מודולרית רקורסיבית). אם השארית היא אפס, $`p`$ הוא גורם של $`c_5`$, וזה יפריך את ראשוניותו. כיוון ש-$`c_5`$ הוא מספר מרסן, גורם ראשוני כזה $`p`$ חייב להיות מהצורה $`2kc_4 +1`$. בנוסף, כיוון ש-$`2^n-1`$ [פריק](https://he.wikipedia.org/wiki/%D7%9E%D7%A1%D7%A4%D7%A8_%D7%A4%D7%A8%D7%99%D7%A7) כש-$`n`$ פריק, גילוי של איבר פריק בסדרה ישלול את האפשרות של ראשוניים נוספים בה.

אם $`c_5`$ היה ראשוני, זה היה סותר גם את השערת מרסן החדשה. ידוע ש-$`\frac{2^{c_4} + 1}{3}`$ פריק, עם הגורם



```math
886407410000361345663448535540258622490179142922169401 = 5209834514912200\,c_4 + 1
```

 (בדקנו את השוויון, וש-$`2^{c_4} \equiv -1`$ מודולו הגורם הזה).[^10]

## בתרבות הפופולרית

בסרט *[פיוצ'רמה](https://he.wikipedia.org/wiki/%D7%A4%D7%99%D7%95%D7%A6%27%D7%A8%D7%9E%D7%94)* "החיה עם מיליארד הגבים", מספר המרסן הכפול $`M_{M_7}`$ נראה לרגע ב"הוכחה אלמנטרית של [השערת גולדבך](https://he.wikipedia.org/wiki/%D7%94%D7%A9%D7%A2%D7%A8%D7%AA_%D7%92%D7%95%D7%9C%D7%93%D7%91%D7%9A)". בסרט המספר הזה נקרא "ראשוני מאדים".
