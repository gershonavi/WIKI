# התאמת שימורה

ב[תורת המספרים](https://he.wikipedia.org/wiki/%D7%AA%D7%95%D7%A8%D7%AA_%D7%94%D7%9E%D7%A1%D7%A4%D7%A8%D7%99%D7%9D), **התאמת שימורה** היא התאמה בין [תבניות מודולריות](https://he.wikipedia.org/wiki/%D7%AA%D7%91%D7%A0%D7%99%D7%AA_%D7%9E%D7%95%D7%93%D7%95%D7%9C%D7%A8%D7%99%D7%AA) $`F`$ ממשקל חצי-שלם $`k + 1/2`$ לבין תבניות מודולריות $`f`$ ממשקל זוגי $`2k`$, שגילה [גורו שימורה](https://he.wikipedia.org/wiki/%D7%92%D7%95%D7%A8%D7%95_%D7%A9%D7%99%D7%9E%D7%95%D7%A8%D7%94) ב-1973.[^1] תכונתה העיקרית היא שהערך העצמי של [אופרטור הקה](%D7%90%D7%95%D7%A4%D7%A8%D7%98%D7%95%D7%A8%20%D7%94%D7%A7%D7%94.md) $`T_{n^2}`$ על $`F`$ שווה לערך העצמי של $`T_n`$ על $`f`$. (במשקל חצי-שלם, אופרטורי הקה $`T_m`$ עם $`m`$ שאינו ריבוע מתאפסים, ולכן האופרטורים המעניינים הם $`T_{p^2}`$.)

תהי $`f`$ [תבנית שפיץ](%D7%AA%D7%91%D7%A0%D7%99%D7%AA%20%D7%A9%D7%A4%D7%99%D7%A5.md) הולומורפית ממשקל $`(2k+1)/2`$ וקרקטר $`\chi`$, שהיא תבנית עצמית של כל אופרטורי הקה $`T(p^2)`$. נגדיר



```math
\sum_{n=1}^\infty\Lambda(n)n^{-s} = \prod_p\left(1 - \omega_pp^{-s} + \chi(p)^2p^{2k-1-2s}\right)^{-1},
```

 כאשר $`\omega_p`$ הם הערכים העצמיים של אופרטורי הקה $`T(p^2)`$. בעזרת [המשוואה הפונקציונלית](https://he.wikipedia.org/wiki/%D7%9E%D7%A9%D7%95%D7%95%D7%90%D7%94_%D7%A4%D7%95%D7%A0%D7%A7%D7%A6%D7%99%D7%95%D7%A0%D7%9C%D7%99%D7%AA_%28%D7%A4%D7%95%D7%A0%D7%A7%D7%A6%D7%99%D7%99%D7%AA_L%29) של [פונקציות L](https://he.wikipedia.org/wiki/%D7%A4%D7%95%D7%A0%D7%A7%D7%A6%D7%99%D7%99%D7%AA_L), שימורה הראה ש-



```math
F(z) = \sum_{n=1}^\infty\Lambda(n)q^n
```

 היא תבנית מודולרית הולומורפית ממשקל $`2k`$ וקרקטר $`\chi^2`$.

ההוכחה של שימורה משתמשת ב[קונבולוציית רנקין–סלברג](%D7%A9%D7%99%D7%98%D7%AA%20%D7%A8%D7%A0%D7%A7%D7%99%D7%9F%E2%80%93%D7%A1%D7%9C%D7%91%D7%A8%D7%92.md) של $`f(z)`$ עם טורי התטא



```math
\theta_\psi(z) = \sum_{n=-\infty}^\infty\psi(n)\,n^\nu e^{2i\pi n^2z}, \qquad \nu = \frac{1 - \psi(-1)}2,
```

 עבור [קרקטרי דיריכלה](https://he.wikipedia.org/wiki/%D7%A7%D7%A8%D7%A7%D7%98%D7%A8_%D7%93%D7%99%D7%A8%D7%99%D7%9B%D7%9C%D7%94) $`\psi`$ שונים, ואחר כך מפעילה את [משפט ההיפוך של וייל](https://he.wikipedia.org/wiki/%D7%9E%D7%A9%D7%A4%D7%98_%D7%94%D7%94%D7%99%D7%A4%D7%95%D7%9A_%D7%A9%D7%9C_%D7%95%D7%99%D7%99%D7%9C).

## אופרטורי הקה במשקל חצי-שלם

עבור $`f = \sum b(n)q^n`$ ממשקל $`k + \tfrac12`$ על $`\Gamma_0(4N)`$ עם קרקטר $`\chi`$, ולראשוני $`p \nmid 4N`$, אופרטור הקה $`T(p^2)`$ פועל על המקדמים כך:



```math
b(n) \mapsto b(p^2n) + \chi(p)\left(\frac{(-1)^kn}p\right)p^{k-1}b(n) + \chi(p^2)p^{2k-1}b(n/p^2),
```

 כאשר $`\left(\frac\cdot p\right)`$ הוא [סמל לז'נדר](https://he.wikipedia.org/wiki/%D7%A1%D7%99%D7%9E%D7%9F_%D7%9C%D7%96%27%D7%A0%D7%93%D7%A8), ו-$`b(n/p^2) = 0`$ אם $`p^2 \nmid n`$. אם $`f`$ עצמית עם ערך עצמי $`\omega_p`$ ו-$`b(1) = 1`$, הצבת $`n = 1`$ נותנת



```math
\omega_p = b(p^2) + \chi(p)\left(\frac{(-1)^k}p\right)p^{k-1}.
```



## דוגמה: התבנית של טאנל

התבנית



```math
g(z) = \eta(8z)\eta(16z)\theta(2z) = q + 2q^3 + q^9 - 2q^{11} - 4q^{17} - 2q^{19} - 3q^{25} + 4q^{33} - \cdots,
```

 כאשר $`\eta`$ היא [פונקציית אטא של דדקינד](%D7%A4%D7%95%D7%A0%D7%A7%D7%A6%D7%99%D7%99%D7%AA%20%D7%90%D7%98%D7%90%20%D7%A9%D7%9C%20%D7%93%D7%93%D7%A7%D7%99%D7%A0%D7%93.md) ו-$`\theta(z) = \sum_ne^{2\pi in^2z}`$, היא תבנית שפיץ ממשקל $`\tfrac32`$ ($`k = 1`$) על $`\Gamma_0(128)`$. ההתאמה של שימורה שולחת אותה לתבנית השפיץ ממשקל 2 שמתאימה ל[עקום האליפטי](https://he.wikipedia.org/wiki/%D7%A2%D7%A7%D7%95%D7%9D_%D7%90%D7%9C%D7%99%D7%A4%D7%98%D7%99) $`y^2 = x^3 - x`$ (מוליך 32). כך, למשל:

- $`p = 5`$: $`\omega_5 = b(25) + \left(\frac{-1}5\right)b(1) = -3 + 1 = -2`$, ואכן $`a_5 = 5 + 1 - \#E(\mathbb F_5) = -2`$.
- $`p = 13`$: $`\omega_{13} = b(169) + 1 = 6 = a_{13}`$.
- $`p = 3`$: $`\omega_3 = b(9) + \left(\frac{-1}3\right) = 1 - 1 = 0 = a_3`$, כמו לכל $`p \equiv 3 \pmod 4`$ (העקום הוא בעל [כפל מרוכב](%D7%9B%D7%A4%D7%9C%20%D7%9E%D7%A8%D7%95%D7%9B%D7%91.md) ב-$`\mathbb Z[i]`$).

בדקנו בחישוב מחשב, עבור $`p = 3, 5, 7, 11, 13, 17`$, ש-$`g`$ היא אכן פונקציה עצמית של $`T(p^2)`$ (לכל המקדמים $`b(n)`$ עם $`n \lt 4000/p^2`$), ושהערך העצמי שווה ל-$`a_p`$ של העקום.

הדוגמה הזו היא חלק מ**משפט טאנל** על [מספרים קונגרואנטיים](https://he.wikipedia.org/wiki/%D7%9E%D7%A1%D7%A4%D7%A8_%D7%A7%D7%95%D7%A0%D7%92%D7%A8%D7%95%D7%90%D7%A0%D7%98%D7%99): לפי [משפט ולדשפורגר](https://he.wikipedia.org/wiki/%D7%9E%D7%A9%D7%A4%D7%98_%D7%95%D7%9C%D7%93%D7%A9%D7%A4%D7%95%D7%A8%D7%92%D7%A8), המקדמים של תבניות ממשקל חצי-שלם כמו $`g`$ קשורים לערכים המרכזיים $`L(E_n, 1)`$ של הסיבובים $`E_n: y^2 = x^3 - n^2x`$ של העקום, ולכן הם קובעים (בהנחת [השערת בירץ' וסווינרטון-דייר](https://he.wikipedia.org/wiki/%D7%94%D7%A9%D7%A2%D7%A8%D7%AA_%D7%91%D7%99%D7%A8%D7%A5%27_%D7%95%D7%A1%D7%95%D7%95%D7%99%D7%A0%D7%A8%D7%98%D7%95%D7%9F-%D7%93%D7%99%D7%99%D7%A8)) אם $`n`$ מספר קונגרואנטי.
