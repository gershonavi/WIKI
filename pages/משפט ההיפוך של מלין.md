# משפט ההיפוך של מלין

ב[מתמטיקה](https://he.wikipedia.org/wiki/%D7%9E%D7%AA%D7%9E%D7%98%D7%99%D7%A7%D7%94), **משפט ההיפוך של מלין** (או **נוסחת ההיפוך של מלין**), הקרוי על שמו של יאלמר מלין,[^1][^2] קובע באילו תנאים [התמרת מלין](https://he.wikipedia.org/wiki/%D7%94%D7%AA%D7%9E%D7%A8%D7%AA_%D7%9E%D7%9C%D7%99%D7%9F.md) ההפוכה, או באופן שקול [התמרת לפלס](https://he.wikipedia.org/wiki/%D7%94%D7%AA%D7%9E%D7%A8%D7%AA_%D7%9C%D7%A4%D7%9C%D7%A1) הדו-צדדית ההפוכה, מוגדרת ומשחזרת את הפונקציה שהותמרה.

## ניסוח

תהי $`\varphi(s)`$ [פונקציה אנליטית](https://he.wikipedia.org/wiki/%D7%A4%D7%95%D7%A0%D7%A7%D7%A6%D7%99%D7%94_%D7%90%D7%A0%D7%9C%D7%99%D7%98%D7%99%D7%AA) ברצועה $`a < \Re(s) < b`$, השואפת לאפס [במידה שווה](https://he.wikipedia.org/wiki/%D7%94%D7%AA%D7%9B%D7%A0%D7%A1%D7%95%D7%AA_%D7%91%D7%9E%D7%99%D7%93%D7%94_%D7%A9%D7%95%D7%95%D7%94) כאשר $`\Im(s) \to \pm \infty`$ לכל ערך ממשי $`c`$ בין $`a`$ ל-$`b`$, ושהאינטגרל שלה לאורך ישר כזה [מתכנס בהחלט](https://he.wikipedia.org/wiki/%D7%94%D7%AA%D7%9B%D7%A0%D7%A1%D7%95%D7%AA_%D7%91%D7%94%D7%97%D7%9C%D7%98). אם



```math
f(x)= \{ \mathcal{M}^{-1} \varphi \} = \frac{1}{2 \pi i} \int_{c-i \infty}^{c+i \infty} x^{-s} \varphi(s)\, ds,
```

 אז



```math
\varphi(s)= \{ \mathcal{M} f \} = \int_0^{\infty} x^{s-1} f(x)\,dx.
```



בכיוון ההפוך, נניח ש-$`f(x)`$ רציפה למקוטעין על המספרים הממשיים החיוביים, ובכל נקודת קפיצה היא מקבלת את הערך האמצעי בין הגבולות משני הצדדים, ונניח שהאינטגרל



```math
\varphi(s)=\int_0^{\infty} x^{s-1} f(x)\,dx
```

 מתכנס בהחלט כאשר $`a < \Re(s) < b`$. אז אפשר לשחזר את $`f`$ מהתמרת מלין שלה $`\varphi`$ באמצעות התמרת מלין ההפוכה. את התוצאות האלה מקבלים כאשר קושרים את התמרת מלין ל[התמרת פורייה](https://he.wikipedia.org/wiki/%D7%94%D7%AA%D7%9E%D7%A8%D7%AA_%D7%A4%D7%95%D7%A8%D7%99%D7%99%D7%94) בחילוף משתנים, ומפעילים גרסה מתאימה של משפט ההיפוך של פורייה.[^3]

## תנאי החסימות

אם $`f(x)`$ רציפה, אפשר לחזק את תנאי החסימות על $`\varphi(s)`$. אם $`\varphi(s)`$ אנליטית ברצועה $`a < \Re(s) < b`$ ומקיימת $`\vert\varphi(s)\vert < K \vert s \vert^{-2}`$ עבור קבוע חיובי $`K`$, אז $`f(x)`$ המוגדרת על ידי אינטגרל ההיפוך קיימת ורציפה, והתמרת מלין של $`f`$ היא $`\varphi`$ לפחות ברצועה $`a < \Re(s) < b`$.

מצד שני, אם מסתפקים בכך ש-$`f`$ תהיה פונקציה מוכללת, אפשר להחליש את תנאי החסימות על $`\varphi`$ ולדרוש רק גידול פולינומיאלי בכל רצועה סגורה המוכלת ברצועה הפתוחה $`a < \Re(s) < b`$.

אפשר לנסח גם גרסה של המשפט ב[מרחבי בנך](https://he.wikipedia.org/wiki/%D7%9E%D7%A8%D7%97%D7%91_%D7%91%D7%A0%D7%9A). נסמן ב-$`L_{\nu, p}(R^{+})`$ את [מרחב $`L^p`$](https://he.wikipedia.org/wiki/%D7%9E%D7%A8%D7%97%D7%91_Lp) הממושקל של הפונקציות המרוכבות $`f`$ על הממשיים החיוביים המקיימות



```math
\|f\| = \left(\int_0^\infty |x^\nu f(x)|^p\, \frac{dx}{x}\right)^{1/p} < \infty,
```

 כאשר $`\nu`$ ו-$`p`$ מספרים ממשיים קבועים ו-$`p>1`$. אם $`f(x)`$ שייכת ל-$`L_{\nu, p}(R^{+})`$ עם $`1 < p \le 2`$, אז $`\varphi(s)`$ שייכת ל-$`L_{\nu, q}(R^{+})`$ עם $`q = p/(p-1)`$, ומתקיים



```math
f(x)=\frac{1}{2 \pi i} \int_{\nu-i \infty}^{\nu+i \infty} x^{-s} \varphi(s)\,ds.
```

 כאן מזהים פונקציות השוות זו לזו בכל מקום פרט ל[קבוצה ממידה אפס](https://he.wikipedia.org/wiki/%D7%A7%D7%91%D7%95%D7%A6%D7%94_%D7%9E%D7%9E%D7%99%D7%93%D7%94_%D7%90%D7%A4%D7%A1).

את התמרת לפלס הדו-צדדית אפשר להגדיר על ידי



```math
\left\{\mathcal{B} f\right\}(s) = \left\{\mathcal{M} f(- \ln x) \right\}(s),
```

 ולכן המשפטים האלה חלים גם עליה.
