# משפט יורקט-ריכרט

**משפט יורקט–ריכרט** (ב[אנגלית](https://he.wikipedia.org/wiki/%D7%90%D7%A0%D7%92%D7%9C%D7%99%D7%AA): Jurkat–Richert theorem) הוא [משפט מתמטי](https://he.wikipedia.org/wiki/%D7%9E%D7%A9%D7%A4%D7%98_%28%D7%9E%D7%AA%D7%9E%D7%98%D7%99%D7%A7%D7%94%29) ב[תורת הנפה](%D7%AA%D7%95%D7%A8%D7%AA%20%D7%94%D7%A0%D7%A4%D7%94.md). הוא רכיב מרכזי בהוכחות של [משפט צ'ן](%D7%9E%D7%A9%D7%A4%D7%98%20%D7%A6%27%D7%9F.md) על [השערת גולדבך](https://he.wikipedia.org/wiki/%D7%94%D7%A9%D7%A2%D7%A8%D7%AA_%D7%92%D7%95%D7%9C%D7%93%D7%91%D7%9A).[^1] את המשפט הוכיחו ב-1965 וולפגנג ב. יורקט והנס-אגון ריכרט.[^2]

## ניסוח המשפט

הניסוח כאן לקוח מספרם של דיאמונד והלברשטם.[^3] ניסוחים אחרים מופיעים אצל יורקט וריכרט,[^4] אצל הלברשטם וריכרט[^5] ואצל נתנסון.[^6]

תהי $`A`$ סדרה סופית של מספרים שלמים ותהי $`P`$ קבוצה של מספרים ראשוניים. נסמן ב-$`A_d`$ את מספר האיברים של $`A`$ המתחלקים ב-$`d`$, וב-$`P(z)`$ את מכפלת האיברים של $`P`$ הקטנים מ-$`z`$. נסמן ב-$`\omega(d)`$ [פונקציה כפלית](https://he.wikipedia.org/wiki/%D7%A4%D7%95%D7%A0%D7%A7%D7%A6%D7%99%D7%94_%D7%9B%D7%A4%D7%9C%D7%99%D7%AA) כך ש-$`\omega(p)/p`$ הוא בקירוב החלק של איברי $`A`$ המתחלקים ב-$`p`$, ב-$`X`$ קירוב נוח כלשהו ל-$`|A|`$, ונכתוב את השארית כ-



```math
r_A (d) = \left| A_d \right| - \frac{\omega(d)}{d} X.
```

 נסמן ב-$`S(A,P,z)`$ את מספר האיברים של $`A`$ הזרים ל-$`P(z)`$, ונכתוב



```math
V(z) = \prod_{p \in P,\ p < z} \left( 1 - \frac{\omega(p)}{p} \right).
```

 נסמן ב-$`\nu(m)`$ את מספר המחלקים הראשוניים השונים של $`m`$, וב-$`F_1`$ ו-$`f_1`$ פונקציות המקיימות משוואות דיפרנציאליות-הפרשיות מסוימות (ראו דיאמונד והלברשטם, עמ' 67–68, להגדרה ולתכונות).

נניח שהממד (צפיפות הנפה) הוא 1, כלומר יש קבוע $`C`$ כך שעבור $`2 \le z < w`$ מתקיים



```math
\prod_{z \le p < w} \left( 1 - \frac{\omega(p)}{p} \right)^{-1} \le \left( \frac{\log w}{\log z} \right) \left( 1 + \frac{C}{\log z} \right).
```

 (הספר של דיאמונד והלברשטם מרחיב את המשפט לממדים גבוהים מ-1.) אז משפט יורקט–ריכרט קובע שלכל מספרים $`y`$ ו-$`z`$ עם $`2 \le z \le y \le X`$ מתקיים



```math
S(A,P,z) \le XV(z) \left( F_1 \left(\frac{\log y}{\log z} \right) + O\left(\frac{(\log \log y)^{3/4} }{(\log y)^{1/4} }\right) \right) + \sum_{m\mid P(z),\ m < y} 4^{\nu(m)} \left| r_A(m) \right|
```

 וגם



```math
S(A,P,z) \ge XV(z) \left( f_1 \left(\frac{\log y}{\log z} \right) - O\left(\frac{(\log \log y)^{3/4} }{(\log y)^{1/4} }\right) \right) - \sum_{m\mid P(z),\ m < y} 4^{\nu(m)} \left| r_A(m) \right|.
```



## פירוש

המשפט אומר שאפשר לחסום את מספר האיברים "הנקיים" מראשוניים קטנים מלמעלה ומלמטה על ידי הערך הצפוי $`XV(z)`$ כפול פונקציה של $`s = \log y/\log z`$, ועוד שגיאה שנשלטת על ידי השאריות $`r_A(m)`$ עבור $`m < y`$. הפונקציות של הנפה הליניארית (ממד 1) נתונות במפורש בתחום ההתחלתי:



```math
F_1(s) = \frac{2e^\gamma}{s} \quad (1 \le s \le 3), \qquad f_1(s) = \frac{2e^\gamma \log(s-1)}{s} \quad (2 \le s \le 4),
```

 כאשר $`\gamma`$ הוא [קבוע אוילר-מסקרוני](https://he.wikipedia.org/wiki/%D7%A7%D7%91%D7%95%D7%A2_%D7%90%D7%95%D7%99%D7%9C%D7%A8-%D7%9E%D7%A1%D7%A7%D7%A8%D7%95%D7%A0%D7%99), ו-$`f_1(s) = 0`$ עבור $`s \le 2`$. החסם התחתון חיובי רק כאשר $`s > 2`$, כלומר $`z < y^{1/2}`$: זו אחת הסיבות לכך שבמשפט צ'ן אפשר לנפות רק עד בערך שורש ריבועי של רמת ההתפלגות, ומכאן שמתקבלים מספרים בעלי שני גורמים ראשוניים לכל היותר, ולא ראשוניים.
