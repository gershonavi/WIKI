# פונקציית ריס

ב[מתמטיקה](https://he.wikipedia.org/wiki/%D7%9E%D7%AA%D7%9E%D7%98%D7%99%D7%A7%D7%94), **פונקציית ריס** (ב[אנגלית](https://he.wikipedia.org/wiki/%D7%90%D7%A0%D7%92%D7%9C%D7%99%D7%AA): Riesz function) היא [פונקציה שלמה](https://he.wikipedia.org/wiki/%D7%A4%D7%95%D7%A0%D7%A7%D7%A6%D7%99%D7%94_%D7%A9%D7%9C%D7%9E%D7%94) שהגדיר [מרסל ריס](https://he.wikipedia.org/wiki/%D7%9E%D7%A8%D7%A1%D7%9C_%D7%A8%D7%99%D7%A1) בהקשר של [השערת רימן](https://he.wikipedia.org/wiki/%D7%94%D7%A9%D7%A2%D7%A8%D7%AA_%D7%A8%D7%99%D7%9E%D7%9F), באמצעות [טור החזקות](https://he.wikipedia.org/wiki/%D7%98%D7%95%D7%A8_%D7%97%D7%96%D7%A7%D7%95%D7%AA)



```math
{\rm Riesz}(x) = \sum_{k=1}^\infty \frac{(-1)^{k-1}x^k}{(k-1)! \zeta(2k)}=x \sum_{n=1}^\infty \frac{\mu(n)}{n^2} \exp\left(\frac{-x}{n^2}\right).
```

 אם נגדיר $`F(x) = \tfrac12 {\rm Riesz}(4 \pi^2 x)`$, אפשר להגדיר אותה בעזרת המקדמים של פיתוח [טור לורן](https://he.wikipedia.org/wiki/%D7%98%D7%95%D7%A8_%D7%9C%D7%95%D7%A8%D7%9F) של הקוטנגנס ה[היפרבולי](https://he.wikipedia.org/wiki/%D7%A4%D7%95%D7%A0%D7%A7%D7%A6%D7%99%D7%95%D7%AA_%D7%94%D7%99%D7%A4%D7%A8%D7%91%D7%95%D7%9C%D7%99%D7%95%D7%AA) (או, באופן שקול, הרגיל) סביב אפס. אם



```math
\frac{x}{2} \coth \frac{x}{2} = \sum_{n=0}^\infty c_n x^n = 1 + \frac{1}{12} x^2 - \frac{1}{720}x^4 + \cdots
```

 אז אפשר להגדיר את $`F`$ כ-



```math
F(x) = \sum_{k=1}^\infty \frac{x^k}{c_{2k}(k-1)!} = 12x - 720x^2 + 15120x^3 - \cdots
```



הערכים $`\zeta(2k)`$ שואפים ל-1 כאשר $`k`$ גדל, והשוואת הטור של פונקציית ריס לטור של $`x\exp(-x)`$ מראה שזו פונקציה שלמה. לחלופין, אפשר להגדיר את $`F`$ כ-



```math
F(x) = \sum_{k=1}^{\infty}\frac{k^{\overline{k+1} }x^{k} }{B_{2k} },
```

 כאשר $`n^{\overline{k} }`$ מסמן את העצרת העולה בסימון של [דונלד קנות'](https://he.wikipedia.org/wiki/%D7%93%D7%95%D7%A0%D7%9C%D7%93_%D7%A7%D7%A0%D7%95%D7%AA%27), ו-$`B_n`$ הם [מספרי ברנולי](https://he.wikipedia.org/wiki/%D7%9E%D7%A1%D7%A4%D7%A8%D7%99_%D7%91%D7%A8%D7%A0%D7%95%D7%9C%D7%99). הטור הוא טור מתחלף, והפונקציה שואפת במהירות למינוס אינסוף עבור ערכים שליליים של $`x`$. הערכים החיוביים של $`x`$ מעניינים ועדינים יותר.

פונקציית ריס מקיימת את המשוואה האינטגרלית



```math
1-\exp(-x)= \int_{0}^{\infty}\frac {\lfloor\sqrt{x/t}\rfloor}{t} \mathrm{Riesz}(t)\, dt.
```



## קריטריון ריס

אפשר להראות ש-



```math
\mathrm{Riesz}(x) = O(x^e)\qquad (x\to\infty)
```

 לכל מעריך $`e`$ הגדול מ-$`1/2`$ (ב[סימון O גדולה](https://he.wikipedia.org/wiki/%D7%A1%D7%99%D7%9E%D7%95%D7%9F_%D7%90%D7%A1%D7%99%D7%9E%D7%A4%D7%98%D7%95%D7%98%D7%99)), כאשר הפונקציה מקבלת ערכים חיוביים ושליליים כאחד. ריס הראה שהשערת רימן שקולה לטענה שהאמור לעיל נכון לכל $`e`$ הגדול מ-$`1/4`$[^1]. באותו מאמר הוסיף הערה פסימית מעט: הוא כתב שעדיין אינו יודע אם תנאי זה יקל על אימות ההשערה.

## התמרת מלין של פונקציית ריס

פונקציית ריס קשורה ל[פונקציית זטא של רימן](https://he.wikipedia.org/wiki/%D7%A4%D7%95%D7%A0%D7%A7%D7%A6%D7%99%D7%99%D7%AA_%D7%96%D7%98%D7%90_%D7%A9%D7%9C_%D7%A8%D7%99%D7%9E%D7%9F) דרך [התמרת מלין](%D7%94%D7%AA%D7%9E%D7%A8%D7%AA%20%D7%9E%D7%9C%D7%99%D7%9F.md) שלה. אם ניקח



```math
{\mathcal M}({\rm Riesz}(z)) = \int_0^\infty {\rm Riesz}(z) z^s \frac{dz}{z},
```

 נראה שאם $`\Re(s)>-1`$ אז האינטגרל $`\int_0^1 {\rm Riesz}(z) z^s \frac{dz}{z}`$ מתכנס, ואילו מתנאי הגידול נובע שאם $`\Re(s) < -\tfrac{1}{2}`$ אז $`\int_1^\infty {\rm Riesz}(z) z^s \frac{dz}{z}`$ מתכנס. מכאן שהתמרת מלין של פונקציית ריס מוגדרת ברצועה $`-1 < \Re(s) < -\tfrac12`$, ובה



```math
{\mathcal M}({\rm Riesz}(z)) = \frac{\Gamma(s+1)}{\zeta(-2s)}.
```

 מהתמרת מלין ההפוכה מתקבל ביטוי לפונקציית ריס:



```math
{\rm Riesz}(z) = \frac{1}{2\pi i}\int_{c - i \infty}^{c+i \infty} \frac{\Gamma(s+1)}{\zeta(-2s)} z^{-s} ds,
```

 כאשר $`c`$ בין $`-1`$ ל-$`-\tfrac12`$. אם השערת רימן נכונה, אפשר להזיז את קו האינטגרציה לכל ערך הקטן מ-$`-\tfrac14`$, וכך מתקבלת השקילות בין קצב הגידול כשורש רביעי של פונקציית ריס לבין השערת רימן.

## חישוב פונקציית ריס

המקדמים בטור מקלורן של $`F`$ גדלים בערכם המוחלט עד שהם מגיעים למקסימום באיבר ה-40, $`-1.753\times 10^{17}`$. עד האיבר ה-109 הם יורדים מתחת ל-1 בערכם המוחלט. 1000 האיברים הראשונים מספיקים לחישוב מדויק מאוד של $`F(z)`$ עבור $`|z| < 9`$, אך לשם כך יש לחשב פולינום ממעלה 1000, באריתמטיקה רציונלית עם מקדמים בעלי מונים ומכנים גדולים, או בחישובי נקודה צפה של יותר מ-100 ספרות. אפשרות אחרת היא להשתמש בהתמרת מלין ההפוכה ולבצע אינטגרציה נומרית. אף אחת מהגישות אינה קלה חישובית.

גישה נוספת היא האצת התכנסות. מאחר ש-$`\zeta(2k)`$ שואף ל-1 כאשר $`k`$ גדל, איברי הטור שואפים לאיברי



```math
\sum_{k=1}^\infty \frac{(-1)^{k+1}x^k}{(k-1)!} = x \exp(-x).
```

 ואכן, ריס ציין ש-$`\sum_{n=1}^\infty {\rm Riesz}(x/n^2) = x \exp(-x)`$. שיטת קומר להאצת התכנסות נותנת



```math
{\rm Riesz}(x) = x \exp(-x) - \sum_{k=1}^\infty \left(\zeta(2k) -1\right) \left(\frac{(-1)^{k+1} }{(k-1)! \zeta(2k)}\right)x^k,
```

 עם [סדר התכנסות](https://he.wikipedia.org/wiki/%D7%A1%D7%93%D7%A8_%D7%94%D7%AA%D7%9B%D7%A0%D7%A1%D7%95%D7%AA) משופר. המשך התהליך נותן טור חדש לפונקציית ריס עם תכונות התכנסות טובות בהרבה:



```math
{\rm Riesz}(x) = \sum_{k=1}^\infty \frac{(-1)^{k+1}x^k}{(k-1)!} \left(\sum_{n=1}^\infty \mu(n)n^{-2k}\right) = x \sum_{n=1}^\infty \frac{\mu(n)}{n^2} \exp\left(-\frac{x}{n^2}\right),
```

 כאשר $`\mu`$ היא [פונקציית מביוס](https://he.wikipedia.org/wiki/%D7%A4%D7%95%D7%A0%D7%A7%D7%A6%D7%99%D7%99%D7%AA_%D7%9E%D7%91%D7%99%D7%95%D7%A1), ושינוי סדר האיברים מוצדק בזכות [התכנסות בהחלט](https://he.wikipedia.org/wiki/%D7%94%D7%AA%D7%9B%D7%A0%D7%A1%D7%95%D7%AA_%D7%91%D7%94%D7%97%D7%9C%D7%98). הפעלה נוספת של שיטת קומר נותנת



```math
{\rm Riesz}(x) = x \left(\frac{6}{\pi^2} + \sum_{n=1}^\infty \frac{\mu(n)}{n^2}\left(\exp\left(-\frac{x}{n^2}\right) - 1\right)\right),
```

 שאיבריו יורדים לבסוף כמו $`n^{-4}`$.

הטורים שלעיל מתכנסים בהחלט בכל מקום, ולכן אפשר לגזור אותם איבר-איבר, וכך מתקבל ביטוי לנגזרת של פונקציית ריס:



```math
{\rm Riesz}'(x) = \frac{\text{Riesz}(x)}{x} + x\left(-\frac{90}{\pi^4} + \sum_{n=1}^\infty \frac{\mu(n)}{n^4} \left(1-\exp\left(-\frac{x}{n^2}\right)\right)\right).
```



מרק וולף הראה, בהנחת השערת רימן, שעבור $`x`$ גדול[^2]



```math
{\rm Riesz}(x) \sim K x^{1/4} \sin\left(\phi-\frac{1}{2}\gamma_1\log(x)\right),
```

 כאשר $`\gamma_1=14.13472514\ldots`$ הוא החלק המדומה של האפס הלא טריוויאלי הראשון של פונקציית זטא, $`K = 7.7750627\ldots\times 10^{-5}`$ ו-$`\phi=-0.54916\ldots`$. הדבר מתיישב עם המשפטים הכלליים על אפסי פונקציית ריס שהוכיח הרברט וילף ב-1964[^3].

## קריטריון הארדי-ליטלווד

[גודפרי הרולד הארדי](https://he.wikipedia.org/wiki/%D7%92%D7%95%D7%93%D7%A4%D7%A8%D7%99_%D7%94%D7%A8%D7%95%D7%9C%D7%93_%D7%94%D7%90%D7%A8%D7%93%D7%99) ו[ג'ון אדנזור ליטלווד](https://he.wikipedia.org/wiki/%D7%92%27%D7%95%D7%9F_%D7%90%D7%93%D7%A0%D7%96%D7%95%D7%A8_%D7%9C%D7%99%D7%98%D7%9C%D7%95%D7%95%D7%93)[^4][^5] הוכיחו, בשיטות דומות, שהשערת רימן שקולה לטענה שלכל מעריך $`e`$ הגדול מ-$`-1/4`$



```math
\sum_{k=1}^\infty \frac{(-x)^k}{k! \zeta(2k+1)} = O(x^{e})\qquad (x\to\infty).
```
