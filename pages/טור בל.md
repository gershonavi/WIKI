# טור בל

ב[מתמטיקה](https://he.wikipedia.org/wiki/%D7%9E%D7%AA%D7%9E%D7%98%D7%99%D7%A7%D7%94), **טור בל** הוא [טור חזקות פורמלי](https://he.wikipedia.org/wiki/%D7%98%D7%95%D7%A8_%D7%97%D7%96%D7%A7%D7%95%D7%AA_%D7%A4%D7%95%D7%A8%D7%9E%D7%9C%D7%99) המשמש לחקר תכונות של [פונקציות אריתמטיות](https://he.wikipedia.org/wiki/%D7%A4%D7%95%D7%A0%D7%A7%D7%A6%D7%99%D7%94_%D7%90%D7%A8%D7%99%D7%AA%D7%9E%D7%98%D7%99%D7%AA). טורי בל הוצגו ופותחו על ידי [אריק טמפל בל](https://he.wikipedia.org/wiki/%D7%90%D7%A8%D7%99%D7%A7_%D7%98%D7%9E%D7%A4%D7%9C_%D7%91%D7%9C).

בהינתן פונקציה אריתמטית $`f`$ ו[ראשוני](https://he.wikipedia.org/wiki/%D7%9E%D7%A1%D7%A4%D7%A8_%D7%A8%D7%90%D7%A9%D7%95%D7%A0%D7%99) $`p`$, מגדירים את טור החזקות הפורמלי $`f_p(x)`$, הנקרא טור בל של $`f`$ מודולו $`p`$:



```math
f_p(x)=\sum_{n=0}^\infty f(p^n)x^n.
```



אפשר להראות ששתי [פונקציות כפליות](https://he.wikipedia.org/wiki/%D7%A4%D7%95%D7%A0%D7%A7%D7%A6%D7%99%D7%94_%D7%9B%D7%A4%D7%9C%D7%99%D7%AA) זהות אם כל טורי בל שלהן שווים; טענה זו נקראת לעיתים **משפט היחידות**: עבור פונקציות כפליות $`f`$ ו-$`g`$ מתקיים $`f=g`$ [אם ורק אם](https://he.wikipedia.org/wiki/%D7%90%D7%9D_%D7%95%D7%A8%D7%A7_%D7%90%D7%9D) $`f_p(x)=g_p(x)`$ לכל ראשוני $`p`$.

אפשר לכפול שני טורים (טענה הנקראת לעיתים **משפט הכפל**): לכל שתי פונקציות אריתמטיות $`f`$ ו-$`g`$, תהי $`h=f*g`$ [קונבולוציית דיריכלה](https://he.wikipedia.org/wiki/%D7%A7%D7%95%D7%A0%D7%91%D7%95%D7%9C%D7%95%D7%A6%D7%99%D7%99%D7%AA_%D7%93%D7%99%D7%A8%D7%99%D7%9B%D7%9C%D7%94) שלהן. אז לכל ראשוני $`p`$



```math
h_p(x)=f_p(x) g_p(x).
```



בפרט, קל מאוד למצוא בעזרת זה את טור בל של ההופכי של פונקציה ביחס לקונבולוציית דיריכלה.

אם $`f`$ [כפלית לחלוטין](%D7%A4%D7%95%D7%A0%D7%A7%D7%A6%D7%99%D7%94%20%D7%9B%D7%A4%D7%9C%D7%99%D7%AA%20%D7%9C%D7%97%D7%9C%D7%95%D7%98%D7%99%D7%9F.md), אז באופן פורמלי



```math
f_p(x)=\frac{1}{1-f(p)x}.
```



## דוגמאות

להלן טורי בל של פונקציות אריתמטיות מוכרות:

- ל[פונקציית מביוס](https://he.wikipedia.org/wiki/%D7%A4%D7%95%D7%A0%D7%A7%D7%A6%D7%99%D7%99%D7%AA_%D7%9E%D7%91%D7%99%D7%95%D7%A1) $`\mu`$: $`\mu_p(x)=1-x`$.
- לריבוע של פונקציית מביוס: $`\mu_p^2(x) = 1+x`$.
- ל[פונקציית אוילר](https://he.wikipedia.org/wiki/%D7%A4%D7%95%D7%A0%D7%A7%D7%A6%D7%99%D7%99%D7%AA_%D7%90%D7%95%D7%99%D7%9C%D7%A8) $`\varphi`$: $`\varphi_p(x)=\frac{1-x}{1-px}`$.
- לאיבר היחידה של קונבולוציית דיריכלה $`\delta`$: $`\delta_p(x)=1`$.
- ל[פונקציית ליוביל](https://he.wikipedia.org/wiki/%D7%A4%D7%95%D7%A0%D7%A7%D7%A6%D7%99%D7%99%D7%AA_%D7%9C%D7%99%D7%95%D7%91%D7%99%D7%9C) $`\lambda`$: $`\lambda_p(x)=\frac{1}{1+x}`$.
- לפונקציית החזקה $`\mathrm{Id}_k(n)=n^k`$, שהיא כפלית לחלוטין: $`(\mathrm{Id}_k)_p(x)=\frac{1}{1-p^kx}`$.
- ל[פונקציית המחלקים](https://he.wikipedia.org/wiki/%D7%A4%D7%95%D7%A0%D7%A7%D7%A6%D7%99%D7%99%D7%AA_%D7%94%D7%9E%D7%97%D7%9C%D7%A7%D7%99%D7%9D) $`\sigma_k`$: $`(\sigma_k)_p(x)=\frac{1}{(1-p^kx)(1-x)}`$.
- לפונקציה הקבועה 1: $`1_p(x) = (1-x)^{-1}`$, כלומר [הטור ההנדסי](https://he.wikipedia.org/wiki/%D7%A1%D7%93%D7%A8%D7%94_%D7%94%D7%A0%D7%93%D7%A1%D7%99%D7%AA).
- אם $`f(n) = 2^{\omega(n)} = \sum_{d|n} \mu^2(d)`$, כאשר $`\omega`$ היא [פונקציית אומגה הראשונית](%D7%A4%D7%95%D7%A0%D7%A7%D7%A6%D7%99%D7%95%D7%AA%20%D7%90%D7%95%D7%9E%D7%92%D7%94%20%D7%A8%D7%90%D7%A9%D7%95%D7%A0%D7%99%D7%95%D7%AA.md), אז $`f_p(x) = \frac{1+x}{1-x}`$.
- נניח ש-$`f`$ כפלית ו-$`g`$ פונקציה אריתמטית כלשהי המקיימת $`f(p^{n+1}) = f(p) f(p^n) - g(p) f(p^{n-1})`$ לכל ראשוני $`p`$ ולכל $`n \geq 1`$. אז $`f_p(x) = \left(1-f(p)x + g(p)x^2\right)^{-1}`$.
- אם $`\mu_k`$ היא פונקציית מביוס מסדר $`k`$, המוגדרת על ידי $`\mu_k(n) = \sum_{d^k|n} \mu_{k-1}\left(\frac{n}{d^k}\right) \mu_{k-1}\left(\frac{n}{d}\right)`$, אז $`(\mu_k)_p(x) = \frac{1-2x^k+x^{k+1} }{1-x}`$.
