# משפט פון שטאודט–קלאוזן

ב[תורת המספרים](https://he.wikipedia.org/wiki/%D7%AA%D7%95%D7%A8%D7%AA_%D7%94%D7%9E%D7%A1%D7%A4%D7%A8%D7%99%D7%9D), **משפט פון שטאודט–קלאוזן** הוא תוצאה שקובעת את ה[חלק השברי](https://he.wikipedia.org/wiki/%D7%97%D7%9C%D7%A7_%D7%A9%D7%91%D7%A8%D7%99) של [מספרי ברנולי](https://he.wikipedia.org/wiki/%D7%9E%D7%A1%D7%A4%D7%A8%D7%99_%D7%91%D7%A8%D7%A0%D7%95%D7%9C%D7%99). הוא התגלה באופן בלתי תלוי על ידי קרל פון שטאודט (1840) ותומאס קלאוזן (1840).

במפורש: אם $`n`$ שלם חיובי, ומוסיפים $`1/p`$ למספר ברנולי $`B_{2n}`$ לכל [ראשוני](https://he.wikipedia.org/wiki/%D7%9E%D7%A1%D7%A4%D7%A8_%D7%A8%D7%90%D7%A9%D7%95%D7%A0%D7%99) $`p`$ שעבורו $`p-1`$ מחלק את $`2n`$, מקבלים מספר שלם:



```math
B_{2n} + \sum_{(p-1)\mid 2n} \frac1p \in \mathbb Z .
```



מכאן מיד מתקבל תיאור של המכנים של מספרי ברנולי $`B_{2n}`$ השונים מאפס: המכנה הוא מכפלת כל הראשוניים $`p`$ שעבורם $`p-1`$ מחלק את $`2n`$. בפרט, המכנים [חופשיים מריבועים](%D7%9E%D7%A1%D7%A4%D7%A8%20%D7%97%D7%95%D7%A4%D7%A9%D7%99%20%D7%9E%D7%A8%D7%99%D7%91%D7%95%D7%A2%D7%99%D7%9D.md) ומתחלקים ב-6 (כי $`p = 2, 3`$ תמיד מופיעים).

המכנים הם

  
6, 30, 42, 30, 66, 2730, 6, 510, 798, 330, 138, 2730, 6, 870, 14322, 510, 6, 1919190, 6, 13530, ... (סדרה [A002445](https://oeis.org/A002445) ב-OEIS).

סדרת השלמים $`B_{2n} + \sum_{(p-1)\mid 2n} \frac1p`$ היא

  
1, 1, 1, 1, 1, 1, 2, −6, 56, −528, 6193, −86579, 1425518, −27298230, ... (סדרה [A000146](https://oeis.org/A000146) ב-OEIS).

(בדקנו בחישוב את שתי הרשימות.)

### דוגמה: $`B_{12}`$

$`B_{12} = -\tfrac{691}{2730}`$. הראשוניים שעבורם $`p - 1 \mid 12`$ הם $`2, 3, 5, 7, 13`$, ומכפלתם $`2730`$ – בדיוק המכנה. והסכום:



```math
\frac12 + \frac13 + \frac15 + \frac17 + \frac1{13} = \frac{1365 + 910 + 546 + 390 + 210}{2730} = \frac{3421}{2730},
```

 ולכן $`B_{12} + \tfrac{3421}{2730} = \tfrac{2730}{2730} = 1`$. (המונה 691 של $`B_{12}`$ הוא ה-691 של [קונגרואנציית רמנוג'אן](%D7%A4%D7%95%D7%A0%D7%A7%D7%A6%D7%99%D7%99%D7%AA%20%D7%94%D7%98%D7%90%D7%95%20%D7%A9%D7%9C%20%D7%A8%D7%9E%D7%A0%D7%95%D7%92%27%D7%90%D7%9F.md) $`\tau(n) \equiv \sigma_{11}(n) \pmod{691}`$.)

## הוכחה

הוכחה של משפט פון שטאודט–קלאוזן נובעת מנוסחה מפורשת למספרי ברנולי:



```math
B_{2n}=\sum_{j=0}^{2n}{\frac{1}{j+1} }\sum_{m=0}^{j}{(-1)^{m}{j\choose m}m^{2n} }
```

 וכמסקנה:



```math
B_{2n}=\sum_{j=0}^{2n}{\frac{j!}{j+1} }(-1)^jS(2n,j)
```

 כאשר $`S(n,j)`$ הם [מספרי סטירלינג](https://he.wikipedia.org/wiki/%D7%9E%D7%A1%D7%A4%D7%A8%D7%99_%D7%A1%D7%98%D7%99%D7%A8%D7%9C%D7%99%D7%A0%D7%92) מהסוג השני.

נזדקק גם ללמות הבאות. יהי $`p`$ ראשוני; אז:

**1**. אם $`p - 1`$ מחלק את $`2n`$, אז

  
$`\sum_{m=0}^{p-1}{(-1)^m{p-1\choose m} m^{2n} }\equiv{-1}\pmod p.`$

**2**. אם $`p - 1`$ אינו מחלק את $`2n`$, אז

  
$`\sum_{m=0}^{p-1}{(-1)^m{p-1\choose m} m^{2n} }\equiv0\pmod p.`$

**הוכחה של 1 ו-2.** לפי [המשפט הקטן של פרמה](https://he.wikipedia.org/wiki/%D7%94%D7%9E%D7%A9%D7%A4%D7%98_%D7%94%D7%A7%D7%98%D7%9F_%D7%A9%D7%9C_%D7%A4%D7%A8%D7%9E%D7%94), $`m^{p-1} \equiv 1 \pmod{p}`$ לכל $`m = 1, 2, \ldots, p - 1`$.

אם $`p - 1`$ מחלק את $`2n`$, אז $`m^{2n} \equiv 1 \pmod{p}`$ לכל $`m = 1, \ldots, p - 1`$, ולכן

  
$`\sum_{m=1}^{p-1} (-1)^m \binom{p-1}{m} m^{2n} \equiv \sum_{m=1}^{p-1} (-1)^m \binom{p-1}{m} = (1 - 1)^{p-1} - 1 = -1 \pmod{p},`$

ומכאן (1).

אם $`p - 1`$ אינו מחלק את $`2n`$, אז לפי משפט פרמה $`m^{2n} \equiv m^{2n-(p-1)} \pmod{p}`$. נסמן $`w = \lfloor 2n / (p - 1) \rfloor`$; אחרי איטרציה,

  
$`m^{2n} \equiv m^{2n-w(p-1)} \pmod{p}`$

לכל $`m = 1, \ldots, p - 1`$, ו-$`0 \lt 2n - w(p - 1) \lt p - 1`$. לכן

  
$`\sum_{m=0}^{p-1} (-1)^m \binom{p-1}{m} m^{2n} \equiv \sum_{m=0}^{p-1} (-1)^m \binom{p-1}{m} m^{2n-w(p-1)} \pmod{p}.`$

הסכום בצד ימין הוא $`(-1)^{p-1}(p-1)!\,S(k, p-1)`$ עם $`k = 2n - w(p-1) \lt p - 1`$, ולמה (2) נובעת מכך ש-$`S(k,j) = 0`$ כאשר $`j \gt k`$.

**3**. קל להראות שאם $`a, b \gt 2`$, אז $`ab`$ מחלק את $`(ab - 1)!`$.

**4**. מספרי סטירלינג מהסוג השני הם שלמים.

עכשיו אפשר להוכיח את המשפט. בנוסחה $`B_{2n} = \sum_j \frac{j!}{j+1}(-1)^jS(2n,j)`$:

- אם $`j + 1`$ פריק ו-$`j \gt 3`$, אז לפי (3) $`j + 1`$ מחלק את $`j!`$, והמחובר שלם (לפי (4)).
- עבור $`j = 3`$ ($`j + 1 = 4`$):

  
$`\sum_{m=0}^{3} (-1)^m \binom{3}{m} m^{2n} = 3 \cdot 2^{2n} - 3^{2n} - 3 \equiv 0 \pmod{4},`$

כי $`3\cdot 4^n \equiv 0`$ ו-$`9^n \equiv 1 \pmod 4`$.

- אם $`j + 1 = p`$ ראשוני, אז לפי (1) ו-(2) המחובר הוא $`-\tfrac1p`$ ועוד שלם כש-$`p - 1 \mid 2n`$, ושלם אחרת.

לכן



```math
B_{2n} = I_n - \sum_{(p-1)\mid 2n} \frac{1}{p},
```

 כאשר $`I_n`$ שלם, כנדרש.[^1]
