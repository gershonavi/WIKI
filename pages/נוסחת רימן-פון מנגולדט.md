# נוסחת רימן-פון מנגולדט

ב[מתמטיקה](https://he.wikipedia.org/wiki/%D7%9E%D7%AA%D7%9E%D7%98%D7%99%D7%A7%D7%94), **נוסחת רימן-פון מנגולדט** (ב[אנגלית](https://he.wikipedia.org/wiki/%D7%90%D7%A0%D7%92%D7%9C%D7%99%D7%AA): Riemann–von Mangoldt formula), הקרויה על שם [ברנהרד רימן](https://he.wikipedia.org/wiki/%D7%91%D7%A8%D7%A0%D7%94%D7%A8%D7%93_%D7%A8%D7%99%D7%9E%D7%9F) והנס פון מנגולדט, מתארת את התפלגות האפסים של [פונקציית זטא של רימן](https://he.wikipedia.org/wiki/%D7%A4%D7%95%D7%A0%D7%A7%D7%A6%D7%99%D7%99%D7%AA_%D7%96%D7%98%D7%90_%D7%A9%D7%9C_%D7%A8%D7%99%D7%9E%D7%9F).

לפי הנוסחה, המספר $`N(T)`$ של אפסי פונקציית זטא שהחלק המדומה שלהם גדול מ-0 וקטן או שווה ל-$`T`$ מקיים



```math
N(T)=\frac{T}{2\pi}\log{\frac{T}{2\pi}}-\frac{T}{2\pi}+O(\log{T}).
```



את הנוסחה ניסח רימן במאמרו הנודע "[על מספר הראשוניים מתחת לגודל נתון](https://he.wikipedia.org/wiki/%D7%A2%D7%9C_%D7%9E%D7%A1%D7%A4%D7%A8_%D7%94%D7%A8%D7%90%D7%A9%D7%95%D7%A0%D7%99%D7%99%D7%9D_%D7%9E%D7%AA%D7%97%D7%AA_%D7%9C%D7%92%D7%95%D7%93%D7%9C_%D7%A0%D7%AA%D7%95%D7%9F)" (1859), ופון מנגולדט הוכיח אותה לבסוף ב-1905.

בקלונד (Backlund) נתן צורה מפורשת לשגיאה, לכל $`T > 2`$:



```math
\left\vert{ N(T) - \left({\frac{T}{2\pi}\log{\frac{T}{2\pi}}-\frac{T}{2\pi} } - \frac{7}{8}\right)}\right\vert < 0.137 \log T + 0.443 \log\log T + 4.350 .
```

 מאז שופרה תוצאה זו, בין השאר על ידי חסנעליזדה, שן ו-וונג[^1]:



```math
\left|N(T)-\left(\frac T{2\pi}\log\frac T{2\pi}-\frac T{2\pi}\right)\right|\leq0.1038\log T+0.2573\log\log T+9.3675
```

 לכל $`T \ge e`$.

בהנחת [השערת לינדלף](%D7%94%D7%A9%D7%A2%D7%A8%D7%AA%20%D7%9C%D7%99%D7%A0%D7%93%D7%9C%D7%A3.md) או [השערת רימן](https://he.wikipedia.org/wiki/%D7%94%D7%A9%D7%A2%D7%A8%D7%AA_%D7%A8%D7%99%D7%9E%D7%9F), אפשר לשפר את איבר השגיאה ל-$`o(\log{T})`$ ול-$`O(\log{T}/\log{\log{T}})`$, בהתאמה[^2].

נוסחה מדויקת יותר נתנו אנטולי קרצובה ומ. א. קורולב[^3].

באופן דומה, לכל [קרקטר דיריכלה](https://he.wikipedia.org/wiki/%D7%A7%D7%A8%D7%A7%D7%98%D7%A8_%D7%93%D7%99%D7%A8%D7%99%D7%9B%D7%9C%D7%94) פרימיטיבי $`\chi`$ מודולו $`q`$ מתקיים



```math
N(T,\chi)=\frac{T}{\pi}\log{\frac{qT}{2\pi e}}+O(\log{qT}),
```

 כאשר $`N(T,\chi)`$ הוא מספר האפסים של $`L(s,\chi)`$ שהחלק המדומה שלהם בין $`-T`$ ל-$`T`$ (ראו [פונקציית L של דיריכלה](https://he.wikipedia.org/wiki/%D7%A4%D7%95%D7%A0%D7%A7%D7%A6%D7%99%D7%99%D7%AA_L_%D7%A9%D7%9C_%D7%93%D7%99%D7%A8%D7%99%D7%9B%D7%9C%D7%94)).
