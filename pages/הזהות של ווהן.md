# הזהות של ווהן

ב[מתמטיקה](https://he.wikipedia.org/wiki/%D7%9E%D7%AA%D7%9E%D7%98%D7%99%D7%A7%D7%94), ובפרט ב[תורת המספרים האנליטית](https://he.wikipedia.org/wiki/%D7%AA%D7%95%D7%A8%D7%AA_%D7%94%D7%9E%D7%A1%D7%A4%D7%A8%D7%99%D7%9D_%D7%94%D7%90%D7%A0%D7%9C%D7%99%D7%98%D7%99%D7%AA.md), **הזהות של ווהן** היא [זהות](https://he.wikipedia.org/wiki/%D7%96%D7%94%D7%95%D7%AA_%28%D7%9E%D7%AA%D7%9E%D7%98%D7%99%D7%A7%D7%94%29) שמצא רוברט צ'ארלס ווהן בשנת 1977,[^1] ושבעזרתה אפשר לפשט את עבודתו של [וינוגרדוב](https://he.wikipedia.org/wiki/%D7%90%D7%99%D7%95%D7%95%D7%90%D7%9F_%D7%95%D7%99%D7%A0%D7%95%D7%92%D7%A8%D7%93%D7%95%D7%91) על סכומים טריגונומטריים. הזהות משמשת להערכת פונקציות סכומיות מהצורה



```math
\sum_{n \leq N} f(n)\Lambda(n),
```



כאשר $`f`$ היא [פונקציה אריתמטית](https://he.wikipedia.org/wiki/%D7%A4%D7%95%D7%A0%D7%A7%D7%A6%D7%99%D7%94_%D7%90%D7%A8%D7%99%D7%AA%D7%9E%D7%98%D7%99%D7%AA) כלשהי של המספרים הטבעיים $`n`$, שערכיה ביישומים הם לעיתים קרובות [שורשי יחידה](https://he.wikipedia.org/wiki/%D7%A9%D7%95%D7%A8%D7%A9_%D7%99%D7%97%D7%99%D7%93%D7%94), ו-$`\Lambda`$ היא [פונקציית פון מנגולד](https://he.wikipedia.org/wiki/%D7%A4%D7%95%D7%A0%D7%A7%D7%A6%D7%99%D7%99%D7%AA_%D7%A4%D7%95%D7%9F_%D7%9E%D7%A0%D7%92%D7%95%D7%9C%D7%93).

## אופן השימוש בשיטה

המוטיבציה לבניית הזהות מתוארת בקצרה בתחילת פרק 24 בספרו של [דבנפורט](https://he.wikipedia.org/wiki/%D7%94%D7%A8%D7%95%D7%9C%D7%93_%D7%93%D7%91%D7%A0%D7%A4%D7%95%D7%A8%D7%98.md).[^2] בונים ארבעה סכומים נפרדים, על סמך פירוק ה[נגזרת הלוגריתמית](https://he.wikipedia.org/wiki/%D7%A0%D7%92%D7%96%D7%A8%D7%AA_%D7%9C%D7%95%D7%92%D7%A8%D7%99%D7%AA%D7%9E%D7%99%D7%AA) של [פונקציית זטא של רימן](https://he.wikipedia.org/wiki/%D7%A4%D7%95%D7%A0%D7%A7%D7%A6%D7%99%D7%99%D7%AA_%D7%96%D7%98%D7%90_%D7%A9%D7%9C_%D7%A8%D7%99%D7%9E%D7%9F) באמצעות [טורי דיריכלה](https://he.wikipedia.org/wiki/%D7%98%D7%95%D7%A8_%D7%93%D7%99%D7%A8%D7%99%D7%9B%D7%9C%D7%94) חלקיים, הקטועים בגבולות העליונים $`U`$ ו-$`V`$. במדויק, מגדירים



```math
F(s) = \sum_{m \leq U} \Lambda(m) m^{-s}, \qquad G(s) = \sum_{d \leq V} \mu(d) d^{-s},
```



כאשר $`\mu`$ היא [פונקציית מביוס](https://he.wikipedia.org/wiki/%D7%A4%D7%95%D7%A0%D7%A7%D7%A6%D7%99%D7%99%D7%AA_%D7%9E%D7%91%D7%99%D7%95%D7%A1), ומקבלים את הזהות המדויקת



```math
-\frac{\zeta'(s)}{\zeta(s)} = F(s) - \zeta(s) F(s) G(s) - \zeta'(s) G(s) + \left(-\frac{\zeta'(s)}{\zeta(s)} - F(s)\right) (1-\zeta(s) G(s)).
```



מפיתוח זה נובע שאפשר לכתוב



```math
\Lambda(n) = a_1(n) + a_2(n) + a_3(n) + a_4(n),
```



כאשר



```math
\begin{align}
a_1(n) & = \begin{cases} \Lambda(n), & n \leq U, \\ 0, & n > U, \end{cases} \\
a_2(n) & = - \sum_{\stackrel{mdr = n}{m \leq U,\ d \leq V}} \Lambda(m) \mu(d), \\
a_3(n) & = \sum_{\stackrel{hd=n}{d \leq V}} \mu(d) \log h, \\
a_4(n) & = -\sum_{\stackrel{mk=n}{m > U,\ k > 1}} \Lambda(m) \left(\sum_{\stackrel{d|k}{d \leq V}} \mu(d)\right).
\end{align}
```



מגדירים את הפונקציות הסכומיות המתאימות, עבור $`1 \leq i \leq 4`$,



```math
S_i(N) = \sum_{n \leq N} f(n) a_i(n),
```



כך ש-



```math
\sum_{n \leq N} f(n) \Lambda(n) = S_1(N) + S_2(N) + S_3(N) + S_4(N).
```



לבסוף, אחרי הערכות טכניות ועדינות של הסכומים האלה, מתקבלת הצורה הבאה של הזהות של ווהן, בהנחה ש-$`|f(n)| \leq 1`$ לכל $`n`$, $`U,V \geq 2`$ ו-$`UV \leq N`$:



```math
\sum_{n \leq N} f(n) \Lambda(n) \ll U + (\log N) \sum_{t\leq UV}\left(\max_{w} \left|\sum_{w \leq r \leq N/t} f(rt)\right|\right) + \sqrt{N} (\log N)^3 \max_{U \leq M \leq N/V} \max_{V \leq j \leq N/M}\left(\sum_{V < k \leq N/M} \left| \sum_{\stackrel{M < m \leq 2M}{m \leq N/k,\ m \leq N/j}} f(mj) \overline{f(mk)}\right|\right)^{1/2}.
```



בחלק מהמקרים אפשר לקבל הערכות חדות יותר אם מטפלים ברכיב $`S_2`$ בזהירות רבה יותר, ומפצלים אותו לסכום על $`t \leq U`$ ולסכום על $`U < t \leq UV`$. הבחירה האופטימלית של $`U`$ ו-$`V`$ כפונקציות של $`N`$ תלויה ביישום.

## יישומים

- הזהות של ווהן שימשה לפישוט ההוכחה של [משפט בומביירי-וינוגרדוב](https://he.wikipedia.org/wiki/%D7%9E%D7%A9%D7%A4%D7%98_%D7%91%D7%95%D7%9E%D7%91%D7%99%D7%99%D7%A8%D7%99-%D7%95%D7%99%D7%A0%D7%95%D7%92%D7%A8%D7%93%D7%95%D7%91.md) ולחקר סכומי קומר.
- בפרק 25 בספרו של דבנפורט הזהות משמשת להערכת [סכום אקספוננציאלי](https://he.wikipedia.org/wiki/%D7%A1%D7%9B%D7%95%D7%9D_%D7%90%D7%A7%D7%A1%D7%A4%D7%95%D7%A0%D7%A0%D7%A6%D7%99%D7%90%D7%9C%D7%99.md) חשוב של וינוגרדוב, הקשור לראשוניים:



```math
S(\alpha) = \sum_{n \leq N} \Lambda(n) e(n\alpha),
```



  
כאשר $`e(x) = e^{2\pi i x}`$. אם $`\alpha`$ ממשי ו-$`a/q`$ קירוב רציונלי שלו המקיים $`\left| \alpha - a/q \right| \leq 1/q^2`$ ו-$`\gcd(a, q) = 1`$, אז

$`S(\alpha) \ll \left(\frac{N}{\sqrt{q}} + N^{4/5} + \sqrt{Nq}\right) (\log N)^4.`$

ההערכה נובעת מהזהות של ווהן דרך הטענה

$`S(\alpha) \ll \left(UV + q + \frac{N}{\sqrt{U}} + \frac{N}{\sqrt{V}} + \frac{N}{\sqrt{q}} + \sqrt{Nq}\right) (\log(qN))^4,`$

ובחירת $`U = V = N^{2/5}`$ במקרים הלא טריוויאליים, שבהם $`q \leq N`$.

- בפרק 26 בספרו של דבנפורט השיטה משמשת להערכת סכומים אקספוננציאליים של שלושה ראשוניים, בדרך להוכחת [משפט וינוגרדוב](https://he.wikipedia.org/wiki/%D7%94%D7%A9%D7%A2%D7%A8%D7%AA_%D7%92%D7%95%D7%9C%D7%93%D7%91%D7%9A).
- הזהות שימשה גם בעבודות נוספות, למשל בהוכחה של [טרנס טאו](https://he.wikipedia.org/wiki/%D7%98%D7%A8%D7%A0%D7%A1_%D7%98%D7%90%D7%95) שכל שלם גדול מ-1 הוא סכום של לכל היותר חמישה ראשוניים,[^3] בעבודתו של קונרי על אפסי פונקציית זטא על הישר הקריטי,[^4] בעבודה של מונטגומרי וּווהן על התפלגות מספרים [חופשיים מריבועים](https://he.wikipedia.org/wiki/%D7%9E%D7%A1%D7%A4%D7%A8_%D7%97%D7%95%D7%A4%D7%A9%D7%99_%D7%9E%D7%A8%D7%99%D7%91%D7%95%D7%A2%D7%99%D7%9D),[^5] ובעבודה של הית'-בראון ופטרסון על סכומי קומר.[^6]
