# שיטת צ'קרוואלה

**שיטת צ'קרוואלה** ([סנסקריט](https://he.wikipedia.org/wiki/%D7%A1%D7%A0%D7%A1%D7%A7%D7%A8%D7%99%D7%98): चक्रवाल विधि) היא [אלגוריתם](https://he.wikipedia.org/wiki/%D7%90%D7%9C%D7%92%D7%95%D7%A8%D7%99%D7%AA%D7%9D) מחזורי לפתרון [משוואות ריבועיות](https://he.wikipedia.org/wiki/%D7%9E%D7%A9%D7%95%D7%95%D7%90%D7%94_%D7%A8%D7%99%D7%91%D7%95%D7%A2%D7%99%D7%AA) לא מסוימות, ובהן [משוואת פל](https://he.wikipedia.org/wiki/%D7%9E%D7%A9%D7%95%D7%95%D7%90%D7%AA_%D7%A4%D7%9C). בדרך כלל מייחסים אותה לבהסקרה השני (בערך 1114–1185 לספירה), אם כי יש המייחסים אותה לג'איאדווה (בערך 950–1000 לספירה). ג'איאדווה הצביע על כך שאפשר להכליל את הגישה של ברהמגופטה לפתרון משוואות מהסוג הזה, ותיאר את השיטה הכללית, שבהסקרה השני שכלל אחר כך בחיבורו *ביג'גניטה*. הוא קרא לה שיטת צ'קרוואלה: *צ'קרה* פירושו "גלגל" בסנסקריט, רמז לאופי המחזורי של האלגוריתם. לפי ק.-או. סלניוס, שום הישג אירופי בתקופתו של בהסקרה, וגם הרבה אחריה, לא הגיע לגובה המופלא של המורכבות המתמטית שלה.

השיטה נקראת גם **השיטה המחזורית**, ויש בה עקבות של [אינדוקציה מתמטית](https://he.wikipedia.org/wiki/%D7%90%D7%99%D7%A0%D7%93%D7%95%D7%A7%D7%A6%D7%99%D7%94_%D7%9E%D7%AA%D7%9E%D7%98%D7%99%D7%AA).[^1]

## היסטוריה

*צ'קרה* בסנסקריט פירושו מעגל. לפי אגדה עממית, צ'קרוואלה הוא רכס הרים מיתולוגי שמקיף את הארץ כמו חומה, ושאור וחושך אינם מגבילים אותו.

ברהמגופטה חקר ב-628 לספירה משוואות ריבועיות לא מסוימות, ובהן משוואת פל



```math
x^2 = Ny^2 + 1,
```

 עבור השלמים המינימליים $`x`$ ו-$`y`$. ברהמגופטה ידע לפתור אותה עבור כמה ערכים של $`N`$, אבל לא לכולם.

ג'איאדווה ובהסקרה הציעו את הפתרון השלם הראשון למשוואה, ובעזרת שיטת צ'קרוואלה מצאו עבור $`x^2 = 61y^2 + 1`$ את הפתרון



```math
x = 1\,766\,319\,049, \qquad y = 226\,153\,980.
```

 המקרה הזה היה ידוע בקושי שלו, ובאירופה פתר אותו לראשונה ויליאם בראונקר ב-1657–1658, בתגובה לאתגר של [פרמה](https://he.wikipedia.org/wiki/%D7%A4%D7%99%D7%99%D7%A8_%D7%93%D7%94_%D7%A4%D7%A8%D7%9E%D7%94), בעזרת [שברים משולבים](https://he.wikipedia.org/wiki/%D7%A9%D7%91%D7%A8_%D7%9E%D7%A9%D7%95%D7%9C%D7%91). שיטה לבעיה הכללית תיאר לראשונה באופן מלא וקפדני [לגראנז'](https://he.wikipedia.org/wiki/%D7%96%27%D7%95%D7%96%D7%A3-%D7%9C%D7%95%D7%90%D7%99_%D7%9C%D7%92%D7%A8%D7%90%D7%A0%D7%96%27) ב-1766. השיטה של לגראנז' דורשת לחשב 10 איטרציות (ולא 21, כפי שנטען לעתים קרובות, כי 10 איטרציות נותנות את הפתרון $`29718^2 = 61\cdot3805^2 - 1`$, ואפשר להעלות אותו בריבוע כדי לחסוך את 11 האיטרציות הנותרות) של המנות המתקרבות של [השבר המשולב הפשוט](https://he.wikipedia.org/wiki/%D7%A9%D7%91%D7%A8_%D7%9E%D7%A9%D7%95%D7%9C%D7%91) של $`\sqrt{61}`$, בעוד ששיטת צ'קרוואלה פשוטה בהרבה. (בדקנו ש-$`29718^2 - 61\cdot3805^2 = -1`$.)

סלניוס כתב בהערכתו את השיטה שהיא אלגוריתם קירוב מיטבי באורך מינימלי, שבזכות כמה תכונות מינימליות מגיע לפתרונות הטובים ביותר במאמץ מינימלי ותוך הימנעות ממספרים גדולים, ושהיא הקדימה את השיטות האירופיות ביותר מאלף שנה.[^2] הרמן הנקל כינה את שיטת צ'קרוואלה "הדבר הטוב ביותר שהושג בתורת המספרים לפני לגראנז'".[^3]

## השיטה

מזהות ברהמגופטה רואים שלכל $`N`$,



```math
(x_1x_2 + Ny_1y_2)^2 - N(x_1y_2 + x_2y_1)^2 = (x_1^2 - Ny_1^2)(x_2^2 - Ny_2^2).
```

 (זו בדיוק כפליות הנורמה: $`(x_1 + y_1\sqrt N)(x_2 + y_2\sqrt N) = (x_1x_2 + Ny_1y_2) + (x_1y_2 + x_2y_1)\sqrt N`$.) עבור המשוואה $`x^2 - Ny^2 = k`$, הזהות מאפשרת "הרכבה" (*סמאסה*) של שתי שלשות פתרון $`(x_1, y_1, k_1)`$ ו-$`(x_2, y_2, k_2)`$ לשלשה חדשה



```math
(x_1x_2 + Ny_1y_2,\ x_1y_2 + x_2y_1,\ k_1k_2).
```



הרעיון המרכזי בשיטה הכללית הוא שאפשר להרכיב כל שלשה $`(a, b, k)`$ (כלומר, כזו שמקיימת $`a^2 - Nb^2 = k`$) עם השלשה הטריוויאלית $`(m, 1, m^2 - N)`$, ולקבל את השלשה החדשה $`(am + Nb,\ a + bm,\ k(m^2 - N))`$ לכל $`m`$. אם התחלנו בשלשה עם $`\gcd(a, b) = 1`$, אפשר לחלק אותה ב-$`k`$ (זו [הלמה של בהסקרה](%D7%94%D7%9C%D7%9E%D7%94%20%D7%A9%D7%9C%20%D7%91%D7%94%D7%A1%D7%A7%D7%A8%D7%94.md)):



```math
a^2 - Nb^2 = k \ \Rightarrow\ \left(\frac{am + Nb}k\right)^2 - N\left(\frac{a + bm}k\right)^2 = \frac{m^2 - N}k.
```

 כיוון שהסימנים בתוך הריבועים אינם משנים, אפשר לבצע את ההחלפות



```math
a \leftarrow \frac{am + Nb}{|k|}, \qquad b \leftarrow \frac{a + bm}{|k|}, \qquad k \leftarrow \frac{m^2 - N}k.
```

 כשבוחרים מספר שלם חיובי $`m`$ כך ש-$`(a + bm)/k`$ שלם, גם שני המספרים האחרים בשלשה שלמים. מבין ה-$`m`$-ים האלה, השיטה בוחרת אחד שממזער את הערך המוחלט של $`m^2 - N`$, ולכן גם של $`(m^2 - N)/k`$. אז מפעילים את ההחלפות עם הערך שנבחר של $`m`$, ומתקבלת שלשה חדשה $`(a, b, k)`$. חוזרים על התהליך עד שמגיעים לשלשה עם $`k = 1`$. השיטה תמיד מסתיימת בפתרון, כפי שלגראנז' הוכיח ב-1768.[^4] אפשר גם לעצור כבר כש-$`k = \pm1, \pm2`$ או $`\pm4`$, כי השיטה של ברהמגופטה (להלן) נותנת פתרון במקרים האלה.

## שיטת ההרכבה של ברהמגופטה

ב-628 לספירה גילה ברהמגופטה דרך כללית למצוא $`x`$ ו-$`y`$ של $`x^2 = Ny^2 + 1`$, בהינתן $`a^2 = Nb^2 + k`$, כאשר $`k = \pm1, \pm2`$ או $`\pm4`$.

=== k = ±1 === נרכיב את השלשה $`(a, b, k)`$ עם עצמה בעזרת זהות ברהמגופטה:



```math
(a^2 + Nb^2)^2 - N(2ab)^2 = k^2 \ \Rightarrow\ (2a^2 - k)^2 - N(2ab)^2 = k^2.
```

 את השלשה החדשה אפשר לכתוב כ-$`(2a^2 - k, 2ab, k^2)`$. הצבת $`k = -1`$ נותנת פתרון:



```math
x = 2a^2 + 1, \qquad y = 2ab.
```

 עבור $`k = 1`$, $`(a, b)`$ המקורי כבר היה פתרון; הצבת $`k = 1`$ נותנת פתרון שני:



```math
x = 2a^2 - 1, \qquad y = 2ab.
```



=== k = ±2 === שוב מהמשוואה:



```math
(2a^2 - k)^2 - N(2ab)^2 = k^2 \ \Rightarrow\ \left(\frac{2a^2 - k}k\right)^2 - N\left(\frac{2ab}k\right)^2 = 1.
```

 הצבת $`k = 2`$ נותנת $`x = a^2 - 1, y = ab`$, והצבת $`k = -2`$ נותנת $`x = a^2 + 1, y = ab`$.

=== k = 4 === הצבת $`k = 4`$ במשוואה $`\left(\frac{2a^2 - k}k\right)^2 - N\left(\frac{2ab}k\right)^2 = 1`$ נותנת את השלשה $`\left(\frac{a^2 - 2}2, \frac{ab}2, 1\right)`$, שהיא פתרון שלם אם $`a`$ זוגי:



```math
x = \frac{a^2 - 2}2, \qquad y = \frac{ab}2.
```

 אם $`a`$ אי-זוגי, מתחילים במשוואות $`\left(\frac a2\right)^2 - N\left(\frac b2\right)^2 = 1`$ ו-$`\left(\frac{2a^2 - 4}4\right)^2 - N\left(\frac{2ab}4\right)^2 = 1`$, כלומר בשלשות $`\left(\frac a2, \frac b2, 1\right)`$ ו-$`\left(\frac{a^2 - 2}2, \frac{ab}2, 1\right)`$. הרכבתן נותנת



```math
\left(\frac a2(a^2 - 3)\right)^2 - N\left(\frac b2(a^2 - 1)\right)^2 = 1,
```

 ולכן כש-$`a`$ אי-זוגי:



```math
x = \frac a2(a^2 - 3), \qquad y = \frac b2(a^2 - 1).
```

 (למשל עבור $`N = 5`$: $`3^2 - 5\cdot1^2 = 4`$, ו-$`x = \frac32\cdot6 = 9`$, $`y = \frac12\cdot8 = 4`$; אכן $`81 - 80 = 1`$.)

=== k = −4 === כאשר $`k = -4`$, מתקיים $`\left(\frac a2\right)^2 - N\left(\frac b2\right)^2 = -1`$. הרכבה עם עצמה נותנת



```math
\left(\frac{a^2 + Nb^2}4\right)^2 - N\left(\frac{ab}2\right)^2 = 1 \ \Rightarrow\ \left(\frac{a^2 + 2}2\right)^2 - N\left(\frac{ab}2\right)^2 = 1.
```

 הרכבה נוספת עם עצמה נותנת



```math
\left(\frac{a^4 + 4a^2 + 2}2\right)^2 - N\left(\frac{ab(a^2 + 2)}2\right)^2 = 1.
```

 לבסוף, הרכבה של השלשות $`\left(\frac{a^2 + 2}2, \frac{ab}2, 1\right)`$ ו-$`\left(\frac{a^4 + 4a^2 + 2}2, \frac{ab(a^2 + 2)}2, 1\right)`$ נותנת את הפתרונות



```math
x = \frac{(a^2 + 2)\left[(a^2 + 1)(a^2 + 3) - 2\right]}2, \qquad y = \frac{ab(a^2 + 3)(a^2 + 1)}2.
```

 [^5] (הערה: $`k = -4`$ שימושי למציאת פתרון של משוואת פל, אבל זה לא תמיד הזוג השלם הקטן ביותר. למשל $`36^2 - 52\cdot5^2 = -4`$, והנוסחה נותנת $`x = 1093435849`$, $`y = 151632270`$ – פתרון נכון, אבל גם $`x = 649, y = 90`$ פותר את $`x^2 - 52y^2 = 1`$.)

## דוגמאות

=== n = 61 === המקרה $`n = 61`$ (מציאת פתרון שלם של $`a^2 - 61b^2 = 1`$), שפרמה הציב כאתגר מאות שנים מאוחר יותר, הופיע אצל בהסקרה כדוגמה.[^6]

מתחילים בפתרון כלשהו של $`a^2 - 61b^2 = k`$. כאן אפשר לבחור $`b = 1`$, וכיוון ש-$`8^2 - 61\cdot1^2 = 3`$, יש לנו את השלשה $`(a, b, k) = (8, 1, 3)`$. הרכבה עם $`(m, 1, m^2 - 61)`$ וחלוקה ב-3 (הלמה של בהסקרה) נותנות



```math
\left(\frac{8m + 61}3, \frac{8 + m}3, \frac{m^2 - 61}3\right).
```

 כדי ש-3 יחלק את $`8 + m`$ ו-$`|m^2 - 61|`$ יהיה מינימלי, בוחרים $`m = 7`$, ומקבלים את השלשה $`(39, 5, -4)`$.

**מסלול ברהמגופטה.** עכשיו $`k = -4`$, ואפשר להפעיל ישירות את הנוסחה של ברהמגופטה עם $`a = 39, b = 5`$:



```math
x = \frac{(39^2 + 2)\left[(39^2 + 1)(39^2 + 3) - 2\right]}2 = 1766319049, \qquad y = \frac{39\cdot5\cdot(39^2 + 3)(39^2 + 1)}2 = 226153980.
```

 זה הפתרון השלם המינימלי.

**המסלול המחזורי המלא.** אם ממשיכים בשיטת צ'קרוואלה עד $`k = 1`$, מקבלים (בחישוב שלנו) את 13 הצעדים:

| צעד | $`m`$ | $`a`$        | $`b`$       | $`k`$ |
|-----|-----|------------|-----------|-----|
| 0   | –   | 8          | 1         | 3   |
| 1   | 7   | 39         | 5         | −4  |
| 2   | 9   | 164        | 21        | −5  |
| 3   | 6   | 453        | 58        | 5   |
| 4   | 9   | 1523       | 195       | 4   |
| 5   | 7   | 5639       | 722       | −3  |
| 6   | 8   | 29718      | 3805      | −1  |
| 7   | 8   | 469849     | 60158     | −3  |
| 8   | 7   | 2319527    | 296985    | 4   |
| 9   | 9   | 9747957    | 1248098   | 5   |
| 10  | 6   | 26924344   | 3447309   | −5  |
| 11  | 9   | 90520989   | 11590025  | −4  |
| 12  | 7   | 335159612  | 42912791  | 3   |
| 13  | 8   | 1766319049 | 226153980 | 1   |

בצעד 6 מופיע $`k = -1`$, כלומר $`29718^2 - 61\cdot3805^2 = -1`$, ושם אפשר כבר לעצור ולהשתמש בנוסחה $`x = 2a^2 + 1`$, $`y = 2ab`$, שנותנת שוב את אותו פתרון. שימו לב לסימטריה של הטבלה: ערכי $`|k|`$ ו-$`m`$ חוזרים בסדר הפוך סביב האמצע – תכונה מוכרת של המחזור של השבר המשולב של $`\sqrt{61}`$.[^7]

=== n = 67 === נניח שרוצים לפתור $`x^2 - 67y^2 = 1`$.[^8]

מתחילים בפתרון כלשהו של $`a^2 - 67b^2 = k`$; כאן נבחר $`b = 1`$, ונקבל $`8^2 - 67\cdot1^2 = -3`$. בכל צעד מוצאים $`m \gt 0`$ כך ש-$`k`$ מחלק את $`a + bm`$ ו-$`|m^2 - 67|`$ מינימלי. אז מעדכנים את $`a, b, k`$ ל-$`\frac{am + Nb}{|k|}, \frac{a + bm}{|k|}`$ ו-$`\frac{m^2 - N}k`$ בהתאמה.

איטרציה ראשונה  

יש לנו $`(a, b, k) = (8, 1, -3)`$. רוצים $`m`$ חיובי כך ש-3 מחלק את $`8 + m`$, ו-$`|m^2 - 67|`$ מינימלי. התנאי הראשון אומר ש-$`m`$ מהצורה $`3t + 1`$ (כלומר 1, 4, 7, 10, ...), ומבין אלה המינימום מתקבל ב-$`m = 7`$. ההחלפה נותנת $`a = (8\cdot7 + 67\cdot1)/3 = 41`$, $`b = (8 + 1\cdot7)/3 = 5`$, $`k = (7^2 - 67)/(-3) = 6`$, כלומר הפתרון החדש



```math
41^2 - 67\cdot5^2 = 6.
```



איטרציה שנייה  

עכשיו $`(a, b, k) = (41, 5, 6)`$. רוצים ש-6 יחלק את $`41 + 5m`$, ולכן $`m`$ מהצורה $`6t + 5`$ (5, 11, 17, ...), ומבין אלה $`|m^2 - 67|`$ מינימלי ב-$`m = 5`$. אז $`a = \frac{41\cdot5 + 67\cdot5}6 = 90`$,[^9] $`b = \frac{41 + 25}6 = 11`$, $`k = \frac{25 - 67}6 = -7`$:



```math
90^2 - 67\cdot11^2 = -7.
```



איטרציה שלישית  

כדי ש-7 יחלק את $`90 + 11m`$, צריך $`m = 2 + 7t`$ (2, 9, 16, ...), ומבין אלה בוחרים $`m = 9`$:



```math
221^2 - 67\cdot27^2 = -2.
```



הפתרון הסופי  

בשלב הזה אפשר להמשיך בשיטה המחזורית (היא תסתיים אחרי שבע איטרציות בסך הכול, ב-$`(48842, 5967, 1)`$, דרך $`(1899, 232, -7)`$, $`(3577, 437, 6)`$ ו-$`(9053, 1106, -3)`$), אבל כיוון שאגף ימין הוא אחד מ-$`\pm1, \pm2, \pm4`$, אפשר להשתמש ישירות בתצפית של ברהמגופטה. הרכבת השלשה $`(221, 27, -2)`$ עם עצמה נותנת



```math
\left(\frac{221^2 + 67\cdot27^2}2\right)^2 - 67\cdot(221\cdot27)^2 = 1,
```

 כלומר הפתרון השלם



```math
48842^2 - 67\cdot5967^2 = 1.
```

 הפתרון מקרב את $`\sqrt{67}`$ על ידי $`\frac{48842}{5967}`$, עם שגיאה של בערך $`1.7\times10^{-9}`$.
