# נוסחת צ'אולה–סלברג

ב[מתמטיקה](https://he.wikipedia.org/wiki/%D7%9E%D7%AA%D7%9E%D7%98%D7%99%D7%A7%D7%94), **נוסחת צ'אולה–סלברג** (Chowla–Selberg formula) היא חישוב של מכפלה מסוימת של ערכי [פונקציית גמא](https://he.wikipedia.org/wiki/%D7%A4%D7%95%D7%A0%D7%A7%D7%A6%D7%99%D7%99%D7%AA_%D7%92%D7%9E%D7%90) בנקודות רציונליות, במונחי ערכים של [פונקציית אטא של דדקינד](%D7%A4%D7%95%D7%A0%D7%A7%D7%A6%D7%99%D7%99%D7%AA%20%D7%90%D7%98%D7%90%20%D7%A9%D7%9C%20%D7%93%D7%93%D7%A7%D7%99%D7%A0%D7%93.md) במספרים אי-רציונליים ריבועיים מדומים. התוצאה נמצאה בעיקרה על ידי מתיאש לרך (1897), והתגלתה מחדש על ידי צ'אולה ו[סלברג](https://he.wikipedia.org/wiki/%D7%90%D7%98%D7%9C%D7%94_%D7%A1%D7%9C%D7%91%D7%A8%D7%92) (1949, 1967).

## ניסוח

בצורה לוגריתמית, נוסחת צ'אולה–סלברג אומרת שבמקרים מסוימים אפשר לחשב את הסכום



```math
\frac{w}{4}\sum_r \chi(r)\log \Gamma\left( \frac{r}{D} \right) = \frac{h}{2}\log\left(4\pi\sqrt{|D|}\right) + \sum_\tau\log\left(\sqrt{\mathrm{Im}(\tau)}\,|\eta(\tau)|^2\right)
```

 בעזרת [נוסחת הגבול של קרונקר](%D7%A0%D7%95%D7%A1%D7%97%D7%AA%20%D7%94%D7%92%D7%91%D7%95%D7%9C%20%D7%A9%D7%9C%20%D7%A7%D7%A8%D7%95%D7%A0%D7%A7%D7%A8.md). כאן $`\chi`$ הוא סמל השארית הריבועית מודולו $`D`$, כאשר $`-D`$ ה[דיסקרימיננטה](https://he.wikipedia.org/wiki/%D7%93%D7%99%D7%A1%D7%A7%D7%A8%D7%99%D7%9E%D7%99%D7%A0%D7%A0%D7%98%D7%94) של [שדה ריבועי](https://he.wikipedia.org/wiki/%D7%A9%D7%93%D7%94_%D7%A8%D7%99%D7%91%D7%95%D7%A2%D7%99) מדומה. הסכום הוא על $`0 \lt r \lt D`$, עם המוסכמה הרגילה $`\chi(r) = 0`$ אם ל-$`r`$ ול-$`D`$ יש גורם משותף. $`\eta`$ היא פונקציית האטא של דדקינד, $`h`$ [מספר המחלקה](%D7%97%D7%91%D7%95%D7%A8%D7%AA%20%D7%9E%D7%97%D7%9C%D7%A7%D7%95%D7%AA%20%D7%94%D7%90%D7%99%D7%93%D7%99%D7%90%D7%9C%D7%99%D7%9D.md), ו-$`w`$ מספר שורשי היחידה בשדה. הסכום על $`\tau`$ הוא על נציגים $`\tau = \tfrac{-b + \sqrt{-D} }{2a}`$ של $`h`$ מחלקות התבניות הריבועיות המצומצמות $`(a, b, c)`$ עם דיסקרימיננטה $`-D`$.

### דוגמאות מספריות

בדקנו בחישוב (ברמת דיוק של 30 ספרות) שהנוסחה מתקיימת בדיוק במקרים הבאים:

- $`D = 4`$ ($`\mathbb Q(i)`$, $`w = 4`$, $`h = 1`$, $`\tau = i`$): שני האגפים שווים ל-$`1.0847415\ldots`$.
- $`D = 3`$ ($`w = 6`$, $`h = 1`$, $`\tau = \tfrac{-1 + \sqrt{-3} }{2}`$): $`1.0234055\ldots`$.
- $`D = 7`$ ($`w = 2`$, $`h = 1`$): $`1.1997285\ldots`$.
- $`D = 23`$ ($`w = 2`$, $`h = 3`$, עם שלוש התבניות $`x^2 + xy + 6y^2`$, $`2x^2 \pm xy + 3y^2`$): $`4.2558205\ldots`$.

## מקור ושימושים

היום מבינים שמקורן של נוסחאות כאלה הוא בתורת ה[כפל המרוכב](%D7%9B%D7%A4%D7%9C%20%D7%9E%D7%A8%D7%95%D7%9B%D7%91.md), ובפרט בתורת המחזורים של יריעה אבלית מטיפוס CM. זה הוביל למחקר רב ולהכללות. בפרט יש אנלוג לנוסחת צ'אולה–סלברג ל[מספרים $`p`$-אדיים](https://he.wikipedia.org/wiki/%D7%9E%D7%A1%D7%A4%D7%A8_p-%D7%90%D7%93%D7%99), עם פונקציית גמא $`p`$-אדית, שנקרא נוסחת גרוס–קובליץ.

נוסחת צ'אולה–סלברג נותנת נוסחה למכפלה סופית של ערכי פונקציית האטא. בשילוב עם תורת הכפל המרוכב אפשר לקבל נוסחה לערכים המוחלטים של פונקציית האטא בנקודות בודדות:



```math
\mathrm{Im}(\tau)\,|\eta(\tau)|^4 = \frac{\alpha}{4\pi\sqrt{|D|} } \prod_r\Gamma(r/|D|)^{\chi(r)\frac{w}{2h} }
```

 עבור מספר אלגברי $`\alpha`$ כלשהו.

## דוגמה

בעזרת נוסחת השיקוף של אוילר לפונקציית גמא ($`\Gamma(\tfrac14)\Gamma(\tfrac34) = \pi\sqrt2`$), המקרה $`D = 4`$ נותן:



```math
\eta(i) = \frac{\Gamma(\tfrac{1}{4})}{2\pi^{3/4} } = 0.7682254223\ldots
```

 (בדקנו בחישוב מול המכפלה $`\eta(i) = e^{-\pi/12}\prod_{n\ge1}(1 - e^{-2\pi n})`$.)
