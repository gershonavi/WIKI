# סדרת להמר

*אין לבלבל עם [\[\[בעיית פונקציית אוילר של להמר](https://he.wikipedia.org/wiki/%5B%5B%D7%91%D7%A2%D7%99%D7%99%D7%AA_%D7%A4%D7%95%D7%A0%D7%A7%D7%A6%D7%99%D7%99%D7%AA_%D7%90%D7%95%D7%99%D7%9C%D7%A8_%D7%A9%D7%9C_%D7%9C%D7%94%D7%9E%D7%A8)\]\].* ב[מתמטיקה](https://he.wikipedia.org/wiki/%D7%9E%D7%AA%D7%9E%D7%98%D7%99%D7%A7%D7%94), **סדרת להמר** $`U_n(\sqrt R, Q)`$ או $`V_n(\sqrt R, Q)`$ היא הכללה של [סדרת לוקאס](https://he.wikipedia.org/wiki/%D7%A1%D7%93%D7%A8%D7%AA_%D7%9C%D7%95%D7%A7%D7%90%D7%A1) $`U_n(P, Q)`$ או $`V_n(P, Q)`$, שמאפשרת את השורש הריבועי של שלם $`R`$ במקום השלם $`P`$.[^1] איברי הסדרה נקראים **מספרי להמר**, על שם [דריק הנרי להמר](https://he.wikipedia.org/wiki/%D7%93%D7%A8%D7%99%D7%A7_%D7%94%D7%A0%D7%A8%D7%99_%D7%9C%D7%94%D7%9E%D7%A8).

כדי להבטיח שהערכים יהיו תמיד שלמים, כל איבר שני בסדרת להמר מחולק ב-$`\sqrt{R}`$ ביחס לאיבר המתאים בסדרת לוקאס. כלומר, כש-$`R = P^2`$, סדרות להמר ולוקאס קשורות כך:



```math
\begin{align}
P\,U_{2n}(\sqrt{P^2},Q) &= U_{2n}(P,Q), & U_{2n+1}(\sqrt{P^2},Q) &= U_{2n+1}(P,Q), \\
V_{2n}(\sqrt{P^2},Q) &= V_{2n}(P,Q), & P\,V_{2n+1}(\sqrt{P^2},Q) &= V_{2n+1}(P,Q).
\end{align}
```



## יחסים אלגבריים

יהיו $`a`$ ו-$`b`$ [מספרים מרוכבים](https://he.wikipedia.org/wiki/%D7%9E%D7%A1%D7%A4%D7%A8_%D7%9E%D7%A8%D7%95%D7%9B%D7%91) עם



```math
a + b = \sqrt{R},\qquad ab = Q,
```

 בתנאים הבאים:

- $`Q`$ ו-$`R`$ שלמים שונים מאפס ו[זרים](https://he.wikipedia.org/wiki/%D7%9E%D7%A1%D7%A4%D7%A8%D7%99%D7%9D_%D7%96%D7%A8%D7%99%D7%9D);
- $`a/b`$ אינו [שורש יחידה](https://he.wikipedia.org/wiki/%D7%A9%D7%95%D7%A8%D7%A9_%D7%99%D7%97%D7%99%D7%93%D7%94).

אז מספרי להמר המתאימים הם



```math
U_n(\sqrt{R},Q) = \frac{a^n-b^n}{a-b}
```

 עבור $`n`$ [אי-זוגי](https://he.wikipedia.org/wiki/%D7%9E%D7%A1%D7%A4%D7%A8_%D7%90%D7%99-%D7%96%D7%95%D7%92%D7%99), ו-



```math
U_n(\sqrt{R},Q) = \frac{a^n-b^n}{a^2-b^2}
```

 עבור $`n`$ זוגי. המספרים הנלווים להם הם



```math
V_n(\sqrt{R},Q) = \frac{a^n+b^n}{a+b}
```

 עבור $`n`$ אי-זוגי, ו-



```math
V_n(\sqrt{R},Q) = a^n+b^n
```

 עבור $`n`$ זוגי.

## נוסחת נסיגה

מספרי להמר מקיימים [נוסחת נסיגה](https://he.wikipedia.org/wiki/%D7%A0%D7%95%D7%A1%D7%97%D7%AA_%D7%A0%D7%A1%D7%99%D7%92%D7%94) ליניארית



```math
U_n = (R-2Q)U_{n-2}-Q^2U_{n-4} = (a^2+b^2)U_{n-2}-a^2b^2U_{n-4},
```

 עם ערכי ההתחלה $`U_0=0`$, $`U_1=1`$, $`U_2=1`$, $`U_3=R-Q=a^2+ab+b^2`$. באופן דומה, הסדרה הנלווית מקיימת



```math
V_n = (R-2Q)V_{n-2}-Q^2V_{n-4} = (a^2+b^2)V_{n-2}-a^2b^2V_{n-4},
```

 עם ערכי ההתחלה $`V_0=2`$, $`V_1=1`$, $`V_2=R-2Q=a^2+b^2`$, $`V_3=R-3Q=a^2-ab+b^2`$. (הסיבה: $`a^2`$ ו-$`b^2`$ הם שורשי $`x^2 - (a^2+b^2)x + a^2b^2 = x^2 - (R - 2Q)x + Q^2`$, שמקדמיו שלמים, ולכן כל אחת מתת-הסדרות הזוגית והאי-זוגית היא סדרת לוקאס במשתנה $`a^2`$.)

כל נוסחאות הנסיגה של סדרות לוקאס תקפות גם לסדרות להמר, אם מחלקים אותן למקרים של $`n`$ זוגי ואי-זוגי ומכניסים גורמים מתאימים של $`\sqrt R`$. למשל,



```math
\begin{align}
U_{2n}(\sqrt R,Q) &= U_{2n-1}(\sqrt R,Q) - Q\, U_{2n-2}(\sqrt R,Q), &
U_{2n+1}(\sqrt R,Q) &= R\, U_{2n}(\sqrt R,Q) - Q\, U_{2n-1}(\sqrt R,Q), \\
V_{2n}(\sqrt R,Q) &= R\, V_{2n-1}(\sqrt R,Q) - Q\, V_{2n-2}(\sqrt R,Q), &
V_{2n+1}(\sqrt R,Q) &= V_{2n}(\sqrt R,Q) - Q\, V_{2n-1}(\sqrt R,Q).
\end{align}
```



## דוגמאות

(את כל הנוסחאות לעיל בדקנו בחישוב סימבולי עבור $`(R, Q) = (5, 1), (3, -1), (7, 2), (1, -1)`$.)

- $`R = 1`$, $`Q = -1`$: כאן $`R = P^2`$ עם $`P = 1`$, וסדרת להמר מתלכדת עם סדרת לוקאס $`U_n(1, -1)`$, כלומר עם [סדרת פיבונאצ'י](https://he.wikipedia.org/wiki/%D7%A1%D7%93%D7%A8%D7%AA_%D7%A4%D7%99%D7%91%D7%95%D7%A0%D7%90%D7%A6%27%D7%99): $`0, 1, 1, 2, 3, 5, 8, 13, \ldots`$; וה-$`V_n`$ הם [מספרי לוקאס](https://he.wikipedia.org/wiki/%D7%9E%D7%A1%D7%A4%D7%A8%D7%99_%D7%9C%D7%95%D7%A7%D7%90%D7%A1) (לפי היחסים שבפתיחה, עם $`P = 1`$).
- $`R = 5`$, $`Q = 1`$: כאן $`a = \tfrac{1+\sqrt5}2 = \phi`$ (ה[יחס הזהב](https://he.wikipedia.org/wiki/%D7%99%D7%97%D7%A1_%D7%94%D7%96%D7%94%D7%91)) ו-$`b = 1/\phi`$. מקבלים $`U_n = 0, 1, 1, 4, 3, 11, 8, 29, \ldots`$: האיברים במקומות האי-זוגיים הם מספרי לוקאס $`L_1, L_3, L_5, L_7 = 1, 4, 11, 29`$, ואלה שבמקומות הזוגיים הם מספרי פיבונאצ'י $`F_2, F_4, F_6 = 1, 3, 8`$. אפשר לבדוק את נוסחת הנסיגה: $`R - 2Q = 3`$, $`Q^2 = 1`$, ו-$`U_6 = 3U_4 - U_2 = 9 - 1 = 8`$, $`U_7 = 3U_5 - U_3 = 33 - 4 = 29`$.
- $`R = 3`$, $`Q = -1`$: $`U_n = 0, 1, 1, 4, 5, 19, 24, 91, \ldots`$, עם $`R - 2Q = 5`$ ו-$`U_7 = 5\cdot19 - 4 = 91`$.
