# פונקציית למבדא המודולרית

ב[מתמטיקה](https://he.wikipedia.org/wiki/%D7%9E%D7%AA%D7%9E%D7%98%D7%99%D7%A7%D7%94), **פונקציית למבדא המודולרית** $`\lambda(\tau)`$[^1] היא [פונקציה הולומורפית](https://he.wikipedia.org/wiki/%D7%A4%D7%95%D7%A0%D7%A7%D7%A6%D7%99%D7%94_%D7%94%D7%95%D7%9C%D7%95%D7%9E%D7%95%D7%A8%D7%A4%D7%99%D7%AA) בעלת סימטריה רבה על [חצי המישור העליון](%D7%97%D7%A6%D7%99%20%D7%94%D7%9E%D7%99%D7%A9%D7%95%D7%A8%20%D7%94%D7%A2%D7%9C%D7%99%D7%95%D7%9F.md) המרוכב. היא אינווריאנטית תחת הפעולה ה[לינארית-שבורה](https://he.wikipedia.org/wiki/%D7%94%D7%A2%D7%AA%D7%A7%D7%AA_%D7%9E%D7%91%D7%99%D7%95%D7%A1) של [תת-חבורת הקונגרואנציה](%D7%AA%D7%AA-%D7%97%D7%91%D7%95%D7%A8%D7%AA%20%D7%A7%D7%95%D7%A0%D7%92%D7%A8%D7%95%D7%90%D7%A0%D7%A6%D7%99%D7%94.md) $`\Gamma(2)`$ של $`\mathrm{SL}_2(\mathbb Z)`$, והיא יוצרת את [שדה הפונקציות](https://he.wikipedia.org/wiki/%D7%A9%D7%93%D7%94_%D7%A4%D7%95%D7%A0%D7%A7%D7%A6%D7%99%D7%95%D7%AA) של המנה המתאימה; כלומר, היא **האופטמודול** של [העקום המודולרי](%D7%A2%D7%A7%D7%95%D7%9D%20%D7%9E%D7%95%D7%93%D7%95%D7%9C%D7%A8%D7%99.md) $`X(2)`$. בכל נקודה $`\tau`$ אפשר לתאר את ערכה כ[יחס כפול](https://he.wikipedia.org/wiki/%D7%99%D7%97%D7%A1_%D7%9B%D7%A4%D7%95%D7%9C) של נקודות ההסתעפות של הכיסוי הכפול המסועף של הישר הפרויקטיבי על ידי ה[עקום אליפטי](https://he.wikipedia.org/wiki/%D7%A2%D7%A7%D7%95%D7%9D_%D7%90%D7%9C%D7%99%D7%A4%D7%98%D7%99) $`\mathbb C/\langle 1, \tau\rangle`$, כאשר ההעתקה היא המנה ביחס לאינוולוציה $`[-1]`$.

פיתוח ה-$`q`$, עם $`q = e^{\pi i\tau}`$ הנום, הוא



```math
\lambda(\tau) = 16q - 128q^2 + 704q^3 - 3072q^4 + 11488q^5 - 38400q^6 + \cdots
```

 (סדרה A115977 ב-[OEIS](https://he.wikipedia.org/wiki/OEIS)). אם מסמטרים את פונקציית למבדא תחת הפעולה הקנונית של ה[חבורה הסימטרית](https://he.wikipedia.org/wiki/%D7%94%D7%97%D7%91%D7%95%D7%A8%D7%94_%D7%94%D7%A1%D7%99%D7%9E%D7%98%D7%A8%D7%99%D7%AA) $`S_3`$ על $`X(2)`$, ומנרמלים בצורה מתאימה, מתקבלת פונקציה על חצי המישור העליון שאינווריאנטית תחת כל החבורה המודולרית $`\mathrm{SL}_2(\mathbb Z)`$, ולמעשה זו [פונקציית $`j`$](%D7%90%D7%99%D7%A0%D7%95%D7%95%D7%A8%D7%99%D7%90%D7%A0%D7%98%20j.md) המודולרית של קליין.

## תכונות מודולריות

הפונקציה $`\lambda(\tau)`$ אינווריאנטית תחת החבורה שנוצרת על ידי[^2]



```math
\tau \mapsto \tau + 2, \qquad \tau \mapsto \frac\tau{1 - 2\tau}.
```

 היוצרים של החבורה המודולרית פועלים כך:[^3]



```math
\tau \mapsto \tau + 1:\quad \lambda \mapsto \frac\lambda{\lambda - 1}; \qquad \tau \mapsto -\frac1\tau:\quad \lambda \mapsto 1 - \lambda.
```

 לכן הפעולה של החבורה המודולרית על $`\lambda(\tau)`$ היא הפעולה של **החבורה האנהרמונית**, שנותנת את ששת הערכים של היחס הכפול:[^4]



```math
\left\{\lambda,\ \frac1{1 - \lambda},\ \frac{\lambda - 1}\lambda,\ \frac1\lambda,\ \frac\lambda{\lambda - 1},\ 1 - \lambda\right\}.
```

 החבורה $`\mathrm{SL}_2(\mathbb Z)/\Gamma(2) \cong \mathrm{SL}_2(\mathbb F_2) \cong S_3`$ פועלת על ששת הערכים האלה בדיוק כמו $`S_3`$ על סידורי שלוש נקודות ההסתעפות.

## קשר לפונקציות אחרות

$`\lambda`$ היא הריבוע של המודולוס האליפטי,[^5] כלומר $`\lambda(\tau) = k^2(\tau)`$. בעזרת [פונקציית אטא של דדקינד](%D7%A4%D7%95%D7%A0%D7%A7%D7%A6%D7%99%D7%99%D7%AA%20%D7%90%D7%98%D7%90%20%D7%A9%D7%9C%20%D7%93%D7%93%D7%A7%D7%99%D7%A0%D7%93.md) $`\eta(\tau)`$ ו[פונקציות התטא](https://he.wikipedia.org/wiki/%D7%A4%D7%95%D7%A0%D7%A7%D7%A6%D7%99%D7%99%D7%AA_%D7%AA%D7%98%D7%90):[^6]



```math
\lambda(\tau) = \left(\frac{\sqrt2\,\eta\left(\frac\tau2\right)\eta^2(2\tau)}{\eta^3(\tau)}\right)^8 = \frac{16}{\left(\frac{\eta(\tau/2)}{\eta(2\tau)}\right)^8 + 16} = \frac{\theta_2^4(\tau)}{\theta_3^4(\tau)},
```

 וכן



```math
\frac1{\lambda(\tau)^{1/4} } - \lambda(\tau)^{1/4} = \frac12\left(\frac{\eta\left(\frac\tau4\right)}{\eta(\tau)}\right)^4 = 2\,\frac{\theta_4^2\left(\frac\tau2\right)}{\theta_2^2\left(\frac\tau2\right)},
```

 כאשר



```math
\theta_2(\tau) = \sum_{n=-\infty}^\infty e^{\pi i\tau(n + 1/2)^2}, \qquad \theta_3(\tau) = \sum_{n=-\infty}^\infty e^{\pi i\tau n^2}, \qquad \theta_4(\tau) = \sum_{n=-\infty}^\infty(-1)^ne^{\pi i\tau n^2}.
```



בעזרת חצאי המחזורים של [הפונקציות האליפטיות של ויירשטראס](%D7%94%D7%A4%D7%95%D7%A0%D7%A7%D7%A6%D7%99%D7%94%20%D7%94%D7%90%D7%9C%D7%99%D7%A4%D7%98%D7%99%D7%AA%20%D7%A9%D7%9C%20%D7%95%D7%99%D7%99%D7%A8%D7%A9%D7%98%D7%A8%D7%90%D7%A1.md): יהי $`[\omega_1, \omega_2]`$ [זוג מחזורים יסודי](%D7%96%D7%95%D7%92%20%D7%9E%D7%97%D7%96%D7%95%D7%A8%D7%99%D7%9D%20%D7%99%D7%A1%D7%95%D7%93%D7%99.md) עם $`\tau = \omega_2/\omega_1`$, ו-



```math
e_1 = \wp\left(\frac{\omega_1}2\right), \qquad e_2 = \wp\left(\frac{\omega_2}2\right), \qquad e_3 = \wp\left(\frac{\omega_1 + \omega_2}2\right).
```

 אז[^7]



```math
\lambda = \frac{e_3 - e_2}{e_1 - e_2}.
```

 כיוון ששלושת הערכים בחצאי המחזורים שונים זה מזה, מכאן ש-$`\lambda`$ אינה מקבלת את הערכים 0 ו-1.[^8]

הקשר ל[אינווריאנט j](%D7%90%D7%99%D7%A0%D7%95%D7%95%D7%A8%D7%99%D7%90%D7%A0%D7%98%20j.md) הוא[^9][^10]



```math
j(\tau) = \frac{256\bigl(1 - \lambda(1 - \lambda)\bigr)^3}{\bigl(\lambda(1 - \lambda)\bigr)^2} = \frac{256(1 - \lambda + \lambda^2)^3}{\lambda^2(1 - \lambda)^2},
```

 וזה אינווריאנט $`j`$ של העקום האליפטי בצורת לז'נדר $`y^2 = x(x - 1)(x - \lambda)`$. למשל, $`\lambda(i) = \tfrac12`$ נותן $`j(i) = 256\cdot(3/4)^3/(1/16) = 1728`$.

בהינתן $`m \in \mathbb C\setminus\{0, 1\}`$, יהי



```math
\tau = i\frac{K\{1 - m\} }{K\{m\} },
```

 כאשר $`K`$ הוא [האינטגרל האליפטי השלם מהסוג הראשון](https://he.wikipedia.org/wiki/%D7%90%D7%99%D7%A0%D7%98%D7%92%D7%A8%D7%9C_%D7%90%D7%9C%D7%99%D7%A4%D7%98%D7%99) עם פרמטר $`m = k^2`$. אז $`\lambda(\tau) = m`$. (בדקנו זאת בחישוב מספרי עבור $`m = 0.3`$.)

## משוואות מודולריות

**המשוואה המודולרית ממעלה $`p`$** (כאשר $`p`$ [מספר ראשוני](https://he.wikipedia.org/wiki/%D7%9E%D7%A1%D7%A4%D7%A8_%D7%A8%D7%90%D7%A9%D7%95%D7%A0%D7%99)) היא משוואה אלגברית ב-$`\lambda(p\tau)`$ וב-$`\lambda(\tau)`$. אם $`\lambda(p\tau) = u^8`$ ו-$`\lambda(\tau) = v^8`$, המשוואות המודולריות ממעלות $`p = 2, 3, 5, 7`$ הן, בהתאמה,[^11]



```math
\begin{align}
&(1 + u^4)^2v^8 - 4u^4 = 0, \\
&u^4 - v^4 + 2uv(1 - u^2v^2) = 0, \\
&u^6 - v^6 + 5u^2v^2(u^2 - v^2) + 4uv(1 - u^4v^4) = 0, \\
&(1 - u^8)(1 - v^8) - (1 - uv)^8 = 0.
\end{align}
```

 את הגודל $`v`$ (ולכן גם את $`u`$) אפשר לראות כפונקציה הולומורפית בחצי המישור העליון $`\mathrm{Im}\tau \gt 0`$:



```math
v = \prod_{k=1}^\infty\tanh\frac{(k - 1/2)\pi i}\tau = \sqrt2e^{\pi i\tau/8}\frac{\sum_{k\in\mathbb Z}e^{(2k^2 + k)\pi i\tau} }{\sum_{k\in\mathbb Z}e^{k^2\pi i\tau} } = \cfrac{\sqrt2e^{\pi i\tau/8} }{1 + \cfrac{e^{\pi i\tau} }{1 + e^{\pi i\tau} + \cfrac{e^{2\pi i\tau} }{1 + e^{2\pi i\tau} + \cfrac{e^{3\pi i\tau} }{1 + e^{3\pi i\tau} + \ddots} } } }
```

 (בדקנו את ארבע המשוואות המודולריות ואת שלושת הביטויים ל-$`v`$ בחישוב מספרי, עבור $`\tau = 1.1i`$.)

כיוון ש-$`\lambda(i) = 1/2`$, אפשר להשתמש במשוואות המודולריות כדי לקבל [ערכים אלגבריים](https://he.wikipedia.org/wiki/%D7%9E%D7%A1%D7%A4%D7%A8_%D7%90%D7%9C%D7%92%D7%91%D7%A8%D7%99) של $`\lambda(pi)`$ לכל ראשוני $`p`$. (לכל חזקת ראשוני אפשר לחזור על המשוואה המודולרית ממעלה $`p`$, ולכן התהליך נותן ערכים אלגבריים של $`\lambda(ni)`$ לכל $`n`$ טבעי.) למשל, עבור $`p = 2`$: $`v^8 = \tfrac12`$ והמשוואה $`(1 + u^4)^2 = 8u^4`$ נותנת $`u^4 = 3 - 2\sqrt2 = (\sqrt2 - 1)^2`$, ולכן $`\lambda(2i) = u^8 = (\sqrt2 - 1)^4 \approx 0.02944`$. הערכים האלגבריים של $`\lambda(ni)`$ נתונים גם על ידי[^12]



```math
\lambda(ni) = \prod_{k=1}^{n/2}\mathrm{sl}^8\frac{(2k - 1)\varpi}{2n} \quad (2 \mid n), \qquad \lambda(ni) = \frac1{2^n}\prod_{k=1}^{n-1}\left(1 - \mathrm{sl}^2\frac{k\varpi}n\right)^2 \quad (2 \nmid n),
```

 כאשר $`\mathrm{sl}`$ הוא הסינוס הלמניסקטי ו-$`\varpi \approx 2.62206`$ הוא קבוע הלמניסקטה (ו-$`\mathrm{sl}(a\varpi)`$ אלגברי לכל $`a`$ רציונלי). (בדקנו את שתי הנוסחאות עבור $`n = 2, \dots, 7`$.)

## למבדא-כוכב

### הגדרה וחישוב

הפונקציה $`\lambda^*(x)`$[^13] (עבור $`x \in \mathbb R^+`$) נותנת את המודולוס האליפטי $`k`$ שעבורו [האינטגרל האליפטי השלם מהסוג הראשון](https://he.wikipedia.org/wiki/%D7%90%D7%99%D7%A0%D7%98%D7%92%D7%A8%D7%9C_%D7%90%D7%9C%D7%99%D7%A4%D7%98%D7%99) $`K(k)`$ והאינטגרל המשלים $`K\left(\sqrt{1 - k^2}\right)`$ מקיימים



```math
\frac{K\left[\sqrt{1 - \lambda^*(x)^2}\right]}{K[\lambda^*(x)]} = \sqrt x.
```

 את ערכי $`\lambda^*(x)`$ אפשר לחשב כך:



```math
\lambda^*(x) = \frac{\theta_2^2(i\sqrt x)}{\theta_3^2(i\sqrt x)} = \left[\sum_{a=-\infty}^\infty\exp\left(-(a + 1/2)^2\pi\sqrt x\right)\right]^2\left[\sum_{a=-\infty}^\infty\exp\left(-a^2\pi\sqrt x\right)\right]^{-2} = \frac{\sum_{a=-\infty}^\infty\mathrm{sech}\left[(a + 1/2)\pi\sqrt x\right]}{\sum_{a=-\infty}^\infty\mathrm{sech}\left(a\pi\sqrt x\right)}.
```

 הקשר בין $`\lambda^*`$ ל-$`\lambda`$ הוא



```math
\lambda^*(x) = \sqrt{\lambda\left(i\sqrt x\right)}.
```



### תכונות

כל ערך של $`\lambda^*`$ ב[מספר רציונלי](https://he.wikipedia.org/wiki/%D7%9E%D7%A1%D7%A4%D7%A8_%D7%A8%D7%A6%D7%99%D7%95%D7%A0%D7%9C%D7%99) חיובי הוא [מספר אלגברי](https://he.wikipedia.org/wiki/%D7%9E%D7%A1%D7%A4%D7%A8_%D7%90%D7%9C%D7%92%D7%91%D7%A8%D7%99) חיובי:



```math
\lambda^*(x) \in \overline{\mathbb Q}_+ \quad \forall x \in \mathbb Q^+.
```

 את $`K(\lambda^*(x))`$ ואת $`E(\lambda^*(x))`$ ([האינטגרל האליפטי השלם מהסוג השני](https://he.wikipedia.org/wiki/%D7%90%D7%99%D7%A0%D7%98%D7%92%D7%A8%D7%9C_%D7%90%D7%9C%D7%99%D7%A4%D7%98%D7%99)) אפשר לבטא בצורה סגורה בעזרת [פונקציית גמא](https://he.wikipedia.org/wiki/%D7%A4%D7%95%D7%A0%D7%A7%D7%A6%D7%99%D7%99%D7%AA_%D7%92%D7%9E%D7%90) לכל $`x \in \mathbb Q^+`$, כפי שהוכיחו סלברג וצ'אולה ב-1949.[^14]

הביטוי הבא נכון לכל $`n \in \mathbb N`$:



```math
\sqrt n = \sum_{a=1}^n\mathrm{dn}\left[\frac{2a}nK\left[\lambda^*\left(\frac1n\right)\right];\lambda^*\left(\frac1n\right)\right],
```

 כאשר $`\mathrm{dn}`$ היא פונקציית יעקובי delta amplitudinis עם מודולוס $`k`$.

כשיודעים ערך אחד של $`\lambda^*`$, אפשר להשתמש בנוסחה הבאה כדי לחשב ערכים קשורים:[^15]



```math
\lambda^*(n^2x) = \lambda^*(x)^n\prod_{a=1}^n\mathrm{sn}\left\{\frac{2a - 1}nK[\lambda^*(x)];\lambda^*(x)\right\}^2,
```

 כאשר $`n \in \mathbb N`$ ו-$`\mathrm{sn}`$ היא פונקציית יעקובי sinus amplitudinis עם מודולוס $`k`$.

קשרים נוספים:



```math
\lambda^*(x)^2 + \lambda^*(1/x)^2 = 1,
```





```math
[\lambda^*(x) + 1][\lambda^*(4/x) + 1] = 2,
```





```math
\lambda^*(4x) = \frac{1 - \sqrt{1 - \lambda^*(x)^2} }{1 + \sqrt{1 - \lambda^*(x)^2} } = \tan\left\{\frac12\arcsin[\lambda^*(x)]\right\}^2,
```





```math
\lambda^*(x) - \lambda^*(9x) = 2[\lambda^*(x)\lambda^*(9x)]^{1/4} - 2[\lambda^*(x)\lambda^*(9x)]^{3/4}.
```

 ועוד, עם $`a = \left[\frac{2\lambda^*(x)}{1 - \lambda^*(x)^2}\right]^{1/12}`$ ועם $`f, b, c, d`$ שמוגדרים באותו אופן מ-$`\lambda^*(25x)`$, $`\lambda^*(49x)`$, $`\lambda^*(121x)`$, $`\lambda^*(169x)`$ בהתאמה:



```math
\begin{align}
&a^6 - f^6 = 2af + 2a^5f^5, \\
&a^8 + b^8 - 7a^4b^4 = 2\sqrt2ab + 2\sqrt2a^7b^7, \\
&a^{12} - c^{12} = 2\sqrt2(ac + a^3c^3)(1 + 3a^2c^2 + a^4c^4)(2 + 3a^2c^2 + 2a^4c^4), \\
&(a^2 - d^2)(a^4 + d^4 - 7a^2d^2)\left[(a^2 - d^2)^4 - a^2d^2(a^2 + d^2)^2\right] = 8ad + 8a^{13}d^{13}.
\end{align}
```

 (את כל הקשרים בסעיף הזה בדקנו בחישוב מספרי בדיוק של 40 ספרות.)

### אינווריאנטי המחלקה של רמנוג'אן

אינווריאנטי המחלקה של [רמנוג'אן](https://he.wikipedia.org/wiki/%D7%A1%D7%A8%D7%99%D7%A0%D7%99%D7%95%D7%95%D7%90%D7%A1%D7%94_%D7%A8%D7%9E%D7%A0%D7%95%D7%92%27%D7%90%D7%9F) $`G_n`$ ו-$`g_n`$ מוגדרים על ידי[^16]



```math
G_n = 2^{-1/4}e^{\pi\sqrt n/24}\prod_{k=0}^\infty\left(1 + e^{-(2k+1)\pi\sqrt n}\right), \qquad g_n = 2^{-1/4}e^{\pi\sqrt n/24}\prod_{k=0}^\infty\left(1 - e^{-(2k+1)\pi\sqrt n}\right),
```

 כאשר $`n \in \mathbb Q^+`$. עבור $`n`$ כאלה, אינווריאנטי המחלקה הם מספרים אלגבריים. למשל



```math
g_{58} = \sqrt{\frac{5 + \sqrt{29} }2}, \qquad g_{190} = \sqrt{\left(\sqrt5 + 2\right)\left(\sqrt{10} + 3\right)}.
```

 בין הזהויות שמקיימים אינווריאנטי המחלקה:[^17]



```math
G_n = G_{1/n}, \qquad g_n = \frac1{g_{4/n} }, \qquad g_{4n} = 2^{1/4}g_nG_n.
```

 אינווריאנטי המחלקה קשורים הדוק לפונקציות ובר המודולריות $`\mathfrak f`$ ו-$`\mathfrak f_1`$. אלה הקשרים בין למבדא-כוכב לאינווריאנטי המחלקה:



```math
G_n = \sin\{2\arcsin[\lambda^*(n)]\}^{-1/12} = 1\Big/\left[\sqrt[12]{2\lambda^*(n)}\sqrt[24]{1 - \lambda^*(n)^2}\right],
```





```math
g_n = \tan\{2\arctan[\lambda^*(n)]\}^{-1/12} = \sqrt[12]{[1 - \lambda^*(n)^2]/[2\lambda^*(n)]},
```





```math
\lambda^*(n) = \tan\left\{\frac12\arctan[g_n^{-12}]\right\} = \sqrt{g_n^{24} + 1} - g_n^{12}.
```



## הופעות נוספות

### משפט פיקאר הקטן

פונקציית למבדא שימשה בהוכחה המקורית של משפט פיקאר הקטן, שלפיו [פונקציה שלמה](https://he.wikipedia.org/wiki/%D7%A4%D7%95%D7%A0%D7%A7%D7%A6%D7%99%D7%94_%D7%A9%D7%9C%D7%9E%D7%94) לא קבועה על [המישור המרוכב](https://he.wikipedia.org/wiki/%D7%94%D7%9E%D7%99%D7%A9%D7%95%D7%A8_%D7%94%D7%9E%D7%A8%D7%95%D7%9B%D7%91) אינה יכולה להחמיץ יותר מערך אחד. פיקאר הוכיח את המשפט ב-1879.[^18] נניח, בדרך השלילה, ש-$`f`$ שלמה ואינה מקבלת את הערכים 0 ו-1. כיוון ש-$`\lambda`$ הולומורפית, יש לה הופכית הולומורפית מקומית $`\omega`$ שמוגדרת מחוץ ל-$`0, 1, \infty`$. נתבונן בפונקציה $`z \mapsto \omega(f(z))`$. לפי משפט המונודרומיה היא הולומורפית (ומוגדרת היטב, כי $`\mathbb C`$ פשוט קשר), ומעתיקה את המישור המרוכב לחצי המישור העליון. מכאן קל לבנות פונקציה הולומורפית מ-$`\mathbb C`$ לעיגול היחידה (למשל על ידי הרכבה עם $`w \mapsto \frac{w - i}{w + i}`$), שלפי [משפט ליוביל](https://he.wikipedia.org/wiki/%D7%9E%D7%A9%D7%A4%D7%98_%D7%9C%D7%99%D7%95%D7%91%D7%99%D7%9C_%28%D7%90%D7%A0%D7%9C%D7%99%D7%96%D7%94_%D7%9E%D7%A8%D7%95%D7%9B%D7%91%D7%AA%29) חייבת להיות קבועה; לכן גם $`f`$ קבועה.[^19]

### ירח

הפונקציה $`\tau \mapsto 16/\lambda(2\tau) - 8`$ היא [האופטמודול](%D7%A2%D7%A7%D7%95%D7%9D%20%D7%9E%D7%95%D7%93%D7%95%D7%9C%D7%A8%D7%99.md) המנורמל של החבורה $`\Gamma_0(4)`$, ופיתוח ה-$`q`$ שלה



```math
q^{-1} + 20q - 62q^3 + 216q^5 - 641q^7 + \cdots
```

 (סדרה A007248 ב-OEIS), עם $`q = e^{2\pi i\tau}`$, הוא הקרקטר המדורג של כל איבר במחלקת הצמידות 4C של [חבורת המפלצת](%D7%97%D7%91%D7%95%D7%A8%D7%AA%20%D7%94%D7%9E%D7%A4%D7%9C%D7%A6%D7%AA.md) כשהיא פועלת על אלגברת הקודקודים של המפלצת. (את המקדמים שכאן בדקנו בחישוב מספרי.)
