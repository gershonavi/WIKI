# משפט הורוויץ (תורת המספרים)

ב[תורת המספרים](https://he.wikipedia.org/wiki/%D7%AA%D7%95%D7%A8%D7%AA_%D7%94%D7%9E%D7%A1%D7%A4%D7%A8%D7%99%D7%9D), **משפט הורוויץ**, שנקרא על שם [אדולף הורוויץ](https://he.wikipedia.org/wiki/%D7%90%D7%93%D7%95%D7%9C%D7%A3_%D7%94%D7%95%D7%A8%D7%95%D7%95%D7%99%D7%A5), נותן [חסם](https://he.wikipedia.org/wiki/%D7%97%D7%A1%D7%9D_%D7%A2%D7%9C%D7%99%D7%95%D7%9F) על [קירוב דיופנטי](https://he.wikipedia.org/wiki/%D7%A7%D7%99%D7%A8%D7%95%D7%91_%D7%93%D7%99%D7%95%D7%A4%D7%A0%D7%98%D7%99). המשפט קובע שלכל [מספר אי-רציונלי](https://he.wikipedia.org/wiki/%D7%9E%D7%A1%D7%A4%D7%A8_%D7%90%D7%99-%D7%A8%D7%A6%D7%99%D7%95%D7%A0%D7%9C%D7%99) $`\xi`$ יש אינסוף זוגות של שלמים [זרים](https://he.wikipedia.org/wiki/%D7%9E%D7%A1%D7%A4%D7%A8%D7%99%D7%9D_%D7%96%D7%A8%D7%99%D7%9D) $`m, n`$ כך ש-



```math
\left|\xi - \frac mn\right| \lt \frac1{\sqrt5\,n^2}.
```

 אי אפשר לוותר על התנאי ש-$`\xi`$ אי-רציונלי. יתרה מזו, הקבוע $`\sqrt5`$ הוא הטוב ביותר האפשרי: אם מחליפים את $`\sqrt5`$ במספר כלשהו $`A \gt \sqrt5`$, ולוקחים $`\xi = (1 + \sqrt5)/2`$ ([יחס הזהב](https://he.wikipedia.org/wiki/%D7%99%D7%97%D7%A1_%D7%94%D7%96%D7%94%D7%91)), יש רק מספר **סופי** של זוגות שלמים זרים $`m, n`$ שמקיימים את אי-השוויון.

המשפט שקול לטענה ש[קבוע מרקוב](https://he.wikipedia.org/wiki/%D7%A7%D7%91%D7%95%D7%A2_%D7%9E%D7%A8%D7%A7%D7%95%D7%91) של כל מספר הוא לפחות $`\sqrt5`$. הוא משפר את [משפט הקירוב של דיריכלה](%D7%9E%D7%A9%D7%A4%D7%98%20%D7%94%D7%A7%D7%99%D7%A8%D7%95%D7%91%20%D7%A9%D7%9C%20%D7%93%D7%99%D7%A8%D7%99%D7%9B%D7%9C%D7%94.md), שנותן את אי-השוויון עם $`1/n^2`$ במקום $`1/(\sqrt5n^2)`$.

## הוכחה

**הקיום.** יהיו $`p_k/q_k`$ המנות המתקרבות של [השבר המשולב](https://he.wikipedia.org/wiki/%D7%A9%D7%91%D7%A8_%D7%9E%D7%A9%D7%95%D7%9C%D7%91) של $`\xi`$. הטענה המרכזית: מבין כל שלוש מנות מתקרבות עוקבות, לפחות אחת מקיימת $`|\xi - p/q| \lt 1/(\sqrt5q^2)`$. כיוון שיש אינסוף מנות מתקרבות (כש-$`\xi`$ אי-רציונלי), מקבלים אינסוף קירובים כאלה. רעיון ההוכחה: אם $`|\xi - p_k/q_k| \ge 1/(\sqrt5q_k^2)`$ לשתי מנות עוקבות, אז מכך ש-$`\xi`$ בין $`p_k/q_k`$ ל-$`p_{k+1}/q_{k+1}`$ ו-$`|p_{k+1}/q_{k+1} - p_k/q_k| = 1/(q_kq_{k+1})`$, מקבלים $`\frac1{q_kq_{k+1} } \ge \frac1{\sqrt5}\left(\frac1{q_k^2} + \frac1{q_{k+1}^2}\right)`$, כלומר $`t + 1/t \le \sqrt5`$ עבור $`t = q_{k+1}/q_k`$, ומכאן $`t \lt \frac{1 + \sqrt5}2`$. אם זה קורה גם לזוג הבא, מקבלים מ-$`q_{k+2} = a_{k+2}q_{k+1} + q_k \ge q_{k+1} + q_k`$ ש-$`\frac{q_{k+2} }{q_{k+1} } \ge 1 + \frac{q_k}{q_{k+1} } \gt 1 + \frac2{1 + \sqrt5} = \frac{1 + \sqrt5}2`$ – סתירה.

**האופטימליות של $`\sqrt5`$.** יהי $`\varphi = \frac{1 + \sqrt5}2`$ ו-$`\varphi' = \frac{1 - \sqrt5}2`$, ונניח ש-$`\left|\varphi - \frac mn\right| \lt \frac1{An^2}`$ עם $`A \gt \sqrt5`$. נכתוב $`m = n\varphi + \frac\delta n`$ עם $`|\delta| \lt \frac1A`$. אז $`m - n\varphi' = n\sqrt5 + \frac\delta n`$, ולכן



```math
m^2 - mn - n^2 = (m - n\varphi)(m - n\varphi') = \frac\delta n\left(n\sqrt5 + \frac\delta n\right) = \delta\sqrt5 + \frac{\delta^2}{n^2}.
```

 אגף שמאל הוא מספר שלם שונה מאפס (כי $`\varphi`$ אי-רציונלי), ולכן $`\left|\delta\sqrt5 + \frac{\delta^2}{n^2}\right| \ge 1`$, כלומר $`|\delta| \ge \frac1{\sqrt5} - \frac{\delta^2}{\sqrt5n^2}`$. עבור $`n`$ גדול האגף הימני קרוב ל-$`\frac1{\sqrt5} \gt \frac1A`$, בסתירה ל-$`|\delta| \lt \frac1A`$. לכן יש רק מספר סופי של פתרונות.

## דוגמאות

נסמן $`c(p/q) = q^2\left|\xi - \frac pq\right|`$; משפט הורוויץ אומר ש-$`c \lt 1/\sqrt5 = 0.44721\ldots`$ לאינסוף $`p/q`$.

- **יחס הזהב.** המנות המתקרבות הן היחסים בין [מספרי פיבונאצ'י](https://he.wikipedia.org/wiki/%D7%9E%D7%A1%D7%A4%D7%A8_%D7%A4%D7%99%D7%91%D7%95%D7%A0%D7%90%D7%A6%27%D7%99) עוקבים, $`F_{k+1}/F_k`$, והערכים של $`c`$ הם

  
  
$`0.382,\ 0.472,\ 0.438,\ 0.451,\ 0.446,\ 0.448,\ 0.4470,\ 0.4473,\ 0.44718,\ 0.44722,\ 0.44721, \ldots`$

(עבור $`\frac21, \frac32, \frac53, \frac85, \ldots, \frac{233}{144}`$). הם מתכנסים ל-$`1/\sqrt5`$ לסירוגין מעל ומתחת – בדיוק הגבול שמשפט הורוויץ קובע, ולכן אי אפשר לשפר את הקבוע.

- **$`\sqrt2`$.** המנות המתקרבות $`\frac11, \frac32, \frac75, \frac{17}{12}, \frac{41}{29}, \ldots`$ נותנות $`c = 0.414, 0.343, 0.355, 0.3532, 0.3536, \ldots \to \frac1{2\sqrt2} = 0.35355\ldots`$. לכן עבור $`\sqrt2`$ אפשר לקחת אפילו קבוע $`\sqrt8`$ במקום $`\sqrt5`$ (אבל לא יותר).
- **$`\pi`$.** עבור המנות המתקרבות $`3, \frac{22}7, \frac{333}{106}, \frac{355}{113}, \frac{103993}{33102}, \frac{104348}{33215}`$, הערכים הם $`c = 0.142, 0.062, 0.935, 0.0034, 0.633, 0.366`$. בדיוק כפי שההוכחה מבטיחה, בכל שלוש עוקבות לפחות אחת מתחת ל-$`0.447`$. הערך הקטן $`0.0034`$ עבור $`\frac{355}{113}`$ נובע מהמנה החלקית הגדולה $`a_4 = 292`$ בשבר המשולב $`\pi = [3; 7, 15, 1, 292, \ldots]`$.

## ההמשך: ספקטרום לגראנז'

אם מוציאים את יחס הזהב ואת כל המספרים ה[שקולים](https://he.wikipedia.org/wiki/%D7%9E%D7%A1%D7%A4%D7%A8%D7%99%D7%9D_%D7%A9%D7%A7%D7%95%D7%9C%D7%99%D7%9D) לו (אלה שהשבר המשולב שלהם מסתיים ב-$`1, 1, 1, \ldots`$), אפשר להחליף את $`\sqrt5`$ ב-$`\sqrt8`$; אחרי הוצאה נוספת של המספרים השקולים ל-$`\sqrt2`$, אפשר להחליף ב-$`\sqrt{221}/5`$, וכן הלאה. הסדרה $`\sqrt5, \sqrt8, \sqrt{221}/5, \ldots`$ היא סדרת [מספרי לגראנז'](https://he.wikipedia.org/wiki/%D7%9E%D7%A1%D7%A4%D7%A8_%D7%9C%D7%92%D7%A8%D7%90%D7%A0%D7%96%27), $`L_n = \sqrt{9 - 4/m_n^2}`$, כאשר $`m_n`$ הם [מספרי מרקוב](%D7%9E%D7%A1%D7%A4%D7%A8%20%D7%9E%D7%A8%D7%A7%D7%95%D7%91.md), והיא מתכנסת ל-3.
