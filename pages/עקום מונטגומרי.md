# עקום מונטגומרי

ב[מתמטיקה](https://he.wikipedia.org/wiki/%D7%9E%D7%AA%D7%9E%D7%98%D7%99%D7%A7%D7%94), **עקום מונטגומרי** הוא צורה של [עקום אליפטי](https://he.wikipedia.org/wiki/%D7%A2%D7%A7%D7%95%D7%9D_%D7%90%D7%9C%D7%99%D7%A4%D7%98%D7%99) שהציג פיטר ל' מונטגומרי ב-1987,[^1] השונה מ[צורת ויירשטראס](https://he.wikipedia.org/wiki/%D7%A6%D7%95%D7%A8%D7%AA_%D7%95%D7%99%D7%99%D7%A8%D7%A9%D7%98%D7%A8%D7%90%D7%A1) הרגילה. הוא משמש לחישובים מסוימים, ובפרט ביישומים שונים של [קריפטוגרפיה](https://he.wikipedia.org/wiki/%D7%A7%D7%A8%D7%99%D7%A4%D7%98%D7%95%D7%92%D7%A8%D7%A4%D7%99%D7%94_%D7%A9%D7%9C_%D7%A2%D7%A7%D7%95%D7%9E%D7%99%D7%9D_%D7%90%D7%9C%D7%99%D7%A4%D7%98%D7%99%D7%99%D7%9D). מונטגומרי הציג אותו במקור כדי להאיץ את [שיטת העקומים האליפטיים לפירוק לגורמים](https://he.wikipedia.org/wiki/%D7%A9%D7%99%D7%98%D7%AA_%D7%94%D7%A2%D7%A7%D7%95%D7%9E%D7%99%D7%9D_%D7%94%D7%90%D7%9C%D7%99%D7%A4%D7%98%D7%99%D7%99%D7%9D_%D7%A9%D7%9C_%D7%9C%D7%A0%D7%A1%D7%98%D7%A8%D7%94); כיום הדוגמה המפורסמת ביותר היא [Curve25519](https://he.wikipedia.org/wiki/Curve25519).

## הגדרה

עקום מונטגומרי מעל [שדה](https://he.wikipedia.org/wiki/%D7%A9%D7%93%D7%94_%28%D7%9E%D7%91%D7%A0%D7%94_%D7%90%D7%9C%D7%92%D7%91%D7%A8%D7%99%29) $`K`$ מוגדר על ידי המשוואה



```math
M_{A,B}: By^2 = x^3 + Ax^2 + x
```

 עבור $`A, B \in K`$ כך ש-$`B(A^2 - 4) \ne 0`$.

בדרך כלל מתבוננים בעקום הזה מעל [שדה סופי](https://he.wikipedia.org/wiki/%D7%A9%D7%93%D7%94_%D7%A1%D7%95%D7%A4%D7%99) $`K`$ (למשל $`K = \mathbb F_q`$, שדה בן $`q`$ איברים) ש[המאפיין](https://he.wikipedia.org/wiki/%D7%9E%D7%90%D7%A4%D7%99%D7%99%D7%9F_%28%D7%90%D7%9C%D7%92%D7%91%D7%A8%D7%94%29) שלו שונה מ-2, עם $`A \ne \pm 2`$ ו-$`B \ne 0`$. מעל שדות כאלה, [סדר](https://he.wikipedia.org/wiki/%D7%A1%D7%93%D7%A8_%28%D7%AA%D7%95%D7%A8%D7%AA_%D7%94%D7%97%D7%91%D7%95%D7%A8%D7%95%D7%AA%29) החבורה של העקום מתחלק תמיד ב-4. מתבוננים בעקומי מונטגומרי גם מעל [המספרים הרציונליים](https://he.wikipedia.org/wiki/%D7%9E%D7%A1%D7%A4%D7%A8_%D7%A8%D7%A6%D7%99%D7%95%D7%A0%D7%9C%D7%99), עם אותן הגבלות על $`A`$ ו-$`B`$.

לכל עקום מונטגומרי יש את הנקודה $`(0, 0)`$, והיא נקודה מסדר 2 (המשיק בה אנכי).

### למה הסדר מתחלק ב-4

נקודות מסדר 2 הן הנקודות עם $`y = 0`$, כלומר $`x = 0`$ או $`x^2 + Ax + 1 = 0`$. מנוסחת ההכפלה שלהלן, $`x(2P) = \frac{(x^2-1)^2}{4x(x^2+Ax+1)}`$, ולכן $`2P = (0, 0)`$ אם ורק אם $`x(P) = \pm 1`$. הנקודות עם $`x = 1`$ קיימות מעל $`\mathbb F_q`$ אם ורק אם $`(A+2)/B`$ ריבוע, והנקודות עם $`x = -1`$ אם ורק אם $`(A-2)/B`$ ריבוע. אם $`A^2 - 4`$ ריבוע, ל-$`x^2 + Ax + 1`$ יש שורשים, וכל שלוש הנקודות מסדר 2 רציונליות – תת-חבורה מסדר 4. אחרת, המכפלה $`\frac{A+2}{B}\cdot\frac{A-2}{B} = \frac{A^2-4}{B^2}`$ אינה ריבוע, ולכן בדיוק אחד משני הגורמים ריבוע, ויש נקודה מסדר 4. בשני המקרים 4 מחלק את $`\#M_{A,B}(\mathbb F_q)`$.

**דוגמה.** העקום $`y^2 = x^3 + 3x^2 + x`$ מעל $`\mathbb F_{13}`$ ($`A = 3`$, $`B = 1`$). כאן $`A^2 - 4 = 5`$ אינו ריבוע מודולו 13, ולכן $`(0, 0)`$ היא הנקודה היחידה מסדר 2. לעומת זאת $`A - 2 = 1`$ ריבוע, והנקודות $`(-1, \pm 1) = (12, \pm 1)`$ הן מסדר 4. ספירה ישירה נותנת 16 נקודות (כולל הנקודה באינסוף), והחבורה [ציקלית](https://he.wikipedia.org/wiki/%D7%97%D7%91%D7%95%D7%A8%D7%94_%D7%A6%D7%99%D7%A7%D7%9C%D7%99%D7%AA): למשל $`P = (2, 3)`$ מסדר 16, ו-$`8P = (0, 0)`$.

## אריתמטיקה של מונטגומרי

אפשר לבצע "פעולות" בין [נקודות](https://he.wikipedia.org/wiki/%D7%A0%D7%A7%D7%95%D7%93%D7%94_%28%D7%92%D7%90%D7%95%D7%9E%D7%98%D7%A8%D7%99%D7%94%29) של עקום אליפטי: "חיבור" של שתי נקודות $`P, Q`$ פירושו מציאת נקודה שלישית $`R = P + Q`$; "הכפלה" של נקודה פירושה חישוב $`[2]P = P + P`$ (ראו [חוק החבורה](https://he.wikipedia.org/wiki/%D7%A2%D7%A7%D7%95%D7%9D_%D7%90%D7%9C%D7%99%D7%A4%D7%98%D7%99) ולהלן).

נקודה $`P = (x, y)`$ על עקום מונטגומרי $`By^2 = x^3 + Ax^2 + x`$ אפשר לייצג ב**קואורדינטות מונטגומרי** $`P = (X : Z)`$, שהן [קואורדינטות פרויקטיביות](https://he.wikipedia.org/wiki/%D7%9E%D7%A8%D7%97%D7%91_%D7%A4%D7%A8%D7%95%D7%99%D7%A7%D7%98%D7%99%D7%91%D7%99) עם $`x = X/Z`$ כאשר $`Z \ne 0`$.

הייצוג הזה מאבד מידע: אין בו הבחנה בין הנקודות ה[אפיניות](https://he.wikipedia.org/wiki/%D7%9E%D7%A8%D7%97%D7%91_%D7%90%D7%A4%D7%99%D7%A0%D7%99) $`(x, y)`$ ו-$`(x, -y)`$, כי שתיהן מיוצגות על ידי אותה $`(X : Z)`$. בכל זאת, אפשר לחשב בעזרתו כפולות של נקודות: בהינתן $`P = (X : Z)`$, לחשב $`[n]P = (X_n : Z_n)`$. המחיר הוא שאי אפשר לחבר שתי נקודות כלליות לפי ה-$`x`$ שלהן בלבד (ל-$`x(P+Q)`$ ול-$`x(P-Q)`$ אותו מידע התחלתי), ולכן חיבור דורש לדעת גם את ההפרש – "חיבור דיפרנציאלי".

נתבונן בשתי הנקודות $`P_n = [n]P = (X_n : Z_n)`$ ו-$`P_m = [m]P = (X_m : Z_m)`$. הסכום שלהן הוא $`P_{m+n} = P_m + P_n = (X_{m+n} : Z_{m+n})`$, עם



```math
X_{m+n} = Z_{m-n}\bigl((X_m - Z_m)(X_n + Z_n) + (X_m + Z_m)(X_n - Z_n)\bigr)^2,
```





```math
Z_{m+n} = X_{m-n}\bigl((X_m - Z_m)(X_n + Z_n) - (X_m + Z_m)(X_n - Z_n)\bigr)^2.
```



אם $`m = n`$, הפעולה היא הכפלה, והקואורדינטות של $`[2]P_n = P_{2n} = (X_{2n} : Z_{2n})`$ נתונות על ידי



```math
4X_nZ_n = (X_n + Z_n)^2 - (X_n - Z_n)^2,
```





```math
X_{2n} = (X_n + Z_n)^2(X_n - Z_n)^2,
```





```math
Z_{2n} = (4X_nZ_n)\left((X_n - Z_n)^2 + \frac{A+2}{4}(4X_nZ_n)\right).
```



הפעולה הראשונה (חיבור דיפרנציאלי) עולה $`4\mathbf M + 2\mathbf S`$, ו-$`3\mathbf M + 2\mathbf S`$ כאשר $`Z_{m-n} = 1`$, כמו בסולם מונטגומרי עם נקודת בסיס מנורמלת;[^2] כאן $`\mathbf M`$ מסמן כפל של שני איברים כלליים בשדה שמעליו מוגדר העקום, ו-$`\mathbf S`$ מסמן העלאה בריבוע של איבר כללי.

הפעולה השנייה (הכפלה) עולה $`2\mathbf M + 2\mathbf S + 1\mathbf D`$, כאשר $`\mathbf D`$ מסמן כפל של איבר כללי בקבוע. הקבוע הוא $`(A+2)/4`$, ולכן אפשר לבחור את $`A`$ כך ש-$`\mathbf D`$ יהיה זול. למשל, ב-Curve25519 $`A = 486662`$ ו-$`(A+2)/4 = 121666`$, מספר קטן.

שתי הנוסחאות יחד הן הבסיס ל[סולם מונטגומרי](%D7%9B%D7%A4%D7%9C%20%D7%A1%D7%A7%D7%9C%D7%A8%D7%99%20%D7%A2%D7%9C%20%D7%A2%D7%A7%D7%95%D7%9D%20%D7%90%D7%9C%D7%99%D7%A4%D7%98%D7%99.md): שומרים את הזוג $`(P_k, P_{k+1})`$, שההפרש ביניהם תמיד $`P`$, ובכל צעד מחשבים $`(P_{2k}, P_{2k+1})`$ או $`(P_{2k+1}, P_{2k+2})`$ בהכפלה אחת וחיבור דיפרנציאלי אחד.

### אלגוריתם ודוגמה

האלגוריתם הבא מכפיל נקודה $`P_1 = (X_1 : Z_1)`$ על עקום מונטגומרי, בהנחה ש-$`Z_1 = 1`$. עלותו $`1\mathbf M + 2\mathbf S`$, כפל אחד ב-$`A`$, שלוש פעולות חיבור וכפל אחד ב-4:



```math
XX_1 = X_1^2,
```





```math
X_2 = (XX_1 - 1)^2,
```





```math
Z_2 = 4X_1(XX_1 + AX_1 + 1).
```



**דוגמה מעל הממשיים.** תהי $`P_1 = (2, \sqrt 3)`$ נקודה על העקום $`2y^2 = x^3 - x^2 + x`$ ($`A = -1`$, $`B = 2`$; אכן $`8 - 4 + 2 = 6 = 2\cdot 3`$). בקואורדינטות $`(X_1 : Z_1)`$, $`P_1 = (2 : 1)`$, ואז



```math
XX_1 = 4, \qquad X_2 = (4-1)^2 = 9, \qquad Z_2 = 4\cdot 2\cdot(4 - 2 + 1) = 24.
```

 התוצאה היא $`P_2 = (9 : 24)`$, כלומר $`x(2P_1) = 3/8`$; הנוסחה האפינית שלהלן נותנת אותו ערך.

**דוגמה מעל $`\mathbb F_{13}`$.** על $`y^2 = x^3 + 3x^2 + x`$, עם $`P = (2, 3)`$:

- הכפלה: $`X_2 = (4-1)^2 = 9`$, $`Z_2 = 4\cdot 2\cdot(4 + 6 + 1) = 88 \equiv 10`$, ולכן $`x(2P) = 9\cdot 10^{-1} = 9\cdot 4 \equiv 10 \pmod{13}`$.
- חיבור דיפרנציאלי של $`2P = (9 : 10)`$ ו-$`P = (2 : 1)`$, עם ההפרש $`P = (2 : 1)`$: $`(X_m - Z_m)(X_n + Z_n) + (X_m + Z_m)(X_n - Z_n) = (-1)(3) + 19\cdot 1 = 16`$, וההפרש שלהם הוא $`-22`$; לכן $`X_3 = 1\cdot 16^2 \equiv 9`$ ו-$`Z_3 = 2\cdot 22^2 \equiv 6`$, ו-$`x(3P) = 9\cdot 6^{-1} \equiv 8 \pmod{13}`$.

ואכן, בחישוב אפיני מלא $`2P = (10, 7)`$ ו-$`3P = (8, 7)`$.

## חיבור

בהינתן שתי נקודות $`P_1 = (x_1, y_1)`$, $`P_2 = (x_2, y_2)`$ על עקום מונטגומרי $`M_{A,B}`$ בקואורדינטות אפיניות, הנקודה $`P_3 = P_1 + P_2`$ מתקבלת [גאומטרית](https://he.wikipedia.org/wiki/%D7%92%D7%90%D7%95%D7%9E%D7%98%D7%A8%D7%99%D7%94) מנקודת החיתוך השלישית של $`M_{A,B}`$ עם הישר דרך $`P_1`$ ו-$`P_2`$. את הקואורדינטות $`(x_3, y_3)`$ של $`P_3`$ מוצאים כך:

1.  מתבוננים בישר כללי $`y = lx + m`$ ודורשים שיעבור דרך $`P_1`$ ו-$`P_2`$. מקבלים $`l = \frac{y_2 - y_1}{x_2 - x_1}`$ ו-$`m = y_1 - lx_1`$.
2.  חותכים את הישר עם העקום: מציבים $`y = lx + m`$ במשוואת העקום ומקבלים [משוואה ממעלה שלישית](https://he.wikipedia.org/wiki/%D7%9E%D7%A9%D7%95%D7%95%D7%90%D7%94_%D7%9E%D7%9E%D7%A2%D7%9C%D7%94_%D7%A9%D7%9C%D7%99%D7%A9%D7%99%D7%AA)
    

    ```math
    x^3 + (A - Bl^2)x^2 + (1 - 2Blm)x - Bm^2 = 0.
    ```



      
    למשוואה הזו שלושה פתרונות, שהם קואורדינטות ה-$`x`$ של $`P_1`$, $`P_2`$ ונקודת החיתוך השלישית. לכן אפשר לכתוב אותה כ-$`(x - x_1)(x - x_2)(x - x_3) = 0`$.
3.  השוואת המקדמים של $`x^2`$ נותנת $`-x_1 - x_2 - x_3 = A - Bl^2`$, ולכן
    

    ```math
    x_3 = B\left(\frac{y_2 - y_1}{x_2 - x_1}\right)^2 - A - x_1 - x_2.
    ```


4.  כדי למצוא את קואורדינטת ה-$`y`$ מציבים את $`x_3`$ במשוואת הישר. זה לא נותן את $`P_3`$ ישירות, אלא את הנקודה $`R`$ שמקיימת $`R + P_1 + P_2 = P_\infty`$. כיוון ש-$`R + P_1 + P_2 = P_\infty`$ [אם ורק אם](https://he.wikipedia.org/wiki/%D7%90%D7%9D_%D7%95%D7%A8%D7%A7_%D7%90%D7%9D) $`-R = P_1 + P_2`$, צריך להפוך את הסימן של קואורדינטת ה-$`y`$ של $`R`$.

לסיכום, הקואורדינטות של $`P_3 = P_1 + P_2`$ הן



```math
x_3 = \frac{B(y_2 - y_1)^2}{(x_2 - x_1)^2} - A - x_1 - x_2,
```





```math
y_3 = \frac{(2x_1 + x_2 + A)(y_2 - y_1)}{x_2 - x_1} - \frac{B(y_2 - y_1)^3}{(x_2 - x_1)^3} - y_1.
```



## הכפלה

בהינתן נקודה $`P_1`$ על $`M_{A,B}`$, הנקודה $`[2]P_1`$ מתקבלת גאומטרית מנקודת החיתוך השלישית של העקום עם המשיק ב-$`P_1`$. לכן אפשר לפעול כמו בנוסחת החיבור, אבל עכשיו הישר $`y = lx + m`$ משיק לעקום ב-$`P_1`$. אם $`M_{A,B}: f(x, y) = 0`$ עם



```math
f(x, y) = x^3 + Ax^2 + x - By^2,
```

 אז השיפוע נתון, לפי [משפט הפונקציה הסתומה](https://he.wikipedia.org/wiki/%D7%9E%D7%A9%D7%A4%D7%98_%D7%94%D7%A4%D7%95%D7%A0%D7%A7%D7%A6%D7%99%D7%94_%D7%94%D7%A1%D7%AA%D7%95%D7%9E%D7%94), על ידי



```math
l = -\frac{\partial f/\partial x}{\partial f/\partial y} = \frac{3x_1^2 + 2Ax_1 + 1}{2By_1},
```

 והקואורדינטות של $`P_3 = 2P_1`$ הן



```math
x_3 = Bl^2 - A - 2x_1 = \frac{B(3x_1^2 + 2Ax_1 + 1)^2}{(2By_1)^2} - A - 2x_1,
```





```math
y_3 = (3x_1 + A)l - Bl^3 - y_1.
```

 כשמצמצמים את הביטוי ל-$`x_3`$ בעזרת משוואת העקום מקבלים את הנוסחה הפרויקטיבית שלמעלה: $`x_3 = \frac{(x_1^2 - 1)^2}{4x_1(x_1^2 + Ax_1 + 1)}`$.

## שקילות לעקומי אדוארדס מסובבים

יהי $`K`$ שדה ממאפיין שונה מ-2, ויהי $`M_{A,B}`$ עקום אליפטי בצורת מונטגומרי



```math
M_{A,B}: Bv^2 = u^3 + Au^2 + u
```

 עם $`A \in K \setminus \{-2, 2\}`$, $`B \in K \setminus \{0\}`$, ויהי $`E_{a,d}`$ עקום אליפטי בצורת [אדוארדס מסובב](%D7%A2%D7%A7%D7%95%D7%9D%20%D7%90%D7%93%D7%95%D7%90%D7%A8%D7%93%D7%A1.md):



```math
E_{a,d}: ax^2 + y^2 = 1 + dx^2y^2,
```

 עם $`a, d \in K \setminus \{0\}`$, $`a \ne d`$.

המשפט הבא מראה שעקומי מונטגומרי ועקומי אדוארדס מסובבים [שקולים בירציונלית](https://he.wikipedia.org/wiki/%D7%92%D7%90%D7%95%D7%9E%D7%98%D7%A8%D7%99%D7%94_%D7%91%D7%99%D7%A8%D7%A6%D7%99%D7%95%D7%A0%D7%9C%D7%99%D7%AA):[^3]

**משפט.** כל עקום אדוארדס מסובב שקול בירציונלית לעקום מונטגומרי מעל $`K`$. בפרט, העקום $`E_{a,d}`$ שקול בירציונלית לעקום $`M_{A,B}`$ עם



```math
A = \frac{2(a+d)}{a-d}, \qquad B = \frac{4}{a-d}.
```

 ההעתקה



```math
\psi: E_{a,d} \to M_{A,B}, \qquad (x, y) \mapsto (u, v) = \left(\frac{1+y}{1-y}, \frac{1+y}{(1-y)x}\right)
```

 היא שקילות בירציונלית, וההפכית שלה היא



```math
\psi^{-1}: M_{A,B} \to E_{a,d}, \qquad (u, v) \mapsto (x, y) = \left(\frac uv, \frac{u-1}{u+1}\right), \qquad a = \frac{A+2}{B},\ d = \frac{A-2}{B}.
```



השקילות אינה מוגדרת בכל מקום: ההעתקה $`\psi^{-1}`$ אינה מוגדרת בנקודות של $`M_{A,B}`$ שבהן $`v = 0`$ או $`u + 1 = 0`$.[^4] השקילות היא גם [הומומורפיזם](https://he.wikipedia.org/wiki/%D7%94%D7%95%D7%9E%D7%95%D7%9E%D7%95%D7%A8%D7%A4%D7%99%D7%96%D7%9D) של חבורות, ולכן אפשר לעבור בין הצורות לפי הצורך: למשל, Curve25519 שקול לעקום האדוארדס המסובב שעליו בנויה מערכת החתימות Ed25519.

**דוגמה.** עבור העקום $`y^2 = x^3 + 3x^2 + x`$ מעל $`\mathbb F_{13}`$: $`a = (3+2)/1 = 5`$, $`d = (3-2)/1 = 1`$, והנקודה $`(u, v) = (2, 3)`$ עוברת ל-$`(x, y) = (2\cdot 3^{-1}, 1\cdot 3^{-1}) = (5, 9)`$. אכן $`5\cdot 5^2 + 9^2 = 206 \equiv 11`$ ו-$`1 + 5^2\cdot 9^2 = 2026 \equiv 11 \pmod{13}`$.

## שקילות לעקומי ויירשטראס

כל עקום אליפטי אפשר לכתוב בצורת ויירשטראס. בפרט, את העקום בצורת מונטגומרי



```math
M_{A,B}: By^2 = x^3 + Ax^2 + x
```

 אפשר להעביר כך: מחלקים כל איבר במשוואה ב-$`B^3`$, ומציבים $`u = x/B`$, $`v = y/B`$. מקבלים



```math
v^2 = u^3 + \frac AB u^2 + \frac{1}{B^2}u.
```

 כדי לקבל צורת ויירשטראס קצרה, מחליפים את $`u`$ ב-$`t - \frac{A}{3B}`$, ומקבלים



```math
v^2 = t^3 + \left(\frac{3 - A^2}{3B^2}\right)t + \left(\frac{2A^3 - 9A}{27B^3}\right).
```

 לכן ההעתקה היא



```math
\psi: M_{A,B} \to E_{a,b}, \qquad (x, y) \mapsto (t, v) = \left(\frac xB + \frac{A}{3B}, \frac yB\right), \qquad a = \frac{3 - A^2}{3B^2},\ b = \frac{2A^3 - 9A}{27B^3}.
```

 (כאן $`a, b`$ הם מקדמי ויירשטראס, ולא מקדמי אדוארדס מהסעיף הקודם; ההעברה דורשת גם שהמאפיין יהיה שונה מ-3.)

בכיוון ההפוך, עקום אליפטי מעל שדה $`\mathbb F`$ בצורת ויירשטראס



```math
E_{a,b}: v^2 = t^3 + at + b
```

 אפשר להעביר לצורת מונטגומרי אם ורק אם מתקיימים שני התנאים:[^5]

1.  למשוואה $`z^3 + az + b = 0`$ יש לפחות שורש אחד $`\alpha \in \mathbb F`$ (כלומר יש נקודה רציונלית מסדר 2);
2.  $`3\alpha^2 + a`$ הוא [שארית ריבועית](https://he.wikipedia.org/wiki/%D7%A9%D7%90%D7%A8%D7%99%D7%AA_%D7%A8%D7%99%D7%91%D7%95%D7%A2%D7%99%D7%AA) ב-$`\mathbb F`$.

כאשר התנאים מתקיימים, עבור $`s = \left(\sqrt{3\alpha^2 + a}\right)^{-1}`$ ההעתקה היא



```math
\psi^{-1}: E_{a,b} \to M_{A,B}, \qquad (t, v) \mapsto (x, y) = \bigl(s(t - \alpha), sv\bigr), \qquad A = 3\alpha s,\ B = s.
```



**דוגמה.** העקום $`y^2 = x^3 + 3x^2 + x`$ מעל $`\mathbb F_{13}`$ עובר לעקום $`v^2 = t^3 + 11t + 1`$, והנקודה $`(2, 3)`$ עוברת ל-$`(t, v) = (2 + 3\cdot 3^{-1}, 3) = (3, 3)`$: אכן $`3^3 + 11\cdot 3 + 1 = 61 \equiv 9 = 3^2 \pmod{13}`$.

בפרט, עקום בצורת ויירשטראס שסדר החבורה שלו אי-זוגי (למשל עקום מסדר ראשוני, כמו העקומים של NIST) אינו ניתן להעברה לצורת מונטגומרי, כי אין לו נקודה מסדר 2.
