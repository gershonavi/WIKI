# מספר קאלן

ב[מתמטיקה](https://he.wikipedia.org/wiki/%D7%9E%D7%AA%D7%9E%D7%98%D7%99%D7%A7%D7%94), **מספר קאלן** הוא איבר ב[סדרת השלמים](https://he.wikipedia.org/wiki/%D7%A1%D7%93%D7%A8%D7%94_%28%D7%9E%D7%AA%D7%9E%D7%98%D7%99%D7%A7%D7%94%29) $`C_n = n \cdot 2^n + 1`$ (כאשר $`n`$ [מספר טבעי](https://he.wikipedia.org/wiki/%D7%9E%D7%A1%D7%A4%D7%A8_%D7%98%D7%91%D7%A2%D7%99)). מספרי קאלן נחקרו לראשונה על ידי המתמטיקאי האירי ג'יימס קאלן ב-1905. הם מקרים פרטיים של [מספרי פרות'](https://he.wikipedia.org/wiki/%D7%9E%D7%A1%D7%A4%D7%A8_%D7%A4%D7%A8%D7%95%D7%AA%27). המספרים הראשונים הם $`C_1 = 3`$, $`C_2 = 9`$, $`C_3 = 25`$, $`C_4 = 65`$, $`C_5 = 161`$, $`C_6 = 385`$, ....

## תכונות

ב-1976 הראה [כריסטופר הולי](https://he.wikipedia.org/wiki/%D7%9B%D7%A8%D7%99%D7%A1%D7%98%D7%95%D7%A4%D7%A8_%D7%94%D7%95%D7%9C%D7%99) שה[צפיפות הטבעית](https://he.wikipedia.org/wiki/%D7%A6%D7%A4%D7%99%D7%A4%D7%95%D7%AA_%D7%98%D7%91%D7%A2%D7%99%D7%AA) של השלמים החיוביים $`n \leq x`$ שעבורם $`C_n`$ [ראשוני](https://he.wikipedia.org/wiki/%D7%9E%D7%A1%D7%A4%D7%A8_%D7%A8%D7%90%D7%A9%D7%95%D7%A0%D7%99) היא מסדר $`o(x)`$ כש-$`x \to \infty`$. במובן הזה, [כמעט כל](https://he.wikipedia.org/wiki/%D7%9B%D7%9E%D7%A2%D7%98_%D7%9B%D7%9C) מספרי קאלן [פריקים](https://he.wikipedia.org/wiki/%D7%9E%D7%A1%D7%A4%D7%A8_%D7%A4%D7%A8%D7%99%D7%A7).[^1] את ההוכחה של הולי עיבד הירומי סויאמה כדי להראות שהיא עובדת לכל סדרה של מספרים $`n\cdot2^{n + a} + b`$, כאשר $`a`$ ו-$`b`$ שלמים, ובפרט גם ל[מספרי וודול](%D7%9E%D7%A1%D7%A4%D7%A8%20%D7%95%D7%95%D7%93%D7%95%D7%9C.md). **ראשוני קאלן** הידועים היחידים, שישה עשר בסך הכל, הם אלה עבור $`n`$ השווה ל-

  
1, 141, 4713, 5795, 6611, 18496, 32292, 32469, 59656, 90825, 262419, 361275, 481899, 1354828, 6328548, 6679881 ((סדרה [A005849](https://oeis.org/A005849) ב-OEIS)).

(בדקנו שעבור $`n \lt 1000`$ הערכים היחידים הם 1 ו-141.) בכל זאת, משערים שיש אינסוף ראשוני קאלן.

מספר קאלן $`C_n`$ [מתחלק](https://he.wikipedia.org/wiki/%D7%94%D7%AA%D7%97%D7%9C%D7%A7%D7%95%D7%AA) ב-$`p = 2n - 1`$ אם $`p`$ מספר ראשוני מהצורה $`8k - 3`$; למשל, $`C_3 = 25`$ מתחלק ב-$`5`$, ו-$`C_7 = 897 = 3\cdot13\cdot23`$ מתחלק ב-13. יתרה מזו, מ[המשפט הקטן של פרמה](https://he.wikipedia.org/wiki/%D7%94%D7%9E%D7%A9%D7%A4%D7%98_%D7%94%D7%A7%D7%98%D7%9F_%D7%A9%D7%9C_%D7%A4%D7%A8%D7%9E%D7%94) נובע שאם $`p`$ ראשוני [אי-זוגי](https://he.wikipedia.org/wiki/%D7%9E%D7%A1%D7%A4%D7%A8_%D7%90%D7%99-%D7%96%D7%95%D7%92%D7%99), אז $`p`$ מחלק את $`C_{m(k)}`$ לכל $`m(k) = (2^k - k)(p - 1) - k`$ (עבור $`k \gt 0`$). הוכח גם שהראשוני $`p`$ מחלק את $`C_{(p + 1)/2}`$ כש[סמל יעקובי](https://he.wikipedia.org/wiki/%D7%A1%D7%9E%D7%9C_%D7%99%D7%A2%D7%A7%D7%95%D7%91%D7%99) $`\left(\tfrac 2p\right)`$ הוא $`-1`$, ומחלק את $`C_{(3p - 1)/2}`$ כשסמל יעקובי $`\left(\tfrac2p\right)`$ הוא $`+1`$. (את כל טענות ההתחלקות האלה בדקנו לכל הראשוניים $`p \lt 5000`$.)

*הוכחה של הטענה על $`m(k)`$:* לפי פרמה, $`2^{p-1} \equiv 1 \pmod p`$, ולכן $`2^{m(k)} \equiv 2^{-k}`$, ו-$`m(k) \equiv (2^k - k)\cdot(-1) - k = -2^k \pmod p`$. לכן $`m(k)\cdot 2^{m(k)} \equiv -2^k\cdot2^{-k} = -1`$, כלומר $`C_{m(k)} \equiv 0 \pmod p`$.

לא ידוע אם יש מספר ראשוני $`p`$ כך שגם $`C_p`$ ראשוני.

$`C_n`$ מקיים את [נוסחת הנסיגה](https://he.wikipedia.org/wiki/%D7%A0%D7%95%D7%A1%D7%97%D7%AA_%D7%A0%D7%A1%D7%99%D7%92%D7%94)



```math
C_n=4(C_{n-1}-C_{n-2})+1.
```

 (למשל, $`4(25 - 9) + 1 = 65 = C_4`$.)

## הכללות

לפעמים מגדירים **מספר קאלן מוכלל בבסיס $`b`$** כמספר מהצורה $`n\cdot b^n + 1`$, כאשר $`n + 2 \gt b`$; אם ראשוני ניתן לכתיבה בצורה הזו, הוא נקרא **ראשוני קאלן מוכלל**. [מספרי וודול](%D7%9E%D7%A1%D7%A4%D7%A8%20%D7%95%D7%95%D7%93%D7%95%D7%9C.md) נקראים לפעמים **מספרי קאלן מהסוג השני**.[^2]

נכון לאפריל 2025, ראשוני קאלן המוכלל הגדול ביותר הידוע הוא $`4052186\cdot69^{4052186} + 1`$. יש בו 7,451,366 ספרות, והוא התגלה על ידי משתתף בפרויקט [PrimeGrid](https://he.wikipedia.org/wiki/PrimeGrid).[^3]

לפי המשפט הקטן של פרמה, אם יש ראשוני $`p`$ כך ש-$`n`$ מתחלק ב-$`p - 1`$ ו-$`n + 1`$ מתחלק ב-$`p`$ (בפרט, כש-$`n = p - 1`$), ו-$`p`$ אינו מחלק את $`b`$, אז $`b^n \equiv 1 \pmod p`$ (כי $`b^n`$ הוא חזקה של $`b^{p - 1}`$, ו-$`b^{p - 1} \equiv 1 \pmod p`$). לכן $`n\cdot b^n + 1 \equiv n + 1 \equiv 0 \pmod p`$, והמספר אינו ראשוני. למשל, אם עבור $`n \equiv 2 \pmod 6`$ כלשהו (כלומר 2, 8, 14, 20, 26, 32, ...) המספר $`n\cdot b^n + 1`$ ראשוני, אז $`b`$ חייב להתחלק ב-3 (מלבד $`b = 1`$).

ה-$`n`$ הקטן ביותר שעבורו $`n\cdot b^n + 1`$ ראשוני (בלי התנאי $`n + 2 \gt b`$; סימן שאלה אם הערך אינו ידוע כרגע) הוא, עבור $`b = 1, 2, 3, \ldots`$:[^4]
