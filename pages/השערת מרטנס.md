# השערת מרטנס

<img src="https://commons.wikimedia.org/wiki/Special:FilePath/Congettura_Mertens.png" alt="הגרף מציג את פונקציית מרטנס <math>M(n)</math> ואת השורשים <math>\pm \sqrt{n}</math> עבור <math>n \le 10{,}000</math>. לאחר שחישב ערכים אלה שיער מרטנס שהערך המוחלט של <math>M(n)</math> חסום תמיד על ידי <math>\sqrt{n}</math>." width="320">

ב[מתמטיקה](https://he.wikipedia.org/wiki/%D7%9E%D7%AA%D7%9E%D7%98%D7%99%D7%A7%D7%94), **השערת מרטנס** היא הטענה ש[פונקציית מרטנס](%D7%A4%D7%95%D7%A0%D7%A7%D7%A6%D7%99%D7%99%D7%AA%20%D7%9E%D7%A8%D7%98%D7%A0%D7%A1.md) $`M(n)`$ חסומה בין $`-\sqrt{n}`$ ל-$`\sqrt{n}`$. ההשערה הופרכה, אך עוד קודם לכן הוכח שנכונותה הייתה גוררת את [השערת רימן](https://he.wikipedia.org/wiki/%D7%94%D7%A9%D7%A2%D7%A8%D7%AA_%D7%A8%D7%99%D7%9E%D7%9F). את ההשערה העלה תומאס סטילטיס במכתב ששלח אל [שארל הרמיט](https://he.wikipedia.org/wiki/%D7%A9%D7%90%D7%A8%D7%9C_%D7%94%D7%A8%D7%9E%D7%99%D7%98) בשנת 1885 (ושנדפס בשנת 1905), ולאחר מכן העלה אותה בדפוס [פרנץ מרטנס](%D7%A4%D7%A8%D7%A0%D7%A5%20%D7%9E%D7%A8%D7%98%D7%A0%D7%A1.md) בשנת 1897. [אנדרו אודליצקו](https://he.wikipedia.org/wiki/%D7%90%D7%A0%D7%93%D7%A8%D7%95_%D7%90%D7%95%D7%93%D7%9C%D7%99%D7%A6%D7%A7%D7%95) ו[הרמן טה רילה](%D7%94%D7%A8%D7%9E%D7%9F%20%D7%98%D7%94%20%D7%A8%D7%99%D7%9C%D7%94.md) הפריכו אותה בשנת 1985. זוהי דוגמה בולטת להשערה מתמטית שהופרכה למרות ראיות חישוביות רבות שתמכו בה.

## הגדרה

ב[תורת המספרים](https://he.wikipedia.org/wiki/%D7%AA%D7%95%D7%A8%D7%AA_%D7%94%D7%9E%D7%A1%D7%A4%D7%A8%D7%99%D7%9D), פונקציית מרטנס מוגדרת על ידי



```math
M(n) = \sum_{1 \le k \le n} \mu(k),
```

 כאשר $`\mu(k)`$ היא [פונקציית מביוס](https://he.wikipedia.org/wiki/%D7%A4%D7%95%D7%A0%D7%A7%D7%A6%D7%99%D7%99%D7%AA_%D7%9E%D7%91%D7%99%D7%95%D7%A1). השערת מרטנס קובעת שלכל $`n > 1`$ מתקיים



```math
|M(n)| < \sqrt{n}.
```



## הפרכת ההשערה

סטילטיס טען ב-1885 שהוכיח תוצאה חלשה יותר, שלפיה $`m(n) := M(n)/\sqrt{n}`$ היא [פונקציה חסומה](https://he.wikipedia.org/wiki/%D7%A4%D7%95%D7%A0%D7%A7%D7%A6%D7%99%D7%94_%D7%97%D7%A1%D7%95%D7%9E%D7%94), אך לא פרסם הוכחה.[^1] במונחי $`m(n)`$, השערת מרטנס היא ש-$`-1 < m(n) < 1`$.

ב-1985 הוכיחו אודליצקו וטה רילה שהשערת מרטנס שגויה, בעזרת אלגוריתם LLL (לנסטרה–לנסטרה–לובאס) לצמצום בסיס של סריג:[^2][^3]



```math
\liminf m(n) < -1.009
```

 ו-$`\limsup m(n) > 1.06`$. מאוחר יותר הוכח שה[דוגמה הנגדית](https://he.wikipedia.org/wiki/%D7%93%D7%95%D7%92%D7%9E%D7%94_%D7%A0%D7%92%D7%93%D7%99%D7%AA) הראשונה נמצאת מתחת ל-$`e^{3.21\times10^{64} } \approx 10^{1.39\times10^{64} }`$[^4] אך מעל $`10^{16}`$.[^5] החסם העליון הורד מאז ל-$`e^{1.59\times10^{40} }`$,[^6] כלומר בערך $`10^{6.91\times10^{39} }`$, ולאחר מכן ל-$`e^{1.017\times10^{29} } \approx 10^{4.416\times10^{28} }`$.[^7] ב-2024 הורידו סונגקי קים ופונג נגויאן את החסם ל-$`e^{1.96\times10^{19} } \approx 10^{8.512\times10^{18} }`$,[^8] אך לא ידועה אף דוגמה נגדית מפורשת.

לפי חוק הלוגריתם האיטרטיבי, אם מחליפים את $`\mu`$ בסדרה אקראית של הערכים $`+1`$ ו-$`-1`$, סדר הגודל של [הסכום החלקי](https://he.wikipedia.org/wiki/%D7%98%D7%95%D7%A8_%28%D7%9E%D7%AA%D7%9E%D7%98%D7%99%D7%A7%D7%94%29) של $`n`$ האיברים הראשונים הוא (בהסתברות 1) בערך $`\sqrt{n \log\log n}`$. מכאן עולה שסדר הגודל של $`m(n)`$ עשוי להיות בסביבות $`\sqrt{\log\log n}`$. ייתכן שסדר הגודל האמיתי קטן מעט יותר: בתחילת שנות ה-90 שיער סטיב גונק שסדר הגודל של $`m(n)`$ הוא $`(\log\log\log n)^{5/4}`$. נייתן אנג (Nathan Ng) תמך בכך ב-2004 בטיעון היוריסטי, המניח את השערת רימן והשערות מסוימות על ההתנהגות הממוצעת של אפסי [פונקציית זטא של רימן](https://he.wikipedia.org/wiki/%D7%A4%D7%95%D7%A0%D7%A7%D7%A6%D7%99%D7%99%D7%AA_%D7%96%D7%98%D7%90_%D7%A9%D7%9C_%D7%A8%D7%99%D7%9E%D7%9F).[^9]

ב-1979 מצאו כהן ודרס[^10] את הערך הגדול ביותר הידוע של $`m(n)`$, בערך 0.570591, עבור $`M(7766842813) = 50286`$. ב-2011 מצא קוזנצוב את הערך השלילי הגדול ביותר הידוע (ב[ערך מוחלט](https://he.wikipedia.org/wiki/%D7%A2%D7%A8%D7%9A_%D7%9E%D7%95%D7%97%D7%9C%D7%98)), $`m(n) \approx -0.585768`$, עבור $`M(11609864264058592345) = -1995900927`$.[^11] ב-2016 חישב הרסט את $`M(n)`$ לכל $`n \le 10^{16}`$, ולא מצא ערכים גדולים יותר של $`m(n)`$.[^12]

ב-2006 שיפרו קוטניק וטה רילה את החסם העליון והראו שיש אינסוף ערכים של $`n`$ שעבורם $`m(n) > 1.2184`$, אך בלי לתת ערך מסוים של $`n`$ כזה.[^13] ב-2016 השיג הרסט שיפור נוסף והראה שמתקיים



```math
\liminf m(n) < -1.837625
```

 ו-$`\limsup m(n) > 1.826054`$.

## הקשר להשערת רימן

הקשר להשערת רימן מבוסס על [טור דיריכלה](https://he.wikipedia.org/wiki/%D7%98%D7%95%D7%A8_%D7%93%D7%99%D7%A8%D7%99%D7%9B%D7%9C%D7%94) של ההופכי של פונקציית זטא של רימן,



```math
\frac{1}{\zeta(s)} = \sum_{n=1}^\infty \frac{\mu(n)}{n^s},
```

 התקף בתחום $`\mathrm{Re}(s) > 1`$. אפשר לכתוב אותו כ[אינטגרל סטילטיס](https://he.wikipedia.org/wiki/%D7%90%D7%99%D7%A0%D7%98%D7%92%D7%A8%D7%9C_%D7%A8%D7%99%D7%9E%D7%9F-%D7%A1%D7%98%D7%99%D7%9C%D7%98%D7%99%D7%A1)



```math
\frac{1}{\zeta(s)} = \int_0^\infty x^{-s}\, dM(x),
```

 ולאחר [אינטגרציה בחלקים](https://he.wikipedia.org/wiki/%D7%90%D7%99%D7%A0%D7%98%D7%92%D7%A8%D7%A6%D7%99%D7%94_%D7%91%D7%97%D7%9C%D7%A7%D7%99%D7%9D) מתקבל ההופכי של פונקציית זטא כ[התמרת מלין](%D7%94%D7%AA%D7%9E%D7%A8%D7%AA%20%D7%9E%D7%9C%D7%99%D7%9F.md):



```math
\frac{1}{s \zeta(s)} = \left\{ \mathcal{M} M \right\}(-s) = \int_0^\infty x^{-s} M(x)\, \frac{dx}{x}.
```

 בעזרת [משפט ההיפוך של מלין](%D7%9E%D7%A9%D7%A4%D7%98%20%D7%94%D7%94%D7%99%D7%A4%D7%95%D7%9A%20%D7%A9%D7%9C%20%D7%9E%D7%9C%D7%99%D7%9F.md) אפשר לבטא את $`M`$ באמצעות $`1/\zeta`$:



```math
M(x) = \frac{1}{2 \pi i} \int_{\sigma-i\infty}^{\sigma+i\infty} \frac{x^s}{s \zeta(s)}\,ds.
```

 ביטוי זה תקף עבור $`1 < \sigma < 2`$, ובהנחת השערת רימן גם עבור $`\tfrac{1}{2} < \sigma < 2`$. מכאן שאינטגרל התמרת מלין חייב להתכנס, ולכן $`M(x)`$ היא $`O(x^e)`$ לכל מעריך $`e`$ הגדול מ-$`\tfrac{1}{2}`$. מכאן נובע שהטענה



```math
M(x) = O\Big(x^{\tfrac{1}{2} + \epsilon}\Big)
```

 לכל $`\epsilon`$ חיובי שקולה להשערת רימן. לכן השערת רימן הייתה נובעת מהשערת מרטנס החזקה יותר, והיא נובעת גם מהשערתו של סטילטיס, שלפיה



```math
M(x) = O\Big(x^\tfrac{1}{2}\Big).
```
