# פונקציית דיקמן

<img src="https://commons.wikimedia.org/wiki/Special:FilePath/Mplwp_Dickman_function_log.svg" alt="פונקציית דיקמן-דה בראון <math>\rho(u)</math> בסקלה לוגריתמית. הגרף כמעט ישר, כלומר הלוגריתם של הפונקציה כמעט ליניארי." width="320">

ב[תורת המספרים האנליטית](https://he.wikipedia.org/wiki/%D7%AA%D7%95%D7%A8%D7%AA_%D7%94%D7%9E%D7%A1%D7%A4%D7%A8%D7%99%D7%9D_%D7%94%D7%90%D7%A0%D7%9C%D7%99%D7%98%D7%99%D7%AA.md), **פונקציית דיקמן** או **פונקציית דיקמן-דה בראון** $`\rho`$ היא [פונקציה מיוחדת](https://he.wikipedia.org/wiki/%D7%A4%D7%95%D7%A0%D7%A7%D7%A6%D7%99%D7%94_%D7%9E%D7%99%D7%95%D7%97%D7%93%D7%AA) המשמשת להערכת השיעור של [המספרים החלקים](https://he.wikipedia.org/wiki/%D7%9E%D7%A1%D7%A4%D7%A8_%D7%97%D7%9C%D7%A7) עד גבול נתון. ראשון שחקר אותה היה האקטואר קרל דיקמן, שהגדיר אותה בפרסום המתמטי היחיד שלו.[^1] מאוחר יותר חקר אותה המתמטיקאי ההולנדי ניקולאס חוברט דה בראון.[^2][^3]

## הגדרה

פונקציית דיקמן-דה בראון $`\rho(u)`$ היא [פונקציה רציפה](https://he.wikipedia.org/wiki/%D7%A4%D7%95%D7%A0%D7%A7%D7%A6%D7%99%D7%94_%D7%A8%D7%A6%D7%99%D7%A4%D7%94) המקיימת את המשוואה הדיפרנציאלית עם השהיה



```math
u\rho'(u) + \rho(u-1) = 0
```



עם תנאי ההתחלה $`\rho(u) = 1`$ עבור $`0 \le u \le 1`$.

## תכונות

דיקמן הוכיח שעבור $`a`$ קבוע מתקיים



```math
\Psi(x, x^{1/a})\sim x\rho(a),
```



כאשר $`\Psi(x,y)`$ הוא מספר המספרים השלמים ה-$`y`$-חלקים (כלומר שכל גורמיהם הראשוניים אינם גדולים מ-$`y`$) שאינם גדולים מ-$`x`$. באופן שקול, מספר המספרים ה-$`B`$-חלקים הקטנים מ-$`N`$ הוא בערך



```math
\Psi(N,B) \approx N \rho\left(\frac{\log N}{\log B}\right).
```



רמאסוואמי נתן מאוחר יותר הוכחה מדויקת לכך שעבור $`a`$ קבוע, $`\Psi(x,x^{1/a})`$ אסימפטוטי ל-$`x \rho(a)`$, עם חסם השגיאה[^4]



```math
\Psi(x,x^{1/a})=x\rho(a)+O(x/\log x).
```



ידוע גם חסם הדוק יותר:[^5]



```math
\Psi(x,x^{1/a})=x\rho(a)+(1-\gamma)\rho(a-1)\frac{x}{\log x}+O\left(\frac{x}{(\log x)^2}\right),
```



כאשר $`\gamma`$ הוא [קבוע אוילר-מסקרוני](https://he.wikipedia.org/wiki/%D7%A7%D7%91%D7%95%D7%A2_%D7%90%D7%95%D7%99%D7%9C%D7%A8-%D7%9E%D7%A1%D7%A7%D7%A8%D7%95%D7%A0%D7%99).

## שימושים

<img src="https://commons.wikimedia.org/wiki/Special:FilePath/Dickman_prob_factor_size.svg" alt="שימוש בפונקציית דיקמן-דה בראון לחישוב ההסתברות שהגורם הראשוני הגדול ביותר והשני בגודלו של <math>x</math> קטנים מ-<math>x^a</math>" width="320">

עיקר השימוש בפונקציית דיקמן-דה בראון הוא הערכת השכיחות של מספרים חלקים בגודל נתון. הערכה זו משמשת לאופטימיזציה של אלגוריתמים שונים בתורת המספרים, כמו [שיטת P–1 לפירוק לגורמים](https://he.wikipedia.org/wiki/%D7%90%D7%9C%D7%92%D7%95%D7%A8%D7%99%D7%AA%D7%9D_p-1_%D7%A9%D7%9C_%D7%A4%D7%95%D7%9C%D7%90%D7%A8%D7%93), והיא מעניינת גם כשלעצמה.[^6]

אפשר להראות ש-[^7]



```math
\Psi(x,y)=xu^{O(-u)},
```



והדבר קשור להערכה $`\rho(u)\approx u^{-u}`$ שלהלן. גם לקבוע גולומב-דיקמן יש הגדרה חלופית באמצעות פונקציית דיקמן-דה בראון.

## הערכה

קירוב ראשון הוא $`\rho(u)\approx u^{-u}`$. הערכה טובה יותר היא[^8]



```math
\rho(u)\sim \frac{1}{\xi\sqrt{2\pi u}} \exp(-u\xi+\operatorname{Ei}(\xi)),
```



כאשר $`\operatorname{Ei}`$ הוא [האינטגרל המעריכי](https://he.wikipedia.org/wiki/%D7%90%D7%99%D7%A0%D7%98%D7%92%D7%A8%D7%9C_%D7%9E%D7%A2%D7%A8%D7%99%D7%9B%D7%99) ו-$`\xi`$ הוא השורש החיובי של



```math
e^\xi-1=u\xi.
```



חסם עליון פשוט הוא $`\rho(x)\le1/x!`$.

## חישוב

לכל קטע $`[n-1, n]`$, כאשר $`n`$ [שלם](https://he.wikipedia.org/wiki/%D7%9E%D7%A1%D7%A4%D7%A8_%D7%A9%D7%9C%D7%9D), קיימת [פונקציה אנליטית](https://he.wikipedia.org/wiki/%D7%A4%D7%95%D7%A0%D7%A7%D7%A6%D7%99%D7%94_%D7%90%D7%A0%D7%9C%D7%99%D7%98%D7%99%D7%AA) $`\rho_n`$ כך ש-$`\rho_n(u)=\rho(u)`$ בקטע. עבור $`0 \le u \le 1`$ מתקיים $`\rho(u) = 1`$; עבור $`1 \le u \le 2`$ מתקיים $`\rho(u) = 1-\log u`$; ועבור $`2 \le u \le 3`$



```math
\rho(u) = 1-(1-\log(u-1))\log(u) + \operatorname{Li}_2(1 - u) + \frac{\pi^2}{12},
```



כאשר $`\operatorname{Li}_2`$ הוא הדילוגריתם (ראו [פולילוגריתם](https://he.wikipedia.org/wiki/%D7%A4%D7%95%D7%9C%D7%99%D7%9C%D7%95%D7%92%D7%A8%D7%99%D7%AA%D7%9D)). את שאר הפונקציות $`\rho_n`$ אפשר לחשב באמצעות טורים אינסופיים.[^9]

שיטה חלופית היא חישוב חסמים עליונים ותחתונים בעזרת [כלל הטרפז](https://he.wikipedia.org/wiki/%D7%9B%D7%9C%D7%9C_%D7%94%D7%98%D7%A8%D7%A4%D7%96);[^10] רשת שהולכת ומתעדנת מאפשרת דיוק שרירותי. לחישובים בדיוק גבוה (מאות ספרות) עדיף פיתוח טור רקורסיבי סביב נקודות האמצע של הקטעים.[^11] את הערכים עבור $`u \le 7`$ אפשר לחשב היטב ב[אינטגרציה נומרית](https://he.wikipedia.org/wiki/%D7%90%D7%99%D7%A0%D7%98%D7%92%D7%A8%D7%A6%D7%99%D7%94_%D7%A0%D7%95%D7%9E%D7%A8%D7%99%D7%AA) בדיוק כפול רגיל.[^12]

## הרחבה

פרידלנדר הגדיר מקבילה דו-ממדית $`\sigma(u,v)`$ של $`\rho(u)`$.[^13] הפונקציה משמשת להערכת פונקציה $`\Psi(x,y,z)`$ הדומה לזו של דה בראון, אך סופרת את השלמים ה-$`y`$-חלקים שיש להם לכל היותר גורם ראשוני אחד הגדול מ-$`z`$. אז



```math
\Psi(x,x^{1/a},x^{1/b})\sim x\sigma(b,a).
```



מספרים מסוג זה מופיעים בגרסה הדו-שלבית של שיטת P–1 לפירוק לגורמים.[^14]
