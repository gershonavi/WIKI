# זוג רות–אהרון

ב[מתמטיקה](https://he.wikipedia.org/wiki/%D7%9E%D7%AA%D7%9E%D7%98%D7%99%D7%A7%D7%94), **זוג רות–אהרון** הוא זוג של שני [שלמים](https://he.wikipedia.org/wiki/%D7%9E%D7%A1%D7%A4%D7%A8_%D7%A9%D7%9C%D7%9D) עוקבים (למשל 714 ו-715) שסכומי ה[גורמים הראשוניים](https://he.wikipedia.org/wiki/%D7%92%D7%95%D7%A8%D7%9D_%D7%A8%D7%90%D7%A9%D7%95%D7%A0%D7%99) שלהם שווים:



```math
714 = 2 \times 3 \times 7 \times 17,
```





```math
715 = 5 \times 11 \times 13,
```

 ו-



```math
2 + 3 + 7 + 17 = 5 + 11 + 13 = 29.
```

 יש גרסאות שונות של ההגדרה, לפי השאלה כמה פעמים סופרים ראשוני שמופיע יותר מפעם אחת בפירוק.

את השם נתן [קרל פומרנס](https://he.wikipedia.org/wiki/%D7%A7%D7%A8%D7%9C_%D7%A4%D7%95%D7%9E%D7%A8%D7%A0%D7%A1), על שם [בייב רות'](https://he.wikipedia.org/wiki/%D7%91%D7%99%D7%99%D7%91_%D7%A8%D7%95%D7%AA%27) ו[האנק אהרון](https://he.wikipedia.org/wiki/%D7%94%D7%90%D7%A0%D7%A7_%D7%90%D7%94%D7%A8%D7%95%D7%9F): מספר ה[הום ראנים](https://he.wikipedia.org/wiki/%D7%94%D7%95%D7%9D_%D7%A8%D7%90%D7%9F) שרות' צבר בקריירה שלו בעונות הסדירות היה 714, שיא שאהרון שבר ב-8 באפריל 1974, כשחבט את ההום ראן ה-715 שלו. פומרנס היה מתמטיקאי ב[אוניברסיטת ג'ורג'יה](https://he.wikipedia.org/wiki/%D7%90%D7%95%D7%A0%D7%99%D7%91%D7%A8%D7%A1%D7%99%D7%98%D7%AA_%D7%92%27%D7%95%D7%A8%D7%92%27%D7%99%D7%94) בזמן שאהרון (שחקן של [אטלנטה ברייבס](https://he.wikipedia.org/wiki/%D7%90%D7%98%D7%9C%D7%A0%D7%98%D7%94_%D7%91%D7%A8%D7%99%D7%99%D7%91%D7%A1) הסמוכה) שבר את השיא של רות', וסטודנט של אחד מעמיתיו של פומרנס הבחין שסכומי הגורמים הראשוניים של 714 ו-715 שווים.[^1]

בלשון [פונקציות אריתמטיות](https://he.wikipedia.org/wiki/%D7%A4%D7%95%D7%A0%D7%A7%D7%A6%D7%99%D7%94_%D7%90%D7%A8%D7%99%D7%AA%D7%9E%D7%98%D7%99%D7%AA): נסמן ב-$`\mathrm{sopf}(n)`$ את סכום הגורמים הראשוניים *השונים* של $`n`$, וב-$`\mathrm{sopfr}(n)`$ את סכום הגורמים הראשוניים *עם חזרות* (כך ש-$`\mathrm{sopfr}(p_1^{e_1}\cdots p_k^{e_k}) = e_1p_1 + \cdots + e_kp_k`$). זוג רות–אהרון הוא $`(n, n+1)`$ עם $`\mathrm{sopf}(n) = \mathrm{sopf}(n+1)`$ או, בגרסה השנייה, $`\mathrm{sopfr}(n) = \mathrm{sopfr}(n+1)`$.

## דוגמאות

אם סופרים רק גורמים ראשוניים שונים, זוגות רות–אהרון הראשונים הם:



```math
(5, 6), (24, 25), (49, 50), (77, 78), (104, 105), (153, 154), (369, 370), (492, 493), (714, 715), (1682, 1683), (2107, 2108)
```

 (האיבר הקטן בכל זוג מופיע ב-(סדרה [A006145](https://oeis.org/A006145) ב-OEIS)). למשל $`24 = 2^3\cdot3`$ ו-$`25 = 5^2`$, עם $`2 + 3 = 5`$; ו-$`104 = 2^3\cdot13`$, $`105 = 3\cdot5\cdot7`$, עם $`2 + 13 = 3 + 5 + 7 = 15`$.

אם סופרים גורמים ראשוניים חוזרים (למשל $`8 = 2\times2\times2`$ ו-$`9 = 3\times3`$, עם $`2+2+2 = 3+3`$), זוגות רות–אהרון הראשונים הם:



```math
(5, 6), (8, 9), (15, 16), (77, 78), (125, 126), (714, 715), (948, 949), (1330, 1331)
```

 (האיבר הקטן מופיע ב-(סדרה [A039752](https://oeis.org/A039752) ב-OEIS)). למשל $`125 = 5^3`$ ו-$`126 = 2\cdot3^2\cdot7`$, עם $`5+5+5 = 2+3+3+7 = 15`$; ו-$`1331 = 11^3`$, $`1330 = 2\cdot5\cdot7\cdot19`$, עם $`33 = 33`$.

החיתוך של שתי הרשימות מתחיל ב-



```math
(5, 6), (77, 78), (714, 715), (5405, 5406)
```

 (האיבר הקטן מופיע ב-(סדרה [A039753](https://oeis.org/A039753) ב-OEIS)). כאן $`5405 = 5\cdot23\cdot47`$ ו-$`5406 = 2\cdot3\cdot17\cdot53`$, עם סכום 75. (את שלוש הרשימות בדקנו בחיפוש ממצה.)

כל זוג רות–אהרון של [מספרים חופשיים מריבועים](%D7%9E%D7%A1%D7%A4%D7%A8%20%D7%97%D7%95%D7%A4%D7%A9%D7%99%20%D7%9E%D7%A8%D7%99%D7%91%D7%95%D7%A2%D7%99%D7%9D.md) שייך לשתי הרשימות, עם אותו סכום. אבל בחיתוך יש גם זוגות שאינם חופשיים מריבועים, למשל



```math
(7129199, 7129200) = (7\times11^2\times19\times443,\ 2^4\times3\times5^2\times13\times457).
```

 כאן $`7+11+19+443 = 2+3+5+13+457 = 480`$, וגם $`7+11+11+19+443 = 2+2+2+2+3+5+5+13+457 = 491`$.

## צפיפות

זוגות רות–אהרון דלילים (כלומר, הצפיפות שלהם 0). את זה שיערו נלסון, פני ופומרנס ב-1974,[^2] והוכיחו [פול ארדש](https://he.wikipedia.org/wiki/%D7%A4%D7%95%D7%9C_%D7%90%D7%A8%D7%93%D7%A9) ופומרנס ב-1978.[^3] רעיון ההוכחה: אצל רוב המספרים, הגורם הראשוני הגדול ביותר "שולט" בסכום, ולכן שוויון הסכומים מחייב ש-$`n`$ ו-$`n+1`$ יהיו בעלי גורמים ראשוניים גדולים קרובים מאוד זה לזה – וארדש ופומרנס הראו שזה נדיר.

הספירה הבאה (שחישבנו) ממחישה את הדלילות – מספר הזוגות $`(n, n+1)`$ עם $`n \lt x`$:

| $`x`$                 | $`10^3`$ | $`10^4`$ | $`10^5`$ | $`10^6`$ |
|---------------------|--------|--------|--------|--------|
| לפי גורמים שונים    | 9      | 19     | 40     | 139    |
| לפי גורמים עם חזרות | 7      | 20     | 57     | 149    |

## שלשות רות–אהרון

קיימות גם **שלשות רות–אהרון** (זוגות רות–אהרון חופפים; (סדרה [A227654](https://oeis.org/A227654) ב-OEIS)).[^4] השתיים הראשונות, כשסופרים גורמים ראשוניים שונים:



```math
89460294 = 2 \times 3 \times 7 \times 11 \times 23 \times 8419,
```





```math
89460295 = 5 \times 4201 \times 4259,
```





```math
89460296 = 2 \times 2 \times 2 \times 31 \times 43 \times 8389,
```

 ו-$`2 + 3 + 7 + 11 + 23 + 8419 = 5 + 4201 + 4259 = 2 + 31 + 43 + 8389 = 8465`$;



```math
151165960539 = 3 \times 11 \times 11 \times 83 \times 2081 \times 2411,
```





```math
151165960540 = 2 \times 2 \times 5 \times 7 \times 293 \times 1193 \times 3089,
```





```math
151165960541 = 23 \times 29 \times 157 \times 359 \times 4021,
```

 ו-$`3 + 11 + 83 + 2081 + 2411 = 2 + 5 + 7 + 293 + 1193 + 3089 = 23 + 29 + 157 + 359 + 4021 = 4589`$.

ידועות עוד שלוש דוגמאות, שמתחילות ב-3089285427491 (סכום 1740), ב-6999761340223 (סכום 15906) וב-7539504384825 (סכום 63670). (את כל חמש השלשות בדקנו בפירוק לגורמים.)

שתי שלשות רות–אהרון הראשונות כשסופרים גורמים ראשוניים חוזרים:



```math
417162 = 2 \times 3 \times 251 \times 277,
```





```math
417163 = 17 \times 53 \times 463,
```





```math
417164 = 2 \times 2 \times 11 \times 19 \times 499,
```

 ו-$`2 + 3 + 251 + 277 = 17 + 53 + 463 = 2 + 2 + 11 + 19 + 499 = 533`$;



```math
6913943284 = 2 \times 2 \times 37 \times 89 \times 101 \times 5197,
```





```math
6913943285 = 5 \times 283 \times 1259 \times 3881,
```





```math
6913943286 = 2 \times 3 \times 167 \times 2549 \times 2707,
```

 ו-$`2 + 2 + 37 + 89 + 101 + 5197 = 5 + 283 + 1259 + 3881 = 2 + 3 + 167 + 2549 + 2707 = 5428`$.

אין דוגמאות נוספות מתחת ל-$`10^{13}`$.[^5]
