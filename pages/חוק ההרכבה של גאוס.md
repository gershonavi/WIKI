# חוק ההרכבה של גאוס

ב[תורת המספרים](https://he.wikipedia.org/wiki/%D7%AA%D7%95%D7%A8%D7%AA_%D7%94%D7%9E%D7%A1%D7%A4%D7%A8%D7%99%D7%9D), **חוק ההרכבה של גאוס** (Gauss composition law) הוא כלל, שהמציא [קרל פרידריך גאוס](https://he.wikipedia.org/wiki/%D7%A7%D7%A8%D7%9C_%D7%A4%D7%A8%D7%99%D7%93%D7%A8%D7%99%D7%9A_%D7%92%D7%90%D7%95%D7%A1), לביצוע [פעולה בינארית](https://he.wikipedia.org/wiki/%D7%A4%D7%A2%D7%95%D7%9C%D7%94_%D7%91%D7%99%D7%A0%D7%90%D7%A8%D7%99%D7%AA) על [תבניות ריבועיות בינאריות](https://he.wikipedia.org/wiki/%D7%AA%D7%91%D7%A0%D7%99%D7%AA_%D7%A8%D7%99%D7%91%D7%95%D7%A2%D7%99%D7%AA_%D7%91%D7%99%D7%A0%D7%90%D7%A8%D7%99%D7%AA) אינטגרליות. גאוס הציג את הכלל בספרו Disquisitiones Arithmeticae,[^1] ספר לימוד בתורת המספרים שפורסם ב-1801, בסעיפים 234–244. חוק ההרכבה הוא אחת התוצאות העמוקות ביותר בתורת התבניות הריבועיות הבינאריות, והניסוח של גאוס וההוכחות שלו לתכונותיו נחשבים בדרך כלל למסובכים וקשים מאוד.[^2] מתמטיקאים מאוחרים יותר פישטו את הניסוח של חוק ההרכבה והציגו אותו בצורה שמתאימה לחישובים מספריים. למושג יש גם הכללות בכמה כיוונים.

## תבניות ריבועיות בינאריות אינטגרליות

ביטוי מהצורה $`Q(x, y) = \alpha x^2 + \beta xy + \gamma y^2`$, כאשר $`\alpha, \beta, \gamma, x, y`$ כולם [שלמים](https://he.wikipedia.org/wiki/%D7%9E%D7%A1%D7%A4%D7%A8_%D7%A9%D7%9C%D7%9D), נקרא תבנית ריבועית בינארית אינטגרלית. התבנית נקראת **פרימיטיבית** אם $`\alpha, \beta, \gamma`$ [זרים](https://he.wikipedia.org/wiki/%D7%9E%D7%A1%D7%A4%D7%A8%D7%99%D7%9D_%D7%96%D7%A8%D7%99%D7%9D) (במשותף). הגודל $`\Delta = \beta^2 - 4\alpha\gamma`$ נקרא ה**דיסקרימיננטה** של התבנית. שלם $`\Delta`$ הוא דיסקרימיננטה של תבנית כלשהי אם ורק אם $`\Delta \equiv 0, 1 \pmod 4`$. $`\Delta`$ נקרא דיסקרימיננטה יסודית אם ורק אם אחד מהתנאים הבאים מתקיים:

- $`\Delta \equiv 1 \pmod 4`$ ו-$`\Delta`$ [חופשי מריבועים](%D7%9E%D7%A1%D7%A4%D7%A8%20%D7%97%D7%95%D7%A4%D7%A9%D7%99%20%D7%9E%D7%A8%D7%99%D7%91%D7%95%D7%A2%D7%99%D7%9D.md);
- $`\Delta = 4m`$, כאשר $`m \equiv 2`$ או $`3 \pmod 4`$ ו-$`m`$ חופשי מריבועים.

אם $`\Delta \lt 0`$ ו-$`\alpha \gt 0`$, התבנית נקראת **מוגדרת חיובית**; אם $`\Delta \lt 0`$ ו-$`\alpha \lt 0`$, היא **מוגדרת שלילית**; ואם $`\Delta \gt 0`$, היא **לא מוגדרת**.

### שקילות של תבניות

שתי תבניות $`g(x, y)`$ ו-$`h(x, y)`$ נקראות שקולות (או **שקולות במובן הצר**) אם יש שלמים $`\alpha, \beta, \gamma, \delta`$ כך ש-



```math
\alpha\delta - \beta\gamma = 1 \quad\text{ו-}\quad g(\alpha x + \beta y, \gamma x + \delta y) = h(x, y).
```

 מסמנים זאת $`g(x, y) \sim h(x, y)`$. היחס $`\sim`$ הוא [יחס שקילות](https://he.wikipedia.org/wiki/%D7%99%D7%97%D7%A1_%D7%A9%D7%A7%D7%99%D7%9C%D7%95%D7%AA) על קבוצת התבניות, ומחלקת השקילות של $`g`$ מסומנת $`[g(x, y)]`$. שתי תבניות נקראות **שקולות שלא במובן הצר** אם מתקיים אותו דבר עם $`\alpha\delta - \beta\gamma = -1`$. קל לראות שלתבניות שקולות (בכל אחד מהמובנים) יש אותה דיסקרימיננטה.

## הניסוח של גאוס לחוק ההרכבה

### רקע היסטורי

הזהות הבאה, שנקראת זהות ברהמגופטה, הייתה ידועה למתמטיקאי ההודי ברהמגופטה (598–668), שהשתמש בה כדי לחשב קירובים הולכים ומשתפרים לשורשים ריבועיים של שלמים חיוביים:



```math
(x^2 + Dy^2)(u^2 + Dv^2) = (xu + Dyv)^2 + D(xv - yu)^2.
```

 אם נכתוב $`f(x, y) = x^2 + Dy^2`$, אפשר לכתוב את הזהות בצורה $`f(x, y)f(u, v) = f(X, Y)`$, כאשר $`X = xu + Dyv`$ ו-$`Y = xv - yu`$. חוק ההרכבה של גאוס מכליל את הזהות הזו לזהות מהצורה $`g(x, y)h(u, v) = F(X, Y)`$, כאשר $`g, h, F`$ תבניות ריבועיות בינאריות אינטגרליות, ו-$`X, Y`$ צירופים לינאריים של המכפלות $`xu, xv, yu, yv`$.

### חוק ההרכבה

נתבונן בתבניות



```math
g(x, y) = ax^2 + bxy + cy^2, \quad h(x, y) = dx^2 + exy + fy^2, \quad F(x, y) = Ax^2 + Bxy + Cy^2.
```

 אם אפשר למצוא שלמים $`p, q, r, s`$ ו-$`p', q', r', s'`$ כך שלששת המספרים



```math
pq' - qp',\ pr' - rp',\ ps' - sp',\ qr' - rq',\ qs' - sq',\ rs' - sr'
```

 אין מחלק משותף מלבד $`\pm1`$, וכך שאם נגדיר



```math
X = pxu + qxv + ryu + syv, \qquad Y = p'xu + q'xv + r'yu + s'yv,
```

 מתקיים באופן זהותי



```math
g(x, y)h(u, v) = F(X, Y),
```

 אז התבנית $`F(x, y)`$ נקראת **הרכבה** של התבניות $`g(x, y)`$ ו-$`h(x, y)`$. ההרכבה של שתי תבניות, אם היא קיימת, אינה יחידה (אבל מחלקת השקילות שלה יחידה, כמתואר להלן).

### דוגמה

נתבונן בתבניות



```math
g(x, y) = 2x^2 + 3xy - 10y^2, \quad h(x, y) = 5x^2 + 3xy - 4y^2, \quad F(x, y) = 10x^2 + 3xy - 2y^2,
```

 שלשלושתן דיסקרימיננטה $`9 + 80 = 89`$. ניקח



```math
[p, q, r, s] = [1, 0, 0, 2], \qquad [p', q', r', s'] = [0, 2, 5, 3].
```

 אז



```math
pq' - qp' = 2,\ pr' - rp' = 5,\ ps' - sp' = 3,\ qr' - rq' = 0,\ qs' - sq' = 4,\ rs' - sr' = 10,
```

 ולששת המספרים האלה אין מחלק משותף מלבד $`\pm1`$. נגדיר



```math
X = xu + 2yv, \qquad Y = 2xv + 5yu + 3yv.
```

 אז אפשר לוודא (בדקנו בפיתוח סימבולי) ש-$`g(x, y)h(u, v) = F(X, Y)`$. למשל, עם $`x = u = 1`$, $`y = v = 0`$: $`g(1, 0)h(1, 0) = 2\cdot5 = 10 = F(1, 0)`$; ועם $`x = 0, y = 1, u = 1, v = 0`$: $`g(0, 1)h(1, 0) = (-10)\cdot5 = -50`$, ו-$`X = 0`$, $`Y = 5`$, $`F(0, 5) = -2\cdot25 = -50`$. לכן $`F(x, y)`$ היא הרכבה של $`g(x, y)`$ ו-$`h(x, y)`$.

## אלגוריתם לחישוב ההרכבה

האלגוריתם הבא מחשב הרכבה של שתי תבניות.[^3] נתונות התבניות



```math
f_1(x, y) = a_1x^2 + b_1xy + c_1y^2, \qquad f_2(x, y) = a_2x^2 + b_2xy + c_2y^2
```

 עם אותה דיסקרימיננטה $`\Delta = b_1^2 - 4a_1c_1 = b_2^2 - 4a_2c_2`$.

1.  מחשבים $`\beta = \frac{b_1 + b_2}2`$.
2.  מחשבים $`n = \gcd(a_1, a_2, \beta)`$.
3.  מוצאים $`t, u, v`$ כך ש-$`a_1t + a_2u + \beta v = n`$ (ב[אלגוריתם אוקלידס המורחב](https://he.wikipedia.org/wiki/%D7%90%D7%9C%D7%92%D7%95%D7%A8%D7%99%D7%AA%D7%9D_%D7%90%D7%95%D7%A7%D7%9C%D7%99%D7%93%D7%A1_%D7%94%D7%9E%D7%95%D7%A8%D7%97%D7%91)).
4.  מחשבים $`A = \frac{a_1a_2}{n^2}`$.
5.  מחשבים $`B = \frac{a_1b_2t + a_2b_1u + v(b_1b_2 + \Delta)/2}n`$.
6.  מחשבים $`C = \frac{B^2 - \Delta}{4A}`$.
7.  התבנית היא $`F(x, y) = Ax^2 + Bxy + Cy^2`$.
8.  מחשבים
    

    ```math
    X = nx_1x_2 + \frac{(b_2 - B)n}{2a_2}x_1y_2 + \frac{(b_1 - B)n}{2a_1}y_1x_2 + \frac{[b_1b_2 + \Delta - B(b_1 + b_2)]n}{4a_1a_2}y_1y_2,
    ```



    

    ```math
    Y = \frac{a_1}nx_1y_2 + \frac{a_2}ny_1x_2 + \frac{b_1 + b_2}{2n}y_1y_2.
    ```



אז $`F(X, Y) = f_1(x_1, y_1)f_2(x_2, y_2)`$, ולכן $`F(x, y)`$ היא הרכבה של $`f_1`$ ו-$`f_2`$.

### דוגמה מלאה: דיסקרימיננטה −23

יש בדיוק שלוש תבניות מצומצמות עם דיסקרימיננטה $`-23`$: $`x^2 + xy + 6y^2`$, $`2x^2 + xy + 3y^2`$ ו-$`2x^2 - xy + 3y^2`$. נרכיב את $`f = 2x^2 + xy + 3y^2`$ עם עצמה:

- $`\beta = (1 + 1)/2 = 1`$, $`n = \gcd(2, 2, 1) = 1`$; ניקח $`t = u = 0`$, $`v = 1`$.
- $`A = 2\cdot2/1 = 4`$; $`B = (0 + 0 + 1\cdot(1 - 23)/2)/1 = -11`$; $`C = (121 + 23)/16 = 9`$.
- כלומר $`f \circ f = 4x^2 - 11xy + 9y^2`$ (דיסקרימיננטה $`121 - 144 = -23`$), עם $`X = x_1x_2 + 3x_1y_2 + 3y_1x_2`$ ו-$`Y = 2x_1y_2 + 2y_1x_2 + y_1y_2`$. בדקנו בפיתוח סימבולי ש-$`f(x_1, y_1)f(x_2, y_2) = 4X^2 - 11XY + 9Y^2`$.
- צמצום: ההחלפה $`x \mapsto x + y`$ נותנת $`4x^2 - 3xy + 2y^2`$, והחלפת התפקידים $`(x, y) \mapsto (-y, x)`$ נותנת $`2x^2 + 3xy + 4y^2`$, ושוב $`x \mapsto x - y`$ נותנת $`2x^2 - xy + 3y^2`$.

כלומר $`[f]^2 = [2x^2 - xy + 3y^2] = [f]^{-1}`$, ובחישוב נוסף $`[f]^3 = [x^2 + xy + 6y^2]`$ – איבר היחידה. חבורת המחלקות של דיסקרימיננטה $`-23`$ היא אם כן [ציקלית](https://he.wikipedia.org/wiki/%D7%97%D7%91%D7%95%D7%A8%D7%94_%D7%A6%D7%99%D7%A7%D7%9C%D7%99%D7%AA) מסדר 3, בהתאם לכך שמספר המחלקות של $`\mathbb Q(\sqrt{-23})`$ הוא 3.

## תכונות של חוק ההרכבה

### קיום ההרכבה

לשתי תבניות פרימיטיביות יש הרכבה (פרימיטיבית) אם ורק אם יש להן אותה דיסקרימיננטה.

### תבניות שקולות וחוק ההרכבה

יהיו $`g, h, g', h'`$ תבניות כך ש-$`g \sim g'`$ ו-$`h \sim h'`$. אם $`F`$ הרכבה של $`g`$ ו-$`h`$, ו-$`F'`$ הרכבה של $`g'`$ ו-$`h'`$, אז $`F \sim F'`$.

### פעולה בינארית

יהי $`D`$ שלם קבוע, ותהי $`S_D`$ קבוצת כל התבניות הפרימיטיביות עם דיסקרימיננטה $`D`$ (ועבור $`D \lt 0`$, רק המוגדרות החיוביות). תהי $`G_D`$ קבוצת מחלקות השקילות שלה ביחס ל-$`\sim`$. עבור $`[g], [h] \in G_D`$, תהי $`F`$ הרכבה של $`g`$ ו-$`h`$ ב-$`S_D`$. אז



```math
[g] \circ [h] = [F]
```

 מגדירה פעולה בינארית מוגדרת היטב $`\circ`$ על $`G_D`$.

### החבורה G<sub>D</sub>

- הקבוצה $`G_D`$ היא [חבורה אבלית](https://he.wikipedia.org/wiki/%D7%97%D7%91%D7%95%D7%A8%D7%94_%D7%90%D7%91%D7%9C%D7%99%D7%AA) סופית ביחס לפעולה $`\circ`$.
- [איבר היחידה](https://he.wikipedia.org/wiki/%D7%90%D7%99%D7%91%D7%A8_%D7%99%D7%97%D7%99%D7%93%D7%94) של $`G_D`$ הוא



```math
\begin{cases}[x^2 - (D/4)y^2] & D \equiv 0 \pmod 4, \\ [x^2 + xy + ((1 - D)/4)y^2] & D \equiv 1 \pmod 4.\end{cases}
```



- ההופכי של $`[ax^2 + bxy + cy^2]`$ ב-$`G_D`$ הוא $`[ax^2 - bxy + cy^2]`$.

## הגישה המודרנית לחוק ההרכבה

התיאור הבא של הגישה המודרנית מבוסס על המונוגרפיה של דאנקן ביואל,[^4] שבה אפשר למצוא פרטים נוספים והוכחות לכל הטענות.

### מספרים ושלמים אלגבריים ריבועיים

בסעיף הזה נקרא לאיברי $`\mathbb Z`$ "שלמים רציונליים", כדי להבדיל אותם מ[שלמים אלגבריים](https://he.wikipedia.org/wiki/%D7%A9%D7%9C%D7%9D_%D7%90%D7%9C%D7%92%D7%91%D7%A8%D7%99). מספר מרוכב $`\alpha`$ נקרא **מספר אלגברי ריבועי** אם הוא מקיים משוואה $`ax^2 + bx + c = 0`$ עם $`a, b, c \in \mathbb Z`$, ו**שלם אלגברי ריבועי** אם הוא מקיים משוואה $`x^2 + bx + c = 0`$ עם $`b, c \in \mathbb Z`$. המספרים האלגבריים הריבועיים הם המספרים מהצורה



```math
\alpha = \frac{-b + e\sqrt d}{2a},
```

 כאשר $`a, b, d, e \in \mathbb Z`$ ו-$`d`$ חופשי מריבועים. השלם $`d`$ נקרא ה**רדיקנד** של $`\alpha`$. הנורמה של $`\alpha`$ היא $`N(\alpha) = (b^2 - e^2d)/4a^2`$.[^5]

השדה הקטן ביותר שמכיל את $`\mathbb Q`$ ומספר אלגברי ריבועי $`\alpha`$ (שאינו רציונלי) הוא ה[שדה ריבועי](https://he.wikipedia.org/wiki/%D7%A9%D7%93%D7%94_%D7%A8%D7%99%D7%91%D7%95%D7%A2%D7%99) $`\mathbb Q(\alpha) = \mathbb Q(\sqrt d) = \{t + u\sqrt d : t, u \in \mathbb Q\}`$. ה**דיסקרימיננטה** של $`\mathbb Q(\sqrt d)`$ היא $`\Delta = 4d`$ אם $`d \equiv 2, 3 \pmod 4`$, ו-$`\Delta = d`$ אם $`d \equiv 1 \pmod 4`$. קבוצת השלמים האלגבריים הריבועיים עם רדיקנד $`d`$ מסומנת $`O(\sqrt d)`$:



```math
O(\sqrt d) = \begin{cases}\{a + b\sqrt d : a, b \in \mathbb Z\} & d \equiv 2, 3 \pmod 4, \\ \{(a + b\sqrt d)/2 : a, b \in \mathbb Z,\ a \equiv b \pmod 2\} & d \equiv 1 \pmod 4.\end{cases}
```

 זהו [חוג](https://he.wikipedia.org/wiki/%D7%97%D7%95%D7%92_%28%D7%9E%D7%91%D7%A0%D7%94_%D7%90%D7%9C%D7%92%D7%91%D7%A8%D7%99%29) ביחס לחיבור ולכפל הרגילים, ו-$`O(\sqrt d) = \{a + b\delta : a, b \in \mathbb Z\}`$, כאשר $`\delta = -\sqrt d`$ אם $`d \equiv 2, 3 \pmod 4`$, ו-$`\delta = (1 - \sqrt d)/2`$ אם $`d \equiv 1 \pmod 4`$.[^6]

### אידיאלים בשדות ריבועיים

יהי $`\mathbf a`$ [אידיאל](https://he.wikipedia.org/wiki/%D7%90%D7%99%D7%93%D7%99%D7%90%D7%9C_%28%D7%AA%D7%95%D7%A8%D7%AA_%D7%94%D7%97%D7%95%D7%92%D7%99%D7%9D%29) בחוג השלמים $`O(\sqrt d)`$. אפשר למצוא $`\alpha_1, \alpha_2 \in O(\sqrt d)`$ כך שכל איבר של $`\mathbf a`$ מוצג באופן יחיד כ-$`\alpha_1x + \alpha_2y`$ עם $`x, y \in \mathbb Z`$. זוג כזה נקרא **בסיס** של האידיאל, ומסמנים $`\mathbf a = \langle\alpha_1, \alpha_2\rangle`$. ה**נורמה** של האידיאל היא



```math
N(\mathbf a) = \frac{|\alpha_1\overline{\alpha_2} - \overline{\alpha_1}\alpha_2|}{\sqrt{|\Delta|} },
```

 והיא אינה תלויה בבחירת הבסיס.

- ה**מכפלה** של שני אידיאלים $`\mathbf a = \langle\alpha_1, \alpha_2\rangle`$ ו-$`\mathbf b = \langle\beta_1, \beta_2\rangle`$ היא האידיאל שנוצר על ידי הצירופים הלינאריים השלמים של $`\alpha_1\beta_1, \alpha_1\beta_2, \alpha_2\beta_1, \alpha_2\beta_2`$.
- **אידיאל שברי** הוא תת-קבוצה $`I`$ של השדה שסגורה לצירופים $`\lambda\alpha + \mu\beta`$ עם $`\lambda, \mu \in O(\sqrt d)`$, ושיש שלם אלגברי קבוע $`\nu \ne 0`$ כך ש-$`\nu\alpha \in O(\sqrt d)`$ לכל $`\alpha \in I`$.
- אידיאל נקרא [ראשי](https://he.wikipedia.org/wiki/%D7%90%D7%99%D7%93%D7%99%D7%90%D7%9C_%D7%A8%D7%90%D7%A9%D7%99) אם הוא מהצורה $`(\alpha) = \{\lambda\alpha : \lambda \in O(\sqrt d)\}`$.

תוצאה חשובה: לכל אידיאל (שלם או שברי) $`\mathbf a`$ יש אידיאל שלם $`\mathbf b`$ כך שהמכפלה $`\mathbf{ab}`$ ראשית.

### יחס שקילות על אידיאלים

שני אידיאלים $`\mathbf a`$ ו-$`\mathbf b`$ נקראים שקולים, $`\mathbf a \sim \mathbf b`$, אם יש אידיאל ראשי $`(\alpha)`$ כך ש-$`\mathbf a = (\alpha)\mathbf b`$; והם **שקולים במובן הצר** אם בנוסף הנורמה של $`\alpha`$ חיובית. מחלקות השקילות (או מחלקות השקילות הצרה) של האידיאלים השבריים יוצרות חבורה אבלית ביחס לכפל אידיאלים, שאיבר היחידה שלה הוא מחלקת האידיאלים הראשיים (או האידיאלים הראשיים $`(\alpha)`$ עם $`N(\alpha) \gt 0`$). אלה [חבורת המחלקות](%D7%97%D7%91%D7%95%D7%A8%D7%AA%20%D7%9E%D7%97%D7%9C%D7%A7%D7%95%D7%AA%20%D7%94%D7%90%D7%99%D7%93%D7%99%D7%90%D7%9C%D7%99%D7%9D.md) ו[חבורת המחלקות הצרה](%D7%97%D7%91%D7%95%D7%A8%D7%AA%20%D7%94%D7%9E%D7%97%D7%9C%D7%A7%D7%95%D7%AA%20%D7%94%D7%A6%D7%A8%D7%94.md) של $`\mathbb Q(\sqrt d)`$.

### תבניות ומחלקות אידיאלים

התוצאה המרכזית שמקשרת בין התבניות למחלקות האידיאלים:

  
חבורת המחלקות של התבניות הריבועיות הבינאריות הפרימיטיביות עם דיסקרימיננטה יסודית $`\Delta`$ (המוגדרות החיוביות, אם $`\Delta \lt 0`$) איזומורפית לחבורת המחלקות הצרה של השדה הריבועי $`\mathbb Q(\sqrt\Delta)`$.

ההתאמה: לאידיאל $`\mathbf a = \langle\alpha_1, \alpha_2\rangle`$ (עם בסיס מכוון מתאים) מתאימים את התבנית $`N(\alpha_1x + \alpha_2y)/N(\mathbf a)`$. למשל, עבור $`\Delta = -23`$, האידיאל $`\langle2, (1 + \sqrt{-23})/2\rangle`$ מנורמה 2 נותן את התבנית $`N(2x + \tfrac{1+\sqrt{-23} }2y)/2 = 2x^2 + xy + 3y^2`$.

## הגישה של בהרגבה

*ערך מורחב: [קוביית בהרגבה](%D7%A7%D7%95%D7%91%D7%99%D7%99%D7%AA%20%D7%91%D7%94%D7%A8%D7%92%D7%91%D7%94.md)* [מנג'ול בהרגבה](https://he.wikipedia.org/wiki/%D7%9E%D7%A0%D7%92%27%D7%95%D7%9C_%D7%91%D7%94%D7%A8%D7%92%D7%91%D7%94), מתמטיקאי קנדי-אמריקאי זוכה [מדליית פילדס](https://he.wikipedia.org/wiki/%D7%9E%D7%93%D7%9C%D7%99%D7%99%D7%AA_%D7%A4%D7%99%D7%9C%D7%93%D7%A1), הציג תצורה, שנקראת קוביית בהרגבה, של שמונה שלמים $`a, b, c, d, e, f, g, h`$ בקודקודי קובייה, כדי לחקור את חוקי ההרכבה של תבניות ריבועיות בינאריות ותבניות אחרות. הוא הגדיר מטריצות שמתאימות לפאות הנגדיות של הקובייה:



```math
M_1 = \begin{bmatrix}a & b \\ c & d\end{bmatrix}, N_1 = \begin{bmatrix}e & f \\ g & h\end{bmatrix},\quad M_2 = \begin{bmatrix}a & c \\ e & g\end{bmatrix}, N_2 = \begin{bmatrix}b & d \\ f & h\end{bmatrix},\quad M_3 = \begin{bmatrix}a & e \\ b & f\end{bmatrix}, N_3 = \begin{bmatrix}c & g \\ d & h\end{bmatrix},
```

 ובנה מהן שלוש תבניות:



```math
Q_i(x, y) = -\det(M_ix - N_iy), \qquad i = 1, 2, 3.
```

[^7] בהרגבה הוכיח את התוצאה הבאה, שמקשרת בין קוביית בהרגבה לחוק ההרכבה של גאוס:[^8] אם קובייה נותנת שלוש תבניות פרימיטיביות $`Q_1, Q_2, Q_3`$, אז יש להן אותה דיסקרימיננטה, ומכפלתן היא איבר היחידה בחבורה שמוגדרת על ידי ההרכבה של גאוס. להפך, אם $`Q_1, Q_2, Q_3`$ שלוש תבניות פרימיטיביות כלשהן עם אותה דיסקרימיננטה שמכפלתן היא איבר היחידה, אז יש קובייה שנותנת אותן.
