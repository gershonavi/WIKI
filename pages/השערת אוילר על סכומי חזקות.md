# השערת אוילר על סכומי חזקות

ב[תורת המספרים](https://he.wikipedia.org/wiki/%D7%AA%D7%95%D7%A8%D7%AA_%D7%94%D7%9E%D7%A1%D7%A4%D7%A8%D7%99%D7%9D), **השערת אוילר** על סכומי חזקות היא [השערה](https://he.wikipedia.org/wiki/%D7%94%D7%A9%D7%A2%D7%A8%D7%94_%28%D7%9E%D7%AA%D7%9E%D7%98%D7%99%D7%A7%D7%94%29) שהופרכה, הקשורה ל[המשפט האחרון של פרמה](https://he.wikipedia.org/wiki/%D7%94%D7%9E%D7%A9%D7%A4%D7%98_%D7%94%D7%90%D7%97%D7%A8%D7%95%D7%9F_%D7%A9%D7%9C_%D7%A4%D7%A8%D7%9E%D7%94). [לאונרד אוילר](https://he.wikipedia.org/wiki/%D7%9C%D7%90%D7%95%D7%A0%D7%A8%D7%93_%D7%90%D7%95%D7%99%D7%9C%D7%A8) הציג אותה ב-1778 ל[אקדמיה למדעים של סנקט פטרבורג](https://he.wikipedia.org/wiki/%D7%94%D7%90%D7%A7%D7%93%D7%9E%D7%99%D7%94_%D7%94%D7%A8%D7%95%D7%A1%D7%99%D7%AA_%D7%9C%D7%9E%D7%93%D7%A2%D7%99%D7%9D). היא קובעת שלכל [שלמים](https://he.wikipedia.org/wiki/%D7%9E%D7%A1%D7%A4%D7%A8_%D7%A9%D7%9C%D7%9D) $`n`$ ו-$`k`$ גדולים מ-1, אם הסכום של $`n`$ חזקות $`k`$-יות של שלמים חיוביים הוא בעצמו חזקה $`k`$-ית, אז $`n`$ גדול או שווה ל-$`k`$:



```math
a_1^k + a_2^k + \dots + a_n^k = b^k \implies n \ge k.
```

 ההשערה היא ניסיון להכליל את המשפט האחרון של פרמה, שהוא המקרה $`n = 2`$: אם $`a_1^k + a_2^k = b^k`$, אז $`2 \ge k`$.

ההשערה נכונה במקרה $`k = 3`$ (מה שנובע מהמשפט האחרון של פרמה לחזקות שלישיות), אבל הופרכה עבור $`k = 4`$ ו-$`k = 5`$. לא ידוע אם היא נכשלת או מתקיימת לאיזשהו $`k \ge 6`$.

## רקע

אוילר הכיר את השוויון $`59^4 + 158^4 = 133^4 + 134^4`$, שמערב סכומים של ארבע חזקות רביעיות;[^1] אבל זו אינה [דוגמה נגדית](https://he.wikipedia.org/wiki/%D7%93%D7%95%D7%92%D7%9E%D7%94_%D7%A0%D7%92%D7%93%D7%99%D7%AA), כי אף איבר אינו מבודד בצד אחד של המשוואה. הוא גם נתן פתרון מלא לבעיית ארבע הקוביות, כמו ב[מספר של אפלטון](https://he.wikipedia.org/wiki/%D7%94%D7%9E%D7%A1%D7%A4%D7%A8_%D7%A9%D7%9C_%D7%90%D7%A4%D7%9C%D7%98%D7%95%D7%9F) $`3^3 + 4^3 + 5^3 = 6^3`$ או ב[מספר המונית](https://he.wikipedia.org/wiki/%D7%9E%D7%A1%D7%A4%D7%A8_%D7%9E%D7%95%D7%A0%D7%99%D7%AA) 1729.[^2] הפתרון הכללי של המשוואה $`x_1^3 + x_2^3 = x_3^3 + x_4^3`$ הוא



```math
\begin{align}
x_1 &= \lambda\left(1 - (a - 3b)(a^2 + 3b^2)\right), \\
x_2 &= \lambda\left((a + 3b)(a^2 + 3b^2) - 1\right), \\
x_3 &= \lambda\left((a + 3b) - (a^2 + 3b^2)^2\right), \\
x_4 &= \lambda\left((a^2 + 3b^2)^2 - (a - 3b)\right),
\end{align}
```

 כאשר $`a`$, $`b`$ ו-$`\lambda`$ מספרים רציונליים כלשהם. (בדקנו בפיתוח סימבולי ש-$`x_1^3 + x_2^3 - x_3^3 - x_4^3 = 0`$ זהותית.)

ההשערה הוצגה ב-1778, אבל פורסמה רק אחרי מותו של אוילר.[^3]

## דוגמאות נגדיות

[ל. ג'. לנדר](https://he.wikipedia.org/wiki/%D7%9C%D7%99%D7%90%D7%95%D7%9F_%D7%92%27._%D7%9C%D7%A0%D7%93%D7%A8) ו[ת. ר. פרקין](https://he.wikipedia.org/wiki/%D7%AA%D7%95%D7%9E%D7%90%D7%A1_%D7%A8._%D7%A4%D7%A8%D7%A7%D7%99%D7%9F) הפריכו את השערת אוילר ב-1966, כשמצאו בחיפוש ממוחשב ישיר על מחשב [CDC 6600](https://he.wikipedia.org/wiki/CDC_6600) דוגמה נגדית עבור $`k = 5`$.[^4] התוצאה פורסמה במאמר בן שני משפטים בלבד. ידועים ארבעה פתרונות פרימיטיביים (כלומר, שבהם אין גורם משותף לכל המחוברים) של $`a^5 + b^5 + c^5 + d^5 = e^5`$ בשלמים:



```math
\begin{align}
144^5 &= 27^5 + 84^5 + 110^5 + 133^5, \\
14132^5 &= (-220)^5 + 5027^5 + 6237^5 + 14068^5, \\
85359^5 &= 55^5 + 3183^5 + 28969^5 + 85282^5, \\
1956878^5 &= 719115^5 + 1331622^5 + (-1340632)^5 + 1956213^5
\end{align}
```

 (לנדר ופרקין, 1966; שר וזיידל, 1996; פריי, 2004; בראון, 2026).[^5][^6] (בדקנו את ארבע הזהויות בחשבון שלמים מדויק.)

ב-1986 מצא [נועם אלקיס](https://he.wikipedia.org/wiki/%D7%A0%D7%95%D7%A2%D7%9D_%D7%90%D7%9C%D7%A7%D7%99%D7%A1) דוגמה נגדית למקרה $`k = 4`$, שפורסמה ב-1988.[^7] בשיטה של אלקיס אפשר לבנות סדרה אינסופית של דוגמאות נגדיות למקרה $`k = 4`$, והקטנה ביותר שהוא מצא היא



```math
20615673^4 = 2682440^4 + 15365639^4 + 18796760^4.
```



מקרה פרטי של הפתרונות של אלקיס אפשר לצמצם לזהות



```math
(85v^2 + 484v - 313)^4 + (68v^2 - 586v + 10)^4 + (2u)^4 = (357v^2 - 204v + 363)^4,
```

 כאשר



```math
u^2 = 22030 + 28849v - 56158v^2 + 36941v^3 - 31790v^4.
```

 זה [עקום אליפטי](https://he.wikipedia.org/wiki/%D7%A2%D7%A7%D7%95%D7%9D_%D7%90%D7%9C%D7%99%D7%A4%D7%98%D7%99) עם [נקודה רציונלית](https://he.wikipedia.org/wiki/%D7%A0%D7%A7%D7%95%D7%93%D7%94_%D7%A8%D7%A6%D7%99%D7%95%D7%A0%D7%9C%D7%99%D7%AA) ב-$`v_1 = -\frac{31}{467}`$. מהנקודה הרציונלית ההתחלתית הזו אפשר לחשב אוסף אינסופי של נקודות נוספות (בעזרת חוק החיבור על העקום). הצבת $`v_1`$ בזהות והסרת גורמים משותפים נותנות את הדוגמה המספרית שלמעלה. (בדקנו: ב-$`v_1`$ מתקיים $`u = \frac{30731278}{218089}`$, וכפל ב-$`467^2`$ וחלוקה במחלק המשותף נותנים בדיוק $`2682440, 15365639, 18796760`$ ו-$`20615673`$.)

ב-1988 מצא [רוג'ר פריי](https://he.wikipedia.org/wiki/%D7%A8%D7%95%D7%92%27%D7%A8_%D7%A4%D7%A8%D7%99%D7%99) את הדוגמה הנגדית הקטנה ביותר האפשרית,



```math
95800^4 + 217519^4 + 414560^4 = 422481^4,
```

 עבור $`k = 4`$, בחיפוש ממוחשב ישיר בטכניקות שהציע אלקיס. זה הפתרון היחיד עם ערכי משתנים מתחת ל-1,000,000.[^8]

## הכללות

ב-1967 שיערו ל. ג'. לנדר, ת. ר. פרקין ו[ג'ון סלפרידג'](https://he.wikipedia.org/wiki/%D7%92%27%D7%95%D7%9F_%D7%A1%D7%9C%D7%A4%D7%A8%D7%99%D7%93%D7%92%27)[^9] שאם



```math
\sum_{i=1}^na_i^k = \sum_{j=1}^mb_j^k,
```

 כאשר $`a_i \ne b_j`$ שלמים חיוביים לכל $`1 \le i \le n`$ ו-$`1 \le j \le m`$, אז $`m + n \ge k`$ (ראו [השערת לנדר, פרקין וסלפרידג'](%D7%94%D7%A9%D7%A2%D7%A8%D7%AA%20%D7%9C%D7%A0%D7%93%D7%A8%2C%20%D7%A4%D7%A8%D7%A7%D7%99%D7%9F%20%D7%95%D7%A1%D7%9C%D7%A4%D7%A8%D7%99%D7%93%D7%92%27.md)). במקרה הפרטי $`m = 1`$, ההשערה אומרת שאם $`\sum_{i=1}^na_i^k = b^k`$ (בתנאים שלמעלה), אז $`n \ge k - 1`$.

את המקרה הפרטי אפשר לתאר כבעיה של [חלוקה](https://he.wikipedia.org/wiki/%D7%97%D7%9C%D7%95%D7%A7%D7%94_%28%D7%AA%D7%95%D7%A8%D7%AA_%D7%94%D7%9E%D7%A1%D7%A4%D7%A8%D7%99%D7%9D%29) של חזקה מושלמת למעט חזקות זהות. עבור $`k = 4, 5, 7, 8`$ ו-$`n = k`$ או $`k - 1`$, ידועים פתרונות רבים. הנה כמה מהם (את כולם בדקנו בחשבון שלמים מדויק).

=== k = 3 === מהמשפט האחרון של פרמה ידוע שאין פתרון ל-$`a^3 + b^3 = c^3`$. (סכום חיובי מינימלי של חזקות שלישיות הוא $`9^3 - 8^3 - 6^3 = 1`$, שנותן פתרון של המשוואה עם $`a = (1, 6, 8)`$ ו-$`b = 9`$, אבל שם האיבר הקטן אינו גדול מ-1.)

הפתרון הקטן ביותר עם איברים גדולים מ-1 הוא



```math
3^3 + 4^3 + 5^3 = 6^3
```

 (המספר של אפלטון, 216). זה המקרה $`a = 1`$, $`b = 0`$ בנוסחה של [סריניוואסה רמנוג'אן](https://he.wikipedia.org/wiki/%D7%A1%D7%A8%D7%99%D7%A0%D7%99%D7%95%D7%95%D7%90%D7%A1%D7%94_%D7%A8%D7%9E%D7%A0%D7%95%D7%92%27%D7%90%D7%9F)[^10]



```math
(3a^2 + 5ab - 5b^2)^3 + (4a^2 - 4ab + 6b^2)^3 + (5a^2 - 5ab - 3b^2)^3 = (6a^2 - 4ab + 4b^2)^3.
```

 אפשר גם להציג קובייה כסכום של שלוש קוביות באחת משתי דרכים פרמטריות:[^11]



```math
\begin{align}
a^3(a^3 + b^3)^3 &= b^3(a^3 + b^3)^3 + a^3(a^3 - 2b^3)^3 + b^3(2a^3 - b^3)^3, \\
a^3(a^3 + 2b^3)^3 &= a^3(a^3 - b^3)^3 + b^3(a^3 - b^3)^3 + b^3(2a^3 + b^3)^3.
\end{align}
```

 (שלוש הזהויות נבדקו בפיתוח סימבולי.) את המספר $`2{,}100{,}000^3`$ אפשר לכתוב כסכום של שלוש קוביות חיוביות בתשע דרכים שונות.[^12]

=== k = 4 ===



```math
\begin{align}
422481^4 &= 95800^4 + 217519^4 + 414560^4, \\
353^4 &= 30^4 + 120^4 + 272^4 + 315^4
\end{align}
```

 (ר. פריי, 1988; ר. נורי, הקטן ביותר, 1911).

=== k = 5 ===



```math
\begin{align}
144^5 &= 27^5 + 84^5 + 110^5 + 133^5, \\
72^5 &= 19^5 + 43^5 + 46^5 + 47^5 + 67^5, \\
94^5 &= 21^5 + 23^5 + 37^5 + 79^5 + 84^5, \\
107^5 &= 7^5 + 43^5 + 57^5 + 80^5 + 100^5
\end{align}
```

 (לנדר ופרקין, 1966; לנדר, פרקין וסלפרידג', הקטן ביותר, 1967; לנדר, פרקין וסלפרידג', השני בגודלו, 1967; סאסטרי, 1934, השלישי בגודלו).

=== k = 6 === ידוע מאז 2002 שאין פתרונות עבור $`k = 6`$ שהאיבר האחרון בהם קטן או שווה ל-730000.[^13]

=== k = 7 ===



```math
568^7 = 127^7 + 258^7 + 266^7 + 413^7 + 430^7 + 439^7 + 525^7
```

 (מ. דודריל, 1999).

=== k = 8 ===



```math
1409^8 = 90^8 + 223^8 + 478^8 + 524^8 + 748^8 + 1088^8 + 1190^8 + 1324^8
```

 (ס. צ'ייס, 2000).
