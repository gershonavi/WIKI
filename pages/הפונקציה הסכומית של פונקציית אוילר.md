# הפונקציה הסכומית של פונקציית אוילר

ב[תורת המספרים](https://he.wikipedia.org/wiki/%D7%AA%D7%95%D7%A8%D7%AA_%D7%94%D7%9E%D7%A1%D7%A4%D7%A8%D7%99%D7%9D), **הפונקציה הסכומית של פונקציית אוילר** $`\Phi(n)`$ היא הפונקציה הסכומית של [פונקציית אוילר](https://he.wikipedia.org/wiki/%D7%A4%D7%95%D7%A0%D7%A7%D7%A6%D7%99%D7%99%D7%AA_%D7%90%D7%95%D7%99%D7%9C%D7%A8), המוגדרת על ידי



```math
\Phi(n) = \sum_{k=1}^n \varphi(k), \qquad n\in \mathbb{N}.
```



זהו מספר הזוגות הסדורים $`(p,q)`$ של מספרים שלמים [זרים](https://he.wikipedia.org/wiki/%D7%9E%D7%A1%D7%A4%D7%A8%D7%99%D7%9D_%D7%96%D7%A8%D7%99%D7%9D) המקיימים $`1 \le p \le q \le n`$.

הערכים הראשונים הם 0, 1, 2, 4, 6, 10, 12, 18, 22, 28, 32, ... (סדרה [A002088](https://oeis.org/A002088) ב-OEIS). הערכים בחזקות של 10 הם 1, 32, 3044, 304192, 30397486, 3039650754, ... (סדרה [A064018](https://oeis.org/A064018)).

## תכונות

לכל $`n \geq 0`$ ממשי מתקיימת הזהות



```math
\sum_{d=1}^n \Phi\left(\frac{n}{d}\right)=\frac{1}{2}\lfloor n \rfloor \lfloor n+1 \rfloor,
```



הנותנת נוסחת נסיגה סתומה לפונקציה.[^1]

הפעלת [נוסחת ההיפוך של מביוס](https://he.wikipedia.org/wiki/%D7%A0%D7%95%D7%A1%D7%97%D7%AA_%D7%94%D7%94%D7%99%D7%A4%D7%95%D7%9A_%D7%A9%D7%9C_%D7%9E%D7%91%D7%99%D7%95%D7%A1) על פונקציית אוילר או על הזהות שלעיל נותנת



```math
\Phi(n) = \sum_{k=1}^n k\sum _{d\mid k} \frac {\mu (d)}{d} = \frac{1}{2} \sum _{k=1}^n \mu(k) \left\lfloor \frac {n}{k} \right\rfloor \left(1 + \left\lfloor \frac {n}{k} \right\rfloor \right),
```



כאשר $`\mu`$ היא [פונקציית מביוס](https://he.wikipedia.org/wiki/%D7%A4%D7%95%D7%A0%D7%A7%D7%A6%D7%99%D7%99%D7%AA_%D7%9E%D7%91%D7%99%D7%95%D7%A1). מכאן אפשר להראות של-$`\Phi(n)`$ יש הפיתוח האסימפטוטי



```math
\Phi(n) = \frac{1}{2\zeta(2)}n^{2}+O\left( n\log n \right ) = \frac{3}{\pi^2}n^2+O\left( n\log n \right),
```



כאשר $`\zeta(2) = \pi^2/6`$ הוא ערך [פונקציית זטא של רימן](https://he.wikipedia.org/wiki/%D7%A4%D7%95%D7%A0%D7%A7%D7%A6%D7%99%D7%99%D7%AA_%D7%96%D7%98%D7%90_%D7%A9%D7%9C_%D7%A8%D7%99%D7%9E%D7%9F) בנקודה 2.[^2]

## הפונקציה הסכומית של ההופכי

הפונקציה הסכומית של ההופכי של פונקציית אוילר היא



```math
S(n) = \sum _{k=1}^{n}{\frac {1}{\varphi (k)}}.
```



[אדמונד לנדאו](https://he.wikipedia.org/wiki/%D7%90%D7%93%D7%9E%D7%95%D7%A0%D7%93_%D7%9C%D7%A0%D7%93%D7%90%D7%95) הראה בשנת 1900 שלפונקציה זו ההתנהגות האסימפטוטית[^3]



```math
S(n) = A (\gamma+\log n)+ B +O\left(\frac{\log n} n\right),
```



כאשר $`\gamma`$ הוא [קבוע אוילר-מסקרוני](https://he.wikipedia.org/wiki/%D7%A7%D7%91%D7%95%D7%A2_%D7%90%D7%95%D7%99%D7%9C%D7%A8-%D7%9E%D7%A1%D7%A7%D7%A8%D7%95%D7%A0%D7%99),



```math
A = \sum_{k=1}^\infty \frac{\mu (k)^2}{k \varphi(k)} = \frac{\zeta(2)\zeta(3)}{\zeta(6)} = \prod_{p} \left(1+\frac 1 {p(p-1)} \right)
```



ו-



```math
B = \sum_{k=1}^{\infty} \frac{\mu (k)^2\log k}{k \,\varphi(k)} = A \sum_{p}\frac {\log p}{p^2-p+1}.
```



הקבוע $`A = 1.943596\ldots`$ נקרא לעיתים **קבוע לנדאו לפונקציית אוילר**. הטור $`\sum_{k=1}^\infty 1 / (k \varphi (k))`$ מתכנס ל-



```math
\sum _{k=1}^\infty \frac 1 {k\varphi (k)} = \zeta(2) \prod_{p} \left(1 + \frac 1 {p^2(p-1)}\right) =2.20386\ldots
```



המכפלה על הראשוניים באגף ימין היא קבוע (סדרה [A065483](https://oeis.org/A065483) ב-OEIS) שערכו



```math
\prod_{p} \left(1+\frac 1 {p^2(p-1)} \right) = 1.339784\ldots
```
