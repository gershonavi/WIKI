# פונקציית קלאוזן

<img src="https://commons.wikimedia.org/wiki/Special:FilePath/Mplwp_Clausen.svg" alt="הגרף של פונקציית קלאוזן <math>\mathrm{Cl}_2(\theta)</math>" width="320">

ב[מתמטיקה](https://he.wikipedia.org/wiki/%D7%9E%D7%AA%D7%9E%D7%98%D7%99%D7%A7%D7%94), **פונקציית קלאוזן** (ב[אנגלית](https://he.wikipedia.org/wiki/%D7%90%D7%A0%D7%92%D7%9C%D7%99%D7%AA): Clausen function), שהציג תומאס קלאוזן ב-1832, היא [פונקציה טרנסצנדנטית](https://he.wikipedia.org/wiki/%D7%A4%D7%95%D7%A0%D7%A7%D7%A6%D7%99%D7%94_%D7%98%D7%A8%D7%A0%D7%A1%D7%A6%D7%A0%D7%93%D7%A0%D7%98%D7%99%D7%AA) מיוחדת של משתנה אחד. אפשר להציג אותה כ[אינטגרל מסוים](https://he.wikipedia.org/wiki/%D7%90%D7%99%D7%A0%D7%98%D7%92%D7%A8%D7%9C_%D7%9E%D7%A1%D7%95%D7%99%D7%9D), כ[טור טריגונומטרי](https://he.wikipedia.org/wiki/%D7%98%D7%95%D7%A8_%D7%A4%D7%95%D7%A8%D7%99%D7%99%D7%94) ובצורות נוספות. היא קשורה קשר הדוק ל[פולילוגריתם](https://he.wikipedia.org/wiki/%D7%A4%D7%95%D7%9C%D7%99%D7%9C%D7%95%D7%92%D7%A8%D7%99%D7%AA%D7%9D), ל[פונקציית פוליגמא](https://he.wikipedia.org/wiki/%D7%A4%D7%95%D7%A0%D7%A7%D7%A6%D7%99%D7%99%D7%AA_%D7%A4%D7%95%D7%9C%D7%99%D7%92%D7%9E%D7%90), ל[פונקציית זטא של רימן](https://he.wikipedia.org/wiki/%D7%A4%D7%95%D7%A0%D7%A7%D7%A6%D7%99%D7%99%D7%AA_%D7%96%D7%98%D7%90_%D7%A9%D7%9C_%D7%A8%D7%99%D7%9E%D7%9F), ל[פונקציית אטא של דיריכלה](%D7%A4%D7%95%D7%A0%D7%A7%D7%A6%D7%99%D7%99%D7%AA%20%D7%90%D7%98%D7%90%20%D7%A9%D7%9C%20%D7%93%D7%99%D7%A8%D7%99%D7%9B%D7%9C%D7%94.md) ול[פונקציית בטא של דיריכלה](https://he.wikipedia.org/wiki/%D7%A4%D7%95%D7%A0%D7%A7%D7%A6%D7%99%D7%99%D7%AA_%D7%91%D7%98%D7%90_%D7%A9%D7%9C_%D7%93%D7%99%D7%A8%D7%99%D7%9B%D7%9C%D7%94).

**פונקציית קלאוזן מסדר 2** – שנקראת לעיתים קרובות "פונקציית קלאוזן", אף שהיא רק אחת ממשפחה שלמה של פונקציות – נתונה על ידי האינטגרל



```math
\mathrm{Cl}_2(\varphi)=-\int_0^\varphi \log\left|2\sin\frac{x}{2} \right|\, dx,
```

 כאשר $`\log`$ מסמן את ה[לוגריתם הטבעי](https://he.wikipedia.org/wiki/%D7%9C%D7%95%D7%92%D7%A8%D7%99%D7%AA%D7%9D_%D7%98%D7%91%D7%A2%D7%99). בתחום $`0 < \varphi < 2\pi`$ פונקציית ה[סינוס](https://he.wikipedia.org/wiki/%D7%A1%D7%99%D7%A0%D7%95%D7%A1_%28%D7%98%D7%A8%D7%99%D7%92%D7%95%D7%A0%D7%95%D7%9E%D7%98%D7%A8%D7%99%D7%94%29) שבתוך סימן ה[ערך המוחלט](https://he.wikipedia.org/wiki/%D7%A2%D7%A8%D7%9A_%D7%9E%D7%95%D7%97%D7%9C%D7%98) חיובית ממש, ולכן אפשר להשמיט את סימן הערך המוחלט. לפונקציית קלאוזן יש גם הצגה כ[טור פורייה](https://he.wikipedia.org/wiki/%D7%98%D7%95%D7%A8_%D7%A4%D7%95%D7%A8%D7%99%D7%99%D7%94):



```math
\mathrm{Cl}_2(\varphi)=\sum_{k=1}^\infty \frac{\sin k\varphi}{k^2} = \sin\varphi +\frac{\sin 2\varphi}{2^2}+\frac{\sin 3\varphi}{3^2}+\frac{\sin 4\varphi}{4^2}+ \cdots
```



פונקציות קלאוזן, כמשפחה של פונקציות, מופיעות בתחומי מחקר רבים במתמטיקה המודרנית, בפרט בחישוב סוגים רבים של אינטגרלים לוגריתמיים ופולילוגריתמיים, מסוימים ולא מסוימים. יש להן גם שימושים רבים בסכימת [טורים היפרגאומטריים](https://he.wikipedia.org/wiki/%D7%98%D7%95%D7%A8_%D7%94%D7%99%D7%A4%D7%A8%D7%92%D7%90%D7%95%D7%9E%D7%98%D7%A8%D7%99), בסכומים שמערבים את ההופכי של [המקדם הבינומי](https://he.wikipedia.org/wiki/%D7%9E%D7%A7%D7%93%D7%9D_%D7%91%D7%99%D7%A0%D7%95%D7%9E%D7%99) המרכזי, בסכומים של פונקציית פוליגמא ובטורי L של דיריכלה.

## תכונות בסיסיות

לפונקציית קלאוזן (מסדר 2) יש [אפסים](https://he.wikipedia.org/wiki/%D7%A9%D7%95%D7%A8%D7%A9_%28%D7%A9%D7%9C_%D7%A4%D7%95%D7%A0%D7%A7%D7%A6%D7%99%D7%94%29) פשוטים בכל הכפולות השלמות של $`\pi`$, כי אם $`k`$ שלם אז $`\sin k\pi=0`$:



```math
\mathrm{Cl}_2(m\pi) = 0, \quad m= 0,\, \pm 1,\, \pm 2,\, \pm 3,\, \cdots
```



יש לה מקסימום בנקודות $`\theta = \frac{\pi}{3}+2m\pi`$ ($`m`$ שלם):



```math
\mathrm{Cl}_2\left(\frac{\pi}{3}+2m\pi \right) =1.01494160 \ldots
```

 ומינימום בנקודות $`\theta = -\frac{\pi}{3}+2m\pi`$:



```math
\mathrm{Cl}_2\left(-\frac{\pi}{3}+2m\pi \right) =-1.01494160 \ldots
```



התכונות הבאות נובעות ישירות מהגדרת הטור:



```math
\mathrm{Cl}_2(\theta+2m\pi) = \mathrm{Cl}_2(\theta), \qquad \mathrm{Cl}_2(-\theta) = -\mathrm{Cl}_2(\theta).
```

 ראו (Lu & Perez, 1992).

## הגדרה כללית

באופן כללי יותר, מגדירים את שתי פונקציות קלאוזן המוכללות:



```math
\mathrm{S}_z(\theta) = \sum_{k=1}^\infty \frac{\sin k\theta}{k^z}, \qquad \mathrm{C}_z(\theta) = \sum_{k=1}^\infty \frac{\cos k\theta}{k^z},
```

 שמוגדרות עבור $`z`$ מרוכב עם $`\mathrm{Re} z > 1`$. אפשר להרחיב את ההגדרה לכל ה[מישור המרוכב](https://he.wikipedia.org/wiki/%D7%94%D7%9E%D7%99%D7%A9%D7%95%D7%A8_%D7%94%D7%9E%D7%A8%D7%95%D7%9B%D7%91) באמצעות [המשכה אנליטית](https://he.wikipedia.org/wiki/%D7%94%D7%9E%D7%A9%D7%9B%D7%94_%D7%90%D7%A0%D7%9C%D7%99%D7%98%D7%99%D7%AA).

כאשר $`z`$ הוא מספר שלם אי-שלילי, **פונקציות קלאוזן הסטנדרטיות** מוגדרות על ידי טורי הפורייה הבאים:



```math
\mathrm{Cl}_{2m+2}(\theta) = \sum_{k=1}^\infty \frac{\sin k\theta }{k^{2m+2} }, \qquad \mathrm{Cl}_{2m+1}(\theta) = \sum_{k=1}^\infty \frac{\cos k\theta }{k^{2m+1} },
```





```math
\mathrm{Sl}_{2m+2}(\theta) = \sum_{k=1}^\infty \frac{\cos k\theta }{k^{2m+2} }, \qquad \mathrm{Sl}_{2m+1}(\theta) = \sum_{k=1}^\infty \frac{\sin k\theta }{k^{2m+1} }.
```



הערה: לפונקציות קלאוזן מסוג **SL** יש גם הסימון החלופי $`\mathrm{Gl}_m(\theta)`$, והן נקראות לעיתים **פונקציות גלישר–קלאוזן** (על שם ג'יימס ויטבריד לי גלישר; מכאן הסימון GL).

## הקשר לפולינומי ברנולי

פונקציות קלאוזן מסוג SL הן [פולינומים](https://he.wikipedia.org/wiki/%D7%A4%D7%95%D7%9C%D7%99%D7%A0%D7%95%D7%9D) ב-$`\theta`$, והן קשורות קשר הדוק ל[פולינומי ברנולי](https://he.wikipedia.org/wiki/%D7%9E%D7%A1%D7%A4%D7%A8%D7%99_%D7%91%D7%A8%D7%A0%D7%95%D7%9C%D7%99). הקשר נראה מתוך הצגת פולינומי ברנולי כטורי פורייה:



```math
B_{2n-1}(x)=\frac{2(-1)^n(2n-1)!}{(2\pi)^{2n-1} } \, \sum_{k=1}^\infty \frac{\sin 2\pi kx}{k^{2n-1} },
```





```math
B_{2n}(x)=\frac{2(-1)^{n-1}(2n)!}{(2\pi)^{2n} } \, \sum_{k=1}^\infty \frac{\cos 2\pi kx}{k^{2n} }.
```



אם מציבים $`x= \theta/2\pi`$ ומסדרים את האיברים, מקבלים את הביטויים הסגורים (הפולינומיים) הבאים:



```math
\mathrm{Sl}_{2m}(\theta) = \frac{(-1)^{m-1}(2\pi)^{2m} }{2(2m)!} B_{2m}\left(\frac{\theta}{2\pi}\right),
```





```math
\mathrm{Sl}_{2m-1}(\theta) = \frac{(-1)^{m}(2\pi)^{2m-1} }{2(2m-1)!} B_{2m-1}\left(\frac{\theta}{2\pi}\right),
```

 כאשר פולינומי ברנולי $`B_n(x)`$ מוגדרים באמצעות [מספרי ברנולי](https://he.wikipedia.org/wiki/%D7%9E%D7%A1%D7%A4%D7%A8%D7%99_%D7%91%D7%A8%D7%A0%D7%95%D7%9C%D7%99) $`B_n \equiv B_n(0)`$ על ידי



```math
B_n(x)=\sum_{j=0}^n\binom{n}{j} B_jx^{n-j}.
```



מכאן מתקבלים, למשל (עבור $`0 \le \theta \le 2\pi`$):



```math
\mathrm{Sl}_1(\theta)= \frac{\pi}{2}-\frac \theta 2,
```





```math
\mathrm{Sl}_2(\theta)= \frac{\pi^2}{6}-\frac{\pi\theta} 2 +\frac{\theta^2}{4},
```





```math
\mathrm{Sl}_3(\theta)= \frac{\pi^2\theta}{6} -\frac{\pi\theta^2}{4}+\frac{\theta^3}{12},
```





```math
\mathrm{Sl}_4(\theta)= \frac{\pi^4}{90}-\frac{\pi^2\theta^2}{12}+\frac{\pi\theta^3}{12}-\frac{\theta^4}{48}.
```



## נוסחת ההכפלה

עבור $`0 < \theta < \pi`$ אפשר להוכיח ישירות מהגדרת הטור או האינטגרל את נוסחת ההכפלה (ראו גם Lu & Perez, 1992, שם התוצאה מופיעה בלי הוכחה):



```math
\mathrm{Cl}_2(2\theta) = 2\mathrm{Cl}_2(\theta) - 2\mathrm{Cl}_2(\pi-\theta).
```



נסמן ב-$`K=\mathrm{Cl}_2\left(\frac{\pi}{2}\right)`$ את [קבוע קטלן](https://he.wikipedia.org/wiki/%D7%A7%D7%91%D7%95%D7%A2_%D7%A7%D7%98%D7%9C%D7%9F). מנוסחת ההכפלה נובעים מיד הקשרים



```math
\mathrm{Cl}_2\left(\frac{\pi}{4}\right)- \mathrm{Cl}_2 \left(\frac{3\pi} 4\right)=\frac K 2, \qquad 2\mathrm{Cl}_2\left(\frac{\pi}{3}\right)= 3\mathrm{Cl}_2 \left(\frac{2\pi} 3\right).
```



לפונקציות קלאוזן מסדר גבוה יותר אפשר לקבל נוסחאות הכפלה מהנוסחה שלמעלה: מחליפים את $`\theta`$ במשתנה דמה $`x`$ ומבצעים אינטגרציה על הקטע $`[0, \theta]`$. חזרה על התהליך נותנת:



```math
\mathrm{Cl}_3(2\theta) = 4\mathrm{Cl}_3(\theta) + 4\mathrm{Cl}_3(\pi-\theta),
```





```math
\mathrm{Cl}_4(2\theta) = 8\mathrm{Cl}_4(\theta) - 8\mathrm{Cl}_4(\pi-\theta),
```





```math
\mathrm{Cl}_5(2\theta) = 16\mathrm{Cl}_5(\theta) + 16 \mathrm{Cl}_5(\pi-\theta),
```





```math
\mathrm{Cl}_6(2\theta) = 32\mathrm{Cl}_6(\theta) - 32 \mathrm{Cl}_6(\pi-\theta),
```

 ובאופן כללי, באינדוקציה על $`m \ge 1`$:



```math
\mathrm{Cl}_{m+1}(2\theta) = 2^m\left[\mathrm{Cl}_{m+1}(\theta) + (-1)^m \mathrm{Cl}_{m+1}(\pi-\theta) \right].
```



נוסחת ההכפלה המוכללת מאפשרת להרחיב את התוצאה על פונקציית קלאוזן מסדר 2 שמערבת את קבוע קטלן. עבור $`m \ge 1`$ שלם:



```math
\mathrm{Cl}_{2m}\left(\frac \pi 2 \right) = 2^{2m-1} \left[\mathrm{Cl}_{2m}\left(\frac{\pi}{4}\right)- \mathrm{Cl}_{2m}\left(\frac{3\pi}{4}\right) \right] = \beta(2m),
```

 כאשר $`\beta(x)`$ היא [פונקציית בטא של דיריכלה](https://he.wikipedia.org/wiki/%D7%A4%D7%95%D7%A0%D7%A7%D7%A6%D7%99%D7%99%D7%AA_%D7%91%D7%98%D7%90_%D7%A9%D7%9C_%D7%93%D7%99%D7%A8%D7%99%D7%9B%D7%9C%D7%94).

### הוכחת נוסחת ההכפלה

מהגדרת האינטגרל,



```math
\mathrm{Cl}_2(2\theta)=-\int_0^{2\theta} \log\left| 2 \sin \frac{x}{2} \right| \,dx.
```

 לפי נוסחת הזווית הכפולה של הסינוס, $`\sin x = 2\sin\frac{x}{2}\cos\frac{x}{2}`$, מקבלים



```math
\begin{align}
& -\int_0^{2\theta} \log\left| \left(2 \sin \frac{x}{4} \right)\left(2 \cos \frac{x}{4} \right) \right| \,dx \\
= {} & -\int_0^{2\theta} \log\left| 2 \sin \frac{x}{4} \right| \,dx -\int_0^{2\theta} \log\left| 2 \cos \frac{x}{4} \right| \,dx .
\end{align}
```

 בשני האינטגרלים נציב $`x=2y`$, $`dx=2\, dy`$:



```math
\begin{align}
& -2\int_0^\theta \log\left| 2 \sin \frac{x}{2} \right| \,dx -2\int_0^\theta \log\left| 2 \cos \frac{x}{2} \right| \,dx \\
= {} & 2\, \mathrm{Cl}_2(\theta) -2\int_0^\theta \log\left| 2 \cos \frac{x}{2} \right| \,dx .
\end{align}
```

 באינטגרל האחרון נציב $`y=\pi-x`$, $`dx = -dy`$, ונשתמש בזהות $`\cos\left(\frac{\pi-y}{2}\right) = \sin \frac{y}{2}`$:



```math
\begin{align}
\mathrm{Cl}_2(2\theta) &=2\, \mathrm{Cl}_2(\theta) -2\int_0^\theta \log\left| 2 \cos \frac{x}{2} \right| \,dx \\
&= 2\, \mathrm{Cl}_2(\theta) +2\int_{\pi}^{\pi-\theta} \log\left| 2 \sin \frac{y}{2} \right| \,dy \\
&= 2\, \mathrm{Cl}_2(\theta) -2\, \mathrm{Cl}_2(\pi-\theta) + 2\, \mathrm{Cl}_2(\pi).
\end{align}
```

 מאחר ש-$`\mathrm{Cl}_2(\pi) = 0`$, מקבלים



```math
\mathrm{Cl}_2(2\theta)=2\, \mathrm{Cl}_2(\theta)-2\, \mathrm{Cl}_2(\pi-\theta). \qquad \blacksquare
```



## נגזרות של פונקציות קלאוזן מסדר כללי

גזירה ישירה של טורי הפורייה נותנת:



```math
\frac{d}{d\theta}\mathrm{Cl}_{2m+2}(\theta) = \sum_{k=1}^\infty \frac{\cos k\theta }{k^{2m+1} }=\mathrm{Cl}_{2m+1}(\theta),
```





```math
\frac{d}{d\theta}\mathrm{Cl}_{2m+1}(\theta) = -\sum_{k=1}^\infty \frac{\sin k\theta }{k^{2m} }=-\mathrm{Cl}_{2m}(\theta),
```





```math
\frac{d}{d\theta}\mathrm{Sl}_{2m+2}(\theta) = -\sum_{k=1}^\infty \frac{\sin k\theta }{k^{2m+1} }=-\mathrm{Sl}_{2m+1} (\theta),
```





```math
\frac{d}{d\theta}\mathrm{Sl}_{2m+1}(\theta) = \sum_{k=1}^\infty \frac{\cos k\theta }{k^{2m} }=\mathrm{Sl}_{2m} (\theta).
```



לפי [המשפט היסודי של החשבון האינפיניטסימלי](https://he.wikipedia.org/wiki/%D7%94%D7%9E%D7%A9%D7%A4%D7%98_%D7%94%D7%99%D7%A1%D7%95%D7%93%D7%99_%D7%A9%D7%9C_%D7%94%D7%97%D7%A9%D7%91%D7%95%D7%9F_%D7%94%D7%90%D7%99%D7%A0%D7%A4%D7%99%D7%A0%D7%99%D7%98%D7%A1%D7%99%D7%9E%D7%9C%D7%99) מתקיים גם



```math
\frac{d}{d\theta}\mathrm{Cl}_2(\theta) = \frac{d}{d\theta} \left[ -\int_0^\theta \log \left| 2\sin \frac{x}{2}\right| \,dx \, \right] = - \log \left| 2\sin \frac{\theta}{2}\right| = \mathrm{Cl}_1(\theta).
```



## הקשר לאינטגרל הארקטנגנס

*אינטגרל הארקטנגנס* מוגדר בקטע $`0 < z < 1`$ על ידי



```math
\mathrm{Ti}_2(z)=\int_0^z \frac{\tan^{-1}x}{x}\,dx = \sum_{k=0}^\infty (-1)^k \frac{z^{2k+1} }{(2k+1)^2}.
```

 יש לו הצגה סגורה באמצעות פונקציית קלאוזן:



```math
\mathrm{Ti}_2(\tan \theta)= \theta\log(\tan \theta) + \frac{1}{2} \mathrm{Cl}_2(2\theta) +\frac{1}{2}\mathrm{Cl}_2(\pi-2\theta).
```



### הוכחה

מהגדרת אינטגרל הארקטנגנס,



```math
\mathrm{Ti}_2(\tan \theta) = \int_0^{\tan \theta}\frac{\tan^{-1}x}{x}\,dx .
```

 [אינטגרציה בחלקים](https://he.wikipedia.org/wiki/%D7%90%D7%99%D7%A0%D7%98%D7%92%D7%A8%D7%A6%D7%99%D7%94_%D7%91%D7%97%D7%9C%D7%A7%D7%99%D7%9D) נותנת



```math
\int_0^{\tan \theta} \frac{\tan^{-1}x}{x}\,dx= \tan^{-1}x\log x \, \Bigg|_0^{\tan \theta} - \int_0^{\tan \theta} \frac{\log x}{1+x^2}\,dx = \theta \log \tan \theta - \int_0^{\tan \theta}\frac{\log x}{1+x^2}\,dx .
```

 ההצבה $`x=\tan y`$, $`dy=\frac{dx}{1+x^2}`$ נותנת



```math
\theta \log \tan \theta - \int_0^\theta \log(\tan y)\,dy .
```

 באינטגרל האחרון נציב $`y=x/2`$, $`dy=dx/2`$:



```math
\begin{align}
& \theta \log \tan \theta - \frac 1 2 \int_0^{2\theta}\log\left(\tan \frac x 2 \right)\,dx \\[6pt]
= {} & \theta \log \tan \theta - \frac{1}{2}\int_0^{2\theta}\log\left(\frac{2\sin (x/2) }{2\cos (x/2)}\right)\,dx \\[6pt]
= {} & \theta \log \tan \theta - \frac{1}{2}\int_0^{2\theta}\log\left(2\sin \frac{x}{2} \right)\,dx+ \frac{1}{2}\int_0^{2\theta}\log\left(2\cos \frac{x}{2}\right)\,dx \\[6pt]
= {} & \theta \log \tan \theta +\frac{1}{2}\mathrm{Cl}_2(2\theta)+ \frac{1}{2} \int_0^{2\theta} \log\left(2\cos \frac{x}{2}\right)\,dx.
\end{align}
```

 לבסוף, כמו בהוכחת נוסחת ההכפלה, ההצבה $`x=\pi-y`$ מעבירה את האינטגרל האחרון ל-



```math
\int_0^{2\theta}\log\left(2\cos \frac{x}{2}\right)\,dx= \mathrm{Cl}_2(\pi-2\theta) - \mathrm{Cl}_2(\pi) = \mathrm{Cl}_2(\pi-2\theta).
```

 לכן



```math
\mathrm{Ti}_2(\tan \theta) = \theta \log \tan \theta +\frac{1}{2}\mathrm{Cl}_2(2\theta)+ \frac{1}{2} \mathrm{Cl}_2(\pi-2\theta). \qquad \blacksquare
```



## הקשר לפונקציית G של בארנס

עבור $`0 < z < 1`$ ממשי אפשר לבטא את פונקציית קלאוזן מסדר 2 באמצעות פונקציית G של בארנס ו[פונקציית גמא](https://he.wikipedia.org/wiki/%D7%A4%D7%95%D7%A0%D7%A7%D7%A6%D7%99%D7%99%D7%AA_%D7%92%D7%9E%D7%90):



```math
\mathrm{Cl}_{2}(2\pi z) = 2\pi \log \left( \frac{G(1-z)}{G(1+z)} \right) +2\pi z \log \left( \frac{\pi}{ \sin \pi z } \right) ,
```

 או, באופן שקול,



```math
\mathrm{Cl}_{2}(2\pi z) = 2\pi \log \left( \frac{G(1-z)}{G(z)} \right) -2\pi \log \Gamma(z)+2\pi z \log \left( \frac{\pi}{ \sin \pi z } \right) .
```

 ראו (Adamchik, 2003).

## הקשר לפולילוגריתם

פונקציות קלאוזן הן החלק הממשי והחלק המדומה של ה[פולילוגריתם](https://he.wikipedia.org/wiki/%D7%A4%D7%95%D7%9C%D7%99%D7%9C%D7%95%D7%92%D7%A8%D7%99%D7%AA%D7%9D) על [מעגל היחידה](https://he.wikipedia.org/wiki/%D7%9E%D7%A2%D7%92%D7%9C_%D7%94%D7%99%D7%97%D7%99%D7%93%D7%94):



```math
\mathrm{Cl}_{2m}(\theta) = \mathrm{Im} (\mathrm{Li}_{2m}(e^{i \theta})), \quad m \ge 1,
```





```math
\mathrm{Cl}_{2m+1}(\theta) = \mathrm{Re} (\mathrm{Li}_{2m+1}(e^{i \theta})), \quad m \ge 0 .
```

 קל לראות זאת מהגדרת הפולילוגריתם כטור:



```math
\mathrm{Li}_n(z)=\sum_{k=1}^\infty \frac{z^k}{k^n} \quad \Longrightarrow \quad \mathrm{Li}_n\left(e^{i\theta}\right)= \sum_{k=1}^\infty \frac{e^{ik\theta} }{k^n}.
```

 לפי [נוסחת אוילר](https://he.wikipedia.org/wiki/%D7%A0%D7%95%D7%A1%D7%97%D7%AA_%D7%90%D7%95%D7%99%D7%9C%D7%A8) $`e^{i\theta} = \cos \theta +i\sin \theta`$, ולפי [נוסחת דה-מואבר](https://he.wikipedia.org/wiki/%D7%A0%D7%95%D7%A1%D7%97%D7%AA_%D7%93%D7%94-%D7%9E%D7%95%D7%90%D7%91%D7%A8)



```math
(\cos \theta +i\sin \theta)^k= \cos k\theta +i\sin k\theta \quad \Rightarrow \quad \mathrm{Li}_n\left(e^{i\theta}\right)=\sum_{k=1}^\infty \frac{\cos k\theta}{k^n}+ i \, \sum_{k=1}^\infty \frac{\sin k\theta}{k^n}.
```

 לכן



```math
\mathrm{Li}_{2m}\left(e^{i\theta}\right)= \mathrm{Sl}_{2m}(\theta)+i\mathrm{Cl}_{2m}(\theta), \qquad \mathrm{Li}_{2m+1}\left(e^{i\theta}\right) = \mathrm{Cl}_{2m+1}(\theta)+i\mathrm{Sl}_{2m+1}(\theta).
```



## הקשר לפונקציית פוליגמא

פונקציות קלאוזן קשורות קשר הדוק ל[פונקציית פוליגמא](https://he.wikipedia.org/wiki/%D7%A4%D7%95%D7%A0%D7%A7%D7%A6%D7%99%D7%99%D7%AA_%D7%A4%D7%95%D7%9C%D7%99%D7%92%D7%9E%D7%90). אפשר לבטא אותן כצירופים ליניאריים של סינוסים ופונקציות פוליגמא. אחד הקשרים האלה (והוכחתו בהמשך):



```math
\mathrm{Cl}_{2m}\left( \frac{q\pi}{p}\right)= \frac{1}{(2p)^{2m}(2m-1)!} \, \sum_{j=1}^{p} \sin\left(\tfrac{qj\pi}{p}\right)\, \left[\psi_{2m-1}\left(\tfrac{j}{2p}\right)+(-1)^q\psi_{2m-1}\left(\tfrac{j+p}{2p}\right)\right].
```

 מסקנה מיידית היא הנוסחה השקולה באמצעות [פונקציית זטא של הורוויץ](%D7%A4%D7%95%D7%A0%D7%A7%D7%A6%D7%99%D7%99%D7%AA%20%D7%96%D7%98%D7%90%20%D7%A9%D7%9C%20%D7%94%D7%95%D7%A8%D7%95%D7%95%D7%99%D7%A5.md):



```math
\mathrm{Cl}_{2m}\left( \frac{q\pi}{p}\right)= \frac{1}{(2p)^{2m} } \, \sum_{j=1}^{p} \sin\left(\tfrac{qj\pi}{p}\right)\, \left[\zeta\left(2m,\tfrac{j}{2p}\right)+(-1)^q \zeta\left(2m,\tfrac{j+p}{2p}\right)\right].
```



### הוכחה

יהיו $`p`$ ו-$`q`$ מספרים שלמים חיוביים כך ש-$`0 < q/p < 1`$. לפי הגדרת הטור של פונקציית קלאוזן מסדר זוגי,



```math
\mathrm{Cl}_{2m}\left( \frac{q\pi}{p}\right)= \sum_{k=1}^\infty \frac{\sin (kq\pi/p)}{k^{2m} } .
```

 נפצל את הסכום ל-$`p`$ חלקים בדיוק לפי השארית של $`k`$ מודולו $`p`$: החלק ה-$`j`$ מכיל את האיברים מהצורה $`kp+j`$, עבור $`j = 1, \ldots, p`$. כך מקבלים סכום כפול:



```math
\mathrm{Cl}_{2m}\left( \frac{q\pi}{p}\right)= \sum_{j=1}^{p} \sum_{k=0}^\infty \frac{\sin \left[(kp+j)\frac{q\pi}{p}\right]}{(kp+j)^{2m} } = \sum_{j=1}^{p} \frac{1}{p^{2m} } \sum_{k=0}^\infty \frac{\sin \left[(kp+j)\frac{q\pi}{p}\right]}{(k+j/p)^{2m} } .
```

 לפי נוסחת החיבור של הסינוס,



```math
\sin \left[(kp+j)\frac{q\pi}{p}\right]=\sin kq\pi \cos \frac{qj\pi}{p}+\cos kq\pi \sin\frac{qj\pi}{p} = (-1)^{kq}\sin\frac{qj\pi}{p},
```

 כי $`\sin m\pi = 0`$ ו-$`\cos m\pi = (-1)^m`$ לכל $`m`$ שלם. לכן



```math
\mathrm{Cl}_{2m}\left( \frac{q\pi}{p}\right)= \sum_{j=1}^p \frac{1}{p^{2m} } \sin\left(\frac{qj\pi}{p}\right) \sum_{k=0}^\infty \frac{(-1)^{kq} }{(k+j/p)^{2m} } .
```

 כדי להפוך את הסכום הפנימי לסכום לא מתחלף, נפצל אותו לפי הזוגיות של $`k`$:



```math
\begin{align}
\sum_{k=0}^\infty \frac{(-1)^{kq} }{(k+j/p)^{2m} } &=\sum_{k=0}^\infty \frac{1}{(2k+j/p)^{2m} }+ (-1)^q \sum_{k=0}^\infty \frac{1}{(2k+1+j/p)^{2m} } \\
&= \frac{1}{2^{2m} }\left[ \sum_{k=0}^\infty \frac{1}{(k+\frac{j}{2p})^{2m} }+ (-1)^q \sum_{k=0}^\infty \frac{1}{\left(k+\frac{j+p}{2p}\right)^{2m} } \right].
\end{align}
```

 עבור $`m \ge 1`$ שלם, לפונקציית פוליגמא יש ההצגה כטור



```math
\psi_m(z)=(-1)^{m+1}m! \sum_{k=0}^\infty \frac{1}{(k+z)^{m+1} } ,
```

 ולכן הסכום הפנימי שווה ל-



```math
\frac{1}{2^{2m}(2m-1)!} \left[\psi_{2m-1}\left(\tfrac{j}{2p}\right)+(-1)^q\psi_{2m-1} \left(\tfrac{j+p}{2p}\right)\right] .
```

 הצבה בסכום הכפול נותנת את התוצאה המבוקשת. $`\blacksquare`$

## הקשר לאינטגרל הלוגסינוס המוכלל

**אינטגרל הלוגסינוס המוכלל** מוגדר על ידי[^1][^2]



```math
\mathcal{L}s_n^{m}(\theta) = -\int_0^\theta x^m \log^{n-m-1} \left| 2\sin\frac{x}{2} \right| \, dx .
```

 בסימון המוכלל הזה, $`\mathrm{Cl}_2(\theta) = \mathcal{L}s_2^{0}(\theta)`$.

## הקשר של קומר

[ארנסט קומר](https://he.wikipedia.org/wiki/%D7%90%D7%A8%D7%A0%D7%A1%D7%98_%D7%A7%D7%95%D7%9E%D7%A8) ורוג'רס נתנו את הקשר



```math
\mathrm{Li}_2(e^{i \theta}) = \zeta(2) - \theta(2\pi-\theta)/4 + i\mathrm{Cl}_2(\theta),
```

 התקף עבור $`0\leq \theta \leq 2\pi`$.

## הקשר לפונקציית לובצ'בסקי

**פונקציית לובצ'בסקי** $`\Lambda`$ היא בעצם אותה פונקציה אחרי החלפת משתנה:



```math
\Lambda(\theta) = - \int_0^\theta \log|2 \sin(t)| \,dt = \mathrm{Cl}_2(2\theta)/2 .
```

 השם "פונקציית לובצ'בסקי" אינו מדויק היסטורית, כי הנוסחאות של [לובצ'בסקי](https://he.wikipedia.org/wiki/%D7%A0%D7%99%D7%A7%D7%95%D7%9C%D7%90%D7%99_%D7%9C%D7%95%D7%91%D7%A6%27%D7%91%D7%A1%D7%A7%D7%99) לנפח היפרבולי השתמשו בפונקציה שונה מעט:



```math
\int_0^\theta \log| \sec(t)| \,dt = \Lambda(\theta+\pi/2)+\theta\log 2.
```



## הקשר לפונקציות L של דיריכלה

עבור ערכים רציונליים של $`\theta/\pi`$ (כלומר $`\theta/\pi=p/q`$ עבור שלמים $`p, q`$), הסדרה $`\sin(n\theta)`$ מחזורית ב-$`n`$, ולכן אפשר לבטא את $`\mathrm{Cl}_s(\theta)`$ כסכום פשוט של ערכי [פונקציית זטא של הורוויץ](%D7%A4%D7%95%D7%A0%D7%A7%D7%A6%D7%99%D7%99%D7%AA%20%D7%96%D7%98%D7%90%20%D7%A9%D7%9C%20%D7%94%D7%95%D7%A8%D7%95%D7%95%D7%99%D7%A5.md) (כמו בסעיף על פונקציית פוליגמא). כך אפשר לחשב בקלות קשרים בין [פונקציות L של דיריכלה](https://he.wikipedia.org/wiki/%D7%A4%D7%95%D7%A0%D7%A7%D7%A6%D7%99%D7%99%D7%AA_L_%D7%A9%D7%9C_%D7%93%D7%99%D7%A8%D7%99%D7%9B%D7%9C%D7%94) מסוימות.

## האצת התכנסות

נוסחה להאצת התכנסות הטור של פונקציית קלאוזן היא



```math
\frac{\mathrm{Cl}_2(\theta)} \theta = 1-\log|\theta| + \sum_{n=1}^\infty \frac{\zeta(2n)}{n(2n+1)} \left(\frac \theta {2\pi}\right)^{2n},
```

 התקפה עבור $`|\theta|<2\pi`$. כאן $`\zeta(s)`$ היא [פונקציית זטא של רימן](https://he.wikipedia.org/wiki/%D7%A4%D7%95%D7%A0%D7%A7%D7%A6%D7%99%D7%99%D7%AA_%D7%96%D7%98%D7%90_%D7%A9%D7%9C_%D7%A8%D7%99%D7%9E%D7%9F). צורה שמתכנסת מהר יותר היא



```math
\frac{\mathrm{Cl}_2(\theta)}{\theta} = 3-\log\left[|\theta| \left(1-\frac{\theta^2}{4\pi^2}\right)\right] -\frac{2\pi}{\theta} \log \left( \frac{2\pi+\theta}{2\pi-\theta}\right) +\sum_{n=1}^\infty \frac{\zeta(2n)-1}{n(2n+1)} \left(\frac{\theta}{2\pi}\right)^{2n}.
```

 ההתכנסות מהירה כי $`\zeta(n)-1`$ שואף לאפס במהירות כאשר $`n`$ גדל. את שתי הצורות מקבלים בטכניקות סכימה מחדש מהסוג שמשמש לקבלת טורי זטא רציונליים (Borwein, Bradley, Crandall, 2000).

נסמן ב-$`G`$ את פונקציית G של בארנס, ב-$`K`$ את [קבוע קטלן](https://he.wikipedia.org/wiki/%D7%A7%D7%91%D7%95%D7%A2_%D7%A7%D7%98%D7%9C%D7%9F) וב-$`V`$ את קבוע גיזקינג. כמה ערכים מיוחדים:



```math
\mathrm{Cl}_2\left(\frac{\pi}{2}\right)=K, \qquad \mathrm{Cl}_2\left(\frac{\pi}{3}\right)=V,
```





```math
\mathrm{Cl}_2\left(\frac{\pi}{3}\right)=3\pi \log\left( \frac{G\left(\frac{2}{3}\right)}{ G\left(\frac{1}{3}\right)} \right)-3\pi \log \Gamma\left(\frac{1}{3}\right)+\pi \log \left(\frac{ 2\pi }{\sqrt{3} }\right),
```





```math
\mathrm{Cl}_2\left(\frac{2\pi}{3}\right)=2\pi \log\left( \frac{G\left(\frac{2}{3}\right)}{ G\left(\frac{1}{3}\right)} \right)-2\pi \log \Gamma\left(\frac{1}{3}\right) +\frac{2\pi}{3} \log \left(\frac{ 2\pi }{\sqrt{3} }\right),
```





```math
\mathrm{Cl}_2\left(\frac{\pi}{4}\right)= 2\pi\log \left( \frac{G\left(\frac{7}{8}\right)}{G\left(\frac{1}{8}\right)} \right) -2\pi \log \Gamma\left(\frac{1}{8}\right)+\frac{\pi}{4}\log \left( \frac{2\pi}{\sqrt{2-\sqrt{2} } } \right),
```





```math
\mathrm{Cl}_2\left(\frac{3\pi}{4}\right)= 2\pi\log \left( \frac{G\left(\frac{5}{8}\right)}{G\left(\frac{3}{8}\right)} \right) -2\pi \log \Gamma\left(\frac{3}{8}\right)+\frac{3\pi}{4}\log \left( \frac{2\pi}{\sqrt{2+\sqrt{2} } } \right),
```





```math
\mathrm{Cl}_2\left(\frac{\pi}{6}\right)= 2\pi\log \left( \frac{G\left(\frac{11}{12}\right)}{G\left(\frac{1}{12}\right)} \right) -2\pi \log \Gamma\left(\frac{1}{12}\right)+\frac{\pi}{6}\log \left( \frac{2\pi \sqrt{2} }{\sqrt{3}-1} \right),
```





```math
\mathrm{Cl}_2\left(\frac{5\pi}{6}\right)= 2\pi\log \left( \frac{G\left(\frac{7}{12}\right)}{G\left(\frac{5}{12}\right)} \right) -2\pi \log \Gamma\left(\frac{5}{12}\right)+\frac{5\pi}{6}\log \left( \frac{2\pi \sqrt{2} }{\sqrt{3}+1} \right).
```

 באופן כללי, מנוסחת השיקוף של פונקציית G של בארנס,



```math
\mathrm{Cl}_2(2\pi z)=2\pi\log\left( \frac{G(1-z)}{G(z)} \right)-2\pi\log\Gamma(z)+2\pi z\log\left(\frac{\pi}{\sin\pi z}\right) ,
```

```math
\mathrm{Cl}_2(2\pi z)=2\pi\log\left( \frac{G(1-z)}{G(z)} \right)-2\pi\log\Gamma(z)+2\pi z\log\big(\Gamma(z)\Gamma(1 - z)\big) .
```



## ערכים מיוחדים מוכללים

כמה ערכים מיוחדים של פונקציות קלאוזן מסדר גבוה:



```math
\mathrm{Cl}_{2m}(0)=\mathrm{Cl}_{2m}(\pi) = \mathrm{Cl}_{2m}(2\pi)=0,
```





```math
\mathrm{Cl}_{2m}\left(\frac{\pi}{2}\right)=\beta(2m),
```





```math
\mathrm{Cl}_{2m+1}(0)=\mathrm{Cl}_{2m+1}(2\pi)=\zeta(2m+1),
```





```math
\mathrm{Cl}_{2m+1}(\pi)=-\eta(2m+1)=-\left(\frac{2^{2m}-1}{2^{2m} }\right) \zeta(2m+1),
```





```math
\mathrm{Cl}_{2m+1}\left(\frac{\pi}{2}\right)=-\frac{1}{2^{2m+1} }\eta(2m+1)=-\left(\frac{2^{2m}-1}{2^{4m+1} }\right)\zeta(2m+1),
```

 כאשר $`\beta(x)`$ היא פונקציית בטא של דיריכלה, $`\eta(x)`$ היא [פונקציית אטא של דיריכלה](%D7%A4%D7%95%D7%A0%D7%A7%D7%A6%D7%99%D7%99%D7%AA%20%D7%90%D7%98%D7%90%20%D7%A9%D7%9C%20%D7%93%D7%99%D7%A8%D7%99%D7%9B%D7%9C%D7%94.md) (שנקראת גם פונקציית זטא המתחלפת), ו-$`\zeta(x)`$ היא פונקציית זטא של רימן.

## אינטגרלים של הפונקציה

מהצגות הטור של פונקציות קלאוזן נובעים בקלות האינטגרלים הבאים:



```math
\int_0^\theta \mathrm{Cl}_{2m}(x)\,dx=\zeta(2m+1)-\mathrm{Cl}_{2m+1}(\theta),
```





```math
\int_0^\theta \mathrm{Cl}_{2m+1}(x)\,dx=\mathrm{Cl}_{2m+2}(\theta),
```





```math
\int_0^\theta \mathrm{Sl}_{2m}(x)\,dx=\mathrm{Sl}_{2m+1}(\theta),
```





```math
\int_0^\theta \mathrm{Sl}_{2m+1}(x)\,dx=\zeta(2m+2)-\mathrm{Sl}_{2m+2}(\theta).
```



בשיטות של [אנליזת פורייה](https://he.wikipedia.org/wiki/%D7%90%D7%A0%D7%9C%D7%99%D7%96%D7%94_%D7%94%D7%A8%D7%9E%D7%95%D7%A0%D7%99%D7%AA) אפשר למצוא את המומנטים הראשונים של ריבוע הפונקציה $`\mathrm{Cl}_2(x)`$ בקטע $`[0,\pi]`$:[^3]



```math
\int_0^\pi \mathrm{Cl}_2^2(x)\,dx=\frac{\pi}{2}\zeta(4),
```





```math
\int_0^\pi x\mathrm{Cl}_2^2(x)\,dx=\frac{221}{90720} \pi^{6}-4 \zeta(\overline{5}, 1)-2 \zeta(\overline{4}, 2),
```





```math
\int_0^\pi x^2\mathrm{Cl}_2^2(x)\,dx=-\frac{2}{3} \pi\left[12 \zeta(\overline{5}, 1)+6 \zeta(\overline{4}, 2)-\frac{23}{10080} \pi^{6}\right].
```

 כאן $`\zeta(\overline{a}, b) = \sum_{n>m\ge1}\frac{(-1)^n}{n^am^b}`$ הם ערכים של פונקציית הזטא המרובה המתחלפת. (הנוסחה הראשונה נובעת מ[זהות פרסבל](https://he.wikipedia.org/wiki/%D7%96%D7%94%D7%95%D7%AA_%D7%A4%D7%A8%D7%A1%D7%91%D7%9C): $`\int_0^{2\pi}\mathrm{Cl}_2^2 = \pi\zeta(4)`$, ו-$`\mathrm{Cl}_2^2`$ סימטרית ביחס ל-$`\pi`$.)

## אינטגרלים שמחושבים באמצעות הפונקציה

אפשר לחשב מספר גדול של אינטגרלים טריגונומטריים ולוגריתמיים-טריגונומטריים באמצעות פונקציית קלאוזן וקבועים מתמטיים נפוצים כמו $`K`$ (קבוע קטלן), $`\log 2`$, ו-$`\zeta(2)`$, $`\zeta(3)`$.

הדוגמאות שלהלן נובעות ישירות מהצגת האינטגרל של פונקציית קלאוזן, וההוכחות דורשות לא הרבה יותר מ[טריגונומטריה](https://he.wikipedia.org/wiki/%D7%98%D7%A8%D7%99%D7%92%D7%95%D7%A0%D7%95%D7%9E%D7%98%D7%A8%D7%99%D7%94) בסיסית, אינטגרציה בחלקים ולעיתים אינטגרציה איבר-איבר של טורי הפורייה. (עבור $`0 < \theta < \pi/2`$.)



```math
\int_0^\theta \log(\sin x)\,dx=-\tfrac{1}{2}\mathrm{Cl}_2(2\theta)-\theta\log 2,
```





```math
\int_0^\theta \log(\cos x)\,dx=\tfrac{1}{2}\mathrm{Cl}_2(\pi-2\theta)-\theta\log 2,
```





```math
\int_0^\theta \log(\tan x)\,dx=-\tfrac{1}{2}\mathrm{Cl}_2(2\theta)-\tfrac{1}{2} \mathrm{Cl}_2(\pi-2\theta),
```





```math
\int_0^\theta \log(1+\cos x)\,dx=2\mathrm{Cl}_2(\pi-\theta)-\theta\log 2,
```





```math
\int_0^\theta \log(1-\cos x)\,dx=-2\mathrm{Cl}_2(\theta)-\theta\log 2,
```





```math
\int_0^\theta \log(1+\sin x)\,dx=2K-2\mathrm{Cl}_2\left(\frac{\pi}{2}+\theta\right) -\theta\log 2,
```





```math
\int_0^\theta \log(1-\sin x)\,dx=-2K+2\mathrm{Cl}_2\left(\frac{\pi}{2}-\theta\right)-\theta\log 2.
```
