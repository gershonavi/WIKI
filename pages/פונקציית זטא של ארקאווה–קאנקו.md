# פונקציית זטא של ארקאווה–קאנקו

ב[מתמטיקה](https://he.wikipedia.org/wiki/%D7%9E%D7%AA%D7%9E%D7%98%D7%99%D7%A7%D7%94), **פונקציית הזטא של ארקאווה–קאנקו** (ב[אנגלית](https://he.wikipedia.org/wiki/%D7%90%D7%A0%D7%92%D7%9C%D7%99%D7%AA): Arakawa–Kaneko zeta function) היא הכללה של [פונקציית זטא של רימן](https://he.wikipedia.org/wiki/%D7%A4%D7%95%D7%A0%D7%A7%D7%A6%D7%99%D7%99%D7%AA_%D7%96%D7%98%D7%90_%D7%A9%D7%9C_%D7%A8%D7%99%D7%9E%D7%9F), שמייצרת ערכים מיוחדים של פונקציית ה[פולילוגריתם](https://he.wikipedia.org/wiki/%D7%A4%D7%95%D7%9C%D7%99%D7%9C%D7%95%D7%92%D7%A8%D7%99%D7%AA%D7%9D).

## הגדרה

פונקציית הזטא $`\xi_k(s)`$ מוגדרת על ידי



```math
\xi_k(s) = \frac{1}{\Gamma(s)} \int_0^{\infty} \frac{t^{s-1} }{e^t-1}\mathrm{Li}_k(1-e^{-t}) \, dt,
```

 כאשר $`\mathrm{Li}_k`$ הוא הפולילוגריתם ה-$`k`$-י



```math
\mathrm{Li}_k(z) = \sum_{n=1}^{\infty} \frac{z^n}{n^k}.
```



## תכונות

האינטגרל מתכנס עבור $`\mathrm{Re}(s) > 0`$, ול-$`\xi_k(s)`$ יש [המשכה אנליטית](https://he.wikipedia.org/wiki/%D7%94%D7%9E%D7%A9%D7%9B%D7%94_%D7%90%D7%A0%D7%9C%D7%99%D7%98%D7%99%D7%AA) לכל המישור המרוכב כ[פונקציה שלמה](https://he.wikipedia.org/wiki/%D7%A4%D7%95%D7%A0%D7%A7%D7%A6%D7%99%D7%94_%D7%A9%D7%9C%D7%9E%D7%94).

המקרה הפרטי $`k = 1`$ נותן $`\xi_1(s) = s \zeta(s+1)`$, כאשר $`\zeta`$ היא פונקציית זטא של רימן. (**הוכחה, נוסף בתרגום:** $`\mathrm{Li}_1(z) = -\log(1-z)`$, ולכן $`\mathrm{Li}_1(1-e^{-t}) = t`$, והאינטגרל הוא $`\frac{1}{\Gamma(s)}\int_0^\infty\frac{t^s}{e^t-1}dt = \frac{\Gamma(s+1)\zeta(s+1)}{\Gamma(s)} = s\zeta(s+1)`$.)

המקרה הפרטי $`s = 1`$ נותן, באופן מפתיע, גם $`\xi_k(1) = \zeta(k+1)`$.

הערכים בשלמים קשורים לערכים של [פונקציות זטא מרובות](%D7%A4%D7%95%D7%A0%D7%A7%D7%A6%D7%99%D7%99%D7%AA%20%D7%96%D7%98%D7%90%20%D7%9E%D7%A8%D7%95%D7%91%D7%94.md) (בגרסת ה"כוכב", שבה מותר שוויון בין האינדקסים) על ידי



```math
\xi_k(m) = \zeta^\star(k+1,\underbrace{1,\ldots,1}_{m-1}),
```

 כאשר



```math
\zeta^\star(k_1,k_2,\dots,k_n)=\sum_{m_1\ge m_2\ge\cdots\ge m_n \ge 1}\frac{1}{m_1^{k_1}m_2^{k_2}\cdots m_n^{k_n} }.
```

 (בערך האנגלי הנוסחה מופיעה בצורה $`\xi_k(m) = \zeta_m^*(k,1,\ldots,1)`$, עם סכום על $`m_1 \lt m_2 \lt \cdots \lt m_n`$ שבו המעריך $`k`$ על האינדקס הקטן ביותר. בצורה זו הטור מתבדר, כי המעריך 1 נמצא על האינדקס הגדול ביותר; ואף אחרי היפוך הסדר, הערכים אינם מתאימים. הניסוח המתוקן כאן נבדק מספרית.)

### דוגמאות (נוסף בתרגום, נבדקו מספרית)

- $`\xi_2(2) = \zeta^\star(3,1) = \zeta(3,1) + \zeta(4) = \frac{\pi^4}{360} + \frac{\pi^4}{90} = \frac{\pi^4}{72} \approx 1.3529040.`$
- $`\xi_3(2) = \zeta^\star(4,1) = 3\zeta(5) - \zeta(2)\zeta(3) \approx 1.1334789.`$
- $`\xi_2(3) = \zeta^\star(3,1,1) = \zeta(2)\zeta(3) - \tfrac12\zeta(5) \approx 1.4588405.`$
- $`\xi_1(2.5) = 2.5\,\zeta(3.5) \approx 2.8168347`$, ו-$`\xi_2(1) = \zeta(3)`$, $`\xi_3(1) = \zeta(4)`$.

כאן $`\zeta(a,b) = \sum_{m\gt n\ge1}m^{-a}n^{-b}`$ הם ערכי זטא כפולים רגילים (עם אי-שוויון חזק), ו-$`\zeta^\star`$ כולל גם את האיברים עם שוויון: למשל $`\zeta^\star(3,1) = \zeta(3,1) + \zeta(4)`$.
