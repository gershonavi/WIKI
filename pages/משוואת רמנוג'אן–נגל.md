# משוואת רמנוג'אן–נגל

ב[תורת המספרים](https://he.wikipedia.org/wiki/%D7%AA%D7%95%D7%A8%D7%AA_%D7%94%D7%9E%D7%A1%D7%A4%D7%A8%D7%99%D7%9D), **משוואת רמנוג'אן–נגל** היא [משוואה](https://he.wikipedia.org/wiki/%D7%9E%D7%A9%D7%95%D7%95%D7%90%D7%94) בין [מספר ריבועי](https://he.wikipedia.org/wiki/%D7%9E%D7%A1%D7%A4%D7%A8_%D7%A8%D7%99%D7%91%D7%95%D7%A2%D7%99) לבין מספר שקטן בשבע מ[חזקה של שתיים](https://he.wikipedia.org/wiki/%D7%97%D7%96%D7%A7%D7%94_%D7%A9%D7%9C_2). זו דוגמה ל[משוואה דיופנטית מעריכית](https://he.wikipedia.org/wiki/%D7%9E%D7%A9%D7%95%D7%95%D7%90%D7%94_%D7%93%D7%99%D7%95%D7%A4%D7%A0%D7%98%D7%99%D7%AA_%D7%9E%D7%A2%D7%A8%D7%99%D7%9B%D7%99%D7%AA) – משוואה שפותרים בשלמים, ושאחד המשתנים בה מופיע כ[מעריך](https://he.wikipedia.org/wiki/%D7%97%D7%96%D7%A7%D7%94_%28%D7%9E%D7%AA%D7%9E%D7%98%D7%99%D7%A7%D7%94%29).

המשוואה נקראת על שם [סריניוואסה רמנוג'אן](https://he.wikipedia.org/wiki/%D7%A1%D7%A8%D7%99%D7%A0%D7%99%D7%95%D7%95%D7%90%D7%A1%D7%94_%D7%A8%D7%9E%D7%A0%D7%95%D7%92%27%D7%90%D7%9F), ששיער שיש לה רק חמישה פתרונות ב[שלמים](https://he.wikipedia.org/wiki/%D7%9E%D7%A1%D7%A4%D7%A8_%D7%A9%D7%9C%D7%9D), ועל שם [טריגווה נגל](https://he.wikipedia.org/wiki/%D7%98%D7%A8%D7%99%D7%92%D7%95%D7%95%D7%94_%D7%A0%D7%92%D7%9C), שהוכיח את ההשערה. ממנה נובע (יחד עם טיעון נוסף) שאין [קודים בינאריים מושלמים](https://he.wikipedia.org/wiki/%D7%A7%D7%95%D7%93_%D7%9E%D7%95%D7%A9%D7%9C%D7%9D) עם [מרחק המינג](https://he.wikipedia.org/wiki/%D7%9E%D7%A8%D7%97%D7%A7_%D7%94%D7%9E%D7%99%D7%A0%D7%92) מינימלי 5 או 6, מלבד הקודים הטריוויאליים.

## המשוואה והפתרון

המשוואה היא



```math
2^n - 7 = x^2,
```

 ופתרונות ב[מספרים טבעיים](https://he.wikipedia.org/wiki/%D7%9E%D7%A1%D7%A4%D7%A8_%D7%98%D7%91%D7%A2%D7%99) $`n`$ ו-$`x`$ קיימים רק כאשר $`n = 3, 4, 5, 7`$ ו-15 (סדרה [A060728](https://oeis.org/A060728) ב-OEIS).

את זה שיער ב-1913 המתמטיקאי ההודי סריניוואסה רמנוג'אן, הציע באופן בלתי תלוי ב-1943 המתמטיקאי הנורווגי [וילהלם ליונגרן](https://he.wikipedia.org/wiki/%D7%95%D7%99%D7%9C%D7%94%D7%9C%D7%9D_%D7%9C%D7%99%D7%95%D7%A0%D7%92%D7%A8%D7%9F), והוכיח ב-1948 המתמטיקאי הנורווגי טריגווה נגל. ערכי $`x`$ המתאימים לערכי $`n`$ הם



```math
x = 1, 3, 5, 11, 181
```

 (סדרה [A038198](https://oeis.org/A038198) ב-OEIS).[^1] כלומר:



```math
2^3 - 7 = 1^2, \quad 2^4 - 7 = 3^2, \quad 2^5 - 7 = 5^2, \quad 2^7 - 7 = 11^2, \quad 2^{15} - 7 = 32761 = 181^2.
```

 (בדקנו בחיפוש ממצה שאין פתרונות נוספים עם $`n \lt 200`$.)

### רעיון ההוכחה של נגל

אם $`n`$ זוגי, $`n = 2m`$, אז $`(2^m - x)(2^m + x) = 7`$, ולכן $`2^m - x = 1`$ ו-$`2^m + x = 7`$, כלומר $`m = 2, x = 3`$ – הפתרון $`n = 4`$. המקרה המעניין הוא $`n`$ אי-זוגי. אחרי טיפול במקרים קטנים, כותבים את המשוואה (עבור $`x`$ אי-זוגי ו-$`n \ge 3`$) כ-



```math
\frac{x + \sqrt{-7} }2\cdot\frac{x - \sqrt{-7} }2 = 2^{n-2},
```

 בחוג השלמים של $`\mathbb Q(\sqrt{-7})`$, שהוא [תחום פריקות יחידה](https://he.wikipedia.org/wiki/%D7%AA%D7%97%D7%95%D7%9D_%D7%A4%D7%A8%D7%99%D7%A7%D7%95%D7%AA_%D7%99%D7%97%D7%99%D7%93%D7%94). שם $`2 = \alpha\bar\alpha`$ עם $`\alpha = \frac{1 + \sqrt{-7} }2`$, ומשיקולי פריקות יחידה $`\frac{x \pm \sqrt{-7} }2 = \pm\alpha^{n-2}`$. השוואת חלקים מדומים נותנת את התנאי $`\alpha^{k} - \bar\alpha^{k} = \pm\sqrt{-7}`$ עם $`k = n - 2`$, ונגל הראה, בעזרת חשבון מודולרי בחזקות של 2, שזה קורה רק עבור $`k = 1, 3, 5, 13`$ – כלומר $`n = 3, 5, 7, 15`$.

## מספרי מרסן משולשיים

הבעיה של מציאת כל ה[מספרים המשולשיים](https://he.wikipedia.org/wiki/%D7%9E%D7%A1%D7%A4%D7%A8_%D7%9E%D7%A9%D7%95%D7%9C%D7%A9%D7%99) מהצורה $`2^b - 1`$ ([מספרי מרסן](https://he.wikipedia.org/wiki/%D7%9E%D7%A1%D7%A4%D7%A8_%D7%9E%D7%A8%D7%A1%D7%9F)) שקולה למשוואה:



```math
\begin{align}
& \ 2^b - 1 = \frac{y(y + 1)}2 \\[2pt]
\Longleftrightarrow & \ 8(2^b - 1) = 4y(y + 1) \\
\Longleftrightarrow & \ 2^{b+3} - 8 = 4y^2 + 4y \\
\Longleftrightarrow & \ 2^{b+3} - 7 = 4y^2 + 4y + 1 \\
\Longleftrightarrow & \ 2^{b+3} - 7 = (2y + 1)^2.
\end{align}
```

 ערכי $`b`$ הם בדיוק ערכי $`n - 3`$, כלומר $`b = 0, 1, 2, 4, 12`$, ומספרי המרסן המשולשיים המתאימים (שנקראים גם **מספרי רמנוג'אן–נגל**) הם



```math
\frac{y(y + 1)}2 = \frac{(x - 1)(x + 1)}8
```

 עבור $`x = 1, 3, 5, 11`$ ו-181, כלומר 0, 1, 3, 15, 4095, ולא יותר (סדרה [A076046](https://oeis.org/A076046) ב-OEIS). למשל $`4095 = 2^{12} - 1 = \frac{90\cdot91}2`$.

## קשר לקודים מושלמים

[קוד בינארי](https://he.wikipedia.org/wiki/%D7%A7%D7%95%D7%93_%D7%9E%D7%AA%D7%A7%D7%9F_%D7%A9%D7%92%D7%99%D7%90%D7%95%D7%AA) באורך $`N`$ שמתקן שתי שגיאות הוא **מושלם** אם הכדורים ברדיוס 2 סביב מילות הקוד מכסים את $`\{0, 1\}^N`$ בלי חפיפה. כל כדור כזה מכיל $`1 + N + \binom N2`$ וקטורים, ולכן מספר זה חייב להיות חזקה של 2:



```math
1 + N + \frac{N(N - 1)}2 = 2^r \iff (2N + 1)^2 + 7 = 2^{r+3}.
```

 זו בדיוק משוואת רמנוג'אן–נגל עם $`x = 2N + 1`$, ולכן $`N \in \{0, 1, 2, 5, 90\}`$. המקרים $`N \le 5`$ טריוויאליים (קוד החזרה), ועבור $`N = 90`$ מתקיים $`1 + 90 + 4005 = 4096 = 2^{12}`$ – אבל [גולאי](https://he.wikipedia.org/wiki/%D7%9E%D7%A8%D7%A1%D7%9C_%D7%92%D7%95%D7%9C%D7%90%D7%99) הראה בטיעון קומבינטורי נפרד שקוד מושלם כזה אינו קיים.[^2]

## משוואות מטיפוס רמנוג'אן–נגל

משוואה מהצורה



```math
x^2 + D = AB^n
```

 עם $`D, A, B`$ קבועים ומשתנים $`x, n`$ נקראת *משוואה מטיפוס רמנוג'אן–נגל*. מהתוצאה של [זיגל](https://he.wikipedia.org/wiki/%D7%A7%D7%A8%D7%9C_%D7%9C%D7%95%D7%93%D7%95%D7%95%D7%99%D7%92_%D7%96%D7%99%D7%92%D7%9C) ([משפט זיגל על נקודות שלמות](%D7%9E%D7%A9%D7%A4%D7%98%20%D7%96%D7%99%D7%92%D7%9C%20%D7%A2%D7%9C%20%D7%A0%D7%A7%D7%95%D7%93%D7%95%D7%AA%20%D7%A9%D7%9C%D7%9E%D7%95%D7%AA.md)) נובע שמספר הפתרונות בכל מקרה סופי.[^3] כותבים $`n = 3m + r`$ עם $`r \in \{0, 1, 2\}`$ ו-$`B^n = B^ry^3`$ עם $`y = B^m`$, וכך המשוואה מטיפוס רמנוג'אן–נגל מצטמצמת לשלושה [עקומי מורדל](%D7%A2%D7%A7%D7%95%D7%9D%20%D7%9E%D7%95%D7%A8%D7%93%D7%9C.md) (לפי $`r`$), שלכל אחד מהם יש מספר סופי של פתרונות שלמים:



```math
r = 0: \qquad (Ax)^2 = (Ay)^3 - A^2D,
```





```math
r = 1: \qquad (ABx)^2 = (ABy)^3 - A^2B^2D,
```





```math
r = 2: \qquad (AB^2x)^2 = (AB^2y)^3 - A^2B^4D.
```

 (למשל עבור $`r = 1`$: מכפילים את $`x^2 + D = ABy^3`$ ב-$`A^2B^2`$.)

למשוואה עם $`A = 1`$, $`B = 2`$ ו-$`D \gt 0`$ יש לכל היותר שני פתרונות, פרט למקרה $`D = 7`$ שמתאים למשוואת רמנוג'אן–נגל. זה לא נכון עבור $`D \lt 0`$; למשל עבור $`D = -17`$, למשוואה $`x^2 - 17 = 2^n`$ יש ארבעה פתרונות: $`(x, n) = (5, 3), (7, 5), (9, 6), (23, 9)`$. באופן כללי, אם $`D = -(4^k - 3\cdot2^{k+1} + 1)`$ עבור שלם $`k \ge 3`$, יש לפחות ארבעה פתרונות:



```math
(x, n) = \begin{cases}(2^k - 3, 3), \\ (2^k - 1, k + 2), \\ (2^k + 1, k + 3), \\ (3\cdot2^k - 1, 2k + 3),\end{cases}
```

 ואלה הארבעה היחידים אם $`D \gt -10^{12}`$.[^4] (בדקנו את ארבעת הפתרונות לכל $`3 \le k \le 8`$, למשל עבור $`k = 4`$, $`D = -161`$: $`(13, 3), (15, 6), (17, 7), (47, 11)`$; את הזהות הכללית אפשר לבדוק בפתיחת סוגריים – למשל $`(2^k - 1)^2 + D = 2^{k+2}`$.)

יש אינסוף ערכי $`D`$ שעבורם יש בדיוק שני פתרונות, ביניהם $`D = 2^m - 1`$ עבור $`m \ge 4`$.[^5] שני הפתרונות הם $`(x, n) = (1, m)`$ ו-$`(2^{m-1} - 1, 2m - 2)`$, כי $`(2^{m-1} - 1)^2 + 2^m - 1 = 2^{2m-2}`$.[^6]

## משוואות מטיפוס לבג–נגל

משוואה מהצורה



```math
x^2 + D = Ay^n
```

 עם $`D, A`$ קבועים ומשתנים $`x, y, n`$, כאשר $`n \gt 2`$, נקראת *משוואה מטיפוס לבג–נגל*. השם הוא על שם [ויקטור-אמדה לבג](https://he.wikipedia.org/wiki/%D7%95%D7%99%D7%A7%D7%98%D7%95%D7%A8-%D7%90%D7%9E%D7%93%D7%94_%D7%9C%D7%91%D7%92), שהוכיח שלמשוואה



```math
x^2 + 1 = y^n
```

 אין פתרונות לא טריוויאליים.[^7]

מתוצאות של שורי ו[טיידמן](https://he.wikipedia.org/wiki/%D7%A8%D7%95%D7%91%D7%A8%D7%98_%D7%98%D7%99%D7%99%D7%93%D7%9E%D7%9F)[^8] נובע שמספר הפתרונות בכל מקרה סופי.[^9] ביז'ו, מיניוט וסיקסק פתרו את המשוואות מהטיפוס הזה עם $`A = 1`$ ו-$`1 \le D \le 100`$, בשילוב של שיטת בייקר עם השיטה המודולרית (של [ויילס](https://he.wikipedia.org/wiki/%D7%9E%D7%A9%D7%A4%D7%98_%D7%95%D7%99%D7%99%D7%9C%D7%A1)).[^10] בפרט, להכללה הבאה של משוואת רמנוג'אן–נגל:



```math
y^n = x^2 + 7
```

 יש פתרונות בשלמים חיוביים רק כאשר $`x = 1, 3, 5, 11`$ או 181. (בכל המקרים $`x^2 + 7`$ הוא חזקה של 2; למשל $`181^2 + 7 = 2^{15} = 8^5 = 32^3`$.)
