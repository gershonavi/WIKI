# מספר היפר-משוכלל

ב[תורת המספרים](https://he.wikipedia.org/wiki/%D7%AA%D7%95%D7%A8%D7%AA_%D7%94%D7%9E%D7%A1%D7%A4%D7%A8%D7%99%D7%9D), **מספר $`k`$-היפר-משוכלל** הוא [מספר טבעי](https://he.wikipedia.org/wiki/%D7%9E%D7%A1%D7%A4%D7%A8_%D7%98%D7%91%D7%A2%D7%99) $`n`$ שעבורו מתקיים השוויון



```math
n = 1+k\bigl(\sigma(n)-n-1\bigr),
```

 כאשר $`\sigma(n)`$ היא פונקציית סכום המחלקים (כלומר, סכום כל ה[מחלק](https://he.wikipedia.org/wiki/%D7%9E%D7%97%D7%9C%D7%A7)ים החיוביים של $`n`$). **מספר היפר-משוכלל** הוא מספר $`k`$-היפר-משוכלל עבור שלם $`k`$ כלשהו. מספרים היפר-משוכללים מכלילים את ה[מספרים המשוכללים](https://he.wikipedia.org/wiki/%D7%9E%D7%A1%D7%A4%D7%A8_%D7%9E%D7%A9%D7%95%D7%9B%D7%9C%D7%9C), שהם המספרים ה-1-היפר-משוכללים.[^1]

שימו לב ש-$`\sigma(n) - n - 1`$ הוא סכום המחלקים ה"פנימיים" של $`n`$ (בלי 1 ובלי $`n`$). ההגדרה אומרת ש-$`n - 1`$ שווה $`k`$ פעמים הסכום הזה. *דוגמאות:*

- $`n = 21 = 3\cdot7`$: המחלקים הפנימיים הם 3 ו-7, עם סכום 10, ו-$`1 + 2\cdot10 = 21`$. לכן 21 הוא 2-היפר-משוכלל.
- $`n = 301 = 7\cdot43`$: $`1 + 6\cdot(7 + 43) = 301`$, ולכן 301 הוא 6-היפר-משוכלל.
- $`n = 325 = 5^2\cdot13`$: המחלקים הפנימיים הם $`5, 13, 25, 65`$, עם סכום 108, ו-$`1 + 3\cdot108 = 325`$.
- $`n = 28`$: המחלקים הפנימיים הם $`2, 4, 7, 14`$, עם סכום 27, ו-$`1 + 1\cdot27 = 28`$ – זה בדיוק התנאי של מספר משוכלל.

המספרים הראשונים בסדרת המספרים ה-$`k`$-היפר-משוכללים הם 6, 21, 28, 301, 325, 496, 697, ... ((סדרה [A034897](https://oeis.org/A034897) ב-OEIS)), עם ערכי $`k`$ המתאימים 1, 2, 1, 6, 3, 1, 12, ... ((סדרה [A034898](https://oeis.org/A034898) ב-OEIS)). המספרים ה-$`k`$-היפר-משוכללים הראשונים שאינם משוכללים הם 21, 301, 325, 697, 1333, ... ((סדרה [A007592](https://oeis.org/A007592) ב-OEIS)). (את כל המספרים ההיפר-משוכללים עד $`10^7`$ מצאנו בחיפוש ממצה.)

מספרים $`k`$-היפר-משוכללים ידועים

## בניות

אפשר להראות שאם $`k \gt 1`$ הוא [שלם אי-זוגי](https://he.wikipedia.org/wiki/%D7%9E%D7%A1%D7%A4%D7%A8_%D7%90%D7%99-%D7%96%D7%95%D7%92%D7%99), ו-$`p = \tfrac{3k+1}{2}`$ ו-$`q = 3k+4`$ הם [מספרים ראשוניים](https://he.wikipedia.org/wiki/%D7%9E%D7%A1%D7%A4%D7%A8_%D7%A8%D7%90%D7%A9%D7%95%D7%A0%D7%99), אז $`p^2q`$ הוא $`k`$-היפר-משוכלל. למשל, עבור $`k = 3`$: $`p = 5`$, $`q = 13`$, ו-$`5^2\cdot13 = 325`$; עבור $`k = 11`$: $`p = 17`$, $`q = 37`$, ו-$`17^2\cdot37 = 10693`$.

*הוכחה:* המחלקים הפנימיים של $`p^2q`$ הם $`p, p^2, q, pq`$, וסכומם $`(p + p^2)(1) + q(1 + p) = (1+p)(p + q)`$. עם $`p = \tfrac{3k+1}2`$ ו-$`q = 3k + 4 = 2p + 3`$: $`1 + p = \tfrac{3(k+1)}{2}`$ ו-$`p + q = 3p + 3 = \tfrac{9(k+1)}{2}`$, ולכן $`k\cdot(1+p)(p+q) = \tfrac{27k(k+1)^2}{4}`$. מצד שני, $`p^2q - 1 = \tfrac{(3k+1)^2(3k+4)}{4} - 1 = \tfrac{27k^3 + 54k^2 + 27k}{4} = \tfrac{27k(k+1)^2}4`$. השוויון מתקיים.

ג'אדסון מקקרני שיער ב-2000 שכל המספרים ה-$`k`$-היפר-משוכללים עבור $`k \gt 1`$ אי-זוגי הם מהצורה הזו, אבל ההשערה טרם הוכחה.[^3] (בטבלה, כל השורות עם $`k`$ אי-זוגי – 3, 11, 19, 31, 35, 59, 75, 91 – אכן נותנות מספר אחד מהצורה $`p^2q`$.)

יתרה מזו, אפשר להוכיח שאם $`p \ne q`$ ראשוניים אי-זוגיים ו-$`k`$ שלם כך ש-$`k(p+q) = pq-1`$, אז $`pq`$ הוא $`k`$-היפר-משוכלל – זה פשוט התנאי עצמו, כי המחלקים הפנימיים של $`pq`$ הם $`p`$ ו-$`q`$. למשל $`6\cdot(7 + 43) = 300 = 7\cdot43 - 1`$.

אפשר גם להראות שאם $`k \gt 0`$ ו-$`p = k+1`$ ראשוני, אז לכל $`i \gt 1`$ שעבורו $`q = p^i - p+1`$ ראשוני, $`n = p^{i-1}q`$ הוא $`k`$-היפר-משוכלל. (עבור $`k = 1`$, $`p = 2`$, זו בדיוק הבנייה של אוקלידס למספרים משוכללים: $`q = 2^i - 1`$ ראשוני מרסן ו-$`n = 2^{i-1}(2^i - 1)`$.) למשל, עבור $`k = 2`$, $`p = 3`$: עם $`i = 2`$, $`q = 7`$ ו-$`n = 3\cdot7 = 21`$; עם $`i = 4`$, $`q = 79`$ ו-$`n = 27\cdot79 = 2133`$. הטבלה הבאה מונה ערכים ידועים של $`k`$ וערכי $`i`$ המתאימים שעבורם $`n`$ הוא $`k`$-היפר-משוכלל (את הערכים $`i \lt 40`$ עבור $`k = 2, 4, 6`$ בדקנו בחישוב):

*הוכחת הבנייה:* המחלקים הפנימיים של $`p^{i-1}q`$ הם $`p, \ldots, p^{i-1}`$ ו-$`q, pq, \ldots, p^{i-2}q`$. נסמן $`S = 1 + p + \cdots + p^{i-2} = \tfrac{p^{i-1}-1}{p-1}`$. סכומם הוא $`pS + qS = S(p + q)`$, ו-$`p + q = p^i + 1`$, ולכן הסכום הוא $`S(p^i + 1)`$. עם $`k = p - 1`$: $`k\cdot S(p^i+1) = (p^{i-1} - 1)(p^i + 1)`$, ו-$`n - 1 = p^{i-1}(p^i - p + 1) - 1 = p^{2i-1} - p^i + p^{i-1} - 1 = (p^{i-1} - 1)(p^i + 1)`$. השוויון מתקיים.
