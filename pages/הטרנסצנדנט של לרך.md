# הטרנסצנדנט של לרך

ב[מתמטיקה](https://he.wikipedia.org/wiki/%D7%9E%D7%AA%D7%9E%D7%98%D7%99%D7%A7%D7%94), **הטרנסצנדנט של לרך** (ב[אנגלית](https://he.wikipedia.org/wiki/%D7%90%D7%A0%D7%92%D7%9C%D7%99%D7%AA): Lerch transcendent) היא פונקציה מיוחדת שמכלילה את [פונקציית זטא של הורוויץ](%D7%A4%D7%95%D7%A0%D7%A7%D7%A6%D7%99%D7%99%D7%AA%20%D7%96%D7%98%D7%90%20%D7%A9%D7%9C%20%D7%94%D7%95%D7%A8%D7%95%D7%95%D7%99%D7%A5.md) ואת ה[פולילוגריתם](https://he.wikipedia.org/wiki/%D7%A4%D7%95%D7%9C%D7%99%D7%9C%D7%95%D7%92%D7%A8%D7%99%D7%AA%D7%9D). היא קרויה על שם המתמטיקאי הצ'כי מתיאס לרך, שפרסם ב-1887 מאמר על פונקציה דומה.[^1] הטרנסצנדנט של לרך נתון על ידי



```math
\Phi(z, s, \alpha) = \sum_{n=0}^\infty \frac { z^n} {(n+\alpha)^s}.
```

 הטור מתכנס עבור כל מספר ממשי $`\alpha > 0`$ כאשר $`|z| < 1`$, או כאשר $`|z| = 1`$ ו-$`\operatorname{Re}(s) > 1`$.[^2]

## מקרים פרטיים

הטרנסצנדנט של לרך קשור לפונקציות מיוחדות שונות ומכליל אותן.

**פונקציית זטא של לרך** נתונה על ידי



```math
L(\lambda, s, \alpha) = \sum_{n=0}^\infty \frac { e^{2\pi i\lambda n}} {(n+\alpha)^s}=\Phi(e^{2\pi i\lambda}, s,\alpha).
```



[פונקציית זטא של הורוויץ](%D7%A4%D7%95%D7%A0%D7%A7%D7%A6%D7%99%D7%99%D7%AA%20%D7%96%D7%98%D7%90%20%D7%A9%D7%9C%20%D7%94%D7%95%D7%A8%D7%95%D7%95%D7%99%D7%A5.md) היא המקרה הפרטי[^3]



```math
\zeta(s,\alpha) = \sum_{n=0}^\infty \frac{1}{(n+\alpha)^s} = \Phi(1,s,\alpha).
```

 ה[פולילוגריתם](https://he.wikipedia.org/wiki/%D7%A4%D7%95%D7%9C%D7%99%D7%9C%D7%95%D7%92%D7%A8%D7%99%D7%AA%D7%9D) הוא מקרה פרטי נוסף:[^4]



```math
\operatorname{Li}_s(z) = \sum_{n=1}^\infty \frac{z^n}{n^s} =z\Phi(z,s,1).
```

 [פונקציית זטא של רימן](https://he.wikipedia.org/wiki/%D7%A4%D7%95%D7%A0%D7%A7%D7%A6%D7%99%D7%99%D7%AA_%D7%96%D7%98%D7%90_%D7%A9%D7%9C_%D7%A8%D7%99%D7%9E%D7%9F) היא מקרה פרטי של שתיהן:[^5]



```math
\zeta(s) =\sum_{n=1}^\infty \frac{1}{n^s} = \Phi(1,s,1).
```

 [פונקציית אטא של דיריכלה](%D7%A4%D7%95%D7%A0%D7%A7%D7%A6%D7%99%D7%99%D7%AA%20%D7%90%D7%98%D7%90%20%D7%A9%D7%9C%20%D7%93%D7%99%D7%A8%D7%99%D7%9B%D7%9C%D7%94.md):[^6]



```math
\eta(s) = \sum_{n=1}^\infty \frac{(-1)^{n-1}}{n^s} = \Phi(-1,s,1).
```

 [פונקציית בטא של דיריכלה](https://he.wikipedia.org/wiki/%D7%A4%D7%95%D7%A0%D7%A7%D7%A6%D7%99%D7%99%D7%AA_%D7%91%D7%98%D7%90_%D7%A9%D7%9C_%D7%93%D7%99%D7%A8%D7%99%D7%9B%D7%9C%D7%94):[^7]



```math
\beta(s) = \sum_{k=0}^\infty \frac{(-1)^{k}}{(2k+1)^s} = 2^{-s}\Phi(-1,s,\tfrac12).
```

 פונקציית למדא של דיריכלה:[^8]



```math
\lambda(s) = \sum_{k=0}^\infty \frac{1}{(2k+1)^s} = 2^{-s}\Phi(1,s,\tfrac12).
```

 פונקציית חי של לז'נדר:[^9]



```math
\chi_s(z) = \sum_{k=0}^\infty \frac{z^{2k+1}}{(2k+1)^s}= \frac {z}{2^s} \Phi(z^2,s,\tfrac12).
```

 אינטגרל הארקטנגנס:[^10]



```math
\operatorname{Ti}_s(z)= \sum_{k=0}^\infty \frac{(-1)^k z^{2k+1}}{(2k+1)^s}=\frac{z}{2^s}\Phi(-z^2,s,\tfrac12).
```

 [פונקציות הפוליגמא](https://he.wikipedia.org/wiki/%D7%A4%D7%95%D7%A0%D7%A7%D7%A6%D7%99%D7%99%D7%AA_%D7%A4%D7%95%D7%9C%D7%99%D7%92%D7%9E%D7%90), עבור $`n`$ שלם חיובי:<ref>לפונקציית הפוליגמא יש ההצגה כטור $`\psi^{(m)}(z) = (-1)^{m+1}\, m! \sum_{k=0}^\infty \frac{1}{(z+k)^{m+1</ref>`$, התקפה עבור ערכים שלמים $`m > 0`$ ולכל $`z`$ מרוכב שאינו שלם אי-חיובי. ראו גם (באנגלית) [Polygamma Function](https://mathworld.wolfram.com/PolygammaFunction.html), באתר MathWorld\|כיווון=שמאל}}



```math
\psi^{(n)}(\alpha)= (-1)^{n+1} n!\,\Phi (1,n+1,\alpha).
```

 [פונקציית קלאוזן](%D7%A4%D7%95%D7%A0%D7%A7%D7%A6%D7%99%D7%99%D7%AA%20%D7%A7%D7%9C%D7%90%D7%95%D7%96%D7%9F.md):[^11]



```math
\operatorname{Cl}_2(z)= \frac{ie^{-iz}}2 \Phi(e^{-iz},2,1)-\frac{ie^{iz}}2 \Phi(e^{iz},2,1).
```



## הצגות אינטגרליות

לטרנסצנדנט של לרך יש ההצגה האינטגרלית



```math
\Phi(z,s,a)=\frac{1}{\Gamma(s)}\int_0^\infty \frac{t^{s-1}e^{-at}}{1-ze^{-t}}\,dt .
```

 ההוכחה משתמשת בהגדרת [פונקציית גמא](https://he.wikipedia.org/wiki/%D7%A4%D7%95%D7%A0%D7%A7%D7%A6%D7%99%D7%99%D7%AA_%D7%92%D7%9E%D7%90) כאינטגרל כדי לכתוב



```math
\Phi(z,s,a)\Gamma(s) = \sum_{n=0}^\infty \frac{z^n}{(n+a)^s} \int_0^\infty x^s e^{-x} \frac{dx}{x} = \sum_{n=0}^\infty \int_0^\infty t^s z^n e^{-(n+a)t} \frac{dt}{t},
```

 ואחר כך מחליפים את סדר הסכימה והאינטגרציה. ההצגה האינטגרלית המתקבלת מתכנסת עבור $`z \in \mathbb C \setminus [1,\infty)`$, $`\operatorname{Re}(s) > 0`$ ו-$`\operatorname{Re}(a) > 0`$. כך מתקבלת [המשכה אנליטית](https://he.wikipedia.org/wiki/%D7%94%D7%9E%D7%A9%D7%9B%D7%94_%D7%90%D7%A0%D7%9C%D7%99%D7%98%D7%99%D7%AA) של $`\Phi(z,s,a)`$ לערכים של $`z`$ מחוץ ל[עיגול היחידה](https://he.wikipedia.org/wiki/%D7%9E%D7%A2%D7%92%D7%9C_%D7%94%D7%99%D7%97%D7%99%D7%93%D7%94). הנוסחה תקפה גם כאשר $`z = 1`$, $`\operatorname{Re}(s) > 1`$ ו-$`\operatorname{Re}(a) > 0`$; ראו [פונקציית זטא של הורוויץ](%D7%A4%D7%95%D7%A0%D7%A7%D7%A6%D7%99%D7%99%D7%AA%20%D7%96%D7%98%D7%90%20%D7%A9%D7%9C%20%D7%94%D7%95%D7%A8%D7%95%D7%95%D7%99%D7%A5.md).[^12][^13]

הצגה כ[אינטגרל קווי](https://he.wikipedia.org/wiki/%D7%90%D7%99%D7%A0%D7%98%D7%92%D7%A8%D7%9C_%D7%A7%D7%95%D7%95%D7%99) נתונה על ידי



```math
\Phi(z,s,a)=-\frac{\Gamma(1-s)}{2\pi i} \int_C \frac{(-t)^{s-1}e^{-at}}{1-ze^{-t}}\,dt ,
```

 כאשר $`C`$ היא מסילת הנקל שמקיפה את הציר הממשי החיובי נגד כיוון השעון, ואינה מקיפה אף אחת מהנקודות $`t = \log(z) + 2k\pi i`$ (עבור $`k`$ שלם), שהן [קטבים](https://he.wikipedia.org/wiki/%D7%A7%D7%95%D7%98%D7%91_%28%D7%90%D7%A0%D7%9C%D7%99%D7%96%D7%94_%D7%9E%D7%A8%D7%95%D7%9B%D7%91%D7%AA%29) של האינטגרנד. האינטגרל מניח $`\operatorname{Re}(a) > 0`$.[^14]

### הצגות אינטגרליות נוספות

הצגה אינטגרלית בדומה לזו של הרמיט נתונה על ידי



```math
\Phi(z,s,a)= \frac{1}{2a^s}+ \int_0^\infty \frac{z^t}{(a+t)^s}\,dt+ \frac{2}{a^{s-1}} \int_0^\infty \frac{\sin(s\arctan(t)-ta\log(z))}{(1+t^2)^{s/2}(e^{2\pi at}-1)}\,dt
```

 עבור $`\operatorname{Re}(a)>0`$ ו-$`|z|<1`$, ועל ידי



```math
\Phi(z,s,a)=\frac{1}{2a^s}+ \frac{\log^{s-1}(1/z)}{z^a}\Gamma(1-s,a\log(1/z))+ \frac{2}{a^{s-1}} \int_0^\infty \frac{\sin(s\arctan(t)-ta\log(z))}{(1+t^2)^{s/2}(e^{2\pi at}-1)}\,dt
```

 עבור $`\operatorname{Re}(a)>0`$.

הצגות דומות הן



```math
\Phi(z,s,a)= \frac{1}{2a^s} + \int_{0}^{\infty}\frac{\cos(t\log z)\sin\left(s\arctan\tfrac{t}{a}\right) - \sin(t\log z)\cos\left(s\arctan\tfrac{t}{a}\right)}{\left(a^2 + t^2\right)^{\frac{s}{2}} \tanh\pi t }\,dt,
```

 ו-



```math
\Phi(-z,s,a)= \frac{1}{2a^s} + \int_{0}^{\infty}\frac{\cos(t\log z)\sin\left(s\arctan\tfrac{t}{a}\right) - \sin(t\log z)\cos\left(s\arctan\tfrac{t}{a}\right)}{\left(a^2 + t^2\right)^{\frac{s}{2}} \sinh\pi t }\,dt,
```

 התקפות עבור $`z`$ חיובי (ובאופן כללי יותר בכל מקום שבו האינטגרלים מתכנסים). בנוסף,



```math
\Phi(e^{i\varphi},s,a)=L\left(\tfrac{\varphi}{2\pi}, s, a\right)= \frac{1}{a^s} + \frac{1}{2\Gamma(s)}\int_{0}^{\infty}\frac{t^{s-1}e^{-at}\left(e^{i\varphi}-e^{-t}\right)}{\cosh{t}-\cos{\varphi}}\,dt .
```

 הנוסחה האחרונה ידועה גם בשם **נוסחת ליפשיץ**.

## זהויות

כאשר $`\lambda`$ רציונלי, כל מחובר מכיל [שורש יחידה](https://he.wikipedia.org/wiki/%D7%A9%D7%95%D7%A8%D7%A9_%D7%99%D7%97%D7%99%D7%93%D7%94), ולכן אפשר לבטא את $`L(\lambda, s, \alpha)`$ כסכום סופי של ערכי פונקציית זטא של הורוויץ. נניח $`\lambda = \frac{p}{q}`$ עם $`p, q`$ שלמים ו-$`q > 0`$. אז $`z = \omega = e^{2 \pi i p/q}`$ ו-$`\omega^q = 1`$, ו-



```math
\Phi(\omega, s, \alpha) = \sum_{n=0}^\infty \frac {\omega^n} {(n+\alpha)^s} = \sum_{m=0}^{q-1} \sum_{n=0}^\infty \frac {\omega^{qn + m}}{(qn + m + \alpha)^s} = \sum_{m=0}^{q-1} \omega^m q^{-s} \zeta \left( s,\frac{m + \alpha}{q} \right) .
```



זהויות נוספות:



```math
\Phi(z,s,a)=z^n \Phi(z,s,a+n) + \sum_{k=0}^{n-1} \frac {z^k}{(k+a)^s},
```





```math
\Phi(z,s-1,a)=\left(a+z\frac{\partial}{\partial z}\right) \Phi(z,s,a),
```





```math
\Phi(z,s+1,a)=-\frac{1}{s}\frac{\partial}{\partial a} \Phi(z,s,a).
```



## הצגות כטור

הצגה כטור של הטרנסצנדנט של לרך נתונה על ידי



```math
\Phi(z,s,q)=\frac{1}{1-z} \sum_{n=0}^\infty \left(\frac{-z}{1-z} \right)^n \sum_{k=0}^n (-1)^k \binom{n}{k} (q+k)^{-s},
```

 כאשר $`\tbinom{n}{k}`$ הוא [מקדם בינומי](https://he.wikipedia.org/wiki/%D7%9E%D7%A7%D7%93%D7%9D_%D7%91%D7%99%D7%A0%D7%95%D7%9E%D7%99). הטור תקף לכל $`s`$ ולכל $`z`$ מרוכב עם $`\operatorname{Re}(z)<1/2`$. יש דמיון כללי להצגה דומה כטור של פונקציית זטא של הורוויץ.

[טור טיילור](https://he.wikipedia.org/wiki/%D7%98%D7%95%D7%A8_%D7%98%D7%99%D7%99%D7%9C%D7%95%D7%A8) בפרמטר הראשון נתן ארתור ארדייי. אפשר לכתוב אותו כטור הבא, התקף עבור[^15] $`\left|\log(z)\right| < 2 \pi`$, $`s\neq 1,2,3,\dots`$, $`a\neq 0,-1,-2,\dots`$:



```math
\Phi(z,s,a)=z^{-a}\left[\Gamma(1-s)\left(-\log (z)\right)^{s-1} +\sum_{k=0}^\infty \zeta(s-k,a)\frac{\log^k (z)}{k!}\right].
```

 אם $`n`$ שלם חיובי, אז



```math
\Phi(z,n,a)=z^{-a}\left\{ \sum_{k=0,\ k\neq n-1}^ \infty \zeta(n-k,a)\frac{\log^k (z)}{k!} +\left[\psi(n)-\psi(a)-\log(-\log(z))\right]\frac{\log^{n-1}(z)}{(n-1)!} \right\},
```

 כאשר $`\psi`$ היא [פונקציית דיגמא](https://he.wikipedia.org/wiki/%D7%A4%D7%95%D7%A0%D7%A7%D7%A6%D7%99%D7%99%D7%AA_%D7%93%D7%99%D7%92%D7%9E%D7%90).

טור טיילור במשתנה השלישי נתון על ידי



```math
\Phi(z,s,a+x)=\sum_{k=0}^\infty \Phi(z,s+k,a)(s)_{k}\frac{(-x)^k}{k!}, \qquad |x|<\operatorname{Re}(a),
```

 כאשר $`(s)_{k}`$ הוא סימן פוכהאמר (העצרת העולה).

הטור סביב $`a = -n`$ נתון על ידי



```math
\Phi(z,s,a)=\sum_{k=0}^n \frac{z^k}{(a+k)^s} +z^n\sum_{m=0}^\infty (1-m-s)_{m}\operatorname{Li}_{s+m}(z)\frac{(a+n)^m}{m!}, \qquad a\rightarrow-n .
```

 במקרה הפרטי $`n = 0`$ מתקבל הטור



```math
\Phi(z,s,a)=\frac{1}{a^s} +\sum_{m=0}^\infty (1-m-s)_m \operatorname{Li}_{s+m}(z)\frac{a^m}{m!}, \qquad |a|<1,
```

 כאשר $`\operatorname{Li}_s(z)`$ הוא הפולילוגריתם.

טור אסימפטוטי כאשר $`s\rightarrow-\infty`$:



```math
\Phi(z,s,a)=z^{-a}\Gamma(1-s)\sum_{k=-\infty}^\infty [2k\pi i-\log(z)]^{s-1}e^{2k\pi ai}
```

 עבור $`|a|<1`$, $`\operatorname{Re}(s)<0`$, $`z\notin (-\infty,0)`$, ו-



```math
\Phi(-z,s,a)=z^{-a}\Gamma(1-s)\sum_{k=-\infty}^\infty [(2k+1)\pi i-\log(z)]^{s-1}e^{(2k+1)\pi ai}
```

 עבור $`|a|<1`$, $`\operatorname{Re}(s)<0`$, $`z\notin (0,\infty)`$.

טור אסימפטוטי באמצעות פונקציית גמא החלקית:



```math
\Phi(z,s,a)=\frac{1}{2a^s}+ \frac{1}{z^a}\sum_{k=1}^\infty \left[\frac{e^{-2\pi i(k-1)a}\Gamma(1-s,a(-2\pi i(k-1)-\log(z)))} {(-2\pi i(k-1)-\log(z))^{1-s}}+ \frac{e^{2\pi ika}\Gamma(1-s,a(2\pi ik-\log(z)))}{(2\pi ik-\log(z))^{1-s}}\right]
```

 עבור $`|a|<1`$, $`\operatorname{Re}(s)<0`$.

ההצגה כ[פונקציה היפרגאומטרית](https://he.wikipedia.org/wiki/%D7%A4%D7%95%D7%A0%D7%A7%D7%A6%D7%99%D7%94_%D7%94%D7%99%D7%A4%D7%A8%D7%92%D7%90%D7%95%D7%9E%D7%98%D7%A8%D7%99%D7%AA) מוכללת היא[^16]



```math
\Phi(z,s,\alpha)=\frac{1}{\alpha^s}\,{}_{s+1}F_s\left(\begin{array}{c} 1,\alpha,\alpha,\alpha,\cdots\\ 1+\alpha,1+\alpha,1+\alpha,\cdots\\ \end{array}\mid z\right)
```

 (עבור $`s`$ שלם חיובי).

## פיתוח אסימפטוטי

פונקציות הפולילוגריתם $`\operatorname{Li}_{-n}(z)`$ מסדר שלילי מוגדרות על ידי



```math
\operatorname{Li}_0(z)=\frac{z}{1-z}, \qquad \operatorname{Li}_{-n}(z)=z \frac{d}{dz} \operatorname{Li}_{1-n}(z).
```

 נגדיר



```math
\Omega_{a} \equiv\begin{cases} \mathbb{C}\setminus[1,\infty) & \operatorname{Re} a > 0, \\ \{z \in \mathbb{C} : |z|<1\} & \operatorname{Re} a \le 0. \end{cases}
```

 עבור $`|\operatorname{Arg}(a)|<\pi`$, $`s \in \mathbb{C}`$ ו-$`z \in \Omega_{a}`$, פיתוח אסימפטוטי של $`\Phi(z,s,a)`$ עבור $`a`$ גדול ו-$`s`$, $`z`$ קבועים נתון על ידי



```math
\Phi(z,s,a) = \frac{1}{1-z} \frac{1}{a^{s}} + \sum_{n=1}^{N-1} \frac{(-1)^{n} \operatorname{Li}_{-n}(z)}{n!} \frac{(s)_{n}}{a^{n+s}} +O(a^{-N-s})
```

 עבור $`N`$ טבעי, כאשר $`(s)_n = s (s+1)\cdots (s+n-1)`$ הוא סימן פוכהאמר.[^17]

נגדיר



```math
f(z,x,a) \equiv \frac{1-(z e^{-x})^{1-a}}{1-z e^{-x}},
```

 ויהיו $`C_{n}(z,a)`$ מקדמי טיילור שלה בנקודה $`x=0`$. אז עבור $`N`$ טבעי קבוע, $`\operatorname{Re} a > 1`$ ו-$`\operatorname{Re} s > 0`$,



```math
\Phi(z,s,a) - \frac{\operatorname{Li}_{s}(z)}{z^{a}} = \sum_{n=0}^{N-1} C_{n}(z,a) \frac{(s)_{n}}{a^{n+s}} + O\left( (\operatorname{Re} a)^{1-N-s}+a z^{-\operatorname{Re} a} \right)
```

 כאשר $`\operatorname{Re} a \to \infty`$.[^18]
