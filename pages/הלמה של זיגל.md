# הלמה של זיגל

ב[מתמטיקה](https://he.wikipedia.org/wiki/%D7%9E%D7%AA%D7%9E%D7%98%D7%99%D7%A7%D7%94), ובפרט ב[תורת המספרים הטרנסצנדנטיים](%D7%AA%D7%95%D7%A8%D7%AA%20%D7%94%D7%9E%D7%A1%D7%A4%D7%A8%D7%99%D7%9D%20%D7%94%D7%98%D7%A8%D7%A0%D7%A1%D7%A6%D7%A0%D7%93%D7%A0%D7%98%D7%99%D7%99%D7%9D.md) וב[קירובים דיופנטיים](https://he.wikipedia.org/wiki/%D7%A7%D7%99%D7%A8%D7%95%D7%91_%D7%93%D7%99%D7%95%D7%A4%D7%A0%D7%98%D7%99), **הלמה של זיגל** (Siegel's lemma) מתייחסת לחסמים על הפתרונות של [משוואות לינאריות](https://he.wikipedia.org/wiki/%D7%9E%D7%A9%D7%95%D7%95%D7%90%D7%94_%D7%9C%D7%99%D7%A0%D7%90%D7%A8%D7%99%D7%AA), שמתקבלים בבניית [פונקציות עזר](%D7%A4%D7%95%D7%A0%D7%A7%D7%A6%D7%99%D7%99%D7%AA%20%D7%A2%D7%96%D7%A8.md). את קיומם של הפולינומים האלה הוכיח אקסל תואה;[^1] ההוכחה של תואה השתמשה במה שבגרמנית נקרא "עקרון המגירות של דיריכלה", הידוע כ[עקרון שובך היונים](https://he.wikipedia.org/wiki/%D7%A2%D7%A7%D7%A8%D7%95%D7%9F_%D7%A9%D7%95%D7%91%D7%9A_%D7%94%D7%99%D7%95%D7%A0%D7%99%D7%9D). [קרל לודוויג זיגל](https://he.wikipedia.org/wiki/%D7%A7%D7%A8%D7%9C_%D7%9C%D7%95%D7%93%D7%95%D7%95%D7%99%D7%92_%D7%96%D7%99%D7%92%D7%9C) פרסם את הלמה שלו ב-1929.[^2] זהו משפט קיום טהור עבור [מערכת משוואות לינאריות](https://he.wikipedia.org/wiki/%D7%9E%D7%A2%D7%A8%D7%9B%D7%AA_%D7%9E%D7%A9%D7%95%D7%95%D7%90%D7%95%D7%AA_%D7%9C%D7%99%D7%A0%D7%90%D7%A8%D7%99%D7%95%D7%AA).

בשנים האחרונות שופרה הלמה של זיגל כדי לתת חסמים חדים יותר.[^3]

## ניסוח

נניח שנתונה מערכת של $`M`$ משוואות לינאריות ב-$`N`$ נעלמים, עם $`N \gt M`$:



```math
a_{11}X_1 + \cdots + a_{1N}X_N = 0
```





```math
\cdots
```





```math
a_{M1}X_1 + \cdots + a_{MN}X_N = 0,
```

 כאשר המקדמים שלמים, לא כולם 0, וחסומים בערכם המוחלט על ידי $`B`$. אז למערכת יש פתרון $`(X_1, X_2, \ldots, X_N)`$ בשלמים, לא כולם 0, וחסומים על ידי



```math
(NB)^{M/(N-M)}.
```

[^4]

הנקודה החשובה היא שהחסם תלוי רק ב-$`N`$, $`M`$ ו-$`B`$; כשמספר הנעלמים גדול בהרבה ממספר המשוואות (למשל $`N = 2M`$), החסם הוא בערך $`NB`$ – לא הרבה יותר גדול מהמקדמים עצמם. [אלגברה לינארית](https://he.wikipedia.org/wiki/%D7%90%D7%9C%D7%92%D7%91%D7%A8%D7%94_%D7%9C%D7%99%D7%A0%D7%90%D7%A8%D7%99%D7%AA) רגילה (כלל קרמר) נותנת רק חסם מסדר גודל של [דטרמיננטות](https://he.wikipedia.org/wiki/%D7%93%D7%98%D7%A8%D7%9E%D7%99%D7%A0%D7%A0%D7%98%D7%94) $`M\times M`$, כלומר בערך $`M!\,B^M`$.

בומביירי ווָאלֵר (1983) נתנו חסם חד יותר:



```math
\max_j|X_j| \le \left(D^{-1}\sqrt{\det(AA^T)}\right)^{1/(N-M)},
```

 כאשר $`D`$ הוא ה[מחלק המשותף המקסימלי](https://he.wikipedia.org/wiki/%D7%9E%D7%97%D7%9C%D7%A7_%D7%9E%D7%A9%D7%95%D7%AA%D7%A3_%D7%9E%D7%A7%D7%A1%D7%99%D7%9E%D7%9C%D7%99) של ה[מינורים](https://he.wikipedia.org/wiki/%D7%9E%D7%99%D7%A0%D7%95%D7%A8_%28%D7%90%D7%9C%D7%92%D7%91%D7%A8%D7%94_%D7%9C%D7%99%D7%A0%D7%90%D7%A8%D7%99%D7%AA%29) מסדר $`M \times M`$ של ה[מטריצה](https://he.wikipedia.org/wiki/%D7%9E%D7%98%D7%A8%D7%99%D7%A6%D7%94) $`A`$, ו-$`A^T`$ היא ה[משוחלפת](https://he.wikipedia.org/wiki/%D7%9E%D7%98%D7%A8%D7%99%D7%A6%D7%94_%D7%9E%D7%A9%D7%95%D7%97%D7%9C%D7%A4%D7%AA) שלה. בהוכחה שלהם הוחלף עקרון שובך היונים בשיטות מהגאומטריה של המספרים.

## ההוכחה בעזרת עקרון שובך היונים

נסמן ב-$`L_i(X) = \sum_ja_{ij}X_j`$ את התבניות, ונתבונן בכל $`(H + 1)^N`$ הווקטורים $`X`$ עם $`0 \le X_j \le H`$. לכל $`i`$, הערך $`L_i(X)`$ נע בקטע שאורכו $`H\sum_j|a_{ij}| \le NBH`$, ולכן מקבל לכל היותר $`NBH + 1`$ ערכים שלמים. אם



```math
(H + 1)^N \gt (NBH + 1)^M,
```

 אז לשני וקטורים שונים $`X \ne X'`$ יש אותה תמונה $`(L_1, \ldots, L_M)`$, וההפרש $`X - X'`$ הוא פתרון שלם לא טריוויאלי עם $`|X_j - X'_j| \le H`$. התנאי מתקיים כאשר $`H \ge (NB)^{M/(N-M)}`$: אז $`(H+1)^{N-M} \gt H^{N-M} \ge (NB)^M`$, ולכן $`(H + 1)^N \gt (NB)^M(H + 1)^M \ge (NBH + 1)^M`$.

## דוגמה מלאה

נתבונן במערכת עם $`M = 2`$ משוואות ו-$`N = 5`$ נעלמים, ומקדמים חסומים על ידי $`B = 5`$:



```math
3X_1 - 5X_2 + 2X_3 + 4X_4 - X_5 = 0,
```





```math
-2X_1 + X_2 + 5X_3 - 3X_4 + 4X_5 = 0.
```



- **החסם של זיגל:** $`(NB)^{M/(N-M)} = 25^{2/3} \approx 8.55`$, כלומר יש פתרון עם $`\max|X_j| \le 8`$.
- **ספירה מדויקת יותר בהוכחה:** סכום הערכים המוחלטים של המקדמים בכל שורה הוא 15, ולכן כל $`L_i`$ מקבל לכל היותר $`15H + 1`$ ערכים. עבור $`H = 5`$: $`6^5 = 7776 \gt 76^2 = 5776`$, כך שיש פתרון עם $`\max|X_j| \le 5`$. (עבור $`H = 4`$: $`5^5 = 3125 \lt 61^2 = 3721`$, והטיעון לא עובד.)
- **החסם של בומביירי–ואלר:** המחלק המשותף המקסימלי של עשרת המינורים $`2\times2`$ הוא $`D = 1`$, ו-$`\det(AA^T) = 55\cdot55 - (-17)^2 = 2736`$. לכן $`\max|X_j| \le \sqrt{2736}^{1/3} = 2736^{1/6} \approx 3.74`$, כלומר יש פתרון עם $`\max|X_j| \le 3`$.
- **המציאות:** בחיפוש ממצה, הפתרון הקטן ביותר הוא בגובה 2, למשל $`X = (0, 0, 1, -1, -2)`$: בדיקה – $`2 - 4 + 2 = 0`$ ו-$`5 + 3 - 8 = 0`$. יש בדיוק ארבעה פתרונות בגובה 2: $`\pm(0, 0, 1, -1, -2)`$ ו-$`\pm(2, -1, -1, -2, 1)`$.

לעומת זאת, פתרון "רגיל" בדירוג גאוס נותן בסיס למרחב הפתרונות עם מכנה 7, למשל $`(27/7, 19/7, 1, 0, 0)`$, ואחרי הכפלה במכנה – פתרון שלם $`(27, 19, 7, 0, 0)`$, גדול בהרבה.

## השימוש בפונקציות עזר

השימוש הטיפוסי: רוצים פולינום $`P(x, y) = \sum p_{kl}x^ky^l`$ עם מקדמים שלמים, לא כולם אפס, שמתאפס (עם נגזרותיו) בנקודות מסוימות. כל תנאי התאפסות הוא משוואה לינארית במקדמים $`p_{kl}`$, עם מקדמים שגובהם נשלט. אם מספר המקדמים $`N`$ גדול ממספר התנאים $`M`$, הלמה של זיגל נותנת פולינום כזה עם מקדמים קטנים – וזה הצעד הראשון בהוכחות של [משפט תואה](%D7%9E%D7%A9%D7%95%D7%95%D7%90%D7%AA%20%D7%AA%D7%95%D7%90%D7%94.md), [משפט רות](%D7%9E%D7%A9%D7%A4%D7%98%20%D7%A8%D7%95%D7%AA.md), [משפט גלפונד–שניידר](https://he.wikipedia.org/wiki/%D7%9E%D7%A9%D7%A4%D7%98_%D7%92%D7%9C%D7%A4%D7%95%D7%A0%D7%93-%D7%A9%D7%A0%D7%99%D7%99%D7%93%D7%A8) ו[משפט בייקר](%D7%9E%D7%A9%D7%A4%D7%98%20%D7%91%D7%99%D7%99%D7%A7%D7%A8.md). כשהמשוואות הן מעל [שדה מספרים](https://he.wikipedia.org/wiki/%D7%A9%D7%93%D7%94_%D7%9E%D7%A1%D7%A4%D7%A8%D7%99%D7%9D) $`K`$ מדרגה $`d`$, כותבים כל משוואה כ-$`d`$ משוואות רציונליות, ומקבלים חסם עם המעריך $`dM/(N - dM)`$.
