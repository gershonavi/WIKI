# סדרת סומוס

ב[מתמטיקה](https://he.wikipedia.org/wiki/%D7%9E%D7%AA%D7%9E%D7%98%D7%99%D7%A7%D7%94), **סדרת סומוס** היא סדרת מספרים שמוגדרת על ידי [נוסחת נסיגה](https://he.wikipedia.org/wiki/%D7%A0%D7%95%D7%A1%D7%97%D7%AA_%D7%A0%D7%A1%D7%99%D7%92%D7%94) מסוימת, המתוארת להלן. הסדרות התגלו על ידי המתמטיקאי מייקל סומוס. לפי צורת נוסחת הנסיגה שמגדירה אותן (שכוללת חילוק), אפשר היה לצפות שהאיברים יהיו שברים; אבל באופן מפתיע, לכמה סדרות סומוס יש התכונה שכל האיברים שלהן שלמים.

## נוסחאות הנסיגה

לשלם $`k \gt 1`$, סדרת **סומוס-$`k`$** $`\{a_n\}_{n \in \mathbb{Z} }`$ היא פתרון של המשוואה



```math
a_n a_{n-k} = \sum_{i=1}^{\lfloor k/2 \rfloor} \alpha_i a_{n-i} a_{n-k+i},
```

 כאשר $`\alpha_1, \alpha_2, \ldots, \alpha_{\lfloor k/2 \rfloor}`$ פרמטרים קבועים. אפשר לסדר אותה מחדש כנוסחת נסיגה מסדר $`k`$:



```math
a_n = \frac{\sum_{i=1}^{\lfloor k/2 \rfloor} \alpha_i a_{n-i} a_{n-k+i} }{a_{n-k} }.
```

 לכן פתרון לא מנוון נקבע על ידי בחירה של $`k`$ ערכים התחלתיים $`a_0, a_1, \ldots, a_{k - 1}`$. הסדרה שמתקבלת מהבחירה $`\alpha_1 = \alpha_2 = \dots = \alpha_{\lfloor k/2 \rfloor} = 1`$ ו-$`a_0 = a_1 = \dots = a_{k - 1} = 1`$ נקראת **סדרת** סומוס-$`k`$ (בה' הידיעה). סדרת סומוס-$`k`$ סימטרית, כלומר $`s_{-n} = s_{n + k - 1}`$.

עבור $`k = 2`$ או $`3`$ היחסים המגדירים פשוטים מאוד (אין חיבור באגף ימין). במקרה הלא טריוויאלי הראשון, $`k = 4`$, היחס הוא



```math
a_n = \frac{\alpha a_{n-1} a_{n-3} + \beta a_{n-2}^2}{a_{n-4} },
```

 כאשר $`\alpha`$ ו-$`\beta`$ פרמטרים קבועים. במקרה $`k = 5`$ היחס הוא



```math
a_n = \frac{\alpha a_{n-1} a_{n-4} + \beta a_{n-2} a_{n-3} }{a_{n-5} }.
```

*חישוב של כמה איברי סומוס-4:* $`a_4 = \tfrac{a_3a_1 + a_2^2}{a_0} = \tfrac{1 + 1}{1} = 2`$; $`a_5 = \tfrac{a_4a_2 + a_3^2}{a_1} = \tfrac{2 + 1}{1} = 3`$; $`a_6 = \tfrac{3\cdot1 + 2^2}{1} = 7`$; $`a_7 = \tfrac{7\cdot2 + 3^2}{1} = 23`$; $`a_8 = \tfrac{23\cdot3 + 7^2}{2} = \tfrac{118}{2} = 59`$ – כאן כבר יש חילוק לא טריוויאלי, והוא "מצליח"; $`a_9 = \tfrac{59\cdot7 + 23^2}{3} = \tfrac{942}{3} = 314`$.

## שלמות ותופעת לורן

צורת נוסחאות הנסיגה שמתארות את סדרות סומוס כוללת חילוק, ולכן נראה סביר שהסדרות יכילו ערכים שאינם שלמים. ובכל זאת, עבור $`k \le 7`$ סדרות סומוס מכילות רק ערכים שלמים.[^2][^3][^4] באופן כללי, עבור $`k \le 7`$, סדרת סומוס-$`k`$ מקיימת את מה שנקרא **תכונת לורן**: כפונקציה של האיברים ההתחלתיים $`a_0, \ldots, a_{k-1}`$, כל איבר $`a_n`$ הוא [פולינום לורן](https://he.wikipedia.org/wiki/%D7%A4%D7%95%D7%9C%D7%99%D7%A0%D7%95%D7%9D_%D7%9C%D7%95%D7%A8%D7%9F) בכמה משתנים, עם מקדמים ב-$`\mathbb{Z}[\alpha_1, \dots, \alpha_{\lfloor k/2 \rfloor}]`$. (למשל, בסומוס-4 הכללית עם $`\alpha = \beta = 1`$: $`a_4 = \tfrac{a_1a_3 + a_2^2}{a_0}`$, $`a_5 = \tfrac{a_1a_2a_3 + a_2^3 + a_0a_3^2}{a_0a_1}`$, ו-$`a_6`$ הוא שוב שבר שהמכנה שלו מונום, $`a_0^2a_1a_2`$ – אף שבחישוב הישיר $`a_6 = (a_5a_3 + a_4^2)/a_2`$ נראה כאילו יכולים להופיע מכנים מסובכים. כשכל האיברים ההתחלתיים שווים ל-1, המכנים הם 1 וכל האיברים שלמים.)

כמה מתמטיקאים חקרו את בעיית ההוכחה וההסבר של התכונה הזו בסדרות סומוס; היא קשורה קשר הדוק לקומבינטוריקה של [אלגברות אשכולות](https://he.wikipedia.org/wiki/%D7%90%D7%9C%D7%92%D7%91%D7%A8%D7%AA_%D7%90%D7%A9%D7%9B%D7%95%D7%9C%D7%95%D7%AA).[^5][^6][^7]

עבור $`k \ge 8`$, סדרות סומוס-$`k`$ מכילות בסופו של דבר ערכים שאינם שלמים. בסומוס-8, הערך הלא שלם הראשון הוא האיבר ה-18, שערכו $`420514/7`$ (בדקנו).

## נוסחה סגורה

נתבונן ביחס סומוס-4



```math
a_n a_{n-4} = \alpha a_{n-1} a_{n-3} + \beta a_{n-2}^2
```

 עם $`\alpha \ne 0`$. אז סדרת סומוס-4 בערכים [מרוכבים](https://he.wikipedia.org/wiki/%D7%9E%D7%A1%D7%A4%D7%A8_%D7%9E%D7%A8%D7%95%D7%9B%D7%91) מתאימה לסדרה חשבונית של נקודות $`Q + nP`$ על [עקום אליפטי](https://he.wikipedia.org/wiki/%D7%A2%D7%A7%D7%95%D7%9D_%D7%90%D7%9C%D7%99%D7%A4%D7%98%D7%99) $`E`$. האיבר הכללי נתון בנוסחה[^8]



```math
a_n = A B^n \frac{\sigma(z_0 + n \kappa)}{\sigma(\kappa)^{n^2} },
```

 כאשר $`\sigma(z) = \sigma(z; g_2, g_3)`$ היא [פונקציית סיגמא של ויירשטראס](https://he.wikipedia.org/wiki/%D7%A4%D7%95%D7%A0%D7%A7%D7%A6%D7%99%D7%99%D7%AA_%D7%A1%D7%99%D7%92%D7%9E%D7%90_%D7%A9%D7%9C_%D7%95%D7%99%D7%99%D7%A8%D7%A9%D7%98%D7%A8%D7%90%D7%A1) המשויכת לעקום $`E`$ הכתוב בצורה הקנונית



```math
E: \quad y^2 = 4 x^3 - g_2 x - g_3.
```

 ששת הפרמטרים $`g_2, g_3, A, B, z_0, \kappa \in \mathbb{C}`$ נקבעים ביחידות (עד כדי בחירת סימן) על ידי המקדמים $`\alpha, \beta`$ והאיברים ההתחלתיים $`a_0, a_1, a_2, a_3`$. קואורדינטות $`(x, y)`$ של הסדרה $`Q + n P`$ נתונות על ידי $`(\wp(z_0 + n \kappa), \wp'(z_0 + n \kappa))`$, כאשר $`\wp(z) = \wp(z; g_2, g_3)`$ היא [פונקציית ויירשטראס](https://he.wikipedia.org/wiki/%D7%A4%D7%95%D7%A0%D7%A7%D7%A6%D7%99%D7%99%D7%AA_%D7%95%D7%99%D7%99%D7%A8%D7%A9%D7%98%D7%A8%D7%90%D7%A1). המקדמים $`\alpha`$ ו-$`\beta`$ נתונים כ[פונקציות אליפטיות](https://he.wikipedia.org/wiki/%D7%A4%D7%95%D7%A0%D7%A7%D7%A6%D7%99%D7%94_%D7%90%D7%9C%D7%99%D7%A4%D7%98%D7%99%D7%AA) של $`\kappa`$:



```math
\alpha = \wp(\kappa)^2, \quad \beta =\wp'(\kappa)^2 (\wp(2 \kappa) - \wp(\kappa)).
```



*קשר מפורש לדוגמה:* סדרת סומוס-4 היא (בערך מוחלט) תת-הסדרה של האיברים במקומות האי-זוגיים ב[סדרת ההתחלקות האליפטית](%D7%A1%D7%93%D7%A8%D7%AA%20%D7%94%D7%AA%D7%97%D7%9C%D7%A7%D7%95%D7%AA%20%D7%90%D7%9C%D7%99%D7%A4%D7%98%D7%99%D7%AA.md) של העקום $`y^2 + y = x^3 - x`$ עם הנקודה $`(0, 0)`$: אם $`W_n`$ היא הסדרה $`1, 1, -1, 1, 2, -1, -3, -5, 7, \ldots`$ ((סדרה [A006769](https://oeis.org/A006769) ב-OEIS)), אז $`|W_{2n+1}| = a_{n+2}`$ (בדקנו עבור $`n \lt 20`$). כך הגידול של סומוס-4, $`\log a_n \approx c\,n^2`$, נובע מהגידול ה"אקספוננציאלי-ריבועי" של סדרות התחלקות אליפטיות.
