# בעיית פרוהה–טארי–אסקוט

ב[מתמטיקה](https://he.wikipedia.org/wiki/%D7%9E%D7%AA%D7%9E%D7%98%D7%99%D7%A7%D7%94), **בעיית פרוהה–טארי–אסקוט** מבקשת למצוא שתי מולטי-קבוצות [זרות](https://he.wikipedia.org/wiki/%D7%A7%D7%91%D7%95%D7%A6%D7%95%D7%AA_%D7%96%D7%A8%D7%95%D7%AA) $`A`$ ו-$`B`$, כל אחת עם $`n`$ [מספרים שלמים](https://he.wikipedia.org/wiki/%D7%9E%D7%A1%D7%A4%D7%A8_%D7%A9%D7%9C%D7%9D), שבהן $`k`$ סכומי החזקות הראשונים שווים. כלומר, שתי המולטי-קבוצות צריכות לקיים את המשוואות



```math
\sum_{a\in A}a^i = \sum_{b\in B}b^i
```

 לכל מספר שלם $`i`$ מ-1 עד $`k`$ נתון. הוכח ש-$`n`$ חייב להיות גדול ממש מ-$`k`$. פתרונות עם $`k = n - 1`$ נקראים **פתרונות אידיאליים**. פתרונות אידיאליים ידועים עבור $`3 \le n \le 10`$ ועבור $`n = 12`$. לא ידוע פתרון אידיאלי עבור $`n = 11`$ או עבור $`n \ge 13`$.[^1]

הבעיה נקראת על שם אז'ן פרוהה, שחקר אותה בתחילת שנות ה-50 של המאה ה-19, ועל שם גסטון טארי ואדוארד ב. אסקוט, שחקרו אותה בתחילת שנות ה-10 של המאה ה-20. מקורה במכתבים של [כריסטיאן גולדבך](https://he.wikipedia.org/wiki/%D7%9B%D7%A8%D7%99%D7%A1%D7%98%D7%99%D7%90%D7%9F_%D7%92%D7%95%D7%9C%D7%93%D7%91%D7%9A) ו[לאונרד אוילר](https://he.wikipedia.org/wiki/%D7%9C%D7%90%D7%95%D7%A0%D7%A8%D7%93_%D7%90%D7%95%D7%99%D7%9C%D7%A8) (1750/1751).

## ניסוח פולינומי

לפי [זהויות ניוטון](https://he.wikipedia.org/wiki/%D7%96%D7%94%D7%95%D7%99%D7%95%D7%AA_%D7%A0%D7%99%D7%95%D7%98%D7%95%D7%9F), שוויון סכומי החזקות $`p_1, \ldots, p_k`$ של שתי מולטי-קבוצות בגודל $`n`$ שקול לשוויון של $`k`$ ה[פולינומים הסימטריים האלמנטריים](https://he.wikipedia.org/wiki/%D7%A4%D7%95%D7%9C%D7%99%D7%A0%D7%95%D7%9D_%D7%A1%D7%99%D7%9E%D7%98%D7%A8%D7%99_%D7%90%D7%9C%D7%9E%D7%A0%D7%98%D7%A8%D7%99) הראשונים. לכן $`A, B`$ הם פתרון אם ורק אם



```math
\prod_{a\in A}(x - a) - \prod_{b\in B}(x - b)
```

 הוא פולינום ממעלה לכל היותר $`n - k - 1`$. מכאן רואים מיד ש-$`n \gt k`$: אם $`k \ge n`$, ההפרש הוא אפס, ושני הפולינומים זהים – כלומר $`A = B`$. בפתרון אידיאלי ($`k = n - 1`$) ההפרש הוא **קבוע** שונה מאפס.

## דוגמאות

### פתרונות אידיאליים

פתרון אידיאלי עבור $`n = 6`$ נתון על ידי שתי הקבוצות $`\{0, 5, 6, 16, 17, 22\}`$ ו-$`\{1, 2, 10, 12, 20, 21\}`$, כי:



```math
0^1 + 5^1 + 6^1 + 16^1 + 17^1 + 22^1 = 1^1 + 2^1 + 10^1 + 12^1 + 20^1 + 21^1 = 66,
```





```math
0^2 + 5^2 + 6^2 + 16^2 + 17^2 + 22^2 = 1^2 + 2^2 + 10^2 + 12^2 + 20^2 + 21^2 = 1090,
```





```math
0^3 + 5^3 + 6^3 + 16^3 + 17^3 + 22^3 = 1^3 + 2^3 + 10^3 + 12^3 + 20^3 + 21^3 = 19998,
```





```math
0^4 + 5^4 + 6^4 + 16^4 + 17^4 + 22^4 = 1^4 + 2^4 + 10^4 + 12^4 + 20^4 + 21^4 = 385234,
```





```math
0^5 + 5^5 + 6^5 + 16^5 + 17^5 + 22^5 = 1^5 + 2^5 + 10^5 + 12^5 + 20^5 + 21^5 = 7632966.
```

 בניסוח הפולינומי:



```math
x(x - 5)(x - 6)(x - 16)(x - 17)(x - 22) - (x - 1)(x - 2)(x - 10)(x - 12)(x - 20)(x - 21) = -100800.
```

 (בדקנו בפיתוח סימבולי: כל המקדמים של $`x^1, \ldots, x^5`$ מתבטלים.)

עבור $`n = 12`$, פתרון אידיאלי נתון על ידי $`A = \{\pm22, \pm61, \pm86, \pm127, \pm140, \pm151\}`$ ו-$`B = \{\pm35, \pm47, \pm94, \pm121, \pm146, \pm148\}`$.[^2] כאן הקבוצות סימטריות ($`\pm`$), כך שסכומי החזקות האי-זוגיות מתאפסים אוטומטית בשני הצדדים, ונשאר לבדוק רק את החזקות הזוגיות $`2, 4, \ldots, 10`$. (בדקנו שסכומי החזקות שווים עד $`i = 11`$.)

### פתרונות אחרים

פרוהה השתמש בסדרת תואה–מורס כדי לבנות פתרון עם $`n = 2^k`$ לכל $`k`$. ליתר דיוק, מחלקים את המספרים מ-0 עד $`2^{k+1} - 1`$ ל-(א) המספרים שבייצוג הבינארי שלהם יש מספר זוגי של אחדות ו-(ב) המספרים שבייצוג הבינארי שלהם יש מספר אי-זוגי של אחדות; שתי הקבוצות בחלוקה נותנות פתרון לבעיה.[^3] למשל, עבור $`n = 8`$ ו-$`k = 3`$, הפתרון של פרוהה הוא:



```math
0^1 + 3^1 + 5^1 + 6^1 + 9^1 + 10^1 + 12^1 + 15^1 = 1^1 + 2^1 + 4^1 + 7^1 + 8^1 + 11^1 + 13^1 + 14^1,
```





```math
0^2 + 3^2 + 5^2 + 6^2 + 9^2 + 10^2 + 12^2 + 15^2 = 1^2 + 2^2 + 4^2 + 7^2 + 8^2 + 11^2 + 13^2 + 14^2,
```





```math
0^3 + 3^3 + 5^3 + 6^3 + 9^3 + 10^3 + 12^3 + 15^3 = 1^3 + 2^3 + 4^3 + 7^3 + 8^3 + 11^3 + 13^3 + 14^3.
```

 (בחזקה הרביעית השוויון כבר נשבר, כצפוי.)

**למה זה עובד.** נסמן $`t_m = \pm1`$ לפי זוגיות מספר האחדות של $`m`$. אז



```math
\sum_{m=0}^{2^{k+1}-1}t_mx^m = \prod_{j=0}^{k}\left(1 - x^{2^j}\right),
```

 כי כל $`m`$ מתקבל בדיוק פעם אחת כסכום של חזקות שונות של 2, והסימן הוא $`(-1)^{(\text{מספר האחדות})}`$. לכל גורם יש שורש ב-$`x = 1`$, ולכן למכפלה יש שורש מסדר $`k + 1`$ ב-$`x = 1`$. מכאן שהנגזרות $`\left(x\frac d{dx}\right)^i`$ של המכפלה מתאפסות ב-$`x = 1`$ לכל $`i \le k`$, כלומר $`\sum_mt_mm^i = 0`$ – בדיוק השוויון $`\sum_{a\in A}a^i = \sum_{b\in B}b^i`$.

## הכללות

גרסה רב-ממדית של הבעיה הציגו וחקרו אנדראס אלפרס ורוברט טיידמן ב-2007:[^4] בהינתן פרמטרים $`n, k \in \mathbb N`$, מצאו שתי מולטי-קבוצות שונות $`\{(x_1, y_1), \dots, (x_n, y_n)\}`$ ו-$`\{(x_1', y_1'), \dots, (x_n', y_n')\}`$ של נקודות ב-$`\mathbb Z^2`$ כך ש-



```math
\sum_{i=1}^nx_i^jy_i^{d-j} = \sum_{i=1}^n{x'}_i^j{y'}_i^{d-j}
```

 לכל $`d, j \in \{0, \dots, k\}`$ עם $`j \le d`$. הבעיה קשורה לטומוגרפיה בדידה, והיא מובילה גם לפתרונות מיוחדים של בעיית פרוהה–טארי–אסקוט מעל השלמים הגאוסיים (אם כי הפתרונות של בעיית אלפרס–טיידמן אינם ממצים את כל הפתרונות מעל השלמים הגאוסיים).

פתרון עבור $`n = 6`$ ו-$`k = 5`$ נתון, למשל, על ידי



```math
\{(x_1, y_1), \dots, (x_6, y_6)\} = \{(2, 1), (1, 3), (3, 6), (6, 7), (7, 5), (5, 2)\}
```

 ו-



```math
\{(x'_1, y'_1), \dots, (x'_6, y'_6)\} = \{(1, 2), (2, 5), (5, 7), (7, 6), (6, 3), (3, 1)\}.
```

 שימו לב שהקבוצה השנייה היא שיקוף של הראשונה ביחס לישר $`y = x`$ (החלפת הקואורדינטות). בדקנו שכל 21 השוויונות ($`0 \le j \le d \le 5`$) מתקיימים, ושבדרגה $`d = 6`$ השוויון נשבר. לא ידועים פתרונות עם $`n = k + 1`$ עבור $`k \ge 6`$.
