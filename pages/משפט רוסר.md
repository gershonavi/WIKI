# משפט רוסר

ב[תורת המספרים](https://he.wikipedia.org/wiki/%D7%AA%D7%95%D7%A8%D7%AA_%D7%94%D7%9E%D7%A1%D7%A4%D7%A8%D7%99%D7%9D), **משפט רוסר** קובע שה[מספר הראשוני](https://he.wikipedia.org/wiki/%D7%9E%D7%A1%D7%A4%D7%A8_%D7%A8%D7%90%D7%A9%D7%95%D7%A0%D7%99) ה-$`n`$-י גדול מ-$`n \log n`$, כאשר $`\log`$ היא פונקציית ה[לוגריתם הטבעי](https://he.wikipedia.org/wiki/%D7%9C%D7%95%D7%92%D7%A8%D7%99%D7%AA%D7%9D_%D7%98%D7%91%D7%A2%D7%99). את המשפט פרסם ג'ון ברקלי רוסר בשנת 1939.[^1]

הניסוח המלא הוא: יהי $`p_n`$ הראשוני ה-$`n`$-י. אז לכל $`n\geq 1`$



```math
p_n > n \log n.
```



בשנת 1999 הוכיח פייר דוזאר חסם תחתון הדוק יותר, עבור $`n\geq 2`$:[^2]



```math
p_n > n (\log n + \log \log n - 1).
```
