# פונקציות אליפטיות למניסקטיות

ב[מתמטיקה](https://he.wikipedia.org/wiki/%D7%9E%D7%AA%D7%9E%D7%98%D7%99%D7%A7%D7%94), **הפונקציות האליפטיות הלמניסקטיות** הן [פונקציות אליפטיות](https://he.wikipedia.org/wiki/%D7%A4%D7%95%D7%A0%D7%A7%D7%A6%D7%99%D7%94_%D7%90%D7%9C%D7%99%D7%A4%D7%98%D7%99%D7%AA) שקשורות לאורך הקשת של [למניסקטת ברנולי](https://he.wikipedia.org/wiki/%D7%9C%D7%9E%D7%A0%D7%99%D7%A1%D7%A7%D7%98%D7%94). חקרו אותן לראשונה ג'וליו פניאנו ב-1718, ואחריו [לאונרד אוילר](https://he.wikipedia.org/wiki/%D7%9C%D7%90%D7%95%D7%A0%D7%A8%D7%93_%D7%90%D7%95%D7%99%D7%9C%D7%A8), [קרל פרידריך גאוס](https://he.wikipedia.org/wiki/%D7%A7%D7%A8%D7%9C_%D7%A4%D7%A8%D7%99%D7%93%D7%A8%D7%99%D7%9A_%D7%92%D7%90%D7%95%D7%A1) ואחרים.

**הסינוס הלמניסקטי** ו**הקוסינוס הלמניסקטי**, שמסומנים בדרך כלל $`\mathrm{sl}`$ ו-$`\mathrm{cl}`$ (הסימון של גאוס), הם האנלוגים של ה[פונקציות הטריגונומטריות](https://he.wikipedia.org/wiki/%D7%A4%D7%95%D7%A0%D7%A7%D7%A6%D7%99%D7%95%D7%AA_%D7%98%D7%A8%D7%99%D7%92%D7%95%D7%A0%D7%95%D7%9E%D7%98%D7%A8%D7%99%D7%95%D7%AA) סינוס וקוסינוס. הסינוס הטריגונומטרי מקשר בין אורך קשת לאורך מיתר במעגל שקוטרו 1, $`x^2+y^2 = x`$; הסינוס הלמניסקטי מקשר בין אורך קשת לאורך מיתר בלמניסקטה $`(x^2+y^2)^2=x^2-y^2`$.

לפונקציות הלמניסקטיות יש מחזורים שקשורים למספר $`\varpi = 2.622057\ldots`$, שנקרא **הקבוע הלמניסקטי** – היחס בין היקף הלמניסקטה לקוטר שלה. זה האנלוג ה"ממעלה רביעית" של $`\pi = 3.141592\ldots`$, היחס בין היקף המעגל לקוטרו.

כפונקציות מרוכבות, ל-$`\mathrm{sl}`$ ול-$`\mathrm{cl}`$ יש **סריג מחזורים ריבועי** (כפולה של [השלמים הגאוסיים](https://he.wikipedia.org/wiki/%D7%A9%D7%9C%D7%9D_%D7%92%D7%90%D7%95%D7%A1%D7%99)) עם המחזורים היסודיים $`(1 + i)\varpi`$ ו-$`(1 - i)\varpi`$. הן מקרה פרטי של פונקציות אליפטיות של יעקובי: $`\mathrm{sl} z = \mathrm{sn}(z; -1)`$ ו-$`\mathrm{cl} z = \mathrm{cd}(z; -1)`$.

## הגדרות

אפשר להגדיר את $`\mathrm{sl}`$ ו-$`\mathrm{cl}`$ כפתרון של בעיית ההתחלה



```math
\frac{d}{dz} \mathrm{sl} z = \bigl(1 + \mathrm{sl}^2 z\bigr)\mathrm{cl}z,\quad \frac{d}{dz} \mathrm{cl} z = -\bigl(1 + \mathrm{cl}^2 z\bigr)\mathrm{sl}z,\quad \mathrm{sl} 0 = 0,\ \mathrm{cl} 0 = 1,
```

 או, באופן שקול, כהפכיות של [אינטגרל אליפטי](https://he.wikipedia.org/wiki/%D7%90%D7%99%D7%A0%D7%98%D7%92%D7%A8%D7%9C_%D7%90%D7%9C%D7%99%D7%A4%D7%98%D7%99) – העתקת שוורץ–כריסטופל מעיגול היחידה המרוכב לריבוע שקודקודיו $`\pm\tfrac12\varpi, \pm\tfrac12\varpi i`$:



```math
z = \int_0^{\mathrm{sl} z}\frac{dt}{\sqrt{1-t^4} } = \int_{\mathrm{cl} z}^1\frac{dt}{\sqrt{1-t^4} }.
```

 מחוץ לריבוע הזה מרחיבים את הפונקציות לכל המישור המרוכב ב[המשכה אנליטית](https://he.wikipedia.org/wiki/%D7%94%D7%9E%D7%A9%D7%9B%D7%94_%D7%90%D7%A0%D7%9C%D7%99%D7%98%D7%99%D7%AA), על ידי שיקופים חוזרים.

להשוואה: אפשר להגדיר את הסינוס והקוסינוס כפתרון של $`\sin' = \cos`$, $`\cos' = -\sin`$, $`\sin 0 = 0`$, $`\cos 0 = 1`$, או כהפכי של $`z = \int_0^{\sin z}\frac{dt}{\sqrt{1-t^2} }`$.

## הקבוע הלמניסקטי

לפונקציות הלמניסקטיות יש מחזור ממשי מינימלי $`2\varpi`$, מחזור מדומה מינימלי $`2\varpi i`$, ומחזורים מרוכבים יסודיים $`(1\pm i)\varpi`$, כאשר



```math
\varpi = 2\int_0^1\frac{dt}{\sqrt{1-t^4} } = \frac{\sqrt{2}\,\pi^{3/2} }{2\,\Gamma\left(\tfrac{3}{4}\right)^2} = 2.6220575542921\ldots
```

 מתקיים $`\mathrm{cl}z = \mathrm{sl}\bigl(\tfrac12\varpi - z\bigr)`$, בדומה ל-$`\cos z = \sin\bigl(\tfrac12\pi - z\bigr)`$.

הקבוע $`\varpi`$ הוא אנלוג קרוב של $`\pi`$, ולזהויות רבות עם $`\pi`$ יש אנלוגים עם $`\varpi`$. למשל, בדומה ל[נוסחת מאצ'ין](https://he.wikipedia.org/wiki/%D7%A0%D7%95%D7%A1%D7%97%D7%AA_%D7%9E%D7%90%D7%A6%27%D7%99%D7%9F) $`\tfrac14\pi = 4\arctan\tfrac15 - \arctan\tfrac1{239}`$, גאוס מצא



```math
\tfrac12\varpi = 2 \mathrm{arcsl} \tfrac12 + \mathrm{arcsl} \tfrac7{23}.
```

 גאוס גילה גם את הקשר ל[ממוצע האריתמטי-גאומטרי](https://he.wikipedia.org/wiki/%D7%94%D7%9E%D7%9E%D7%95%D7%A6%D7%A2_%D7%94%D7%90%D7%A8%D7%99%D7%AA%D7%9E%D7%98%D7%99-%D7%92%D7%90%D7%95%D7%9E%D7%98%D7%A8%D7%99) $`M`$:



```math
\frac\pi\varpi = M\bigl(1, \sqrt2\bigr) = 1.1981402347\ldots
```

 (בדקנו בחישוב את שני השוויונות, בדיוק של 30 ספרות.) ההבחנה הזו, מ-30 במאי 1799, הובילה את גאוס לתורת הפונקציות האליפטיות.

## זהויות

### אפסים, קטבים וסימטריות

$`\mathrm{cl}`$ זוגית ו-$`\mathrm{sl}`$ אי-זוגית. הזזה ב-$`\tfrac12\varpi`$ מחליפה ביניהן: $`\mathrm{sl}\bigl(z + \tfrac12\varpi\bigr) = \mathrm{cl} z`$ ו-$`\mathrm{cl}\bigl(z + \tfrac12\varpi\bigr) = -\mathrm{sl} z`$. הזזה ב-$`\varpi`$ או ב-$`i\varpi`$ הופכת את הסימן של שתיהן, ולכן הן שמורות תחת הזזה ב-$`(a + bi)\varpi`$ כאשר $`a + b`$ זוגי: זה סריג המחזורים הריבועי האלכסוני. שיקופים וסיבובים ברבע סיבוב פועלים בפשטות:



```math
\mathrm{sl}\bar z = \overline{\mathrm{sl} z}, \qquad \mathrm{sl}(iz) = i\mathrm{sl}z, \qquad \mathrm{cl}(iz) = \frac{1}{\mathrm{cl}z}.
```

 ל-$`\mathrm{sl}`$ יש אפסים פשוטים בכפולות שלמות-גאוסיות של $`\varpi`$, וקטבים פשוטים בנקודות $`\bigl(a + \tfrac12\bigr)\varpi + \bigl(b + \tfrac12\bigr)\varpi i`$.

### זהות "פיתגורית" ונגזרות



```math
\mathrm{cl}^2 z + \mathrm{sl}^2 z + \mathrm{cl}^2 z\, \mathrm{sl}^2 z = 1,
```

 או באופן שקול $`\bigl(1 + \mathrm{cl}^2 z\bigr) \bigl(1+\mathrm{sl}^2 z\bigr) = 2`$. לכן $`(x, y) = (\mathrm{cl} t, \mathrm{sl} t)`$ הוא פרמטריזציה של העקום $`x^2 + y^2 + x^2y^2 = 1`$. הנגזרות מקיימות $`(\mathrm{sl}' z)^2 = 1 - \mathrm{sl}^4 z`$ ו-$`\mathrm{sl}'' z = -2\mathrm{sl}^3 z`$ (ובאופן דומה ל-$`\mathrm{cl}`$). אינטגרלים: $`\int\mathrm{cl}z\,dz = \arctan\mathrm{sl}z + C`$.

### נוסחאות חיבור וכפל

הזהות המקורית של פניאנו, ששימשה אותו לחציית הלמניסקטה, היא



```math
\mathrm{sl}(u+v) = \frac{\mathrm{sl}u\,\mathrm{sl}'v + \mathrm{sl}v\,\mathrm{sl}'u}{1 + \mathrm{sl}^2u\, \mathrm{sl}^2v}.
```

 בעזרת הנגזרת והזהות הפיתגורית אפשר לכתוב אותה כך:



```math
\mathrm{sl}(u+v) = \frac{\mathrm{sl}u\, \mathrm{cl}v + \mathrm{cl}u\, \mathrm{sl}v}{1 - \mathrm{sl}u\, \mathrm{cl}u\, \mathrm{sl}v\, \mathrm{cl}v}, \qquad \mathrm{cl}(u+v) = \frac{\mathrm{cl}u\, \mathrm{cl}v - \mathrm{sl}u\, \mathrm{sl}v}{1 + \mathrm{sl}u\, \mathrm{cl}u\, \mathrm{sl}v\, \mathrm{cl}v}.
```

 נוסחאות ההכפלה וההשלשה הן



```math
\mathrm{sl} 2x = 2\,\mathrm{sl}x\,\mathrm{cl}x\frac{1+\mathrm{sl}^2x}{1+\mathrm{sl}^4x}, \qquad \mathrm{sl} 3x = \frac{3\mathrm{sl}x - 6\mathrm{sl}^5x - \mathrm{sl}^9x}{1 + 6\mathrm{sl}^4x - 3\mathrm{sl}^8x}.
```

 שימו לב ל"סימטריה ההפוכה" של המקדמים במונה ובמכנה של $`\mathrm{sl}3x`$.

### כפל מרוכב



```math
\mathrm{sl}\bigl((1\pm i)z\bigr)=(1\pm i)\frac{\mathrm{sl}z}{\mathrm{sl}'z}.
```

 זה מקרה פרטי של [כפל מרוכב](%D7%9B%D7%A4%D7%9C%20%D7%9E%D7%A8%D7%95%D7%9B%D7%91.md): יש נוסחאות דומות ל-$`\mathrm{sl}\bigl((n+mi)z\bigr)`$ לכל שלם גאוסי $`n + mi`$, כלומר ל-$`\mathrm{sl}`$ יש כפל מרוכב ב-$`\mathbb Z[i]`$. העקום האליפטי שמתאים לסריג הוא $`y^2 = x^3 - x`$ (עד כדי שינוי קנה מידה), ו[אינווריאנט ה-$`j`$](%D7%90%D7%99%D7%A0%D7%95%D7%95%D7%A8%D7%99%D7%90%D7%A0%D7%98%20j.md) שלו הוא 1728.

(בדקנו בחישוב, בנקודה $`z = 0.3 + 0.2i`$ ובערכים ממשיים, את הזהות הפיתגורית, נוסחת החיבור, נוסחת ההשלשה ונוסחת הכפל המרוכב.)

## הפולינומים הלמנטומיים

הפונקציה $`\mathrm{sl}`$ מאפשרת לבנות את [ההרחבות האבליות](https://he.wikipedia.org/wiki/%D7%AA%D7%95%D7%A8%D7%AA_%D7%A9%D7%93%D7%95%D7%AA_%D7%94%D7%9E%D7%97%D7%9C%D7%A7%D7%94) של $`K = \mathbb Q(i)`$, כמו ששורשי היחידה בונים את ההרחבות האבליות של $`\mathbb Q`$ (זה ה**יוגנדטראום** של קרונקר עבור $`\mathbb Q(i)`$). לשלם גאוסי $`\beta = m + ni`$ עם $`m + n`$ אי-זוגי, **הפולינום הלמנטומי** ה-$`\beta`$-י הוא



```math
\Lambda_\beta(x) = \prod_{[\alpha]\in(\mathcal O/\beta\mathcal O)^\times}\bigl(x - \mathrm{sl}(\alpha\delta_\beta)\bigr),
```

 כאשר $`\mathcal O = \mathbb Z[i]`$ ו-$`\delta_\beta`$ יוצר של נקודות ה-$`\beta`$-פיתול (למשל $`2\varpi/\beta`$). זה פולינום מתוקן ואי-פריק מעל $`K`$ עם מקדמים ב-$`\mathbb Z[i]`$, והוא האנלוג הלמניסקטי של [הפולינומים הציקלוטומיים](https://he.wikipedia.org/wiki/%D7%A4%D7%95%D7%9C%D7%99%D7%A0%D7%95%D7%9D_%D7%A6%D7%99%D7%A7%D7%9C%D7%95%D7%98%D7%95%D7%9E%D7%99). למשל:

- $`\Lambda_5(x)=x^{16}+52x^{12}-26x^8-12x^4+1`$, והשורש $`\omega_5 = \mathrm{sl}(2\varpi/5)`$ שלו הוא $`\omega_5 = \sqrt[4]{-13+6\sqrt{5}+2\sqrt{85-38\sqrt{5} } }`$;
- $`\Lambda_{-1+2i}(x)=x^4-1+2i`$, עם השורש $`\mathrm{sl}\bigl(2\varpi/(-1+2i)\bigr)`$.

(בדקנו בחישוב ששני הערכים האלה אכן שורשים של הפולינומים.) עבור $`\beta`$ חיובי ואי-זוגי, המעלה היא



```math
\deg\Lambda_{\beta}=\beta^2\prod_{p\mid\beta}\left(1-\frac{1}{p}\right)\left(1-\frac{(-1)^{(p-1)/2} }{p}\right),
```

 בדומה ל-$`\deg\Phi_{k}=k\prod_{p\mid k}\left(1-\frac{1}{p}\right)`$. למשל $`\deg\Lambda_5 = 25\cdot\frac45\cdot\frac45 = 16`$ ו-$`\deg\Lambda_3 = 9\cdot\frac23\cdot\frac43 = 8`$.

## הקשר לצורות גאומטריות

### אורך הקשת של למניסקטת ברנולי

תהי $`\mathcal{L}`$ למניסקטת ברנולי שהמרחק ממרכזה לנקודה הרחוקה ביותר הוא 1. אפשר לאפיין אותה כמקום הגאומטרי של הנקודות שמכפלת מרחקיהן משני המוקדים $`\bigl(\pm\tfrac1{\sqrt2},0\bigr)`$ היא $`\tfrac12`$, או על ידי המשוואה הקוטבית $`r^2 = \cos 2\theta`$, או המשוואה הקרטזית $`(x^2+y^2)^2=x^2-y^2`$. ההיקף של $`\mathcal{L}`$ הוא $`2\varpi`$, והשטח שהיא חוסמת הוא 1.

הנקודה ברביע הראשון במרחק $`r`$ מהראשית היא $`\big(x(r), y(r)\big) = \Bigl(\sqrt{\tfrac12r^2(1 + r^2)},\, \sqrt{\tfrac12r^2(1 - r^2)}\Bigr)`$, ואורך הקשת מהראשית אליה הוא



```math
\int_0^r \sqrt{x'(t)^2 + y'(t)^2}\,dt = \int_0^r \frac{dt}{\sqrt{1-t^4} } = \mathrm{arcsl} r.
```

 כלומר הסינוס הלמניסקטי נותן את המרחק מהראשית כפונקציה של אורך הקשת. (למשל עבור $`r = 0.6`$ שני הצדדים שווים ל-$`0.6082303\ldots`$; בדקנו בחישוב.)

### חלוקת הלמניסקטה

פניאנו גילה ב-1718 את נוסחת ההכפלה לאינטגרל הלמניסקטי, ובעזרתה חילק את הלמניסקטה לחצאים בסרגל ובמחוגה. [אבל](https://he.wikipedia.org/wiki/%D7%A0%D7%99%D7%9C%D7%A1_%D7%94%D7%A0%D7%A8%D7%99%D7%A7_%D7%90%D7%91%D7%9C) הוכיח ב-1827–1828 שאפשר לחלק את הלמניסקטה ל-$`n`$ חלקים שווים בסרגל ובמחוגה כאשר $`n = 2^kp_1\cdots p_m`$ עם $`p_i`$ ראשוניי פרמה שונים, ומייקל רוזן הוכיח ב-1981 שאלה המקרים היחידים – בדיוק כמו במשפט גאוס–ונצל על [מצולעים משוכללים בני-בנייה](https://he.wikipedia.org/wiki/%D7%9E%D7%A6%D7%95%D7%9C%D7%A2_%D7%91%D7%A8-%D7%91%D7%A0%D7%99%D7%99%D7%94). באופן שקול: החלוקה אפשרית אם ורק אם $`\varphi(n)`$ חזקה של 2. למשל, אפשר לחלק את הלמניסקטה ל-15 חלקים שווים, כי $`15 = 3\cdot 5`$. נקודות החלוקה הן $`\Bigl(r_j\sqrt{\tfrac12(1+r_j^2)},\ \pm\sqrt{\tfrac12r_j^2(1-r_j^2)}\Bigr)`$ עם $`r_j=\mathrm{sl}\frac{2j\varpi}{n}`$.

## טורי חזקות

טור החזקות של הסינוס הלמניסקטי סביב הראשית הוא



```math
\mathrm{sl}z = z-12\frac{z^5}{5!}+3024\frac{z^9}{9!}-4390848\frac{z^{13} }{13!}+\cdots,\qquad |z|\lt \tfrac{\varpi}{\sqrt{2} },
```

 כאשר רק חזקות מהצורה $`z^{4k+1}`$ מופיעות. המקדמים $`a_n`$ מקיימים $`a_1 = 1`$ והנסיגה



```math
a_{n+2}=-\frac{2}{(n+1)(n+2)}\sum_{i+j+k=n}a_ia_ja_k,
```

 שנובעת מהמשוואה $`\mathrm{sl}'' = -2\mathrm{sl}^3`$. לדוגמה, ל-$`a_{13}`$ תורמות רק ששת ההרכבים $`11 = 9+1+1 = 1+9+1 = 1+1+9 = 5+5+1 = 5+1+5 = 1+5+5`$, ומתקבל $`a_{13} = -\frac{11}{15600} = -\frac{4390848}{13!}`$.

## חישוב

אפשר לחשב את הפונקציות הלמניסקטיות מהר בעזרת [פונקציות התטא של יעקובי](https://he.wikipedia.org/wiki/%D7%A4%D7%95%D7%A0%D7%A7%D7%A6%D7%99%D7%99%D7%AA_%D7%AA%D7%98%D7%90) עם $`q = e^{-\pi}`$:



```math
\mathrm{sl}\Bigl(\frac\varpi\pi x\Bigr) = \frac{\theta_1(x, e^{-\pi})}{\theta_3(x, e^{-\pi})}, \qquad \mathrm{cl}\Bigl(\frac\varpi\pi x\Bigr)=\frac{\theta_2(x, e^{-\pi})}{\theta_4(x, e^{-\pi})}.
```

 את כל הבדיקות המספריות בערך הזה עשינו בנוסחאות האלה. יש גם טור פורייה מהיר:



```math
\mathrm{sl}\Bigl(\frac{\varpi}{\pi}x\Bigr)=\frac{2\pi}{\varpi}\sum_{n=0}^\infty \frac{(-1)^n\sin ((2n+1)x)}{\cosh ((n+\tfrac12)\pi)},\qquad |\mathrm{Im}\,x|\lt\tfrac{\pi}{2}.
```
