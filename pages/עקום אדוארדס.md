# עקום אדוארדס

ב[מתמטיקה](https://he.wikipedia.org/wiki/%D7%9E%D7%AA%D7%9E%D7%98%D7%99%D7%A7%D7%94), **עקומי אדוארדס** הם משפחה של [עקומים אליפטיים](https://he.wikipedia.org/wiki/%D7%A2%D7%A7%D7%95%D7%9D_%D7%90%D7%9C%D7%99%D7%A4%D7%98%D7%99) שחקר [הרולד אדוארדס](%D7%94%D7%A8%D7%95%D7%9C%D7%93%20%D7%90%D7%93%D7%95%D7%90%D7%A8%D7%93%D7%A1.md) ב-2007.[^1] עקומים אליפטיים מעל [שדות סופיים](https://he.wikipedia.org/wiki/%D7%A9%D7%93%D7%94_%D7%A1%D7%95%D7%A4%D7%99) נמצאים בשימוש נרחב בקריפטוגרפיה של עקומים אליפטיים. את השימושים של עקומי אדוארדס ב[קריפטוגרפיה](https://he.wikipedia.org/wiki/%D7%A7%D7%A8%D7%99%D7%A4%D7%98%D7%95%D7%92%D7%A8%D7%A4%D7%99%D7%94) פיתחו דניאל ברנשטיין ותניה לנגה, שהצביעו על כמה יתרונות של צורת אדוארדס לעומת צורת ויירשטראס המוכרת יותר: בעיקר, חוק חיבור אחד ויחיד שעובד לכל זוג נקודות, בלי מקרים מיוחדים. מערכת החתימות Ed25519 בנויה על עקום כזה.

## הגדרה

המשוואה של עקום אדוארדס מעל [שדה](https://he.wikipedia.org/wiki/%D7%A9%D7%93%D7%94_%28%D7%9E%D7%91%D7%A0%D7%94_%D7%90%D7%9C%D7%92%D7%91%D7%A8%D7%99%29) $`K`$ ש[מאפיינו](https://he.wikipedia.org/wiki/%D7%9E%D7%90%D7%A4%D7%99%D7%99%D7%9F_%28%D7%90%D7%9C%D7%92%D7%91%D7%A8%D7%94%29) אינו 2 היא



```math
x^2 + y^2 = 1 + d\,x^2y^2
```

 עבור [סקלר](https://he.wikipedia.org/wiki/%D7%A1%D7%A7%D7%9C%D7%A8) $`d \in K \setminus \{0, 1\}`$. גם הצורה הבאה, עם פרמטרים $`c`$ ו-$`d`$, נקראת עקום אדוארדס:



```math
x^2 + y^2 = c^2(1 + d\,x^2y^2),
```

 כאשר $`c, d \in K`$ ו-$`cd(1 - c^4d) \ne 0`$.

כל עקום אדוארדס שקול בירציונלית לעקום אליפטי ב[צורת מונטגומרי](%D7%A2%D7%A7%D7%95%D7%9D%20%D7%9E%D7%95%D7%A0%D7%98%D7%92%D7%95%D7%9E%D7%A8%D7%99.md), ולכן יש עליו חוק חבורה [אלגברי](https://he.wikipedia.org/wiki/%D7%97%D7%91%D7%95%D7%A8%D7%94_%D7%90%D7%9C%D7%92%D7%91%D7%A8%D7%99%D7%AA) ברגע שבוחרים נקודה שתשמש איבר נייטרלי. אם $`K`$ סופי, אז חלק ניכר מכל העקומים האליפטיים מעל $`K`$ אפשר לכתוב כעקומי אדוארדס (בדיוק אלה שיש להם נקודה מסדר 4; ראו להלן). לעיתים קרובות מגדירים עקומים אליפטיים בצורת אדוארדס עם $`c = 1`$, בלי הגבלת הכלליות. בסעיפים הבאים נניח ש-$`c = 1`$.

## חוק החבורה

(ראו גם [חוק החבורה בעקומי ויירשטראס](https://he.wikipedia.org/wiki/%D7%A2%D7%A7%D7%95%D7%9D_%D7%90%D7%9C%D7%99%D7%A4%D7%98%D7%99).)

כל עקום אדוארדס $`x^2 + y^2 = 1 + dx^2y^2`$ מעל שדה $`K`$ ממאפיין שונה מ-2, עם $`d \ne 1`$, שקול בירציונלית לעקום אליפטי מעל אותו שדה:



```math
\frac1e v^2 = u^3 + \left(\frac4e - 2\right)u^2 + u, \qquad e = 1 - d,\quad u = \frac{1+y}{1-y},\quad v = \frac{2(1+y)}{x(1-y)},
```

 והנקודה $`(0, 1)`$ עוברת לנקודה באינסוף $`O`$. ההעתקה הבירציונלית הזו משרה מבנה של חבורה על כל עקום אדוארדס.

### חוק החיבור של אדוארדס

בכל עקום אליפטי, הסכום של שתי נקודות נתון על ידי ביטוי רציונלי בקואורדינטות שלהן, אם כי בדרך כלל צריך כמה נוסחאות כדי לכסות את כל הזוגות האפשריים. בעקום אדוארדס, כשהאיבר ה[נייטרלי](https://he.wikipedia.org/wiki/%D7%90%D7%99%D7%91%D7%A8_%D7%99%D7%97%D7%99%D7%93%D7%94) הוא הנקודה $`(0, 1)`$, הסכום של $`(x_1, y_1)`$ ו-$`(x_2, y_2)`$ נתון על ידי הנוסחה



```math
(x_1, y_1) + (x_2, y_2) = \left(\frac{x_1y_2 + x_2y_1}{1 + dx_1x_2y_1y_2},\ \frac{y_1y_2 - x_1x_2}{1 - dx_1x_2y_1y_2}\right).
```



ה[נגדית](https://he.wikipedia.org/wiki/%D7%90%D7%99%D7%91%D7%A8_%D7%A0%D7%92%D7%93%D7%99) של נקודה $`(x, y)`$ היא $`(-x, y)`$. הנקודה $`(0, -1)`$ היא מסדר 2, והנקודות $`(\pm 1, 0)`$ הן מסדר 4. בפרט, לעקום אדוארדס יש תמיד נקודה מסדר 4 עם קואורדינטות ב-$`K`$. לכן מעל שדה סופי, סדר החבורה של עקום אדוארדס מתחלק תמיד ב-4.

אם $`d`$ **אינו ריבוע** ב-$`K`$, אין נקודות חריגות: לכל שתי נקודות $`(x_1, y_1), (x_2, y_2)`$ על העקום, המכנים $`1 + dx_1x_2y_1y_2`$ ו-$`1 - dx_1x_2y_1y_2`$ שונים מאפס. לכן חוק החיבור של אדוארדס **שלם** כאשר $`d`$ אינו ריבוע ב-$`K`$: הנוסחאות עובדות לכל זוג נקודות על העקום, בלי חריגים להכפלה, לאיבר הנייטרלי, לנקודות נגדיות וכדומה.[^2] במילים אחרות, הנוסחה מוגדרת לכל זוג נקודות על העקום מעל $`K`$, ונותנת את סכומן.

**למה אין חריגים.** נניח ש-$`dx_1x_2y_1y_2 = \pm 1`$, ונסמן $`\epsilon = dx_1x_2y_1y_2`$; אז $`x_1, x_2, y_1, y_2 \ne 0`$. ממשוואת העקום של הנקודה השנייה מקבלים $`dx_1^2y_1^2(x_2^2 + y_2^2) = dx_1^2y_1^2 + d^2x_1^2x_2^2y_1^2y_2^2 = dx_1^2y_1^2 + \epsilon^2`$, ולכן $`dx_1^2y_1^2(x_2^2 + y_2^2) = 1 + dx_1^2y_1^2 = x_1^2 + y_1^2`$. עכשיו חשבו את $`(x_1 + \epsilon y_1)^2`$: $`x_1^2 + y_1^2 + 2\epsilon x_1y_1 = dx_1^2y_1^2(x_2^2 + y_2^2) + 2dx_1^2y_1^2x_2y_2 = dx_1^2y_1^2(x_2 + y_2)^2`$. אם $`x_2 + y_2 \ne 0`$, מקבלים ש-$`d = \left(\frac{x_1 + \epsilon y_1}{x_1y_1(x_2 + y_2)}\right)^2`$ ריבוע, בסתירה. אם $`x_2 + y_2 = 0`$, מחליפים את התפקיד של הסימן ומקבלים באותו אופן $`(x_1 - \epsilon y_1)^2 = dx_1^2y_1^2(x_2 - y_2)^2`$ עם $`x_2 - y_2 = 2x_2 \ne 0`$, ושוב $`d`$ ריבוע.

אם $`d`$ **ריבוע** ב-$`K`$, לאותה פעולה עשויות להיות נקודות חריגות, כלומר זוגות נקודות על העקום שעבורם אחד המכנים מתאפס: $`1 + dx_1x_2y_1y_2 = 0`$ או $`1 - dx_1x_2y_1y_2 = 0`$.

נוסחת החיבור הזו מהירה יותר מנוסחאות מאוחדות אחרות, ויש לה את התכונה החזקה של שלמות: היא אינה דורשת חריגים או הסתעפויות. אחת התכונות המושכות של חוק החיבור של אדוארדס היא שהוא **מאוחד**: אפשר להשתמש בו גם להכפלת נקודה, וזה מפשט את ההגנה מפני [התקפות ערוץ צדדי](https://he.wikipedia.org/wiki/%D7%94%D7%AA%D7%A7%D7%A4%D7%AA_%D7%A2%D7%A8%D7%95%D7%A5_%D7%A6%D7%93%D7%93%D7%99).[^3] העובדה שהחישוב אינו מסתעף פירושה שהוא אינו מדליף מידע על תזמון שקשור להסתעפויות, למשל דרך צריכת ההספק של המחשב.

**דוגמה.** נתבונן בעקום אדוארדס עם $`d = 2`$,



```math
x^2 + y^2 = 1 + 2x^2y^2,
```

 ובנקודה $`P_1 = (1, 0)`$ שעליו. הסכום של $`P_1`$ עם האיבר הנייטרלי $`(0, 1)`$ הוא שוב $`P_1`$:



```math
x_3 = \frac{1\cdot 1 + 0\cdot 0}{1 + 0} = 1, \qquad y_3 = \frac{0\cdot 1 - 1\cdot 0}{1 - 0} = 0.
```



### אנלוגיה במעגל

כדי להבין טוב יותר את "החיבור" של נקודות על עקום, דוגמה טובה היא חבורת המעגל הקלאסית: ניקח את מעגל היחידה



```math
x^2 + y^2 = 1
```

 ושתי נקודות $`P_1 = (x_1, y_1)`$, $`P_2 = (x_2, y_2)`$ עליו. יהיו $`\alpha_1, \alpha_2`$ הזוויות שעבורן



```math
P_1 = (\sin\alpha_1, \cos\alpha_1), \qquad P_2 = (\sin\alpha_2, \cos\alpha_2).
```

 הסכום של $`P_1`$ ו-$`P_2`$ נתון על ידי סכום "הזוויות שלהן": $`P_3 = P_1 + P_2`$ היא הנקודה על המעגל עם



```math
x_3 = \sin(\alpha_1 + \alpha_2) = \sin\alpha_1\cos\alpha_2 + \sin\alpha_2\cos\alpha_1 = x_1y_2 + x_2y_1,
```





```math
y_3 = \cos(\alpha_1 + \alpha_2) = \cos\alpha_1\cos\alpha_2 - \sin\alpha_1\sin\alpha_2 = y_1y_2 - x_1x_2.
```

 לכן נוסחת החיבור במעגל היחידה היא



```math
(x_1, y_1) + (x_2, y_2) = (x_1y_2 + x_2y_1,\ y_1y_2 - x_1x_2).
```

 זה בדיוק חוק אדוארדס עם $`d = 0`$; העקום עם $`d \ne 0`$ הוא "עיוות" של המעגל, והמכנים $`1 \pm dx_1x_2y_1y_2`$ הם התיקון. כמו במעגל, הנקודה $`(0, 1)`$ (זווית 0) היא האיבר הנייטרלי, $`(\pm 1, 0)`$ הן "רבע סיבוב" (סדר 4), ו-$`(0, -1)`$ היא "חצי סיבוב" (סדר 2).

### חיבור כחיתוך עם חתך חרוט

הנקודות על עקום אליפטי יוצרות [חבורה אבלית](https://he.wikipedia.org/wiki/%D7%97%D7%91%D7%95%D7%A8%D7%94_%D7%90%D7%91%D7%9C%D7%99%D7%AA): אפשר לחבר נקודות ולקחת כפולות שלמות של נקודה. כאשר עקום אליפטי מתואר על ידי [משוואה ממעלה שלישית](https://he.wikipedia.org/wiki/%D7%9E%D7%A9%D7%95%D7%95%D7%90%D7%94_%D7%9E%D7%9E%D7%A2%D7%9C%D7%94_%D7%A9%D7%9C%D7%99%D7%A9%D7%99%D7%AA) לא-סינגולרית, הסכום $`P + Q`$ קשור ישירות לנקודת החיתוך השלישית של העקום עם הישר דרך $`P`$ ו-$`Q`$.

ההעתקה הבירציונלית בין עקום אדוארדס לבין העקום הממעלה השלישית המתאים מעבירה ישרים ל[חתכי חרוט](https://he.wikipedia.org/wiki/%D7%97%D7%AA%D7%9A_%D7%97%D7%A8%D7%95%D7%98) מהצורה $`Axy + Bx + Cy + D = 0`$.[^4] במילים אחרות, בעקומי אדוארדס שלוש הנקודות $`P`$, $`Q`$ ו-$`-(P+Q)`$ נמצאות על [היפרבולה](https://he.wikipedia.org/wiki/%D7%94%D7%99%D7%A4%D7%A8%D7%91%D7%95%D7%9C%D7%94).

בהינתן שתי נקודות שונות $`P_1 = (x_1, y_1) \ne P_2 = (x_2, y_2)`$, שאינן האיבר הנייטרלי, המקדמים של חתך החרוט הם (עד כדי כפל בסקלר):



```math
A = (x_1 - x_2) + (x_1y_2 - x_2y_1),\quad B = (x_2y_2 - x_1y_1) + y_1y_2(x_2 - x_1),\quad C = D = x_1x_2(y_1 - y_2).
```

 במקרה של הכפלת נקודה $`P = (x, y)`$, הנקודה $`-2P`$ נמצאת על חתך החרוט שמשיק לעקום בנקודה $`P`$, ומקדמיו (עד כדי כפל בסקלר) הם



```math
A = dx^2y - 1,\quad B = y - x^2,\quad C = D = x(1 - y).
```



## קואורדינטות הומוגניות פרויקטיביות

בהקשר הקריפטוגרפי משתמשים ב[קואורדינטות הומוגניות](https://he.wikipedia.org/wiki/%D7%A7%D7%95%D7%90%D7%95%D7%A8%D7%93%D7%99%D7%A0%D7%98%D7%95%D7%AA_%D7%94%D7%95%D7%9E%D7%95%D7%92%D7%A0%D7%99%D7%95%D7%AA) כדי להימנע מהפיכות בשדה, שמופיעות בנוסחה האפינית ויקרות בהרבה מכפל. כדי להימנע מהפיכות בנוסחאות החיבור של אדוארדס, אפשר לכתוב את משוואת העקום ב[קואורדינטות פרויקטיביות](https://he.wikipedia.org/wiki/%D7%9E%D7%A8%D7%97%D7%91_%D7%A4%D7%A8%D7%95%D7%99%D7%A7%D7%98%D7%99%D7%91%D7%99):



```math
(X^2 + Y^2)Z^2 = Z^4 + dX^2Y^2.
```

 נקודה פרויקטיבית $`(X : Y : Z)`$ מתאימה לנקודה ה[אפינית](https://he.wikipedia.org/wiki/%D7%9E%D7%A8%D7%97%D7%91_%D7%90%D7%A4%D7%99%D7%A0%D7%99) $`(X/Z, Y/Z)`$ על עקום אדוארדס. האיבר הנייטרלי מיוצג על ידי $`(0 : 1 : 1)`$, וההופכי של $`(X : Y : Z)`$ הוא $`(-X : Y : Z)`$.

נוסחת החיבור בקואורדינטות הומוגניות היא $`(X_1 : Y_1 : Z_1) + (X_2 : Y_2 : Z_2) = (X_3 : Y_3 : Z_3)`$, עם



```math
X_3 = Z_1Z_2(X_1Y_2 + X_2Y_1)(Z_1^2Z_2^2 - dX_1X_2Y_1Y_2),
```





```math
Y_3 = Z_1Z_2(Y_1Y_2 - X_1X_2)(Z_1^2Z_2^2 + dX_1X_2Y_1Y_2),
```





```math
Z_3 = (Z_1^2Z_2^2 - dX_1X_2Y_1Y_2)(Z_1^2Z_2^2 + dX_1X_2Y_1Y_2).
```



### קואורדינטות מורחבות

את החיבור של שתי נקודות על עקום אדוארדס אפשר לחשב ביעילות רבה יותר בקואורדינטות **מורחבות** $`(X : Y : Z : T)`$, שבהן $`T = XY/Z`$:[^5]



```math
(X_3 : Y_3 : Z_3 : T_3) = (X_1 : Y_1 : Z_1 : T_1) + (X_2 : Y_2 : Z_2 : T_2),
```





```math
A = X_1X_2,\quad B = Y_1Y_2,\quad C = dT_1T_2,\quad D = Z_1Z_2,
```





```math
E = (X_1 + Y_1)(X_2 + Y_2) - A - B,\quad F = D - C,\quad G = D + C,\quad H = B - A,
```





```math
X_3 = E\cdot F,\quad Y_3 = G\cdot H,\quad Z_3 = F\cdot G,\quad T_3 = E\cdot H.
```

 גם הנוסחאות האלה שלמות כאשר $`d`$ אינו ריבוע, ואפשר להשתמש בהן גם להכפלה. הקואורדינטה $`T_3`$ מקיימת שוב $`T_3Z_3 = X_3Y_3`$.

## הכפלה

**הכפלה** אפשר לבצע באותה נוסחה בדיוק כמו חיבור, כאשר $`(x_1, y_1) = (x_2, y_2)`$. עבור $`P = (x, y)`$:



```math
(x, y) + (x, y) = \left(\frac{2xy}{1 + dx^2y^2},\ \frac{y^2 - x^2}{1 - dx^2y^2}\right) = \left(\frac{2xy}{x^2 + y^2},\ \frac{y^2 - x^2}{2 - x^2 - y^2}\right).
```

 המכנים פושטו בעזרת משוואת העקום $`x^2 + y^2 = 1 + dx^2y^2`$, כך שהפרמטר $`d`$ כבר אינו מופיע. האצה נוספת מתקבלת מחישוב $`2xy`$ כ-$`(x+y)^2 - x^2 - y^2`$. כך עלות ההכפלה בקואורדינטות הומוגניות יורדת ל-$`3\mathbf M + 4\mathbf S`$ (ועוד 6 חיבורים בשדה, ו-3 כפלים ב-$`c`$ בצורה הכללית), בעוד שחיבור כללי עולה $`10\mathbf M + 1\mathbf S + 1\mathbf D`$ (ועוד 7 חיבורים בשדה, וכפל אחד ב-$`c`$ בצורה הכללית). כאן $`\mathbf M`$ הוא כפל בשדה, $`\mathbf S`$ העלאה בריבוע בשדה, ו-$`\mathbf D`$ כפל בפרמטר $`d`$ של העקום.

**דוגמה.** על העקום $`x^2 + y^2 = 1 + 2x^2y^2`$ מהדוגמה הקודמת, עם $`P_1 = (1, 0)`$:



```math
x_2 = \frac{2\cdot 1\cdot 0}{1 + 0} = 0, \qquad y_2 = \frac{0 - 1}{2 - 1} = -1,
```

 ולכן $`2P_1 = (0, -1)`$, הנקודה מסדר 2 – כצפוי, כי $`P_1`$ מסדר 4.

## חיבור מעורב

**חיבור מעורב** הוא המקרה שבו ידוע ש-$`Z_2 = 1`$ (למשל, כשמוסיפים שוב ושוב נקודת בסיס קבועה). במקרה כזה הכפל $`Z_1 \cdot Z_2`$ מתייתר, והעלות יורדת ל-$`9\mathbf M + 1\mathbf S + 1\mathbf D`$ (ועוד 7 חיבורים בשדה). האלגוריתם, לעקום עם $`c = 1`$:



```math
A = Z_1\ (= Z_1\cdot Z_2),\quad B = Z_1^2,\quad C = X_1X_2,\quad D = Y_1Y_2,\quad E = d\cdot C\cdot D,\quad F = B - E,\quad G = B + E,
```





```math
X_3 = A\cdot F\cdot\bigl((X_1 + Y_1)(X_2 + Y_2) - C - D\bigr),\quad Y_3 = A\cdot G\cdot(D - C),\quad Z_3 = F\cdot G.
```

 [^6]

## הכפלה בשלוש

**הכפלה בשלוש** אפשר לבצע על ידי הכפלה ואז חיבור התוצאה לנקודה המקורית. שימוש במשוואת העקום, כמו בהכפלה, נותן



```math
3(x_1, y_1) = \left(\frac{(x_1^2 + y_1^2)^2 - (2y_1)^2}{4(x_1^2 - 1)x_1^2 - (x_1^2 - y_1^2)^2}\,x_1,\ \frac{(x_1^2 + y_1^2)^2 - (2x_1)^2}{-4(y_1^2 - 1)y_1^2 + (x_1^2 - y_1^2)^2}\,y_1\right).
```

 יש שתי קבוצות נוסחאות לפעולה הזו בקואורדינטות אדוארדס הסטנדרטיות. הראשונה עולה $`9\mathbf M + 4\mathbf S`$, והשנייה $`7\mathbf M + 7\mathbf S`$. אם היחס $`\mathbf S/\mathbf M`$ קטן מאוד, ובפרט קטן מ-$`2/3`$, הקבוצה השנייה עדיפה; ביחסים גדולים יותר עדיפה הראשונה.[^7] את הנוסחאות מוצאים בחישוב סימבולי של $`3(X_1 : Y_1 : Z_1)`$ בעזרת נוסחאות החיבור וההכפלה, והשוואה ל-$`(X_3 : Y_3 : Z_3)`$.

**דוגמה.** על העקום עם $`d = 2`$ ועם $`P_1 = (1, 0)`$:



```math
x_3 = \frac{(1 + 0)^2 - 0}{4\cdot 0\cdot 1 - (1 - 0)^2}\cdot 1 = -1, \qquad y_3 = \frac{(1+0)^2 - 4}{-4\cdot(0 - 1)\cdot 0 + 1}\cdot 0 = 0.
```

 לכן $`3P_1 = (-1, 0) = -P_1`$. אפשר לקבל את התוצאה הזו גם מדוגמת ההכפלה: $`2P_1 = (0, -1)`$, ולכן $`3P_1 = 2P_1 + P_1 = (0, -1) + (1, 0) = (-1, 0) = -P_1`$.[^8]

**האלגוריתם** (עלות $`9\mathbf M + 4\mathbf S`$):



```math
A = X_1^2,\quad B = Y_1^2,\quad C = (2Z_1)^2,\quad D = A + B,\quad E = D^2,\quad F = 2D\cdot(A - B),
```





```math
G = E - B\cdot C,\quad H = E - A\cdot C,\quad I = F + H,\quad J = F - G,
```





```math
X_3 = G\cdot J\cdot X_1,\quad Y_3 = H\cdot I\cdot Y_1,\quad Z_3 = I\cdot J\cdot Z_1.
```



## דוגמה מעל שדה סופי

נתבונן בעקום $`x^2 + y^2 = 1 + 2x^2y^2`$ מעל $`\mathbb F_{13}`$. המספר 2 אינו ריבוע מודולו 13, ולכן חוק החיבור שלם. לעקום 8 נקודות:



```math
(0, 1),\ (0, 12),\ (\pm 1, 0),\ (4, 4),\ (4, 9),\ (9, 4),\ (9, 9),
```

 כלומר בנוסף לנקודה הנייטרלית, לנקודה מסדר 2 ולשתי הנקודות מסדר 4 יש עוד ארבע נקודות, כולן מסדר 8, והחבורה ציקלית. עבור $`P = (4, 4)`$: $`2P = \left(\frac{32}{1 + 2\cdot 256}, \frac{0}{\cdots}\right) = (6\cdot 6^{-1}, 0) = (1, 0)`$, ולכן $`P`$ אכן מסדר 8. ההמשך הוא $`3P = (4, 9)`$, $`4P = (0, 12) = (0, -1)`$, $`5P = (9, 9)`$. ההעתקה לצורת מונטגומרי ($`e = 1 - 2 = -1`$) נותנת את העקום $`12v^2 = u^3 + 7u^2 + u`$ מעל $`\mathbb F_{13}`$, והנקודה $`P`$ עוברת ל-$`(u, v) = (7, 10)`$; אכן $`12\cdot 100 \equiv 4`$ ו-$`7^3 + 7\cdot 7^2 + 7 = 693 \equiv 4 \pmod{13}`$.

## קואורדינטות אדוארדס הפוכות

ברנשטיין ולנגה הציגו מערכת קואורדינטות מהירה עוד יותר לעקומים אליפטיים, **קואורדינטות אדוארדס הפוכות**, שבהן הקואורדינטות $`(X : Y : Z)`$ מקיימות



```math
(X^2 + Y^2)Z^2 = dZ^4 + X^2Y^2,
```

 ומתאימות לנקודה האפינית $`(Z/X, Z/Y)`$ על עקום האדוארדס $`x^2 + y^2 = 1 + dx^2y^2`$, כאשר $`XYZ \ne 0`$.

בניגוד לקואורדינטות אדוארדס הסטנדרטיות, בקואורדינטות הפוכות אין נוסחאות חיבור שלמות: חלק מהנקודות, כמו האיבר הנייטרלי, דורשות טיפול נפרד. אבל לנוסחאות החיבור עדיין יש את היתרון של איחוד חזק: אפשר להשתמש בהן כמות שהן להכפלת נקודה.

## קואורדינטות מורחבות לעקומי אדוארדס

יש מערכת קואורדינטות נוספת לייצוג עקום אדוארדס, **הקואורדינטות המורחבות** שתוארו למעלה,[^9] והן מהירות אף יותר מהקואורדינטות ההפוכות. עלויות הפעולות בקואורדינטות השונות מרוכזות במאגר הנוסחאות המפורשות (Explicit-Formulas Database).
