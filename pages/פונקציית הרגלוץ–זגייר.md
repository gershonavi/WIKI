# פונקציית הרגלוץ–זגייר

ב[מתמטיקה](https://he.wikipedia.org/wiki/%D7%9E%D7%AA%D7%9E%D7%98%D7%99%D7%A7%D7%94), **פונקציית הרגלוץ–זגייר** (ב[אנגלית](https://he.wikipedia.org/wiki/%D7%90%D7%A0%D7%92%D7%9C%D7%99%D7%AA): Herglotz–Zagier function),[^1] הקרויה על שם גוסטב הרגלוץ ו[דון זגייר](https://he.wikipedia.org/wiki/%D7%93%D7%95%D7%9F_%D7%96%D7%90%D7%92%D7%99%D7%99%D7%A8),[^2] היא הפונקציה



```math
F(x)= \sum^{\infty}_{n=1} \left(\frac{\Gamma^{\prime}(nx)}{\Gamma (nx)} -\log (nx)\right) \frac{1}{n}, \qquad x > 0.
```



את הפונקציה הציג זגייר, שהשתמש בה כדי לקבל [נוסחת הגבול של קרונקר](%D7%A0%D7%95%D7%A1%D7%97%D7%AA%20%D7%94%D7%92%D7%91%D7%95%D7%9C%20%D7%A9%D7%9C%20%D7%A7%D7%A8%D7%95%D7%A0%D7%A7%D7%A8.md) עבור [שדות ריבועיים ממשיים](https://he.wikipedia.org/wiki/%D7%A9%D7%93%D7%94_%D7%A8%D7%99%D7%91%D7%95%D7%A2%D7%99).[^3]

## התכנסות (נוסף בתרגום)

הביטוי $`\Gamma'/\Gamma = \psi`$ הוא [פונקציית הדיגמא](https://he.wikipedia.org/wiki/%D7%A4%D7%95%D7%A0%D7%A7%D7%A6%D7%99%D7%99%D7%AA_%D7%93%D7%99%D7%92%D7%9E%D7%90). לפי נוסחת סטירלינג, $`\psi(t) = \log t - \frac{1}{2t} + O(t^{-2})`$ כאשר $`t \to \infty`$. לכן האיבר ה-$`n`$-י בטור מתנהג כמו



```math
\frac{1}{n}\Big(-\frac{1}{2nx}\Big) = -\frac{1}{2xn^2},
```

 והטור מתכנס בהחלט לכל $`x > 0`$. כל איברי הטור שליליים (כי $`\psi(t) \lt \log t`$ לכל $`t > 0`$), ולכן $`F(x) \lt 0`$.

## זהויות (נוסף בתרגום)

הזהויות הבאות נבדקו מספרית בדיוק גבוה:

- הערך ב-1:



```math
F(1) = \sum_{n=1}^\infty \frac{\psi(n) - \log n}{n} = -\frac{\gamma^2}{2} - \frac{\pi^2}{12} - \gamma_1 \approx -0.91624015,
```



  
כאשר $`\gamma`$ הוא [קבוע אוילר-מסקרוני](https://he.wikipedia.org/wiki/%D7%A7%D7%91%D7%95%D7%A2_%D7%90%D7%95%D7%99%D7%9C%D7%A8-%D7%9E%D7%A1%D7%A7%D7%A8%D7%95%D7%A0%D7%99) ו-$`\gamma_1`$ הוא [קבוע סטילטיס](%D7%A7%D7%91%D7%95%D7%A2%D7%99%20%D7%A1%D7%98%D7%99%D7%9C%D7%98%D7%99%D7%A1.md) הראשון.

- יחס ההדדיות $`x \leftrightarrow 1/x`$:



```math
F(x) + F\!\left(\frac1x\right) = 2F(1) + \frac12\log^2 x - \frac{\pi^2}{6}\left(x + \frac1x - 2\right).
```



  
למשל עבור $`x = 2`$ אגף ימין פחות $`2F(1) + \tfrac12\log^2 2`$ שווה ל-$`-\tfrac{\pi^2}{6}\cdot\tfrac12 \approx -0.8224670`$.

שתי הזהויות נבדקו עבור $`x = 2, 3, 0.7, 5`$ בדיוק של כ-20 ספרות.
