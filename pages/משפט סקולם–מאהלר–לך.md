# משפט סקולם–מאהלר–לך

ב[תורת המספרים האלגברית](https://he.wikipedia.org/wiki/%D7%AA%D7%95%D7%A8%D7%AA_%D7%94%D7%9E%D7%A1%D7%A4%D7%A8%D7%99%D7%9D_%D7%94%D7%90%D7%9C%D7%92%D7%91%D7%A8%D7%99%D7%AA), **משפט סקולם–מאהלר–לך** קובע שאם סדרת מספרים מקיימת [נוסחת נסיגה לינארית](https://he.wikipedia.org/wiki/%D7%A0%D7%95%D7%A1%D7%97%D7%AA_%D7%A0%D7%A1%D7%99%D7%92%D7%94) עם מקדמים קבועים, אז – פרט למספר סופי של יוצאי דופן – המקומות שבהם הסדרה מתאפסת יוצרים תבנית שחוזרת באופן קבוע. המשפט קרוי על שם [תורלף סקולם](https://he.wikipedia.org/wiki/%D7%AA%D7%95%D7%A8%D7%9C%D7%A3_%D7%A1%D7%A7%D7%95%D7%9C%D7%9D) (שהוכיח אותו לסדרות של [מספרים רציונליים](https://he.wikipedia.org/wiki/%D7%9E%D7%A1%D7%A4%D7%A8_%D7%A8%D7%A6%D7%99%D7%95%D7%A0%D7%9C%D7%99)),[^1] קורט מאהלר (שהוכיח אותו לסדרות של [מספרים אלגבריים](https://he.wikipedia.org/wiki/%D7%9E%D7%A1%D7%A4%D7%A8_%D7%90%D7%9C%D7%92%D7%91%D7%A8%D7%99))[^2] וכריסטר לך (שהוכיח אותו לסדרות עם ערכים בכל [שדה ממאפיין אפס](https://he.wikipedia.org/wiki/%D7%9E%D7%90%D7%A4%D7%99%D7%99%D7%9F_%28%D7%90%D7%9C%D7%92%D7%91%D7%A8%D7%94%29)).[^3] ההוכחות הידועות שלו משתמשות באנליזה p-אדית והן אינן קונסטרוקטיביות.

## ניסוח המשפט

יהי $`K`$ שדה ממאפיין אפס, למשל שדה ה[מספרים המרוכבים](https://he.wikipedia.org/wiki/%D7%9E%D7%A1%D7%A4%D7%A8_%D7%9E%D7%A8%D7%95%D7%9B%D7%91) $`\mathbb C`$. תהי $`(u_n)`$ סדרה עם ערכים ב-$`K`$ שמקיימת נוסחת נסיגה מהצורה



```math
u_{n+d} = c_{d-1}u_{n+d-1} + \cdots + c_0u_n,
```

 עם $`c_0, \dots, c_{d-1} \in K`$. אז קבוצת האפסים $`\{n \in \mathbb N : u_n = 0\}`$ היא איחוד של מספר סופי של [סדרות חשבוניות](https://he.wikipedia.org/wiki/%D7%A1%D7%93%D7%A8%D7%94_%D7%97%D7%A9%D7%91%D7%95%D7%A0%D7%99%D7%AA) וקבוצה סופית.

אם $`c_0 \ne 0`$ (מה שמוציא סדרות כמו $`1, 0, 0, 0, \dots`$), אז קבוצת האפסים היא למעשה איחוד של קבוצה סופית ומספר סופי של סדרות חשבוניות **מלאות**, כאשר סדרה חשבונית אינסופית נקראת מלאה אם יש שלמים $`a, b`$ כך שהיא מורכבת מכל השלמים החיוביים ששקולים ל-$`b`$ מודולו $`a`$.

**רעיון ההוכחה.** בוחרים ראשוני $`p`$ מתאים כך שכל הנתונים (המקדמים, ערכי ההתחלה ושורשי הפולינום האופייני) הם שלמים p-אדיים והפולינום האופייני "טוב" מודולו $`p`$. אז יש $`M \ge 1`$ כך שלכל $`r = 0, 1, \dots, M-1`$, הפונקציה $`k \mapsto u_{r + Mk}`$ מתרחבת לפונקציה **אנליטית p-אדית** $`f_r(z)`$ על $`\mathbb Z_p`$ (טור חזקות מתכנס). לפונקציה אנליטית p-אדית שאינה זהותית אפס יש רק מספר סופי של אפסים בכדור $`\mathbb Z_p`$ (משפט שטרסמן). לכן לכל $`r`$: או ש-$`f_r \equiv 0`$ – ואז כל הסדרה החשבונית $`r + M\mathbb N`$ מורכבת מאפסים – או שיש ל-$`f_r`$ רק מספר סופי של אפסים. זה בדיוק המבנה שהמשפט מתאר. ההוכחה אינה נותנת חסם על האפסים ה"בודדים".

## דוגמאות

**דוגמה 1.** נתבונן בסדרה



```math
0, 0, 1, 0, 1, 0, 2, 0, 3, 0, 5, 0, 8, 0, \dots
```

 שמחליפה לסירוגין בין אפסים ל[מספרי פיבונאצ'י](https://he.wikipedia.org/wiki/%D7%A1%D7%93%D7%A8%D7%AA_%D7%A4%D7%99%D7%91%D7%95%D7%A0%D7%90%D7%A6%27%D7%99). אפשר לקבל אותה מנוסחת הנסיגה



```math
F(i) = F(i-2) + F(i-4)
```

 (גרסה של נוסחת הנסיגה של פיבונאצ'י), עם תנאי ההתחלה $`F(1) = F(2) = F(4) = 0`$ ו-$`F(3) = 1`$. בסדרה הזו $`F(i) = 0`$ אם ורק אם $`i = 1`$ או $`i`$ זוגי. לכן קבוצת האפסים מתפרקת לקבוצה סופית (הקבוצה $`\{1\}`$) ולסדרה חשבונית מלאה אחת (המספרים הזוגיים החיוביים). כאן $`c_0 = 1 \ne 0`$.

בדוגמה הזו הספיקה סדרה חשבונית אחת, אבל בסדרות נסיגה אחרות האפסים יכולים להופיע במקומות שיוצרים כמה סדרות חשבוניות.

**דוגמה 2 (אפסים "בודדים").** הסדרה של ברסטל,



```math
u_{n+3} = 2u_{n+2} - 4u_{n+1} + 4u_n, \qquad u_0 = u_1 = 0,\ u_2 = 1,
```

 מתחילה ב-$`0, 0, 1, 2, 0, -4, 0, 16, 16, \dots`$, ומתאפסת בדיוק ב-



```math
n = 0,\ 1,\ 4,\ 6,\ 13,\ 52.
```

 (חישוב ממוחשב עד $`n = 5000`$ לא מצא אפסים נוספים, וידוע שאלה כל האפסים.) כאן אין אף סדרה חשבונית אינסופית של אפסים – כל קבוצת האפסים היא "הקבוצה הסופית" שבמשפט – ובכל זאת האפס האחרון מופיע רק ב-$`n = 52`$. הדוגמה ממחישה למה קשה לקבוע מתי "נגמרו" האפסים.

## תוצאות קשורות

**בעיית סקולם** היא הבעיה להכריע אם לסדרת נסיגה נתונה יש אפס. יש אלגוריתם שבודק אם יש אינסוף אפסים,[^4] ואם כן מוצא את הפירוק שלהם לקבוצות מחזוריות, שקיומו מובטח ממשפט סקולם–מאהלר–לך. אבל לא ידוע אם יש אלגוריתם שמכריע אם לסדרת נסיגה יש אפסים לא מחזוריים כלשהם.[^5]
