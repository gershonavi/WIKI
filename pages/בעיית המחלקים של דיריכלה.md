# בעיית המחלקים של דיריכלה

<img src="https://commons.wikimedia.org/wiki/Special:FilePath/Divisor-summatory-big.svg" alt="אותה פונקציה עבור <math>x < 10^7</math>" width="320">

ב[תורת המספרים](https://he.wikipedia.org/wiki/%D7%AA%D7%95%D7%A8%D7%AA_%D7%94%D7%9E%D7%A1%D7%A4%D7%A8%D7%99%D7%9D), **בעיית המחלקים של דיריכלה** עוסקת בהתנהגות האסימפטוטית של **הפונקציה הסכומית של פונקציית המחלקים**, כלומר הסכום של ערכי [פונקציית המחלקים](https://he.wikipedia.org/wiki/%D7%A4%D7%95%D7%A0%D7%A7%D7%A6%D7%99%D7%99%D7%AA_%D7%9E%D7%97%D7%9C%D7%A7%D7%99%D7%9D). הפונקציה מופיעה לעיתים קרובות בחקר ההתנהגות האסימפטוטית של [פונקציית זטא של רימן](https://he.wikipedia.org/wiki/%D7%A4%D7%95%D7%A0%D7%A7%D7%A6%D7%99%D7%99%D7%AA_%D7%96%D7%98%D7%90_%D7%A9%D7%9C_%D7%A8%D7%99%D7%9E%D7%9F), והשאלות השונות על התנהגותה מכונות "בעיות מחלקים".

## הגדרה

הפונקציה הסכומית של פונקציית המחלקים מוגדרת על ידי



```math
D(x)=\sum_{n\le x} d(n) = \sum_{j,k \atop jk\le x} 1,
```

 כאשר



```math
d(n)=\sigma_0(n) = \sum_{j,k \atop jk=n} 1
```

 היא פונקציית המחלקים, הסופרת בכמה דרכים אפשר לכתוב את השלם $`n`$ כמכפלה של שני שלמים. באופן כללי יותר מגדירים



```math
D_k(x)=\sum_{n\le x} d_k(n)= \sum_{m\le x}\sum_{mn\le x} d_{k-1}(n),
```

 כאשר $`d_k(n)`$ סופרת בכמה דרכים אפשר לכתוב את $`n`$ כמכפלה של $`k`$ מספרים. אפשר לראות בגודל זה את מספר נקודות הסריג התחומות על ידי משטח היפרבולי ב-$`k`$ ממדים. כך, עבור $`k=2`$, הפונקציה $`D(x) = D_2(x)`$ סופרת את נקודות הסריג הריבועי התחומות משמאל על ידי הציר האנכי, מלמטה על ידי הציר האופקי, ומימין למעלה על ידי ה[היפרבולה](https://he.wikipedia.org/wiki/%D7%94%D7%99%D7%A4%D7%A8%D7%91%D7%95%D7%9C%D7%94) $`jk = x`$. בקירוב אפשר לחשוב על הצורה הזו כעל [סימפלקס](https://he.wikipedia.org/wiki/%D7%A1%D7%99%D7%9E%D7%A4%D7%9C%D7%A7%D7%A1) היפרבולי. מכאן מתקבל ביטוי חלופי ל-$`D(x)`$, ודרך פשוטה לחשב אותה בזמן $`O(\sqrt{x})`$:



```math
D(x)=\sum_{k=1}^x \left\lfloor\frac{x}{k}\right\rfloor = 2 \sum_{k=1}^u \left\lfloor\frac{x}{k}\right\rfloor - u^2, \qquad u = \left\lfloor \sqrt{x}\right\rfloor.
```



אם מחליפים את ההיפרבולה במעגל, השאלה המתקבלת היא [בעיית המעגל של גאוס](https://he.wikipedia.org/wiki/%D7%91%D7%A2%D7%99%D7%99%D7%AA_%D7%94%D7%9E%D7%A2%D7%92%D7%9C_%D7%A9%D7%9C_%D7%92%D7%90%D7%95%D7%A1).

ערכי $`D(n)`$ הראשונים (סדרה [A006218](https://oeis.org/A006218) ב-[OEIS](https://he.wikipedia.org/wiki/%D7%94%D7%90%D7%A0%D7%A6%D7%99%D7%A7%D7%9C%D7%95%D7%A4%D7%93%D7%99%D7%94_%D7%94%D7%9E%D7%A7%D7%95%D7%95%D7%A0%D7%AA_%D7%9C%D7%A1%D7%93%D7%A8%D7%95%D7%AA_%D7%A9%D7%9C_%D7%9E%D7%A1%D7%A4%D7%A8%D7%99%D7%9D_%D7%A9%D7%9C%D7%9E%D7%99%D7%9D)):

  
0, 1, 3, 5, 8, 10, 14, 16, 20, 23, 27, 29, 35, 37, 41, 45, 50, 52, 58, 60, 66, 70, 74, 76, 84, 87, 91, 95, 101, 103, 111, ...

## בעיית המחלקים של דיריכלה

נראה שמציאת ביטוי סגור לסכום הזה חורגת מהשיטות הידועות, אך אפשר לתת קירובים. ההתנהגות המובילה היא



```math
D(x) = x\log x + x(2\gamma-1) + \Delta(x),
```

 כאשר $`\gamma`$ הוא [קבוע אוילר-מסקרוני](https://he.wikipedia.org/wiki/%D7%A7%D7%91%D7%95%D7%A2_%D7%90%D7%95%D7%99%D7%9C%D7%A8-%D7%9E%D7%A1%D7%A7%D7%A8%D7%95%D7%A0%D7%99), ואיבר השגיאה מקיים



```math
\Delta(x) = O\left(\sqrt{x}\right)
```

 (ב[סימון O גדולה](https://he.wikipedia.org/wiki/%D7%A1%D7%99%D7%9E%D7%95%D7%9F_%D7%90%D7%A1%D7%99%D7%9E%D7%A4%D7%98%D7%95%D7%98%D7%99)). את ההערכה הזו אפשר להוכיח בעזרת שיטת ההיפרבולה של דיריכלה, ו[דיריכלה](https://he.wikipedia.org/wiki/%D7%99%D7%95%D7%94%D7%90%D7%9F_%D7%A4%D7%98%D7%A8_%D7%92%D7%95%D7%A1%D7%98%D7%91_%D7%9C%D7%96%27%D7%9F_%D7%93%D7%99%D7%A8%D7%99%D7%9B%D7%9C%D7%94) היה הראשון שהוכיח אותה, בשנת 1849.[^1] **בעיית המחלקים של דיריכלה**, בניסוח מדויק, היא לשפר את חסם השגיאה ולמצוא את הערך הקטן ביותר של $`\theta`$ שעבורו



```math
\Delta(x) = O\left(x^{\theta+\epsilon}\right)
```

 לכל $`\epsilon > 0`$. הבעיה עודנה פתוחה, וההתקדמות בה איטית. רבות מהשיטות פועלות הן בבעיה זו והן בבעיית המעגל של גאוס, שאף היא בעיה של ספירת נקודות סריג. סקירה של הידוע והלא ידוע על הבעיות האלה מופיעה בסעיף F1 בספרו של ריצ'רד גיא על בעיות פתוחות בתורת המספרים.[^2]

ציוני הדרך בחקר הבעיה:

- ב-1904 הוכיח גאורגי וורונוי שאפשר לשפר את איבר השגיאה ל-$`O(x^{1/3}\log x)`$.[^3]
- ב-1916 הראה [גודפרי הרולד הארדי](https://he.wikipedia.org/wiki/%D7%92%D7%95%D7%93%D7%A4%D7%A8%D7%99_%D7%94%D7%A8%D7%95%D7%9C%D7%93_%D7%94%D7%90%D7%A8%D7%93%D7%99) ש-$`\inf \theta \ge 1/4`$. בפרט הוא הראה שעבור קבוע כלשהו $`K`$ יש ערכי $`x`$ גדולים כרצוננו שעבורם $`\Delta(x) > Kx^{1/4}`$, וערכי $`x`$ גדולים כרצוננו שעבורם $`\Delta(x) < -Kx^{1/4}`$.[^4]
- ב-1922 שיפר יוהנס ואן דר קורפוט את החסם של דיריכלה ל-$`\inf \theta \le 33/100 = 0.33`$.[^5]
- ב-1928 הוכיח ואן דר קורפוט ש-$`\inf \theta \le 27/82 = 0.3\overline{29268}`$.[^6]
- ב-1950 הוכיח צ'י טסונג-טאו, וב-1953 הוכיח באופן בלתי תלוי הנס-אגון ריכרט, ש-$`\inf \theta \le 15/46 = 0.32608695652\ldots`$.[^7]
- ב-1969 הראה גריגורי קולסניק ש-$`\inf \theta \le 12/37 = 0.\overline{324}`$.[^8]
- ב-1973 הראה קולסניק ש-$`\inf \theta \le 346/1067 = 0.32427366448\ldots`$.[^9]
- ב-1982 הראה קולסניק ש-$`\inf \theta \le 35/108 = 0.32\overline{407}`$.[^10]
- ב-1988 הוכיחו הנריק איוונייץ וצ'רלס מוצוקי ש-$`\inf \theta \leq 7/22 = 0.3\overline{18}`$.[^11]
- ב-2003 שיפר מרטין הקסלי את התוצאה ל-$`\inf \theta \leq 131/416 = 0.31490384615\ldots`$.[^12]

לפיכך $`\inf \theta`$ נמצא בין 1/4 ל-131/416 (בערך 0.3149), וההשערה הרווחת היא שהוא שווה ל-1/4. ראיות תאורטיות תומכות בהשערה, שכן ל-$`\Delta(x)/x^{1/4}`$ יש התפלגות גבולית (שאינה גאוסית).[^13] הערך 1/4 היה נובע גם מהשערה על זוגות מעריכים.[^14]

## בעיית המחלקים של פילץ

במקרה המוכלל מתקיים



```math
D_k(x) = xP_k(\log x)+\Delta_k(x),
```

 כאשר $`P_k`$ הוא פולינום [ממעלה](https://he.wikipedia.org/wiki/%D7%9E%D7%A2%D7%9C%D7%94_%D7%A9%D7%9C_%D7%A4%D7%95%D7%9C%D7%99%D7%A0%D7%95%D7%9D) $`k-1`$. בהערכות פשוטות מראים ש



```math
\Delta_k(x)=O\left(x^{1-1/k} \log^{k-2} x\right)
```

 לכל שלם $`k\ge 2`$. כמו במקרה $`k=2`$, ה[אינפימום](https://he.wikipedia.org/wiki/%D7%90%D7%99%D7%A0%D7%A4%D7%99%D7%9E%D7%95%D7%9D_%D7%95%D7%A1%D7%95%D7%A4%D7%A8%D7%9E%D7%95%D7%9D) של החסם אינו ידוע לאף ערך של $`k`$. חישוב האינפימומים האלה ידוע בשם **בעיית המחלקים של פילץ**, על שמו של המתמטיקאי הגרמני אדולף פילץ. אם מגדירים את $`\alpha_k`$ כערך הקטן ביותר שעבורו $`\Delta_k(x)=O\left(x^{\alpha_k+\varepsilon}\right)`$ לכל $`\varepsilon>0`$, ידועות התוצאות הבאות (כאשר $`\alpha_2`$ הוא ה-$`\theta`$ מהפרק הקודם):



```math
\alpha_2\le\frac{131}{416},
```

[^15]



```math
\alpha_3 \le\frac{43}{96},
```

[^16] וכן[^17]



```math
\begin{align}
\alpha_k & \le \frac{3k-4}{4k}\quad(4\le k\le 8) \\[6pt]
\alpha_9 & \le\frac{35}{54}\ ,\quad \alpha_{10}\le\frac{41}{60}\ ,\quad \alpha_{11}\le\frac{7}{10} \\[6pt]
\alpha_k & \le \frac{k-2}{k+2}\quad(12\le k\le 25) \\[6pt]
\alpha_k & \le \frac{k-1}{k+4}\quad(26\le k\le 50) \\[6pt]
\alpha_k & \le \frac{31k-98}{32k}\quad(51\le k\le 57) \\[6pt]
\alpha_k & \le \frac{7k-34}{7k}\quad(k\ge 58)
\end{align}
```



אדוארד צ'רלס טיצ'מרש שיער ש-$`\alpha_k =\frac{k-1}{2k}`$.

## ייצוג באמצעות התמרת מלין

את שני החלקים אפשר לבטא כ[התמרות מלין](https://he.wikipedia.org/wiki/%D7%94%D7%AA%D7%9E%D7%A8%D7%AA_%D7%9E%D7%9C%D7%99%D7%9F.md):



```math
D(x)=\frac{1}{2\pi i} \int_{c-i\infty}^{c+i\infty} \zeta^2(w) \frac {x^w}{w}\, dw
```

 עבור $`c>1`$, כאשר $`\zeta(s)`$ היא פונקציית זטא של רימן. באופן דומה,



```math
\Delta(x)=\frac{1}{2\pi i} \int_{c^\prime-i\infty}^{c^\prime+i\infty} \zeta^2(w) \frac {x^w}{w} \,dw
```

 עבור $`0<c^\prime<1`$. האיבר המוביל של $`D(x)`$ מתקבל מהזזת מסלול האינטגרציה אל מעבר לקוטב הכפול ב-$`w=1`$: האיבר המוביל הוא ה[שארית](https://he.wikipedia.org/wiki/%D7%A9%D7%90%D7%A8%D7%99%D7%AA_%28%D7%90%D7%A0%D7%9C%D7%99%D7%96%D7%94_%D7%9E%D7%A8%D7%95%D7%9B%D7%91%D7%AA%29), לפי [נוסחת האינטגרל של קושי](https://he.wikipedia.org/wiki/%D7%A0%D7%95%D7%A1%D7%97%D7%AA_%D7%94%D7%90%D7%99%D7%A0%D7%98%D7%92%D7%A8%D7%9C_%D7%A9%D7%9C_%D7%A7%D7%95%D7%A9%D7%99). באופן כללי,



```math
D_k(x)=\frac{1}{2\pi i} \int_{c-i\infty}^{c+i\infty} \zeta^k(w) \frac {x^w}{w} \,dw,
```

 וכך גם עבור $`\Delta_k(x)`$, לכל $`k\ge 2`$.
