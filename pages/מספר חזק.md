# מספר חזק

**מספר חזק** (באנגלית: powerful number) הוא [מספר שלם חיובי](https://he.wikipedia.org/wiki/%D7%9E%D7%A1%D7%A4%D7%A8_%D7%98%D7%91%D7%A2%D7%99) $`m`$ כך שלכל [ראשוני](https://he.wikipedia.org/wiki/%D7%9E%D7%A1%D7%A4%D7%A8_%D7%A8%D7%90%D7%A9%D7%95%D7%A0%D7%99) $`p`$ שמחלק את $`m`$, גם $`p^2`$ מחלק את $`m`$. באופן שקול, מספר חזק הוא מכפלה של [ריבוע](https://he.wikipedia.org/wiki/%D7%9E%D7%A1%D7%A4%D7%A8_%D7%A8%D7%99%D7%91%D7%95%D7%A2%D7%99) ו[קובייה](https://he.wikipedia.org/wiki/%D7%97%D7%96%D7%A7%D7%94_%D7%A9%D7%9C%D7%99%D7%A9%D7%99%D7%AA), כלומר מספר מהצורה $`m = a^2b^3`$, כאשר $`a`$ ו-$`b`$ שלמים חיוביים. [פול ארדש](https://he.wikipedia.org/wiki/%D7%A4%D7%95%D7%9C_%D7%90%D7%A8%D7%93%D7%A9) ו[ג'ורג' סקרש](https://he.wikipedia.org/wiki/%D7%92%27%D7%95%D7%A8%D7%92%27_%D7%A1%D7%A7%D7%A8%D7%A9) חקרו מספרים כאלה, ו[סולומון גולומב](https://he.wikipedia.org/wiki/%D7%A1%D7%95%D7%9C%D7%95%D7%9E%D7%95%D7%9F_%D7%92%D7%95%D7%9C%D7%95%D7%9E%D7%91) נתן להם את השם "חזקים". הם נקראים גם **מלאי-ריבוע** (squarefull), או **2-מלאים**.[^1] (אין לבלבל עם המונח squareful, שמציין מספרים שאינם [חופשיים מריבועים](https://he.wikipedia.org/wiki/%D7%9E%D7%A1%D7%A4%D7%A8_%D7%97%D7%95%D7%A4%D7%A9%D7%99_%D7%9E%D7%A8%D7%99%D7%91%D7%95%D7%A2%D7%99%D7%9D).)

למשל,



```math
144000 = 2^7\times 3^2\times 5^3 = 2^3\times 2^4\times 3^2 \times 5^3 = (2\times5)^3 \times (2^2\times 3)^2 = 10^3\times12^2
```

 הוא מספר חזק: כל מעריך בפירוק לגורמים ראשוניים שלו גדול מ-1, והוא מכפלה של ריבוע וקובייה.

רשימת כל המספרים החזקים בין 1 ל-1000:

  
1, 4, 8, 9, 16, 25, 27, 32, 36, 49, 64, 72, 81, 100, 108, 121, 125, 128, 144, 169, 196, 200, 216, 225, 243, 256, 288, 289, 324, 343, 361, 392, 400, 432, 441, 484, 500, 512, 529, 576, 625, 648, 675, 676, 729, 784, 800, 841, 864, 900, 961, 968, 972, 1000 ((סדרה [A001694](https://oeis.org/A001694) ב-OEIS); את הרשימה בדקנו בחישוב).

## שקילות שתי ההגדרות

אם $`m = a^2b^3`$, אז כל ראשוני בפירוק של $`a`$ מופיע בפירוק של $`m`$ עם מעריך לפחות 2, וכל ראשוני בפירוק של $`b`$ מופיע בפירוק של $`m`$ עם מעריך לפחות 3; לכן $`m`$ חזק.

בכיוון השני, נניח ש-$`m`$ חזק, עם הפירוק לגורמים ראשוניים



```math
m = \prod p_i^{\alpha_i},
```

 כאשר כל $`\alpha_i \ge 2`$. נגדיר $`\gamma_i = 3`$ אם $`\alpha_i`$ אי-זוגי, ו-$`\gamma_i = 0`$ אחרת, ו-$`\beta_i = \alpha_i - \gamma_i`$. אז כל $`\beta_i`$ הם שלמים זוגיים אי-שליליים (כאן משתמשים בכך ש-$`\alpha_i \ge 3`$ כש-$`\alpha_i`$ אי-זוגי), וכל $`\gamma_i`$ הם 0 או 3, ולכן



```math
m = \left(\prod p_i^{\beta_i}\right)\left(\prod p_i^{\gamma_i}\right) = \left(\prod p_i^{\beta_i/2} \right)^2 \left( \prod p_i^{\gamma_i/3}\right)^3
```

 נותן את ההצגה הרצויה של $`m`$ כמכפלה של ריבוע וקובייה.

באופן לא פורמלי: בהינתן הפירוק של $`m`$, ניקח את $`b`$ להיות מכפלת הגורמים הראשוניים של $`m`$ שהמעריך שלהם אי-זוגי (ואם אין כאלה, $`b = 1`$). כיוון ש-$`m`$ חזק, כל גורם כזה מופיע עם מעריך לפחות 3, ולכן $`m/b^3`$ שלם. כל גורם ראשוני של $`m/b^3`$ מופיע עם מעריך זוגי, ולכן $`m/b^3`$ הוא ריבוע, נאמר $`a^2`$; ואז $`m = a^2b^3`$. למשל:



```math
m = 21600 = 2^5 \times 3^3 \times 5^2,\quad b = 2 \times 3 = 6,\quad a = \sqrt{\frac{m}{b^3} } = \sqrt{2^2 \times 5^2} = 10,\quad m = a^2b^3 = 10^2 \times 6^3.
```

 להצגה $`m = a^2b^3`$ שמתקבלת כך יש התכונה ש-$`b`$ [חופשי מריבועים](https://he.wikipedia.org/wiki/%D7%9E%D7%A1%D7%A4%D7%A8_%D7%97%D7%95%D7%A4%D7%A9%D7%99_%D7%9E%D7%A8%D7%99%D7%91%D7%95%D7%A2%D7%99%D7%9D), והיא נקבעת ביחידות על ידי התכונה הזו.

## תכונות מתמטיות

### סכום ההופכיים

סכום ההופכיים של המספרים החזקים מתכנס. את ערכו אפשר לכתוב בכמה דרכים, למשל כמכפלה אינסופית:



```math
\prod_p\left(1+\frac{1}{p(p-1)}\right)=\frac{\zeta(2)\zeta(3)}{\zeta(6)} = \frac{315}{2\pi^4}\zeta(3)=1.9435964368\ldots,
```

 כאשר $`p`$ רץ על הראשוניים, $`\zeta`$ היא [פונקציית זטא של רימן](https://he.wikipedia.org/wiki/%D7%A4%D7%95%D7%A0%D7%A7%D7%A6%D7%99%D7%99%D7%AA_%D7%96%D7%98%D7%90_%D7%A9%D7%9C_%D7%A8%D7%99%D7%9E%D7%9F), ו-$`\zeta(3)`$ הוא [קבוע אפרי](https://he.wikipedia.org/wiki/%D7%A7%D7%91%D7%95%D7%A2_%D7%90%D7%A4%D7%A8%D7%99) ((סדרה [A082695](https://oeis.org/A082695) ב-OEIS)).[^2]

*מאיפה המכפלה:* המספרים החזקים הם בדיוק המכפלות של חזקות ראשוניות $`p^e`$ עם $`e \ne 1`$. לכן, לפי [פירוק אוילרי](https://he.wikipedia.org/wiki/%D7%9E%D7%9B%D7%A4%D7%9C%D7%AA_%D7%90%D7%95%D7%99%D7%9C%D7%A8), סכום ההופכיים הוא $`\prod_p\left(1 + \frac1{p^2} + \frac1{p^3} + \cdots\right) = \prod_p\left(1 + \frac{1}{p^2(1 - 1/p)}\right) = \prod_p\left(1 + \frac1{p(p-1)}\right)`$. ובכלל, סכום ההופכיים של החזקות ה-$`s`$ של המספרים החזקים (ה[טור דיריכלה](https://he.wikipedia.org/wiki/%D7%98%D7%95%D7%A8_%D7%93%D7%99%D7%A8%D7%99%D7%9B%D7%9C%D7%94) היוצר שלהם) הוא



```math
\frac{\zeta(2s)\zeta(3s)}{\zeta(6s)}
```

 בכל מקום שבו הוא מתכנס. (בדקנו מספרית את שלושת הביטויים לערך הסכום עבור $`s = 1`$.)

### ספירה

יהי $`k(x)`$ מספר המספרים החזקים בקטע $`[1, x]`$. אז $`k(x)`$ פרופורציוני ל[שורש הריבועי](https://he.wikipedia.org/wiki/%D7%A9%D7%95%D7%A8%D7%A9_%D7%A8%D7%99%D7%91%D7%95%D7%A2%D7%99) של $`x`$. ליתר דיוק,[^3]



```math
cx^{1/2}-3x^{1/3}\le k(x) \le cx^{1/2},\quad c = \zeta(3/2)/\zeta(3) = 2.173\ldots
```

 הסיבה: כל מספר חזק נכתב באופן יחיד כ-$`a^2b^3`$ עם $`b`$ חופשי מריבועים, ולכן $`k(x) = \sum_{b\text{ חופשי מריבועים} } \left\lfloor\sqrt{x/b^3}\right\rfloor`$, ו-$`\sum_b \mu^2(b) b^{-3/2} = \zeta(3/2)/\zeta(3)`$. בחישוב לפי הנוסחה הזו:

| $`x`$       | $`k(x)`$  | $`cx^{1/2} - 3x^{1/3}`$ | $`cx^{1/2}`$ |
|-----------|---------|-----------------------|------------|
| $`10^4`$    | 185     | 152.7                 | 217.3      |
| $`10^6`$    | 2027    | 1873.3                | 2173.3     |
| $`10^8`$    | 21044   | 20340.1               | 21732.5    |
| $`10^{10}`$ | 214122  | 210862.1              | 217325.4   |
| $`10^{12}`$ | 2158391 | 2143254.3             | 2173254.3  |

(הפער מ-$`cx^{1/2}`$ הוא בערך (כפי שרואים בטבלה) $`c' x^{1/3}`$ עם $`c' = \zeta(2/3)/\zeta(2) \approx -1.48`$, שמתאים ל"תרומת הקוביות".)

### מספרים חזקים עוקבים

שני המספרים החזקים העוקבים הקטנים ביותר הם 8 ו-9. כיוון של[משוואת פל](https://he.wikipedia.org/wiki/%D7%9E%D7%A9%D7%95%D7%95%D7%90%D7%AA_%D7%A4%D7%9C) $`x^2-8y^2=1`$ יש אינסוף פתרונות שלמים, יש אינסוף זוגות של מספרים חזקים עוקבים ($`x^2`$ ו-$`8y^2 = x^2 - 1`$, שהוא תמיד חזק, כי $`8 = 2^3`$ ולכן החזקה של 2 בו היא לפחות 3).[^4] למשל $`(x, y) = (3, 1)`$ נותן $`(8, 9)`$, ו-$`(17, 6)`$ נותן $`(288, 289) = (2^5\cdot3^2,\ 17^2)`$. באופן כללי יותר, אפשר למצוא מספרים חזקים עוקבים בפתרון משוואת פל דומה $`x^2-ny^2=\pm 1`$ לכל [קובייה מושלמת](https://he.wikipedia.org/wiki/%D7%9E%D7%A1%D7%A4%D7%A8_%D7%A7%D7%95%D7%91%D7%99) $`n`$. אבל באחד משני המספרים בזוג שמתקבל כך הוא תמיד ריבוע.

הזוגות של מספרים חזקים עוקבים מתחת ל-$`2\cdot10^5`$ הם (חיפוש שלנו):



```math
(8, 9),\ (288, 289),\ (675, 676),\ (9800, 9801),\ (12167, 12168).
```

 לפי גיא, ארדש שאל אם יש אינסוף זוגות של מספרים חזקים עוקבים כמו $`(23^3,\ 2^3 3^2 13^2) = (12167, 12168)`$, שבהם אף אחד מהשניים אינו ריבוע. ווקר (1976) הראה שיש אכן אינסוף זוגות כאלה, כשהראה של-$`3^3 c^2 + 1 = 7^3 d^2`$ יש אינסוף פתרונות.[^5] הפתרונות של ווקר מתקבלים, לכל שלם אי-זוגי $`k`$, מהמספר



```math
(2\sqrt{7}+3\sqrt{3})^{7k}=a\sqrt{7}+b\sqrt{3},
```

 עם $`a`$ שמתחלק ב-7 ו-$`b`$ שמתחלק ב-3, ומהם בונים את המספרים החזקים העוקבים $`7a^2`$ ו-$`3b^2`$, עם $`7a^2 = 1 + 3b^2`$. הזוג העוקב הקטן ביותר במשפחה הזו מתקבל עבור $`k = 1`$, $`a = 2637362`$ ו-$`b = 4028637`$:



```math
7\cdot 2637362^2 = 2^2\cdot 7^3\cdot 13^2\cdot 43^2\cdot 337^2=48689748233308,
```





```math
3\cdot 4028637^2 = 3^3\cdot 139^2\cdot 9661^2 = 48689748233307.
```

 (את החזקה ה-7 פיתחנו ואת שני הפירוקים בדקנו בחישוב. הסיבה שמעלים בחזקה 7: $`(2\sqrt7 + 3\sqrt3)(2\sqrt7 - 3\sqrt3) = 28 - 27 = 1`$, ולכן לכל חזקה אי-זוגית $`7a^2 - 3b^2 = 1`$; החזקה ה-7 מבטיחה ש-$`7 \mid a`$ ו-$`3 \mid b`$.)

### שלושה מספרים חזקים עוקבים

לפי [השערה](https://he.wikipedia.org/wiki/%D7%94%D7%A9%D7%A2%D7%A8%D7%95%D7%AA_%D7%90%D7%A8%D7%93%D7%A9) של ארדש, מולין וולש, אין שלושה מספרים חזקים עוקבים. אם קיימת שלשה כזו, האיבר הקטן בה חייב להיות שקול ל-7, 27 או 35 מודולו 36.[^6]

*הוכחה:* מספר חזק אינו יכול להיות $`\equiv 2 \pmod 4`$ (אז 2 היה מחלק אותו בדיוק פעם אחת), ולכן בשלשה $`n, n+1, n+2`$ חייב להיות $`n \equiv 3 \pmod 4`$ (השאריות 3, 0, 1). באותה דרך, מספר חזק אינו $`\equiv 3, 6 \pmod 9`$; שלוש שאריות עוקבות מודולו 9 שנמנעות מ-3 ו-6 הן רק $`(7, 8, 0)`$, $`(8, 0, 1)`$ ו-$`(0, 1, 2)`$, ולכן $`n \equiv 7, 8, 0 \pmod 9`$. שילוב לפי [משפט השאריות הסיני](https://he.wikipedia.org/wiki/%D7%9E%D7%A9%D7%A4%D7%98_%D7%94%D7%A9%D7%90%D7%A8%D7%99%D7%95%D7%AA_%D7%94%D7%A1%D7%99%D7%A0%D7%99) נותן $`n \equiv 7, 35, 27 \pmod{36}`$.

אם [השערת abc](https://he.wikipedia.org/wiki/%D7%94%D7%A9%D7%A2%D7%A8%D7%AA_abc) נכונה, יש רק מספר סופי של שלשות של מספרים חזקים עוקבים.

## סכומים והפרשים של מספרים חזקים

כל מספר אי-זוגי הוא הפרש של שני ריבועים עוקבים: $`(k + 1)^2 - k^2 = 2k + 1`$. באופן דומה, כל כפולה של 4 היא הפרש של ריבועי שני מספרים שההפרש ביניהם 2: $`(k + 2)^2 - k^2 = 4k + 4`$. אבל [מספר זוגי בודד](https://he.wikipedia.org/wiki/%D7%9E%D7%A1%D7%A4%D7%A8_%D7%96%D7%95%D7%92%D7%99_%D7%91%D7%95%D7%93%D7%93), כלומר מספר שמתחלק ב-2 אבל לא ב-4, אינו יכול להיות הפרש של ריבועים. זה מעורר את השאלה אילו מספרים זוגיים בודדים הם הפרשים של מספרים חזקים. גולומב הציג כמה הצגות כאלה:



```math
2 = 3^3 - 5^2,\qquad 10 = 13^3 - 3^7,\qquad 18 = 19^2 - 7^3 = 3^5 - 15^2.
```

 שיערו ש-6 אינו ניתן להצגה כזו, וגולומב שיער שיש אינסוף שלמים שאינם הפרש של שני מספרים חזקים. אבל נרקייביץ' הראה ש-6 ניתן להצגה כזו באינסוף דרכים, כמו



```math
6 = 5^4\cdot7^3 - 463^2
```

 ($`214375 - 214369`$), ומקדניאל הראה שלכל שלם יש אינסוף הצגות כאלה.[^7]

ארדש שיער שכל שלם גדול מספיק הוא סכום של לכל היותר שלושה מספרים חזקים; את זה הוכיח [רוג'ר הית'-בראון](https://he.wikipedia.org/wiki/%D7%A8%D7%95%D7%92%27%D7%A8_%D7%94%D7%99%D7%AA%27-%D7%91%D7%A8%D7%90%D7%95%D7%9F) (1987).

## הכללה

באופן כללי יותר, אפשר להתבונן בשלמים שכל הגורמים הראשוניים שלהם מופיעים עם מעריך לפחות $`k`$. שלם כזה נקרא **$`k`$-חזק** או **$`k`$-מלא**.

המספרים



```math
(2^{k+1} - 1)^k,\quad 2^k(2^{k+1} - 1)^k,\quad (2^{k+1} - 1)^{k+1}
```

 הם מספרים $`k`$-חזקים בסדרה חשבונית (למשל עבור $`k = 2`$: $`49, 196, 343`$, עם הפרש 147). יתרה מזו, אם $`a_1, a_2, \ldots, a_s`$ הם $`k`$-חזקים בסדרה חשבונית עם הפרש $`d`$, אז



```math
a_1(a_s + d)^k,\ a_2(a_s + d)^k,\ \ldots,\ a_s(a_s + d)^k,\ (a_s + d)^{k+1}
```

 הם $`s + 1`$ מספרים $`k`$-חזקים בסדרה חשבונית.

יש זהות עם מספרים $`k`$-חזקים:



```math
a^k(a^\ell + \cdots + 1)^k + a^{k + 1}(a^\ell + \cdots + 1)^k + \cdots + a^{k + \ell}(a^\ell + \cdots + 1)^k = a^k(a^\ell + \cdots +1)^{k+1}.
```

 (למשל עבור $`a = 2, \ell = 2, k = 2`$: $`4\cdot49 + 8\cdot49 + 16\cdot49 = 1372 = 4\cdot343`$.) היא נותנת אינסוף $`(\ell+1)`$-יות של מספרים $`k`$-חזקים שגם סכומן $`k`$-חזק. ניטאז' הראה שיש אינסוף פתרונות ל-$`x + y = z`$ במספרים 3-חזקים זרים בזוגות.[^8] כהן בנה משפחה אינסופית של פתרונות ל-$`x + y = z`$ במספרים 3-חזקים זרים שאינם קוביות, כך: השלשה



```math
X = 9712247684771506604963490444281,\ Y = 32295800804958334401937923416351,\ Z = 27474621855216870941749052236511
```

 היא פתרון של המשוואה $`32X^3 + 49Y^3 = 81Z^3`$ (בדקנו בחישוב). אפשר לבנות פתרון נוסף כשמגדירים $`X' = X(49Y^3 + 81Z^3)`$, $`Y' = -Y(32X^3 + 81Z^3)`$, $`Z' = Z(32X^3 - 49Y^3)`$ ומשמיטים את המחלק המשותף.[^9]
