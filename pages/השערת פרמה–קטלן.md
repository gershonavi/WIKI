# השערת פרמה–קטלן

ב[תורת המספרים](https://he.wikipedia.org/wiki/%D7%AA%D7%95%D7%A8%D7%AA_%D7%94%D7%9E%D7%A1%D7%A4%D7%A8%D7%99%D7%9D), **השערת פרמה–קטלן** היא הכללה של [המשפט האחרון של פרמה](https://he.wikipedia.org/wiki/%D7%94%D7%9E%D7%A9%D7%A4%D7%98_%D7%94%D7%90%D7%97%D7%A8%D7%95%D7%9F_%D7%A9%D7%9C_%D7%A4%D7%A8%D7%9E%D7%94) ושל [השערת קטלן](https://he.wikipedia.org/wiki/%D7%94%D7%A9%D7%A2%D7%A8%D7%AA_%D7%A7%D7%98%D7%9C%D7%9F). ה[השערה](https://he.wikipedia.org/wiki/%D7%94%D7%A9%D7%A2%D7%A8%D7%94_%28%D7%9E%D7%AA%D7%9E%D7%98%D7%99%D7%A7%D7%94%29) קובעת של[משוואה](https://he.wikipedia.org/wiki/%D7%9E%D7%A9%D7%95%D7%95%D7%90%D7%94)



```math
a^m + b^n = c^k \qquad (1)
```

 יש רק מספר [סופי](https://he.wikipedia.org/wiki/%D7%A7%D7%91%D7%95%D7%A6%D7%94_%D7%A1%D7%95%D7%A4%D7%99%D7%AA) של פתרונות $`(a, b, c, m, n, k)`$ עם שלשות שונות של ערכים $`(a^m, b^n, c^k)`$, כאשר $`a, b, c`$ [שלמים חיוביים זרים](https://he.wikipedia.org/wiki/%D7%9E%D7%A1%D7%A4%D7%A8%D7%99%D7%9D_%D7%96%D7%A8%D7%99%D7%9D) ו-$`m, n, k`$ שלמים חיוביים שמקיימים



```math
\frac1m + \frac1n + \frac1k \lt 1. \qquad (2)
```

 אי-השוויון על $`m`$, $`n`$ ו-$`k`$ הוא חלק הכרחי מההשערה. בלעדיו היו אינסוף פתרונות, למשל עם $`k = 1`$ (לכל $`a, b, m, n`$, עם $`c = a^m + b^n`$), עם $`m = n = k = 2`$ (אינסוף ה[שלשות הפיתגוריות](https://he.wikipedia.org/wiki/%D7%A9%D7%9C%D7%A9%D7%94_%D7%A4%D7%99%D7%AA%D7%92%D7%95%D7%A8%D7%99%D7%AA)), ולמשל $`7^5 + 393^3 = 7792^2`$ (כאן $`\frac15 + \frac13 + \frac12 = \frac{31}{30} \gt 1`$).

הסיבה הגאומטרית לתנאי (2): כש-$`\frac1m + \frac1n + \frac1k \gt 1`$ ה"אורביפולד" המתאים הוא כדורי (כמו במשוואה הפיתגורית), ויש אינסוף פתרונות פרימיטיביים שמתפרמטרים בפולינומים; כש-$`= 1`$ (למשל $`(2, 3, 6)`$, $`(2, 4, 4)`$, $`(3, 3, 3)`$) הוא אוקלידי ומתאים לעקומים אליפטיים, ומספר הפתרונות סופי; וכש-$`\lt 1`$ הוא היפרבולי. ההשערה טוענת שגם כשמאפשרים לכל המעריכים להשתנות, יש רק מספר סופי של פתרונות בתחום ההיפרבולי.

## פתרונות ידועים

נכון ל-2024, ידועים עשרת הפתרונות הבאים של משוואה (1) שמקיימים את תנאי (2):[^1][^2][^3]

| פתרון                                              | $`\frac1m + \frac1n + \frac1k`$  |
|----------------------------------------------------|--------------------------------|
| $`1^m + 2^3 = 3^2`$ (עם $`m \gt 6`$, כדי לקיים את (2)) | $`\frac{41}{42}`$ (עבור $`m = 7`$) |
| $`2^5 + 7^2 = 3^4`$                                  | $`\frac{19}{20}`$                |
| $`7^3 + 13^2 = 2^9`$                                 | $`\frac{17}{18}`$                |
| $`2^7 + 17^3 = 71^2`$                                | $`\frac{41}{42}`$                |
| $`3^5 + 11^4 = 122^2`$                               | $`\frac{19}{20}`$                |
| $`33^8 + 1549034^2 = 15613^3`$                       | $`\frac{23}{24}`$                |
| $`1414^3 + 2213459^2 = 65^7`$                        | $`\frac{41}{42}`$                |
| $`9262^3 + 15312283^2 = 113^7`$                      | $`\frac{41}{42}`$                |
| $`17^7 + 76271^3 = 21063928^2`$                      | $`\frac{41}{42}`$                |
| $`43^8 + 96222^3 = 30042907^2`$                      | $`\frac{23}{24}`$                |

(בדקנו בחשבון שלמים מדויק את כל עשר הזהויות, את הזרות של $`a, b, c`$ ואת תנאי (2).) שימו לב לשתי תופעות: בכל הפתרונות מופיע המעריך 2, וכל הסכומים $`\frac1m + \frac1n + \frac1k`$ קרובים מאוד ל-1 – הערך המקסימלי שקטן מ-1, $`\frac{41}{42}`$, מתקבל עבור $`(2, 3, 7)`$, והוא מופיע בחמישה פתרונות.

הראשון מבין אלה ($`1^m + 2^3 = 3^2`$) הוא הפתרון היחיד שבו אחד מ-$`a`$, $`b`$ או $`c`$ הוא 1, לפי השערת קטלן, ש[פרדה מיכאילסקו](https://he.wikipedia.org/wiki/%D7%A4%D7%A8%D7%93%D7%94_%D7%9E%D7%99%D7%9B%D7%90%D7%99%D7%9C%D7%A1%D7%A7%D7%95) הוכיח ב-2002. אף שהמקרה הזה נותן אינסוף פתרונות של (1) (כי אפשר לבחור כל $`m \gt 6`$), הם נותנים רק שלשת ערכים אחת $`(a^m, b^n, c^k)`$.

## תוצאות חלקיות

לפי משפט דרמון–גרנוויל, שמשתמש ב[משפט פלטינגס](https://he.wikipedia.org/wiki/%D7%9E%D7%A9%D7%A4%D7%98_%D7%A4%D7%9C%D7%98%D7%99%D7%A0%D7%92%D7%A1), לכל בחירה קבועה של שלמים חיוביים $`m`$, $`n`$ ו-$`k`$ שמקיימים את (2), יש רק מספר סופי של שלשות זרות $`(a, b, c)`$ שפותרות את (1).[^4][^5] (הרעיון: כל פתרון כזה מתרומם לנקודה רציונלית על אחד ממספר סופי של עקומים מגנוס 2 לפחות, ולכל אחד מהם יש רק מספר סופי של נקודות רציונליות.) אבל השערת פרמה–קטלן המלאה חזקה יותר, כי היא מאפשרת למעריכים $`m`$, $`n`$ ו-$`k`$ להשתנות.

[השערת abc](https://he.wikipedia.org/wiki/%D7%94%D7%A9%D7%A2%D7%A8%D7%AA_abc) גוררת את השערת פרמה–קטלן.[^6] הנה הטיעון: אם $`a^m + b^n = c^k`$, אז הרדיקל (מכפלת הראשוניים השונים) של $`a^mb^nc^k`$ הוא לכל היותר $`abc \le (c^k)^{1/m + 1/n + 1/k}`$ בערך. כשהסכום קטן מ-1, הרדיקל קטן מ-$`(c^k)^{1-\delta}`$ עבור $`\delta = 1 - \frac{41}{42} = \frac1{42}`$ לפחות, והשערת abc אומרת שיש רק מספר סופי של משוואות $`A + B = C`$ כאלה.

לרשימת תוצאות על צירופים בלתי אפשריים של מעריכים, ראו [השערת בעל](https://he.wikipedia.org/wiki/%D7%94%D7%A9%D7%A2%D7%A8%D7%AA_%D7%91%D7%A2%D7%9C). השערת בעל נכונה [אם ורק אם](https://he.wikipedia.org/wiki/%D7%90%D7%9D_%D7%95%D7%A8%D7%A7_%D7%90%D7%9D) בכל פתרונות פרמה–קטלן $`m = 2`$, $`n = 2`$ או $`k = 2`$.

פונן, שפר ושטול[^7] מנו את שלשות המעריכים שעבורן הפתרונות נקבעו במלואם (הסימון $`\{p, q, r\}`$ פירושו שהפתרונות נקבעו לכל תמורה של $`(p, q, r)`$):

| שלשת מעריכים                                          | מקור                                                 |
|-------------------------------------------------------|------------------------------------------------------|
| $`\{2, 3, 7\}`$                                         | פונן–שפר–שטול 2007[^8]                               |
| $`\{2, 3, 8\}`$, $`\{2, 4, 6\}`$                          | ברוין 1999, 2003                                     |
| $`\{2, 3, 9\}`$                                         | ברוין 2004                                           |
| $`\{2, 2q, 3\}`$ לראשוני $`7 \lt q \lt 1000`$, $`q \ne 31`$ | צ'ן 2007                                             |
| $`\{2, 4, 5\}`$                                         | ברוין 2003                                           |
| $`(2, 4, 7)`$                                           |                                                      |
| $`(2, 4, q)`$ לראשוני $`q \ge 211`$                       | אלנברג 2004                                          |
| $`(2, n, 4)`$                                           | נובע מבנט–סקינר 2004 (המקרה $`(4, n, 4)`$: דרמון 1993) |
| $`\{2, n, n\}`$, $`\{3, n, n\}`$                          | דרמון–מרל 1997                                       |
| $`\{3, 3, 4\}`$, $`\{3, 3, 5\}`$                          | ברוין 2000                                           |
| $`\{3, 3, q\}`$ עבור $`17 \le q \le 10000`$               | קראוס 1998                                           |
| $`\{2n, 2n, 5\}`$                                       | בנט 2006                                             |
| $`\{n, n, n\}`$                                         | ויילס 1995, טיילור–ויילס 1995 (המשפט האחרון של פרמה) |

לכל אחת משלשות המעריכים האלה, אם יש לה פתרון בכלל, הוא מופיע ברשימה שבסעיף "פתרונות ידועים". למשל, עבור $`\{2, 3, 7\}`$ אלה בדיוק $`1^7 + 2^3 = 3^2`$, $`2^7 + 17^3 = 71^2`$, $`1414^3 + 2213459^2 = 65^7`$, $`9262^3 + 15312283^2 = 113^7`$ ו-$`17^7 + 76271^3 = 21063928^2`$.

סיקורה השתמש בין השאר במחשבי ה[אשכול](https://he.wikipedia.org/wiki/%D7%9E%D7%97%D7%A9%D7%91_%D7%90%D7%A9%D7%9B%D7%95%D7%9C) של המרכז לחקר חישובי ב[אוניברסיטת באפלו](https://he.wikipedia.org/wiki/%D7%90%D7%95%D7%A0%D7%99%D7%91%D7%A8%D7%A1%D7%99%D7%98%D7%AA_%D7%91%D7%90%D7%A4%D7%9C%D7%95) כדי לבדוק את כל השישיות $`(a, b, c, m, n, k)`$ עם $`\min(m, n, k) \le 113`$ ו-$`a^m, b^n, c^k \lt M_{\min(m,n,k)}`$, כאשר $`M_2 = 2^{71}`$, $`M_3 = 2^{80}`$, $`M_4 = 2^{100}`$ ו-$`M_5 = \dots = M_{113} = 2^{113}`$. הוא לא מצא פתרונות נוספים על אלה שלמעלה.[^9] (למשל, חמשת הפתרונות הגדולים הידועים שוחזרו כולם בבדיקה עבור $`\min(m, n, k) = 2`$, שבה $`a^m`$, $`b^n`$ ו-$`c^k`$ נבדקו עד $`2^{71} \approx 2.4\cdot10^{21}`$; הגדול שבהם, $`30042907^2 \approx 9.0\cdot10^{14}`$, רחוק מתחת לחסם הזה.)
