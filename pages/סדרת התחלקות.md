# סדרת התחלקות

ב[מתמטיקה](https://he.wikipedia.org/wiki/%D7%9E%D7%AA%D7%9E%D7%98%D7%99%D7%A7%D7%94), **סדרת התחלקות** (ב[אנגלית](https://he.wikipedia.org/wiki/%D7%90%D7%A0%D7%92%D7%9C%D7%99%D7%AA): divisibility sequence) היא [סדרה](https://he.wikipedia.org/wiki/%D7%A1%D7%93%D7%A8%D7%94_%28%D7%9E%D7%AA%D7%9E%D7%98%D7%99%D7%A7%D7%94%29) של [מספרים שלמים](https://he.wikipedia.org/wiki/%D7%9E%D7%A1%D7%A4%D7%A8_%D7%A9%D7%9C%D7%9D) $`(a_n)`$, שהאינדקסים שלה הם המספרים השלמים החיוביים $`n`$, כך ש-



```math
m\mid n \ \Longrightarrow\ a_m\mid a_n
```

 (אם $`m`$ מחלק את $`n`$, אז $`a_m`$ מחלק את $`a_n`$) לכל $`m`$ ו-$`n`$. כלומר, בכל פעם שאינדקס אחד הוא כפולה של אינדקס אחר, גם האיבר המתאים הוא כפולה של האיבר האחר. אפשר להכליל את המושג לסדרות עם ערכים ב[חוג](https://he.wikipedia.org/wiki/%D7%97%D7%95%D7%92_%28%D7%9E%D7%91%D7%A0%D7%94_%D7%90%D7%9C%D7%92%D7%91%D7%A8%D7%99%29) כלשהו שבו מוגדר מושג ההתחלקות.

**סדרת התחלקות חזקה** היא סדרה של מספרים שלמים $`(a_n)`$ כך שלכל זוג מספרים שלמים חיוביים $`m`$ ו-$`n`$,



```math
\gcd(a_m,a_n) = a_{\gcd(m,n)},
```

 כאשר $`\gcd`$ הוא ה[מחלק המשותף המקסימלי](https://he.wikipedia.org/wiki/%D7%9E%D7%97%D7%9C%D7%A7_%D7%9E%D7%A9%D7%95%D7%AA%D7%A3_%D7%9E%D7%A7%D7%A1%D7%99%D7%9E%D7%9C%D7%99).

כל סדרת התחלקות חזקה היא סדרת התחלקות: $`\gcd(m,n) = m`$ אם ורק אם $`m\mid n`$. לכן, לפי תכונת ההתחלקות החזקה, $`\gcd(a_m,a_n) = a_m`$, ולכן $`a_m\mid a_n`$.

## דוגמאות

כל [סדרת לוקאס](https://he.wikipedia.org/wiki/%D7%A1%D7%93%D7%A8%D7%AA_%D7%9C%D7%95%D7%A7%D7%90%D7%A1) מהסוג הראשון $`U_n(P, Q)`$ היא סדרת התחלקות. יתרה מזו, היא סדרת התחלקות חזקה כאשר $`\gcd(P, Q) = 1`$. דוגמאות מסוימות:

- כל סדרה קבועה $`a_n = k`$ היא סדרת התחלקות חזקה; זו הסדרה $`kU_n(1, 0)`$ עבור $`n \ge 1`$.
- כל סדרה מהצורה $`a_n = kn`$, עבור מספר שלם $`k`$ שונה מאפס, היא סדרת התחלקות. היא שווה ל-$`kU_n(2, 1)`$.
- [מספרי פיבונאצ'י](https://he.wikipedia.org/wiki/%D7%A1%D7%93%D7%A8%D7%AA_%D7%A4%D7%99%D7%91%D7%95%D7%A0%D7%90%D7%A6%27%D7%99) $`F_n`$ הם סדרת התחלקות חזקה; זו הסדרה $`U_n(1, -1)`$. למשל $`\gcd(F_{12}, F_{18}) = \gcd(144, 2584) = 8 = F_6`$.
- [מספרי מרסן](https://he.wikipedia.org/wiki/%D7%9E%D7%A1%D7%A4%D7%A8_%D7%9E%D7%A8%D7%A1%D7%9F) $`a_n = 2^n-1`$ הם סדרת התחלקות חזקה; זו הסדרה $`U_n(3, 2)`$.
- מספרי הרפיוניט $`R^{(b)}_n`$ (המספרים שבבסיס $`b`$ כתובים כרצף של $`n`$ ספרות 1), עבור $`n = 1, 2, \dots`$, בכל בסיס $`b`$, הם סדרת התחלקות חזקה; זו הסדרה $`U_n(b + 1, b)`$.
- כל סדרה מהצורה $`a_n = A^n - B^n`$, עבור מספרים שלמים $`A>B>0`$, היא סדרת התחלקות; זו הסדרה $`(A - B)U_n(A + B, AB)`$. אם $`A`$ ו-$`B`$ זרים, זו סדרת התחלקות חזקה.

סדרות התחלקות אליפטיות הן משפחה נוספת של סדרות התחלקות.
