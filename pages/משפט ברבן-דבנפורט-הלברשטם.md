# משפט ברבן-דבנפורט-הלברשטם

ב[מתמטיקה](https://he.wikipedia.org/wiki/%D7%9E%D7%AA%D7%9E%D7%98%D7%99%D7%A7%D7%94), **משפט ברבן–דבנפורט–הלברשטם** (ב[אנגלית](https://he.wikipedia.org/wiki/%D7%90%D7%A0%D7%92%D7%9C%D7%99%D7%AA): Barban–Davenport–Halberstam theorem) הוא טענה על התפלגות ה[מספרים הראשוניים](https://he.wikipedia.org/wiki/%D7%9E%D7%A1%D7%A4%D7%A8_%D7%A8%D7%90%D7%A9%D7%95%D7%A0%D7%99) ב[סדרות חשבוניות](https://he.wikipedia.org/wiki/%D7%A1%D7%93%D7%A8%D7%94_%D7%97%D7%A9%D7%91%D7%95%D7%A0%D7%99%D7%AA). ידוע שבטווח הארוך הראשוניים מתפלגים באופן שווה בין הסדרות האפשריות עם אותו הפרש ([משפט דיריכלה](https://he.wikipedia.org/wiki/%D7%9E%D7%A9%D7%A4%D7%98_%D7%93%D7%99%D7%A8%D7%99%D7%9B%D7%9C%D7%94)). משפטים מטיפוס ברבן–דבנפורט–הלברשטם נותנים הערכות לאיבר השגיאה, וקובעים עד כמה ההתפלגויות קרובות להתפלגות אחידה.

## ניסוח

יהי $`a`$ [זר](https://he.wikipedia.org/wiki/%D7%9E%D7%A1%D7%A4%D7%A8%D7%99%D7%9D_%D7%96%D7%A8%D7%99%D7%9D) ל-$`q`$, ויהי



```math
\vartheta(x;q,a) = \sum_{p\leq x,\ p \equiv a \bmod q} \log p
```

 מספר משוקלל של הראשוניים בסדרה החשבונית $`a \bmod q`$. מתקיים



```math
\vartheta(x;q,a) = \frac{x}{\varphi(q)} + E(x;q,a),
```

 כאשר $`\varphi`$ היא [פונקציית אוילר](https://he.wikipedia.org/wiki/%D7%A4%D7%95%D7%A0%D7%A7%D7%A6%D7%99%D7%99%D7%AA_%D7%90%D7%95%D7%99%D7%9C%D7%A8) ואיבר השגיאה $`E`$ קטן לעומת $`x`$. ניקח את סכום ריבועי איברי השגיאה



```math
V(x,Q) = \sum_{q \leq Q}\ \sum_{\substack{a \bmod q\\ \gcd(a,q)=1} } |E(x;q,a)|^2.
```

 אז



```math
V(x,Q) = O(Q x \log x) + O\left(x^2 (\log x)^{-A}\right)
```

 עבור $`1 \leq Q \leq x`$ ולכל $`A`$ חיובי, כאשר $`O`$ הוא [סימון O גדולה](https://he.wikipedia.org/wiki/%D7%A1%D7%99%D7%9E%D7%95%D7%9F_%D7%90%D7%A1%D7%99%D7%9E%D7%A4%D7%98%D7%95%D7%98%D7%99) של לנדאו.

צורה זו של המשפט היא של גלגר. התוצאה של ברבן תקפה רק עבור $`Q \leq x (\log x)^{-B}`$, עבור $`B`$ כלשהו התלוי ב-$`A`$, ובתוצאה של דבנפורט והלברשטם $`B = A + 5`$.

## פירוש

יש בערך $`\sum_{q \le Q}\varphi(q) \approx \tfrac{3}{\pi^2}Q^2`$ זוגות $`(q, a)`$. אילו השגיאות היו "אקראיות" בגודל טיפוסי $`\sqrt{x/\varphi(q)}`$ (כמו סטיית התקן של סכום של כ-$`x/(\varphi(q)\log x)`$ ראשוניים, כשכל אחד תורם $`\log p`$), הסכום $`V(x,Q)`$ היה בערך $`\sum_{q \le Q}\varphi(q) \cdot \frac{x\log x}{\varphi(q)} = Q x \log x`$ — בדיוק האיבר הראשי במשפט. כלומר, בממוצע על כל המודולים עד $`Q`$, השגיאות אינן גדולות יותר ממה שמצפים מרעש אקראי, וזאת עד $`Q`$ קרוב ל-$`x`$. זו תוצאה "בממוצע ריבועי", משלימה ל[משפט בומביירי-וינוגרדוב](%D7%9E%D7%A9%D7%A4%D7%98%20%D7%91%D7%95%D7%9E%D7%91%D7%99%D7%99%D7%A8%D7%99-%D7%95%D7%99%D7%A0%D7%95%D7%92%D7%A8%D7%93%D7%95%D7%91.md), שעוסק בשגיאה המרבית אך רק עד $`Q \approx \sqrt x`$.
