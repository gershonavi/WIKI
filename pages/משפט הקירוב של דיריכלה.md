# משפט הקירוב של דיריכלה

ב[תורת המספרים](https://he.wikipedia.org/wiki/%D7%AA%D7%95%D7%A8%D7%AA_%D7%94%D7%9E%D7%A1%D7%A4%D7%A8%D7%99%D7%9D), **משפט דיריכלה על קירובים דיופנטיים**, שנקרא גם **משפט הקירוב של דיריכלה**, קובע שלכל [מספרים ממשיים](https://he.wikipedia.org/wiki/%D7%9E%D7%A1%D7%A4%D7%A8_%D7%9E%D7%9E%D7%A9%D7%99) $`\alpha`$ ו-$`N`$ עם $`1 \le N`$, יש שלמים $`p`$ ו-$`q`$ כך ש-$`1 \le q \le N`$ ו-



```math
|q\alpha - p| \le \frac1{\lfloor N\rfloor + 1} \lt \frac1N.
```

 כאן $`\lfloor N\rfloor`$ מסמן את [החלק השלם](https://he.wikipedia.org/wiki/%D7%A4%D7%95%D7%A0%D7%A7%D7%A6%D7%99%D7%99%D7%AA_%D7%94%D7%A2%D7%A8%D7%9A_%D7%94%D7%A9%D7%9C%D7%9D) של $`N`$.

זו תוצאה יסודית ב[קירובים דיופנטיים](https://he.wikipedia.org/wiki/%D7%A7%D7%99%D7%A8%D7%95%D7%91_%D7%93%D7%99%D7%95%D7%A4%D7%A0%D7%98%D7%99), שמראה שלכל מספר ממשי יש סדרה של קירובים רציונליים טובים: מסקנה מיידית היא שעבור $`\alpha`$ אי-רציונלי נתון, אי-השוויון



```math
\left|\alpha - \frac pq\right| \lt \frac1{q^2}
```

 מתקיים עבור אינסוף זוגות שלמים $`p`$ ו-$`q`$. (מחלקים את אי-השוויון של המשפט ב-$`q`$ ומשתמשים ב-$`q \le N`$; כש-$`N`$ גדל, $`|q\alpha - p| \lt 1/N`$ שואף לאפס, ולכן מתקבלים אינסוף שברים שונים, כי $`\alpha`$ אי-רציונלי.) זה מראה שלכל [מספר אי-רציונלי](https://he.wikipedia.org/wiki/%D7%9E%D7%A1%D7%A4%D7%A8_%D7%90%D7%99-%D7%A8%D7%A6%D7%99%D7%95%D7%A0%D7%9C%D7%99) [מעריך אי-רציונליות](https://he.wikipedia.org/wiki/%D7%9E%D7%99%D7%93%D7%AA_%D7%90%D7%99-%D7%A8%D7%A6%D7%99%D7%95%D7%A0%D7%9C%D7%99%D7%95%D7%AA) לפחות 2.

[משפט תואה–זיגל–רות](https://he.wikipedia.org/wiki/%D7%9E%D7%A9%D7%A4%D7%98_%D7%AA%D7%95%D7%90%D7%94%E2%80%93%D7%96%D7%99%D7%92%D7%9C%E2%80%93%D7%A8%D7%95%D7%AA) קובע שעבור מספרים אלגבריים אי-רציונליים, המעריך 2 במסקנה של משפט דיריכלה הוא הטוב ביותר האפשרי: מספרים כאלה אינם ניתנים לקירוב בשום מעריך גדול מ-2. המשפט של תואה–זיגל–רות משתמש בטכניקות מתקדמות, אבל עבור מספרים פשוטים רבים, כמו [יחס הזהב](https://he.wikipedia.org/wiki/%D7%99%D7%97%D7%A1_%D7%94%D7%96%D7%94%D7%91) $`(1 + \sqrt5)/2`$, הרבה יותר קל לבדוק שאינם ניתנים לקירוב מעבר למעריך 2. (עבור אי-רציונלי ריבועי $`\alpha`$ עם פולינום מינימלי $`f`$, $`|f(p/q)| \ge 1/(aq^2)`$ כי זה שבר עם מכנה $`aq^2`$ שאינו אפס, ומכאן $`|\alpha - p/q| \ge c/q^2`$.)

### דוגמה

יהי $`\alpha = \sqrt2`$ ו-$`N = 10`$. החלקים השבריים של $`k\sqrt2`$ עבור $`k = 0, 1, \ldots, 10`$ הם



```math
0,\ 0.414,\ 0.828,\ 0.243,\ 0.657,\ 0.071,\ 0.485,\ 0.899,\ 0.314,\ 0.728,\ 0.142.
```

 יש 11 מספרים ו-10 קטעים $`[0, 0.1), [0.1, 0.2), \ldots`$, ולכן לפי [עקרון שובך היונים](https://he.wikipedia.org/wiki/%D7%A2%D7%A7%D7%A8%D7%95%D7%9F_%D7%A9%D7%95%D7%91%D7%9A_%D7%94%D7%99%D7%95%D7%A0%D7%99%D7%9D) שניים מהם באותו קטע – למשל $`0`$ (עבור $`k = 0`$) ו-$`0.071`$ (עבור $`k = 5`$). ההפרש נותן $`q = 5 - 0 = 5`$: $`|5\sqrt2 - 7| = 0.0711\ldots \lt \frac1{10}`$, כלומר $`\left|\sqrt2 - \frac75\right| \lt \frac1{50} \lt \frac1{25}`$. ואכן, בין $`1 \le q \le 10`$, $`q = 5`$ הוא היחיד עם $`|q\sqrt2 - p| \le \frac1{11}`$.

## הגרסה הסימולטנית

הגרסה הסימולטנית של משפט הקירוב של דיריכלה קובעת שבהינתן מספרים ממשיים $`\alpha_1, \ldots, \alpha_d`$ ו[מספר טבעי](https://he.wikipedia.org/wiki/%D7%9E%D7%A1%D7%A4%D7%A8_%D7%98%D7%91%D7%A2%D7%99) $`N`$, יש שלמים $`p_1, \ldots, p_d, q \in \mathbb Z`$, $`1 \le q \le N`$, כך ש-



```math
\left|\alpha_i - \frac{p_i}q\right| \le \frac1{qN^{1/d} }.
```

 [^1] כלומר, אפשר לקרב כמה מספרים בבת אחת בעזרת מכנה משותף, אבל במחיר: המעריך יורד מ-2 ל-$`1 + 1/d`$.

**דוגמה.** עבור $`\alpha_1 = \sqrt2`$, $`\alpha_2 = \sqrt3`$ ו-$`N = 100`$ (כך ש-$`N^{1/2} = 10`$), המכנה הקטן ביותר שעובד הוא $`q = 41`$: $`\frac{58}{41}`$ ו-$`\frac{71}{41}`$, עם $`|41\sqrt2 - 58| = 0.0172`$ ו-$`|41\sqrt3 - 71| = 0.0141`$, שניהם קטנים מ-$`\frac1{10}`$.

## שיטות הוכחה

### הוכחה בעקרון שובך היונים

המשפט נובע מ[עקרון שובך היונים](https://he.wikipedia.org/wiki/%D7%A2%D7%A7%D7%A8%D7%95%D7%9F_%D7%A9%D7%95%D7%91%D7%9A_%D7%94%D7%99%D7%95%D7%A0%D7%99%D7%9D). [פטר גוסטב לז'ן דיריכלה](https://he.wikipedia.org/wiki/%D7%A4%D7%98%D7%A8_%D7%92%D7%95%D7%A1%D7%98%D7%91_%D7%9C%D7%96%27%D7%9F_%D7%93%D7%99%D7%A8%D7%99%D7%9B%D7%9C%D7%94), שהוכיח את התוצאה, השתמש באותו עיקרון בהקשרים אחרים (למשל ב[משוואת פל](https://he.wikipedia.org/wiki/%D7%9E%D7%A9%D7%95%D7%95%D7%90%D7%AA_%D7%A4%D7%9C)), ובכך שנתן לעיקרון שם (בגרמנית, *Schubfachprinzip* – "עקרון המגירות") הפך אותו לנפוץ. השיטה מתרחבת גם לקירוב סימולטני.

**שלד ההוכחה.** יהי $`\alpha`$ מספר אי-רציונלי ו-$`N`$ שלם. לכל $`k = 0, 1, \ldots, N`$ נכתוב $`k\alpha = m_k + x_k`$, כאשר $`m_k`$ שלם ו-$`0 \le x_k \lt 1`$. נחלק את הקטע $`[0, 1)`$ ל-$`N`$ קטעים קטנים באורך $`\frac1N`$. יש לנו $`N + 1`$ מספרים $`x_0, x_1, \ldots, x_N`$ ו-$`N`$ קטעים, ולכן לפי עקרון שובך היונים לפחות שניים מהם באותו קטע. נקרא להם $`x_i, x_j`$ עם $`i \lt j`$. אז



```math
|(j - i)\alpha - (m_j - m_i)| = |j\alpha - m_j - (i\alpha - m_i)| = |x_j - x_i| \lt \frac1N.
```

 חלוקה של שני האגפים ב-$`j - i`$ נותנת



```math
\left|\alpha - \frac{m_j - m_i}{j - i}\right| \lt \frac1{(j - i)N} \le \frac1{(j - i)^2},
```

 וזה מוכיח את המשפט.

### הוכחה בעזרת משפט מינקובסקי

הוכחה פשוטה נוספת למשפט הקירוב של דיריכלה מבוססת על [משפט מינקובסקי](https://he.wikipedia.org/wiki/%D7%9E%D7%A9%D7%A4%D7%98_%D7%9E%D7%99%D7%A0%D7%A7%D7%95%D7%91%D7%A1%D7%A7%D7%99), שמופעל על הקבוצה



```math
S = \left\{(x, y) \in \mathbb R^2 : -N - \frac12 \le x \le N + \frac12,\ |\alpha x - y| \le \frac1N\right\}.
```

 זו מקבילית קמורה וסימטרית ביחס לראשית, והשטח שלה הוא $`(2N + 1)\cdot\frac2N = 4 + \frac2N \gt 4`$; לכן משפט מינקובסקי מבטיח בה נקודה לא טריוויאלית עם קואורדינטות שלמות $`(q, p)`$. (אפשר להניח $`q \gt 0`$, ו-$`q \ne 0`$ כי אחרת $`|p| \le 1/N \lt 1`$ גורר $`p = 0`$.) ההוכחה מתרחבת באופן טבעי לקירובים סימולטניים, כשמתבוננים בקבוצה



```math
S = \left\{(x, y_1, \ldots, y_d) \in \mathbb R^{1+d} : -N - \frac12 \le x \le N + \frac12,\ |\alpha_ix - y_i| \le \frac1{N^{1/d} }\right\},
```

 שנפחה $`(2N + 1)\cdot\frac{2^d}N \gt 2^{d+1}`$.

## משפטים קשורים

### משפט לז'נדר על שברים משולבים

בחיבורו *Essai sur la théorie des nombres* מ-1798 נתן [אדריאן-מארי לז'נדר](https://he.wikipedia.org/wiki/%D7%90%D7%93%D7%A8%D7%99%D7%90%D7%9F-%D7%9E%D7%90%D7%A8%D7%99_%D7%9C%D7%96%27%D7%A0%D7%93%D7%A8) תנאי הכרחי ומספיק לכך שמספר רציונלי יהיה מנה מתקרבת של [השבר המשולב הפשוט](https://he.wikipedia.org/wiki/%D7%A9%D7%91%D7%A8_%D7%9E%D7%A9%D7%95%D7%9C%D7%91) של מספר ממשי נתון.[^2] מסקנה של הקריטריון, שנקראת לעתים קרובות **משפט לז'נדר** בתורת השברים המשולבים, היא:[^3]

**משפט.** אם $`\alpha`$ מספר ממשי ו-$`p, q`$ שלמים חיוביים כך ש-$`\left|\alpha - \frac pq\right| \lt \frac1{2q^2}`$, אז $`p/q`$ היא מנה מתקרבת של השבר המשולב של $`\alpha`$.

**הוכחה.** נלך לפי ההוכחה ב*[מבוא לתורת המספרים](https://he.wikipedia.org/wiki/%D7%9E%D7%91%D7%95%D7%90_%D7%9C%D7%AA%D7%95%D7%A8%D7%AA_%D7%94%D7%9E%D7%A1%D7%A4%D7%A8%D7%99%D7%9D_%28%D7%94%D7%90%D7%A8%D7%93%D7%99_%D7%95%D7%A8%D7%99%D7%99%D7%98%29)* של [הארדי](https://he.wikipedia.org/wiki/%D7%92%D7%95%D7%93%D7%A4%D7%A8%D7%99_%D7%94%D7%A8%D7%95%D7%9C%D7%93_%D7%94%D7%90%D7%A8%D7%93%D7%99) ו[רייט](https://he.wikipedia.org/wiki/%D7%90%D7%93%D7%95%D7%90%D7%A8%D7%93_%D7%9E%D7%99%D7%99%D7%98%D7%9C%D7%A0%D7%93_%D7%A8%D7%99%D7%99%D7%98).[^4] נניח ש-$`\alpha, p, q`$ מקיימים $`\left|\alpha - \frac pq\right| \lt \frac1{2q^2}`$, ונניח ש-$`\alpha \gt p/q`$. אז אפשר לכתוב $`\alpha - \frac pq = \frac\theta{q^2}`$, עם $`0 \lt \theta \lt 1/2`$. נכתוב את $`p/q`$ כשבר משולב סופי $`[a_0; a_1, \ldots, a_n]`$; כיוון שלכל מספר רציונלי יש שתי הצגות שונות כשבר משולב סופי, שאורכיהן נבדלים באחד (אחת עם $`a_n = 1`$ ואחת עם $`a_n \ne 1`$), אפשר לבחור את $`n`$ זוגי. (במקרה $`\alpha \lt p/q`$ היינו בוחרים $`n`$ אי-זוגי.)

יהיו $`p_0/q_0, \ldots, p_n/q_n = p/q`$ המנות המתקרבות של השבר המשולב הזה. נגדיר $`\omega := \frac1\theta - \frac{q_{n-1} }{q_n}`$, כך ש-$`\theta = \frac{q_n}{q_{n-1} + \omega q_n}`$, ולכן



```math
\alpha = \frac pq + \frac\theta{q^2} = \frac{p_n}{q_n} + \frac1{q_n(q_{n-1} + \omega q_n)} = \frac{(p_nq_{n-1} + 1) + \omega p_nq_n}{q_n(q_{n-1} + \omega q_n)} = \frac{p_{n-1}q_n + \omega p_nq_n}{q_n(q_{n-1} + \omega q_n)} = \frac{p_{n-1} + \omega p_n}{q_{n-1} + \omega q_n},
```

 כאשר השתמשנו בכך ש-$`p_{n-1}q_n - p_nq_{n-1} = (-1)^n`$ וש-$`n`$ זוגי.

מהמשוואה הזו נובע ש-$`\alpha = [a_0; a_1, \ldots, a_n, \omega]`$. כיוון ש-$`0 \lt \theta \lt 1/2`$ גורר $`\omega \gt 1`$ (כי $`1/\theta \gt 2`$ ו-$`q_{n-1}/q_n \le 1`$), מסיקים שהשבר המשולב של $`\alpha`$ הוא $`[a_0; a_1, \ldots, a_n, b_0, b_1, \ldots]`$, כאשר $`[b_0; b_1, \ldots]`$ הוא השבר המשולב של $`\omega`$; ולכן $`p_n/q_n = p/q`$ היא מנה מתקרבת של השבר המשולב של $`\alpha`$. $`\blacksquare`$

**דוגמה.** $`\pi = [3; 7, 15, 1, 292, 1, \ldots]`$, והמנות המתקרבות הראשונות הן $`3, \frac{22}7, \frac{333}{106}, \frac{355}{113}, \ldots`$. למשל $`\left|\pi - \frac{355}{113}\right| = 2.67\times10^{-7}`$, הרבה מתחת ל-$`\frac1{2\cdot113^2} = 3.9\times10^{-5}`$. הקבוע $`\frac12`$ במשפט חיוני: השבר $`\frac{19}6`$ מקיים $`\left|\pi - \frac{19}6\right| = 0.025 \lt \frac1{36}`$, כלומר הוא "קירוב דיריכלה", אבל $`0.025 \gt \frac1{72}`$, והוא באמת **אינו** מנה מתקרבת של $`\pi`$ (הוא מנה מתקרבת ביניים, $`\frac{22 - 3}{7 - 1}`$). חיפוש על $`q \lt 120`$ מראה שזה השבר המצומצם היחיד עם $`|\pi - p/q| \lt 1/q^2`$ שאינו מנה מתקרבת.

המשפט הוא הבסיס של [ההתקפה של וינר](https://he.wikipedia.org/wiki/%D7%94%D7%94%D7%AA%D7%A7%D7%A4%D7%94_%D7%A9%D7%9C_%D7%95%D7%99%D7%A0%D7%A8), ניצול בזמן פולינומי של פרוטוקול ההצפנה [RSA](https://he.wikipedia.org/wiki/RSA) שעלול לקרות בבחירה לא זהירה של מפתח ציבורי ומפתח פרטי (ליתר דיוק, ההתקפה מצליחה אם הגורמים הראשוניים של המפתח הציבורי $`n = pq`$ מקיימים $`q \lt p \lt 2q`$, והמפתח הפרטי $`d`$ קטן מ-$`\frac13n^{1/4}`$).[^5] הסיבה: $`ed = 1 + k\varphi(n)`$, ולכן $`\left|\frac en - \frac kd\right|`$ קטן מאוד, ולפי משפט לז'נדר $`k/d`$ מופיע בין המנות המתקרבות של $`e/n`$ – שאותן כל אחד יכול לחשב.
