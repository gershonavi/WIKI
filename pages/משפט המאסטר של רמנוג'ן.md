# משפט המאסטר של רמנוג'ן

ב[מתמטיקה](https://he.wikipedia.org/wiki/%D7%9E%D7%AA%D7%9E%D7%98%D7%99%D7%A7%D7%94), **משפט המאסטר של רמנוג'ן** (ב[אנגלית](https://he.wikipedia.org/wiki/%D7%90%D7%A0%D7%92%D7%9C%D7%99%D7%AA): Ramanujan's master theorem), הקרוי על שם [סריניוואסה רמנוג'ן](https://he.wikipedia.org/wiki/%D7%A1%D7%A8%D7%99%D7%A0%D7%99%D7%95%D7%95%D7%90%D7%A1%D7%94_%D7%A8%D7%9E%D7%A0%D7%95%D7%92%27%D7%90%D7%9F),[^1] הוא טכניקה שנותנת ביטוי אנליטי ל[התמרת מלין](%D7%94%D7%AA%D7%9E%D7%A8%D7%AA%20%D7%9E%D7%9C%D7%99%D7%9F.md) של [פונקציה אנליטית](https://he.wikipedia.org/wiki/%D7%A4%D7%95%D7%A0%D7%A7%D7%A6%D7%99%D7%94_%D7%90%D7%A0%D7%9C%D7%99%D7%98%D7%99%D7%AA).

התוצאה מנוסחת כך:

אם לפונקציה מרוכבת $`f(x)`$ יש פיתוח מהצורה



```math
f(x)=\sum_{k=0}^\infty \frac{\,\varphi(k)\,}{k!}(-x)^k
```

 כאשר $`\varphi(s)`$ פונקציה אנליטית, אז התמרת מלין של $`f(x)`$ נתונה על ידי



```math
\int_0^\infty x^{s-1} f(x) \, dx = \Gamma(s)\,\varphi(-s)
```

 כאשר $`\Gamma(s)`$ היא [פונקציית גמא](https://he.wikipedia.org/wiki/%D7%A4%D7%95%D7%A0%D7%A7%D7%A6%D7%99%D7%99%D7%AA_%D7%92%D7%9E%D7%90).

רמנוג'ן השתמש בה רבות כדי לחשב [אינטגרלים מסוימים](https://he.wikipedia.org/wiki/%D7%90%D7%99%D7%A0%D7%98%D7%92%D7%A8%D7%9C_%D7%9E%D7%A1%D7%95%D7%99%D7%9D) ו[טורים אינסופיים](https://he.wikipedia.org/wiki/%D7%98%D7%95%D7%A8_%28%D7%9E%D7%AA%D7%9E%D7%98%D7%99%D7%A7%D7%94%29).

גרסאות רב-ממדיות של המשפט מופיעות גם ב[פיזיקה קוונטית](https://he.wikipedia.org/wiki/%D7%9E%D7%9B%D7%A0%D7%99%D7%A7%D7%AA_%D7%94%D7%A7%D7%95%D7%95%D7%A0%D7%98%D7%99%D7%9D), דרך [דיאגרמות פיינמן](https://he.wikipedia.org/wiki/%D7%93%D7%99%D7%90%D7%92%D7%A8%D7%9E%D7%AA_%D7%A4%D7%99%D7%99%D7%A0%D7%9E%D7%9F).[^2]

תוצאה דומה קיבל גם ג'יימס וויטבר לי גלישר.[^3]

## הדגמה ראשונה (נוסף בתרגום)

**הדוגמה הבסיסית.** עבור $`\varphi(k) = 1`$ מתקבל $`f(x) = \sum_k (-x)^k/k! = e^{-x}`$, והמשפט נותן $`\int_0^\infty x^{s-1}e^{-x}\,dx = \Gamma(s)`$, שהיא פשוט ההגדרה של פונקציית גמא.

**אינטגרל בטא.** עבור $`a > 0`$, לפי [הבינום המוכלל](https://he.wikipedia.org/wiki/%D7%94%D7%91%D7%99%D7%A0%D7%95%D7%9D_%D7%A9%D7%9C_%D7%A0%D7%99%D7%95%D7%98%D7%95%D7%9F),



```math
(1+x)^{-a} = \sum_{k=0}^\infty \binom{-a}{k} x^k = \sum_{k=0}^\infty \frac{\Gamma(a+k)}{\Gamma(a)\,k!}(-x)^k,
```

 כלומר $`\varphi(k) = \Gamma(a+k)/\Gamma(a)`$. המשפט נותן מיד



```math
\int_0^\infty \frac{x^{s-1} }{(1+x)^{a} }\,dx = \Gamma(s)\,\frac{\Gamma(a-s)}{\Gamma(a)}, \qquad 0 \lt \mathrm{Re}(s) \lt \mathrm{Re}(a),
```

 שהיא נוסחת [אינטגרל בטא](https://he.wikipedia.org/wiki/%D7%A4%D7%95%D7%A0%D7%A7%D7%A6%D7%99%D7%99%D7%AA_%D7%91%D7%98%D7%90) הידועה. (למשל עבור $`a = 2.5`$, $`s = 0.7`$ שני האגפים שווים ל-$`0.909464\ldots`$; נבדק בחישוב.)

שימו לב לאופי ה"פורמלי" של המשפט: הטור של $`f`$ מתכנס רק עבור $`|x| \lt 1`$, ובכל זאת המשפט נותן את האינטגרל על כל $`(0,\infty)`$. הסיבה היא ש-$`\varphi`$ היא פונקציה אנליטית של משתנה רציף, ולא רק סדרה של מקדמים; ההוכחה של הרדי (להלן) מבהירה את התנאים הנדרשים.

## ניסוח חלופי

ניסוח חלופי של משפט המאסטר של רמנוג'ן הוא:



```math
\int_0^\infty x^{s-1}\left(\,\lambda(0) - x\,\lambda(1) + x^2\,\lambda(2) -\,\cdots\,\right) dx = \frac{\pi}{\,\sin(\pi s)\,}\,\lambda(-s)
```

 והוא הופך לצורה שלמעלה אחרי ההצבה $`\lambda(n) \equiv \frac{\varphi(n)}{\,\Gamma(1+n)\,}`$ ושימוש במשוואה הפונקציונלית של פונקציית גמא.

(**פירוט:** לפי נוסחת ההשתקפות של אוילר, $`\Gamma(s)\Gamma(1-s) = \pi/\sin(\pi s)`$, ולכן $`\Gamma(s)\varphi(-s) = \Gamma(s)\Gamma(1-s)\lambda(-s) = \frac{\pi}{\sin \pi s}\lambda(-s)`$. למשל עבור $`\lambda \equiv 1`$ מתקבל $`\int_0^\infty \frac{x^{s-1} }{1+x}\,dx = \frac{\pi}{\sin \pi s}`$.)

האינטגרל שלמעלה מתכנס עבור $`0 \lt \mathrm{Re}(s) \lt 1`$, בכפוף לתנאי גידול על $`\varphi`$.[^4]

## הוכחה

הוכחה בהנחות "טבעיות" (אף שאינן התנאים החלשים ביותר הנדרשים) של משפט המאסטר של רמנוג'ן נתן [ג'. ה. הרדי](https://he.wikipedia.org/wiki/%D7%92%D7%95%D7%93%D7%A4%D7%A8%D7%99_%D7%94%D7%A8%D7%95%D7%9C%D7%93_%D7%94%D7%90%D7%A8%D7%93%D7%99)[^5] (פרק XI), תוך שימוש ב[משפט השאריות](https://he.wikipedia.org/wiki/%D7%9E%D7%A9%D7%A4%D7%98_%D7%94%D7%A9%D7%90%D7%A8%D7%99%D7%95%D7%AA) וב[משפט ההיפוך של מלין](%D7%94%D7%AA%D7%9E%D7%A8%D7%AA%20%D7%9E%D7%9C%D7%99%D7%9F.md) הידוע.

### ההוכחה של רמנוג'ן[^6]

נזכיר את ההצגה של אוילר לפונקציית גמא:



```math
\int_0^\infty x^{n-1}e^{-mx}\,dx=m^{-n}\Gamma(n).
```

 בוחרים $`m=r^k`$, כופלים את שני האגפים ב-$`\frac{f^{(k)}(a)h^k}{k!}`$ (כאן $`f^{(k)}`$ היא הנגזרת ה-$`k`$-ית) ומסכמים על $`k \ge 0`$:



```math
\sum_{k=0}^\infty\frac{f^{(k)}(a)h^k}{k!}\int_0^\infty x^{n-1}e^{-r^kx}\,dx=\Gamma(n)\sum_{k=0}^\infty\frac{f^{(k)}(a)(hr^{-n})^k}{k!}.
```

 הסכום באגף ימין הוא [טור טיילור](https://he.wikipedia.org/wiki/%D7%98%D7%95%D7%A8_%D7%98%D7%99%D7%99%D7%9C%D7%95%D7%A8), ושווה ל-$`f(a + hr^{-n})`$. כותבים את $`e^{-r^kx}`$ כטור:



```math
\sum_{k=0}^\infty\frac{f^{(k)}(a)h^k}{k!}\int_0^\infty x^{n-1}\sum_{j=0}^\infty \frac{(-r^kx)^j}{j!}\,dx=\Gamma(n)f(hr^{-n}+a).
```

 משנים את סדר הסכימה באגף שמאל:



```math
\sum_{j=0}^\infty \frac{(-1)^j}{j!}\int_0^\infty x^{n-1+j} \sum_{k=0}^\infty \frac{f^{(k)}(a)(hr^j)^k}{k!}\,dx=\Gamma(n)f(hr^{-n}+a).
```

 שוב הסכום על $`k`$ הוא טור טיילור, ושווה ל-$`f(a + hr^j)`$:



```math
\int_0^\infty x^{n-1}\sum_{j=0}^\infty \frac{f(hr^j+a)(-x)^j}{j!}\,dx=\Gamma(n)f(hr^{-n}+a).
```

 (בערך האנגלי נכתב כאן בטעות $`f^{k}(hr^j+a)`$; אחרי סכימת טור טיילור לא נשארת נגזרת.) לבסוף מגדירים $`\phi(N) = f(hr^{N}+a)`$ ו-$`F(x)=\sum_{j=0}^\infty \frac{\phi(j)(-x)^j}{j!}`$, ומקבלים את משפט המאסטר:



```math
\int_0^\infty x^{n-1}F(x)\,dx=\Gamma(n)\phi(-n).
```

 (הטיעון הוא פורמלי: החלפות סדר הסכימה והאינטגרציה אינן מוצדקות בו. לכן נדרשת הוכחה קפדנית כמו זו של הרדי.)

### ההוכחה של הרדי[^7]

תהי $`\lambda(z)`$ פונקציה אנליטית חד-ערכית המוגדרת על חצי המישור



```math
H(\delta) = \left\{z\in \mathbb{C} : \mathrm{Re}(z)\ge - \delta \right\}
```

 עבור $`0 \lt \delta \lt 1`$ כלשהו. נניח שעבור $`A \lt \pi`$ כלשהו, $`\lambda`$ מקיימת את תנאי הגידול



```math
|\lambda(v+iw)| \lt Ce^{Pv+A|w|}
```

 לכל $`z=v+iw \in H(\delta)`$. יהי $`0 \lt x \lt e^{-P}`$. מכאן שהטור $`F(x)=\sum_{n=0}^\infty (-x)^n\lambda(n)`$ מתכנס. מכיוון של-$`\frac{\pi}{\sin(\pi s)}`$ יש קטבים בנקודות $`s = -n`$, $`n = 0, 1, 2, \ldots`$, עם שארית $`(-1)^n`$, משפט השאריות נותן



```math
F(x)=\frac{1}{2\pi i}\int_{c-i\infty}^{c+i\infty}\frac{\pi}{\sin(\pi s)}\lambda(-s)x^{-s}\,ds
```

 לכל $`0 \lt c \lt \delta`$. האינטגרל הזה מתכנס בהחלט ובמידה שווה עבור $`c\in(a,b)`$, לכל $`0 \lt a \lt b \lt \delta`$. הפעלת משפט ההיפוך של מלין נותנת



```math
\int_0^\infty x^{s-1}F(x)\,dx=\frac{\pi}{\sin(\pi s)}\lambda(-s).
```

 (**למה התנאי $`A \lt \pi`$:** על הישר $`s = c + iw`$ מתקיים $`|\pi/\sin(\pi s)| \approx 2\pi e^{-\pi|w|}`$, ולכן הגורם $`e^{A|w|}`$ מ-$`\lambda`$ נבלע, והאינטגרנד דועך מעריכית.)

## יישום לפולינומי ברנולי

ה[פונקציה יוצרת](https://he.wikipedia.org/wiki/%D7%A4%D7%95%D7%A0%D7%A7%D7%A6%D7%99%D7%94_%D7%99%D7%95%D7%A6%D7%A8%D7%AA) של פולינומי ברנולי $`B_k(x)`$ נתונה על ידי:



```math
\frac{z\,e^{x\,z} }{\,e^z - 1\,}=\sum_{k=0}^\infty B_k(x)\,\frac{z^k}{k!}.
```

 את הפולינומים האלה אפשר לבטא בעזרת [פונקציית זטא של הורוויץ](%D7%A4%D7%95%D7%A0%D7%A7%D7%A6%D7%99%D7%99%D7%AA%20%D7%96%D7%98%D7%90%20%D7%A9%D7%9C%20%D7%94%D7%95%D7%A8%D7%95%D7%95%D7%99%D7%A5.md):



```math
\zeta(s,a) = \sum_{n=0}^\infty \frac{1}{\,(n+a)^s\,}
```

 על ידי $`\zeta(1-n,a) = -\frac{B_n(a)}{n}`$ עבור $`n \geq 1`$. בעזרת משפט המאסטר של רמנוג'ן והפונקציה היוצרת של פולינומי ברנולי מקבלים את ההצגה האינטגרלית הבאה:[^8]



```math
\int_0^\infty x^{s-1}\left(\frac{e^{-ax} }{\,1 - e^{-x}\,}-\frac{1}{x}\right) dx = \Gamma(s)\,\zeta(s,a)
```

 התקפה עבור $`0 \lt \mathrm{Re}(s) \lt 1`$. (בדיקה מספרית: עבור $`s = 1/2`$, $`a = 0.3`$ שני האגפים שווים ל-$`0.0197677884\ldots`$.)

## יישום לפונקציית גמא

ההגדרה של ויירשטראס לפונקציית גמא



```math
\Gamma(x) = \frac{\,e^{-\gamma\,x\,} }{x}\,\prod_{n=1}^\infty \left(\,1 + \frac{x}{n}\,\right)^{-1} e^{x/n}
```

 שקולה לביטוי



```math
\log\Gamma(1+x) = -\gamma\,x + \sum_{k=2}^\infty \frac{\,\zeta(k)\,}{k}\,(-x)^k
```

 כאשר $`\zeta(k)`$ היא [פונקציית זטא של רימן](https://he.wikipedia.org/wiki/%D7%A4%D7%95%D7%A0%D7%A7%D7%A6%D7%99%D7%99%D7%AA_%D7%96%D7%98%D7%90_%D7%A9%D7%9C_%D7%A8%D7%99%D7%9E%D7%9F) ו-$`\gamma`$ [קבוע אוילר-מסקרוני](https://he.wikipedia.org/wiki/%D7%A7%D7%91%D7%95%D7%A2_%D7%90%D7%95%D7%99%D7%9C%D7%A8-%D7%9E%D7%A1%D7%A7%D7%A8%D7%95%D7%A0%D7%99).

אם מפעילים את משפט המאסטר של רמנוג'ן (בניסוח החלופי, עם $`\lambda(n) = \zeta(n+2)/(n+2)`$), מקבלים:



```math
\int_0^\infty x^{s-1} \frac{\,\gamma\,x + \log\Gamma(1+x)\,}{x^2}\, dx = \frac{\pi}{\sin(\pi s)}\frac{\zeta(2-s)}{2-s}
```

 התקף עבור $`0 \lt \mathrm{Re}(s) \lt 1`$.

המקרים הפרטיים $`s = \frac{1}{2}`$ ו-$`s = \frac{3}{4}`$ הם



```math
\int_0^\infty \frac{\,\gamma x+\log\Gamma(1+x)\,}{x^{5/2} } \, dx = \frac{2\pi}{3}\,\zeta\left( \frac{3}{2} \right) \approx 5.4713461
```





```math
\int_0^\infty \frac{\,\gamma\,x+\log\Gamma(1+x)\,}{x^{9/4} } \, dx = \sqrt{2}\, \frac{4\pi}{5} \zeta\left(\frac 5 4\right) \approx 16.332435
```

 (הערכים המספריים נבדקו באינטגרציה נומרית.)

## יישום לפונקציות בסל

ל[פונקציית בסל](https://he.wikipedia.org/wiki/%D7%A4%D7%95%D7%A0%D7%A7%D7%A6%D7%99%D7%95%D7%AA_%D7%91%D7%A1%D7%9C) מהסוג הראשון יש [טור החזקות](https://he.wikipedia.org/wiki/%D7%98%D7%95%D7%A8_%D7%97%D7%96%D7%A7%D7%95%D7%AA)



```math
J_\nu(z)=\sum_{k=0}^\infty \frac{(-1)^k}{\Gamma(k+\nu+1)k!}\bigg(\frac{z}{2}\bigg)^{2k+\nu}.
```

 בעזרת משפט המאסטר של רמנוג'ן, יחד עם כמה זהויות של פונקציית גמא וסידור מחדש, אפשר לחשב את האינטגרל



```math
\frac{2^{\nu-2s}\pi}{\sin{(\pi(s-\nu))} } \int_0^\infty z^{s-1-\nu/2}J_\nu(\sqrt{z})\,dz = \Gamma(s)\Gamma(s-\nu)
```

 התקף עבור $`0 \lt 2\,\mathrm{Re}(s) \lt \mathrm{Re}(\nu)+\tfrac{3}{2}`$.

באופן שקול, אם מעדיפים את [פונקציית בסל הספרית](https://he.wikipedia.org/wiki/%D7%A4%D7%95%D7%A0%D7%A7%D7%A6%D7%99%D7%95%D7%AA_%D7%91%D7%A1%D7%9C) $`j_\nu(z)`$, הנוסחה הופכת ל



```math
\frac{2^{\nu-2s}\sqrt{\pi}(1-2s+2\nu)}{\cos{(\pi(s-\nu))} } \int_0^\infty z^{s-1-\nu/2}j_\nu(\sqrt{z})\,dz = \Gamma(s)\Gamma\bigg(\frac{1}{2}+s-\nu\bigg)
```

 התקפה עבור $`0 \lt 2\,\mathrm{Re}(s) \lt \mathrm{Re}(\nu)+2`$. (שתי הנוסחאות נבדקו מספרית, למשל עבור $`\nu = 1, s = 0.8`$ ועבור $`\nu = 0.5, s = 0.7`$.)

הפתרון מרשים בכך שהוא מצליח "לעבור" בין הזהויות העיקריות של פונקציית גמא. בפרט, הבחירה $`J_{1/2}(\sqrt z)`$ נותנת את הריבוע של פונקציית גמא, $`j_0(\sqrt{z})`$ נותנת את נוסחת ההכפלה, $`z^{-1/2}J_{1}(\sqrt z)`$ נותנת את נוסחת ההשתקפות, וקיבוע לערך הניתן לחישוב $`s=\frac{1}{2}`$ או $`s=1`$ נותן את פונקציית גמא עצמה, עד כדי השתקפות ושינוי קנה מידה.

## שיטת האינטגרציה בסוגריים

**שיטת האינטגרציה בסוגריים** (method of brackets) מפעילה את משפט המאסטר של רמנוג'ן על מגוון רחב של אינטגרלים.[^9] השיטה מייצרת את [פיתוח הטור](https://he.wikipedia.org/wiki/%D7%98%D7%95%D7%A8_%D7%97%D7%96%D7%A7%D7%95%D7%AA) של האינטגרנד, בונה ממנו "טור סוגריים", מזהה את המקדם של הטור ואת הפרמטרים של הנוסחה, ומחשבת את האינטגרל.[^10]

### נוסחאות אינטגרציה

הפרק הזה מציג את נוסחאות האינטגרציה עבור אינטגרנדים עם מעריכים שלמים עוקבים ובלעדיהם, ועבור אינטגרלים יחידים וכפולים. אפשר להכליל את נוסחת האינטגרציה לאינטגרלים כפולים לכל אינטגרל מרובה. בכל המקרים יש ערך פרמטר $`n^{\ast}`$, או מערך של ערכי פרמטרים $`N^{\ast}`$, שפותר [משוואה ליניארית](https://he.wikipedia.org/wiki/%D7%9E%D7%A9%D7%95%D7%95%D7%90%D7%94_%D7%9C%D7%99%D7%A0%D7%99%D7%90%D7%A8%D7%99%D7%AA) אחת או יותר הנגזרות מהמעריכים בפיתוח הטור של האינטגרנד.

#### מעריכים שלמים עוקבים, משתנה אחד

זהו פיתוח הטור, האינטגרל ונוסחת האינטגרציה עבור אינטגרל שפיתוח הטור של האינטגרנד שלו מכיל מעריכים שלמים עוקבים:[^11]



```math
\begin{align}
&f(y)=\sum_{n=0}^\infty \frac{(-1)^{n} }{n!} \ \varphi(n) \ y^{n} \\
&\int_0^\infty y^{c-1} f(y) \, dy \\
&= \int_0^\infty \sum_{n=0}^\infty \frac{(-1)^{n} }{n!} \ \varphi(n) \ y^{n+c-1} dy \\
&=\Gamma(-n^{\ast})\,\varphi(n^{\ast}).
\end{align}
```

 הפרמטר $`n^{\ast}`$ הוא פתרון של המשוואה הליניארית



```math
n^{\ast}+c=0, \quad n^{\ast}= -c.
```

 (זהו בדיוק משפט המאסטר, עם $`s = c`$.)

#### מעריכים כלליים, משתנה אחד

ההצבה $`y=x^{a}`$ נותנת את פיתוח הטור, האינטגרל ונוסחת האינטגרציה עבור אינטגרל שפיתוח הטור של האינטגרנד שלו עשוי שלא להכיל מעריכים שלמים עוקבים:[^12]



```math
\begin{align}
&f(x)=\sum_{n=0}^\infty \frac{(-1)^{n} }{n!} \ \varphi(n) \ x^{an} \\
&\int_0^\infty x^{c-1} f(x) \, dx \\
&=\int_0^\infty \sum_{n=0}^\infty \frac{(-1)^{n} }{n!} \ \varphi(n) \ x^{an+c-1} dx \\
&=a^{-1} \ \Gamma(-n^{\ast})\,\varphi(n^{\ast}).
\end{align}
```

 הפרמטר $`n^{\ast}`$ הוא פתרון של המשוואה הליניארית



```math
a \, n^{\ast}+c=0, \quad n^{\ast}=-a^{-1} c.
```



#### מעריכים שלמים עוקבים, אינטגרל כפול

זהו פיתוח הטור, האינטגרל ונוסחת האינטגרציה עבור אינטגרל כפול שפיתוח הטור של האינטגרנד שלו מכיל מעריכים שלמים עוקבים:[^13]



```math
\begin{align} &f(y_{1},y_{2})=\sum_{n_1=0}^\infty \sum_{n_2=0}^\infty \frac{(-1)^{n_{1} } }{n_{1}!} \frac{(-1)^{n_{2} } }{n_{2}!} \ \varphi(n_{1},n_{2}) \ y_{1}^{n_{1} } \ y_{2}^{n_{2} } \\
&\int_0^\infty \int_0^\infty y^{c_{1}-1}_{1} y^{c_{2}-1}_{2} \ f(y_{1},y_{2}) \ dy_{1} \ dy_{2} \\
&=\int_0^\infty \int_0^\infty \sum^\infty_{n_{1}=0} \sum^\infty_{n_{2}=0} \frac{(-1)^{n_{1} } }{n_{1}!} \frac{(-1)^{n_{2} } }{n_{2}!} \ \varphi(n_{1},n_{2}) \ y_{1}^{n_{1}+c_{1}-1} \ y_{2}^{n_{2}+c_{2}-1} \ dy_{1} \ dy_{2} \\
&=\Gamma(-n^{\ast}_{1}) \ \Gamma(-n^{\ast}_{2}) \ \varphi(n^{\ast}_{1},n^{\ast}_{2}).
\end{align}
```

 הפרמטרים $`n^{\ast}_{1}`$ ו-$`n^{\ast}_{2}`$ הם פתרונות של המשוואות הליניאריות



```math
n^{\ast}_{1}+c_{1}=0, \quad n^{\ast}_{2}+c_{2}=0, \quad n^{\ast}_{1}=-c_{1}, \quad n^{\ast}_{2}=-c_{2}.
```



#### מעריכים כלליים, אינטגרל כפול

הפרק הזה מתאר את נוסחת האינטגרציה עבור אינטגרל כפול שפיתוח הטור של האינטגרנד שלו עשוי שלא להכיל מעריכים שלמים עוקבים. ה[מטריצות](https://he.wikipedia.org/wiki/%D7%9E%D7%98%D7%A8%D7%99%D7%A6%D7%94) מכילות את הפרמטרים הדרושים כדי לבטא את המעריכים בפיתוח הטור של האינטגרנד, וה[דטרמיננטה](https://he.wikipedia.org/wiki/%D7%93%D7%98%D7%A8%D7%9E%D7%99%D7%A0%D7%A0%D7%98%D7%94) של ה[מטריצה ההפיכה](https://he.wikipedia.org/wiki/%D7%9E%D7%98%D7%A8%D7%99%D7%A6%D7%94_%D7%94%D7%A4%D7%99%D7%9B%D7%94) $`A`$ מסומנת $`\det|A|`$:[^14]



```math
A= \begin{pmatrix} a_{11} & a_{12} \\ a_{21} & a_{22} \end{pmatrix}, \quad C= \begin{pmatrix} c_{1} \\ c_{2} \end{pmatrix}, \quad N^{\ast}= \begin{pmatrix} n^{\ast}_{1} \\ n^{\ast}_{2} \end{pmatrix}.
```

 ההצבה



```math
y_{1}=x^{a_{11} }_{1} x^{a_{21} }_{2}, \quad y_{2}=x^{a_{12} }_{1} x^{a_{22} }_{2}
```

 נותנת את פיתוח הטור, האינטגרל ונוסחת האינטגרציה עבור אינטגרל כפול שפיתוח הטור של האינטגרנד שלו עשוי שלא להכיל מעריכים שלמים עוקבים.[^15] האינטגרל ונוסחת האינטגרציה הם[^16]



```math
\begin{align}
&\int_0^\infty \int_0^\infty \sum^\infty_{n_{1}=0} \sum^\infty_{n_{2}=0} \frac{(-1)^{n_{1} } }{n_{1}!} \frac{(-1)^{n_{2} } }{n_{2}!} \ \varphi(n_{1},n_{2}) \ x_{1}^{n_{1}a_{11}+n_{2}a_{12}+c_{1}-1} \ x_{2}^{n_{1}a_{21}+n_{2}a_{22}+c_{2}-1} \ dx_{1} \ dx_{2} \\
&=\det|A|^{-1} \ \Gamma(-n^{\ast}_{1}) \ \Gamma(-n^{\ast}_{2}) \ \varphi(n^{\ast}_{1},n^{\ast}_{2}).
\end{align}
```

 מטריצת הפרמטרים $`N^{\ast}`$ היא פתרון של המשוואה הליניארית[^17]



```math
AN^{\ast}+C=0, \quad N^{\ast}=-A^{-1} C.
```



#### מדד סיבוכיות חיובי

במקרים מסוימים יש יותר סכומים ממשתנים. למשל, אם האינטגרנד הוא מכפלה של 3 פונקציות של אותו משתנה, וכל פונקציה מומרת לפיתוח טור, האינטגרנד הופך למכפלה של 3 סכומים, שכל אחד מהם מתאים לפיתוח טור אחר.

- **מספר הסוגריים** הוא מספר המשוואות הליניאריות הקשורות לאינטגרל. המונח משקף את הנוהג המקובל לסמן כל משוואה ליניארית בסוגריים.[^18]
- **מדד הסיבוכיות** הוא מספר הסכומים באינטגרנד פחות מספר הסוגריים (המשוואות הליניאריות). כל פיתוח טור של האינטגרנד תורם סכום אחד.[^19]
- **אינדקסי הסכימה** הם האינדקסים שממספרים את האיברים בפיתוח טור. בדוגמה יש 3 אינדקסי סכימה $`n_{1}, n_{2}`$ ו-$`n_{3}`$, כי האינטגרנד הוא מכפלה של 3 פיתוחי טור.[^20]
- **אינדקסי הסכימה החופשיים** הם אינדקסי הסכימה שנשארים אחרי שמסיימים את כל האינטגרציות. האינטגרציה מקטינה את מספר הסכומים באינטגרנד, כי היא מחליפה פיתוחי טור (סכומים) בנוסחת אינטגרציה. לכן אחרי האינטגרציה יש פחות אינדקסי סכימה. מספר אינדקסי הסכימה החופשיים שנבחרים שווה למדד הסיבוכיות.[^21]

#### אינטגרלים עם מדד סיבוכיות חיובי

אינדקסי הסכימה החופשיים $`\bar{n}_{1},\ldots, \bar{n}_{f}`$ הם איברי הקבוצה $`F`$. מטריצת אינדקסי הסכימה החופשיים היא $`\bar{N}`$, ומטריצת המקדמים שלהם היא $`\bar{A}`$:



```math
\bar{A}= \begin{pmatrix} \bar{a}_{11} & \ldots &\bar{a}_{1f}
\\ \vdots & & \vdots \\
\bar{a}_{b1} & \ldots & \bar{a}_{bf} \end{pmatrix}, \quad \bar{N}= \begin{pmatrix} \bar{n}_{1} \\ \vdots \\ \bar{n}_{f} \end{pmatrix}.
```

 שאר האינדקסים הם הקבוצה $`B`$, המכילה את האינדקסים $`n_{1},\ldots, n_{b}`$. המטריצות $`A, C`$ ו-$`N^{\ast}`$ מכילות את האיברים שמוכפלים באינדקסים שאינם חופשיים או מתווספים להם. האינדקסים החופשיים שנבחרים צריכים להשאיר את המטריצה $`A`$ הפיכה.



```math
A= \begin{pmatrix} a_{11} & \ldots &a_{1b} \\ \vdots & & \vdots \\
a_{b1} & \ldots & a_{bb} \end{pmatrix}, \quad C= \begin{pmatrix} c_{1} \\ \vdots \\ c_{b} \end{pmatrix}, \quad N^{\ast}= \begin{pmatrix} n^{\ast}_{1} \\ \vdots \\ n^{\ast}_{b} \end{pmatrix}.
```

 זהו פיתוח הטור של הפונקציה, האינטגרל ונוסחת האינטגרציה:[^22]



```math
\begin{align}
&f(x_{1}, \ldots, x_{b})\\
&=\sum_{n \in B} \sum_{\bar{n} \in F} \frac{(-1)^{n_{1} } }{n_{1}!} \frac{(-1)^{\bar{n}_{1} } }{\bar{n}_{1}!}
\cdots
\frac{(-1)^{n_{b} } }{n_{b}!} \frac{(-1)^{\bar{n}_{f} } }{\bar{n}_{f}!}\, \varphi(n_{1}, \ldots, n_{b}, \bar{n}_{1}, \dots, \bar{n}_{f})\prod_{k=1}^{b} x_{k}^{n_{1}a_{k1}+ \dots + \bar{n}_{1}\bar{a}_{k1}+ \dots + c_{k}-1} \\
&\int^{\infty}_{0} \cdots \int^{\infty}_{0} f(x_{1}, \ldots, x_{b}) \ dx_{1} \cdots dx_{b} \\
&=\det|A|^{-1} \sum_{\bar{n} \in F} \frac{(-1)^{\bar{n}_{1} } }{\bar{n}_{1}!}
\cdots
\frac{(-1)^{\bar{n}_{f} } }{\bar{n}_{f}!}
\ \Gamma(-n^{\ast}_{1}) \cdots \Gamma(-n^{\ast}_{b}) \ \varphi(n^{\ast}_{1}, \ldots, n^{\ast}_{b}, \bar{n}_{1}, \dots, \bar{n}_{f}).
\end{align}
```

 הפרמטרים $`n^{\ast}_{1}, \ldots, n^{\ast}_{b}`$ הם פונקציות ליניאריות של הפרמטרים $`\bar{n}_{1}, \ldots, \bar{n}_{f}`$:[^23]



```math
A \, N^{\ast}+\bar{A} \, \bar{N}+C=0, \quad N^{\ast}= -A^{-1}(\bar{A} \, \bar{N}+C).
```

 (בערך האנגלי מופיע לפני האינטגרל גם הגורם $`x^{c_1-1}\cdots x^{c_b-1}`$, אבל הגורמים האלה כבר כלולים במעריכים של $`f`$; השמטנו את הכפילות.)

### טור סוגריים

| סוג הסימון  | סימון טור חזקות                                                 | סימון טור סוגריים                                   |
|-------------|-----------------------------------------------------------------|-----------------------------------------------------|
| מציין       | $`\frac{(-1)^n}{n !}`$                                            | $`\phi_{n}`$                                          |
| מציין מרובה | $`\prod_{j=1}^N \left( \frac{(-1)^{n_{j} } }{n_{j}!} \right)`$    | $`\phi_{n_1,\ldots ,n_N}`$                            |
| סוגר        | $`\int^{\infty}_{0} dx \ x^{a_{1}n_{1}+ \ldots +a_{m}n_{m}+c-1}`$ | $`\langle a_{1}n_{1}+ \ldots + a_{m}n_{m}+c \rangle`$ |

טבלה 1. סימוני טור סוגריים

**סימוני טור סוגריים** הם סימונים שמחליפים סימונים מקובלים של טורי חזקות (טבלה 1).[^24] החלפת סימוני טור החזקות בסימוני טור סוגריים הופכת את טור החזקות לטור סוגריים. טור סוגריים מקל לזהות את הפרמטרים של הנוסחה הדרושים לאינטגרציה. מומלץ גם להחליף סכום המועלה בחזקה:[^25]



```math
\frac{1}{(x_{1}+ \ldots +x_{b})^{\alpha} }
```

 בביטוי טור הסוגריים הבא:



```math
\sum^{\infty}_{m_{1}=0} \ldots \sum^{\infty}_{m_{b}=0} \ \phi_{m_1, \dots,m_b} \ x^{m_{1} }_{1} \dots x^{m_{b} }_{b}\frac{\langle \alpha+m_{1}+ \ldots +m_{b} \rangle}{\Gamma(\alpha)}.
```

 (**מקור הנוסחה (הסבר נוסף):** מתחילים מ-$`\frac{1}{X^\alpha} = \frac{1}{\Gamma(\alpha)}\int_0^\infty t^{\alpha-1}e^{-tX}\,dt`$, עם $`X = x_1 + \cdots + x_b`$; מפתחים כל $`e^{-t x_j}`$ לטור, והאינטגרל על $`t`$ הוא בדיוק הסוגר $`\langle \alpha + m_1 + \cdots + m_b\rangle`$.)

טבלה 2. נוסחאות אינטגרציה

  
**קלט:** ביטוי של אינטגרל.

**פלט:** ערך האינטגרל, או הודעה שאי אפשר לייחס לאינטגרל ערך.

1.  מבטאים את האינטגרנד כטור חזקות.
2.  הופכים את טור החזקות של האינטגרנד לטור סוגריים.
3.  מוצאים את מדד הסיבוכיות, את הפרמטרים של הנוסחה ואת פונקציית המקדם של הטור.
    1.  מדד הסיבוכיות הוא מספר הסכומים באינטגרנד פחות מספר הסוגריים.
    2.  הפרמטרים $`n^{\ast}`$ או המערך $`N^{\ast}`$ הם פתרונות של המשוואות הליניאריות $`an^{\ast}+c=0`$ (מדד סיבוכיות אפס, אינטגרל יחיד), $`AN^{\ast}+C=0`$ (מדד סיבוכיות אפס, אינטגרל מרובה) או $`AN^{\ast}+\bar{A} \bar{N}+C=0`$ (מדד סיבוכיות חיובי). (בערך האנגלי נכתב בטעות "אינטגרל יחיד" גם במקרה השני.)
    3.  מזהים את הפרמטר $`a`$ (מדד סיבוכיות אפס, אינטגרל יחיד) או מחשבים את $`\det |A|`$ (בכל שאר המקרים) מהמשוואות הליניאריות המתאימות.
    4.  מזהים את פונקציית המקדם $`\varphi`$ של טור הסוגריים.
4.  אם מדד הסיבוכיות שלילי, מחזירים שאי אפשר לייחס לאינטגרל ערך.
5.  אם מדד הסיבוכיות אפס, בוחרים מטבלה 2 את הנוסחה למדד סיבוכיות אפס, אינטגרל יחיד או מרובה, מחשבים בעזרתה את ערך האינטגרל ומחזירים אותו.
6.  אם מדד הסיבוכיות חיובי, בוחרים מטבלה 2 את הנוסחה למדד סיבוכיות חיובי, ומחשבים בעזרתה את ערך האינטגרל כפיתוח טור, עבור כל הבחירות האפשריות של אינדקסי הסכימה החופשיים. בוחרים את פיתוחי הטור ה[מתכנסים](https://he.wikipedia.org/wiki/%D7%98%D7%95%D7%A8_%D7%9E%D7%AA%D7%9B%D7%A0%D7%A1) בעלי מדד הסיבוכיות הנמוך ביותר, ומחברים טורים שמתכנסים באותו תחום.
    1.  אם כל פיתוחי הטור מתבדרים או אפסים (כל איברי הטור אפס), מחזירים שאי אפשר לייחס לאינטגרל ערך.
    2.  אם פיתוח הטור אינו אפס ואינו מתבדר, מחזירים אותו כערך האינטגרל.

### דוגמאות

#### מדד סיבוכיות אפס

שיטת הסוגריים תחשב את האינטגרל



```math
\int_0^\infty x^{3/2} \ e^{-x^3/2} \ dx.
```



1.  מבטאים את האינטגרנד כטור חזקות: $`\int_0^\infty \sum_{n=0}^\infty 2^{-n} \frac{(-1)^n}{n!} \ x^{(3 n+5/2)-1} \ dx.`$
2.  הופכים את טור החזקות לטור סוגריים: $`\sum_{n=0}^\infty 2^{-n} \ \phi_n \cdot \left \langle 3 n+ \tfrac{5}{2} \right \rangle.`$
3.  מוצאים את מדד הסיבוכיות, את הפרמטרים ואת פונקציית המקדם: מדד הסיבוכיות הוא אפס (סכום אחד, סוגר אחד); $`3 n^{\ast}+ 5/2=0`$, כלומר $`n^{\ast}= -5/6`$ ו-$`a=3`$; ו-$`\varphi(n)=2^{-n}`$.
4.  משתמשים בטבלה 2 כדי לחשב את האינטגרל:



```math
\int_0^\infty x^{3/2} \, e^{-x^3/2} \, dx = a^{-1} \ \Gamma(-n^{\ast}) \ \varphi(n^{\ast}) = \frac{\Gamma \left(\frac{5}{6} \right) \ 2^{5/6} }{3} \approx 0.6704233.
```

 (בדיקה: הצבה $`u = x^3/2`$ נותנת את אותה תוצאה ישירות, ואינטגרציה נומרית מאשרת את הערך.)

#### מדד סיבוכיות חיובי

שיטת הסוגריים תחשב את האינטגרל



```math
\int^{\infty}_{0} \frac{1}{(1+x^{3}+x^{5})^{1/2} } \ dx.
```

 1. מבטאים את האינטגרנד כטור חזקות, בעזרת הנוסחה לסכום המועלה בחזקה (עם $`x_1 = 1`$, $`x_2 = x^5`$, $`x_3 = x^3`$ ו-$`\alpha = 1/2`$):



```math
\int^{\infty}_{0} \sum_{n_1,n_2,n_3} \ \frac{1}{\Gamma(1/2)}\, \phi_{n_1,n_2,n_3}\, 1^{n_{1} } x^{5n_{2}+ 3n_{3} } \langle n_{1}+n_{2}+n_{3}+1/2 \rangle \ dx.
```

 2. הופכים את טור החזקות לטור סוגריים:



```math
\sum_{n_1,n_2,n_3} \frac{1}{\Gamma(1/2)}\, \phi_{n_1,n_2,n_3} \langle 5 n_{2}+ 3 n_{3}+1 \rangle \langle n_{1}+n_{2}+n_{3}+1/2 \rangle.
```

 3. מוצאים את מדד הסיבוכיות, את הפרמטרים ואת פונקציית המקדם. מדד הסיבוכיות הוא 1, כי יש 3 סכומים ו-2 סוגריים. בוחרים את $`n_{3}`$ כאינדקס החופשי $`\bar{n}_{3}`$. המשוואות הליניאריות, הפתרונות, הדטרמיננטה ומקדם הטור הם:



```math
5n^{\ast}_{2}+ 3 \bar{n}_{3}+1=0, \quad n^{\ast}_{1}+n^{\ast}_{2}+\bar{n}_{3}+1/2=0,
```





```math
\begin{pmatrix} 1 & 1 \\ 0 & 5 \end{pmatrix} \begin{pmatrix} n^{\ast}_{1} \\ n^{\ast}_{2} \end{pmatrix}
+ \begin{pmatrix} 1 \\ 3 \end{pmatrix} \bar{n}_{3}+ \begin{pmatrix} 1/2 \\ 1 \end{pmatrix} =0, \quad\text{i.e.}\quad AN^{\ast} + \bar{A} \bar{N} + C =0,
```





```math
\det |A|=5, \qquad n^{\ast}_{1}= -\frac{2}{5} \bar{n}_{3}-\frac{3}{10}, \quad n^{\ast}_{2}= -\frac{3}{5} \bar{n}_{3}-\frac{1}{5},
```





```math
\varphi(n^{\ast}_{1},n^{\ast}_{2}, \bar{n}_{3})= \frac{1}{\Gamma(1/2)}=\frac{1}{\sqrt{\pi} }.
```

 (בערך האנגלי נכתב בטעות $`1/\sqrt{\Gamma(1/2)}`$ בשלבים 1–3; המקדם הנכון לפי נוסחת הסכום המועלה בחזקה הוא $`1/\Gamma(1/2) = 1/\sqrt\pi`$, וזה מה שמופיע בתוצאה הסופית.)

4\. משתמשים בטבלה 2 כדי לחשב את האינטגרל:



```math
\begin{align}
\int^{\infty}_{0} \frac{dx}{(1+x^{3}+x^{5})^{1/2} }
&=\sum^{\infty}_{\bar{n}_{3}=0} \frac{(-1)^{\bar{n}_{3} } }{\bar{n}_{3}!} \det |A|^{-1}\Gamma(-n^{\ast}_{1}) \Gamma(-n^{\ast}_{2})
\varphi(n^{\ast}_{1},n^{\ast}_{2},\bar{n}_{3}) \\
&=\sum^{\infty}_{\bar{n}_{3}=0}\frac{(-1)^{\bar{n}_{3} } }{\bar{n}_{3}!} \frac{\Gamma(\frac{2}{5} \bar{n}_{3}+\frac{3}{10})\,\Gamma(\frac{3}{5} \bar{n}_{3}+\frac{1}{5})}{5 \sqrt{\pi} } \approx 1.4147248.
\end{align}
```

 (בדיקה, נוסף בתרגום: הטור מתכנס, כי $`\Gamma(\tfrac25 n)\Gamma(\tfrac35 n)/n!`$ דועך בערך כמו $`\big((2/5)^{2/5}(3/5)^{3/5}\big)^n \approx 0.51^n`$ לפי [נוסחת סטירלינג](https://he.wikipedia.org/wiki/%D7%A0%D7%95%D7%A1%D7%97%D7%AA_%D7%A1%D7%98%D7%A8%D7%9C%D7%99%D7%A0%D7%92). סכום הטור שווה לערך האינטגרל המחושב נומרית, $`1.414724796\ldots`$, בכל הספרות שנבדקו.)
