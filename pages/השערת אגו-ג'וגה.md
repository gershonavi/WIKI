# השערת אגו-ג'וגה

ב[תורת המספרים](https://he.wikipedia.org/wiki/%D7%AA%D7%95%D7%A8%D7%AA_%D7%94%D7%9E%D7%A1%D7%A4%D7%A8%D7%99%D7%9D), **השערת אגו–ג'וגה** (ב[אנגלית](https://he.wikipedia.org/wiki/%D7%90%D7%A0%D7%92%D7%9C%D7%99%D7%AA): Agoh–Giuga conjecture) על [מספרי ברנולי](https://he.wikipedia.org/wiki/%D7%9E%D7%A1%D7%A4%D7%A8%D7%99_%D7%91%D7%A8%D7%A0%D7%95%D7%9C%D7%99) $`B_k`$ קובעת ש-$`p`$ הוא [מספר ראשוני](https://he.wikipedia.org/wiki/%D7%9E%D7%A1%D7%A4%D7%A8_%D7%A8%D7%90%D7%A9%D7%95%D7%A0%D7%99) [אם ורק אם](https://he.wikipedia.org/wiki/%D7%90%D7%9D_%D7%95%D7%A8%D7%A7_%D7%90%D7%9D)



```math
pB_{p-1} \equiv -1 \pmod p.
```

 ההשערה קרויה על שם טקשי אגו וג'וזפה ג'וגה.

## ניסוח שקול

ההשערה בניסוח שלמעלה היא של טקשי אגו.[^1] ניסוח שקול הציע ג'וזפה ג'וגה ב-1950:[^2] $`p`$ הוא ראשוני אם ורק אם



```math
1^{p-1}+2^{p-1}+ \cdots +(p-1)^{p-1} \equiv -1 \pmod p,
```

 או בכתיב מקוצר,



```math
\sum_{i=1}^{p-1} i^{p-1} \equiv -1 \pmod p.
```



קל להראות שאם $`p`$ ראשוני, השקילות השנייה מתקיימת: לפי [המשפט הקטן של פרמה](https://he.wikipedia.org/wiki/%D7%94%D7%9E%D7%A9%D7%A4%D7%98_%D7%94%D7%A7%D7%98%D7%9F_%D7%A9%D7%9C_%D7%A4%D7%A8%D7%9E%D7%94),



```math
a^{p-1} \equiv 1 \pmod p
```

 לכל $`a = 1,2,\dots,p-1`$, ולכן הסכום הוא $`p-1`$ איברים ששווים כולם ל-1, כלומר $`p - 1 \equiv -1 \pmod p`$.

לדוגמה, עבור $`p = 5`$: $`1 + 16 + 81 + 256 = 354 = 5 \cdot 71 - 1 \equiv -1 \pmod 5`$. לעומת זאת, עבור המספר הפריק $`n = 4`$: $`1 + 8 + 27 = 36 \equiv 0 \pmod 4`$.

## מצב ההשערה

הטענה היא עדיין השערה, כי טרם הוכח שאם $`n`$ אינו ראשוני (כלומר, $`n`$ [פריק](https://he.wikipedia.org/wiki/%D7%9E%D7%A1%D7%A4%D7%A8_%D7%A4%D7%A8%D7%99%D7%A7)), הנוסחה אינה מתקיימת. הוכח שמספר פריק $`n`$ מקיים את הנוסחה אם ורק אם הוא גם [מספר קרמייקל](https://he.wikipedia.org/wiki/%D7%9E%D7%A1%D7%A4%D7%A8_%D7%A7%D7%A8%D7%9E%D7%99%D7%99%D7%A7%D7%9C) וגם מספר ג'וגה, ושאם מספר כזה קיים, יש בו לפחות 13,800 ספרות.[^3] ב-2001 הראה סוריני שדוגמה נגדית אפשרית צריכה להיות גדולה מ-$`10^{36067}`$;[^4] זה הגבול שהציע בדוקי לשיטת ההוכחה שג'וגה עצמו הציע להשערתו.

## הקשר למשפט וילסון

השערת אגו–ג'וגה דומה ל[משפט וילסון](https://he.wikipedia.org/wiki/%D7%9E%D7%A9%D7%A4%D7%98_%D7%95%D7%99%D7%9C%D7%A1%D7%95%D7%9F), שהוכח. משפט וילסון קובע שמספר $`p`$ הוא ראשוני אם ורק אם



```math
(p-1)! \equiv -1 \pmod p,
```

 או בכתיב אחר,



```math
\prod_{i=1}^{p-1} i \equiv -1 \pmod p.
```



עבור ראשוני אי-זוגי $`p`$ מתקיים



```math
\prod_{i=1}^{p-1} i^{p-1} \equiv (-1)^{p-1} \equiv 1 \pmod p,
```

 וגם עבור $`p=2`$ המכפלה היא $`1^1 = 1`$.

לכן, אם השערת אגו–ג'וגה נכונה, אז יחד עם משפט וילסון: מספר $`p`$ הוא ראשוני אם ורק אם



```math
\sum_{i=1}^{p-1} i^{p-1} \equiv -1 \pmod p
```

 וגם



```math
\prod_{i=1}^{p-1} i^{p-1} \equiv 1 \pmod p.
```
