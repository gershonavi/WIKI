# אי-שוויון פוליה–וינוגרדוב

ב[תורת המספרים](https://he.wikipedia.org/wiki/%D7%AA%D7%95%D7%A8%D7%AA_%D7%94%D7%9E%D7%A1%D7%A4%D7%A8%D7%99%D7%9D), **אי-שוויון פוליה–וינוגרדוב** (Pólya–Vinogradov inequality) הוא חסם עליון על [סכומים](%D7%A1%D7%9B%D7%95%D7%9D%20%D7%A7%D7%A8%D7%A7%D7%98%D7%A8%D7%99%D7%9D.md) של [קרקטר דיריכלה](https://he.wikipedia.org/wiki/%D7%A7%D7%A8%D7%A7%D7%98%D7%A8_%D7%A9%D7%9C_%D7%93%D7%99%D7%A8%D7%99%D7%9B%D7%9C%D7%94) על קטע של שלמים עוקבים. הוא מראה שהערכים של $`\left(\frac ap\right)`$ עבור $`a`$ עוקבים מתנהגים במידה מסוימת כמו משתנה מקרי – כמו [הטלת מטבע](https://he.wikipedia.org/wiki/%D7%94%D7%98%D7%9C%D7%AA_%D7%9E%D7%98%D7%91%D7%A2) – ושבכל קטע ארוך מספיק יש בערך אותו מספר של [שאריות ריבועיות](https://he.wikipedia.org/wiki/%D7%A9%D7%90%D7%A8%D7%99%D7%AA_%D7%A8%D7%99%D7%91%D7%95%D7%A2%D7%99%D7%AA) ושל אי-שאריות.[^1]

## ניסוח

[ג'ורג' פוליה](https://he.wikipedia.org/wiki/%D7%92%27%D7%95%D7%A8%D7%92%27_%D7%A4%D7%95%D7%9C%D7%99%D7%94) ו[איוואן וינוגרדוב](https://he.wikipedia.org/wiki/%D7%90%D7%99%D7%95%D7%95%D7%90%D7%9F_%D7%95%D7%99%D7%A0%D7%95%D7%92%D7%A8%D7%93%D7%95%D7%91) הוכיחו (באופן בלתי תלוי) ב-1918 שלכל קרקטר דיריכלה לא ראשי $`\chi(n)`$ מודולו $`q`$ ולכל שלמים $`M`$ ו-$`N`$,[^2]



```math
\left|\sum_{n=M+1}^{M+N}\chi(n)\right| = O\left(\sqrt q\log q\right).
```

 אם לוקחים $`\chi(n) = \left(\frac nq\right)`$ ([סמל לז'נדר](https://he.wikipedia.org/wiki/%D7%A1%D7%99%D7%9E%D7%9F_%D7%9C%D7%96%27%D7%A0%D7%93%D7%A8), עבור $`q`$ ראשוני), מקבלים שמספר השאריות הריבועיות מודולו $`q`$ בכל קטע באורך $`N`$ הוא



```math
\frac12N + O(\sqrt q\log q).
```



קל יחסית להוכיח ש-



```math
\left|\sum_{n=M+1}^{M+N}\left(\frac nq\right)\right| \lt \sqrt q\log q,
```

 ולמעשה[^3]



```math
\left|\sum_{n=M+1}^{M+N}\left(\frac nq\right)\right| \lt \frac4{\pi^2}\sqrt q\log q + 0.41\sqrt q + 0.61.
```



## הוכחה

ההוכחה משתמשת ב[סכומי גאוס](%D7%A1%D7%9B%D7%95%D7%9D%20%D7%92%D7%90%D7%95%D7%A1.md). עבור $`q = p`$ ראשוני ו-$`\chi = \left(\frac\cdot p\right)`$, יהי $`\tau = \sum_{a=1}^{p-1}\left(\frac ap\right)e^{2\pi ia/p}`$ סכום גאוס; ידוע ש-$`|\tau| = \sqrt p`$, ושלכל $`n`$,



```math
\left(\frac np\right) = \frac1\tau\sum_{a=1}^{p-1}\left(\frac ap\right)e^{2\pi ian/p}.
```

 (זה "התמרת פורייה" של הקרקטר: הקרקטר הוא, עד כדי קבוע, התמרת הפורייה של עצמו.) נסכם על $`n`$ בקטע:



```math
\sum_{n=M+1}^{M+N}\left(\frac np\right) = \frac1\tau\sum_{a=1}^{p-1}\left(\frac ap\right)\sum_{n=M+1}^{M+N}e^{2\pi ian/p}.
```

 הסכום הפנימי הוא [טור הנדסי](https://he.wikipedia.org/wiki/%D7%98%D7%95%D7%A8_%D7%94%D7%A0%D7%93%D7%A1%D7%99), וערכו המוחלט לכל היותר $`\frac1{|\sin(\pi a/p)|}`$. לכן



```math
\left|\sum_{n=M+1}^{M+N}\left(\frac np\right)\right| \le \frac1{\sqrt p}\sum_{a=1}^{p-1}\frac1{|\sin(\pi a/p)|} \le \frac1{\sqrt p}\cdot2\sum_{a=1}^{(p-1)/2}\frac p{2a} \le \sqrt p\,(\log p + 1),
```

 כאשר השתמשנו ב-$`\sin x \ge 2x/\pi`$ עבור $`0 \le x \le \pi/2`$. הנקודה המרכזית: הקטע יכול להיות ארוך כרצוננו, אבל אחרי ההתמרה הסכום תלוי רק ב-$`p - 1`$ תדרים.

## דוגמאות מספריות

חישבנו, לכל ראשוני $`p \lt 20000`$, את המקסימום של $`\left|\sum_{n=M+1}^{M+N}\left(\frac np\right)\right|`$ על כל הקטעים (שווה להפרש בין המקסימום למינימום של הסכומים החלקיים). אף ראשוני לא הפר את החסם של קוקרן, והיחס בין המקסימום ל-$`\sqrt p\log p`$ היה לכל היותר $`0.556`$. כמה ערכים:

| $`p`$   | המקסימום על קטעים | $`\max_N\left|\sum_{n\le N}\left(\frac np\right)\right|`$ | $`\sqrt p\log p`$ |
|-------|-------------------|---------------------------------------------------------|-----------------|
| 11    | 3                 | 3                                                       | 8.0             |
| 101   | 14                | 7                                                       | 46.4            |
| 1009  | 36                | 18                                                      | 219.7           |
| 10007 | 130               | 130                                                     | 921.4           |
| 19991 | 256               | 256                                                     | 1400.2          |
| 19997 | 230               | 115                                                     | 1400.4          |

הערכים בפועל קטנים בהרבה מ-$`\sqrt p\log p`$, ובערך מסדר גודל של $`\sqrt p`$. ראשוניים $`p \equiv 3 \pmod 4`$ (כמו 10007 ו-19991) נותנים סכומים חלקיים גדולים יחסית: עבור 19991, הסכום החלקי עד $`N = 9086`$ הוא 256. הסיבה היא שעבורם הסכום עד $`(p - 1)/2`$ פרופורציונלי ל[מספר המחלקות](https://he.wikipedia.org/wiki/%D7%9E%D7%A1%D7%A4%D7%A8_%D7%94%D7%9E%D7%97%D7%9C%D7%A7%D7%95%D7%AA) של $`\mathbb Q(\sqrt{-p})`$ (נוסחת דיריכלה), שיכול להיות גדול.

## שיפורים וחסמים תחתונים

[מונטגומרי](https://he.wikipedia.org/wiki/%D7%99%D7%95_%D7%9E%D7%95%D7%A0%D7%98%D7%92%D7%95%D7%9E%D7%A8%D7%99) ו[ווהן](https://he.wikipedia.org/wiki/%D7%A8%D7%95%D7%91%D7%A8%D7%98_%D7%A6%27%D7%90%D7%A8%D7%9C%D7%A1_%D7%95%D7%95%D7%94%D7%9F) שיפרו את החסם ב-1977, והראו שאם [השערת רימן המוכללת](%D7%94%D7%A9%D7%A2%D7%A8%D7%AA%20%D7%A8%D7%99%D7%9E%D7%9F%20%D7%94%D7%9E%D7%95%D7%9B%D7%9C%D7%9C%D7%AA.md) נכונה, אז



```math
\left|\sum_{n=M+1}^{M+N}\chi(n)\right| = O\left(\sqrt q\log\log q\right).
```

 אי אפשר לשפר את התוצאה הזו באופן מהותי, כי [שור](https://he.wikipedia.org/wiki/%D7%99%D7%A1%D7%90%D7%99_%D7%A9%D7%95%D7%A8) הוכיח ב-1918 ש-



```math
\max_N\left|\sum_{n=1}^N\left(\frac nq\right)\right| \gt \frac1{2\pi}\sqrt q,
```

 ו[פיילי](https://he.wikipedia.org/wiki/%D7%A8%D7%99%D7%99%D7%9E%D7%95%D7%A0%D7%93_%D7%A4%D7%99%D7%99%D7%9C%D7%99) הוכיח ב-1932 ש-



```math
\max_N\left|\sum_{n=1}^N\left(\frac dn\right)\right| \gt \frac17\sqrt d\log\log d
```

 לאינסוף ערכים של $`d \gt 0`$.[^4] בחישוב שלנו, היחס $`\max_N|\sum_{n\le N}(n/p)|/\sqrt p`$ עבור $`p \lt 20000`$ הוא תמיד לפחות $`0.447`$ (המינימום ב-$`p = 5`$), הרבה מעל $`1/(2\pi) \approx 0.159`$.

## יישום: אי-השארית הריבועית הקטנה ביותר

אי-השארית הריבועית הקטנה ביותר $`n(p)`$ מודולו ראשוני $`p`$ היא תמיד ראשונית (אם $`n = ab`$ עם $`a, b \lt n`$, שניהם שאריות ולכן גם $`n`$). אי-שוויון פוליה–וינוגרדוב נותן $`n(p) = O(\sqrt p\log p)`$: אם כל המספרים $`1, \ldots, N`$ שאריות, הסכום החלקי עד $`N`$ הוא $`N`$, ולכן $`N \le \sqrt p\log p`$. וינוגרדוב שיפר זאת, בעזרת טריק כפלי, ל-$`n(p) \ll p^{1/(2\sqrt e)+\varepsilon}`$, והחסם הטוב ביותר הידוע ללא השערות, $`n(p) \ll p^\theta`$ לכל $`\theta \gt \frac1{4\sqrt e}`$, מגיע מההערכות של בורג'ס לסכומי קרקטרים.[^5] בהנחת השערת רימן המוכללת, אנקני קיבל $`n(p) \ll (\log p)^2`$.[^6]
