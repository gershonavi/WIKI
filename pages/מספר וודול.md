# מספר וודול

ב[תורת המספרים](https://he.wikipedia.org/wiki/%D7%AA%D7%95%D7%A8%D7%AA_%D7%94%D7%9E%D7%A1%D7%A4%D7%A8%D7%99%D7%9D), **מספר וודול** ($`W_n`$) הוא כל [מספר טבעי](https://he.wikipedia.org/wiki/%D7%9E%D7%A1%D7%A4%D7%A8_%D7%98%D7%91%D7%A2%D7%99) מהצורה



```math
W_n = n \cdot 2^n - 1
```

 עבור מספר טבעי $`n`$ כלשהו. מספרי וודול הראשונים הם:

  
1, 7, 23, 63, 159, 383, 895, … ((סדרה [A003261](https://oeis.org/A003261) ב-OEIS)).

## היסטוריה

מספרי וודול נחקרו לראשונה על ידי [אלן קנינגהם](https://he.wikipedia.org/wiki/%D7%90%D7%9C%D7%9F_%D7%A7%D7%A0%D7%99%D7%A0%D7%92%D7%94%D7%9D) וה. ג'. וודול ב-1917,[^1] בהשראת המחקר המוקדם יותר של ג'יימס קאלן על [מספרי קאלן](%D7%9E%D7%A1%D7%A4%D7%A8%20%D7%A7%D7%90%D7%9C%D7%9F.md), שמוגדרים באופן דומה.

## ראשוני וודול

מספרי וודול שהם גם [מספרים ראשוניים](https://he.wikipedia.org/wiki/%D7%9E%D7%A1%D7%A4%D7%A8_%D7%A8%D7%90%D7%A9%D7%95%D7%A0%D7%99) נקראים **ראשוני וודול**. המעריכים הראשונים $`n`$ שעבורם $`W_n`$ ראשוני הם 2, 3, 6, 30, 75, 81, 115, 123, 249, 362, 384, ... ((סדרה [A002234](https://oeis.org/A002234) ב-OEIS)); ראשוני וודול עצמם מתחילים ב-7, 23, 383, 32212254719, ... ((סדרה [A050918](https://oeis.org/A050918) ב-OEIS)). (את הרשימה עד $`n = 400`$ בדקנו בחישוב.)

ב-1976 הראה כריסטופר הולי ש[כמעט כל](https://he.wikipedia.org/wiki/%D7%9B%D7%9E%D7%A2%D7%98_%D7%9B%D7%9C) מספרי קאלן [פריקים](https://he.wikipedia.org/wiki/%D7%9E%D7%A1%D7%A4%D7%A8_%D7%A4%D7%A8%D7%99%D7%A7).[^2] באוקטובר 1995 פרסם וילפריד קלר מאמר שדן בכמה ראשוני קאלן חדשים ובמאמצים לפרק מספרי קאלן ווודול אחרים. במאמר נכללה הודעה אישית לקלר מאת הירומי סויאמה, שלפיה אפשר לנסח מחדש את השיטה של הולי כך שתעבוד לכל סדרה של מספרים $`n\cdot2^{n + a} + b`$, כאשר $`a`$ ו-$`b`$ [שלמים](https://he.wikipedia.org/wiki/%D7%9E%D7%A1%D7%A4%D7%A8_%D7%A9%D7%9C%D7%9D), ובפרט כמעט כל מספרי וודול פריקים.[^3] זו [בעיה פתוחה](https://he.wikipedia.org/wiki/%D7%91%D7%A2%D7%99%D7%94_%D7%A4%D7%AA%D7%95%D7%97%D7%94) אם יש אינסוף ראשוני וודול. נכון לאוקטובר 2018 ידועים שלושים וארבעה ראשוני וודול, והגדול ביותר הידוע הוא $`17016602\times2^{17016602} - 1`$. יש בו 5,122,515 ספרות (בדקנו), והוא נמצא על ידי דייגו ברטולוטי במרץ 2018 בפרויקט ה[מחשוב המבוזר](https://he.wikipedia.org/wiki/%D7%9E%D7%97%D7%A9%D7%95%D7%91_%D7%9E%D7%91%D7%95%D7%96%D7%A8) PrimeGrid.[^4] (שימו לב ש-$`17016602\cdot2^{17016602} = 8508301\cdot2^{17016603}`$, וכך המספר רשום ב-Prime Pages.)

## מגבלות

החל מ-$`W_4 = 63`$ ו-$`W_5 = 159`$, כל מספר וודול שישי מתחלק ב-3; כלומר $`3 \mid W_n`$ לכל $`n \equiv 4, 5 \pmod 6`$. לכן, כדי ש-$`W_n`$ יהיה ראשוני, האינדקס $`n`$ אינו יכול להיות [שקול](https://he.wikipedia.org/wiki/%D7%97%D7%A9%D7%91%D7%95%D7%9F_%D7%9E%D7%95%D7%93%D7%95%D7%9C%D7%A8%D7%99) ל-4 או ל-5 מודולו 6. (הסבר: מודולו 3, $`2^n \equiv (-1)^n`$; עבור $`n \equiv 4 \pmod 6`$: $`n\cdot2^n \equiv 1\cdot1 = 1`$, ועבור $`n \equiv 5 \pmod 6`$: $`n\cdot2^n \equiv 2\cdot(-1) \equiv 1`$. בשני המקרים $`W_n \equiv 0`$.)

כמו כן, לשלם חיובי $`m`$, מספר הוודול $`W_{2^m}`$ יכול להיות ראשוני רק אם $`2^m + m`$ ראשוני: אכן, $`W_{2^m} = 2^m\cdot2^{2^m} - 1 = 2^{2^m + m} - 1`$ הוא [מספר מרסן](https://he.wikipedia.org/wiki/%D7%A8%D7%90%D7%A9%D7%95%D7%A0%D7%99_%D7%9E%D7%A8%D7%A1%D7%9F), וזה ראשוני רק אם המעריך ראשוני. נכון לינואר 2019, הראשוניים היחידים הידועים שהם גם ראשוני וודול וגם [ראשוני מרסן](https://he.wikipedia.org/wiki/%D7%A8%D7%90%D7%A9%D7%95%D7%A0%D7%99_%D7%9E%D7%A8%D7%A1%D7%9F) הם $`W_2 = M_3 = 7`$ ו-$`W_{512} = M_{521}`$ (כאן $`2^9 + 9 = 521`$).

## תכונות התחלקות

כמו מספרי קאלן, למספרי וודול יש תכונות התחלקות רבות. למשל, אם $`p`$ מספר ראשוני, אז $`p`$ מחלק את

- $`W_{(p + 1)/2}`$ אם [סמל יעקובי](https://he.wikipedia.org/wiki/%D7%A1%D7%99%D7%9E%D7%9F_%D7%99%D7%A2%D7%A7%D7%95%D7%91%D7%99) $`\left(\frac{2}{p}\right)`$ הוא $`+1`$, ואת
- $`W_{(3p - 1)/2}`$ אם סמל יעקובי $`\left(\frac{2}{p}\right)`$ הוא $`-1`$.[^5]

למשל, $`\left(\tfrac27\right) = +1`$ ו-$`7 \mid W_4 = 63`$; $`\left(\tfrac25\right) = -1`$ ו-$`5 \mid W_7 = 895`$. (בדקנו את שתי הטענות לכל הראשוניים $`p \lt 5000`$.)

*הוכחה של המקרה הראשון:* עם $`n = (p+1)/2`$: $`2^n = 2\cdot2^{(p-1)/2} \equiv 2\left(\tfrac2p\right) = 2`$ (לפי קריטריון אוילר), ו-$`n \equiv \tfrac12 \pmod p`$. לכן $`n\cdot2^n \equiv 1`$, ו-$`W_n \equiv 0`$. במקרה השני, עם $`n = (3p-1)/2 = (p-1) + (p+1)/2`$: $`n \equiv -\tfrac12 \pmod p`$ ו-$`2^n \equiv 2^{(p+1)/2} \equiv 2\left(\tfrac2p\right) = -2`$, ו-$`n\cdot2^n \equiv (-\tfrac12)(-2) = 1`$.

## הכללה

**מספר וודול מוכלל בבסיס $`b`$** מוגדר כמספר מהצורה $`n \times b^n - 1`$, כאשר $`n + 2 \gt b`$; אם ראשוני ניתן לכתיבה בצורה הזו, הוא נקרא **ראשוני וודול מוכלל**.

הערך הקטן ביותר של $`n`$ שעבורו $`n \times b^n - 1`$ ראשוני (בלי התנאי $`n + 2 \gt b`$), עבור $`b = 1, 2, 3, \ldots`$, הוא[^6]

  
3, 2, 1, 1, 8, 1, 2, 1, 10, 2, 2, 1, 2, 1, 2, 167, 2, 1, 12, 1, 2, 2, 29028, 1, 2, 3, 10, 2, 26850, 1, 8, 1, 42, 2, 6, 2, 24, 1, 2, 3, 2, 1, 2, 1, 2, 2, 140, 1, 2, 2, 22, 2, 8, 1, 2064, 2, 468, 6, 2, 1, 362, 1, 2, 2, 6, 3, 26, 1, 2, 3, 20, 1, 2, 1, 28, 2, 38, 5, 3024, 1, 2, 81, 858, 1, 2, 3, 2, 8, 60, 1, 2, 2, 10, 5, 2, 7, 182, 1, 17782, 3, ... ((סדרה [A240235](https://oeis.org/A240235) ב-OEIS))

(את הערכים עבור $`b \le 30`$ שקטנים מ-3000 בדקנו בחישוב.)

נכון לנובמבר 2021, ראשוני וודול המוכלל הגדול ביותר הידוע עם בסיס גדול מ-2 הוא $`2740879 \times 32^{2740879} - 1`$.[^7]
