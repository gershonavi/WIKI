# משפט זיגל-ולפיש

ב[תורת המספרים האנליטית](%D7%AA%D7%95%D7%A8%D7%AA%20%D7%94%D7%9E%D7%A1%D7%A4%D7%A8%D7%99%D7%9D%20%D7%94%D7%90%D7%A0%D7%9C%D7%99%D7%98%D7%99%D7%AA.md), **משפט זיגל-ולפיש** הוא תוצאה שהשיג ארנולד ולפיש[^1] כיישום של משפט של [קרל לודוויג זיגל](https://he.wikipedia.org/wiki/%D7%A7%D7%A8%D7%9C_%D7%9C%D7%95%D7%93%D7%95%D7%95%D7%99%D7%92_%D7%96%D7%99%D7%92%D7%9C)[^2] לבעיית ה[ראשוניים](https://he.wikipedia.org/wiki/%D7%9E%D7%A1%D7%A4%D7%A8_%D7%A8%D7%90%D7%A9%D7%95%D7%A0%D7%99) ב[סדרות חשבוניות](https://he.wikipedia.org/wiki/%D7%A1%D7%93%D7%A8%D7%94_%D7%97%D7%A9%D7%91%D7%95%D7%A0%D7%99%D7%AA). המשפט מעדן הן את [משפט המספרים הראשוניים](https://he.wikipedia.org/wiki/%D7%9E%D7%A9%D7%A4%D7%98_%D7%94%D7%9E%D7%A1%D7%A4%D7%A8%D7%99%D7%9D_%D7%94%D7%A8%D7%90%D7%A9%D7%95%D7%A0%D7%99%D7%99%D7%9D) והן את [משפט דיריכלה על ראשוניים בסדרות חשבוניות](https://he.wikipedia.org/wiki/%D7%9E%D7%A9%D7%A4%D7%98_%D7%93%D7%99%D7%A8%D7%99%D7%9B%D7%9C%D7%94).

## ניסוח

נגדיר



```math
\psi(x;q,a) = \sum_{n \leq x \atop n \equiv a \pmod{q} }\Lambda(n),
```

 כאשר $`\Lambda`$ היא [פונקציית פון מנגולד](https://he.wikipedia.org/wiki/%D7%A4%D7%95%D7%A0%D7%A7%D7%A6%D7%99%D7%99%D7%AA_%D7%A4%D7%95%D7%9F_%D7%9E%D7%A0%D7%92%D7%95%D7%9C%D7%93), ותהי $`\varphi`$ [פונקציית אוילר](https://he.wikipedia.org/wiki/%D7%A4%D7%95%D7%A0%D7%A7%D7%A6%D7%99%D7%99%D7%AA_%D7%90%D7%95%D7%99%D7%9C%D7%A8).

המשפט קובע שלכל [מספר ממשי](https://he.wikipedia.org/wiki/%D7%9E%D7%A1%D7%A4%D7%A8_%D7%9E%D7%9E%D7%A9%D7%99) $`N`$ קיים קבוע חיובי $`C_N`$, התלוי רק ב-$`N`$, כך ש



```math
\psi(x;q,a)=\frac{x}{\varphi(q)}+O\left(x\exp\left(-C_N(\log x)^{1/2}\right)\right)
```

 בכל פעם ש-$`(a,q) = 1`$ ו-



```math
q\le(\log x)^N.
```



## הערות

הקבוע $`C_N`$ אינו ניתן לחישוב אפקטיבי, משום שמשפט זיגל אינו אפקטיבי.

מהמשפט אפשר להסיק את החסם הבא על משפט המספרים הראשוניים לסדרות חשבוניות: אם, עבור $`(a,q) = 1`$, נסמן ב-$`\pi(x;q,a)`$ את מספר הראשוניים הקטנים מ-$`x`$ או שווים לו והשקולים ל-$`a`$ מודולו $`q`$, אז



```math
\pi(x;q,a) = \frac{\mathrm{Li}(x)}{\varphi(q)}+O\left(x\exp\left(-\frac{C_N}{2}(\log x)^{1/2}\right)\right),
```

 כאשר $`N`$, $`a`$, $`q`$, $`C_N`$ ו-$`\varphi`$ הם כמו במשפט, ו-$`\mathrm{Li}`$ היא [פונקציית האינטגרל הלוגריתמי](https://he.wikipedia.org/wiki/%D7%A4%D7%95%D7%A0%D7%A7%D7%A6%D7%99%D7%99%D7%AA_%D7%94%D7%90%D7%99%D7%A0%D7%98%D7%92%D7%A8%D7%9C_%D7%94%D7%9C%D7%95%D7%92%D7%A8%D7%99%D7%AA%D7%9E%D7%99).
