# משפט ליניק

**משפט ליניק** (ב[אנגלית](https://he.wikipedia.org/wiki/%D7%90%D7%A0%D7%92%D7%9C%D7%99%D7%AA): Linnik's theorem) ב[תורת המספרים האנליטית](%D7%AA%D7%95%D7%A8%D7%AA%20%D7%94%D7%9E%D7%A1%D7%A4%D7%A8%D7%99%D7%9D%20%D7%94%D7%90%D7%A0%D7%9C%D7%99%D7%98%D7%99%D7%AA.md) עונה על שאלה טבעית העולה מ[משפט דיריכלה](https://he.wikipedia.org/wiki/%D7%9E%D7%A9%D7%A4%D7%98_%D7%93%D7%99%D7%A8%D7%99%D7%9B%D7%9C%D7%94) על סדרות חשבוניות. המשפט קובע שקיימים קבועים חיוביים $`c`$ ו-$`L`$ כך שאם נסמן ב-$`p(a,d)`$ את הראשוני הקטן ביותר בסדרה החשבונית



```math
a + nd,
```

 כאשר $`n`$ עובר על המספרים השלמים החיוביים, ו-$`a`$ ו-$`d`$ הם מספרים שלמים חיוביים [זרים](https://he.wikipedia.org/wiki/%D7%9E%D7%A1%D7%A4%D7%A8%D7%99%D7%9D_%D7%96%D7%A8%D7%99%D7%9D) כלשהם עם $`1 \le a \le d - 1`$, אז:



```math
p(a,d) < c\, d^{L}.
```



המשפט קרוי על שם [יורי ליניק](https://he.wikipedia.org/wiki/%D7%99%D7%95%D7%A8%D7%99_%D7%9C%D7%99%D7%A0%D7%99%D7%A7), ש[הוכיח](https://he.wikipedia.org/wiki/%D7%94%D7%95%D7%9B%D7%97%D7%94) אותו ב-1944[^1][^2]. אף שההוכחה של ליניק הראתה שאפשר לחשב את $`c`$ ואת $`L`$ באופן אפקטיבי, הוא לא נתן להם ערכים מספריים.

ממשפט ז'יגמונדי נובע ש-$`p(1,d) \le 2^d - 1`$ לכל $`d \ge 3`$. ידוע גם ש-$`p(1,p) \le L_p`$ לכל ראשוני $`p \ge 5`$, משום ש-$`L_p`$ [שקול](https://he.wikipedia.org/wiki/%D7%97%D7%A9%D7%91%D7%95%D7%9F_%D7%9E%D7%95%D7%93%D7%95%D7%9C%D7%A8%D7%99) ל-1 מודולו $`p`$ לכל ראשוני $`p`$, כאשר $`L_p`$ הוא מספר לוקאס ה-$`p`$-י (ראו [סדרת לוקאס](https://he.wikipedia.org/wiki/%D7%A1%D7%93%D7%A8%D7%AA_%D7%9C%D7%95%D7%A7%D7%90%D7%A1)). בדומה ל[מספרי מרסן](https://he.wikipedia.org/wiki/%D7%9E%D7%A1%D7%A4%D7%A8_%D7%9E%D7%A8%D7%A1%D7%9F), למספרי לוקאס עם אינדקס ראשוני יש [מחלקים](https://he.wikipedia.org/wiki/%D7%9E%D7%97%D7%9C%D7%A7) מהצורה $`2kp+1`$.

## תכונות

ידוע ש-$`L \le 2`$ עבור [כמעט כל](https://he.wikipedia.org/wiki/%D7%9B%D7%9E%D7%A2%D7%98_%D7%9B%D7%9C_%28%D7%9E%D7%AA%D7%9E%D7%98%D7%99%D7%A7%D7%94) "wikilink") המספרים השלמים $`d`$[^3].

בהנחת [השערת רימן המוכללת](%D7%94%D7%A9%D7%A2%D7%A8%D7%AA%20%D7%A8%D7%99%D7%9E%D7%9F%20%D7%94%D7%9E%D7%95%D7%9B%D7%9C%D7%9C%D7%AA.md) אפשר להראות ש-



```math
p(a,d) \leq (1+o(1))\varphi(d)^2 (\log d)^2,
```

 כאשר $`\varphi`$ היא [פונקציית אוילר](https://he.wikipedia.org/wiki/%D7%A4%D7%95%D7%A0%D7%A7%D7%A6%D7%99%D7%99%D7%AA_%D7%90%D7%95%D7%99%D7%9C%D7%A8)[^4], והוכח גם החסם החזק יותר[^5]



```math
p(a,d) \leq \varphi(d)^2 (\log d)^2.
```

 משערים גם ש-



```math
p(a,d) < d^2.
```

[^6]
