# תנועה בראונית ופונקציית זטא של רימן

ב[מתמטיקה](https://he.wikipedia.org/wiki/%D7%9E%D7%AA%D7%9E%D7%98%D7%99%D7%A7%D7%94), **[תנועה בראונית](https://he.wikipedia.org/wiki/%D7%AA%D7%A0%D7%95%D7%A2%D7%94_%D7%91%D7%A8%D7%90%D7%95%D7%A0%D7%99%D7%AA)** ו**[פונקציית זטא של רימן](https://he.wikipedia.org/wiki/%D7%A4%D7%95%D7%A0%D7%A7%D7%A6%D7%99%D7%99%D7%AA_%D7%96%D7%98%D7%90_%D7%A9%D7%9C_%D7%A8%D7%99%D7%9E%D7%9F)** הן שני אובייקטים מרכזיים שמקורם בתחומים שונים – [תורת ההסתברות](https://he.wikipedia.org/wiki/%D7%AA%D7%95%D7%A8%D7%AA_%D7%94%D7%94%D7%A1%D7%AA%D7%91%D7%A8%D7%95%D7%AA) ו[תורת המספרים האנליטית](%D7%AA%D7%95%D7%A8%D7%AA%20%D7%94%D7%9E%D7%A1%D7%A4%D7%A8%D7%99%D7%9D%20%D7%94%D7%90%D7%A0%D7%9C%D7%99%D7%98%D7%99%D7%AA.md) – ויש ביניהם קשרים מתמטיים. הקשרים בין [תהליכים סטוכסטיים](https://he.wikipedia.org/wiki/%D7%AA%D7%94%D7%9C%D7%99%D7%9A_%D7%A1%D7%98%D7%95%D7%9B%D7%A1%D7%98%D7%99) הנגזרים מהתנועה הבראונית לבין פונקציית זטא מראים, במובן מסוים, באופן אינטואיטיבי, את ההתנהגות הסטוכסטית שמסתתרת מאחורי פונקציית זטא. הצגה של פונקציית זטא בעזרת תהליכים סטוכסטיים נקראת **הצגה סטוכסטית**.[^1][^2]

## תנועה בראונית ופונקציית זטא

נסמן ב-$`\zeta(s)`$ את פונקציית זטא של רימן וב-$`\Gamma`$ את [פונקציית גמא](https://he.wikipedia.org/wiki/%D7%A4%D7%95%D7%A0%D7%A7%D7%A6%D7%99%D7%99%D7%AA_%D7%92%D7%9E%D7%90). [פונקציית קסי של רימן](https://he.wikipedia.org/wiki/%D7%A4%D7%95%D7%A0%D7%A7%D7%A6%D7%99%D7%99%D7%AA_%D7%A7%D7%A1%D7%99_%D7%A9%D7%9C_%D7%A8%D7%99%D7%9E%D7%9F) מוגדרת על ידי



```math
\xi(s) := \frac{1}{2}s(s-1)\pi^{-s/2}\Gamma\left(\tfrac{1}{2}s\right)\zeta(s),
```



והיא מקיימת את משוואת הפונקציה



```math
\xi(s)=\xi(1-s)\quad \text{for all } s\in \mathbb{C}.
```



מתברר ש-$`2\xi(s)`$ מתאר את ה[מומנטים](https://he.wikipedia.org/wiki/%D7%9E%D7%95%D7%9E%D7%A0%D7%98_%28%D7%A1%D7%98%D7%98%D7%99%D7%A1%D7%98%D7%99%D7%A7%D7%94%29) של התפלגות הסתברות $`\mu`$ על $`(0,\infty)`$:[^3][^4]



```math
2\xi(s)=\mathbb{E}[X^s]=\int_{0}^{\infty} x^s \, d\mu(x)\quad \text{for all } s\in\mathbb{C},
```



כאשר $`X`$ משתנה מקרי בעל ההתפלגות $`\mu`$. (בפרט $`2\xi(0) = 1`$, כפי שצריך: המסה הכוללת היא 1.) משוואת הפונקציה $`\xi(s) = \xi(1-s)`$ אומרת אז ש-$`\mathbb E[X^s] = \mathbb E[X^{1-s}]`$.

### גשר בראוני ופונקציית זטא

ב-1987 הוכיחו מרק יור ופיליפ ביאן שלמשתנה המקרי המוגדר כהפרש בין המקסימום למינימום של [גשר בראוני](https://he.wikipedia.org/wiki/%D7%92%D7%A9%D7%A8_%D7%91%D7%A8%D7%90%D7%95%D7%A0%D7%99) $`(b_s)_{0\leq s\leq 1}`$ (אחרי נרמול) יש בדיוק ההתפלגות הזו. גשר בראוני הוא תנועה בראונית חד-ממדית $`(W_t)_{0\leq t\leq 1}`$ בהתניה $`W_0=W_1=0`$.[^5] הם הראו ש



```math
X=\sqrt{\frac{2}{\pi} }\left(\max_{0\leq s \leq 1} b_s-\min_{0\leq s \leq 1} b_s\right)
```



פותר את משוואת המומנטים



```math
2\xi(s)=\mathbb{E}[X^s].
```



עם זאת, זה לא התהליך היחיד שקשור להתפלגות הזו; למשל, גם תהליך בסל נותן משתנים מקריים בעלי אותה התפלגות.

### תהליך בסל ופונקציית זטא

**תהליך בסל** $`\mathrm{Bes}(d)`$ מסדר $`d`$ הוא ה[נורמה](https://he.wikipedia.org/wiki/%D7%A0%D7%95%D7%A8%D7%9E%D7%94_%28%D7%9E%D7%AA%D7%9E%D7%98%D7%99%D7%A7%D7%94%29) האוקלידית של תנועה בראונית $`d`$-ממדית. התהליך $`\mathrm{Bes}(3)`$ מוגדר על ידי



```math
R_t:=\sqrt{\left(W_t^{(1)}\right)^2+\left(W_t^{(2)}\right)^2+\left(W_t^{(3)}\right)^2},
```



כאשר $`W_t=(W_t^{(1)},W_t^{(2)},W_t^{(3)})`$ היא תנועה בראונית תלת-ממדית.

נגדיר את זמן הפגיעה $`T_1:=\inf\{t\geq 0 : R_t=1\}`$, ותהי $`\tilde{T}_1`$ זמן פגיעה בלתי תלוי של תהליך $`\mathrm{Bes}(3)`$ אחר. נגדיר את המשתנה המקרי



```math
N=\frac{\pi}{2}\left(T_1+\tilde{T}_1\right).
```



אז[^6][^7]



```math
2\xi(2s)=\mathbb{E}[N^s],
```



כלומר ל-$`N`$ יש אותה התפלגות כמו ל-$`X^2`$.

### ההתפלגות

נסמן ב-$`\varphi`$ את הצפיפות של $`X^2`$ (שהיא גם הצפיפות של $`N`$). היא מקיימת[^8]



```math
\varphi(t)=2t\, \Theta''(t) + 3\Theta'(t)
```



עבור [פונקציית התטא](https://he.wikipedia.org/wiki/%D7%A4%D7%95%D7%A0%D7%A7%D7%A6%D7%99%D7%99%D7%AA_%D7%AA%D7%98%D7%90)



```math
\Theta(t)=\sum_{n=-\infty}^{\infty}e^{-\pi n^2t}.
```



פרמטריזציה אחרת, $`G(y):=\Theta(y^2)`$, נותנת[^9]



```math
h(y)=2y\, G'(y)+y^2G''(y),
```



ובצורה מפורשת



```math
h(y)=4y^2\sum_{n=1}^{\infty}\pi\left(2\pi n^4 y^2 - 3n^2\right)e^{-\pi n^2 y^2},
```



כאשר $`h(y)=2y^2\varphi(y^2)`$ ו



```math
2\xi(s)=\int_0^{\infty} y^{s-1}h(y)\,dy.
```



כלומר הצפיפות של $`X`$ עצמו היא $`h(y)/y = 2y\,\varphi(y^2)`$. (בערך האנגלי נכתב $`h(y) = 2y\varphi(y^2)`$ ו-$`\varphi`$ מתוארת כצפיפות של $`\mu`$; אבל הנוסחה $`h = 2yG' + y^2G''`$, שאותה אפשר לבדוק ישירות, נותנת $`h(y) = 2y^2\varphi(y^2)`$. הנוסחה $`2\xi(s)=\int_0^{\infty} y^{s-1}h(y)\,dy`$ נכונה: שתי אינטגרציות בחלקים נותנות $`s(s-1)\int_0^\infty y^{s-1}(G(y) - 1)\,dy = s(s-1)\pi^{-s/2}\Gamma(s/2)\zeta(s) = 2\xi(s)`$.)

הפונקציה $`h`$ קרובה מאוד לפונקציה $`\Phi`$ שמופיעה בהגדרה של [קבוע דה ברויין–ניומן](%D7%94%D7%A9%D7%A2%D7%A8%D7%AA%20%D7%A0%D7%99%D7%95%D7%9E%D7%9F.md): בהצבה $`y = e^{2u}`$ מקבלים $`h(e^{2u}) = 4\Phi(u)\,e^{-u}`$.
