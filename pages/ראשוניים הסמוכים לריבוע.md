# ראשוניים הסמוכים לריבוע

*אין לבלבל עם [\[\[השערת לז'נדר](https://he.wikipedia.org/wiki/%5B%5B%D7%94%D7%A9%D7%A2%D7%A8%D7%AA_%D7%9C%D7%96%27%D7%A0%D7%93%D7%A8) (קיום ראשוני בין שני ריבועים עוקבים)\]\].* **ראשוניים הסמוכים לריבוע** הם [מספרים ראשוניים](https://he.wikipedia.org/wiki/%D7%9E%D7%A1%D7%A4%D7%A8_%D7%A8%D7%90%D7%A9%D7%95%D7%A0%D7%99) מהצורה $`p = n^2 + 1`$, עבור $`n`$ [שלם](https://he.wikipedia.org/wiki/%D7%9E%D7%A1%D7%A4%D7%A8_%D7%A9%D7%9C%D7%9D). **השערת הראשוניים הסמוכים לריבוע** היא הטענה שיש אינסוף ראשוניים כאלה. זו הבעיה הרביעית מבין ארבע הבעיות של לנדאו, ש[אדמונד לנדאו](https://he.wikipedia.org/wiki/%D7%90%D7%93%D7%9E%D7%95%D7%A0%D7%93_%D7%9C%D7%A0%D7%93%D7%90%D7%95) הציג בקונגרס הבין-לאומי של המתמטיקאים ב-1912 כבעיות "שאין להן מענה במצב הידע הנוכחי"; כולן פתוחות עד היום.

הראשוניים מהצורה הזו הם ((סדרה [A002496](https://oeis.org/A002496) ב-OEIS)):



```math
2, 5, 17, 37, 101, 197, 257, 401, 577, 677, \ldots
```

 (עבור $`n = 1, 2, 4, 6, 10, 14, 16, 20, 24, 26`$). קיום אינסוף ראשוניים כאלה נובע מהשערות כלליות יותר, כמו [השערת בוניאקובסקי](%D7%94%D7%A9%D7%A2%D7%A8%D7%AA%20%D7%91%D7%95%D7%A0%D7%99%D7%90%D7%A7%D7%95%D7%91%D7%A1%D7%A7%D7%99.md) ו[השערת בייטמן-הורן](%D7%94%D7%A9%D7%A2%D7%A8%D7%AA%20%D7%91%D7%99%D7%99%D7%98%D7%9E%D7%9F-%D7%94%D7%95%D7%A8%D7%9F.md).

## תצפיות אלמנטריות

- אם $`n \gt 1`$ אי-זוגי, אז $`n^2 + 1`$ זוגי וגדול מ-2. לכן, מלבד 2, תמיד $`n`$ זוגי ו-$`p \equiv 1 \pmod 4`$.
- ראשוני $`q`$ יכול לחלק את $`n^2 + 1`$ רק אם $`-1`$ הוא [שארית ריבועית](https://he.wikipedia.org/wiki/%D7%A9%D7%90%D7%A8%D7%99%D7%AA_%D7%A8%D7%99%D7%91%D7%95%D7%A2%D7%99%D7%AA) מודולו $`q`$, כלומר $`q = 2`$ או $`q \equiv 1 \pmod 4`$. למשל, אף פעם $`3 \mid n^2 + 1`$. לכן "המכשולים" לראשוניות מגיעים רק מחצי מהראשוניים, ו-$`n^2 + 1`$ ראשוני לעיתים קרובות יותר ממספר אקראי באותו גודל.
- עבור $`q = 5`$: $`n^2 + 1 \equiv 0 \pmod 5`$ בדיוק כש-$`n \equiv 2, 3 \pmod 5`$. כך $`8^2 + 1 = 65 = 5\cdot13`$, $`12^2 + 1 = 145 = 5\cdot29`$, $`22^2 + 1 = 485 = 5\cdot97`$.
- בשלמים גאוסיים, $`n^2 + 1 = (n + i)(n - i)`$. לכן $`n^2 + 1`$ ראשוני בדיוק כש-$`n + i`$ הוא ראשוני גאוסי (עבור $`n \ge 1`$); ההשערה שקולה לכך שיש אינסוף ראשוניים גאוסיים על הישר $`\mathrm{Im} z = 1`$.
- דוגמה מוכרת: [ראשוני פרמה](https://he.wikipedia.org/wiki/%D7%A8%D7%90%D7%A9%D7%95%D7%A0%D7%99_%D7%A4%D7%A8%D7%9E%D7%94) $`2^{2^k} + 1 = \left(2^{2^{k-1} }\right)^2 + 1`$ (עבור $`k \ge 1`$) הם ראשוניים הסמוכים לריבוע: $`5, 17, 257, 65537`$.

## ההשערה הכמותית

השערת בייטמן–הורן (ולפניה השערה E של [הארדי](https://he.wikipedia.org/wiki/%D7%92%D7%95%D7%93%D7%A4%D7%A8%D7%99_%D7%94%D7%A8%D7%95%D7%9C%D7%93_%D7%94%D7%90%D7%A8%D7%93%D7%99) ו[ליטלווד](https://he.wikipedia.org/wiki/%D7%92%27%D7%95%D7%9F_%D7%90%D7%93%D7%A0%D7%96%D7%95%D7%A8_%D7%9C%D7%99%D7%98%D7%9C%D7%95%D7%95%D7%93), 1923) צופה את הקצב המדויק:



```math
\#\{n \le N : n^2 + 1 \text{ ראשוני}\} \sim \frac C2\mathrm{Li}(N) \sim \frac{C}{2}\cdot\frac{N}{\ln N},
```

 כאשר



```math
C = \prod_{p \gt 2}\left(1 - \frac{\left(\frac{-1}{p}\right)}{p - 1}\right) = \left(1+\tfrac12\right)\left(1-\tfrac14\right)\left(1+\tfrac16\right)\left(1+\tfrac1{10}\right)\left(1-\tfrac1{12}\right)\cdots \approx 1.3728,
```

 ו-$`\left(\frac{-1}{p}\right)`$ הוא [סמל לז'נדר](https://he.wikipedia.org/wiki/%D7%A1%D7%99%D7%9E%D7%9F_%D7%9C%D7%96%27%D7%A0%D7%93%D7%A8). כל גורם במכפלה מתקן את ההסתברות "הנאיבית" לפי מספר הפתרונות של $`n^2 \equiv -1 \pmod p`$: שניים כש-$`p \equiv 1 \pmod 4`$, ואפס כש-$`p \equiv 3 \pmod 4`$.

ההתאמה בין ההשערה למציאות מרשימה. בדקנו בחישוב (בנפה על $`n \le 10^7`$):

| $`N`$    | מספר ה-$`n \le N`$ עם $`n^2+1`$ ראשוני | התחזית $`\tfrac C2\left(\mathrm{Li}(N) - \mathrm{Li}(2)\right)`$ |
|--------|------------------------------------|----------------------------------------------------------------------------|
| $`10^2`$ | 19                                 | 20.0                                                                       |
| $`10^3`$ | 112                                | 121.2                                                                      |
| $`10^4`$ | 841                                | 854.6                                                                      |
| $`10^5`$ | 6656                               | 6609.1                                                                     |
| $`10^6`$ | 54110                              | 53968.8                                                                    |
| $`10^7`$ | 456362                             | 456395.6                                                                   |

בעשר המיליונים הראשונים הסטייה היחסית קטנה מ-$`10^{-4}`$.

## תוצאות ידועות

אף שההשערה פתוחה, ידועות כמה תוצאות בכיוונה:

**כמעט-ראשוניים.** הנריק איוואניץ הוכיח ב-1978 שיש אינסוף מספרים מהצורה $`n^2+1`$ עם לכל היותר שני גורמים ראשוניים.[^1] (למשל $`30^2 + 1 = 901 = 17\cdot53`$ ו-$`34^2 + 1 = 1157 = 13\cdot89`$. מבין $`n \le 10^4`$, אצל 3667 מהם ל-$`n^2+1`$ יש לכל היותר שני גורמים ראשוניים, כולל חזרות – כך חישבנו.)

**הגורם הראשוני הגדול ביותר.** אם $`n^2 + 1`$ ראשוני, הגורם הראשוני הגדול ביותר שלו הוא $`n^2+1 \approx n^2`$. סדרה של עבודות – איבנוב (1895), טוד (1949), הולי (1967, מעריך $`1.1`$), דזוייה ואיוואניץ (1982, מעריך $`1.2`$),[^2] דה לה ברטש ודרפו (2020), מריקוסקי (2022, מעריך $`1.279`$)[^3] – הגיעה לתוצאה של גרימלט ומריקוסקי (2025): יש אינסוף $`n`$ שהגורם הראשוני הגדול ביותר של $`n^2+1`$ הוא לפחות $`n^{1.312}`$.[^4] החלפת המעריך ב-2 הייתה נותנת את השערת לנדאו.

**ראשוניים קרובים לישר.** אנקני (1952) וקוביליוס (1955) הוכיחו, בהנחת [השערת רימן המוכללת](%D7%94%D7%A9%D7%A2%D7%A8%D7%AA%20%D7%A8%D7%99%D7%9E%D7%9F%20%D7%94%D7%9E%D7%95%D7%9B%D7%9C%D7%9C%D7%AA.md) עבור [פונקציית L](https://he.wikipedia.org/wiki/%D7%A4%D7%95%D7%A0%D7%A7%D7%A6%D7%99%D7%99%D7%AA_L) של קרקטרי הקה, שיש אינסוף ראשוניים $`p = x^2 + y^2`$ עם $`y = O(\log p)`$; השערת לנדאו היא המקרה החזק $`y = 1`$. התוצאה הטובה ביותר בלי הנחות היא של הרמן ולואיס (2001), עם $`y = O(p^{0.119})`$.[^5]

**צורות דלילות אחרות.** לפי [משפט פרידלנדר–איוואניץ](%D7%9E%D7%A9%D7%A4%D7%98%20%D7%A4%D7%A8%D7%99%D7%93%D7%9C%D7%A0%D7%93%D7%A8-%D7%90%D7%99%D7%95%D7%95%D7%90%D7%A0%D7%99%D7%A5.md) יש אינסוף ראשוניים מהצורה $`x^2 + y^4`$ (למשל $`5 = 2^2 + 1^4`$, $`17 = 1^2 + 2^4`$, $`97 = 9^2 + 2^4`$).[^6] ב-2024 הוכיחו [בן גרין](https://he.wikipedia.org/wiki/%D7%91%D7%9F_%D7%92%D7%A8%D7%99%D7%9F) ומהטאב סוני שיש אינסוף ראשוניים מהצורה $`p^2 + nq^2`$ עם $`p, q`$ ראשוניים, לכל $`n \equiv 0`$ או $`4 \pmod 6`$.[^7] באייר וז'או הוכיחו שיש אינסוף ראשוניים $`p = an^2 + 1`$ עם $`a \lt p^{5/9+\varepsilon}`$.[^8]

**חסם עליון.** [נפת ברון](%D7%A0%D7%A4%D7%AA%20%D7%91%D7%A8%D7%95%D7%9F.md) נותנת חסם עליון: יש $`O(\sqrt x/\log x)`$ ראשוניים כאלה עד $`x`$ – בדיוק סדר הגודל שההשערה הכמותית צופה, אבל רק כחסם עליון. מכאן שכמעט כל המספרים מהצורה $`n^2 + 1`$ פריקים.

## מדוע הבעיה קשה

שיטות הנפה אינן מבדילות בין מספרים עם מספר זוגי ומספר אי-זוגי של גורמים ראשוניים ("בעיית הזוגיות" של סלברג), ולכן הן מגיעות בטבעיות ל"לכל היותר שני גורמים" (כמו אצל איוואניץ) אבל לא לראשוניים. משפט פרידלנדר–איוואניץ עוקף את המחסום עבור $`x^2 + y^4`$ בזכות המבנה הדו-ממדי של הבעיה; עבור הסדרה החד-ממדית והדלילה $`n^2 + 1`$ (יש רק $`\sqrt x`$ איברים עד $`x`$) לא ידועה דרך כזו.
