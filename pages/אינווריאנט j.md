# אינווריאנט j

ב[מתמטיקה](https://he.wikipedia.org/wiki/%D7%9E%D7%AA%D7%9E%D7%98%D7%99%D7%A7%D7%94), **אינווריאנט $`j`$** או **פונקציית $`j`$** (נקרא גם **האינווריאנט המודולרי** או האינווריאנט של קליין) הוא [פונקציה מודולרית](https://he.wikipedia.org/wiki/%D7%A4%D7%95%D7%A0%D7%A7%D7%A6%D7%99%D7%94_%D7%9E%D7%95%D7%93%D7%95%D7%9C%D7%A8%D7%99%D7%AA) ממשקל אפס ביחס ל[חבורה הלינארית המיוחדת](https://he.wikipedia.org/wiki/%D7%97%D7%91%D7%95%D7%A8%D7%94_%D7%9C%D7%99%D7%A0%D7%90%D7%A8%D7%99%D7%AA_%D7%9E%D7%99%D7%95%D7%97%D7%93%D7%AA) $`\mathrm{SL}(2, \mathbb Z)`$, שמוגדרת על [חצי המישור העליון](%D7%97%D7%A6%D7%99%20%D7%94%D7%9E%D7%99%D7%A9%D7%95%D7%A8%20%D7%94%D7%A2%D7%9C%D7%99%D7%95%D7%9F.md) של ה[מספרים המרוכבים](https://he.wikipedia.org/wiki/%D7%9E%D7%A1%D7%A4%D7%A8_%D7%9E%D7%A8%D7%95%D7%9B%D7%91). זו הפונקציה היחידה כזו שהיא [הולומורפית](https://he.wikipedia.org/wiki/%D7%A4%D7%95%D7%A0%D7%A7%D7%A6%D7%99%D7%94_%D7%94%D7%95%D7%9C%D7%95%D7%9E%D7%95%D7%A8%D7%A4%D7%99%D7%AA) מחוץ לקוטב פשוט ב[חוד](https://he.wikipedia.org/wiki/%D7%97%D7%95%D7%93_%28%D7%AA%D7%91%D7%A0%D7%99%D7%95%D7%AA_%D7%9E%D7%95%D7%93%D7%95%D7%9C%D7%A8%D7%99%D7%95%D7%AA%29), ומקיימת



```math
j\left(e^{2\pi i/3}\right) = 0, \qquad j(i) = 1728 = 12^3.
```

 [פונקציות רציונליות](https://he.wikipedia.org/wiki/%D7%A4%D7%95%D7%A0%D7%A7%D7%A6%D7%99%D7%94_%D7%A8%D7%A6%D7%99%D7%95%D7%A0%D7%9C%D7%99%D7%AA) של $`j`$ הן מודולריות, ולמעשה נותנות את כל הפונקציות המודולריות ממשקל 0. באופן קלאסי חקרו את אינווריאנט $`j`$ כפרמטריזציה של [עקומים אליפטיים](https://he.wikipedia.org/wiki/%D7%A2%D7%A7%D7%95%D7%9D_%D7%90%D7%9C%D7%99%D7%A4%D7%98%D7%99) מעל $`\mathbb C`$, אבל יש לו גם קשרים מפתיעים לסימטריות של [חבורת המפלצת](https://he.wikipedia.org/wiki/%D7%97%D7%91%D7%95%D7%A8%D7%AA_%D7%94%D7%9E%D7%A4%D7%9C%D7%A6%D7%AA) (הקשר הזה נקרא [ירח מפלצתי](https://he.wikipedia.org/wiki/%D7%99%D7%A8%D7%97_%D7%9E%D7%A4%D7%9C%D7%A6%D7%AA%D7%99)).

## הגדרה

אפשר להגדיר את אינווריאנט $`j`$ כפונקציה על חצי המישור העליון $`\mathcal H = \{\tau \in \mathbb C \mid \mathrm{Im}\tau \gt 0\}`$ על ידי



```math
j(\tau) = 1728\frac{g_2(\tau)^3}{\Delta(\tau)} = 1728\frac{g_2(\tau)^3}{g_2(\tau)^3 - 27g_3(\tau)^2} = 1728\frac{g_2(\tau)^3}{(2\pi)^{12}\eta(\tau)^{24} }.
```

 מההגדרה השלישית רואים ש-$`j(\tau)`$ הוא [קובייה](https://he.wikipedia.org/wiki/%D7%97%D7%96%D7%A7%D7%94_%D7%A9%D7%9C%D7%99%D7%A9%D7%99%D7%AA) של פונקציה (כי גם $`1728 = 12^3`$ קובייה). אי אפשר להמשיך את הפונקציה [אנליטית](https://he.wikipedia.org/wiki/%D7%94%D7%9E%D7%A9%D7%9B%D7%94_%D7%90%D7%A0%D7%9C%D7%99%D7%98%D7%99%D7%AA) מעבר לחצי המישור העליון, כי הציר הממשי הוא [שפה טבעית](https://he.wikipedia.org/wiki/%D7%A9%D7%A4%D7%94_%D7%98%D7%91%D7%A2%D7%99%D7%AA) שלה.

הפונקציות שמופיעות כאן הן [הדיסקרימיננטה המודולרית](https://he.wikipedia.org/wiki/%D7%94%D7%93%D7%99%D7%A1%D7%A7%D7%A8%D7%99%D7%9E%D7%99%D7%A0%D7%A0%D7%98%D7%94_%D7%94%D7%9E%D7%95%D7%93%D7%95%D7%9C%D7%A8%D7%99%D7%AA) $`\Delta(\tau) = g_2(\tau)^3 - 27g_3(\tau)^2 = (2\pi)^{12}\eta(\tau)^{24}`$, [פונקציית אטא של דדקינד](%D7%A4%D7%95%D7%A0%D7%A7%D7%A6%D7%99%D7%99%D7%AA%20%D7%90%D7%98%D7%90%20%D7%A9%D7%9C%20%D7%93%D7%93%D7%A7%D7%99%D7%A0%D7%93.md) $`\eta(\tau)`$, והאינווריאנטים המודולריים



```math
g_2(\tau) = 60G_4(\tau) = 60\sum_{(m, n) \ne (0, 0)}(m + n\tau)^{-4}, \qquad g_3(\tau) = 140G_6(\tau) = 140\sum_{(m, n) \ne (0, 0)}(m + n\tau)^{-6},
```

 כאשר ל-$`G_4, G_6`$ יש [פיתוחי פורייה](https://he.wikipedia.org/wiki/%D7%98%D7%95%D7%A8_%D7%90%D7%99%D7%99%D7%96%D7%A0%D7%A9%D7%98%D7%99%D7%99%D7%9F)



```math
G_4(\tau) = \frac{\pi^4}{45}E_4(\tau), \qquad G_6(\tau) = \frac{2\pi^6}{945}E_6(\tau),
```

 ו-$`E_4, E_6`$ הם [טורי אייזנשטיין](https://he.wikipedia.org/wiki/%D7%98%D7%95%D7%A8_%D7%90%D7%99%D7%99%D7%96%D7%A0%D7%A9%D7%98%D7%99%D7%99%D7%9F) המנורמלים



```math
E_4(\tau) = 1 + 240\sum_{n=1}^\infty\frac{n^3q^n}{1 - q^n}, \qquad E_6(\tau) = 1 - 504\sum_{n=1}^\infty\frac{n^5q^n}{1 - q^n},
```

 עם $`q = e^{2\pi i\tau}`$ (ריבוע ה[נום](https://he.wikipedia.org/wiki/%D7%A0%D7%95%D7%9D_%28%D7%9E%D7%AA%D7%9E%D7%98%D7%99%D7%A7%D7%94%29)). כך אפשר לבטא את $`j`$ ישירות בעזרת טורי אייזנשטיין:



```math
j(\tau) = 1728\frac{E_4(\tau)^3}{E_4(\tau)^3 - E_6(\tau)^2},
```

 בלי מקדם מספרי נוסף מלבד 1728. מכאן נובעת גם דרך שלישית להגדיר את הדיסקרימיננטה המודולרית:



```math
\Delta(\tau) = (2\pi)^{12}\frac{E_4(\tau)^3 - E_6(\tau)^2}{1728}.
```



**דוגמה: $`\tau = 2i`$.** לפונקציית אטא של דדקינד יש ב-$`2i`$ [ערך מדויק](%D7%A4%D7%95%D7%A0%D7%A7%D7%A6%D7%99%D7%99%D7%AA%20%D7%90%D7%98%D7%90%20%D7%A9%D7%9C%20%D7%93%D7%93%D7%A7%D7%99%D7%A0%D7%93.md)



```math
\eta(2i) = \frac{\Gamma\left(\frac14\right)}{2^{11/8}\pi^{3/4} },
```

 ומכאן ה[מספרים הטרנסצנדנטיים](https://he.wikipedia.org/wiki/%D7%9E%D7%A1%D7%A4%D7%A8_%D7%98%D7%A8%D7%A0%D7%A1%D7%A6%D7%A0%D7%93%D7%A0%D7%98%D7%99)



```math
g_2(2i) = \frac{11\,\Gamma\left(\frac14\right)^8}{2^8\pi^2}, \qquad g_3(2i) = \frac{7\,\Gamma\left(\frac14\right)^{12} }{2^{12}\pi^3},
```

 אבל הצירוף שלהם נותן [מספר אלגברי](https://he.wikipedia.org/wiki/%D7%9E%D7%A1%D7%A4%D7%A8_%D7%90%D7%9C%D7%92%D7%91%D7%A8%D7%99), ולמעשה [מספר שלם](https://he.wikipedia.org/wiki/%D7%9E%D7%A1%D7%A4%D7%A8_%D7%A9%D7%9C%D7%9D):



```math
j(2i) = 1728\frac{g_2(2i)^3}{g_2(2i)^3 - 27g_3(2i)^2} = 1728\cdot\frac{11^3}{11^3 - 27\cdot 7^2} = 1728\cdot\frac{1331}{8} = 66^3 = 287496.
```

 (כל החזקות של $`\Gamma(1/4)`$ ושל $`\pi`$ מצטמצמות: $`g_2^3`$ ו-$`g_3^2`$ שתיהן מכפלות של $`\Gamma(1/4)^{24}/\pi^6`$. את ארבעת הערכים בדקנו גם בחישוב מספרי.)

את כל זה אפשר להבין כשמסתכלים על כל $`\tau`$ כמייצג מחלקת איזומורפיזם של עקומים אליפטיים. כל עקום אליפטי $`E`$ מעל $`\mathbb C`$ הוא [טורוס מרוכב](https://he.wikipedia.org/wiki/%D7%98%D7%95%D7%A8%D7%95%D7%A1_%D7%9E%D7%A8%D7%95%D7%9B%D7%91), ולכן אפשר לזהות אותו עם [סריג](https://he.wikipedia.org/wiki/%D7%A1%D7%A8%D7%99%D7%92_%28%D7%97%D7%91%D7%95%D7%A8%D7%94%29) מדרגה 2 ב-$`\mathbb C`$. אפשר לסובב ולמתוח את הסריג (פעולות ששומרות על מחלקת האיזומורפיזם) כך שייווצר על ידי $`1`$ ו-$`\tau \in \mathcal H`$. הסריג הזה מתאים לעקום האליפטי $`y^2 = 4x^3 - g_2(\tau)x - g_3(\tau)`$ (ראו [הפונקציה האליפטית של ויירשטראס](https://he.wikipedia.org/wiki/%D7%94%D7%A4%D7%95%D7%A0%D7%A7%D7%A6%D7%99%D7%94_%D7%94%D7%90%D7%9C%D7%99%D7%A4%D7%98%D7%99%D7%AA_%D7%A9%D7%9C_%D7%95%D7%99%D7%99%D7%A8%D7%A9%D7%98%D7%A8%D7%90%D7%A1)).

$`j`$ מוגדרת בכל $`\mathcal H`$, כי הדיסקרימיננטה המודולרית אינה מתאפסת שם. זה נובע מכך שלפולינום הממעלה השלישית המתאים יש שורשים שונים.

## התחום היסודי

אפשר להראות ש-$`\Delta`$ היא [תבנית מודולרית](https://he.wikipedia.org/wiki/%D7%AA%D7%91%D7%A0%D7%99%D7%AA_%D7%9E%D7%95%D7%93%D7%95%D7%9C%D7%A8%D7%99%D7%AA) ממשקל 12, ו-$`g_2`$ ממשקל 4, כך ש-$`g_2^3`$ גם היא ממשקל 12. לכן המנה שלהן, ומכאן $`j`$, היא פונקציה מודולרית ממשקל אפס; בפרט, פונקציה הולומורפית $`\mathcal H \to \mathbb C`$ שאינה משתנה תחת הפעולה של $`\mathrm{SL}(2, \mathbb Z)`$. חלוקה במרכז $`\{\pm I\}`$ נותנת את [החבורה המודולרית](https://he.wikipedia.org/wiki/%D7%94%D7%97%D7%91%D7%95%D7%A8%D7%94_%D7%94%D7%9E%D7%95%D7%93%D7%95%D7%9C%D7%A8%D7%99%D7%AA), שאפשר לזהות עם החבורה $`\mathrm{PSL}(2, \mathbb Z)`$.

בעזרת העתקה מתאימה מהחבורה הזו,



```math
\tau \mapsto \frac{a\tau + b}{c\tau + d}, \qquad ad - bc = 1,
```

 אפשר להעביר את $`\tau`$ לערך שנותן אותו ערך של $`j`$ ונמצא ב[תחום היסודי](https://he.wikipedia.org/wiki/%D7%AA%D7%97%D7%95%D7%9D_%D7%99%D7%A1%D7%95%D7%93%D7%99) של $`j`$, שמורכב מהערכים של $`\tau`$ שמקיימים



```math
|\tau| \ge 1, \qquad -\tfrac12 \lt \mathrm{Re}\tau \le \tfrac12, \qquad -\tfrac12 \lt \mathrm{Re}\tau \lt 0 \Rightarrow |\tau| \gt 1.
```

 הפונקציה $`j(\tau)`$, כשמצמצמים אותה לתחום הזה, עדיין מקבלת כל ערך מרוכב בדיוק פעם אחת. במילים אחרות, לכל $`c \in \mathbb C`$ יש $`\tau`$ יחיד בתחום היסודי שעבורו $`c = j(\tau)`$, ולכן $`j`$ מעתיקה את התחום היסודי על כל המישור המרוכב.

בנוסף, שני ערכים $`\tau, \tau' \in \mathcal H`$ נותנים את אותו עקום אליפטי אם ורק אם $`\tau = T(\tau')`$ עבור $`T \in \mathrm{PSL}(2, \mathbb Z)`$ כלשהו. לכן $`j`$ נותנת [התאמה חד-חד-ערכית ועל](https://he.wikipedia.org/wiki/%D7%A4%D7%95%D7%A0%D7%A7%D7%A6%D7%99%D7%94_%D7%97%D7%93-%D7%97%D7%93-%D7%A2%D7%A8%D7%9B%D7%99%D7%AA_%D7%95%D7%A2%D7%9C) בין קבוצת מחלקות האיזומורפיזם של עקומים אליפטיים מעל $`\mathbb C`$ לבין המישור המרוכב.[^1]

כ[משטח רימן](https://he.wikipedia.org/wiki/%D7%9E%D7%A9%D7%98%D7%97_%D7%A8%D7%99%D7%9E%D7%9F), לתחום היסודי (אחרי הדבקת השפות והוספת החוד) יש [גנוס](https://he.wikipedia.org/wiki/%D7%92%D7%A0%D7%95%D7%A1_%28%D7%9E%D7%AA%D7%9E%D7%98%D7%99%D7%A7%D7%94%29) 0, וכל פונקציה מודולרית ([מרמה 1](https://he.wikipedia.org/wiki/%D7%AA%D7%91%D7%A0%D7%99%D7%AA_%D7%9E%D7%95%D7%93%D7%95%D7%9C%D7%A8%D7%99%D7%AA)) היא פונקציה רציונלית ב-$`j`$; ולהפך, כל פונקציה רציונלית ב-$`j`$ היא פונקציה מודולרית. במילים אחרות, שדה הפונקציות המודולריות הוא $`\mathbb C(j)`$.

## תורת שדות המחלקה ו-$`j`$

*ערך מורחב: [כפל מרוכב](%D7%9B%D7%A4%D7%9C%20%D7%9E%D7%A8%D7%95%D7%9B%D7%91.md), [הבעיה השתים-עשרה של הילברט](https://he.wikipedia.org/wiki/%D7%94%D7%91%D7%A2%D7%99%D7%94_%D7%94%D7%A9%D7%AA%D7%99%D7%9D-%D7%A2%D7%A9%D7%A8%D7%94_%D7%A9%D7%9C_%D7%94%D7%99%D7%9C%D7%91%D7%A8%D7%98)* לאינווריאנט $`j`$ יש תכונות מופלאות רבות:

- אם $`\tau`$ נקודה בחצי המישור העליון שהעקום האליפטי המתאים לה הוא בעל [כפל מרוכב](%D7%9B%D7%A4%D7%9C%20%D7%9E%D7%A8%D7%95%D7%9B%D7%91.md) (כלומר, אם $`\tau`$ איבר של [שדה ריבועי](https://he.wikipedia.org/wiki/%D7%A9%D7%93%D7%94_%D7%A8%D7%99%D7%91%D7%95%D7%A2%D7%99) מדומה עם חלק מדומה חיובי), אז $`j(\tau)`$ הוא [שלם אלגברי](https://he.wikipedia.org/wiki/%D7%A9%D7%9C%D7%9D_%D7%90%D7%9C%D7%92%D7%91%D7%A8%D7%99).[^2] הערכים המיוחדים האלה נקראים [מודולי סינגולריים](https://he.wikipedia.org/wiki/%D7%9E%D7%95%D7%93%D7%95%D7%9C%D7%99_%D7%A1%D7%99%D7%A0%D7%92%D7%95%D7%9C%D7%A8%D7%99%D7%99%D7%9D).
- ההרחבה $`\mathbb Q(j(\tau), \tau)/\mathbb Q(\tau)`$ היא [אבלית](%D7%94%D7%A8%D7%97%D7%91%D7%94%20%D7%90%D7%91%D7%9C%D7%99%D7%AA.md), כלומר חבורת גלואה שלה אבלית.
- יהי $`\Lambda`$ הסריג ב-$`\mathbb C`$ שנוצר על ידי $`\{1, \tau\}`$. קל לראות שכל האיברים של $`\mathbb Q(\tau)`$ שמשמרים את $`\Lambda`$ תחת כפל יוצרים חוג עם יחידה, שנקרא [סדר](https://he.wikipedia.org/wiki/%D7%A1%D7%93%D7%A8_%28%D7%AA%D7%95%D7%A8%D7%AA_%D7%94%D7%97%D7%95%D7%92%D7%99%D7%9D%29). הסריגים האחרים עם יוצרים $`\{1, \tau'\}`$ שמתאימים באותו אופן לאותו סדר נותנים את ה[צמודים האלגבריים](https://he.wikipedia.org/wiki/%D7%A6%D7%9E%D7%95%D7%93_%28%D7%AA%D7%95%D7%A8%D7%AA_%D7%94%D7%A9%D7%93%D7%95%D7%AA%29) $`j(\tau')`$ של $`j(\tau)`$ מעל $`\mathbb Q(\tau)`$. בסדר ההכלה, הסדר המקסימלי היחיד ב-$`\mathbb Q(\tau)`$ הוא [חוג השלמים](https://he.wikipedia.org/wiki/%D7%97%D7%95%D7%92_%D7%94%D7%A9%D7%9C%D7%9E%D7%99%D7%9D) של $`\mathbb Q(\tau)`$, וערכי $`\tau`$ שזה הסדר שלהם נותנים [הרחבות לא מסועפות](https://he.wikipedia.org/wiki/%D7%94%D7%A8%D7%97%D7%91%D7%94_%D7%9C%D7%90_%D7%9E%D7%A1%D7%95%D7%A2%D7%A4%D7%AA) של $`\mathbb Q(\tau)`$: $`\mathbb Q(\tau, j(\tau))`$ הוא [שדה המחלקה של הילברט](https://he.wikipedia.org/wiki/%D7%A9%D7%93%D7%94_%D7%94%D7%9E%D7%97%D7%9C%D7%A7%D7%94_%D7%A9%D7%9C_%D7%94%D7%99%D7%9C%D7%91%D7%A8%D7%98) של $`\mathbb Q(\tau)`$.

**דוגמאות.** ל-$`\mathbb Q(i)`$ מספר מחלקה 1, ולכן $`j(i) = 1728`$ רציונלי; אותו דבר עבור $`j(e^{2\pi i/3}) = 0`$. לסדר $`\mathbb Z[2i]`$ (מאינדקס 2 ב-$`\mathbb Z[i]`$) מספר מחלקה 1 גם הוא, ולכן $`j(2i) = 66^3`$ רציונלי. עבור $`\mathbb Q(\sqrt{-163})`$, השדה הריבועי המדומה האחרון עם מספר מחלקה 1, מתקבל



```math
j\left(\frac{1 + \sqrt{-163} }2\right) = -640320^3.
```



התוצאות הקלאסיות האלה הן נקודת המוצא של תורת הכפל המרוכב.

## תכונות טרנסצנדנטיות

ב-1937 הוכיח תאודור שניידר את התוצאה שהוזכרה, שאם $`\tau`$ [מספר אי-רציונלי ריבועי](https://he.wikipedia.org/wiki/%D7%9E%D7%A1%D7%A4%D7%A8_%D7%90%D7%99-%D7%A8%D7%A6%D7%99%D7%95%D7%A0%D7%9C%D7%99_%D7%A8%D7%99%D7%91%D7%95%D7%A2%D7%99) בחצי המישור העליון אז $`j(\tau)`$ שלם אלגברי. בנוסף הוא הוכיח שאם $`\tau`$ [מספר אלגברי](https://he.wikipedia.org/wiki/%D7%9E%D7%A1%D7%A4%D7%A8_%D7%90%D7%9C%D7%92%D7%91%D7%A8%D7%99) שאינו ריבועי מדומה, אז $`j(\tau)`$ [טרנסצנדנטי](https://he.wikipedia.org/wiki/%D7%9E%D7%A1%D7%A4%D7%A8_%D7%98%D7%A8%D7%A0%D7%A1%D7%A6%D7%A0%D7%93%D7%A0%D7%98%D7%99).

לפונקציה $`j`$ יש עוד תכונות טרנסצנדנטיות רבות. קורט מאהלר שיער תוצאת טרנסצנדנטיות מסוימת שנקראת לעיתים קרובות השערת מאהלר: אם $`\tau`$ בחצי המישור העליון, אז $`e^{2\pi i\tau}`$ ו-$`j(\tau)`$ אינם אף פעם אלגבריים בו-זמנית. ההשערה הוכחה ב-1996 על ידי ברה-סירייה, דיאז, גרמן ופיליבר, ונובעת גם מהתוצאות של יורי נסטרנקו ופטריס פיליפון משנות ה-90.[^3] כיום ידועות תוצאות חזקות יותר; למשל, אם $`e^{2\pi i\tau}`$ אלגברי, אז שלושת המספרים



```math
j(\tau), \quad \frac{j'(\tau)}{\pi}, \quad \frac{j''(\tau)}{\pi^2}
```

 [בלתי תלויים אלגברית](https://he.wikipedia.org/wiki/%D7%90%D7%99-%D7%AA%D7%9C%D7%95%D7%AA_%D7%90%D7%9C%D7%92%D7%91%D7%A8%D7%99%D7%AA), ולכן לפחות שניים מהם טרנסצנדנטיים.

## פיתוח $`q`$ וירח

כמה מהתכונות המופלאות של $`j`$ קשורות ל[פיתוח ה-$`q`$](https://he.wikipedia.org/wiki/%D7%A4%D7%99%D7%AA%D7%95%D7%97_q) שלה ([פיתוח פורייה](https://he.wikipedia.org/wiki/%D7%98%D7%95%D7%A8_%D7%A4%D7%95%D7%A8%D7%99%D7%99%D7%94)), שנכתב כ[טור לורן](https://he.wikipedia.org/wiki/%D7%98%D7%95%D7%A8_%D7%9C%D7%95%D7%A8%D7%9F) במשתנה $`q = e^{2\pi i\tau}`$, ומתחיל כך:



```math
j(\tau) = q^{-1} + 744 + 196884\,q + 21493760\,q^2 + 864299970\,q^3 + 20245856256\,q^4 + \cdots
```

 ל-$`j`$ יש [קוטב פשוט](https://he.wikipedia.org/wiki/%D7%A7%D7%95%D7%98%D7%91_%28%D7%90%D7%A0%D7%9C%D7%99%D7%96%D7%94_%D7%9E%D7%A8%D7%95%D7%9B%D7%91%D7%AA%29) בחוד, ולכן אין בפיתוח שלה איברים מתחת ל-$`q^{-1}`$. (את המקדמים האלה בדקנו בחישוב של $`E_4^3/\Delta`$, עם $`\Delta/(2\pi)^{12} = q\prod_{n\ge1}(1 - q^n)^{24}`$.)

כל מקדמי פורייה שלמים, וזה נותן כמה [מספרים כמעט-שלמים](https://he.wikipedia.org/wiki/%D7%9B%D7%9E%D7%A2%D7%98-%D7%A9%D7%9C%D7%9D), ובמיוחד את **הקבוע של רמנוג'אן**:



```math
e^{\pi\sqrt{163} } \approx 640320^3 + 744,
```

 כאשר ההפרש הוא בערך $`-7.5\cdot 10^{-13}`$. ההסבר: עבור $`\tau = \frac{1 + \sqrt{-163} }2`$ מתקיים $`q = -e^{-\pi\sqrt{163} }`$, ולכן $`-640320^3 = j(\tau) = -e^{\pi\sqrt{163} } + 744 - 196884e^{-\pi\sqrt{163} } + \cdots`$, והאיבר $`196884e^{-\pi\sqrt{163} }`$ כבר זעיר.

ה[נוסחה אסימפטוטית](https://he.wikipedia.org/wiki/%D7%A0%D7%95%D7%A1%D7%97%D7%94_%D7%90%D7%A1%D7%99%D7%9E%D7%A4%D7%98%D7%95%D7%98%D7%99%D7%AA) למקדם של $`q^n`$ היא



```math
\frac{e^{4\pi\sqrt n} }{\sqrt2\,n^{3/4} },
```

 וניתן להוכיח אותה ב[שיטת המעגל של הארדי–ליטלווד](https://he.wikipedia.org/wiki/%D7%A9%D7%99%D7%98%D7%AA_%D7%94%D7%9E%D7%A2%D7%92%D7%9C_%D7%A9%D7%9C_%D7%94%D7%90%D7%A8%D7%93%D7%99%E2%80%93%D7%9C%D7%99%D7%98%D7%9C%D7%95%D7%95%D7%93).[^4]

### ירח

מפתיע עוד יותר שמקדמי פורייה של החזקות החיוביות של $`q`$ הם הממדים של החלקים המדורגים של [הצגה](https://he.wikipedia.org/wiki/%D7%94%D7%A6%D7%92%D7%94_%28%D7%9E%D7%AA%D7%9E%D7%98%D7%99%D7%A7%D7%94%29) אינסופית-ממדית מדורגת של [חבורת המפלצת](https://he.wikipedia.org/wiki/%D7%97%D7%91%D7%95%D7%A8%D7%AA_%D7%94%D7%9E%D7%A4%D7%9C%D7%A6%D7%AA), שנקראת **מודול הירח**: המקדם של $`q^n`$ הוא הממד של החלק מדרגה $`n`$ של מודול הירח. הדוגמה הראשונה היא [אלגברת גריס](https://he.wikipedia.org/wiki/%D7%90%D7%9C%D7%92%D7%91%D7%A8%D7%AA_%D7%92%D7%A8%D7%99%D7%A1), שממדה 196884, בהתאם לאיבר $`196884q`$; ואכן $`196884 = 1 + 196883`$, כאשר 196883 הוא הממד של ההצגה האי-פריקה הלא-טריוויאלית הקטנה ביותר של המפלצת. ההבחנה המדהימה הזו, של ג'ון מקיי, הייתה נקודת המוצא של [תורת הירח](https://he.wikipedia.org/wiki/%D7%99%D7%A8%D7%97_%D7%9E%D7%A4%D7%9C%D7%A6%D7%AA%D7%99).

חקר השערת הירח הוביל את ג'ון הורטון קונוויי ואת סיימון נורטון לבחון את הפונקציות המודולריות מגנוס אפס. אם מנרמלים אותן לצורה



```math
q^{-1} + O(q),
```

 אז ג'ון ג' תומפסון הראה שיש רק מספר סופי של פונקציות כאלה (מרמה סופית כלשהי), וכריס קאמינס הראה מאוחר יותר שיש בדיוק 6486 כאלה, ש-616 מהן בעלות מקדמים שלמים.[^5]

## ביטויים חלופיים

מתקיים



```math
j(\tau) = \frac{256(1 - x)^3}{x^2},
```

 כאשר $`x = \lambda(1 - \lambda)`$ ו-$`\lambda`$ היא [פונקציית למבדא המודולרית](https://he.wikipedia.org/wiki/%D7%A4%D7%95%D7%A0%D7%A7%D7%A6%D7%99%D7%99%D7%AA_%D7%9C%D7%9E%D7%91%D7%93%D7%90_%D7%94%D7%9E%D7%95%D7%93%D7%95%D7%9C%D7%A8%D7%99%D7%AA)



```math
\lambda(\tau) = \frac{\theta_2(e^{\pi i\tau})^4}{\theta_3(e^{\pi i\tau})^4} = k(\tau)^2,
```

 מנה של [פונקציות תטא של יעקובי](https://he.wikipedia.org/wiki/%D7%A4%D7%95%D7%A0%D7%A7%D7%A6%D7%99%D7%99%D7%AA_%D7%AA%D7%98%D7%90) $`\theta_m`$, שהיא הריבוע של המודולוס האליפטי $`k(\tau)`$.[^6] הערך של $`j`$ אינו משתנה כאשר מחליפים את $`\lambda`$ בכל אחד משישת הערכים של [היחס הכפול](https://he.wikipedia.org/wiki/%D7%99%D7%97%D7%A1_%D7%9B%D7%A4%D7%95%D7%9C):[^7]



```math
\left\{\lambda,\ \frac1{1 - \lambda},\ \frac{\lambda - 1}\lambda,\ \frac1\lambda,\ \frac\lambda{\lambda - 1},\ 1 - \lambda\right\}.
```

 נקודות ההסתעפות של $`j`$ (כפונקציה של $`\lambda`$) הן מעל $`\{0, 1728, \infty\}`$, כך ש-$`j/1728`$ היא [פונקציית בלי](https://he.wikipedia.org/wiki/%D7%A4%D7%95%D7%A0%D7%A7%D7%A6%D7%99%D7%99%D7%AA_%D7%91%D7%9C%D7%99) עם נקודות הסתעפות $`\{0, 1, \infty\}`$.[^8]

## ביטויים בעזרת פונקציות תטא

מגדירים את ה[נום](https://he.wikipedia.org/wiki/%D7%A0%D7%95%D7%9D_%28%D7%9E%D7%AA%D7%9E%D7%98%D7%99%D7%A7%D7%94%29) $`q = e^{\pi i\tau}`$ (שימו לב: כאן $`q = e^{\pi i\tau}`$, ולא $`e^{2\pi i\tau}`$ כבסעיפים הקודמים) ואת [פונקציית התטא של יעקובי](https://he.wikipedia.org/wiki/%D7%A4%D7%95%D7%A0%D7%A7%D7%A6%D7%99%D7%99%D7%AA_%D7%AA%D7%98%D7%90)



```math
\vartheta(0; \tau) = \vartheta_{00}(0; \tau) = 1 + 2\sum_{n=1}^\infty\left(e^{\pi i\tau}\right)^{n^2} = \sum_{n=-\infty}^\infty q^{n^2},
```

 שממנה אפשר לגזור את פונקציות התטא העזר. נסמן



```math
a = \theta_2(q) = \vartheta_{10}(0; \tau), \qquad b = \theta_3(q) = \vartheta_{00}(0; \tau), \qquad c = \theta_4(q) = \vartheta_{01}(0; \tau),
```

 כאשר $`\vartheta_{ij}`$ ו-$`\theta_n`$ הם סימונים חלופיים, ו-$`a^4 - b^4 + c^4 = 0`$ (זהות יעקובי). אז האינווריאנטים המודולריים $`g_2, g_3`$ הם



```math
g_2(\tau) = \tfrac23\pi^4\left(a^8 + b^8 + c^8\right), \qquad g_3(\tau) = \tfrac4{27}\pi^6\sqrt{\frac{\left(a^8 + b^8 + c^8\right)^3 - 54(abc)^8}2},
```

 והדיסקרימיננטה המודולרית היא



```math
\Delta = g_2^3 - 27g_3^2 = (2\pi)^{12}\left(\tfrac12 abc\right)^8 = (2\pi)^{12}\eta(\tau)^{24},
```

 עם פונקציית אטא של דדקינד $`\eta(\tau)`$. כך אפשר לחשב את $`j(\tau)`$ במהירות:



```math
j(\tau) = 1728\frac{g_2^3}{g_2^3 - 27g_3^2} = 32\frac{\left(a^8 + b^8 + c^8\right)^3}{(abc)^8}.
```



## הגדרה אלגברית

עד כאן התייחסנו ל-$`j`$ כפונקציה של משתנה מרוכב. אבל כאינווריאנט של מחלקות איזומורפיזם של עקומים אליפטיים, אפשר להגדיר אותו באופן אלגברי טהור.[^9] יהי



```math
y^2 + a_1xy + a_3y = x^3 + a_2x^2 + a_4x + a_6
```

 עקום אליפטי מישורי **מעל שדה כלשהו**. מגדירים



```math
\begin{align}
b_2 &= a_1^2 + 4a_2, & b_4 &= a_1a_3 + 2a_4,\\
b_6 &= a_3^2 + 4a_6, & b_8 &= a_1^2a_6 - a_1a_3a_4 + a_2a_3^2 + 4a_2a_6 - a_4^2,\\
c_4 &= b_2^2 - 24b_4, & c_6 &= -b_2^3 + 36b_2b_4 - 216b_6,
\end{align}
```

 ואת ה[דיסקרימיננטה](https://he.wikipedia.org/wiki/%D7%93%D7%99%D7%A1%D7%A7%D7%A8%D7%99%D7%9E%D7%99%D7%A0%D7%A0%D7%98%D7%94)



```math
\Delta = -b_2^2b_8 + 9b_2b_4b_6 - 8b_4^3 - 27b_6^2.
```

 כאשר המאפיין של השדה אינו 2 או 3, אפשר להעביר את המשוואה בהחלפות משתנים עוקבות לצורה הסטנדרטית $`y^2 = 4x^3 - g_2x - g_3`$, עם $`g_2 = c_4/12`$ ו-$`g_3 = c_6/216`$.[^10]

אינווריאנט $`j`$ של העקום האליפטי מוגדר אז כ-



```math
j = \frac{c_4^3}{\Delta}.
```

 כאשר מאפיין השדה שונה מ-2 ו-3, זה שווה ל-



```math
j = 1728\frac{c_4^3}{c_4^3 - c_6^2}
```

 (כי $`1728\Delta = c_4^3 - c_6^2`$). עבור עקום אליפטי בצורת ויירשטראס הקצרה $`y^2 = x^3 + ax + b`$ הנוסחה מתפשטת ל-



```math
j = 1728\frac{4a^3}{4a^3 + 27b^2},
```

 ועבור [עקום מונטגומרי](%D7%A2%D7%A7%D7%95%D7%9D%20%D7%9E%D7%95%D7%A0%D7%98%D7%92%D7%95%D7%9E%D7%A8%D7%99.md) $`By^2 = x^3 + Ax^2 + x`$ ל-



```math
j = 256\frac{(A^2 - 3)^3}{(A + 2)(A - 2)}.
```



**דוגמאות.** ל-$`y^2 = x^3 - x`$ ($`a = -1`$, $`b = 0`$) מתקבל $`j = 1728`$, ול-$`y^2 = x^3 + 1`$ מתקבל $`j = 0`$: אלה העקומים עם כפל מרוכב ב-$`\mathbb Z[i]`$ וב-$`\mathbb Z[e^{2\pi i/3}]`$, בהתאמה. ל-$`y^2 = x^3 + x + 1`$: $`j = 1728\cdot\frac{4}{4 + 27} = \frac{6912}{31}`$.

## הפונקציה ההפוכה

את ה[פונקציה ההפוכה](https://he.wikipedia.org/wiki/%D7%A4%D7%95%D7%A0%D7%A7%D7%A6%D7%99%D7%94_%D7%94%D7%A4%D7%95%D7%9B%D7%94) של אינווריאנט $`j`$ אפשר לבטא בעזרת ה[פונקציה ההיפרגאומטרית](https://he.wikipedia.org/wiki/%D7%A4%D7%95%D7%A0%D7%A7%D7%A6%D7%99%D7%94_%D7%94%D7%99%D7%A4%D7%A8%D7%92%D7%90%D7%95%D7%9E%D7%98%D7%A8%D7%99%D7%AA) $`{}_2F_1`$ (ראו גם [משוואת פיקאר–פוקס](https://he.wikipedia.org/wiki/%D7%9E%D7%A9%D7%95%D7%95%D7%90%D7%AA_%D7%A4%D7%99%D7%A7%D7%90%D7%A8%E2%80%93%D7%A4%D7%95%D7%A7%D7%A1)). במפורש, בהינתן מספר $`N`$, אפשר לפתור את המשוואה $`j(\tau) = N`$ עבור $`\tau`$ לפחות בארבע דרכים.

**שיטה 1:** פותרים את המשוואה ממעלה שישית ב-$`\lambda`$,



```math
j(\tau) = \frac{256\bigl(1 - \lambda(1 - \lambda)\bigr)^3}{\bigl(\lambda(1 - \lambda)\bigr)^2} = \frac{256(1 - x)^3}{x^2},
```

 כאשר $`x = \lambda(1 - \lambda)`$, כך שאפשר לפתור אותה כמשוואה ממעלה שלישית ב-$`x`$. אז



```math
\tau = i\,\frac{ {}_2F_1\left(\tfrac12, \tfrac12; 1; 1 - \lambda\right)}{ {}_2F_1\left(\tfrac12, \tfrac12; 1; \lambda\right)} = i\,\frac{M\left(1, \sqrt{1 - \lambda}\right)}{M\left(1, \sqrt\lambda\right)}
```

 לכל אחד משישת הערכים של $`\lambda`$, כאשר $`M`$ הוא [הממוצע האריתמטי-גאומטרי](https://he.wikipedia.org/wiki/%D7%94%D7%9E%D7%9E%D7%95%D7%A6%D7%A2_%D7%94%D7%90%D7%A8%D7%99%D7%AA%D7%9E%D7%98%D7%99-%D7%92%D7%90%D7%95%D7%9E%D7%98%D7%A8%D7%99).<ref>השוויון מתקיים אם מגדירים את הממוצע האריתמטי-גאומטרי $`M(a, b)`$ של מספרים מרוכבים $`a, b`$ (עם $`a, b \ne 0`$, $`a \ne \pm b`$) כך: $`a_0 = a`$, $`b_0 = b`$, $`a_{n+1} = (a_n + b_n)/2`$, $`b_{n+1} = \pm\sqrt{a_nb_n}`$, כאשר הסימנים נבחרים כך ש-$</ref>

'''שיטה 2:''' פותרים את המשוואה ממעלה רביעית ב-<math>\gamma$,



```math
j(\tau) = \frac{27(1 + 8\gamma)^3}{\gamma(1 - \gamma)^3},
```

 ואז לכל אחד מארבעת השורשים,



```math
\tau = \frac i{\sqrt3}\,\frac{ {}_2F_1\left(\tfrac13, \tfrac23; 1; 1 - \gamma\right)}{ {}_2F_1\left(\tfrac13, \tfrac23; 1; \gamma\right)}.
```



**שיטה 3:** פותרים את המשוואה ממעלה שלישית ב-$`\beta`$,



```math
j(\tau) = \frac{64(1 + 3\beta)^3}{\beta(1 - \beta)^2},
```

 ואז לכל אחד משלושת השורשים,



```math
\tau = \frac i{\sqrt2}\,\frac{ {}_2F_1\left(\tfrac14, \tfrac34; 1; 1 - \beta\right)}{ {}_2F_1\left(\tfrac14, \tfrac34; 1; \beta\right)}.
```



**שיטה 4:** פותרים את המשוואה הריבועית ב-$`\alpha`$,



```math
j(\tau) = \frac{1728}{4\alpha(1 - \alpha)},
```

 ואז



```math
\tau = i\,\frac{ {}_2F_1\left(\tfrac16, \tfrac56; 1; 1 - \alpha\right)}{ {}_2F_1\left(\tfrac16, \tfrac56; 1; \alpha\right)}.
```

 שורש אחד נותן את $`\tau`$ והשני את $`-1/\tau`$, אבל כיוון ש-$`j(\tau) = j(-1/\tau)`$, לא משנה איזה $`\alpha`$ בוחרים. שלוש השיטות האחרונות מופיעות בתורה של [רמנוג'אן](https://he.wikipedia.org/wiki/%D7%A1%D7%A8%D7%99%D7%A0%D7%99%D7%95%D7%95%D7%90%D7%A1%D7%94_%D7%A8%D7%9E%D7%A0%D7%95%D7%92%27%D7%90%D7%9F) על [פונקציות אליפטיות](https://he.wikipedia.org/wiki/%D7%A4%D7%95%D7%A0%D7%A7%D7%A6%D7%99%D7%94_%D7%90%D7%9C%D7%99%D7%A4%D7%98%D7%99%D7%AA) בבסיסים חלופיים. (את ארבע השיטות בדקנו בחישוב מספרי, עבור $`\tau = 0.3 + 0.9i`$ וכל השורשים שנמצאו: בכל המקרים $`\tau`$ שמתקבל מקיים $`j(\tau) = N`$.)

ההיפוך משמש בחישובים בדיוק גבוה של מחזורים של פונקציות אליפטיות, גם כשהמנות שלהם גדלות מאוד. תוצאה קשורה היא שאפשר לבטא בעזרת שורשים ריבועיים בלבד את ערכי $`j`$ בנקודות על הציר המדומה שגודלן הוא חזקה של 2 (ולכן אפשר [לבנות אותם בסרגל ובמחוגה](https://he.wikipedia.org/wiki/%D7%91%D7%A0%D7%99%D7%99%D7%94_%D7%91%D7%A1%D7%A8%D7%92%D7%9C_%D7%95%D7%91%D7%9E%D7%97%D7%95%D7%92%D7%94)). התוצאה הזו כלל אינה מובנת מאליה, כי ה[משוואה המודולרית](https://he.wikipedia.org/wiki/%D7%9E%D7%A9%D7%95%D7%95%D7%90%D7%94_%D7%9E%D7%95%D7%93%D7%95%D7%9C%D7%A8%D7%99%D7%AA) של $`j`$ מסדר 2 היא ממעלה שלישית.[^11]

## נוסחאות ל-π

האחים צ'ודנובסקי מצאו ב-1987 את הנוסחה[^12]



```math
\frac1\pi = \frac{12}{640320^{3/2} }\sum_{k=0}^\infty\frac{(6k)!\,(163\cdot 3344418\,k + 13591409)}{(3k)!\,(k!)^3\,(-640320)^{3k} },
```

 שכל איבר בה מוסיף בערך 14 ספרות עשרוניות נכונות. ההוכחה שלה משתמשת בעובדה ש-



```math
j\left(\frac{1 + \sqrt{-163} }2\right) = -640320^3.
```

 לנוסחאות דומות ראו [טור רמנוג'אן–סאטו](https://he.wikipedia.org/wiki/%D7%98%D7%95%D7%A8_%D7%A8%D7%9E%D7%A0%D7%95%D7%92%27%D7%90%D7%9F%E2%80%93%D7%A1%D7%90%D7%98%D7%95).

## כישלון הסיווג מעל שדות אחרים

אינווריאנט $`j`$ מבחין רק בין מחלקות איזומורפיזם של עקומים אליפטיים מעל המספרים המרוכבים, או באופן כללי יותר מעל [שדה סגור אלגברית](https://he.wikipedia.org/wiki/%D7%A9%D7%93%D7%94_%D7%A1%D7%92%D7%95%D7%A8_%D7%90%D7%9C%D7%92%D7%91%D7%A8%D7%99%D7%AA). מעל שדות אחרים יש עקומים אליפטיים עם אותו אינווריאנט $`j`$ שאינם איזומורפיים (הם [סיבובים](%D7%A1%D7%99%D7%91%D7%95%D7%91%20%D7%A9%D7%9C%20%D7%A2%D7%A7%D7%95%D7%9D%20%D7%90%D7%9C%D7%99%D7%A4%D7%98%D7%99.md) זה של זה). למשל, יהיו



```math
E_1: y^2 = x^3 - 25x, \qquad E_2: y^2 = x^3 - 4x,
```

 ולשניהם אינווריאנט $`j = 1728`$. הנקודות הרציונליות של $`E_2`$ הן



```math
E_2(\mathbb Q) = \{\infty, (2, 0), (-2, 0), (0, 0)\},
```

 כי $`x^3 - 4x = x(x - 2)(x + 2)`$, ואין פתרונות רציונליים עם $`y \ne 0`$. העובדה האחרונה שקולה לכך ש-2 אינו [מספר קונגרואנטי](https://he.wikipedia.org/wiki/%D7%9E%D7%A1%D7%A4%D7%A8_%D7%A7%D7%95%D7%A0%D7%92%D7%A8%D7%95%D7%90%D7%A0%D7%98%D7%99), תוצאה שהולכת אחורה עד [פרמה](https://he.wikipedia.org/wiki/%D7%A4%D7%99%D7%99%D7%A8_%D7%93%D7%94_%D7%A4%D7%A8%D7%9E%D7%94); אפשר להוכיח אותה, למשל, בירידה ($`2`$-descent).[^13]

מצד שני, ל-$`E_1`$ יש את הנקודה $`(-4, 6)`$: $`(-4)^3 + 100 = 36`$. כדי למצוא נקודות נוספות, מחפשים נקודות מהצורה $`(-4n, 6n)`$ (הכפלה של הקואורדינטות ב-$`n`$, לא כפולה בחבורה). המשוואה של $`E_1`$ הופכת ל-$`36n^2 = -64n^3 + 100n`$. חלוקה ב-$`4n`$ (כדי לסלק את הפתרון $`(0, 0)`$) נותנת $`16n^2 + 9n - 25 = 0`$, ונוסחת השורשים נותנת את הפתרונות הרציונליים



```math
n = \frac{-9 \pm \sqrt{81 - 4\cdot 16\cdot(-25)} }{2\cdot 16} = \frac{-9 \pm 41}{32},
```

 כלומר $`n = 1`$ ו-$`n = -\tfrac{25}{16}`$. האחרון נותן את הנקודה $`\left(\tfrac{25}4, -\tfrac{75}8\right)`$, ואכן $`\left(\tfrac{25}4\right)^3 - 25\cdot\tfrac{25}4 = \tfrac{5625}{64} = \left(\tfrac{75}8\right)^2`$. למעשה $`(-4, 6)`$ מסדר אינסופי, ולכן ל-$`E_1`$ יש אינסוף נקודות רציונליות; לכן $`E_1 \not\cong E_2`$ מעל $`\mathbb Q`$. (זה מתאים לכך ש-5 הוא מספר קונגרואנטי: הוא השטח של המשולש עם הצלעות $`\tfrac32, \tfrac{20}3, \tfrac{41}6`$.)

מעל $`\mathbb Q(\sqrt{10})`$, לעומת זאת, העקומים איזומורפיים: ההעתקה



```math
E_2 \to E_1, \qquad (x, y) \mapsto (\mu^2x, \mu^3y), \qquad \mu = \frac{\sqrt{10} }2,
```

 היא איזומורפיזם, כי $`\mu^4 = \tfrac{25}4`$, ולכן $`(\mu^3y)^2 = \mu^6(x^3 - 4x) = (\mu^2x)^3 - 25(\mu^2x)`$.
