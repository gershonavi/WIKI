# השערת לנדר, פרקין וסלפרידג'

ב[תורת המספרים](https://he.wikipedia.org/wiki/%D7%AA%D7%95%D7%A8%D7%AA_%D7%94%D7%9E%D7%A1%D7%A4%D7%A8%D7%99%D7%9D), **השערת לנדר, פרקין וסלפרידג**' (**השערת LPS**) היא השערה פתוחה על [משוואות דיופנטיות](https://he.wikipedia.org/wiki/%D7%9E%D7%A9%D7%95%D7%95%D7%90%D7%94_%D7%93%D7%99%D7%95%D7%A4%D7%A0%D7%98%D7%99%D7%AA) של סכומים שווים של חזקות זהות. היא צופה שכל שוויון לא טריוויאלי



```math
x_1^k + x_2^k + \cdots + x_m^k = y_1^k + y_2^k + \cdots + y_n^k
```

 בין סכומים של חזקות $`k`$ של שלמים חיוביים חייב להכיל לפחות $`k`$ איברים בסך הכול; כלומר,



```math
m + n \ge k.
```

 "לא טריוויאלי" פירושו ששום איבר אינו מופיע בשני הצדדים, אחרי שמצמצמים איברים משותפים. ההשערה נבעה משאלה שהציגו [ליאון ג'. לנדר](https://he.wikipedia.org/wiki/%D7%9C%D7%99%D7%90%D7%95%D7%9F_%D7%92%27._%D7%9C%D7%A0%D7%93%D7%A8), [תומאס ר. פרקין](https://he.wikipedia.org/wiki/%D7%AA%D7%95%D7%9E%D7%90%D7%A1_%D7%A8._%D7%A4%D7%A8%D7%A7%D7%99%D7%9F) ו[ג'ון סלפרידג'](https://he.wikipedia.org/wiki/%D7%92%27%D7%95%D7%9F_%D7%A1%D7%9C%D7%A4%D7%A8%D7%99%D7%93%D7%92%27) בסקירה שלהם מ-1967 על סכומים שווים של חזקות זהות.[^1]

ההשערה עדיין פתוחה. בפרט, לא ידוע פתרון לא טריוויאלי בשלמים חיוביים של



```math
a^5 + b^5 = c^5 + d^5.
```

 [^2] (חיפוש שלנו על כל $`a \le b \lt 3000`$ לא מצא שני סכומים $`a^5 + b^5`$ שווים.)

## ניסוח

יהי $`k \ge 2`$ ויהיו $`m, n \ge 1`$. כיוון שאפשר להחליף בין הצדדים, אפשר להניח $`m \le n`$. נתבונן במשוואה



```math
\sum_{i=1}^mx_i^k = \sum_{j=1}^ny_j^k,
```

 שבה כל ה-$`x_i`$ וה-$`y_j`$ שלמים חיוביים ו-$`x_i \ne y_j`$ לכל $`i`$ ו-$`j`$. חזרות באותו צד של המשוואה אינן אסורות. השערת LPS קובעת שלמשוואה כזו יכול להיות פתרון רק אם $`m + n \ge k`$.

על משוואה מהצורה הזו נהוג לומר שהיא מ**טיפוס** $`(k, m, n)`$ (בסקירה המקורית הסימון היה $`(k.m.n)`$). פתרון נקרא **פרימיטיבי** אם $`\gcd(x_1, \ldots, x_m, y_1, \ldots, y_n) = 1`$. כל פתרון לא פרימיטיבי מתקבל מפתרון פרימיטיבי בכפל של כל הבסיסים בשלם חיובי משותף.

במקרה החד-צדדי $`m = 1`$, ההשערה אומרת ש-



```math
a_1^k + a_2^k + \cdots + a_r^k = b^k \quad\Longrightarrow\quad r \ge k - 1.
```

 זה חלש באיבר אחד מ[השערת אוילר על סכומי חזקות](https://he.wikipedia.org/wiki/%D7%94%D7%A9%D7%A2%D7%A8%D7%AA_%D7%90%D7%95%D7%99%D7%9C%D7%A8_%D7%A2%D7%9C_%D7%A1%D7%9B%D7%95%D7%9E%D7%99_%D7%97%D7%96%D7%A7%D7%95%D7%AA), שטענה $`r \ge k`$.

## רקע היסטורי

השערת אוילר על סכומי חזקות נועדה להכליל את [המשפט האחרון של פרמה](https://he.wikipedia.org/wiki/%D7%94%D7%9E%D7%A9%D7%A4%D7%98_%D7%94%D7%90%D7%97%D7%A8%D7%95%D7%9F_%D7%A9%D7%9C_%D7%A4%D7%A8%D7%9E%D7%94). היא טענה שאי אפשר לכתוב חזקה $`k`$-ית כסכום של פחות מ-$`k`$ חזקות $`k`$-יות חיוביות.

ב-1966 הפריכו לנדר ופרקין את השערת אוילר כשמצאו



```math
27^5 + 84^5 + 110^5 + 133^5 = 144^5.
```

 [^3] בזהות הזו יש רק ארבעה מחוברים בצד שמאל, בניגוד לחסם שאוילר הציע לחזקות חמישיות. אבל יש בה חמישה איברים בסך הכול, כך שהיא מקיימת את חסם LPS המאוחר יותר בשוויון.

בסקירה שלהם מ-1967 סידרו לנדר, פרקין וסלפרידג' את המשוואות לפי טיפוס $`(k, m, n)`$, ושאלו, בין שאר השאלות, האם משוואה כזו לעולם אינה פתירה כאשר $`m + n \lt k`$.[^4] התשובה החיובית לשאלה הזו נודעה כהשערת לנדר, פרקין וסלפרידג'.

השערת אוילר המקורית הופרכה אחר כך גם לחזקות רביעיות. [נועם אלקיס](https://he.wikipedia.org/wiki/%D7%A0%D7%95%D7%A2%D7%9D_%D7%90%D7%9C%D7%A7%D7%99%D7%A1) מצא פתרון ל-



```math
a^4 + b^4 + c^4 = d^4,
```

 ופיתח בנייה שנותנת פתרונות נוספים.[^5] רוג'ר פריי מצא מאוחר יותר את הפתרון הקטן ביותר:



```math
95800^4 + 217519^4 + 414560^4 = 422481^4.
```

 [^6] בזהויות הרביעיות האלה יש ארבעה איברים בסך הכול, ולכן הן נמצאות על הגבול שהשערת LPS צופה, ולא מתחתיו.

## מקרים אלמנטריים

ההשערה נכונה עבור $`k \le 4`$.

עבור $`k = 2`$, בכל צד חייב להיות לפחות איבר אחד, כך שמשוואה עם פחות משני איברים בלתי אפשרית. עבור $`k = 3`$, במשוואה עם פחות משלושה איברים יש איבר אחד בכל צד; החיוביות מאלצת אז את שני הבסיסים להיות שווים, בסתירה לאי-הטריוויאליות.

עבור $`k = 4`$, אחרי החלפת צדדים אם צריך, הטיפוס הלא טריוויאלי היחיד האפשרי עם פחות מארבעה איברים הוא $`(4, 1, 2)`$. זה נותן משוואה



```math
a^4 = b^4 + c^4,
```

 שבלתי אפשרית לפי המשפט האחרון של פרמה (במקרה הזה – כבר לפי פרמה עצמו, ב[ירידה אינסופית](https://he.wikipedia.org/wiki/%D7%99%D7%A8%D7%99%D7%93%D7%94_%D7%90%D7%99%D7%A0%D7%A1%D7%95%D7%A4%D7%99%D7%AA)). לכן המעריך הראשון שאינו פתור הוא $`k = 5`$.

עבור $`k = 5`$, המשפט האחרון של פרמה שולל משוואות מטיפוס $`(5, 1, 2)`$. לכן טיפוסי הדוגמה הנגדית האפשריים במעריך הזה הם



```math
(5, 1, 3) \quad\text{ו-}\quad (5, 2, 2).
```

 לאף אחד מהם לא ידוע פתרון בשלמים חיוביים.

## פתרונות על הגבול המשוער

ידועים פתרונות רבים עם $`m + n = k`$. כמה דוגמאות פרימיטיביות:

| טיפוס       | זהות                                               |
|-------------|----------------------------------------------------|
| $`(4, 2, 2)`$ | $`59^4 + 158^4 = 133^4 + 134^4`$[^7]                 |
| $`(4, 1, 3)`$ | $`422481^4 = 95800^4 + 217519^4 + 414560^4`$[^8]     |
| $`(5, 1, 4)`$ | $`144^5 = 27^5 + 84^5 + 110^5 + 133^5`$[^9]          |
| $`(5, 2, 3)`$ | $`14132^5 + 220^5 = 14068^5 + 6237^5 + 5027^5`$[^10] |
| $`(6, 3, 3)`$ | $`3^6 + 19^6 + 22^6 = 10^6 + 15^6 + 23^6`$[^11]      |

(בדקנו את כל הזהויות בטבלאות בערך בחשבון שלמים מדויק.) הדוגמאות האלה מראות שאי-השוויון המשוער, אם הוא נכון, חד: אי אפשר להחליף את $`m + n \ge k`$ באי-השוויון החזק $`m + n \gt k`$.

פתרונות על הגבול אינם מקדמים לקראת דוגמה נגדית. דוגמה נגדית חייבת להכיל פחות מ-$`k`$ איברים בסך הכול, אחרי צמצום כל האיברים המשותפים.

## פתרונות ידועים עם איבר אחד בצד אחד

במקרה הפרטי $`m = 1`$, פתרון הוא [חלוקה](https://he.wikipedia.org/wiki/%D7%97%D7%9C%D7%95%D7%A7%D7%94_%28%D7%AA%D7%95%D7%A8%D7%AA_%D7%94%D7%9E%D7%A1%D7%A4%D7%A8%D7%99%D7%9D%29) של חזקה $`k`$-ית ל-$`n`$ חזקות זהות. כמה פתרונות ידועים שמקיימים את האילוץ $`n \le k`$:[^12]

| $`k`$    | פתרון                                                                      | מקור                                                                   |
|--------|----------------------------------------------------------------------------|------------------------------------------------------------------------|
| 3      | $`3^3 + 4^3 + 5^3 = 6^3`$                                                    | (אחת הפרשנויות ל[מספר של אפלטון](https://he.wikipedia.org/wiki/%D7%94%D7%9E%D7%A1%D7%A4%D7%A8_%D7%A9%D7%9C_%D7%90%D7%A4%D7%9C%D7%98%D7%95%D7%9F))          |
| 4      | $`95800^4 + 217519^4 + 414560^4 = 422481^4`$                                 | רוג'ר פריי, 1988                                                       |
| 4      | $`30^4 + 120^4 + 272^4 + 315^4 = 353^4`$                                     | ר. נורי, 1911                                                          |
| 5      | $`27^5 + 84^5 + 110^5 + 133^5 = 144^5`$                                      | לנדר ופרקין, 1966                                                      |
| 5      | $`7^5 + 43^5 + 57^5 + 80^5 + 100^5 = 107^5`$                                 | סאסטרי, 1934 (השלישי בגודלו)                                           |
| 6      | (לא ידוע)                                                                  | רסטה ומיריניאק דיווחו ב-2003 שבכל פתרון הבסיס הבודד גדול מ-730000[^13] |
| 7      | $`127^7 + 258^7 + 266^7 + 413^7 + 430^7 + 439^7 + 525^7 = 568^7`$            | מ. דודריל, 1999                                                        |
| 8      | $`90^8 + 223^8 + 478^8 + 524^8 + 748^8 + 1088^8 + 1190^8 + 1324^8 = 1409^8`$ | סקוט צ'ייס, 2000                                                       |

## מצב נוכחי ותוצאות חלקיות

לא ידועה דוגמה נגדית להשערת LPS. המשוואה $`a^5 + b^5 = c^5 + d^5`$ היא מקרה ה"שניים מול שניים" עם המעריך הקטן ביותר שההשערה צופה שהוא בלתי אפשרי, ולא ידוע אם יש לה פתרון לא טריוויאלי בשלמים חיוביים.[^14]

כמה תוצאות מראות שפתרונות של משוואות קשורות דלילים, בלי להוכיח שאינם קיימים כלל. לכל $`k \ge 5`$ קבוע, [טימותי בראונינג](https://he.wikipedia.org/wiki/%D7%98%D7%99%D7%9E%D7%95%D7%AA%D7%99_%D7%91%D7%A8%D7%90%D7%95%D7%A0%D7%99%D7%A0%D7%92) השיג חסמים עליונים על מספר השלמים עד גובה נתון שיש להם יותר מייצוג זר אחד (שונה במהותו) כסכום של שתי חזקות $`k`$-יות.[^15] הערכות צפיפות כאלה מתיישבות עם ההשערה, אבל אינן שוללות פתרונות בודדים. בראונינג הוכיח מאוחר יותר תוצאות "מיעוט" (paucity) דומות למשוואות $`f(x_1) + f(x_2) = f(x_3) + f(x_4)`$ עם מחלקות רחבות של פולינומים ממעלה גבוהה.[^16]

להשערה יש גם השלכות מחוץ לחקר הישיר של סכומים שווים. קיס ושנדור הראו שהיא הייתה גוררת השערת צפיפות ל[קבוצות סידון](https://he.wikipedia.org/wiki/%D7%A1%D7%93%D7%A8%D7%AA_%D7%A1%D7%99%D7%93%D7%95%D7%9F) מוכללות $`B_h[g]`$ שנבנות מחזקות $`k`$-יות מושלמות, בטווח $`h \lt k/2`$, כאשר $`h`$ מספר המחוברים המותר.[^17]

ההשערה אומצה גם כהנחת עבודה בבעיות קשורות. בהנחת המקרה הפרטי שאין שני סכומים שווים של שתים-עשרה חזקות $`k`$-יות שונות כאשר $`k \ge 25`$, הסיקו קרוט ויפ חסם עליון מוחלט, שאינו תלוי ב-$`n`$, על הגודל של [$`n`$-יות דיופנטיות](https://he.wikipedia.org/wiki/n-%D7%99%D7%94_%D7%93%D7%99%D7%95%D7%A4%D7%A0%D7%98%D7%99%D7%AA) עם התכונה $`D_k(n)`$.[^18] החסם המותנה הזה הועבר גם לעבודה מאוחרת יותר על $`n`$-יות דיופנטיות דו-צדדיות.[^19]

חיפושים ממוחשבים ובניות אלגבריות ייצרו פתרונות רבים מטיפוסים שמקיימים $`m + n \ge k`$. הם מספקים עדות לגבי אילו טיפוסים על הגבול ומעליו פתירים, אבל חיפוש סופי אינו יכול לבסס את החסם התחתון של LPS לשלמים כלשהם.
