# מספר הגנר

ב[תורת המספרים](https://he.wikipedia.org/wiki/%D7%AA%D7%95%D7%A8%D7%AA_%D7%94%D7%9E%D7%A1%D7%A4%D7%A8%D7%99%D7%9D), **מספרי הגנר** (Heegner numbers) הם המספרים השלמים החיוביים $`d`$, [החופשיים מריבועים](%D7%A7%D7%91%D7%95%D7%A6%D7%94%20%D7%9C%D7%9C%D7%90%20%D7%94%D7%A4%D7%A8%D7%A9%D7%99%D7%9D%20%D7%A8%D7%99%D7%91%D7%95%D7%A2%D7%99%D7%99%D7%9D.md), שעבורם ל[שדה הריבועי](https://he.wikipedia.org/wiki/%D7%A9%D7%93%D7%94_%D7%A8%D7%99%D7%91%D7%95%D7%A2%D7%99) המדומה $`\mathbb Q(\sqrt{-d})`$ יש [מספר מחלקה](%D7%97%D7%91%D7%95%D7%A8%D7%AA%20%D7%9E%D7%97%D7%9C%D7%A7%D7%95%D7%AA%20%D7%94%D7%90%D7%99%D7%93%D7%99%D7%90%D7%9C%D7%99%D7%9D.md) 1. באופן שקול, בחוג השלמים האלגבריים של $`\mathbb Q(\sqrt{-d})`$ יש פירוק יחיד לגורמים.[^1]

מציאת המספרים האלה היא מקרה פרטי של [בעיית מספר המחלקה](%D7%91%D7%A2%D7%99%D7%99%D7%AA%20%D7%9E%D7%A1%D7%A4%D7%A8%20%D7%94%D7%9E%D7%97%D7%9C%D7%A7%D7%94.md), והם עומדים בבסיס של כמה תוצאות מפתיעות בתורת המספרים.

לפי משפט סטארק–הגנר יש בדיוק תשעה מספרי הגנר:

  
1, 2, 3, 7, 11, 19, 43, 67, 163 (סדרה [A003173](https://oeis.org/A003173) ב-OEIS).

את התוצאה הזו שיער [קרל פרידריך גאוס](https://he.wikipedia.org/wiki/%D7%A7%D7%A8%D7%9C_%D7%A4%D7%A8%D7%99%D7%93%D7%A8%D7%99%D7%9A_%D7%92%D7%90%D7%95%D7%A1), וקורט הגנר הוכיח אותה, עם פגמים קלים, ב-1952. [אלן בייקר](https://he.wikipedia.org/wiki/%D7%90%D7%9C%D7%9F_%D7%91%D7%99%D7%99%D7%A7%D7%A8) והרולד סטארק הוכיחו את התוצאה באופן בלתי תלוי ב-1966, וסטארק הראה בהמשך שהפער בהוכחה של הגנר היה קל.[^2] (טבלה של מספרי המחלקה של השדות הריבועיים המדומים הראשונים, עם החישוב שלהם בעזרת תבניות ריבועיות מצומצמות, מופיעה בערך [חבורת מחלקות האידיאלים](%D7%97%D7%91%D7%95%D7%A8%D7%AA%20%D7%9E%D7%97%D7%9C%D7%A7%D7%95%D7%AA%20%D7%94%D7%90%D7%99%D7%93%D7%99%D7%90%D7%9C%D7%99%D7%9D.md).)

## הפולינום של אוילר שיוצר ראשוניים

הפולינום של [אוילר](https://he.wikipedia.org/wiki/%D7%9C%D7%90%D7%95%D7%A0%D7%A8%D7%93_%D7%90%D7%95%D7%99%D7%9C%D7%A8) שיוצר ראשוניים,



```math
n^2 + n + 41,
```

 נותן [מספרים ראשוניים](https://he.wikipedia.org/wiki/%D7%9E%D7%A1%D7%A4%D7%A8_%D7%A8%D7%90%D7%A9%D7%95%D7%A0%D7%99) שונים לכל $`n = 0,1,\dots,39`$ (עבור $`n = 40`$ מתקבל $`40^2 + 40 + 41 = 41^2`$, שאינו ראשוני). כפי שהראה רבינוביץ', התופעה הזו קשורה למספר הגנר 163. הוא הוכיח שהפולינום



```math
n^2 + n + p
```

 נותן ראשוניים עבור $`n=0,\dots,p-2`$ אם ורק אם הדיסקרימיננטה שלו, $`1-4p`$, היא מינוס מספר הגנר. עבור $`p=41`$, הדיסקרימיננטה היא $`1-4p=-163`$, מינוס מספר הגנר 163.[^3]

מספרי הגנר 1, 2 ו-3 אינם יכולים להתאים לפולינומים יוצרי ראשוניים בדרך הזו: ההתאמה דורשת שמספר הגנר יהיה שקול ל-3 מודולו 4, ועבור מספר הגנר 3 מתקבל $`p=1`$, קטן מדי מכדי ש-$`n=0,\dots,p-2`$ ייתן סדרה לא ריקה של ראשוניים. לכן מספרי הגנר שעבורם ההתאמה עובדת הם 7, 11, 19, 43, 67 ו-163, והם נותנים פולינומים יוצרי ראשוניים מהצורה $`n^2+n+p`$ עבור $`p`$ = 2, 3, 5, 11, 17 או 41. המספרים האחרונים נקראים **המספרים המזליים של אוילר**, בשם שנתן להם פרנסואה לה ליונה.[^4]

**דוגמה מלאה, $`p = 11`$.** הדיסקרימיננטה היא $`1 - 44 = -43`$, ואכן הערכים של $`n^2 + n + 11`$ עבור $`n = 0, 1, \ldots, 9`$ הם

  
11, 13, 17, 23, 31, 41, 53, 67, 83, 101,

כולם ראשוניים; עבור $`n = 10`$ מתקבל $`121 = 11^2`$.

## מספרים שכמעט שלמים והקבוע של רמנוג'אן

**הקבוע של רמנוג'אן** הוא ה[מספר טרנסצנדנטי](https://he.wikipedia.org/wiki/%D7%9E%D7%A1%D7%A4%D7%A8_%D7%98%D7%A8%D7%A0%D7%A1%D7%A6%D7%A0%D7%93%D7%A0%D7%98%D7%99)[^5] $`e^{\pi \sqrt{163} }`$, שהוא "כמעט שלם":[^6]



```math
e^{\pi \sqrt{163} } = 262\,537\,412\,640\,768\,743.999\,999\,999\,999\,25\ldots\approx 640\,320^3+744.
```

 את המספר הזה גילה ב-1859 המתמטיקאי [שארל הרמיט](https://he.wikipedia.org/wiki/%D7%A9%D7%90%D7%A8%D7%9C_%D7%94%D7%A8%D7%9E%D7%99%D7%98).[^7] במאמר [לאחד באפריל](https://he.wikipedia.org/wiki/%D7%90%D7%97%D7%93_%D7%91%D7%90%D7%A4%D7%A8%D7%99%D7%9C) 1975 בטור "משחקים מתמטיים" של ה[סיינטיפיק אמריקן](https://he.wikipedia.org/wiki/%D7%A1%D7%99%D7%99%D7%A0%D7%98%D7%99%D7%A4%D7%99%D7%A7_%D7%90%D7%9E%D7%A8%D7%99%D7%A7%D7%9F), טען [מרטין גרדנר](https://he.wikipedia.org/wiki/%D7%9E%D7%A8%D7%98%D7%99%D7%9F_%D7%92%D7%A8%D7%93%D7%A0%D7%A8) במתיחה שהמספר הוא למעשה שלם, ושהגאון המתמטי ההודי [סריניוואסה רמנוג'אן](https://he.wikipedia.org/wiki/%D7%A1%D7%A8%D7%99%D7%A0%D7%99%D7%95%D7%95%D7%90%D7%A1%D7%94_%D7%A8%D7%9E%D7%A0%D7%95%D7%92%27%D7%90%D7%9F) חזה זאת – ומכאן שמו.[^8]

### פרטים

את הצירוף הזה מסבירים [כפל מרוכב](https://he.wikipedia.org/wiki/%D7%9B%D7%A4%D7%9C_%D7%9E%D7%A8%D7%95%D7%9B%D7%91) ופיתוח ה-$`q`$ של **האינווריאנט $`j`$**. בהמשך, $`j(z)`$ מסמן את האינווריאנט $`j`$ של המספר המרוכב $`z`$. בקצרה, $`j\left(\frac{1+\sqrt{-d} }{2}\right)`$ הוא מספר שלם כאשר $`d`$ מספר הגנר, ו-



```math
e^{\pi \sqrt{d} } \approx -j\left(\frac{1+\sqrt{-d} }{2}\right) + 744
```

 דרך פיתוח ה-$`q`$.

אם $`\tau`$ אי-רציונלי ריבועי (במחצית העליונה של המישור), אז $`j(\tau)`$ הוא [שלם אלגברי](https://he.wikipedia.org/wiki/%D7%9E%D7%A1%D7%A4%D7%A8_%D7%90%D7%9C%D7%92%D7%91%D7%A8%D7%99) ממעלה $`\left|\mathrm{Cl}\bigl(\mathbb{Q}(\tau)\bigr)\right|`$, מספר המחלקה של $`\mathbb{Q}(\tau)`$, והפולינום המינימלי (המתוקן והשלם) שהוא מקיים נקרא **פולינום המחלקה של הילברט**. לכן, אם להרחבה הריבועית המדומה $`\mathbb{Q}(\tau)`$ יש מספר מחלקה 1 (כלומר $`d`$ מספר הגנר), האינווריאנט $`j`$ הוא מספר שלם.

פיתוח ה-$`q`$ של $`j`$, כלומר [טור הפורייה](https://he.wikipedia.org/wiki/%D7%98%D7%95%D7%A8_%D7%A4%D7%95%D7%A8%D7%99%D7%99%D7%94) שלו, שנכתב כ[טור לורן](https://he.wikipedia.org/wiki/%D7%98%D7%95%D7%A8_%D7%9C%D7%95%D7%A8%D7%9F) ב-$`q=e^{2 \pi i \tau}`$, מתחיל כך:



```math
j(\tau) = \frac{1}{q} + 744 + 196\,884 q + \cdots.
```

 המקדמים $`c_n`$ גדלים אסימפטוטית לפי $`\ln(c_n) \sim 4\pi \sqrt{n} + O\bigl(\ln n\bigr)`$, והמקדמים הנמוכים גדלים לאט יותר מ-$`200\,000^n`$; לכן כאשר $`|q| \ll \tfrac{1}{200\,000}`$, הפונקציה $`j`$ מקורבת היטב מאוד על ידי שני האיברים הראשונים שלה. הצבת $`\tau = \frac{1+\sqrt{-163} }{2}`$ נותנת



```math
q=e^{\pi i}e^{-\pi \sqrt{163} } = -e^{-\pi \sqrt{163} }, \qquad \frac{1}{q}=-e^{\pi \sqrt{163} }.
```

 עכשיו



```math
j\left(\frac{1+\sqrt{-163} }{2}\right)=\left(-640\,320\right)^3,
```

 ולכן



```math
\left(-640\,320\right)^3=-e^{\pi \sqrt{163} }+744+O\left(e^{-\pi \sqrt{163} }\right),
```

 או



```math
e^{\pi \sqrt{163} }=640\,320^3+744+O\left(e^{-\pi \sqrt{163} }\right),
```

 כאשר האיבר הלינארי של השגיאה הוא



```math
\frac{-196\,884}{e^{\pi \sqrt{163} } } \approx \frac{-196\,884}{640\,320^3+744} \approx -0.000\,000\,000\,000\,75.
```

 זה מסביר מדוע $`e^{\pi \sqrt{163} }`$ רחוק ממספר שלם בערך בגודל הזה.

## נוסחאות ל-π

האחים צ'ודנובסקי מצאו ב-1987 ש-



```math
\frac{1}{\pi} = \frac{12}{640\,320^{3/2} } \sum_{k=0}^\infty \frac{(6k)! (163 \cdot 3\,344\,418k + 13\,591\,409)}{(3k)!(k!)^3 (-640\,320)^{3k} },
```

 וההוכחה של הנוסחה משתמשת בעובדה ש-



```math
j\left(\frac{1+\sqrt{-163} }{2}\right) = -640\,320^3.
```

 כל איבר בטור מוסיף כ-14 ספרות נכונות של $`\pi`$, ולכן הנוסחה משמשת בחישובים של מיליוני ספרות של $`\pi`$. לנוסחאות דומות ראו טורי רמנוג'אן–סאטו.

## מספרי הגנר האחרים

עבור ארבעת מספרי הגנר הגדולים ביותר, הקירובים שמתקבלים[^9] הם:



```math
\begin{align}
e^{\pi \sqrt{19} } &\approx 96^3+744-0.22\\
e^{\pi \sqrt{43} } &\approx 960^3+744-0.000\,22\\
e^{\pi \sqrt{67} } &\approx 5\,280^3+744-0.000\,0013\\
e^{\pi \sqrt{163} } &\approx 640\,320^3+744-0.000\,000\,000\,000\,75
\end{align}
```

 באופן חלופי,[^10]



```math
\begin{align}
e^{\pi \sqrt{19} } &\approx 12^3\left(3^2-1\right)^3+744-0.22\\
e^{\pi \sqrt{43} } &\approx 12^3\left(9^2-1\right)^3+744-0.000\,22\\
e^{\pi \sqrt{67} } &\approx 12^3\left(21^2-1\right)^3+744-0.000\,0013\\
e^{\pi \sqrt{163} } &\approx 12^3\left(231^2-1\right)^3+744-0.000\,000\,000\,000\,75
\end{align}
```

 כאשר הסיבה לריבועים היא טורי אייזנשטיין מסוימים. עבור מספרי הגנר $`d \lt 19`$ לא מקבלים מספר שכמעט שלם, ואפילו $`d = 19`$ אינו מרשים במיוחד (סטייה של 0.22 ממספר שלם היא סטייה טיפוסית למספר ממשי אקראי). אינווריאנטי ה-$`j`$ השלמים מתפרקים לגורמים קטנים רבים, כפי שנובע מהצורה



```math
12^3\left(n^2-1\right)^3=\left(2^2\cdot 3 \cdot (n-1) \cdot (n+1)\right)^3,
```

 ומתפרקים כך:



```math
\begin{align}
j\left(\tfrac{1+\sqrt{-19} }{2}\right) &= -96^3 = -\left(2^5 \cdot 3\right)^3\\
j\left(\tfrac{1+\sqrt{-43} }{2}\right) &= -960^3 = -\left(2^6 \cdot 3 \cdot 5\right)^3\\
j\left(\tfrac{1+\sqrt{-67} }{2}\right) &= -5\,280^3 = -\left(2^5 \cdot 3 \cdot 5 \cdot 11\right)^3\\
j\left(\tfrac{1+\sqrt{-163} }{2}\right)&= -640\,320^3 = -\left(2^6 \cdot 3 \cdot 5 \cdot 23 \cdot 29\right)^3.
\end{align}
```



המספרים הטרנסצנדנטיים האלה, מלבד היותם קרובים מאוד למספרים שלמים (שהם פשוט מספרים אלגבריים ממעלה 1), קרובים מאוד גם למספרים אלגבריים ממעלה 3:[^11]



```math
\begin{align}
e^{\pi \sqrt{19} } &\approx x^{24}-24.000\,31, & x^3-2x-2&=0\\
e^{\pi \sqrt{43} } &\approx x^{24}-24.000\,000\,31, & x^3-2x^2-2&=0\\
e^{\pi \sqrt{67} } &\approx x^{24}-24.000\,000\,0019, & x^3-2x^2-2x-2&=0\\
e^{\pi \sqrt{163} } &\approx x^{24}-24.000\,000\,000\,000\,0011, & x^3-6x^2+4x-2&=0
\end{align}
```

 (כאשר $`x`$ הוא השורש הממשי של הפולינום). את שורשי הפולינומים ממעלה שלישית אפשר לבטא במדויק כמנות של פונקציית האטא של דדקינד $`\eta(\tau)`$, פונקציה מודולרית שבה מופיע שורש מסדר 24, וזה מסביר את ה-24 בקירוב. באופן דומה יש קירובים במספרים אלגבריים ממעלה 4 וממעלה 6, שגם אותם אפשר לבטא במדויק בעזרת מנות של פונקציית האטא. לדוגמה, עבור $`\tau = \frac{1+\sqrt{-163} }{2}`$,



```math
\begin{align}
e^{\pi \sqrt{163} } &= \left( \frac{e^{\pi i/24} \eta(\tau)}{\eta(2\tau)} \right)^{24}-24.000\,000\,000\,000\,001\,05\dots\\
e^{\pi \sqrt{163} } &= \left( \frac{e^{\pi i/12} \eta(\tau)}{\eta(3\tau)} \right)^{12}-12.000\,000\,000\,000\,000\,21\dots\\
e^{\pi \sqrt{163} } &= \left( \frac{e^{\pi i/6} \eta(\tau)}{\eta(5\tau)} \right)^{6}-6.000\,000\,000\,000\,000\,034\dots
\end{align}
```



## מספרים עם מספר מחלקה 2

שלושת המספרים 88, 148 ו-232, שעבורם לשדה הריבועי המדומה $`\mathbb Q(\sqrt{-d})`$ יש מספר מחלקה 2, אינם מספרי הגנר, אבל יש להם תכונות דומות מבחינת מספרים שכמעט שלמים. לדוגמה,[^12]



```math
\begin{align}
e^{\pi \sqrt{88} } +8\,744 &\approx 2\,508\,952^2-0.077\dots\\
e^{\pi \sqrt{148} } +8\,744 &\approx 199\,148\,648^2+0.000\,97\dots\\
e^{\pi \sqrt{232} } +8\,744 &\approx 24\,591\,257\,752^2-0.000\,0078\dots
\end{align}
```

 ו-



```math
\begin{align}
e^{\pi \sqrt{22} } -24 &\approx \left(6+4\sqrt{2}\right)^{6} -0.000\,11\dots\\
e^{\pi \sqrt{37} } +24 &\approx \left(12+ 2 \sqrt{37}\right)^6 -0.000\,0014\dots\\
e^{\pi \sqrt{58} } -24 &\approx \left(27 + 5 \sqrt{29}\right)^6 -0.000\,000\,011\dots
\end{align}
```
