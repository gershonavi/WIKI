# אלגוריתם מייסל-להמר

**אלגוריתם מייסל–להמר** (על שם [ארנסט מייסל](%D7%90%D7%A8%D7%A0%D7%A1%D7%98%20%D7%9E%D7%99%D7%99%D7%A1%D7%9C.md) ו[דריק הנרי להמר](https://he.wikipedia.org/wiki/%D7%93%D7%A8%D7%99%D7%A7_%D7%94%D7%A0%D7%A8%D7%99_%D7%9C%D7%94%D7%9E%D7%A8)) הוא [אלגוריתם](https://he.wikipedia.org/wiki/%D7%90%D7%9C%D7%92%D7%95%D7%A8%D7%99%D7%AA%D7%9D) המחשב ערכים מדויקים של [פונקציית המספרים הראשוניים](https://he.wikipedia.org/wiki/%D7%A4%D7%95%D7%A0%D7%A7%D7%A6%D7%99%D7%99%D7%AA_%D7%94%D7%9E%D7%A1%D7%A4%D7%A8%D7%99%D7%9D_%D7%94%D7%A8%D7%90%D7%A9%D7%95%D7%A0%D7%99%D7%99%D7%9D) $`\pi(x)`$.[^1][^2]

## תיאור

הבעיה של ספירת המספרים הראשוניים שאינם גדולים מ-$`x`$, בלי למנות את כולם אחד אחד, נחקרה כבר על ידי [לז'נדר](https://he.wikipedia.org/wiki/%D7%90%D7%93%D7%A8%D7%99%D7%90%D7%9F-%D7%9E%D7%90%D7%A8%D7%99_%D7%9C%D7%96%27%D7%A0%D7%93%D7%A8). מתוך [הנפה של ארטוסתנס](https://he.wikipedia.org/wiki/%D7%94%D7%A0%D7%A4%D7%94_%D7%A9%D7%9C_%D7%90%D7%A8%D7%98%D7%95%D7%A1%D7%AA%D7%A0%D7%A1) הוא הסיק ש



```math
\pi (x) - \pi (x^{1/2}) + 1 = \lfloor x \rfloor - \sum_{i} \lfloor x/p_i \rfloor + \sum_{i\lt j} \lfloor x/(p_ip_j) \rfloor - \ldots
```

 כאשר $`\lfloor x \rfloor`$ הוא [הערך השלם](https://he.wikipedia.org/wiki/%D7%A4%D7%95%D7%A0%D7%A7%D7%A6%D7%99%D7%99%D7%AA_%D7%94%D7%A2%D7%A8%D7%9A_%D7%94%D7%A9%D7%9C%D7%9D) של $`x`$ (ה[שלם](https://he.wikipedia.org/wiki/%D7%9E%D7%A1%D7%A4%D7%A8_%D7%A9%D7%9C%D7%9D) הגדול ביותר שאינו עולה על $`x`$), וה-$`p_i`$ עוברים על כל הראשוניים שאינם גדולים מ-$`\sqrt{x}`$.[^3][^4]

נוסחה זו אינה מעשית לחישוב עבור $`x`$ גדול, משום שמספר האיברים השונים מאפס בסכום גדל ביחס ישר ל-$`x`$.[^5][^6] בשנות ה-70 של המאה ה-19 מצא מייסל שיטה יעילה יותר, המבוססת על [נוסחאות נסיגה](https://he.wikipedia.org/wiki/%D7%A0%D7%95%D7%A1%D7%97%D7%AA_%D7%A0%D7%A1%D7%99%D7%92%D7%94) לפונקציות נפה חלקיות ומקטינה את מספר האיברים בסכום של לז'נדר. להמר הרחיב ופישט אותה בשנת 1959.[^7][^8]

### פונקציות המפתח

יהיו $`p_1 = 2, p_2 = 3, p_3 = 5, \ldots`$ המספרים הראשוניים בסדר עולה, ונסמן $`p_0 = 1`$. עבור שלם $`a \ge 0`$ מגדירים



```math
\varphi(x, a) := \left| \left \{ n \le x : p|n \implies p > p_a \right \} \right|,
```

 כלומר מספר הטבעיים שאינם גדולים מ-$`x`$ שכל גורמיהם הראשוניים גדולים מ-$`p_a`$.[^9] כמו כן, עבור שלם $`k \ge 0`$ מגדירים



```math
P_k(x, a) := \left| \left \{ n \le x : n = q_1 q_2 \cdots q_k,\ q_1, \ldots, q_k > p_a \right \} \right|,
```

 כאשר $`q_1, \ldots, q_k`$ ראשוניים. זהו מספר הטבעיים שאינם גדולים מ-$`x`$ שיש להם בדיוק $`k`$ גורמים ראשוניים (כולל ריבוי), כולם גדולים מ-$`p_a`$. מכאן



```math
\varphi(x, a) = \sum_{k=0}^\infty P_k(x, a),
```

 ובסכום יש רק מספר סופי של איברים שונים מאפס, משום ש-$`P_k(x, a) = 0`$ כאשר $`p_{a+1}^k > x`$.[^10] מכיוון ש-$`P_0(x, a) = 1`$ ו-$`P_1(x, a) = \pi(x) - a`$, מתקבל



```math
\pi(x) = \varphi(x,a) + a - 1 - \sum_{k=2}^\infty P_k(x,a).
```

 לכן אפשר לחשב את $`\pi(x)`$ באמצעות חישוב של $`\varphi(x,a)`$ ושל $`P_k(x, a)`$ עבור $`k \ge 2`$, וזה מה שאלגוריתם מייסל–להמר עושה.

### נוסחה עבור P<sub>k</sub>(x, a)

עבור $`k = 2`$ מתקבלת הנוסחה הבאה:



```math
\begin{align}
P_2(x, a) & =\left| \left\{ n : n \le x,~ n = p_b p_c,~ a < b \le c \right\} \right| \\
& = \sum_{b = a+1}^{\pi(x^{1/2})} \left| \left\{ n : n \le x,~ n = p_b p_c,~ b \le c \le \pi \left( \frac{x}{p_b} \right) \right\} \right| \\
& = \sum_{b = a+1}^{\pi(x^{1/2})} \left( \pi\left( \frac{x}{p_b} \right) - (b-1) \right) \\
& = \binom{a}{2} - \binom{\pi(x^{1/2})}{2} + \sum_{b = a+1}^{\pi(x^{1/2})} \pi\left( \frac{x}{p_b} \right).
\end{align}
```

 עבור $`k \ge 3`$ אפשר לפתח זהויות דומות ל-$`P_k(x, a)`$.[^11]

### חישוב φ(x, a)

מתנאי ההתחלה



```math
\varphi(x, 0) = \lfloor x \rfloor
```

 ומנוסחת הנסיגה



```math
\varphi(x, a) = \varphi(x, a-1) - \varphi\left(\frac x {p_a}, a-1 \right)
```

 אפשר לחשב ברקורסיה כל ערך של $`\varphi(x,a)`$.

### שילוב האיברים

כל שנותר הוא לחשב את $`\varphi(x,a)`$ ואת $`P_k(x, a)`$ עבור $`k \ge 2`$, לערכים מסוימים של $`x`$ ושל $`a`$. את זה אפשר לעשות בעזרת נפה ישירה והנוסחאות שלעיל.

## היסטוריה

כבר מייסל מצא שעבור $`k \ge 3`$ מתקיים $`P_k(x, a) = 0`$ אם $`a = \pi(x^{1/3})`$. הוא השתמש במשוואה המתקבלת לחישוב $`\pi(x)`$ עבור ערכים גדולים של $`x`$.[^12]

מייסל חישב את $`\pi(x)`$ עבור ערכי $`x`$ עד $`10^9`$, אך בערך הגדול ביותר החטיא במעט את התוצאה הנכונה.[^13] בעזרת שיטתו ובעזרת מחשב IBM 701 חישב להמר את הערך הנכון של $`\pi(10^9)`$, והחטיא ב-1 את הערך הנכון של $`\pi(10^{10})`$.[^14]

## האלגוריתם המורחב

ג'פרי לגריאס, ויקטור מילר ו[אנדרו אודליצקו](https://he.wikipedia.org/wiki/%D7%90%D7%A0%D7%93%D7%A8%D7%95_%D7%90%D7%95%D7%93%D7%9C%D7%99%D7%A6%D7%A7%D7%95) פרסמו מימוש של האלגוריתם המחשב את $`\pi(x)`$ בזמן $`O(x^{2/3+\varepsilon})`$ ובזיכרון $`O(x^{1/3+\varepsilon})`$ לכל $`\varepsilon > 0`$.[^15] כאשר בוחרים $`a = \pi(x^{1/3})`$, לעץ החישוב של $`\varphi(x,a)`$ יש $`O(x^{2/3})`$ עלים.[^16]

אלגוריתם מייסל–להמר המורחב דורש פחות זמן חישוב מהאלגוריתם שפיתחו מייסל ולהמר, בייחוד עבור ערכים גדולים של $`x`$. שיפורים נוספים ניתנו על ידי דלגליז וריבה ב-1996 ועל ידי גורדון ב-2001 (לא פורסם).[^17][^18]
