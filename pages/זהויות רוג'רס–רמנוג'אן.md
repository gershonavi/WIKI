# זהויות רוג'רס–רמנוג'אן

ב[מתמטיקה](https://he.wikipedia.org/wiki/%D7%9E%D7%AA%D7%9E%D7%98%D7%99%D7%A7%D7%94), **זהויות רוג'רס–רמנוג'אן** הן שתי זהויות שקשורות לטורים היפרגאומטריים בסיסיים ול[חלוקות של מספרים שלמים](https://he.wikipedia.org/wiki/%D7%97%D7%9C%D7%95%D7%A7%D7%94_%28%D7%AA%D7%95%D7%A8%D7%AA_%D7%94%D7%9E%D7%A1%D7%A4%D7%A8%D7%99%D7%9D%29). את הזהויות גילה והוכיח לראשונה לאונרד ג'יימס רוג'רס ב-1894, ומאוחר יותר גילה אותן מחדש (בלי הוכחה) [סריניוואסה רמנוג'אן](https://he.wikipedia.org/wiki/%D7%A1%D7%A8%D7%99%D7%A0%D7%99%D7%95%D7%95%D7%90%D7%A1%D7%94_%D7%A8%D7%9E%D7%A0%D7%95%D7%92%27%D7%90%D7%9F), זמן מה לפני 1913. לרמנוג'אן לא הייתה הוכחה, אבל ב-1917 הוא מצא מחדש את המאמר של רוג'רס, ושניהם פרסמו יחד הוכחה חדשה ב-1919. יששכר שור גילה מחדש והוכיח את הזהויות באופן בלתי תלוי ב-1917.

## הגדרה

זהויות רוג'רס–רמנוג'אן הן



```math
G(q) = \sum_{n=0}^\infty\frac{q^{n^2} }{(q; q)_n} = \frac1{(q; q^5)_\infty(q^4; q^5)_\infty} = 1 + q + q^2 + q^3 + 2q^4 + 2q^5 + 3q^6 + \cdots
```

 (סדרה A003114 ב-OEIS) ו-



```math
H(q) = \sum_{n=0}^\infty\frac{q^{n^2+n} }{(q; q)_n} = \frac1{(q^2; q^5)_\infty(q^3; q^5)_\infty} = 1 + q^2 + q^3 + q^4 + q^5 + 2q^6 + \cdots
```

 (סדרה A003106 ב-OEIS). כאן $`(a; q)_n`$ מסמן את סמל פוכהאמר $`q`$.

## פירוש קומבינטורי

נשים לב לעובדות הבאות:

- $`\frac{q^{n^2} }{(q; q)_n}`$ היא ה[פונקציה היוצרת](https://he.wikipedia.org/wiki/%D7%A4%D7%95%D7%A0%D7%A7%D7%A6%D7%99%D7%94_%D7%99%D7%95%D7%A6%D7%A8%D7%AA) של חלוקות עם בדיוק $`n`$ מחוברים, שבהן כל שני מחוברים סמוכים נבדלים לפחות ב-2. (הסיבה: החלוקה הקטנה ביותר כזו היא $`(2n-1) + \cdots + 3 + 1 = n^2`$, ומעליה מוסיפים חלוקה כלשהי עם לכל היותר $`n`$ חלקים, שהפונקציה היוצרת שלה היא $`1/(q; q)_n`$.)
- $`\frac1{(q; q^5)_\infty(q^4; q^5)_\infty}`$ היא הפונקציה היוצרת של חלוקות שבהן כל מחובר [קונגרואנטי](https://he.wikipedia.org/wiki/%D7%A7%D7%95%D7%A0%D7%92%D7%A8%D7%95%D7%90%D7%A0%D7%A6%D7%99%D7%94) ל-1 או ל-4 מודולו 5.
- $`\frac{q^{n^2+n} }{(q; q)_n}`$ היא הפונקציה היוצרת של חלוקות עם בדיוק $`n`$ מחוברים, שבהן מחוברים סמוכים נבדלים לפחות ב-2 והמחובר הקטן ביותר הוא לפחות 2.
- $`\frac1{(q^2; q^5)_\infty(q^3; q^5)_\infty}`$ היא הפונקציה היוצרת של חלוקות שבהן כל מחובר קונגרואנטי ל-2 או ל-3 מודולו 5.

לכן אפשר לפרש את זהויות רוג'רס–רמנוג'אן כך. יהי $`n`$ שלם אי-שלילי.

1.  מספר החלוקות של $`n`$ שבהן מחוברים סמוכים נבדלים לפחות ב-2 שווה למספר החלוקות של $`n`$ שבהן כל מחובר קונגרואנטי ל-1 או ל-4 מודולו 5.
2.  מספר החלוקות של $`n`$ שבהן מחוברים סמוכים נבדלים לפחות ב-2 והמחובר הקטן ביותר הוא לפחות 2 שווה למספר החלוקות של $`n`$ שבהן כל מחובר קונגרואנטי ל-2 או ל-3 מודולו 5.

באופן חלופי:

1.  מספר החלוקות של $`n`$ שבהן, כשיש $`k`$ מחוברים, המחובר הקטן ביותר הוא לפחות $`k`$, שווה למספר החלוקות של $`n`$ שבהן כל מחובר קונגרואנטי ל-1 או ל-4 מודולו 5.
2.  מספר החלוקות של $`n`$ שבהן, כשיש $`k`$ מחוברים, המחובר הקטן ביותר הוא לפחות $`k + 1`$, שווה למספר החלוקות של $`n`$ שבהן כל מחובר קונגרואנטי ל-2 או ל-3 מודולו 5.

**דוגמה.** עבור $`n = 9`$: החלוקות עם הפרשים לפחות 2 הן $`9,\ 8 + 1,\ 7 + 2,\ 6 + 3,\ 5 + 3 + 1`$ – חמש חלוקות; והחלוקות למחוברים מהצורה $`5a + 1`$ או $`5a + 4`$ הן $`9,\ 6 + 1 + 1 + 1,\ 4 + 4 + 1,\ 4 + 1 + 1 + 1 + 1 + 1,\ 1 + \cdots + 1`$ – גם חמש. בזהות השנייה, עבור $`n = 10`$: $`10,\ 8 + 2,\ 7 + 3,\ 6 + 4`$ מול $`8 + 2,\ 7 + 3,\ 3 + 3 + 2 + 2,\ 2 + 2 + 2 + 2 + 2`$.

## יישום לחלוקות

כיוון שהאיברים שבזהויות הם פונקציות יוצרות של [חלוקות](https://he.wikipedia.org/wiki/%D7%A4%D7%95%D7%A0%D7%A7%D7%A6%D7%99%D7%99%D7%AA_%D7%94%D7%97%D7%9C%D7%95%D7%A7%D7%94_%28%D7%AA%D7%95%D7%A8%D7%AA_%D7%94%D7%9E%D7%A1%D7%A4%D7%A8%D7%99%D7%9D%29) מסוימות, הזהויות הן טענות על חלוקות של [מספרים טבעיים](https://he.wikipedia.org/wiki/%D7%9E%D7%A1%D7%A4%D7%A8_%D7%98%D7%91%D7%A2%D7%99). סדרות המספרים שמתקבלות ממקדמי טורי מקלורן של פונקציות רוג'רס–רמנוג'אן $`G`$ ו-$`H`$ הן סדרות חלוקה מיוחדות מרמה 5:



```math
G(x) = \frac1{(x; x^5)_\infty(x^4; x^5)_\infty} = 1 + \sum_{n=1}^\infty P_G(n)x^n, \qquad H(x) = \frac1{(x^2; x^5)_\infty(x^3; x^5)_\infty} = 1 + \sum_{n=1}^\infty P_H(n)x^n.
```

 הסדרה $`P_G(n)`$ (A003114) נותנת את מספר הדרכים לפרק את $`n`$ למחוברים מהצורה $`5a + 1`$ או $`5a + 4`$ עם $`a \in \mathbb N_0`$. לכן $`P_G(n)`$ הוא מספר הפירוקים של $`n`$ שבהם מחוברים סמוכים נבדלים לפחות ב-2, וזה שווה למספר הפירוקים שבהם כל מחובר שווה ל-1 או ל-4 מודולו 5.

## השברים המשולבים של רוג'רס–רמנוג'אן R ו-S

*ערך מורחב: [השבר המשולב של רוג'רס–רמנוג'אן](%D7%94%D7%A9%D7%91%D7%A8%20%D7%94%D7%9E%D7%A9%D7%95%D7%9C%D7%91%20%D7%A9%D7%9C%20%D7%A8%D7%95%D7%92%27%D7%A8%D7%A1%E2%80%93%D7%A8%D7%9E%D7%A0%D7%95%D7%92%27%D7%90%D7%9F.md)*

### הגדרת השברים המשולבים

ה[שבר משולב](https://he.wikipedia.org/wiki/%D7%A9%D7%91%D7%A8_%D7%9E%D7%A9%D7%95%D7%9C%D7%91) $`R(q)`$ שלהלן נקרא **השבר המשולב של רוג'רס–רמנוג'אן**, והשבר המשולב $`S(q)`$ נקרא **השבר המשולב המתחלף של רוג'רס–רמנוג'אן**:



```math
R(q) = \cfrac{q^{1/5} }{1 + \cfrac q{1 + \cfrac{q^2}{1 + \cfrac{q^3}{1 + \cdots} } } }, \qquad S(q) = \cfrac{q^{1/5} }{1 - \cfrac q{1 + \cfrac{q^2}{1 - \cfrac{q^3}{1 + \cdots} } } }.
```

 [^1] הגורם $`q^{1/5}`$ הופך את השבר המשולב למנה של פונקציות מודולריות, ולכן גם השברים המשולבים האלה מודולריים.[^2] עבור השבר המשולב מתקיים



```math
R(q) = q^{1/5}\frac{(q; q^5)_\infty(q^4; q^5)_\infty}{(q^2; q^5)_\infty(q^3; q^5)_\infty} = q^{1/5}\prod_{k=0}^\infty\frac{(1 - q^{5k+1})(1 - q^{5k+4})}{(1 - q^{5k+2})(1 - q^{5k+3})} = q^{1/5}\frac{H(q)}{G(q)}.
```

 ההגדרה של פונקציית התטא של רמנוג'אן היא



```math
f(a, b) = \sum_{k=-\infty}^\infty a^{\frac{k(k+1)}2}b^{\frac{k(k-1)}2},
```

 ובעזרתה אפשר לכתוב את השבר המשולב $`R`$ כ-



```math
R(q) = q^{1/5}\frac{f(-q, -q^4)}{f(-q^2, -q^3)}.
```

 את הקשר בין השבר המשולב לפונקציות רוג'רס–רמנוג'אן מצא כבר רוג'רס ב-1894 (ומאוחר יותר, באופן בלתי תלוי, רמנוג'אן).

את השבר המשולב אפשר לבטא גם בעזרת [פונקציית אטא של דדקינד](%D7%A4%D7%95%D7%A0%D7%A7%D7%A6%D7%99%D7%99%D7%AA%20%D7%90%D7%98%D7%90%20%D7%A9%D7%9C%20%D7%93%D7%93%D7%A7%D7%99%D7%A0%D7%93.md), בצורת ובר $`\eta_W(x) = x^{1/24}(x; x)_\infty`$ (כפונקציה של הנום):



```math
R(q) = \tan\left\{\frac12\mathrm{arccot}\left[\frac{\eta_W(q^{1/5})}{2\eta_W(q^5)} + \frac12\right]\right\}.
```

 לשבר המשולב המתחלף $`S(q)`$ יש הזהויות הבאות עם שאר פונקציות רוג'רס–רמנוג'אן ועם פונקציית התטא של רמנוג'אן:



```math
S(q) = q^{1/5}\frac{H(-q)}{G(-q)} = q^{1/5}\frac{f(q, -q^4)}{f(-q^2, q^3)} = \frac{R(q^4)}{R(q)R(q^2)} = q^{1/5}\frac{G(q)G(q^2)H(q^4)}{H(q)H(q^2)G(q^4)}.
```

 (את כל הזהויות בסעיף הזה ובסעיפים הבאים בדקנו בחישוב מספרי בדיוק גבוה, בכמה ערכים של $`q`$.)

### זהויות עם פונקציות התטא של יעקובי

עבור פונקציות "ערך האפס" של התטא של יעקובי מתקיים:



```math
\vartheta_{00}(x) = 1 + 2\sum_{n=1}^\infty x^{n^2}, \qquad \vartheta_{01}(x) = 1 - 2\sum_{n=1}^\infty(-1)^{n+1}x^{n^2}, \qquad \vartheta_{10}(x) = 2x^{1/4} + 2x^{1/4}\sum_{n=1}^\infty x^{n^2+n},
```

 והגדרות המכפלה הבאות זהות להגדרות הסכום:



```math
\vartheta_{00}(x) = \prod_{n=1}^\infty(1 - x^{2n})(1 + x^{2n-1})^2, \quad \vartheta_{01}(x) = \prod_{n=1}^\infty(1 - x^{2n})(1 - x^{2n-1})^2, \quad \vartheta_{10}(x) = 2x^{1/4}\prod_{n=1}^\infty(1 - x^{2n})(1 + x^{2n})^2.
```

 שלוש הפונקציות האלה קשורות זו לזו ב**זהות יעקובי**



```math
\vartheta_{00}(x)^4 = \vartheta_{10}(x)^4 + \vartheta_{01}(x)^4.
```

 את הזהויות האלה (שנובעות מהמכפלה המשולשת של יעקובי) אפשר למצוא, למשל, אצל ויטקר ווטסון.

לשברים המשולבים $`R(x)`$ ו-$`S(x)`$ יש הקשרים הבאים לפונקציות התטא, כאשר $`\mathrm{arccot}`$ מקבל ערכים בטווח $`(0, \pi)`$:[^3]



```math
R(x) = \tan\left\langle\frac12\mathrm{arccot}\left\{\frac{\vartheta_{01}(x^{1/5})\left[5\vartheta_{01}(x^5)^2 - \vartheta_{01}(x)^2\right]}{2\vartheta_{01}(x^5)\left[\vartheta_{01}(x)^2 - \vartheta_{01}(x^{1/5})^2\right]} + \frac12\right\}\right\rangle,
```





```math
S(x) = \tan\left\langle\frac12\mathrm{arccot}\left\{\frac{\vartheta_{00}(x^{1/5})\left[5\vartheta_{00}(x^5)^2 - \vartheta_{00}(x)^2\right]}{2\vartheta_{00}(x^5)\left[\vartheta_{00}(x^{1/5})^2 - \vartheta_{00}(x)^2\right]} - \frac12\right\}\right\rangle.
```

 אפשר גם להעביר את השורש החמישי מהנום של פונקציות התטא אל פונקציית הטנגנס החיצונית. כך מתקבלות נוסחאות שדורשות רק אחת משלוש פונקציות התטא העיקריות:



```math
R(x) = \tan\left\{\frac12\arctan\left[\frac12 - \frac{\vartheta_{01}(x)^2}{2\vartheta_{01}(x^5)^2}\right]\right\}^{1/5}\tan\left\{\frac12\mathrm{arccot}\left[\frac12 - \frac{\vartheta_{01}(x)^2}{2\vartheta_{01}(x^5)^2}\right]\right\}^{2/5},
```





```math
S(x) = \tan\left\{\frac12\arctan\left[\frac{\vartheta_{00}(x)^2}{2\vartheta_{00}(x^5)^2} - \frac12\right]\right\}^{1/5}\cot\left\{\frac12\mathrm{arccot}\left[\frac{\vartheta_{00}(x)^2}{2\vartheta_{00}(x^5)^2} - \frac12\right]\right\}^{2/5}.
```



## הגרסאות המודולריות של G ו-H

### הגדרה

אם מציבים $`q = e^{2\pi i\tau}`$ (כאשר החלק המדומה של $`\tau \in \mathbb C`$ חיובי), שתי הפונקציות הבאות הן פונקציות מודולריות של $`\tau`$:



```math
G_M(q) = q^{-1/60}G(q), \qquad H_M(q) = q^{11/60}H(q).
```

 באופן מוחשי: אפשר לבטא אותן באופן אלגברי בעזרת המודולוס האליפטי של לז'נדר (ה[אקסצנטריות](https://he.wikipedia.org/wiki/%D7%90%D7%A7%D7%A1%D7%A6%D7%A0%D7%98%D7%A8%D7%99%D7%95%D7%AA) של האליפסה המתאימה), כפי שמוסבר להלן. עבור השבר המשולב של רוג'רס–רמנוג'אן מתקיים, בעזרת הגרסאות המודולריות של $`G`$ ו-$`H`$,



```math
R(q) = \frac{H_M(q)}{G_M(q)}
```

 (כי $`q^{11/60}/q^{-1/60} = q^{1/5}`$).

### ערכים מיוחדים

לפונקציות האלה יש הערכים הבאים בהופכי של הקבוע של גלפונד, $`e^{-\pi}`$, ובריבוע שלו, כאשר $`\Phi = \frac{1 + \sqrt5}2`$ הוא [יחס הזהב](https://he.wikipedia.org/wiki/%D7%99%D7%97%D7%A1_%D7%94%D7%96%D7%94%D7%91):



```math
G_M(e^{-\pi}) = 2^{-1/2}5^{-1/4}(\sqrt5 - 1)^{1/4}(\sqrt[4]5 + 1)^{1/2}R(e^{-\pi})^{-1/2} = 2^{1/4}5^{-1/8}\Phi^{1/2}\cos\left[\tfrac14\arctan(2) + \tfrac12\arcsin(\Phi^{-2})\right],
```





```math
H_M(e^{-\pi}) = 2^{-1/2}5^{-1/4}(\sqrt5 - 1)^{1/4}(\sqrt[4]5 + 1)^{1/2}R(e^{-\pi})^{1/2} = 2^{1/4}5^{-1/8}\Phi^{1/2}\sin\left[\tfrac14\arctan(2) + \tfrac12\arcsin(\Phi^{-2})\right],
```





```math
G_M(e^{-2\pi}) = 10^{-1/4}(\sqrt5 - 1)^{1/4}R(e^{-2\pi})^{-1/2} = 2^{1/2}5^{-1/8}\cos\left[\tfrac14\arctan(2)\right],
```





```math
H_M(e^{-2\pi}) = 10^{-1/4}(\sqrt5 - 1)^{1/4}R(e^{-2\pi})^{1/2} = 2^{1/2}5^{-1/8}\sin\left[\tfrac14\arctan(2)\right].
```

 בנקודות האלה מקבל השבר המשולב של רוג'רס–רמנוג'אן את הערכים



```math
R(e^{-\pi}) = \tfrac14(\sqrt5 + 1)\left(\sqrt5 - \sqrt{\sqrt5 + 2}\right)\left(\sqrt{\sqrt5 + 2} + \sqrt[4]5\right) = \tan\left[\tfrac14\arctan(2) + \tfrac12\arcsin(\Phi^{-2})\right] \approx 0.51143,
```





```math
R(e^{-2\pi}) = 4\sin\left(\tfrac1{20}\pi\right)\sin\left(\tfrac3{20}\pi\right) = \tan\left[\tfrac14\arctan(2)\right] \approx 0.28408.
```

 ($`R(e^{-\pi})`$ ניתן גם כמכפלה של ערכי הקוסינוס הלמניסקטי.) הערך $`R(e^{-2\pi})`$ הוא אחד הערכים שרמנוג'אן שלח להרדי במכתבו הראשון.

## זהויות עם פונקציית אטא של דדקינד

### גזירה בעזרת הממוצע הגאומטרי

נתונות ההגדרות



```math
G_M(q) = q^{-1/60}\frac1{(q; q^5)_\infty(q^4; q^5)_\infty}, \qquad H_M(q) = q^{11/60}\frac1{(q^2; q^5)_\infty(q^3; q^5)_\infty}.
```

 המנה שלהן היא בדיוק השבר המשולב: $`H_M(q)/G_M(q) = R(q)`$. המכפלה שלהן מצטמצמת לצירוף פשוט של מכפלות פוכהאמר:



```math
H_M(q)\,G_M(q) = q^{1/6}\frac1{(q; q^5)_\infty(q^2; q^5)_\infty(q^3; q^5)_\infty(q^4; q^5)_\infty} = q^{1/6}\frac{(q^5; q^5)_\infty}{(q; q)_\infty} = \frac{\eta_W(q^5)}{\eta_W(q)}.
```

 הממוצע הגאומטרי של שתי שרשראות השוויונות האלה נותן מיד את הביטויים



```math
G_M(q) = \eta_W(q^5)^{1/2}\eta_W(q)^{-1/2}R(q)^{-1/2}, \qquad H_M(q) = \eta_W(q^5)^{1/2}\eta_W(q)^{-1/2}R(q)^{1/2}.
```

 כך מבוטאות $`G_M`$ ו-$`H_M`$ רק בעזרת השבר המשולב $`R`$ ומנת פונקציות אטא. בעזרת מכפלות פוכהאמר בלבד מתקבלות הזהויות הבאות לפונקציות $`G`$ ו-$`H`$ הלא-מודולריות:



```math
G(q) = (q^5; q^5)_\infty^{1/2}(q; q)_\infty^{-1/2}\left[\frac{H(q)}{G(q)}\right]^{-1/2}, \qquad H(q) = (q^5; q^5)_\infty^{1/2}(q; q)_\infty^{-1/2}\left[\frac{H(q)}{G(q)}\right]^{1/2}.
```



### משפט המספרים המחומשים

עבור פונקציית אטא של דדקינד בצורת ובר מתקיים:



```math
\eta_W(x) = 2^{-1/6}\vartheta_{10}(x)^{1/6}\vartheta_{00}(x)^{1/6}\vartheta_{01}(x)^{2/3} = 2^{-1/3}\left[\vartheta_{10}(x^{1/2})\vartheta_{00}(x^{1/2})\vartheta_{01}(x^{1/2})\right]^{1/3},
```





```math
\eta_W(x) = x^{1/24}\prod_{n=1}^\infty(1 - x^n) = x^{1/24}(x; x)_\infty,
```





```math
\eta_W(x) = x^{1/24}\left\{1 + \sum_{n=1}^\infty\left[-x^{\mathrm{Fn}(2n-1)} - x^{\mathrm{Kr}(2n-1)} + x^{\mathrm{Fn}(2n)} + x^{\mathrm{Kr}(2n)}\right]\right\},
```





```math
\eta_W(x) = x^{1/24}\left\{1 + \sum_{n=1}^\infty P(n)x^n\right\}^{-1}.
```

 הנוסחה השלישית היא [משפט המספרים המחומשים](https://he.wikipedia.org/wiki/%D7%9E%D7%A9%D7%A4%D7%98_%D7%94%D7%9E%D7%A1%D7%A4%D7%A8%D7%99%D7%9D_%D7%94%D7%9E%D7%97%D7%95%D7%9E%D7%A9%D7%99%D7%9D), בגלל המעריכים, כאשר



```math
\mathrm{Fn}(z) = \tfrac12z(3z - 1), \qquad \mathrm{Kr}(z) = \tfrac12z(3z + 1)
```

 הם ה[מספרים המחומשים](https://he.wikipedia.org/wiki/%D7%9E%D7%A1%D7%A4%D7%A8_%D7%9E%D7%97%D7%95%D7%9E%D7%A9) ו"מספרי בית הקלפים". הנוסחה הרביעית מכילה כמקדמים את [מספרי החלוקה](https://he.wikipedia.org/wiki/%D7%A4%D7%95%D7%A0%D7%A7%D7%A6%D7%99%D7%99%D7%AA_%D7%94%D7%97%D7%9C%D7%95%D7%A7%D7%94_%28%D7%AA%D7%95%D7%A8%D7%AA_%D7%94%D7%9E%D7%A1%D7%A4%D7%A8%D7%99%D7%9D%29) הרגילים: $`P(n)`$ הוא מספר הדרכים לכתוב את $`n`$ כסכום של מחוברים שלמים חיוביים. למשל $`P(1), \dots, P(6) = 1, 2, 3, 5, 7, 11`$; עבור $`n = 4`$ החלוקות הן $`1 + 1 + 1 + 1,\ 1 + 1 + 2,\ 2 + 2,\ 1 + 3,\ 4`$.

### זהויות נוספות עם פונקציית אטא

את הפונקציות $`G_M`$ ו-$`H_M`$ אפשר לפשט עוד. הקשר הבא נוגע לפונקציית אטא בחזקה החמישית של הנום:



```math
\frac{\eta_W(q^5)}{\eta_W(q)} = \frac{\eta_W(q^2)^4}{\eta_W(q)^4}\,\frac{\vartheta_{01}(q^5)}{\vartheta_{01}(q)}\left[\frac{5\vartheta_{01}(q^5)^2}{4\vartheta_{01}(q)^2} - \frac14\right]^{-1}.
```

 צירוף שלוש הנוסחאות האחרונות נותן את זוג הנוסחאות



```math
G_M(q) = \frac{\eta_W(q^2)^2}{\eta_W(q)^2}\left[\frac{\vartheta_{01}(q^5)}{\vartheta_{01}(q)}\right]^{1/2}\left[\frac{5\vartheta_{01}(q^5)^2}{4\vartheta_{01}(q)^2} - \frac14\right]^{-1/2}R(q)^{-1/2},
```





```math
H_M(q) = \frac{\eta_W(q^2)^2}{\eta_W(q)^2}\left[\frac{\vartheta_{01}(q^5)}{\vartheta_{01}(q)}\right]^{1/2}\left[\frac{5\vartheta_{01}(q^5)^2}{4\vartheta_{01}(q)^2} - \frac14\right]^{-1/2}R(q)^{1/2}.
```



### פונקציית ובר המודולרית המצומצמת

פונקציות ובר המודולריות בצורתן המצומצמת הן דרך יעילה לחשב את ערכי פונקציות רוג'רס–רמנוג'אן. נסמן ב-$`q(\varepsilon)`$ את הנום האליפטי כפונקציה של המודולוס $`\varepsilon`$, ונגדיר את פונקציות ובר המצומצמות



```math
w_{Rn}(\varepsilon) = \frac{2^{(n-1)/4}\left[q(\varepsilon)^n; q(\varepsilon)^{2n}\right]_\infty}{\left[q(\varepsilon); q(\varepsilon)^2\right]_\infty^n}, \qquad w_{R5}(\varepsilon) = \frac{2\left[q(\varepsilon)^5; q(\varepsilon)^{10}\right]_\infty}{\left[q(\varepsilon); q(\varepsilon)^2\right]_\infty^5}.
```

 הפונקציה הזו מקיימת את המשוואה ממעלה שישית



```math
w_{R5}(\varepsilon)^6 - 2w_{R5}(\varepsilon)^5 = \tan\left[2\arctan(\varepsilon)\right]^2\left[2w_{R5}(\varepsilon) + 1\right],
```

 ולכן היא [פונקציה אלגברית](https://he.wikipedia.org/wiki/%D7%A4%D7%95%D7%A0%D7%A7%D7%A6%D7%99%D7%94_%D7%90%D7%9C%D7%92%D7%91%D7%A8%D7%99%D7%AA). אבל לפי משפט אבל–רופיני אי אפשר בדרך כלל לבטא אותה בביטויים אלמנטריים במודולוס. עם זאת, ערכים רבים כן ניתנים לביטוי אלמנטרי. ארבע דוגמאות:

1.  $`\varepsilon = \tfrac12\sqrt2`$: כאן $`\tan[2\arctan\varepsilon]^2 = 8`$, והמשוואה היא $`w^6 - 2w^5 = 16w + 8`$, עם הפתרון $`w_{R5}\left(\tfrac12\sqrt2\right) = \sqrt[4]5 + 1`$.
2.  $`\varepsilon = \sqrt2 - 1`$: המשוואה היא $`w^6 - 2w^5 = 2w + 1`$, ו-
    

    ```math
    w_{R5}(\sqrt2 - 1) = \tfrac12\left\{\tfrac43\sqrt2\cos\left(\tfrac1{10}\pi\right)\cosh\left[\tfrac13\mathrm{artanh}\left(\tfrac38\sqrt6\right)\right] + \tfrac13\tan\left(\tfrac15\pi\right)\right\}^2 - \tfrac12 = \Phi^{-1}\cot\left[\tfrac14\pi - \arctan\left(\tfrac13\sqrt5 - \tfrac13\sqrt[3]{6\sqrt{30} + 4\sqrt5} + \tfrac13\sqrt[3]{6\sqrt{30} - 4\sqrt5}\right)\right].
    ```


3.  $`\varepsilon = (2 - \sqrt3)(\sqrt3 - \sqrt2)`$: המשוואה היא $`w^6 - 2w^5 = (\sqrt2 - 1)^4(2w + 1)`$, ו-$`w_{R5} = \cot\left[\tfrac14\pi - \tfrac14\mathrm{arccsc}\left(\tfrac14\sqrt{10} + \tfrac14\right)\right]`$.
4.  $`\varepsilon = (2 - \sqrt3)(\sqrt3 + \sqrt2)`$: המשוואה היא $`w^6 - 2w^5 = (\sqrt2 + 1)^4(2w + 1)`$, ו-$`w_{R5} = \cot\left[\tfrac14\mathrm{arccsc}\left(\tfrac14\sqrt{10} + \tfrac14\right)\right]`$.

(את ארבע הדוגמאות בדקנו בחישוב מספרי, הן מול ההגדרה כמכפלה והן מול המשוואה.) לפונקציה הזו יש גם הביטוי



```math
w_{R5}(\varepsilon) = \frac{5\vartheta_{01}[q(\varepsilon)^5]^2}{2\vartheta_{01}[q(\varepsilon)]^2} - \frac12.
```



### זהות מדויקת באקסצנטריות לפונקציות G ו-H

כך אפשר לקבל נוסחאות מדויקות ל-$`G`$ ול-$`H`$ כפונקציות של האקסצנטריות. מנת פונקציות האטא הבאה תלויה באקסצנטריות כך:



```math
\frac{\eta_W[q(\varepsilon)^2]}{\eta_W[q(\varepsilon)]} = 2^{-1/4}\tan\left[2\arctan(\varepsilon)\right]^{1/12},
```

 והנוסחה לשבר המשולב $`R`$ כפונקציה של האקסצנטריות היא



```math
R[q(\varepsilon)] = \tan\left\{\frac12\arctan\left[\frac{w_{R5}(\varepsilon) - 2}{2w_{R5}(\varepsilon) + 1}\right]\right\}^{1/5}\tan\left\{\frac12\mathrm{arccot}\left[\frac{w_{R5}(\varepsilon) - 2}{2w_{R5}(\varepsilon) + 1}\right]\right\}^{2/5}.
```

 הצבת שלוש הנוסחאות האחרונות בנוסחאות הסופיות של הסעיף הקודם נותנת, עם $`X = \frac{w_{R5}(\varepsilon) - 2}{2w_{R5}(\varepsilon) + 1}`$:



```math
G_M[q(\varepsilon)] = \frac{\tan[2\arctan(\varepsilon)]^{1/6}\left[2w_{R5}(\varepsilon) + 1\right]^{1/4} }{5^{1/4}w_{R5}(\varepsilon)^{1/2} }\tan\left\{\tfrac12\arctan X\right\}^{-1/10}\tan\left\{\tfrac12\mathrm{arccot}X\right\}^{-1/5},
```





```math
H_M[q(\varepsilon)] = \frac{\tan[2\arctan(\varepsilon)]^{1/6}\left[2w_{R5}(\varepsilon) + 1\right]^{1/4} }{5^{1/4}w_{R5}(\varepsilon)^{1/2} }\tan\left\{\tfrac12\arctan X\right\}^{1/10}\tan\left\{\tfrac12\mathrm{arccot}X\right\}^{1/5}.
```

 באגף שמאל מופיעות $`G_M(q)`$ ו-$`H_M(q)`$ כפונקציות של הנום האליפטי $`q(\varepsilon)`$, ובאגף ימין צירוף אלגברי של האקסצנטריות $`\varepsilon`$. לכן הפונקציות $`G_M(q) = q^{-1/60}G(q)`$ ו-$`H_M(q) = q^{11/60}H(q)`$ אכן מודולריות.

## יישום למשוואות ממעלה חמישית

### המודולוס המתאים לפי שארל ארמיט

המקרה הכללי של משוואות ממעלה חמישית בצורת ברינג–ג'רארד אינו פתיר בביטויים אלמנטריים לפי משפט אבל–רופיני, אבל יש לו פתרון בעזרת הנום האליפטי של מודולוס מתאים, שמתואר בדרך פשוטה בעזרת הפונקציות האליפטיות הלמניסקטיות. נתבונן במשוואה



```math
x^5 + 5x = 4c.
```

 הפתרון הממשי לכל $`c`$ ממשי חיובי הוא



```math
x = \frac{5\vartheta_{00}(Q^5)^3 - \vartheta_{00}(Q^5)\vartheta_{00}(Q)^2}{4\vartheta_{10}(Q)\vartheta_{01}(Q)\vartheta_{00}(Q)}\times\frac{S(Q)^2 + R(Q^2)}{S(Q)}\times\left[R(Q^2)S(Q) + R(Q^2) + S(Q) - 1\right],
```

 כאשר $`Q`$ הוא הנום האליפטי של המודולוס המתאים:



```math
Q = q\left\{\mathrm{ctlh}\left[\tfrac12\mathrm{aclh}(c)\right]^2\right\} = q\left[\left(\sqrt{\sqrt{c^4 + 1} + 1} + c\right)\left(2c^2 + 2 + 2\sqrt{c^4 + 1}\right)^{-1/2}\right].
```

 הקיצור ctlh מסמן את הקוטנגנס הלמניסקטי ההיפרבולי, ו-aclh את פונקציית הקוסינוס הלמניסקטי ההיפרבולי ההפוכה. בערך האנגלי מופיעה גם צורה שקולה, ארוכה יותר, של אותו פתרון.

המתמטיקאי שארל ארמיט קבע את המודולוס האליפטי $`k`$ כפונקציה של המקדם החופשי בצורת ברינג–ג'רארד. במאמרו "Sur la résolution de l'Équation du cinquième degré" הוא תיאר את שיטת החישוב של המודולוס האליפטי מהמקדם החופשי, והגרסה האיטלקית של המאמר, "Sulla risoluzione delle equazioni del quinto grado", מכילה בעמוד 258 בדיוק את משוואת ברינג–ג'רארד שלמעלה, שאפשר לפתור אותה ישירות בעזרת הפונקציות שמבוססות על המודולוס המתאים.

### דוגמאות חישוב

- עבור $`x^5 + 5x = 8`$ ($`c = 2`$): $`Q = q\left[\left(\sqrt{\sqrt{17} + 1} + 2\right)\left(10 + 2\sqrt{17}\right)^{-1/2}\right] = 0.30634665444660742653\ldots`$, והפתרון הוא $`x = 1.16703618370164304731\ldots`$.
- עבור $`x^5 + 5x = 12`$ ($`c = 3`$): $`Q = q\left[\left(\sqrt{\sqrt{82} + 1} + 3\right)\left(20 + 2\sqrt{82}\right)^{-1/2}\right] = 0.37066495115202407562\ldots`$, והפתרון הוא $`x = 1.38409179582314635924\ldots`$.

(חישבנו את שני הפתרונות מהנוסחה, והשווינו לשורש הממשי של המשוואה שנמצא בשיטה נומרית; הספרות מתלכדות.)

## יישומים בפיזיקה

זהויות רוג'רס–רמנוג'אן הופיעו בפתרון של בקסטר למודל המשושים הקשים ב[מכניקה סטטיסטית](https://he.wikipedia.org/wiki/%D7%9E%D7%9B%D7%A0%D7%99%D7%A7%D7%94_%D7%A1%D7%98%D7%98%D7%99%D7%A1%D7%98%D7%99%D7%AA). הצורה הסטנדרטית ה"לא מודולרית" של השבר המשולב של רמנוג'אן היא



```math
\frac{H(q)}{G(q)} = \cfrac1{1 + \cfrac q{1 + \cfrac{q^2}{1 + \cfrac{q^3}{1 + \cdots} } } }.
```



## קשרים לאלגבראות לי אפיניות ולאלגבראות של אופרטורי קודקוד

ג'יימס לפובסקי ורוברט לי וילסון היו הראשונים שהוכיחו את זהויות רוג'רס–רמנוג'אן בשיטות של [תורת ההצגות](https://he.wikipedia.org/wiki/%D7%AA%D7%95%D7%A8%D7%AA_%D7%94%D7%94%D7%A6%D7%92%D7%95%D7%AA) בלבד. הם הוכיחו את הזהויות בעזרת מודולים מרמה 3 של אלגברת לי האפינית $`\widehat{\mathfrak{sl}_2}`$, ותוך כדי ההוכחה המציאו והשתמשו במה שקראו לו $`Z`$-אלגבראות. הגישה של לפובסקי ווילסון אוניברסלית, במובן שהיא מטפלת בכל אלגבראות הלי האפיניות בכל הרמות, ואפשר להשתמש בה כדי למצוא (ולהוכיח) זהויות חלוקה חדשות. הדוגמה הראשונה כזו היא הזהויות של קפרלי, שגילה סטפנו קפרלי בעזרת מודולים מרמה 3 של אלגברת הלי האפינית $`A_2^{(2)}`$.

## הערות שוליים
