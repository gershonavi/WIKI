# משפט אפרי

ב[מתמטיקה](https://he.wikipedia.org/wiki/%D7%9E%D7%AA%D7%9E%D7%98%D7%99%D7%A7%D7%94), **משפט אפרי** (ב[אנגלית](https://he.wikipedia.org/wiki/%D7%90%D7%A0%D7%92%D7%9C%D7%99%D7%AA): Apéry's theorem) הוא תוצאה ב[תורת המספרים](https://he.wikipedia.org/wiki/%D7%AA%D7%95%D7%A8%D7%AA_%D7%94%D7%9E%D7%A1%D7%A4%D7%A8%D7%99%D7%9D) הקובעת ש[קבוע אפרי](https://he.wikipedia.org/wiki/%D7%A7%D7%91%D7%95%D7%A2_%D7%90%D7%A4%D7%A8%D7%99) $`\zeta(3)`$ הוא [אי-רציונלי](https://he.wikipedia.org/wiki/%D7%9E%D7%A1%D7%A4%D7%A8_%D7%90%D7%99-%D7%A8%D7%A6%D7%99%D7%95%D7%A0%D7%9C%D7%99). כלומר, את המספר



```math
\zeta(3) = \sum_{n=1}^\infty \frac{1}{n^3} = \frac{1}{1^3} + \frac{1}{2^3} + \frac{1}{3^3} + \cdots = 1.2020569\ldots
```

 אי אפשר לכתוב כשבר $`p/q`$, כאשר $`p`$ ו-$`q`$ [מספרים שלמים](https://he.wikipedia.org/wiki/%D7%9E%D7%A1%D7%A4%D7%A8_%D7%A9%D7%9C%D7%9D). המשפט קרוי על שם רוז'ה אפרי.

אפשר להראות שהערכים המיוחדים של [פונקציית זטא של רימן](https://he.wikipedia.org/wiki/%D7%A4%D7%95%D7%A0%D7%A7%D7%A6%D7%99%D7%99%D7%AA_%D7%96%D7%98%D7%90_%D7%A9%D7%9C_%D7%A8%D7%99%D7%9E%D7%9F) במספרים השלמים ה[זוגיים](https://he.wikipedia.org/wiki/%D7%96%D7%95%D7%92%D7%99%D7%95%D7%AA_%28%D7%9E%D7%AA%D7%9E%D7%98%D7%99%D7%A7%D7%94%29) $`2n`$ ($`n > 0`$) הם אי-רציונליים, בעזרת [מספרי ברנולי](https://he.wikipedia.org/wiki/%D7%9E%D7%A1%D7%A4%D7%A8%D7%99_%D7%91%D7%A8%D7%A0%D7%95%D7%9C%D7%99), אך עדיין פתוחה השאלה אם ערכי הפונקציה במספרים השלמים האי-זוגיים $`2n+1`$ ($`n > 1`$) הם רציונליים או לא (אם כי [משערים](https://he.wikipedia.org/wiki/%D7%94%D7%A9%D7%A2%D7%A8%D7%94) שהם אי-רציונליים).

## היסטוריה

[לאונרד אוילר](https://he.wikipedia.org/wiki/%D7%9C%D7%90%D7%95%D7%A0%D7%A8%D7%93_%D7%90%D7%95%D7%99%D7%9C%D7%A8) הוכיח שאם $`n`$ מספר שלם חיובי, אז



```math
\frac{1}{1^{2n} } + \frac{1}{2^{2n} } + \frac{1}{3^{2n} } + \frac{1}{4^{2n} } + \cdots = \frac{p}{q}\pi^{2n}
```

 עבור מספר רציונלי $`p/q`$ כלשהו. במפורש, אם מסמנים את הטור האינסופי באגף שמאל ב-$`\zeta(2n)`$, הוא הראה ש-



```math
\zeta(2n) = (-1)^{n+1}\frac{B_{2n}(2\pi)^{2n} }{2(2n)!},
```

 כאשר $`B_n`$ הם מספרי ברנולי הרציונליים. אחרי שהוכח ש-$`\pi^n`$ תמיד אי-רציונלי (מכיוון ש-$`\pi`$ [טרנסצנדנטי](https://he.wikipedia.org/wiki/%D7%9E%D7%A1%D7%A4%D7%A8_%D7%98%D7%A8%D7%A0%D7%A1%D7%A6%D7%A0%D7%93%D7%A0%D7%98%D7%99)), נובע מכך ש-$`\zeta(2n)`$ אי-רציונלי לכל מספר שלם חיובי $`n`$.

לא ידועה הצגה כזו בעזרת $`\pi`$ עבור קבועי הזטא בארגומנטים אי-זוגיים, הערכים $`\zeta(2n+1)`$ עבור מספרים שלמים חיוביים $`n`$. משערים שהיחסים



```math
\frac{\zeta(2n+1)}{\pi^{2n+1} }
```

 הם טרנסצנדנטיים לכל מספר שלם $`n \ge 1`$.[^1]

בשל כך לא נמצאה הוכחה לכך שקבועי הזטא בארגומנטים אי-זוגיים אי-רציונליים, אף שהאמינו (ועדיין מאמינים) שכולם טרנסצנדנטיים. אולם ביוני 1978 נתן רוז'ה אפרי הרצאה בשם "Sur l'irrationalité de ζ(3)" ("על האי-רציונליות של ζ(3)"). במהלך ההרצאה שרטט הוכחות לכך ש-$`\zeta(3)`$ ו-$`\zeta(2)`$ אי-רציונליים; את השנייה הוכיח בשיטות שהן פישוט של השיטות ששימשו לראשונה, ולא בעזרת ההצגה באמצעות $`\pi`$. בשל האופי הבלתי צפוי לחלוטין של ההוכחה והגישה המזלזלת והסכמטית מאוד של אפרי לנושא, רבים מהמתמטיקאים בקהל דחו את ההוכחה כשגויה. אולם אנרי כהן, הנדריק לנסטרה ואלפרד ואן דר פורטן חשדו שאפרי עלה על משהו, ויצאו לאמת את ההוכחה שלו. כעבור חודשיים סיימו לאמת את ההוכחה של אפרי, וב-18 באוגוסט נתן כהן הרצאה שבה הציג את כל פרטי ההוכחה. אחרי ההרצאה עלה אפרי עצמו לבמה והסביר את המקור לכמה מרעיונותיו.[^2]

## ההוכחה של אפרי

ההוכחה המקורית של אפרי[^3][^4] התבססה על קריטריון האי-רציונליות הידוע של [דיריכלה](https://he.wikipedia.org/wiki/%D7%99%D7%95%D7%94%D7%90%D7%9F_%D7%A4%D7%98%D7%A8_%D7%92%D7%95%D7%A1%D7%98%D7%91_%D7%9C%D7%96%27%D7%9F_%D7%93%D7%99%D7%A8%D7%99%D7%9B%D7%9C%D7%94), שלפיו מספר $`\xi`$ הוא אי-רציונלי אם יש אינסוף זוגות של מספרים שלמים [זרים](https://he.wikipedia.org/wiki/%D7%9E%D7%A1%D7%A4%D7%A8%D7%99%D7%9D_%D7%96%D7%A8%D7%99%D7%9D) $`p`$ ו-$`q`$ כך ש-



```math
\left|\xi-\frac{p}{q}\right|\lt \frac{c}{q^{1+\delta} }
```

 עבור $`c, \delta > 0`$ קבועים כלשהם.

(הסבר: אם $`\xi = a/b`$ רציונלי ו-$`p/q \neq \xi`$, אז $`|\xi - p/q| = |aq - bp|/(bq) \geq 1/(bq)`$; וזה סותר את $`c/q^{1+\delta}`$ עבור $`q`$ גדול.)

נקודת המוצא של אפרי הייתה ההצגה של $`\zeta(3)`$ כטור



```math
\zeta(3) = \frac{5}{2} \sum_{n=1}^\infty \frac{(-1)^{n-1} }{n^3\binom{2n}{n} }.
```

 באופן גס, אפרי הגדיר אז סדרה $`c_{n,k}`$ המתכנסת ל-$`\zeta(3)`$ בערך באותה מהירות כמו הטור שלמעלה, ובמפורש



```math
c_{n,k} = \sum_{m=1}^{n}\frac{1}{m^{3} } + \sum_{m=1}^{k}\frac{(-1)^{m-1} }{2m^{3}\binom{n}{m}\binom{n+m}{m} }.
```

 לאחר מכן הגדיר שתי סדרות נוספות, $`a_n`$ ו-$`b_n`$, שהמנה שלהן היא, באופן גס, $`c_{n,k}`$:



```math
a_{n} = \sum_{k=0}^{n}c_{n,k}\binom{n}{k}^{2}\binom{n+k}{k}^{2}
```

 ו-



```math
b_{n}=\sum_{k=0}^{n}\binom{n}{k}^{2}\binom{n+k}{k}^{2}.
```

 הסדרה $`a_n/b_n`$ מתכנסת ל-$`\zeta(3)`$ מהר מספיק כדי להפעיל את הקריטריון, אבל לרוע המזל $`a_n`$ אינו שלם החל מ-$`n=2`$. למרות זאת, אפרי הראה שגם אחרי הכפלת $`a_n`$ ו-$`b_n`$ במספר שלם מתאים ($`2\,\mathrm{lcm}(1, \dots, n)^3`$) כדי לתקן בעיה זו, ההתכנסות עדיין מהירה מספיק כדי להבטיח אי-רציונליות.

לדוגמה, $`b_0, b_1, b_2, b_3, \dots = 1, 5, 73, 1445, \dots`$ (מספרי אפרי), ו-$`a_1/b_1 = 6/5 = 1.2`$, $`a_2/b_2 = 351/292 \approx 1.2020548`$, $`a_3/b_3 = 62531/52020 \approx 1.20205690`$; כל שלב מוסיף כמעט שלוש ספרות נכונות.

## הוכחות מאוחרות יותר

בתוך שנה מהתוצאה של אפרי מצא פריץ בויקרס הוכחה חלופית,[^5] שבה החליף את הטורים של אפרי ב[אינטגרלים](https://he.wikipedia.org/wiki/%D7%90%D7%99%D7%A0%D7%98%D7%92%D7%A8%D7%9C) שבהם מופיעים [פולינומי לז'נדר](https://he.wikipedia.org/wiki/%D7%A4%D7%95%D7%9C%D7%99%D7%A0%D7%95%D7%9E%D7%99_%D7%9C%D7%96%27%D7%A0%D7%93%D7%A8) המוזזים $`\tilde{P}_{n}(x)`$. בעזרת הצגה שלימים הוכללה לנוסחה של חדג'יקוסטס, הראה בויקרס ש-



```math
\int_{0}^{1}\int_{0}^{1}\frac{-\log(xy)}{1-xy}\tilde{P}_{n}(x)\tilde{P}_{n}(y)\,dx\,dy=\frac{A_{n}+B_{n}\zeta(3)}{\mathrm{lcm}\left[1,\ldots,n\right]^{3} }
```

 עבור מספרים שלמים $`A_n`$ ו-$`B_n`$ כלשהם (הסדרות (סדרה [A171484](https://oeis.org/A171484) ב-OEIS) ו-(סדרה [A171485](https://oeis.org/A171485) ב-OEIS)). בעזרת אינטגרציה בחלקים, ובהנחה ש-$`\zeta(3)`$ רציונלי ושווה ל-$`a/b`$, הסיק בויקרס בסופו של דבר את אי-השוויון



```math
0\lt \frac{1}{b}\leq\left|A_{n}+B_{n}\zeta(3)\right|\leq 4\left(\frac{4}{5}\right)^{n},
```

 וזו [סתירה](https://he.wikipedia.org/wiki/%D7%94%D7%95%D7%9B%D7%97%D7%94_%D7%91%D7%93%D7%A8%D7%9A_%D7%94%D7%A9%D7%9C%D7%99%D7%9C%D7%94), כי הביטוי הימני ביותר שואף לאפס כאשר $`n\to\infty`$, ולכן חייב בסופו של דבר לרדת מתחת ל-$`1/b`$.

הוכחה חדשה יותר של ואדים זודילין מזכירה יותר את ההוכחה המקורית של אפרי,[^6] ויש לה גם קווי דמיון להוכחה רביעית, של יורי נסטרנקו.[^7] גם ההוכחות המאוחרות האלה מגיעות לסתירה מההנחה ש-$`\zeta(3)`$ רציונלי, על ידי בניית סדרות השואפות לאפס אך חסומות מלמטה על ידי קבוע חיובי. הן מעט פחות שקופות מההוכחות המוקדמות, כי הן נשענות על טורים היפרגאומטריים (ראו [פונקציה היפרגאומטרית](https://he.wikipedia.org/wiki/%D7%A4%D7%95%D7%A0%D7%A7%D7%A6%D7%99%D7%94_%D7%94%D7%99%D7%A4%D7%A8%D7%92%D7%90%D7%95%D7%9E%D7%98%D7%A8%D7%99%D7%AA)).

## קבועי זטא גבוהים יותר

  
*ראו גם [ערכים מיוחדים של פונקציית זטא של רימן](%D7%A2%D7%A8%D7%9B%D7%99%D7%9D%20%D7%9E%D7%99%D7%95%D7%97%D7%93%D7%99%D7%9D%20%D7%A9%D7%9C%20%D7%A4%D7%95%D7%A0%D7%A7%D7%A6%D7%99%D7%99%D7%AA%20%D7%96%D7%98%D7%90%20%D7%A9%D7%9C%20%D7%A8%D7%99%D7%9E%D7%9F.md)*

אפרי ובויקרס יכלו לפשט את ההוכחות שלהם כך שיעבדו גם עבור $`\zeta(2)`$, בזכות ההצגה כטור



```math
\zeta(2)=3\sum_{n=1}^{\infty}\frac{1}{n^{2}\binom{2n}{n} }.
```

 בעקבות ההצלחה של השיטה של אפרי נערך חיפוש אחר מספר $`\xi_5`$ בעל התכונה ש-



```math
\zeta(5)=\xi_{5}\sum_{n=1}^{\infty}\frac{(-1)^{n-1} }{n^{5}\binom{2n}{n} }.
```

 אילו נמצא $`\xi_5`$ כזה, היה צפוי שהשיטות ששימשו להוכחת משפט אפרי יעבדו גם בהוכחה ש-$`\zeta(5)`$ אי-רציונלי. לרוע המזל, חיפוש ממוחשב נרחב[^8] לא מצא קבוע כזה, ולמעשה ידוע כיום שאם $`\xi_5`$ קיים, והוא [מספר אלגברי](https://he.wikipedia.org/wiki/%D7%9E%D7%A1%D7%A4%D7%A8_%D7%90%D7%9C%D7%92%D7%91%D7%A8%D7%99) ממעלה 25 לכל היותר, אז המקדמים ב[פולינום המינימלי](https://he.wikipedia.org/wiki/%D7%A4%D7%95%D7%9C%D7%99%D7%A0%D7%95%D7%9D_%D7%9E%D7%99%D7%A0%D7%99%D7%9E%D7%9C%D7%99) שלו חייבים להיות עצומים, לפחות $`10^{383}`$. לכן לא נראה סביר שאפשר להרחיב את ההוכחה של אפרי לקבועי הזטא האי-זוגיים הגבוהים יותר.

העבודה של ואדים זודילין וטנגי ריבואל הראתה שאינסוף מהמספרים $`\zeta(2n+1)`$ חייבים להיות אי-רציונליים,[^9] ואף שלפחות אחד מהמספרים $`\zeta(5)`$, $`\zeta(7)`$, $`\zeta(9)`$ ו-$`\zeta(11)`$ חייב להיות אי-רציונלי.[^10] העבודה שלהם משתמשת בצירופים ליניאריים של ערכי פונקציית זטא ובהערכות עליהם, כדי לחסום את ה[ממד](https://he.wikipedia.org/wiki/%D7%9E%D7%9E%D7%93_%28%D7%90%D7%9C%D7%92%D7%91%D7%A8%D7%94_%D7%9C%D7%99%D7%A0%D7%99%D7%90%D7%A8%D7%99%D7%AA%29) של ה[מרחב הווקטורי](https://he.wikipedia.org/wiki/%D7%9E%D7%A8%D7%97%D7%91_%D7%95%D7%A7%D7%98%D7%95%D7%A8%D7%99) הנפרש על ידי ערכי פונקציית זטא במספרים השלמים האי-זוגיים. התקוות שזודילין יצליח לקצר את הרשימה שלו למספר אחד בלבד לא התממשו, אך העבודה על בעיה זו היא עדיין תחום מחקר פעיל. לקבועי הזטא הגבוהים יש שימוש בפיזיקה: הם מתארים פונקציות מתאם בשרשראות ספין קוונטיות (ראו [מודל הייזנברג](https://he.wikipedia.org/wiki/%D7%9E%D7%95%D7%93%D7%9C_%D7%94%D7%99%D7%99%D7%96%D7%A0%D7%91%D7%A8%D7%92)).[^11]
