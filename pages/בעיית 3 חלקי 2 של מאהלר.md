# בעיית 3 חלקי 2 של מאהלר

ב[מתמטיקה](https://he.wikipedia.org/wiki/%D7%9E%D7%AA%D7%9E%D7%98%D7%99%D7%A7%D7%94), **בעיית 3/2 של מאהלר** (ב[אנגלית](https://he.wikipedia.org/wiki/%D7%90%D7%A0%D7%92%D7%9C%D7%99%D7%AA): Mahler's 3/2 problem) עוסקת בשאלת הקיום של "מספרי $`Z`$".

**מספר $`Z`$** הוא מספר ממשי חיובי $`x`$ כך שהחלקים השבורים של



```math
x \left(\frac 3 2\right)^ n
```

 קטנים מ-$`1/2`$ לכל שלם חיובי $`n`$. קורט מאהלר שיער ב-1968 שאין מספרי $`Z`$.[^1]

באופן כללי יותר, עבור מספר ממשי $`\alpha`$ מגדירים את $`\Omega(\alpha)`$ כ-



```math
\Omega(\alpha) = \inf_{\theta>0}\left( \limsup_{n \rightarrow \infty} \left\{\theta\alpha^n\right\} - \liminf_{n \rightarrow \infty} \left\{\theta\alpha^n\right\} \right).
```

 ההשערה של מאהלר הייתה נובעת אילו $`\Omega(3/2)`$ גדול מ-$`1/2`$. (הסבר: אם $`x`$ הוא מספר $`Z`$, כל החלקים השבורים של $`x(3/2)^n`$ נמצאים בקטע $`[0, 1/2)`$, ולכן ההפרש בין ה-limsup ל-liminf שלהם הוא לכל היותר $`1/2`$, כלומר $`\Omega(3/2) \le 1/2`$.) פלאטו, לגריאס ופולינגטון הראו[^2] ש-



```math
\Omega\left(\frac p q\right) > \frac 1 p
```

 לכל רציונלי $`p/q > 1`$ בצורה מצומצמת. עבור $`3/2`$ זה נותן $`\Omega(3/2) > 1/3`$, שעדיין אינו מספיק כדי להוכיח את ההשערה.
