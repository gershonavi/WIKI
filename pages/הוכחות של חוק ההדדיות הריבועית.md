# הוכחות של חוק ההדדיות הריבועית

ב[תורת המספרים](https://he.wikipedia.org/wiki/%D7%AA%D7%95%D7%A8%D7%AA_%D7%94%D7%9E%D7%A1%D7%A4%D7%A8%D7%99%D7%9D), [חוק ההדדיות הריבועית](https://he.wikipedia.org/wiki/%D7%97%D7%95%D7%A7_%D7%94%D7%94%D7%93%D7%93%D7%99%D7%95%D7%AA_%D7%94%D7%A8%D7%99%D7%91%D7%95%D7%A2%D7%99%D7%AA), כמו [משפט פיתגורס](https://he.wikipedia.org/wiki/%D7%9E%D7%A9%D7%A4%D7%98_%D7%A4%D7%99%D7%AA%D7%92%D7%95%D7%A8%D7%A1), זכה למספר גדול באופן חריג של [הוכחות](https://he.wikipedia.org/wiki/%D7%94%D7%95%D7%9B%D7%97%D7%94_%D7%9E%D7%AA%D7%9E%D7%98%D7%99%D7%AA). פורסמו כמה מאות הוכחות שונות שלו. נזכיר את החוק: אם $`p`$ ו-$`q`$ ראשוניים אי-זוגיים שונים, אז



```math
\left(\frac qp\right)\left(\frac pq\right) = (-1)^{\frac{p-1}2\cdot\frac{q-1}2},
```

 כאשר $`\left(\frac ap\right)`$ הוא [סמל לז'נדר](https://he.wikipedia.org/wiki/%D7%A1%D7%99%D7%9E%D7%9F_%D7%9C%D7%96%27%D7%A0%D7%93%D7%A8); ולצידו שני "המשלימים": $`\left(\frac{-1}p\right) = (-1)^{(p-1)/2}`$ ו-$`\left(\frac2p\right) = (-1)^{(p^2-1)/8}`$.

## סקירת ההוכחות

מבין ההוכחות הקומבינטוריות האלמנטריות, יש שתיים שמשתמשות בסוגים של [ספירה כפולה](https://he.wikipedia.org/wiki/%D7%A1%D7%A4%D7%99%D7%A8%D7%94_%D7%9B%D7%A4%D7%95%D7%9C%D7%94). אחת, של [גוטהולד אייזנשטיין](https://he.wikipedia.org/wiki/%D7%92%D7%95%D7%98%D7%94%D7%95%D7%9C%D7%93_%D7%90%D7%99%D7%99%D7%96%D7%A0%D7%A9%D7%98%D7%99%D7%99%D7%9F), סופרת [נקודות סריג](https://he.wikipedia.org/wiki/%D7%A0%D7%A7%D7%95%D7%93%D7%AA_%D7%A1%D7%A8%D7%99%D7%92). אחרת מפעילה את [הלמה של זולוטריוב](https://he.wikipedia.org/wiki/%D7%94%D7%9C%D7%9E%D7%94_%D7%A9%D7%9C_%D7%96%D7%95%D7%9C%D7%95%D7%98%D7%A8%D7%99%D7%95%D7%91) על $`(\mathbb{Z}/pq\mathbb{Z})^{\times}`$, שמתואר לפי [משפט השאריות הסיני](https://he.wikipedia.org/wiki/%D7%9E%D7%A9%D7%A4%D7%98_%D7%94%D7%A9%D7%90%D7%A8%D7%99%D7%95%D7%AA_%D7%94%D7%A1%D7%99%D7%A0%D7%99) כ-$`(\mathbb{Z} /p \mathbb{Z})^{\times} \times (\mathbb{Z} /q \mathbb{Z})^{\times}`$, ומחשבת את ה[סימן של תמורה](https://he.wikipedia.org/wiki/%D7%A1%D7%99%D7%9E%D7%9F_%D7%A9%D7%9C_%D7%AA%D7%9E%D7%95%D7%A8%D7%94). ההוכחה הקצרה ביותר הידועה משתמשת גם היא בגרסה פשוטה של ספירה כפולה, כלומר ספירה כפולה מודולו ראשוני קבוע. בערך הזה נציג את ההוכחה של אייזנשטיין, הוכחה בעזרת [סכומי גאוס](%D7%A1%D7%9B%D7%95%D7%9D%20%D7%92%D7%90%D7%95%D7%A1.md), והוכחה בעזרת [תורת המספרים האלגברית](https://he.wikipedia.org/wiki/%D7%AA%D7%95%D7%A8%D7%AA_%D7%94%D7%9E%D7%A1%D7%A4%D7%A8%D7%99%D7%9D_%D7%94%D7%90%D7%9C%D7%92%D7%91%D7%A8%D7%99%D7%AA).

## ההוכחה של אייזנשטיין

ההוכחה של אייזנשטיין לחוק ההדדיות הריבועית היא פישוט של ההוכחה השלישית של [גאוס](https://he.wikipedia.org/wiki/%D7%A7%D7%A8%D7%9C_%D7%A4%D7%A8%D7%99%D7%93%D7%A8%D7%99%D7%9A_%D7%92%D7%90%D7%95%D7%A1). היא אינטואיטיבית יותר מבחינה גאומטרית ודורשת פחות מניפולציות טכניות.

נקודת המוצא היא "הלמה של אייזנשטיין", שאומרת שעבור ראשוני אי-זוגי $`p`$ ושלם חיובי $`a`$ שאינו מתחלק ב-$`p`$,



```math
\left(\frac ap\right) = (-1)^{\sum_u \left \lfloor au/p \right \rfloor},
```

 כאשר $`\lfloor x \rfloor`$ מסמן את [הערך השלם](https://he.wikipedia.org/wiki/%D7%A4%D7%95%D7%A0%D7%A7%D7%A6%D7%99%D7%99%D7%AA_%D7%94%D7%A2%D7%A8%D7%9A_%D7%94%D7%A9%D7%9C%D7%9D) (השלם הגדול ביותר שאינו גדול מ-$`x`$), והסכום הוא על השלמים ה*זוגיים* $`u = 2, 4, 6, \ldots, p-1`$. למשל,



```math
\left(\frac 7{11}\right) = (-1)^{ \lfloor 14/11 \rfloor + \lfloor 28/11 \rfloor + \lfloor 42/11 \rfloor + \lfloor 56/11 \rfloor + \lfloor 70/11 \rfloor } = (-1)^{1 + 2 + 3 + 5 + 6} = (-1)^{17} = -1.
```

 (ואכן, השאריות הריבועיות מודולו 11 הן 1, 3, 4, 5, 9, ו-7 אינו ביניהן.) התוצאה הזו דומה מאוד ל[למה של גאוס](https://he.wikipedia.org/wiki/%D7%94%D7%9C%D7%9E%D7%94_%D7%A9%D7%9C_%D7%92%D7%90%D7%95%D7%A1_%28%D7%AA%D7%95%D7%A8%D7%AA_%D7%94%D7%9E%D7%A1%D7%A4%D7%A8%D7%99%D7%9D%29), ואפשר להוכיח אותה באופן דומה (ההוכחה מובאת להלן).

בעזרת הייצוג הזה של $`(q/p)`$, הטיעון המרכזי אלגנטי למדי. נצייר את המלבן $`[0, p] \times [0, q]`$ במישור, עם הקודקודים $`A = (0, 0)`$, $`B = (p, 0)`$, $`C = (p, q)`$, ועם הנקודות $`X = (p/2, 0)`$, $`Y = (p/2, q/2)`$, $`Z = (p/2, q)`$ ו-$`W = (0, q/2)`$. הסכום $`\sum_u \lfloor qu/p \rfloor`$ סופר את נקודות הסריג עם קואורדינטת $`x`$ זוגית בפנים המשולש $`ABC`$ (מתחת לאלכסון $`AC`$): בעמודה $`x = u`$ יש בדיוק $`\lfloor qu/p \rfloor`$ נקודות כאלה.

כיוון שבכל עמודה יש מספר זוגי של נקודות (כלומר $`q-1`$ נקודות בגבהים $`1, \ldots, q-1`$), מספר הנקודות האלה באזור $`BCYX`$ שווה *מודולו 2* למספר הנקודות כאלה באזור $`CZY`$ (המשולש שמעל האלכסון, עם $`x \gt p/2`$): בכל עמודה $`x = u \gt p/2`$, הנקודות מתחת לאלכסון ומעליו משלימות זו את זו ל-$`q - 1`$.

אחר כך, כשהופכים את הציור בשני הצירים ($`(x, y) \mapsto (p - x, q - y)`$), רואים שמספר הנקודות עם קואורדינטת $`x`$ זוגית בתוך $`CZY`$ שווה למספר הנקודות בתוך $`AXY`$ עם קואורדינטת $`x`$ *אי-זוגית*. אפשר להצדיק זאת מתמטית כשמציינים ש-$`q-1-\lfloor 2kq/p \rfloor = \lfloor (p-2k)q/p \rfloor`$.[^1]

המסקנה היא



```math
\left(\frac qp\right) = (-1)^\mu,
```

 כאשר $`\mu`$ הוא המספר *הכולל* של נקודות הסריג בפנים $`AXY`$, כלומר $`\mu = \sum_{x=1}^{(p-1)/2}\lfloor qx/p \rfloor`$.

כשמחליפים בין $`p`$ ל-$`q`$, אותו טיעון מראה ש-



```math
\left(\frac pq\right) = (-1)^\nu,
```

 כאשר $`\nu`$ הוא מספר נקודות הסריג בפנים $`WYA`$. כיוון שאין נקודות סריג על הקו $`AY`$ עצמו (כי $`p`$ ו-$`q`$ [זרים](https://he.wikipedia.org/wiki/%D7%9E%D7%A1%D7%A4%D7%A8%D7%99%D7%9D_%D7%96%D7%A8%D7%99%D7%9D)), וכיוון שמספר הנקודות הכולל במלבן $`WYXA`$ הוא



```math
\frac{p-1}2 \cdot \frac{q-1}2,
```

 מקבלים



```math
\left(\frac qp\right) \left(\frac pq\right) = (-1)^{\mu + \nu} = (-1)^{(p-1)(q-1)/4}.
```



*דוגמה מלאה, $`p = 11`$, $`q = 7`$:* כאן $`\mu = \sum_{x=1}^{5}\lfloor 7x/11\rfloor = 0 + 1 + 1 + 2 + 3 = 7`$, ו-$`\nu = \sum_{y=1}^{3}\lfloor 11y/7\rfloor = 1 + 3 + 4 = 8`$. אכן $`\mu + \nu = 15 = 5\cdot3`$; $`\left(\frac7{11}\right) = (-1)^7 = -1`$, ו-$`\left(\frac{11}7\right) = \left(\frac47\right) = 1 = (-1)^8`$. (את הלמה של אייזנשטיין ואת ספירת נקודות הסריג בדקנו בחישוב לכל הראשוניים עד 80 ו-60, בהתאמה.)

### הוכחת הלמה של אייזנשטיין

עבור שלם זוגי $`u`$ בתחום $`1 \le u \le p-1`$, נסמן ב-$`r(u)`$ את השארית החיובית הקטנה ביותר של $`au`$ מודולו $`p`$. (למשל, עבור $`p = 11`$, $`a = 7`$, הערכים המותרים הם $`u = 2, 4, 6, 8, 10`$, והערכים המתאימים של $`r(u)`$ הם 3, 6, 9, 1, 4.)

המספרים $`(-1)^{r(u)}r(u)`$, שוב כשאריות חיוביות קטנות ביותר מודולו $`p`$, כולם *זוגיים* (בדוגמה שלנו הם 8, 6, 2, 10, 4). יתרה מזו, כולם שונים, כי אם $`(-1)^{r(u)}r(u) \equiv (-1)^{r(t)}r(t) \pmod p`$, אפשר לחלק ב-$`a`$ ולקבל $`u \equiv \pm t \pmod p`$. זה מחייב $`u \equiv t \pmod p`$, כי $`u`$ ו-$`t`$ שניהם *זוגיים*, ואילו $`p`$ אי-זוגי (אם $`u \equiv -t`$, אז $`u + t = p`$, וזה בלתי אפשרי). כיוון שיש בדיוק $`(p-1)/2`$ מהם, וכולם שונים, הם פשוט סידור מחדש של השלמים הזוגיים $`2, 4, \ldots, p-1`$ (השוו ל[הוכחה דומה של המשפט הקטן של פרמה](https://he.wikipedia.org/wiki/%D7%94%D7%9E%D7%A9%D7%A4%D7%98_%D7%94%D7%A7%D7%98%D7%9F_%D7%A9%D7%9C_%D7%A4%D7%A8%D7%9E%D7%94)). כשכופלים אותם יחד מקבלים



```math
(-1)^{r(2)}r(2) \cdot (-1)^{r(4)}r(4) \cdots (-1)^{r(p-1)}r(p-1) \equiv 2 \cdot 4 \cdots (p-1)\pmod{p}.
```

 מצד שני, $`r(u) \equiv au`$, ולכן אגף שמאל שקול ל-$`(-1)^{\sum r(u)}a^{(p-1)/2}\cdot 2\cdot4\cdots(p-1)`$. כשמחלקים בשני האגפים ב-$`2, 4, \ldots, p-1`$ (מותר, כי אף אחד מהם אינו מתחלק ב-$`p`$) ומסדרים מחדש, מקבלים



```math
a^{(p-1)/2} \equiv (-1)^{r(2) + r(4) + \cdots + r(p-1)}\pmod{p}.
```

 מצד שני, מההגדרה של $`r(u)`$ ושל פונקציית הערך השלם,



```math
au = p\left\lfloor\frac{au}p\right\rfloor + r(u),
```

 וכיוון ש-$`p`$ אי-זוגי ו-$`u`$ זוגי, נובע ש-$`\lfloor au/p \rfloor`$ ו-$`r(u)`$ שקולים מודולו 2, ולכן



```math
a^{(p-1)/2} \equiv (-1)^{\sum_u \lfloor au/p \rfloor} \pmod{p}.
```

 סיימנו, כי אגף שמאל הוא פשוט ביטוי חלופי ל-$`(a/p)`$, לפי [קריטריון אוילר](https://he.wikipedia.org/wiki/%D7%A7%D7%A8%D7%99%D7%98%D7%A8%D7%99%D7%95%D7%9F_%D7%90%D7%95%D7%99%D7%9C%D7%A8).

### תוספת ללמה

מאותו שוויון, $`qu = p\lfloor qu/p \rfloor + r(u)`$, נובע ש-$`\lfloor qu/p \rfloor`$ ו-$`r(u)`$ שקולים מודולו 2 או לא שקולים, תלוי רק בזוגיות של $`u`$: הם שקולים כש-$`u`$ זוגי, ולא שקולים כש-$`u`$ אי-זוגי. לכן, כשסוכמים על $`1\le u\le \frac{p-1}{2}`$ (כמו בלמה של גאוס), מקבלים



```math
(-1)^{\sum_u \lfloor qu/p \rfloor}= (-1)^{\sum_u (r(u)+u)}.
```

 למשל, עבור $`p = 11`$, $`q = 7`$, השאריות $`r(u)`$ עבור $`u = 1, \ldots, 5`$ הן 7, 3, 10, 6, 2, ופונקציית הערך השלם נותנת 0, 1, 1, 2, 3. תבנית השקילות מודולו 2 (1 = שקולים) היא 0, 1, 0, 1, 0 – בדיוק לפי זוגיות $`u`$.[^2]

## הוכחה בעזרת סכומי גאוס ריבועיים

ההוכחה של חוק ההדדיות הריבועית בעזרת [סכומי גאוס](%D7%A1%D7%9B%D7%95%D7%9D%20%D7%92%D7%90%D7%95%D7%A1.md) היא אחת ההוכחות הנפוצות והקלאסיות. ההוכחות האלה עובדות כשמשווים חישוב של ערך אחד בשתי דרכים שונות: אחת בעזרת [קריטריון אוילר](https://he.wikipedia.org/wiki/%D7%A7%D7%A8%D7%99%D7%98%D7%A8%D7%99%D7%95%D7%9F_%D7%90%D7%95%D7%99%D7%9C%D7%A8), והשנייה בעזרת [הבינום של ניוטון](https://he.wikipedia.org/wiki/%D7%94%D7%91%D7%99%D7%A0%D7%95%D7%9D_%D7%A9%D7%9C_%D7%A0%D7%99%D7%95%D7%98%D7%95%D7%9F). כדוגמה לשימוש בקריטריון אוילר, אפשר להשתמש בו כדי לתת הוכחה מהירה של המקרה המשלים הראשון, קביעת $`\left(\frac{-1}{p}\right)`$ עבור ראשוני אי-זוגי $`p`$: לפי קריטריון אוילר $`\left(\frac{-1}{p}\right) \equiv (-1)^{\frac{p-1}{2} } \pmod{p}`$, אבל כיוון ששני האגפים הם $`\pm1`$ ו-$`p`$ אי-זוגי (ובפרט $`p \gt 2`$), נובע ש-$`\left(\frac{-1}{p}\right) = (-1)^{\frac{p-1}{2} }`$.

### המקרה המשלים השני

יהי $`\zeta_8 = e^{2\pi i/8}`$, [שורש יחידה](https://he.wikipedia.org/wiki/%D7%A9%D7%95%D7%A8%D7%A9_%D7%99%D7%97%D7%99%D7%93%D7%94) פרימיטיבי מסדר 8, ונגדיר $`\tau = \zeta_8+\zeta_8^{-1}`$. כיוון ש-$`\zeta_8^2 = i`$ ו-$`\zeta_8^{-2}=-i`$, רואים ש-$`\tau^{2} = \zeta_8^2 + 2 + \zeta_8^{-2} = 2`$ (ואכן $`\tau = \sqrt2`$). כיוון ש-$`\tau`$ הוא [שלם אלגברי](https://he.wikipedia.org/wiki/%D7%A9%D7%9C%D7%9D_%D7%90%D7%9C%D7%92%D7%91%D7%A8%D7%99), עבור $`p`$ ראשוני אי-זוגי יש משמעות לדבר עליו מודולו $`p`$. (באופן פורמלי, מתבוננים ב[חוג](https://he.wikipedia.org/wiki/%D7%97%D7%95%D7%92_%28%D7%9E%D7%91%D7%A0%D7%94_%D7%90%D7%9C%D7%92%D7%91%D7%A8%D7%99%29) החילופי שמתקבל ממנת השלמים האלגבריים $`\mathbf A`$ באידיאל שנוצר על ידי $`p`$. כיוון ש-$`p^{-1}`$ אינו שלם אלגברי, $`1, 2, \ldots, p`$ הם איברים שונים של $`\mathbf A/p\mathbf A`$.) מקריטריון אוילר נובע ש-



```math
\tau^{p-1} =(\tau^2)^{\frac{p-1}{2} } = 2^{\frac{p-1}{2} } \equiv \left(\frac{2}{p}\right) \pmod{p},
```

 ולכן



```math
\tau^p\equiv \left(\frac{2}{p}\right)\tau\pmod{p}.
```

 אבל אפשר לחשב את $`\tau^p \bmod p`$ גם בעזרת הבינום של ניוטון. כיוון שכל האיברים המעורבים בפיתוח הבינומי מכילים גורם $`p`$, מקבלים $`\tau^p\equiv \zeta_8^p+\zeta_8^{-p} \pmod{p}`$. אפשר להעריך את זה בדיוק כשמפרידים לשני מקרים:

- $`p\equiv \pm 1\pmod{8} \Rightarrow \zeta_8^p+\zeta_8^{-p} = \zeta_8+\zeta_8^{-1}`$;
- $`p\equiv \pm 3 \pmod{8} \Rightarrow \zeta_8^p+\zeta_8^{-p} = -\zeta_8-\zeta_8^{-1}`$.

אלה האפשרויות היחידות לראשוני אי-זוגי מודולו 8, ואת שני המקרים אפשר לחשב בעזרת הצורה המעריכית $`\zeta_8=e^{2\pi i/8}`$ (למשל, $`\zeta_8^3 + \zeta_8^{-3} = 2\cos(3\pi/4) = -\sqrt2`$). אפשר לכתוב זאת בקצרה לכל הראשוניים האי-זוגיים כ-



```math
\tau^p \equiv (-1)^{\frac{p^2-1}{8} }\tau \pmod{p}.
```

 כשמשלבים את שני הביטויים ל-$`\tau^p \bmod p`$ וכופלים ב-$`\tau`$, מקבלים $`2\cdot \left(\frac{2}{p}\right) \equiv 2\cdot(-1)^{\frac{p^2-1}{8} }\pmod{p}`$. כיוון שגם $`\left(\frac{2}{p}\right)`$ וגם $`(-1)^{\frac{p^2-1}{8} }`$ הם $`\pm1`$, ו-2 הפיך מודולו $`p`$, מסיקים ש-



```math
\left(\frac{2}{p}\right) = (-1)^{\frac{p^2-1}{8} }.
```



### המקרה הכללי

הרעיון של ההוכחה הכללית הולך בעקבות המקרה המשלים לעיל: מוצאים שלם אלגברי ש"מקודדים" בו בדרך כלשהי סמלי לז'נדר של $`p`$, ואז מוצאים יחס בין סמלי לז'נדר כשמחשבים את החזקה ה-$`q`$-ית של השלם האלגברי הזה מודולו $`q`$ בשתי דרכים שונות: אחת בעזרת קריטריון אוילר והשנייה בעזרת הבינום של ניוטון.

יהי



```math
g_p = \sum_{k=1}^{p-1}\left(\frac{k}{p}\right)\zeta_p^k,
```

 כאשר $`\zeta_p=e^{2\pi i/p}`$ הוא שורש יחידה פרימיטיבי מסדר $`p`$. זהו [סכום גאוס](%D7%A1%D7%9B%D7%95%D7%9D%20%D7%92%D7%90%D7%95%D7%A1.md) ריבועי. תכונה יסודית של סכומי גאוס האלה היא ש-



```math
g_p^2 = p^*,
```

 כאשר $`p^*=\left(\frac{-1}{p}\right) p`$. (למשל, עבור $`p = 5`$: $`g_5 = \zeta - \zeta^2 - \zeta^3 + \zeta^4 = 2\cos(2\pi/5) - 2\cos(4\pi/5) = \sqrt5`$; ועבור $`p = 7`$, $`g_7 = i\sqrt7`$, ו-$`g_7^2 = -7`$. בדקנו מספרית עבור $`p = 5, 7, 11, 13`$.) כדי למקם זאת בהקשר של ההוכחה הבאה: האיברים הבודדים בסכום גאוס נמצאים ב[שדה הציקלוטומי](%D7%A9%D7%93%D7%94%20%D7%A6%D7%99%D7%A7%D7%9C%D7%95%D7%98%D7%95%D7%9E%D7%99.md) $`L = \mathbb{Q}(\zeta_p)`$, אבל הנוסחה לעיל מראה שהסכום עצמו יוצר את השדה הריבועי היחיד שמוכל ב-$`L`$. שוב, כיוון שסכום גאוס הריבועי הוא שלם אלגברי, אפשר להשתמש איתו בחשבון מודולרי. מהנוסחה היסודית הזו ומקריטריון אוילר מקבלים



```math
g_p^{q-1} = (g_p^2)^{\frac{q-1}{2} } = (p^*)^{\frac{q-1}{2} } \equiv \left(\frac{p^*}{q}\right)\pmod{q},
```

 ולכן



```math
g_p^q \equiv \left(\frac{p^*}{q}\right)g_p\pmod{q}.
```

 בעזרת הבינום של ניוטון מקבלים גם $`g_p^q\equiv\sum_{k=1}^{p-1}\left(\frac{k}{p}\right)^q\zeta_p^{qk} = \sum_{k=1}^{p-1}\left(\frac{k}{p}\right)\zeta_p^{qk} \pmod{q}`$ (כי $`q`$ אי-זוגי). אם $`a`$ הוא ההופכי של $`q`$ מודולו $`p`$, אפשר לכתוב את הסכום הזה מחדש כ-$`\left(\frac{a}{p}\right)\sum_{t=1}^{p-1}\left(\frac{t}{p}\right)\zeta_p^t`$ בעזרת ההצבה $`t=qk`$ (כי $`\left(\frac kp\right) = \left(\frac{at}p\right)`$), שאינה משנה את תחום הסכימה. כיוון ש-$`\left(\frac{a}{p}\right)=\left(\frac{q}{p}\right)`$, אפשר לכתוב



```math
g_p^q\equiv\left(\frac{q}{p}\right)g_p\pmod{q}.
```

 כשמשתמשים בשני הביטויים האלה ל-$`g_p^q \bmod q`$ וכופלים ב-$`g_p`$, מקבלים



```math
\left(\frac{q}{p}\right)p^*\equiv \left(\frac{p^*}{q}\right)p^*\pmod{q}.
```

 כיוון ש-$`p^*`$ הפיך מודולו $`q`$, וסמלי לז'נדר הם $`\pm1`$, מסיקים ש-



```math
\left(\frac{q}{p}\right) = \left(\frac{p^*}{q}\right),
```

 וזה, בצירוף $`\left(\frac{-1}q\right) = (-1)^{(q-1)/2}`$, הוא בדיוק חוק ההדדיות הריבועית.

## הוכחה בעזרת תורת המספרים האלגברית

ההוכחה שמוצגת כאן אינה בשום אופן הפשוטה ביותר הידועה; אבל היא עמוקה למדי, במובן שהיא מניעה כמה מהרעיונות של [הדדיות ארטין](%D7%94%D7%93%D7%93%D7%99%D7%95%D7%AA%20%D7%90%D7%A8%D7%98%D7%99%D7%9F.md).

### מבנה השדה הציקלוטומי

נניח ש-$`p`$ ראשוני אי-זוגי. הכול מתרחש בתוך ה[שדה הציקלוטומי](%D7%A9%D7%93%D7%94%20%D7%A6%D7%99%D7%A7%D7%9C%D7%95%D7%98%D7%95%D7%9E%D7%99.md) $`L = \mathbb Q(\zeta_p)`$, כאשר $`\zeta_p`$ הוא [שורש יחידה](https://he.wikipedia.org/wiki/%D7%A9%D7%95%D7%A8%D7%A9_%D7%99%D7%97%D7%99%D7%93%D7%94) פרימיטיבי מסדר $`p`$. התורה הבסיסית של שדות ציקלוטומיים אומרת שיש איזומורפיזם קנוני



```math
G = \mathrm{Gal}(L/\mathbb Q) \cong (\mathbb Z/p\mathbb Z)^\times
```

 ששולח את האוטומורפיזם $`\sigma_a`$ המקיים $`\sigma_a(\zeta_p) = \zeta_p^a`$ לאיבר $`a \in (\mathbb Z/p\mathbb Z)^\times`$.[^3]

עכשיו נתבונן בתת-החבורה $`H`$ של ה*ריבועים* של איברי $`G`$. כיוון ש-$`G`$ ציקלית (מסדר זוגי $`p - 1`$), ל-$`H`$ יש [אינדקס](https://he.wikipedia.org/wiki/%D7%90%D7%99%D7%A0%D7%93%D7%A7%D7%A1_%D7%A9%D7%9C_%D7%AA%D7%AA-%D7%97%D7%91%D7%95%D7%A8%D7%94) 2 ב-$`G`$, ולכן תת-השדה שמתאים ל-$`H`$ לפי [התאמת גלואה](https://he.wikipedia.org/wiki/%D7%94%D7%9E%D7%A9%D7%A4%D7%98_%D7%94%D7%99%D7%A1%D7%95%D7%93%D7%99_%D7%A9%D7%9C_%D7%AA%D7%95%D7%A8%D7%AA_%D7%92%D7%9C%D7%95%D7%90%D7%94) חייב להיות הרחבה *ריבועית* של $`\mathbb Q`$. (למעשה זו ההרחבה הריבועית *היחידה* של $`\mathbb Q`$ שמוכלת ב-$`L`$.) תורת [המחזורים הגאוסיים](%D7%9E%D7%97%D7%96%D7%95%D7%A8%20%D7%92%D7%90%D7%95%D7%A1%D7%99.md) קובעת איזו: מתברר שזו $`\mathbb Q(\sqrt{p^*})`$, כאשר



```math
p^* = \begin{cases} p & p \equiv 1 \pmod{4}, \\ -p & p \equiv 3 \pmod{4}. \end{cases}
```

 (זה בדיוק התוכן של $`g_p^2 = p^*`$ מהסעיף הקודם.)

בשלב הזה מתחילים לראות רמז לחוק ההדדיות הריבועית. מצד אחד, התמונה של $`H`$ ב-$`(\mathbb Z/p\mathbb Z)^\times`$ מורכבת בדיוק מ*השאריות הריבועיות מודולו $`p`$* (השונות מאפס). מצד שני, $`H`$ קשורה לניסיון להוציא *שורש ריבועי של $`p`$* (או אולי של $`-p`$). במילים אחרות, אם עכשיו $`q`$ ראשוני (שונה מ-$`p`$), הראינו ש-



```math
\left(\frac qp\right) =1 \quad \iff \quad \sigma_q \in H \quad \iff \quad \sigma_q \text{ משאיר את } \mathbb Q(\sqrt{p^*}) \text{ במקומו}.
```



### אוטומורפיזם פרובניוס

ב[חוג השלמים](https://he.wikipedia.org/wiki/%D7%97%D7%95%D7%92_%D7%94%D7%A9%D7%9C%D7%9E%D7%99%D7%9D) $`\mathcal O_L=\mathbb Z[\zeta_p]`$, נבחר [אידיאל ראשוני](https://he.wikipedia.org/wiki/%D7%90%D7%99%D7%93%D7%99%D7%90%D7%9C_%D7%A8%D7%90%D7%A9%D7%95%D7%A0%D7%99) לא מסועף $`\beta`$ כלשהו שמעל $`q`$, ויהי $`\phi \in \mathrm{Gal}(L/\mathbb Q)`$ [אוטומורפיזם פרובניוס](https://he.wikipedia.org/wiki/%D7%90%D7%95%D7%98%D7%95%D7%9E%D7%95%D7%A8%D7%A4%D7%99%D7%96%D7%9D_%D7%A4%D7%A8%D7%95%D7%91%D7%A0%D7%99%D7%95%D7%A1) המשויך ל-$`\beta`$; התכונה המאפיינת של $`\phi`$ היא ש-



```math
\phi(x) \equiv x^q \pmod{\beta}\quad \text{לכל } x\in \mathcal O_L.
```

 (קיומו של איבר פרובניוס כזה תלוי בלא מעט מהמנגנון של תורת המספרים האלגברית.)

העובדה המרכזית על $`\phi`$ שאנחנו צריכים היא שלכל תת-שדה $`K`$ של $`L`$,



```math
\phi\text{ משאיר את } K \text{ במקומו} \quad \iff \quad q\text{ מתפצל לחלוטין ב-} K.
```

 אכן, יהי $`\delta`$ אידיאל כלשהו של $`\mathcal O_K`$ מתחת ל-$`\beta`$ (ולכן מעל $`q`$). אז, כיוון ש-$`\phi(x) \equiv x^q \pmod{\delta}`$ לכל $`x\in \mathcal O_K`$, רואים ש-$`\phi\vert_K \in \mathrm{Gal}(K/\mathbb Q)`$ הוא פרובניוס של $`\delta`$. תוצאה סטנדרטית על $`\phi`$ היא שהסדר שלו שווה לדרגת האינרציה המתאימה; כלומר,



```math
\mathrm{ord}(\phi\vert_K) = [\mathcal O_K/\delta : \mathbb Z/q\mathbb Z].
```

 אגף שמאל שווה 1 אם ורק אם $`\phi`$ משאיר את $`K`$ במקומו, ואגף ימין שווה 1 אם ורק אם $`q`$ מתפצל לחלוטין ב-$`K`$ (ב[הרחבת גלואה](https://he.wikipedia.org/wiki/%D7%94%D7%A8%D7%97%D7%91%D7%AA_%D7%92%D7%9C%D7%95%D7%90%D7%94) כל דרגות האינרציה שוות), וסיימנו.

עכשיו, כיוון ששורשי היחידה מסדר $`p`$ שונים זה מזה מודולו $`\beta`$ (כלומר, הפולינום $`X^p - 1`$ [ספרבילי](https://he.wikipedia.org/wiki/%D7%A4%D7%95%D7%9C%D7%99%D7%A0%D7%95%D7%9D_%D7%A1%D7%A4%D7%A8%D7%91%D7%99%D7%9C%D7%99) במאפיין $`q`$), חייב להתקיים



```math
\phi(\zeta_p) = \zeta_p^q;
```

 כלומר, $`\phi`$ מתלכד עם האוטומורפיזם $`\sigma_q`$ שהוגדר קודם. כשלוקחים את $`K`$ להיות השדה הריבועי שמעניין אותנו, מקבלים את השקילות



```math
\left(\frac qp\right) =1 \quad \iff \quad q\text{ מתפצל לחלוטין ב-} \mathbb Q(\sqrt{p^*}).
```



### סיום ההוכחה

לבסוף צריך להראות ש-



```math
q\text{ מתפצל לחלוטין ב-} \mathbb Q(\sqrt{p^*}) \quad \iff \quad \left(\frac{p^*}q\right) = 1.
```

 אחרי שנעשה זאת, חוק ההדדיות הריבועית נובע מיד, כי



```math
\left(\frac{p^*}q\right) = \left(\frac pq\right)\quad \text{עבור } p\equiv 1 \pmod 4,
```

 ו-



```math
\left(\frac{p^*}q\right) = \left(\frac{-p}q\right) = \left(\frac{-1}q\right)\left(\frac pq\right) = \begin{cases} +\left(\frac pq \right) & q \equiv 1 \pmod{4}, \\ -\left(\frac pq\right) & q \equiv 3 \pmod{4}\end{cases}
```

 עבור $`p\equiv 3 \pmod 4`$.

כדי להראות את השקילות האחרונה, נניח קודם ש-$`\left(\frac{p^*}q\right) = 1`$. במקרה הזה יש שלם $`x`$ (שאינו מתחלק ב-$`q`$) כך ש-$`x^2 \equiv p^* \pmod{q}`$, נאמר $`x^2 - p^* = cq`$ עבור שלם $`c`$. נסמן $`K = \mathbb Q(\sqrt{p^*})`$, ונתבונן באידיאל $`(x-\sqrt{p^*},q)`$ של $`K`$. הוא בוודאי מחלק את האידיאל הראשי $`(q)`$. הוא אינו יכול להיות שווה ל-$`(q)`$, כי $`x-\sqrt{p^*}`$ אינו מתחלק ב-$`q`$. הוא אינו יכול להיות האידיאל כולו, כי אז



```math
(x+\sqrt{p^*}) = (x+\sqrt{p^*})(x-\sqrt{p^*},q) = (cq, q(x+\sqrt{p^*}))
```

 היה מתחלק ב-$`q`$, וזה שוב בלתי אפשרי. לכן $`(q)`$ חייב להתפצל ב-$`K`$.

להפך, נניח ש-$`(q)`$ מתפצל, ויהי $`\beta`$ ראשוני של $`K`$ מעל $`q`$. אז $`(q) \subsetneq \beta`$, ולכן אפשר לבחור



```math
a+b\sqrt{p^*} \in \beta\setminus(q),\quad a,b\in \mathbb Q.
```

 למעשה, כיוון ש-$`p^* \equiv 1 \pmod{4}`$, מהתורה האלמנטרית של [שדות ריבועיים](https://he.wikipedia.org/wiki/%D7%A9%D7%93%D7%94_%D7%A8%D7%99%D7%91%D7%95%D7%A2%D7%99) נובע שחוג השלמים של $`K`$ הוא בדיוק $`\mathbb Z\left[\frac{1+\sqrt{p^*} }2\right]`$, ולכן המכנים של $`a`$ ו-$`b`$ הם לכל היותר 2. כיוון ש-$`q \ne 2`$, אפשר לכפול בבטחה את $`a`$ ו-$`b`$ ב-2, ולהניח ש-$`a+b\sqrt{p^*} \in \beta\setminus(q)`$ כאשר עכשיו $`a`$ ו-$`b`$ שלמים. במקרה הזה



```math
(a+b\sqrt{p^*})(a-b\sqrt{p^*}) = a^2 - b^2p^* \in \beta \cap \mathbb Z = (q),
```

 כלומר $`q \mid a^2 - b^2p^*`$. אבל $`q`$ אינו יכול לחלק את $`b`$, כי אז $`q`$ מחלק גם את $`a`$, וזה סותר את בחירת $`a+b\sqrt{p^*}`$. לכן אפשר לחלק ב-$`b`$ מודולו $`q`$, ולקבל $`p^* \equiv (ab^{-1})^2 \pmod{q}`$, כנדרש.

*דוגמה:* עבור $`p = 7`$: $`p^* = -7`$, ו-$`K = \mathbb Q(\sqrt{-7})`$. עבור $`q = 11`$: $`-7 \equiv 4 = 2^2 \pmod{11}`$, ולכן 11 מתפצל ב-$`K`$ – ואכן $`11 = \left(2 + \sqrt{-7}\right)\left(2 - \sqrt{-7}\right)`$. לכן $`\left(\frac{11}7\right) = 1`$, כמו שראינו בדוגמה של אייזנשטיין.

כל ספר לימוד ב[תורת המספרים האלמנטרית](https://he.wikipedia.org/wiki/%D7%AA%D7%95%D7%A8%D7%AA_%D7%94%D7%9E%D7%A1%D7%A4%D7%A8%D7%99%D7%9D_%D7%94%D7%90%D7%9C%D7%9E%D7%A0%D7%98%D7%A8%D7%99%D7%AA) (ולא מעט ספרים ב[תורת המספרים האלגברית](https://he.wikipedia.org/wiki/%D7%AA%D7%95%D7%A8%D7%AA_%D7%94%D7%9E%D7%A1%D7%A4%D7%A8%D7%99%D7%9D_%D7%94%D7%90%D7%9C%D7%92%D7%91%D7%A8%D7%99%D7%AA)) כולל הוכחה של חוק ההדדיות הריבועית. שניים ראויים לציון מיוחד: ספרו של למרמאייר (2000) כולל הוכחות רבות (חלקן בתרגילים) של חוקי הדדיות ריבועיים ומחזקות גבוהות, ודיון בהיסטוריה שלהם; הביבליוגרפיה העצומה שלו כוללת הפניות ל-196 הוכחות שונות שפורסמו. גם בספרם של איירלנד ורוזן (1990) יש הוכחות רבות לחוק ההדדיות הריבועית (ותרגילים רבים), והוא עוסק גם במקרים הקוביים והריבועיים-ריבועיים. תרגיל 13.26 שם מבקש מהקורא לספור את ההוכחות לחוק שניתנו עד אותו שלב בספר – ולמצוא עוד אחת.
