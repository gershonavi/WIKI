# סכומים של שלוש קוביות

ב[מתמטיקה](https://he.wikipedia.org/wiki/%D7%9E%D7%AA%D7%9E%D7%98%D7%99%D7%A7%D7%94) של סכומי חזקות, [בעיה פתוחה](https://he.wikipedia.org/wiki/%D7%91%D7%A2%D7%99%D7%94_%D7%A4%D7%AA%D7%95%D7%97%D7%94) היא לאפיין את המספרים שאפשר לכתוב כסכום של שלוש קוביות של [מספרים שלמים](https://he.wikipedia.org/wiki/%D7%9E%D7%A1%D7%A4%D7%A8_%D7%A9%D7%9C%D7%9D), כשמותר להשתמש בקוביות חיוביות ושליליות. תנאי הכרחי לכך שמספר שלם $`n`$ יהיה סכום כזה הוא ש-$`n`$ אינו שקול ל-4 או ל-5 [מודולו](https://he.wikipedia.org/wiki/%D7%97%D7%A9%D7%91%D7%95%D7%9F_%D7%9E%D7%95%D7%93%D7%95%D7%9C%D7%A8%D7%99) 9: הקוביות מודולו 9 הן 0, 1 ו-$`-1`$ (כלומר 0, 1, 8), ושום שלושה מהמספרים האלה אינם מסתכמים ל-4 או ל-5 מודולו 9.[^1] לא ידוע אם התנאי ההכרחי הזה גם מספיק.

וריאציות של הבעיה כוללות סכומים של קוביות אי-שליליות וסכומים של קוביות רציונליות. כל מספר שלם הוא סכום של שלוש קוביות רציונליות, אבל לא ידוע אם לקבוצת הסכומים של שלוש קוביות אי-שליליות יש [צפיפות טבעית](https://he.wikipedia.org/wiki/%D7%A6%D7%A4%D7%99%D7%A4%D7%95%D7%AA_%D7%98%D7%91%D7%A2%D7%99%D7%AA) חיובית.

## מקרים קטנים

הצגה לא טריוויאלית של 0 כסכום של שלוש קוביות הייתה נותנת [דוגמה נגדית](https://he.wikipedia.org/wiki/%D7%93%D7%95%D7%92%D7%9E%D7%94_%D7%A0%D7%92%D7%93%D7%99%D7%AA) ל[המשפט האחרון של פרמה](https://he.wikipedia.org/wiki/%D7%94%D7%9E%D7%A9%D7%A4%D7%98_%D7%94%D7%90%D7%97%D7%A8%D7%95%D7%9F_%D7%A9%D7%9C_%D7%A4%D7%A8%D7%9E%D7%94) עבור המעריך 3, כי אחת משלוש הקוביות הייתה בעלת סימן הפוך לשתי האחרות, והנגדית שלה הייתה שווה לסכום השתיים האחרות. לכן, לפי ההוכחה של [לאונרד אוילר](https://he.wikipedia.org/wiki/%D7%9C%D7%90%D7%95%D7%A0%D7%A8%D7%93_%D7%90%D7%95%D7%99%D7%9C%D7%A8) למקרה הזה של המשפט האחרון של פרמה,[^2] יש רק את הפתרונות הטריוויאליים



```math
a^3 + (-a)^3 + 0^3 = 0.
```

 להצגות של 1 ו-2 יש משפחות אינסופיות של פתרונות:



```math
(9b^4)^3 + (3b - 9b^4)^3 + (1 - 9b^3)^3 = 1
```

 (שגילה קורט מאהלר ב-1936),[^3] ו-



```math
(1 + 6c^3)^3 + (1 - 6c^3)^3 + (-6c^2)^3 = 2
```

 (שגילה א. ס. ורברוסוב ב-1908, וציטט ל. ג'. מורדל).[^4] (בדקנו את שתי הזהויות בפיתוח סימבולי. למשל, עבור $`b = 1`$: $`9^3 + (-6)^3 + (-8)^3 = 729 - 216 - 512 = 1`$; ועבור $`c = 1`$: $`7^3 + (-5)^3 + (-6)^3 = 343 - 125 - 216 = 2`$.) אפשר לשנות את קנה המידה שלהן ולקבל הצגות לכל קובייה ולכל מספר שהוא פעמיים קובייה. ידועות גם הצגות אחרות של 2 שאינן מהמשפחות האינסופיות האלה:[^5]



```math
1\,214\,928^3 + 3\,480\,205^3 + (-3\,528\,875)^3 = 2,
```





```math
37\,404\,275\,617^3 + (-25\,282\,289\,375)^3 + (-33\,071\,554\,596)^3 = 2,
```





```math
3\,737\,830\,626\,090^3 + 1\,490\,220\,318\,001^3 + (-3\,815\,176\,160\,999)^3 = 2.
```

 אבל 1 ו-2 הם המספרים היחידים שאת ההצגות שלהם אפשר לפרמטר בעזרת פולינומים ממעלה רביעית כמו למעלה.[^6]

אפילו במקרה של הצגות של 3, לואיס מורדל כתב ב-1953 שאינו יודע דבר מלבד הפתרונות הקטנים



```math
1^3 + 1^3 + 1^3 = 4^3 + 4^3 + (-5)^3 = 3
```

 והעובדה שכל שלושת המספרים בחזקה השלישית חייבים להיות שקולים מודולו 9.[^7]

## תוצאות חישוביות

מאז 1955, בעקבות היוזמה של מורדל, מחברים רבים ביצעו חיפושים ממוחשבים אחר הצגות כאלה. אלסנהנס ויאנל (2009) השתמשו בשיטה של [נועם אלקיס](https://he.wikipedia.org/wiki/%D7%A0%D7%95%D7%A2%D7%9D_%D7%90%D7%9C%D7%A7%D7%99%D7%A1) (2000), שמבוססת על צמצום סריגים, כדי לחפש את כל הפתרונות של ה[משוואה הדיופנטית](https://he.wikipedia.org/wiki/%D7%9E%D7%A9%D7%95%D7%95%D7%90%D7%94_%D7%93%D7%99%D7%95%D7%A4%D7%A0%D7%98%D7%99%D7%AA)



```math
x^3 + y^3 + z^3 = n
```

 עבור $`n`$ חיובי עד 1000 ו-$`\max(|x|, |y|, |z|) \lt 10^{14}`$. אחרי החיפוש הזה נותרו פתוחים, נכון ל-2009, רק המקרים 33, 42, 74, 114, 165, 390, 579, 627, 633, 732, 795, 906, 921 ו-975 מבין $`n \le 1000`$.[^8] אחרי שטימותי בראונינג הציג את הבעיה ב-*Numberphile* ב-2016, הרחיב הויסמן את החיפושים ל-$`\max(|x|, |y|, |z|) \lt 10^{15}`$, ופתר את המקרה 74:



```math
74 = (-284\,650\,292\,555\,885)^3 + 66\,229\,832\,190\,556^3 + 283\,450\,105\,697\,727^3.
```

 ב-2019 פתר אנדרו בוקר את המקרה $`n = 33`$, כשמצא ש-



```math
33 = 8\,866\,128\,975\,287\,528^3 + (-8\,778\,405\,442\,862\,239)^3 + (-2\,736\,111\,468\,807\,040)^3.
```

 כדי להגיע לכך, בוקר השתמש באסטרטגיית חיפוש אחרת, שזמן הריצה שלה פרופורציונלי ל-$`\min(|x|, |y|, |z|)`$ ולא למקסימום – גישה שהציעו במקור הית'-בראון ושותפיו.[^9][^10] הרעיון: אם $`x^3 + y^3 + z^3 = n`$, אז $`x + y`$ מחלק את $`n - z^3`$, ולכן לכל $`z`$ מספיק לעבור על מחלקים $`d`$ של $`n - z^3`$ ולפתור משוואה ריבועית ב-$`x`$. בוקר מצא גם ש-



```math
795 = (-14\,219\,049\,725\,358\,227)^3 + 14\,197\,965\,759\,741\,571^3 + 2\,337\,348\,783\,323\,923^3,
```

 והראה שאין פתרונות עבור $`n = 42`$ ושאר המקרים הפתוחים עם $`n \le 1000`$ עם $`|z| \le 10^{16}`$. זמן קצר לאחר מכן, בספטמבר 2019, פתרו בוקר ואנדרו סאת'רלנד את המקרה $`n = 42`$, אחרי 1.3 מיליון שעות חישוב ברשת החישוב העולמית Charity Engine:



```math
42 = (-80\,538\,738\,812\,075\,974)^3 + 80\,435\,758\,145\,817\,515^3 + 12\,602\,123\,297\,335\,631^3,
```

 וגם מצאו פתרונות לכמה מקרים נוספים שלא היו ידועים, ביניהם $`n = 165`$ ו-$`579`$.[^11]

בוקר וסאת'רלנד מצאו גם הצגה שלישית של 3, בעוד 4 מיליון שעות מחשב:



```math
3 = 569\,936\,821\,221\,962\,380\,720^3 + (-569\,936\,821\,113\,563\,493\,509)^3 + (-472\,715\,493\,453\,327\,032)^3.
```

 [^12] הגילוי סגר שאלה בת 65 שנה של מורדל, שהניעה חלק גדול מהמחקר על הבעיה. (שלושת המספרים שקולים ל-1 מודולו 9, כפי שקאסלס הוכיח שחייב להיות.)

בוקר הציג גם הצגה של 906:



```math
906 = (-74\,924\,259\,395\,610\,397)^3 + 72\,054\,089\,679\,353\,378^3 + 35\,961\,979\,615\,356\,503^3.
```

 המקרים היחידים שנותרו פתוחים עד 1000 הם שבעת המספרים 114, 390, 627, 633, 732, 921 ו-975.

בנובמבר 2026 דווח על פתרון פרימיטיבי (כלומר עם $`\gcd(x, y, z) = 1`$) עבור $`n = 192`$, שמצא ג'פרי בנקס:



```math
192 = 2\,642\,071\,652\,785\,051^3 + (-2\,641\,770\,614\,653\,715)^3 + (-184\,725\,770\,857\,094)^3.
```

 (עבור 192 ידועות כמובן הצגות לא פרימיטיביות, כי $`192 = 3\cdot4^3`$ ו-$`3`$ הוא סכום של שלוש קוביות.)

כל הזהויות בסעיף הזה נבדקו בחשבון שלמים מדויק, וכן שה-$`\gcd`$ של שלושת המספרים בכל אחת מהן הוא 1.

## עניין ציבורי

בעיית סכומי שלוש הקוביות זכתה לפופולריות בשנים האחרונות בזכות בריידי הרן, יוצר ערוץ ה[יוטיוב](https://he.wikipedia.org/wiki/%D7%99%D7%95%D7%98%D7%99%D7%95%D7%91) *Numberphile*, החל מסרטון מ-2015 על "הבעיה הבלתי פתורה עם 33" בהשתתפות טימותי בראונינג. אחריו בא, חצי שנה מאוחר יותר, סרטון על פתרון 74. ב-2019 פרסם הערוץ שלושה סרטונים נוספים, על הפתרונות ל-33, ל-42 ולהצגה החדשה של 3. הפתרון של בוקר ל-33 הופיע בכתבות ב-*Quanta Magazine* וב-*New Scientist*. למספר 42 יש עניין ציבורי נוסף בגלל הופעתו ברומן המדע הבדיוני של [דאגלס אדמס](https://he.wikipedia.org/wiki/%D7%93%D7%90%D7%92%D7%9C%D7%A1_%D7%90%D7%93%D7%9E%D7%A1) מ-1979, *[מדריך הטרמפיסט לגלקסיה](https://he.wikipedia.org/wiki/%D7%9E%D7%93%D7%A8%D7%99%D7%9A_%D7%94%D7%98%D7%A8%D7%9E%D7%A4%D7%99%D7%A1%D7%98_%D7%9C%D7%92%D7%9C%D7%A7%D7%A1%D7%99%D7%94)*, כתשובה לשאלה האולטימטיבית על החיים, היקום וכל השאר. ההודעות של בוקר וסאת'רלנד על הפתרון ל-42 זכו לסיקור בינלאומי בעיתונות, ו-*Popular Mechanics* כלל אותו בין "10 פריצות הדרך הגדולות במתמטיקה של 2019".

## פתירות וכריעות

ב-1992 שיער רוג'ר הית'-בראון שלכל $`n`$ שאינו שקול ל-4 או 5 מודולו 9 יש אינסוף הצגות כסכום של שלוש קוביות.[^13] את המקרה $`n = 33`$ של הבעיה הזו השתמש ביורן פונן כדוגמה הפותחת בסקירה על בעיות בלתי כריעות ב[תורת המספרים](https://he.wikipedia.org/wiki/%D7%AA%D7%95%D7%A8%D7%AA_%D7%94%D7%9E%D7%A1%D7%A4%D7%A8%D7%99%D7%9D), ש[הבעיה העשירית של הילברט](https://he.wikipedia.org/wiki/%D7%94%D7%91%D7%A2%D7%99%D7%94_%D7%94%D7%A2%D7%A9%D7%99%D7%A8%D7%99%D7%AA_%D7%A9%D7%9C_%D7%94%D7%99%D7%9C%D7%91%D7%A8%D7%98) היא הדוגמה המפורסמת שבהן.[^14] אף שהמקרה הזה נפתר מאז, לא ידוע אם הבעיה של הצגת מספרים כסכומי קוביות כריעה – כלומר, לא ידוע אם יש אלגוריתם שיכול לבדוק בזמן סופי, לכל קלט, אם למספר נתון יש הצגה כזו. אם השערת הית'-בראון נכונה, הבעיה כריעה: אלגוריתם יכול לפתור אותה נכון על ידי חישוב $`n`$ מודולו 9, החזרת "לא" כשהתוצאה 4 או 5, ו"כן" אחרת. המחקר של הית'-בראון כולל גם השערות מדויקות יותר על המרחק שאלגוריתם יצטרך לחפש כדי למצוא הצגה מפורשת, ולא רק לקבוע שהיא קיימת.

## וריאציות

וריאציה של הבעיה, שקשורה להבעיה של וורינג, שואלת על הצגות כסכום של שלוש קוביות של שלמים אי-שליליים. במאה ה-19 [קרל גוסטב יעקב יעקובי](https://he.wikipedia.org/wiki/%D7%A7%D7%A8%D7%9C_%D7%92%D7%95%D7%A1%D7%98%D7%91_%D7%99%D7%A2%D7%A7%D7%91_%D7%99%D7%A2%D7%A7%D7%95%D7%91%D7%99) ושותפיו הכינו טבלאות של פתרונות לבעיה הזו. משערים שלמספרים הניתנים להצגה יש [צפיפות טבעית](https://he.wikipedia.org/wiki/%D7%A6%D7%A4%D7%99%D7%A4%D7%95%D7%AA_%D7%98%D7%91%D7%A2%D7%99%D7%AA) חיובית. זה עדיין לא ידוע, אבל טרבור וולי הראה של-$`\Omega(n^{0.917})`$ מהמספרים בין 1 ל-$`n`$ יש הצגות כאלה. הצפיפות היא לכל היותר $`\Gamma(4/3)^3/6 \approx 0.1187`$:[^15] מספר השלשות $`0 \le x \le y \le z`$ עם $`x^3 + y^3 + z^3 \le N`$ הוא בערך $`\frac16\cdot\left(\Gamma(4/3)^3N\right)`$ (נפח של "כדור" $`x^3 + y^3 + z^3 \le N`$ ברביע החיובי, חלקי $`3!`$), ולכן לכל היותר כך נמנים המספרים הניתנים להצגה.

כל מספר שלם אפשר להציג כסכום של שלוש קוביות של [מספרים רציונליים](https://he.wikipedia.org/wiki/%D7%9E%D7%A1%D7%A4%D7%A8_%D7%A8%D7%A6%D7%99%D7%95%D7%A0%D7%9C%D7%99) (ולא רק של שלמים).[^16]
