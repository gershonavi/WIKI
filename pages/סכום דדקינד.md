# סכום דדקינד

ב[מתמטיקה](https://he.wikipedia.org/wiki/%D7%9E%D7%AA%D7%9E%D7%98%D7%99%D7%A7%D7%94), **סכומי דדקינד** הם סכומים סופיים מסוימים של מכפלות של [פונקציית שן מסור](https://he.wikipedia.org/wiki/%D7%A4%D7%95%D7%A0%D7%A7%D7%A6%D7%99%D7%99%D7%AA_%D7%A9%D7%9F_%D7%9E%D7%A1%D7%95%D7%A8). [ריכרד דדקינד](https://he.wikipedia.org/wiki/%D7%A8%D7%99%D7%9B%D7%A8%D7%93_%D7%93%D7%93%D7%A7%D7%99%D7%A0%D7%93) הציג אותם בשנות ה-80 של המאה ה-19, כדי לבטא את [המשוואה הפונקציונלית](https://he.wikipedia.org/wiki/%D7%9E%D7%A9%D7%95%D7%95%D7%90%D7%94_%D7%A4%D7%95%D7%A0%D7%A7%D7%A6%D7%99%D7%95%D7%A0%D7%9C%D7%99%D7%AA) של [פונקציית אטא של דדקינד](%D7%A4%D7%95%D7%A0%D7%A7%D7%A6%D7%99%D7%99%D7%AA%20%D7%90%D7%98%D7%90%20%D7%A9%D7%9C%20%D7%93%D7%93%D7%A7%D7%99%D7%A0%D7%93.md), בהערות שכתב לכתבים המכונסים של [ברנהרד רימן](https://he.wikipedia.org/wiki/%D7%91%D7%A8%D7%A0%D7%94%D7%A8%D7%93_%D7%A8%D7%99%D7%9E%D7%9F).[^1] מאז נחקרו רבות ב[תורת המספרים](https://he.wikipedia.org/wiki/%D7%AA%D7%95%D7%A8%D7%AA_%D7%94%D7%9E%D7%A1%D7%A4%D7%A8%D7%99%D7%9D), אבל הם מופיעים גם בתוצאות ב[טופולוגיה](https://he.wikipedia.org/wiki/%D7%98%D7%95%D7%A4%D7%95%D7%9C%D7%95%D7%92%D7%99%D7%94),[^2] ב[קומבינטוריקה גאומטרית](https://he.wikipedia.org/wiki/%D7%A7%D7%95%D7%9E%D7%91%D7%99%D7%A0%D7%98%D7%95%D7%A8%D7%99%D7%A7%D7%94_%D7%92%D7%90%D7%95%D7%9E%D7%98%D7%A8%D7%99%D7%AA),[^3] ב[גאומטריה אלגברית](https://he.wikipedia.org/wiki/%D7%92%D7%90%D7%95%D7%9E%D7%98%D7%A8%D7%99%D7%94_%D7%90%D7%9C%D7%92%D7%91%D7%A8%D7%99%D7%AA)[^4] וב[סיבוכיות חישובית](https://he.wikipedia.org/wiki/%D7%A1%D7%99%D7%91%D7%95%D7%9B%D7%99%D7%95%D7%AA_%D7%97%D7%99%D7%A9%D7%95%D7%91%D7%99%D7%AA) (למשל בניתוח של מחוללי מספרים אקראיים לינאריים קונגרואנטיים).[^5] סכומי דדקינד הוכללו בכיוונים רבים ומקיימים מספר רב של משוואות פונקציונליות; כאן מובא רק חלק קטן מהן.

## הגדרה

מגדירים את [פונקציית שן המסור](https://he.wikipedia.org/wiki/%D7%A4%D7%95%D7%A0%D7%A7%D7%A6%D7%99%D7%99%D7%AA_%D7%A9%D7%9F_%D7%9E%D7%A1%D7%95%D7%A8) $`(\!(\,)\!) : \mathbb R \to \mathbb R`$ על ידי



```math
(\!(x)\!) = \begin{cases} x - \lfloor x\rfloor - 1/2, & x \in \mathbb R\setminus\mathbb Z; \\ 0, & x \in \mathbb Z.\end{cases}
```

 אז **סכום דדקינד** $`D: \mathbb Z^2 \times \mathbb Z_{\gt 0} \to \mathbb Q`$ מוגדר על ידי



```math
D(a, b; c) = \sum_{n=1}^{c-1}\left(\!\!\left(\frac{an}c\right)\!\!\right)\left(\!\!\left(\frac{bn}c\right)\!\!\right).
```

 במקרה $`a = 1`$ כותבים לעיתים קרובות



```math
s(b, c) = D(1, b; c).
```



**דוגמאות.**

- $`s(1, 5) = \sum_{n=1}^4\left(\frac n5 - \frac12\right)^2 = \frac{9 + 1 + 1 + 9}{100} = \frac15`$.
- $`s(2, 5)`$: המכפלות הן $`\left(-\tfrac3{10}\right)\left(-\tfrac1{10}\right) + \left(-\tfrac1{10}\right)\left(\tfrac3{10}\right) + \left(\tfrac1{10}\right)\left(-\tfrac3{10}\right) + \left(\tfrac3{10}\right)\left(\tfrac1{10}\right) = 0`$.
- $`s(1, 3) = \left(-\tfrac16\right)^2 + \left(\tfrac16\right)^2 = \tfrac1{18}`$, ו-$`s(3, 7) = -\tfrac1{14}`$.

## נוסחאות פשוטות

$`D`$ סימטרית ב-$`a`$ וב-$`b`$, כלומר



```math
D(a, b; c) = D(b, a; c),
```

 ובגלל שפונקציית שן המסור [אי-זוגית](https://he.wikipedia.org/wiki/%D7%A4%D7%95%D7%A0%D7%A7%D7%A6%D7%99%D7%94_%D7%90%D7%99-%D7%96%D7%95%D7%92%D7%99%D7%AA),



```math
D(-a, b; c) = -D(a, b; c).
```

 בגלל המחזוריות של $`D`$ בשני הארגומנטים הראשונים, כשהארגומנט השלישי הוא אורך המחזור של שניהם,



```math
D(a, b; c) = D(a + kc, b + lc; c)
```

 לכל $`k, l`$ שלמים. אם $`d`$ שלם חיובי, אז



```math
D(ad, bd; cd) = dD(a, b; c),
```





```math
D(ad, bd; c) = D(a, b; c)
```

 אם $`(d, c) = 1`$,



```math
D(ad, b; cd) = D(a, b; c)
```

 אם $`(d, b) = 1`$. בהוכחה של השוויון האחרון משתמשים בזהות



```math
\sum_{n=0}^{c-1}\left(\!\!\left(\frac{n + x}c\right)\!\!\right) = (\!(x)\!), \qquad \forall x \in \mathbb R.
```

 [^6] בנוסף, אם $`az \equiv 1 \pmod c`$, אז $`D(a, b; c) = D(1, bz; c)`$. (את כל הזהויות בסעיף הזה בדקנו בחישוב מדויק בשברים, עבור מאות ערכים אקראיים.)

## צורות חלופיות

אם $`b`$ ו-$`c`$ [זרים](https://he.wikipedia.org/wiki/%D7%9E%D7%A1%D7%A4%D7%A8%D7%99%D7%9D_%D7%96%D7%A8%D7%99%D7%9D), אפשר לכתוב את $`s(b, c)`$ כ-



```math
s(b, c) = \frac{-1}c\sum_\omega\frac1{(1 - \omega^b)(1 - \omega)} + \frac14 - \frac1{4c},
```

 כאשר הסכום הוא על [שורשי היחידה](https://he.wikipedia.org/wiki/%D7%A9%D7%95%D7%A8%D7%A9_%D7%99%D7%97%D7%99%D7%93%D7%94) מסדר $`c`$ פרט ל-1, כלומר על כל $`\omega`$ עם $`\omega^c = 1`$ ו-$`\omega \ne 1`$.[^7]

באופן שקול, אם $`b`$ ו-$`c`$ זרים, אז



```math
s(b, c) = \frac1{4c}\sum_{n=1}^{c-1}\cot\left(\frac{\pi n}c\right)\cot\left(\frac{\pi nb}c\right).
```

 הניסוח הזה משקף את העובדה שפונקציית הקוטנגנס הזו היא [התמרת פורייה הבדידה](https://he.wikipedia.org/wiki/%D7%94%D7%AA%D7%9E%D7%A8%D7%AA_%D7%A4%D7%95%D7%A8%D7%99%D7%99%D7%94_%D7%91%D7%93%D7%99%D7%93%D7%94) של פונקציית שן המסור.[^8]

## חוק ההדדיות

דדקינד הוכיח[^9] שאם $`b`$ ו-$`c`$ שלמים חיוביים זרים, אז



```math
s(b, c) + s(c, b) = \frac1{12}\left(\frac bc + \frac1{bc} + \frac cb\right) - \frac14.
```

 יש כמה הוכחות מעקרונות ראשונים, ואפשר להשתמש בחוק ההדדיות של דדקינד כדי להוכיח את [חוק ההדדיות הריבועית](https://he.wikipedia.org/wiki/%D7%97%D7%95%D7%A7_%D7%94%D7%94%D7%93%D7%93%D7%99%D7%95%D7%AA_%D7%94%D7%A8%D7%99%D7%91%D7%95%D7%A2%D7%99%D7%AA).[^10]

**דוגמה.** עבור $`b = 3`$, $`c = 7`$: $`s(7, 3) = s(1, 3) = \tfrac1{18}`$ (מחזוריות), ולכן אגף שמאל הוא $`-\tfrac1{14} + \tfrac1{18} = -\tfrac1{63}`$, ואגף ימין הוא $`\tfrac1{12}\left(\tfrac37 + \tfrac1{21} + \tfrac73\right) - \tfrac14 = \tfrac{59}{252} - \tfrac{63}{252} = -\tfrac1{63}`$.

חוק ההדדיות מאפשר לחשב סכומי דדקינד מהר, באלגוריתם דמוי [אוקלידס](https://he.wikipedia.org/wiki/%D7%94%D7%90%D7%9C%D7%92%D7%95%D7%A8%D7%99%D7%AA%D7%9D_%D7%A9%D7%9C_%D7%90%D7%95%D7%A7%D7%9C%D7%99%D7%93%D7%A1): כל צעד מחליף את $`s(b, c)`$ ב-$`s(c \bmod b, b)`$. למשל:



```math
s(5, 12) = \frac1{12}\left(\frac5{12} + \frac1{60} + \frac{12}5\right) - \frac14 - s(12, 5) = \frac{17}{72} - \frac{18}{72} - s(2, 5) = -\frac1{72} - 0 = -\frac1{72}.
```



אם כותבים את חוק ההדדיות כ-



```math
12bc\bigl(s(b, c) + s(c, b)\bigr) = b^2 + c^2 - 3bc + 1,
```

 נובע שהמספר $`6c\,s(b, c)`$ שלם (עבור $`b, c`$ זרים).

אם $`k = (3, c)`$, אז



```math
12bc\,s(c, b) \equiv 0 \pmod{kc}
```

 ו-



```math
12bc\,s(b, c) \equiv b^2 + 1 \pmod{kc}.
```



קשר בולט בתורת [פונקציית אטא של דדקינד](%D7%A4%D7%95%D7%A0%D7%A7%D7%A6%D7%99%D7%99%D7%AA%20%D7%90%D7%98%D7%90%20%D7%A9%D7%9C%20%D7%93%D7%93%D7%A7%D7%99%D7%A0%D7%93.md) הוא הבא. יהי $`q = 3, 5, 7`$ או $`13`$, ו-$`n = 24/(q - 1)`$. בהינתן שלמים $`a, b, c, d`$ עם $`ad - bc = 1`$ (כלומר, איבר של [החבורה המודולרית](https://he.wikipedia.org/wiki/%D7%94%D7%97%D7%91%D7%95%D7%A8%D7%94_%D7%94%D7%9E%D7%95%D7%93%D7%95%D7%9C%D7%A8%D7%99%D7%AA)), כאשר $`c = kq`$ עבור שלם $`k \gt 0`$ כלשהו, נגדיר



```math
\delta = s(a, c) - \frac{a + d}{12c} - s(a, k) + \frac{a + d}{12k}.
```

 אז $`n\delta`$ הוא מספר שלם [זוגי](https://he.wikipedia.org/wiki/%D7%96%D7%95%D7%92%D7%99%D7%95%D7%AA_%28%D7%9E%D7%AA%D7%9E%D7%98%D7%99%D7%A7%D7%94%29). (בדקנו את הטענה הזו, ואת שתי הקונגרואנציות שלמעלה, בחישוב מדויק עבור מאות מקרים.) זה המקור לכך ש-$`\left(\eta(\tau)/\eta(q\tau)\right)^n`$ היא פונקציה מודולרית על $`\Gamma_0(q)`$.

## ההכללה של רדמכר לחוק ההדדיות

הנס רדמכר מצא את ההכללה הבאה לחוק ההדדיות של סכומי דדקינד:[^11] אם $`a, b, c`$ שלמים חיוביים זרים בזוגות, אז



```math
D(a, b; c) + D(b, c; a) + D(c, a; b) = \frac1{12}\,\frac{a^2 + b^2 + c^2}{abc} - \frac14.
```

 (עבור $`a = 1`$ זה בדיוק חוק ההדדיות של דדקינד, כי $`D(b, c; 1) = 0`$.) מכאן, הסכום המשולש שלמעלה מתאפס [אם ורק אם](https://he.wikipedia.org/wiki/%D7%90%D7%9D_%D7%95%D7%A8%D7%A7_%D7%90%D7%9D) $`(a, b, c)`$ הוא **שלשת מרקוב**, כלומר פתרון של [משוואת מרקוב](https://he.wikipedia.org/wiki/%D7%9E%D7%A9%D7%95%D7%95%D7%90%D7%AA_%D7%9E%D7%A8%D7%A7%D7%95%D7%91)



```math
a^2 + b^2 + c^2 = 3abc.
```

 השלשות הראשונות הן $`(1, 1, 1), (1, 1, 2), (1, 2, 5), (1, 5, 13), (2, 5, 29), (1, 13, 34), \dots`$; למשל, עבור $`(1, 2, 5)`$ מתקבל $`s(2, 5) + D(5, 1; 2) + D(1, 2; 5) = 0 + 0 + 0 = 0`$.
