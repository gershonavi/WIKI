# פונקציית זטא מרובה

ב[מתמטיקה](https://he.wikipedia.org/wiki/%D7%9E%D7%AA%D7%9E%D7%98%D7%99%D7%A7%D7%94), **פונקציות זטא מרובות** (ב[אנגלית](https://he.wikipedia.org/wiki/%D7%90%D7%A0%D7%92%D7%9C%D7%99%D7%AA): multiple zeta functions) הן הכללות של [פונקציית זטא של רימן](https://he.wikipedia.org/wiki/%D7%A4%D7%95%D7%A0%D7%A7%D7%A6%D7%99%D7%99%D7%AA_%D7%96%D7%98%D7%90_%D7%A9%D7%9C_%D7%A8%D7%99%D7%9E%D7%9F), המוגדרות על ידי



```math
\zeta(s_1,\ldots,s_k) = \sum_{n_1 > n_2 > \cdots > n_k > 0}\ \frac{1}{n_1^{s_1} \cdots n_k^{s_k} } = \sum_{n_1 > n_2 > \cdots > n_k > 0}\ \prod_{i=1}^k \frac{1}{n_i^{s_i} },
```

 ו[מתכנסות](https://he.wikipedia.org/wiki/%D7%98%D7%95%D7%A8_%D7%9E%D7%AA%D7%9B%D7%A0%D7%A1) כאשר $`\mathrm{Re}(s_1) + \cdots + \mathrm{Re}(s_i) > i`$ לכל $`i`$. כמו פונקציית זטא של רימן, אפשר להמשיך את פונקציות הזטא המרובות [אנליטית](https://he.wikipedia.org/wiki/%D7%94%D7%9E%D7%A9%D7%9B%D7%94_%D7%90%D7%A0%D7%9C%D7%99%D7%98%D7%99%D7%AA) ל[פונקציות מרומורפיות](https://he.wikipedia.org/wiki/%D7%A4%D7%95%D7%A0%D7%A7%D7%A6%D7%99%D7%94_%D7%9E%D7%A8%D7%95%D7%9E%D7%95%D7%A8%D7%A4%D7%99%D7%AA) (ראו למשל Zhao, 1999). כאשר $`s_1, \ldots, s_k`$ כולם [שלמים](https://he.wikipedia.org/wiki/%D7%9E%D7%A1%D7%A4%D7%A8_%D7%A9%D7%9C%D7%9D) חיוביים (עם $`s_1 > 1`$), הסכומים האלה נקראים לעתים קרובות **ערכי זטא מרובים** (MZV) או **סכומי אוילר**. אפשר לראות בערכים האלה גם ערכים מיוחדים של הפולילוגריתמים המרובים.[^1][^2]

המספר $`k`$ בהגדרה שלמעלה נקרא ה"עומק" של ערך הזטא המרובה, והמספר $`n = s_1 + \cdots + s_k`$ ידוע כ"משקל".[^3]

הקיצור המקובל לכתיבת פונקציות זטא מרובות הוא לשים מחרוזות חוזרות של ארגומנטים בתוך סוגריים מסולסלים, ולציין במעריך את מספר החזרות. למשל,



```math
\zeta(2,1,2,1,3) = \zeta(\{2,1\}^2,3).
```



**הערה על הסימון (נוסף בתרגום):** כאן האינדקס הראשון מתאים לסכום על המספר ה*גדול* ביותר. יש מחברים שמשתמשים בסדר ההפוך. התנאי $`s_1 > 1`$ נדרש להתכנסות, כי הסכום על $`n_1`$ הוא החיצוני.

## הגדרה

פונקציות זטא מרובות מופיעות כמקרים פרטיים של הפולילוגריתמים המרובים



```math
\mathrm{Li}_{s_1,\ldots,s_d}(\mu_1,\ldots,\mu_d) = \sum\limits_{k_1>\cdots>k_d>0}\frac{\mu_1^{k_1}\cdots\mu_d^{k_d} }{k_1^{s_1}\cdots k_d^{s_d} },
```

 שהם הכללות של פונקציות ה[פולילוגריתם](https://he.wikipedia.org/wiki/%D7%A4%D7%95%D7%9C%D7%99%D7%9C%D7%95%D7%92%D7%A8%D7%99%D7%AA%D7%9D). כאשר כל ה-$`\mu_i`$ הם [שורשי יחידה](https://he.wikipedia.org/wiki/%D7%A9%D7%95%D7%A8%D7%A9_%D7%99%D7%97%D7%99%D7%93%D7%94) מסדר $`n`$ וכל ה-$`s_i`$ שלמים אי-שליליים, הערכים של הפולילוגריתם המרובה נקראים **ערכי זטא מרובים צבועים מרמה** $`n`$. בפרט, כאשר $`n=2`$ הם נקראים **סכומי אוילר** או **ערכי זטא מרובים מתחלפים**, וכאשר $`n=1`$ הם נקראים פשוט **ערכי זטא מרובים**. ערכי זטא מרובים נכתבים לעתים קרובות



```math
\zeta(s_1,\ldots,s_d) = \sum\limits_{k_1 > \cdots > k_d > 0} \frac{1}{k_1^{s_1}\cdots k_d^{s_d} },
```

 וסכומי אוילר נכתבים



```math
\zeta(s_1,\ldots,s_d;\varepsilon_1,\ldots,\varepsilon_d) = \sum\limits_{k_1 > \cdots > k_d > 0} \frac{\varepsilon_1^{k_1}\cdots \varepsilon_d^{k_d} }{k_1^{s_1}\cdots k_d^{s_d} },
```

 כאשר $`\varepsilon_i = \pm 1`$. לפעמים מחברים כותבים קו מעל $`s_i`$ המתאים ל-$`\varepsilon_i = -1`$, כך שלמשל



```math
\zeta(\overline{a},b) = \zeta(a,b;-1,1).
```



## מבנה אינטגרלי וזהויות

קונצביץ' הבחין שאפשר לבטא ערכי זטא מרובים צבועים (ולכן גם את המקרים הפרטיים שלהם) כ[אינטגרלים](https://he.wikipedia.org/wiki/%D7%90%D7%99%D7%A0%D7%98%D7%92%D7%A8%D7%9C) רב-משתניים מסוימים. התוצאה מנוסחת לעתים קרובות בעזרת מוסכמה לאינטגרלים איטרטיביים:



```math
\int_0^x f_1(t) dt \cdots f_d(t) dt = \int_0^x f_1(t_1)\left(\int_0^{t_1}f_2(t_2)\left(\int_0^{t_2} \cdots \left( \int_0^{t_{d-1} } f_d(t_d) dt_d\right)\right)dt_2\right)dt_1.
```

 בעזרת המוסכמה הזו אפשר לנסח את התוצאה כך:[^4]



```math
\mathrm{Li}_{s_1,\ldots,s_d}(\mu_1,\ldots,\mu_d) = \int_0^1 \left(\frac{dt}{t}\right)^{s_1-1}\frac{dt}{a_1-t}\cdots \left(\frac{dt}{t}\right)^{s_d-1} \frac{dt}{a_d-t},
```

 כאשר $`a_j = \prod\limits_{i=1}^j \mu_i^{-1}`$ עבור $`j = 1,2,\ldots,d`$.

(**דוגמה, נוסף בתרגום:** $`\zeta(2) = \int_0^1\frac{dt_1}{t_1}\int_0^{t_1}\frac{dt_2}{1-t_2}`$: האינטגרל הפנימי הוא $`-\log(1-t_1) = \sum_n t_1^n/n`$, ואחרי החלוקה ב-$`t_1`$ והאינטגרציה מתקבל $`\sum_n 1/n^2`$.)

התוצאה הזו שימושית מאוד בזכות תוצאה ידועה על מכפלות של אינטגרלים איטרטיביים:



```math
\left(\int_0^x f_1(t)dt \cdots f_n(t) dt \right)\!\left(\int_0^x f_{n+1}(t)dt\cdots f_m(t) dt \right) =
\sum\limits_{\sigma \in \mathfrak{Sh}_{n,m} }\int_0^x f_{\sigma(1)}(t)\cdots f_{\sigma(m)}(t),
```

 כאשר $`\mathfrak{Sh}_{n,m}=\{\sigma \in S_m \mid \sigma(1)\lt\cdots\lt\sigma(n),\ \sigma(n+1)\lt\cdots\lt\sigma(m)\}`$ ו-$`S_m`$ היא [החבורה הסימטרית](https://he.wikipedia.org/wiki/%D7%94%D7%97%D7%91%D7%95%D7%A8%D7%94_%D7%94%D7%A1%D7%99%D7%9E%D7%98%D7%A8%D7%99%D7%AA) על $`m`$ סמלים.

כדי להשתמש בזה בהקשר של ערכי זטא מרובים, מגדירים $`X = \{a,b\}`$, את $`X^*`$ כ[מונואיד](https://he.wikipedia.org/wiki/%D7%9E%D7%95%D7%A0%D7%95%D7%90%D7%99%D7%93_%28%D7%9E%D7%91%D7%A0%D7%94_%D7%90%D7%9C%D7%92%D7%91%D7%A8%D7%99%29) החופשי שנוצר על ידי $`X`$, ואת $`\mathfrak{A}`$ כ[מרחב וקטורי](https://he.wikipedia.org/wiki/%D7%9E%D7%A8%D7%97%D7%91_%D7%95%D7%A7%D7%98%D7%95%D7%A8%D7%99) החופשי מעל $`\mathbb{Q}`$ שנוצר על ידי $`X^*`$. אפשר לצייד את $`\mathfrak{A}`$ במכפלת הערבוב (shuffle), ולהפוך אותו לאלגברה. אז אפשר לראות בפונקציית הזטא המרובה העתקת הצבה, שבה מזהים $`a = \frac{dt}{t}`$, $`b = \frac{dt}{1-t}`$, ומגדירים



```math
\zeta(\mathbf{w}) = \int_0^1 \mathbf{w}
```

 לכל $`\mathbf{w} \in X^*`$, מה שלפי הזהות האינטגרלית שלמעלה נותן



```math
\zeta(a^{s_1-1}b\cdots a^{s_d-1}b) = \zeta(s_1,\ldots,s_d).
```

 אז זהות המכפלה של האינטגרלים נותנת[^5]



```math
\zeta(w)\zeta(v) = \zeta(w \,ш\, v).
```

 (**דוגמה:** $`\zeta(2) = \zeta(ab)`$, ולכן $`\zeta(2)^2 = \zeta(ab \,ш\, ab) = \zeta(2abab + 4aabb) = 2\zeta(2,2) + 4\zeta(3,1)`$. עם $`\zeta(2,2) = \tfrac34\zeta(4)`$ ו-$`\zeta(3,1) = \tfrac14\zeta(4)`$ מתקבל $`\zeta(2)^2 = \tfrac32\zeta(4) + \zeta(4) = \tfrac52\zeta(4)`$, כלומר $`\pi^4/36 = \tfrac52\cdot\pi^4/90`$, נכון.)

## המקרה של שני פרמטרים

במקרה הפרטי של שני פרמטרים בלבד יש לנו (עם $`s > 1`$ ו-$`n, m`$ שלמים):[^6]



```math
\zeta(s,t) = \sum_{n > m \geq 1} \ \frac{1}{n^{s} m^{t} } = \sum_{n=2}^{\infty} \frac{1}{n^{s} } \sum_{m=1}^{n-1} \frac{1}{m^t} = \sum_{n=1}^{\infty} \frac{1}{(n+1)^{s} } \sum_{m=1}^{n} \frac{1}{m^t},
```





```math
\zeta(s,t) = \sum_{n=1}^\infty \frac{H_{n,t} }{(n+1)^s},
```

 כאשר $`H_{n,t}`$ הם [המספרים ההרמוניים המוכללים](https://he.wikipedia.org/wiki/%D7%94%D7%A1%D7%93%D7%A8%D7%94_%D7%94%D7%94%D7%A8%D7%9E%D7%95%D7%A0%D7%99%D7%AA).

פונקציות זטא מרובות מקיימות את מה שנקרא דואליות MZV, שהמקרה הפשוט ביותר שלה הוא הזהות המפורסמת של [אוילר](https://he.wikipedia.org/wiki/%D7%9C%D7%90%D7%95%D7%A0%D7%A8%D7%93_%D7%90%D7%95%D7%99%D7%9C%D7%A8):



```math
\sum_{n=1}^\infty \frac{H_n}{(n+1)^2} = \zeta(2,1) = \zeta(3) = \sum_{n=1}^\infty \frac{1}{n^3},
```

 כאשר $`H_n`$ הם המספרים ההרמוניים.

ערכים מיוחדים של פונקציות זטא כפולות, עם $`s > 0`$ [זוגי](https://he.wikipedia.org/wiki/%D7%96%D7%95%D7%92%D7%99%D7%95%D7%AA_%28%D7%9E%D7%AA%D7%9E%D7%98%D7%99%D7%A7%D7%94%29), $`t > 1`$ אי-זוגי, ו-$`s+t = 2N+1`$ (כאשר, אם צריך, לוקחים $`\zeta(0) = 0`$):[^7]



```math
\zeta(s,t) = \zeta(s)\zeta(t) + \tfrac{1}{2}\Big[\tbinom{s+t}{s}-1\Big]\zeta(s+t) - \sum_{r=1}^{N-1}\Big[\tbinom{2r}{s-1}+\tbinom{2r}{t-1}\Big]\zeta(2r+1)\zeta(s+t-1-2r).
```

 (הנוסחה נבדקה מספרית עבור $`(s,t) = (2,3), (4,3), (2,5), (4,5), (6,3)`$.)

## המקרה של שלושה פרמטרים

במקרה הפרטי של שלושה פרמטרים בלבד יש לנו (עם $`a > 1`$ ו-$`n, j, i`$ שלמים):



```math
\zeta(a,b,c) = \sum_{n > j > i \geq 1}\ \frac{1}{n^{a} j^{b} i^{c} } = \sum_{n=1}^{\infty} \frac{1}{(n+2)^{a} } \sum_{j=1}^n \frac{1}{(j+1)^b} \sum_{i=1}^{j} \frac{1}{i^c} = \sum_{n=1}^{\infty} \frac{1}{(n+2)^{a} } \sum_{j=1}^n \frac{H_{j,c} }{(j+1)^b}.
```



## נוסחת ההשתקפות של אוילר

ערכי הזטא המרובים שלמעלה מקיימים את נוסחת ההשתקפות של אוילר:



```math
\zeta(a,b)+\zeta(b,a)=\zeta(a)\zeta(b)-\zeta(a+b)
```

 עבור $`a,b>1.`$ (**הוכחה, נוסף בתרגום:** המכפלה $`\zeta(a)\zeta(b) = \sum_{n,m}n^{-a}m^{-b}`$ מתפרקת לשלושה חלקים: $`n > m`$ (נותן $`\zeta(a,b)`$), $`n \lt m`$ (נותן $`\zeta(b,a)`$), ו-$`n = m`$ (נותן $`\zeta(a+b)`$). זו **מכפלת ה-stuffle**, בניגוד למכפלת הערבוב שלמעלה.)

בעזרת יחסי הערבוב קל להוכיח ש:[^9]



```math
\zeta(a,b,c)+\zeta(a,c,b)+\zeta(b,a,c)+\zeta(b,c,a)+\zeta(c,a,b)+\zeta(c,b,a)=\zeta(a)\zeta(b)\zeta(c)+2\zeta(a+b+c)-\zeta(a)\zeta(b+c)-\zeta(b)\zeta(a+c)-\zeta(c)\zeta(a+b)
```

 עבור $`a,b,c>1.`$ אפשר לראות בזה הכללה של נוסחאות ההשתקפות.

## סכומים סימטריים במונחי פונקציית זטא

נגדיר $`S(i_1,i_2,\ldots,i_k) = \sum_{n_1 \geq n_2 \geq\cdots \geq n_k \geq 1}\frac{1}{n_1^{i_1} n_2^{i_2}\cdots n_k^{i_k} }`$, ועבור חלוקה $`\Pi=\{P_1, P_2, \dots,P_l\}`$ של הקבוצה $`\{1,2,\dots,k\}`$ נגדיר $`c(\Pi) = (\left|P_1\right|-1)!(\left|P_2\right|-1)!\cdots(\left|P_l\right|-1)!`$. בנוסף, בהינתן $`\Pi`$ כזו ו-$`k`$-יה $`i=\{i_1,\ldots,i_k\}`$ של מעריכים, נגדיר $`\zeta(i,\Pi) = \prod_{s=1}^l \zeta\big(\sum_{j \in P_s} i_j\big)`$.

היחסים בין $`\zeta`$ ל-$`S`$ הם:



```math
S(i_1,i_2)=\zeta(i_1,i_2)+\zeta(i_1+i_2)
```

 ו-$`S(i_1,i_2,i_3)=\zeta(i_1,i_2,i_3)+\zeta(i_1+i_2,i_3)+\zeta(i_1,i_2+i_3)+\zeta(i_1+i_2+i_3).`$

### משפט 1 (הופמן)

לכל $`i_1,\ldots,i_k >1`$ [ממשיים](https://he.wikipedia.org/wiki/%D7%9E%D7%A1%D7%A4%D7%A8_%D7%9E%D7%9E%D7%A9%D7%99):



```math
\sum_{\sigma \in \Sigma_k}S(i_{\sigma(1)}, \dots, i_{\sigma(k)}) = \sum_{\Pi \vdash \{1,\dots,k\} }c(\Pi)\zeta(i,\Pi),
```

 כאשר $`\Pi \vdash \{1,\dots,k\}`$ פירושו ש-$`\Pi`$ עובר על החלוקות של הקבוצה $`\{1,\dots,k\}`$.

**הוכחה.** נניח שכל ה-$`i_j`$ שונים (אין בכך הגבלת כלליות, כי אפשר לעבור לגבולות). את אגף שמאל אפשר לכתוב כ $`\sum_{\sigma}\sum_{n_1\geq n_2 \geq \cdots \geq n_k \geq1} \frac{1}{n_{\sigma(1)}^{i_1}n_{\sigma(2)}^{i_2} \cdots n_{\sigma(k)}^{i_k} }`$. עכשיו חושבים על החבורה הסימטרית $`\Sigma_k`$ כפועלת על $`k`$-יות $`n = (n_1,\ldots,n_k)`$ של שלמים חיוביים. ל-$`k`$-יה נתונה $`n`$ יש חבורת מייצב $`\Sigma_k(n)`$ וחלוקה מתאימה $`\Lambda`$ של $`\{1,2,\ldots,k\}`$: $`\Lambda`$ היא קבוצת [מחלקות השקילות](https://he.wikipedia.org/wiki/%D7%9E%D7%97%D7%9C%D7%A7%D7%AA_%D7%A9%D7%A7%D7%99%D7%9C%D7%95%D7%AA) של היחס $`i \sim j \iff n_i=n_j`$, ו-$`\Sigma_k(n) = \{\sigma \in \Sigma_k : \sigma(i) \sim i\ \forall i\}`$. האיבר $`\frac{1}{n_{1}^{i_1}\cdots n_{k}^{i_k} }`$ מופיע באגף שמאל בדיוק $`\left| \Sigma_k(n) \right|`$ פעמים. באגף ימין הוא מופיע באיברים המתאימים לחלוקות $`\Pi`$ שהן עידונים של $`\Lambda`$: אם מסמנים עידון ב-$`\succeq`$, הוא מופיע $`\sum_{\Pi\succeq\Lambda}c(\Pi)`$ פעמים. לכן המסקנה תנבע אם $`\left| \Sigma_k(n) \right| =\sum_{\Pi\succeq\Lambda}c(\Pi)`$ לכל $`k`$-יה $`n`$ וחלוקה מתאימה $`\Lambda`$. כדי לראות זאת, שימו לב ש-$`c(\Pi)`$ סופר את התמורות שהמבנה המחזורים שלהן נתון על ידי $`\Pi`$: מכיוון שלכל איבר של $`\Sigma_k(n)`$ יש מבנה מחזורים יחיד הנתון על ידי חלוקה שמעדנת את $`\Lambda`$, התוצאה נובעת.[^10]

עבור $`k=3`$ המשפט אומר



```math
\sum_{\sigma \in \Sigma_3}S(i_{\sigma(1)},i_{\sigma(2)},i_{\sigma(3)}) = \zeta(i_1)\zeta(i_2)\zeta(i_3)+\zeta(i_1+i_2)\zeta(i_3)+\zeta(i_1)\zeta(i_2+i_3)+\zeta(i_1+i_3)\zeta(i_2)+2\zeta(i_1+i_2+i_3)
```

 עבור $`i_1,i_2,i_3>1`$. זו התוצאה העיקרית של רמצ'נדרה ראו וסוברמה.[^11]

כאמור, $`\zeta(i_1,i_2,\ldots,i_k)=\sum_{n_1> n_2>\cdots >n_k\geq1}\frac{1}{n_1^{i_1} n_2^{i_2}\cdots n_k^{i_k} }`$. כדי לנסח את האנלוג של משפט 1 עבור $`\zeta`$, נדרש עוד סימון אחד. עבור חלוקה $`\Pi = \{P_1,\ldots,P_l\}`$ של $`\{1,2,\ldots,k\}`$ נגדיר $`\tilde{c}(\Pi)=(-1)^{k-l}c(\Pi)`$.

### משפט 2 (הופמן)

לכל $`i_1,\ldots,i_k>1`$ ממשיים:



```math
\sum_{\sigma \in \Sigma_k}\zeta(i_{\sigma(1)}, \dots, i_{\sigma(k)})=\sum_{\Pi \vdash \{1,\dots,k\} }\tilde{c}(\Pi)\zeta(i,\Pi).
```

 **הוכחה.** ממשיכים באותו קו טיעון כמו בהוכחה הקודמת. אגף שמאל הוא עכשיו $`\sum_{\sigma}\sum_{n_1 > n_2 > \cdots > n_k \geq1} \frac{1}{n_{\sigma(1)}^{i_1}n_{\sigma(2)}^{i_2} \cdots n_{\sigma(k)}^{i_k} }`$, והאיבר $`\frac{1}{n^{i_1}_{1}n^{i_2}_{2} \cdots n^{i_k}_{k} }`$ מופיע באגף שמאל פעם אחת אם כל ה-$`n_i`$ שונים, ולא מופיע כלל אחרת. לכן מספיק להראות ש



```math
\sum_{\Pi\succeq\Lambda}\tilde{c}(\Pi)=\begin{cases} 1, & \left| \Lambda \right|=k, \\ 0, & \left| \Lambda \right| \ne k. \end{cases} \qquad (1)
```

 כדי להוכיח זאת, שימו לב קודם שהסימן של $`\tilde{c}(\Pi)`$ חיובי אם התמורות ממבנה מחזורים $`\Pi`$ [זוגיות](https://he.wikipedia.org/wiki/%D7%A1%D7%99%D7%9E%D7%9F_%D7%A9%D7%9C_%D7%AA%D7%9E%D7%95%D7%A8%D7%94), ושלילי אם הן אי-זוגיות: לכן אגף שמאל של (1) הוא ההפרש בין מספר התמורות הזוגיות למספר התמורות האי-זוגיות בחבורת המייצב $`\Sigma_k(n)`$. אבל בחבורת מייצב כזו יש מספר שווה של תמורות זוגיות ואי-זוגיות, אלא אם כן היא טריוויאלית, כלומר אלא אם כן החלוקה המתאימה $`\Lambda`$ היא $`\{\{1\},\{2\},\ldots,\{k\}\}`$.[^12]

(עבור $`k = 2`$, משפט 2 הוא בדיוק נוסחת ההשתקפות של אוילר, ועבור $`k = 3`$ הוא הזהות על שש התמורות שלמעלה.)

## השערות הסכום והדואליות

המקור לפרק זה הוא הופמן.[^13]

נתחיל בהשערת הסכום, שהיא של ק. מואן.[^14]

**השערת הסכום (הופמן).** לשלמים חיוביים $`k`$ ו-$`n`$, $`\sum_{i_1+\cdots+i_k=n,\ i_1>1}\zeta(i_1,\ldots,i_k) = \zeta(n)`$, כאשר הסכום הוא על $`k`$-יות $`i_1,\ldots,i_k`$ של שלמים חיוביים עם $`i_1>1`$.

שלוש הערות על ה[השערה](https://he.wikipedia.org/wiki/%D7%94%D7%A9%D7%A2%D7%A8%D7%94_%28%D7%9E%D7%AA%D7%9E%D7%98%D7%99%D7%A7%D7%94%29) הזו. ראשית, היא גוררת ש-$`\sum_{i_1+\cdots+i_k=n,\ i_1>1}S(i_1,\ldots,i_k)={n-1\choose k-1}\zeta(n)`$. שנית, במקרה $`k=2`$ היא אומרת ש-$`\zeta(n-1,1)+\zeta(n-2,2)+\cdots+\zeta(2,n-2)=\zeta(n)`$, או, בעזרת היחס בין $`\zeta`$ ל-$`S`$ ומשפט 1, $`2S(n-1,1)=(n+1)\zeta(n)-\sum_{k=2}^{n-2}\zeta(k)\zeta(n-k).`$ את זה הוכיח אוילר,[^15] והוא התגלה מחדש כמה פעמים, בפרט בידי ויליאמס.[^16] לבסוף, ק. מואן[^17] הוכיח את אותה השערה עבור $`k=3`$ בטיעונים ארוכים אבל אלמנטריים.

עבור השערת הדואליות, נגדיר קודם [אינוולוציה](https://he.wikipedia.org/wiki/%D7%90%D7%99%D7%A0%D7%95%D7%95%D7%9C%D7%95%D7%A6%D7%99%D7%94_%28%D7%9E%D7%AA%D7%9E%D7%98%D7%99%D7%A7%D7%94%29) $`\tau`$ על הקבוצה $`\Im`$ של [סדרות](https://he.wikipedia.org/wiki/%D7%A1%D7%93%D7%A8%D7%94_%28%D7%9E%D7%AA%D7%9E%D7%98%D7%99%D7%A7%D7%94%29) סופיות של שלמים חיוביים שהאיבר הראשון שלהן גדול מ-1. תהי $`\mathrm{T}`$ קבוצת הסדרות הסופיות העולות ממש של שלמים חיוביים, ותהי $`\Sigma : \Im \rightarrow \mathrm{T}`$ הפונקציה ששולחת סדרה ב-$`\Im`$ לסדרת הסכומים החלקיים שלה. אם $`\mathrm{T}_n`$ היא קבוצת הסדרות ב-$`\mathrm{T}`$ שהאיבר האחרון שלהן לכל היותר $`n`$, יש לנו שתי אינוולוציות מתחלפות $`R_n`$ ו-$`C_n`$ על $`\mathrm{T}_n`$, המוגדרות על ידי $`R_n(a_1,a_2,\dots,a_l)=(n+1-a_l,n+1-a_{l-1},\dots,n+1-a_1)`$, ו-$`C_n(a_1,\dots,a_l)`$ = המשלים של $`\{a_1,\dots,a_l\}`$ ב-$`\{1,2,\dots,n\}`$ בסדר עולה. ההגדרה של $`\tau`$ היא $`\tau(I) = \Sigma^{-1}R_nC_n\Sigma(I) = \Sigma^{-1}C_nR_n\Sigma(I)`$ עבור $`I=(i_1,i_2,\dots,i_k) \in \Im`$ עם $`i_1+\cdots+i_k=n`$.

למשל,



```math
\tau(3,4,1) = \Sigma^{-1}C_8R_8(3,7,8) = \Sigma^{-1}(3,4,5,7,8) = (3,1,1,2,1).
```

 נאמר שהסדרות $`(i_1,\dots,i_k)`$ ו-$`\tau(i_1,\dots,i_k)`$ דואליות זו לזו, ונקרא לסדרה שקבועה תחת $`\tau`$ דואלית-עצמית.[^18]

**השערת הדואליות (הופמן).** אם $`(h_1,\dots,h_{n-k})`$ דואלית ל-$`(i_1,\dots,i_k)`$, אז $`\zeta(h_1,\dots,h_{n-k}) = \zeta(i_1,\dots,i_k)`$.

(**דוגמאות, נוסף בתרגום (נבדקו בחישוב):** $`\tau(2,1) = (3)`$, וזו זהות אוילר $`\zeta(2,1) = \zeta(3)`$; $`\tau(4,1) = (3,1,1)`$, ואכן $`\zeta(4,1) = \zeta(3,1,1) = 2\zeta(5) - \zeta(2)\zeta(3)`$; והסדרות $`(3,1)`$ ו-$`(2,2)`$ דואליות-עצמיות. כיום הדואליות היא משפט: היא נובעת מההצגה האינטגרלית שלמעלה, על ידי ההצבה $`t \mapsto 1-t`$, שמחליפה את התפקידים של $`a = dt/t`$ ו-$`b = dt/(1-t)`$ והופכת את סדר האינטגרציה.)

השערת הסכום ידועה גם כ**משפט הסכום** (היא הוכחה בידי גרנוויל ובאופן בלתי תלוי בידי זגייר), ואפשר לבטא אותה כך: ערך פונקציית זטא של רימן בשלם $`n \ge 2`$ שווה לסכום כל ערכי הזטא המרובים התקפים (כלומר עם $`s_1 > 1`$) של ה[חלוקות](https://he.wikipedia.org/wiki/%D7%97%D7%9C%D7%95%D7%A7%D7%94_%28%D7%AA%D7%95%D7%A8%D7%AA_%D7%94%D7%9E%D7%A1%D7%A4%D7%A8%D7%99%D7%9D%29) באורך $`k`$ ובמשקל $`n`$, עם $`1 \le k \le n-1`$. בנוסחה:[^19]



```math
\sum_{s_1 + \cdots + s_k=n,\ s_1>1}\zeta(s_1, \ldots, s_k) = \zeta(n).
```

 למשל, עם אורך $`k = 2`$ ומשקל $`n = 7`$:



```math
\zeta(6,1)+\zeta(5,2)+\zeta(4,3)+\zeta(3,4)+\zeta(2,5) = \zeta(7).
```

 (נבדק מספרית: שני האגפים שווים ל-$`1.0083493\ldots`$)

## סכומי אוילר עם כל צירופי הסימנים האפשריים

סכומי אוילר עם סימנים מתחלפים מופיעים בחקר סכומי אוילר הלא מתחלפים.[^20]

### סימון



```math
\sum_{n=1}^\infty \frac{H_n^{(b)}(-1)^{(n+1)} }{(n+1)^a}=\zeta(\bar{a},b),
```

 כאשר $`H_n^{(b)}=1+\frac{1}{2^b}+\frac{1}{3^b}+\cdots+\frac1{n^b}`$ הם המספרים ההרמוניים המוכללים;



```math
\sum_{n=1}^\infty \frac{\bar{H}_n^{(b)} }{(n+1)^a}=\zeta(a,\bar{b}),
```

 כאשר $`\bar{H}_n^{(b)}=-1+\frac{1}{2^b}-\frac{1}{3^b}+\cdots+\frac{(-1)^n}{n^b}`$;



```math
\sum_{n=1}^\infty \frac{\bar{H}_n^{(b)}(-1)^{(n+1)} }{(n+1)^a}=\zeta(\bar{a},\bar{b}).
```

 באופן דומה מוגדרים סכומי אוילר משולשים כמו $`\zeta(\bar a,\bar b,\bar c)`$, $`\zeta(\bar a,b,c)`$, $`\zeta(a,\bar b,c)`$ ו-$`\zeta(a,b,\bar c)`$, כשבכל מקום שבו יש קו מופיע הגורם $`(-1)^{n_i}`$ באינדקס המתאים. (בערך האנגלי הנוסחאות לעומק 3 כתובות כמכפלה של שני טורים נפרדים, וזו שגיאת כתיב: הסכום הפנימי צריך להיות תלוי באינדקס החיצוני, כמו בנוסחה לעומק 3 בפרק הקודם.)

כגרסה של [פונקציית אטא של דיריכלה](%D7%A4%D7%95%D7%A0%D7%A7%D7%A6%D7%99%D7%99%D7%AA%20%D7%90%D7%98%D7%90%20%D7%A9%D7%9C%20%D7%93%D7%99%D7%A8%D7%99%D7%9B%D7%9C%D7%94.md) נגדיר



```math
\phi(s) = \frac{1-2^{(s-1)} } {2^{(s-1)} } \zeta(s), \quad s>1, \qquad \phi(1) = -\ln 2.
```

 (כלומר $`\phi(s) = \sum_{n\ge1}(-1)^n/n^s = -\eta(s)`$.)

### נוסחת השתקפות

אפשר להכליל את נוסחת ההשתקפות $`\zeta(a,b)+\zeta(b,a)=\zeta(a)\zeta(b)-\zeta(a+b)`$ כך:



```math
\zeta(a,\bar{b})+\zeta(\bar{b},a)=\zeta(a)\phi(b)-\phi(a+b),
```





```math
\zeta(\bar{a},b)+\zeta(b,\bar{a})=\zeta(b)\phi(a)-\phi(a+b),
```





```math
\zeta(\bar{a},\bar{b})+\zeta(\bar{b},\bar{a})=\phi(a)\phi(b)-\zeta(a+b).
```

 אם $`a=b`$, מתקבל $`\zeta(\bar{a},\bar{a})=\tfrac{1}{2}\Big[\phi^2(a)-\zeta(2a)\Big]`$.

### יחסים נוספים

מהגדרת הטור קל להוכיח:



```math
\zeta(a,b)+\zeta(a,\bar{b})+\zeta(\bar{a},b)+\zeta(\bar{a},\bar{b})=\frac{\zeta(a,b)}{2^{(a+b-2)} }, \quad a>1,
```





```math
\zeta(a,b,c)+\zeta(a,b,\bar{c})+\zeta(a,\bar{b},c)+\zeta(\bar{a},b,c)+\zeta(a,\bar{b},\bar{c})+\zeta(\bar{a},b,\bar{c})+\zeta(\bar{a},\bar{b},c)+\zeta(\bar{a},\bar{b},\bar{c})=\frac{\zeta(a,b,c)}{2^{(a+b+c-3)} }, \quad a>1.
```

 (**למה, נוסף בתרגום:** $`1 + \varepsilon^n`$ שווה ל-2 כאשר $`n`$ זוגי ול-0 כאשר הוא אי-זוגי. לכן סכום ארבעת הצירופים משאיר רק את האיברים שבהם כל האינדקסים זוגיים, כפול $`2^{\text{depth} }`$. הצבת $`n_i = 2m_i`$ נותנת $`2^{\text{depth} }\cdot 2^{-(a+b+\cdots)}\zeta(a,b,\ldots)`$.)

יחס שימושי נוסף הוא:[^21]



```math
\zeta(a,b)+\zeta(\bar{a},\bar{b})=\sum_{s>0} (a+b-s-1)!\Big[\frac{Z_a(a+b-s,s)}{(a-s)!(b-1)!}+\frac{Z_b(a+b-s,s)}{(b-s)!(a-1)!}\Big],
```

 כאשר $`Z_a(s,t)=\zeta(s,t)+\zeta(\bar{s},t)-\frac{\Big[\zeta(s,t)+\zeta(s+t)\Big]}{2^{(s-1)} }`$ ו-$`Z_b(s,t)=\frac{\zeta(s,t)}{2^{(s-1)} }`$. שימו לב שצריך להשתמש בכל ערכי $`s`$ שעבורם הארגומנטים של העצרות אי-שליליים.

(כל היחסים בפרק הזה נבדקו מספרית, למשל עבור $`(a,b) = (3,2)`$, $`(a,b,c) = (3,4,5)`$, והיחס האחרון עבור $`(a,b) \in \{(2,2),(2,3),(3,2),(3,3)\}`$.)

## תוצאות נוספות

לכל שלמים חיוביים $`a,b,\dots,k`$:



```math
\sum_{n=2}^{\infty} \zeta(n,k) = \zeta(k+1),
```

 ובאופן כללי יותר



```math
\sum_{n=2}^{\infty} \zeta(n,a,b,\dots,k) = \zeta(a+1,b,\dots,k).
```

 (**הוכחה, נוסף בתרגום:** $`\sum_{n\ge2}n_1^{-n} = \frac{1}{n_1(n_1-1)}`$, ו-$`\sum_{n_1 > n_2}\frac{1}{n_1(n_1-1)} = \frac{1}{n_2}`$ ([טור טלסקופי](https://he.wikipedia.org/wiki/%D7%98%D7%95%D7%A8_%D7%98%D7%9C%D7%A1%D7%A7%D7%95%D7%A4%D7%99)). לכן הסכום על האינדקס הראשון פשוט מגדיל באחד את המעריך של $`n_2`$.)

באותו אופן:



```math
\sum_{n=2}^{\infty} \zeta(n,\bar{k}) = \phi(k+1),
```





```math
\sum_{n=2}^{\infty} \zeta(n,\bar{a},b) = \zeta(\overline{a+1},b),
```





```math
\sum_{n=2}^{\infty} \zeta(n,a,\bar{b}) = \zeta(a+1,\bar{b}),
```





```math
\sum_{n=2}^{\infty} \zeta(n,\bar{a},\bar{b}) = \zeta(\overline{a+1},\bar{b}).
```

 (בערך האנגלי הזהות הראשונה כתובה עם $`-\phi(k+1)`$. לפי ההוכחה שלמעלה, הסכום שווה ל-$`\sum_{m}(-1)^m m^{-k-1} = \phi(k+1)`$, וזה גם מה שמתקבל בחישוב מספרי, למשל עבור $`k = 3`$: $`\phi(4) \approx -0.9470328`$.)



```math
\lim_{k \to \infty}\zeta(n,k) = \zeta(n)-1,
```





```math
\sum_{n=2}^\infty (-1)^n\big(\zeta(n) - 1\big) = \frac{1}{2},
```

 (בערך האנגלי הזהות האחרונה כתובה בצורה $`1-\zeta(2)+\zeta(3)-\zeta(4)+\cdots=|\tfrac{1}{2}|`$; הטור הזה, כפשוטו, אינו מתכנס, כי $`\zeta(n) \to 1`$. הניסוח המדויק הוא עם $`\zeta(n) - 1`$, שמתקבל מהטור הטלסקופי $`\sum_{k\ge2}\frac{1}{k(k+1)} = \frac12`$.)



```math
\zeta(a,a)=\tfrac{1}{2}\Big[(\zeta(a))^{2}-\zeta(2a)\Big],
```





```math
\zeta(a,a,a)=\tfrac{1}{6}(\zeta(a))^{3}+\tfrac{1}{3}\zeta(3a)-\tfrac{1}{2}\zeta(a)\zeta(2a).
```



## ערכי הזטא של מורדל–טורנהיים

פונקציית הזטא של מורדל–טורנהיים, שהציג מטסומוטו (2003) בהשראת המאמרים של מורדל (1958) ושל טורנהיים (1950), מוגדרת על ידי



```math
\zeta_{MT,r}(s_1,\dots,s_r;s_{r+1})=\sum_{m_1,\dots,m_r>0}\frac{1}{ m_1^{s_1}\cdots m_r^{s_r}(m_1+\dots+m_r)^{s_{r+1} } }.
```

 היא מקרה פרטי של פונקציית הזטא של שינטני. (למשל, [פונקציית הזטא של ויטן](%D7%A4%D7%95%D7%A0%D7%A7%D7%A6%D7%99%D7%99%D7%AA%20%D7%96%D7%98%D7%90%20%D7%A9%D7%9C%20%D7%95%D7%99%D7%98%D7%9F.md) של $`SU(3)`$ היא $`2^s\zeta_{MT,2}(s,s;s)`$.)
