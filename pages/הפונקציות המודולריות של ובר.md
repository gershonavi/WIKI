# הפונקציות המודולריות של ובר

ב[מתמטיקה](https://he.wikipedia.org/wiki/%D7%9E%D7%AA%D7%9E%D7%98%D7%99%D7%A7%D7%94), **הפונקציות המודולריות של ובר** הן משפחה של שלוש פונקציות, $`\mathfrak f`$, $`\mathfrak f_1`$ ו-$`\mathfrak f_2`$, שחקר [היינריך ובר](https://he.wikipedia.org/wiki/%D7%94%D7%99%D7%99%D7%A0%D7%A8%D7%99%D7%9A_%D7%95%D7%91%D7%A8).[^1] הן שימושיות במיוחד בתורת ה[כפל המרוכב](%D7%9B%D7%A4%D7%9C%20%D7%9E%D7%A8%D7%95%D7%9B%D7%91.md): הערכים שלהן בנקודות מיוחדות נותנים "אינווריאנטי מחלקה" – מספרים אלגבריים שיוצרים את שדה המחלקות של הילברט כמו $`j`$, אבל עם [פולינומים מינימליים](https://he.wikipedia.org/wiki/%D7%A4%D7%95%D7%9C%D7%99%D7%A0%D7%95%D7%9D_%D7%9E%D7%99%D7%A0%D7%99%D7%9E%D7%9C%D7%99) בעלי מקדמים קטנים בהרבה.

## הגדרה

יהי $`q = e^{2\pi i\tau}`$, כאשר $`\tau`$ ב[חצי המישור העליון](%D7%97%D7%A6%D7%99%20%D7%94%D7%9E%D7%99%D7%A9%D7%95%D7%A8%20%D7%94%D7%A2%D7%9C%D7%99%D7%95%D7%9F.md). פונקציות ובר הן



```math
\begin{align}
\mathfrak f(\tau) &= q^{-\frac1{48} }\prod_{n\gt0}(1 + q^{n-1/2}) = \frac{\eta^2(\tau)}{\eta\big(\tfrac\tau2\big)\eta(2\tau)} = e^{-\frac{\pi i}{24} }\frac{\eta\big(\frac{\tau + 1}2\big)}{\eta(\tau)}, \\
\mathfrak f_1(\tau) &= q^{-\frac1{48} }\prod_{n\gt0}(1 - q^{n-1/2}) = \frac{\eta\big(\tfrac\tau2\big)}{\eta(\tau)}, \\
\mathfrak f_2(\tau) &= \sqrt2\,q^{\frac1{24} }\prod_{n\gt0}(1 + q^n) = \frac{\sqrt2\,\eta(2\tau)}{\eta(\tau)}.
\end{align}
```

 אלה גם ההגדרות במאמר של דיוק "Continued Fractions and Modular Functions".[^2] כאן $`\eta(\tau)`$ היא [פונקציית אטא של דדקינד](%D7%A4%D7%95%D7%A0%D7%A7%D7%A6%D7%99%D7%99%D7%AA%20%D7%90%D7%98%D7%90%20%D7%A9%D7%9C%20%D7%93%D7%93%D7%A7%D7%99%D7%A0%D7%93.md), ואת $`(e^{2\pi i\tau})^\alpha`$ יש לפרש כ-$`e^{2\pi i\tau\alpha}`$. מהתיאור כמנות של פונקציות אטא נובע מיד ש-



```math
\mathfrak f(\tau)\,\mathfrak f_1(\tau)\,\mathfrak f_2(\tau) = \sqrt2.
```

 (במכפלה $`\eta^2(\tau)\cdot\eta(\tau/2)\cdot\sqrt2\,\eta(2\tau)`$ במונה ו-$`\eta(\tau/2)\eta(2\tau)\cdot\eta(\tau)\cdot\eta(\tau)`$ במכנה, הכול מצטמצם פרט ל-$`\sqrt2`$.)

הטרנספורמציה $`\tau \mapsto -1/\tau`$ מקבעת את $`\mathfrak f`$ ומחליפה בין $`\mathfrak f_1`$ ל-$`\mathfrak f_2`$. לכן החבורה $`\mathrm{SL}_2(\mathbb Z)`$ פועלת על המרחב הווקטורי המרוכב התלת-ממדי שנפרש על ידי $`\mathfrak f`$, $`\mathfrak f_1`$ ו-$`\mathfrak f_2`$ (עד כדי כפל בשורשי יחידה מסדר 48).

## מכפלה אינסופית חלופית

לחלופין, יהי $`q = e^{\pi i\tau}`$ הנום. אז



```math
\begin{align}
\mathfrak f(q) &= q^{-\frac1{24} }\prod_{n\gt0}(1 + q^{2n-1}) = \frac{\eta^2(\tau)}{\eta\big(\tfrac\tau2\big)\eta(2\tau)}, \\
\mathfrak f_1(q) &= q^{-\frac1{24} }\prod_{n\gt0}(1 - q^{2n-1}) = \frac{\eta\big(\tfrac\tau2\big)}{\eta(\tau)}, \\
\mathfrak f_2(q) &= \sqrt2\,q^{\frac1{12} }\prod_{n\gt0}(1 + q^{2n}) = \frac{\sqrt2\,\eta(2\tau)}{\eta(\tau)}.
\end{align}
```

 צורת המכפלה האינסופית השתנתה מעט, אבל מנות האטא נשארו זהות, ולכן $`\mathfrak f_i(\tau) = \mathfrak f_i(q)`$ כל עוד בשנייה משתמשים בנום $`q = e^{\pi i\tau}`$. התועלת בצורה השנייה היא החיבור לסימון של פונקציות G ו-g של רמנוג'אן ושל [פונקציות התטא של יעקובי](https://he.wikipedia.org/wiki/%D7%A4%D7%95%D7%A0%D7%A7%D7%A6%D7%99%D7%99%D7%AA_%D7%AA%D7%98%D7%90), ששתיהן משתמשות בנום.

## הקשר לפונקציות G ו-g של רמנוג'אן

עדיין עם הנום $`q = e^{\pi i\tau}`$, פונקציות G ו-g של [רמנוג'אן](https://he.wikipedia.org/wiki/%D7%A1%D7%A8%D7%99%D7%A0%D7%99%D7%95%D7%95%D7%90%D7%A1%D7%94_%D7%A8%D7%9E%D7%A0%D7%95%D7%92%27%D7%90%D7%9F) מוגדרות על ידי



```math
\begin{align}
2^{1/4}G_n &= q^{-\frac1{24} }\prod_{k\gt0}(1 + q^{2k-1}), \\
2^{1/4}g_n &= q^{-\frac1{24} }\prod_{k\gt0}(1 - q^{2k-1}),
\end{align}
```

 כאשר $`\tau = \sqrt{-n}`$, כלומר $`q = e^{-\pi\sqrt n}`$. לכן



```math
2^{1/4}G_n = \mathfrak f(\sqrt{-n}), \qquad 2^{1/4}g_n = \mathfrak f_1(\sqrt{-n}).
```

 רמנוג'אן מצא קשרים רבים בין $`G_n`$ ל-$`g_n`$, שמתורגמים לקשרים בין $`\mathfrak f`$ ל-$`\mathfrak f_1`$. למשל, הזהות שלו



```math
(G_n^8 - g_n^8)(G_ng_n)^8 = \tfrac14
```

 שקולה ל-



```math
\left[\mathfrak f^8 - \mathfrak f_1^8\right]\left[\mathfrak f\,\mathfrak f_1\right]^8 = \left[\sqrt2\right]^8 = 16.
```

 אפשר להוכיח אותה ישירות משתי הזהויות שבערך: $`\mathfrak f^8 - \mathfrak f_1^8 = \mathfrak f_2^8`$ (ראו למטה) ו-$`(\mathfrak f\mathfrak f_1)^8 = (\sqrt2/\mathfrak f_2)^8 = 16/\mathfrak f_2^8`$; המכפלה היא $`16`$. המעבר ל-$`G, g`$: $`\mathfrak f^8 - \mathfrak f_1^8 = 4(G^8 - g^8)`$ ו-$`(\mathfrak f\mathfrak f_1)^8 = 16(Gg)^8`$, ולכן $`64(G^8 - g^8)(Gg)^8 = 16`$.

רמנוג'אן גם טבלל ערכים רבים של $`G_n`$ עבור $`n`$ אי-זוגי ושל $`g_n`$ עבור $`n`$ זוגי. זה נותן אוטומטית ערכים מפורשים רבים של $`\mathfrak f`$ ו-$`\mathfrak f_1`$. למשל, עבור $`\tau = \sqrt{-5}, \sqrt{-13}, \sqrt{-37}`$, שמתאימים לדיסקרימיננטות עם מספר מחלקה 2,



```math
\begin{align}
G_5 &= \left(\frac{1 + \sqrt5}2\right)^{1/4}, \\
G_{13} &= \left(\frac{3 + \sqrt{13} }2\right)^{1/4}, \\
G_{37} &= \left(6 + \sqrt{37}\right)^{1/4}
\end{align}
```

 (בדקנו את שלושת הערכים בחישוב מספרי מתוך המכפלה האינסופית), ומהם מקבלים בקלות $`\mathfrak f(\sqrt{-n}) = 2^{1/4}G_n`$, וגם את הדוגמאות המסובכות יותר שבמחברות של רמנוג'אן.

### דוגמה: חישוב $`j(\sqrt{-5})`$

אפשר להשתמש ב-$`G_5`$ כדי לחשב את $`j(\sqrt{-5})`$ במדויק. יהי $`\varphi = \frac{1 + \sqrt5}2`$ [יחס הזהב](https://he.wikipedia.org/wiki/%D7%99%D7%97%D7%A1_%D7%94%D7%96%D7%94%D7%91). אז $`\mathfrak f(\sqrt{-5}) = 2^{1/4}\varphi^{1/4}`$, ולכן



```math
\mathfrak f(\sqrt{-5})^{24} = 2^6\varphi^6 = 64(9 + 4\sqrt5).
```

 לפי הנוסחה $`j = \frac{(\mathfrak f^{24} - 16)^3}{\mathfrak f^{24} }`$ (ראו למטה):



```math
j(\sqrt{-5}) = \frac{\left(64(9 + 4\sqrt5) - 16\right)^3}{64(9 + 4\sqrt5)} = 632000 + 282880\sqrt5 \approx 1264538.909,
```

 בהתאם לחישוב ישיר של $`j(\sqrt{-5})`$ מתוך טור $`q`$ (בדקנו את הפישוט בחישוב סימבולי ואת הערך המספרי בדיוק של 25 ספרות). מספר המחלקה של $`\mathbb Q(\sqrt{-5})`$ הוא 2, ולכן $`j(\sqrt{-5})`$ הוא שלם אלגברי ממעלה 2 – ובאמת הוא ב-$`\mathbb Z[\sqrt5]`$. שימו לב לפער בגדלים: $`G_5^4 = \varphi`$ הוא יחידה קטנה, בעוד ש-$`j(\sqrt{-5})`$ גדול ממיליון. זה היתרון של פונקציות ובר כאינווריאנטי מחלקה.

## הקשר לפונקציות התטא של יעקובי

הארגומנט של [פונקציות התטא של יעקובי](https://he.wikipedia.org/wiki/%D7%A4%D7%95%D7%A0%D7%A7%D7%A6%D7%99%D7%99%D7%AA_%D7%AA%D7%98%D7%90) הקלאסיות הוא באופן מסורתי הנום $`q = e^{\pi i\tau}`$:



```math
\begin{align}
\vartheta_{10}(0; \tau) &= \theta_2(q) = \sum_{n=-\infty}^\infty q^{(n+1/2)^2} = \frac{2\eta^2(2\tau)}{\eta(\tau)}, \\[2pt]
\vartheta_{00}(0; \tau) &= \theta_3(q) = \sum_{n=-\infty}^\infty q^{n^2} = \frac{\eta^5(\tau)}{\eta^2\left(\frac\tau2\right)\eta^2(2\tau)} = \frac{\eta^2\left(\frac{\tau + 1}2\right)}{\eta(\tau + 1)}, \\[3pt]
\vartheta_{01}(0; \tau) &= \theta_4(q) = \sum_{n=-\infty}^\infty(-1)^nq^{n^2} = \frac{\eta^2\left(\frac\tau2\right)}{\eta(\tau)}.
\end{align}
```

 כשמחלקים אותן ב-$`\eta(\tau)`$, ומשתמשים בכך ש-$`\eta(\tau) = e^{-\frac{\pi i}{12} }\eta(\tau + 1)`$, מקבלים בדיוק את הריבועים של פונקציות ובר:



```math
\frac{\theta_2(q)}{\eta(\tau)} = \mathfrak f_2(q)^2, \qquad \frac{\theta_4(q)}{\eta(\tau)} = \mathfrak f_1(q)^2, \qquad \frac{\theta_3(q)}{\eta(\tau)} = \mathfrak f(q)^2.
```

 לפי זהות יעקובי



```math
\theta_2(q)^4 + \theta_4(q)^4 = \theta_3(q)^4
```

 מקבלים



```math
\mathfrak f_2(q)^8 + \mathfrak f_1(q)^8 = \mathfrak f(q)^8.
```



## הקשר לפונקציית j

שלושת השורשים של ה[משוואה ממעלה שלישית](https://he.wikipedia.org/wiki/%D7%9E%D7%A9%D7%95%D7%95%D7%90%D7%94_%D7%9E%D7%9E%D7%A2%D7%9C%D7%94_%D7%A9%D7%9C%D7%99%D7%A9%D7%99%D7%AA)



```math
j(\tau) = \frac{(x - 16)^3}x,
```

 כאשר $`j(\tau)`$ היא [פונקציית j](%D7%90%D7%99%D7%A0%D7%95%D7%95%D7%A8%D7%99%D7%90%D7%A0%D7%98%20j.md), הם $`x = \mathfrak f(\tau)^{24}, -\mathfrak f_1(\tau)^{24}, -\mathfrak f_2(\tau)^{24}`$. בנוסף, מתקיים



```math
j(\tau) = 32\frac{\Big(\theta_2(q)^8 + \theta_3(q)^8 + \theta_4(q)^8\Big)^3}{\Big(\theta_2(q)\,\theta_3(q)\,\theta_4(q)\Big)^8},
```

 ומההגדרות של פונקציות ובר דרך פונקציות התטא, יחד עם $`\mathfrak f_2(q)^2\mathfrak f_1(q)^2\mathfrak f(q)^2 = 2`$, נובע



```math
j(\tau) = \left(\frac{\mathfrak f(\tau)^{16} + \mathfrak f_1(\tau)^{16} + \mathfrak f_2(\tau)^{16} }2\right)^3.
```

 (כל הזהויות בערך נבדקו בחישוב מספרי בנקודה כללית $`\tau = 0.13 + 0.77i`$, בדיוק של 40 ספרות.)
