# משפט נגל–לוץ

ב[מתמטיקה](https://he.wikipedia.org/wiki/%D7%9E%D7%AA%D7%9E%D7%98%D7%99%D7%A7%D7%94), **משפט נגל–לוץ** הוא תוצאה ב[גאומטריה דיופנטית](https://he.wikipedia.org/wiki/%D7%92%D7%90%D7%95%D7%9E%D7%98%D7%A8%D7%99%D7%94_%D7%93%D7%99%D7%95%D7%A4%D7%A0%D7%98%D7%99%D7%AA) של [עקומים אליפטיים](https://he.wikipedia.org/wiki/%D7%A2%D7%A7%D7%95%D7%9D_%D7%90%D7%9C%D7%99%D7%A4%D7%98%D7%99), שמתארת את נקודות ה[פיתול](https://he.wikipedia.org/wiki/%D7%A4%D7%99%D7%AA%D7%95%D7%9C_%28%D7%90%D7%9C%D7%92%D7%91%D7%A8%D7%94%29) ה[רציונליות](https://he.wikipedia.org/wiki/%D7%9E%D7%A1%D7%A4%D7%A8_%D7%A8%D7%A6%D7%99%D7%95%D7%A0%D7%9C%D7%99) על עקומים אליפטיים עם מקדמים שלמים. הוא קרוי על שם טריגווה נגל ואליזבת לוץ.

## הגדרות

נניח שהמשוואה



```math
y^2 = x^3 + ax^2 + bx + c
```

 מגדירה עקום ממעלה שלישית לא סינגולרי $`E`$ עם [מקדמים](https://he.wikipedia.org/wiki/%D7%9E%D7%A7%D7%93%D7%9D_%28%D7%9E%D7%AA%D7%9E%D7%98%D7%99%D7%A7%D7%94%29) שלמים $`a, b, c`$, ותהי $`D`$ ה[דיסקרימיננטה](https://he.wikipedia.org/wiki/%D7%93%D7%99%D7%A1%D7%A7%D7%A8%D7%99%D7%9E%D7%99%D7%A0%D7%A0%D7%98%D7%94) של ה[פולינום](https://he.wikipedia.org/wiki/%D7%A4%D7%95%D7%9C%D7%99%D7%A0%D7%95%D7%9D) ממעלה שלישית באגף ימין:



```math
D = -4a^3c + a^2b^2 + 18abc - 4b^3 - 27c^2.
```



## ניסוח המשפט

אם $`P = (x, y)`$ [נקודה רציונלית](https://he.wikipedia.org/wiki/%D7%A0%D7%A7%D7%95%D7%93%D7%94_%D7%A8%D7%A6%D7%99%D7%95%D7%A0%D7%9C%D7%99%D7%AA) מ[סדר](https://he.wikipedia.org/wiki/%D7%A1%D7%93%D7%A8_%28%D7%AA%D7%95%D7%A8%D7%AA_%D7%94%D7%97%D7%91%D7%95%D7%A8%D7%95%D7%AA%29) סופי על $`E`$, ביחס לחוק החבורה של העקום האליפטי, אז:

1.  $`x`$ ו-$`y`$ שלמים;
2.  או ש-$`y = 0`$, ואז $`P`$ מסדר 2, או ש-$`y`$ מחלק את $`D`$ – ולמעשה $`y^2`$ מחלק את $`D`$.

המשפט נותן **אלגוריתם סופי** למציאת כל נקודות הפיתול: עוברים על המחלקים $`y`$ של $`D`$ שריבועם מחלק את $`D`$, פותרים את המשוואה הממעלה השלישית ב-$`x`$ בשלמים, ובודקים אילו נקודות הן באמת מסדר סופי. הכיוון ההפוך אינו נכון: נקודה שלמה עם $`y^2 \mid D`$ אינה בהכרח מסדר סופי; אבל אם לנקודה כלשהי, או לאחת מכפולותיה, יש קואורדינטות לא שלמות, היא מסדר אינסופי.

## דוגמאות

- **$`y^2 = x^3 + 1`$** ($`a = b = 0`$, $`c = 1`$): $`D = -27`$. המחלקים $`y`$ עם $`y^2 \mid 27`$ הם $`y = \pm1, \pm3`$, ובנוסף $`y = 0`$. מקבלים את הנקודות $`(-1, 0)`$, $`(0, \pm1)`$, $`(2, \pm3)`$. כולן אכן מסדר סופי: $`(2, 3)`$ מסדר 6, ו-$`2(2,3) = (0, 1)`$, $`3(2,3) = (-1, 0)`$. לכן חבורת הפיתול היא $`\mathbb Z/6`$.
- **$`y^2 = x^3 - 2`$**: $`D = -108 = -2^2\cdot3^3`$. המחלקים $`y`$ עם $`y^2 \mid 108`$ הם $`\pm1, \pm2, \pm3, \pm6`$, ואף אחד מהם לא נותן $`x`$ שלם ($`x^3 = 3, 6, 11, 38`$). לכן אין נקודות פיתול פרט ל-$`O`$. בפרט הנקודה $`(3, 5)`$ מסדר אינסופי ($`25 \nmid 108`$) – וזה מראה שלעקום יש דרגה חיובית.
- **$`y^2 = x^3 - x`$**: $`D = 4`$. ל-$`y = \pm1, \pm2`$ אין פתרונות שלמים, ונשארות נקודות מסדר 2: $`(0, 0), (\pm1, 0)`$. חבורת הפיתול היא $`(\mathbb Z/2)^2`$.

## הכללות

משפט נגל–לוץ מוכלל לשדות מספרים כלליים ולמשוואות ממעלה שלישית כלליות יותר.[^1] לעקומים מעל הרציונליים, ההכללה אומרת שלעקום ממעלה שלישית לא סינגולרי שצורת ויירשטראס שלו



```math
y^2 + a_1xy + a_3y = x^3 + a_2x^2 + a_4x + a_6
```

 בעלת מקדמים שלמים, כל נקודה רציונלית $`P = (x, y)`$ מסדר סופי חייבת להיות בעלת קואורדינטות שלמות, או להיות מסדר 2 עם קואורדינטות מהצורה $`x = m/4`$, $`y = n/8`$, עם $`m, n`$ שלמים.

## היסטוריה
