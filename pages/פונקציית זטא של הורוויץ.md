# פונקציית זטא של הורוויץ

<img src="https://commons.wikimedia.org/wiki/Special:FilePath/Hurwitza1ov3v2.png" alt="פונקציית זטא של הורוויץ עבור <math>a=1/3</math>, בהצגה בשיטת צביעת תחום." width="320">

ב[מתמטיקה](https://he.wikipedia.org/wiki/%D7%9E%D7%AA%D7%9E%D7%98%D7%99%D7%A7%D7%94), **פונקציית זטא של הורוויץ** היא אחת מ[פונקציות הזטא](https://he.wikipedia.org/wiki/%D7%A4%D7%95%D7%A0%D7%A7%D7%A6%D7%99%D7%99%D7%AA_%D7%96%D7%98%D7%90) הרבות. היא מוגדרת עבור משתנים [מרוכבים](https://he.wikipedia.org/wiki/%D7%9E%D7%A1%D7%A4%D7%A8_%D7%9E%D7%A8%D7%95%D7%9B%D7%91) $`s`$ עם $`\operatorname{Re}(s) > 1`$ ו-$`a \ne 0, -1, -2, \ldots`$ על ידי



```math
\zeta(s,a) = \sum_{n=0}^\infty \frac{1}{(n+a)^{s}}.
```



עבור ערכים אלה של $`s`$ ו-$`a`$ ה[טור](https://he.wikipedia.org/wiki/%D7%98%D7%95%D7%A8_%28%D7%9E%D7%AA%D7%9E%D7%98%D7%99%D7%A7%D7%94%29) מתכנס בהחלט, וניתן להמשיך אותו ל[פונקציה מרומורפית](https://he.wikipedia.org/wiki/%D7%A4%D7%95%D7%A0%D7%A7%D7%A6%D7%99%D7%94_%D7%9E%D7%A8%D7%95%D7%9E%D7%95%D7%A8%D7%A4%D7%99%D7%AA) המוגדרת לכל $`s \ne 1`$. [פונקציית זטא של רימן](https://he.wikipedia.org/wiki/%D7%A4%D7%95%D7%A0%D7%A7%D7%A6%D7%99%D7%99%D7%AA_%D7%96%D7%98%D7%90_%D7%A9%D7%9C_%D7%A8%D7%99%D7%9E%D7%9F) היא המקרה הפרטי $`\zeta(s,1)`$. הפונקציה קרויה על שם [אדולף הורוויץ](https://he.wikipedia.org/wiki/%D7%90%D7%93%D7%95%D7%9C%D7%A3_%D7%94%D7%95%D7%A8%D7%95%D7%95%D7%99%D7%A5), שהציג אותה בשנת 1882.[^1]

## ייצוג אינטגרלי

לפונקציית זטא של הורוויץ יש הייצוג האינטגרלי



```math
\zeta(s,a) = \frac{1}{\Gamma(s)} \int_0^\infty \frac{x^{s-1}e^{-ax}}{1-e^{-x}}\, dx
```



עבור $`\operatorname{Re}(s)>1`$ ו-$`\operatorname{Re}(a)>0`$, כאשר $`\Gamma`$ היא [פונקציית גמא](https://he.wikipedia.org/wiki/%D7%A4%D7%95%D7%A0%D7%A7%D7%A6%D7%99%D7%99%D7%AA_%D7%92%D7%9E%D7%90) (ניתן לראות באינטגרל זה [התמרת מלין](%D7%94%D7%AA%D7%9E%D7%A8%D7%AA%20%D7%9E%D7%9C%D7%99%D7%9F.md)). את הנוסחה ניתן לקבל, באופן גס, על ידי הכתיבה



```math
\zeta(s,a)\Gamma(s) = \sum_{n=0}^\infty \frac{1}{(n+a)^s} \int_0^\infty x^s e^{-x} \frac{dx}{x} = \sum_{n=0}^\infty \int_0^\infty y^s e^{-(n+a)y} \frac{dy}{y}
```



והחלפת סדר הסכימה והאינטגרציה.[^2]

את הייצוג הזה אפשר להפוך לייצוג כאינטגרל מסילתי



```math
\zeta(s,a) = -\Gamma(1-s)\frac{1}{2 \pi i} \int_C \frac{(-z)^{s-1}e^{-az}}{1-e^{-z}}\, dz,
```



כאשר $`C`$ היא מסילת הנקל המקיפה את הציר הממשי החיובי נגד כיוון השעון, ובחזקה המרוכבת $`(-z)^{s-1}`$ משתמשים בענף הראשי. בניגוד לאינטגרל הקודם, אינטגרל זה תקף לכל $`s`$, והוא [פונקציה שלמה](https://he.wikipedia.org/wiki/%D7%A4%D7%95%D7%A0%D7%A7%D7%A6%D7%99%D7%94_%D7%A9%D7%9C%D7%9E%D7%94) של $`s`$.[^3]

ייצוג זה נותן [המשכה אנליטית](https://he.wikipedia.org/wiki/%D7%94%D7%9E%D7%A9%D7%9B%D7%94_%D7%90%D7%A0%D7%9C%D7%99%D7%98%D7%99%D7%AA) של $`\zeta(s,a)`$ לכל $`s \ne 1`$. בנקודה $`s = 1`$ יש לפונקציה [קוטב](https://he.wikipedia.org/wiki/%D7%A7%D7%95%D7%98%D7%91_%28%D7%90%D7%A0%D7%9C%D7%99%D7%96%D7%94_%D7%9E%D7%A8%D7%95%D7%9B%D7%91%D7%AA%29) פשוט עם [שארית](https://he.wikipedia.org/wiki/%D7%A9%D7%90%D7%A8%D7%99%D7%AA_%28%D7%90%D7%A0%D7%9C%D7%99%D7%96%D7%94_%D7%9E%D7%A8%D7%95%D7%9B%D7%91%D7%AA%29) 1.[^4]

## נוסחת הורוויץ

פונקציית זטא של הורוויץ מקיימת זהות המכלילה את ה[משוואה הפונקציונלית](https://he.wikipedia.org/wiki/%D7%9E%D7%A9%D7%95%D7%95%D7%90%D7%94_%D7%A4%D7%95%D7%A0%D7%A7%D7%A6%D7%99%D7%95%D7%A0%D7%9C%D7%99%D7%AA) של פונקציית זטא של רימן:[^5]



```math
\zeta(1-s,a) = \frac{\Gamma(s)}{(2\pi)^s} \left( e^{-\pi i s/2} \sum_{n=1}^\infty \frac{e^{2\pi ina}}{n^s} + e^{\pi i s/2} \sum_{n=1}^\infty \frac{e^{-2\pi ina}}{n^s} \right),
```



התקפה עבור $`\operatorname{Re}(s) > 1`$ ו-$`0 < a \le 1`$. המשוואה הפונקציונלית של פונקציית זטא של רימן היא המקרה הפרטי $`a = 1`$:[^6]



```math
\zeta(1-s) = \frac{2\Gamma(s)}{(2\pi)^{s}} \cos\left(\frac{\pi s}{2}\right) \zeta(s).
```



ניתן לכתוב את נוסחת הורוויץ גם בצורה[^7]



```math
\zeta(s,a) = \frac{2\Gamma(1-s)}{(2\pi)^{1-s}} \left( \sin\left(\frac{\pi s}{2}\right) \sum_{n=1}^\infty \frac{\cos(2\pi na)}{n^{1-s}} + \cos\left(\frac{\pi s}{2}\right) \sum_{n=1}^\infty \frac{\sin(2\pi na)}{n^{1-s}} \right)
```



(עבור $`\operatorname{Re}(s) < 0`$ ו-$`0 < a \le 1`$).

לנוסחת הורוויץ הוכחות רבות.[^8] הוכחה אחת משתמשת בייצוג כאינטגרל מסילתי וב[משפט השאריות](https://he.wikipedia.org/wiki/%D7%9E%D7%A9%D7%A4%D7%98_%D7%94%D7%A9%D7%90%D7%A8%D7%99%D7%95%D7%AA).[^9][^10] הוכחה שנייה משתמשת בזהות של [פונקציית תטא](https://he.wikipedia.org/wiki/%D7%A4%D7%95%D7%A0%D7%A7%D7%A6%D7%99%D7%99%D7%AA_%D7%AA%D7%98%D7%90), או באופן שקול בנוסחת הסכימה של פואסון.[^11] שתי ההוכחות מקבילות לשתי ההוכחות של המשוואה הפונקציונלית של פונקציית זטא של רימן ב[מאמרו של רימן משנת 1859](https://he.wikipedia.org/wiki/%D7%A2%D7%9C_%D7%9E%D7%A1%D7%A4%D7%A8_%D7%94%D7%A8%D7%90%D7%A9%D7%95%D7%A0%D7%99%D7%99%D7%9D_%D7%9E%D7%AA%D7%97%D7%AA_%D7%9C%D7%92%D7%95%D7%93%D7%9C_%D7%A0%D7%AA%D7%95%D7%9F). הוכחה נוספת משתמשת ב[נוסחת הסכימה של אוילר-מקלורן](https://he.wikipedia.org/wiki/%D7%A0%D7%95%D7%A1%D7%97%D7%AA_%D7%90%D7%95%D7%99%D7%9C%D7%A8-%D7%9E%D7%A7%D7%9C%D7%95%D7%A8%D7%9F) כדי לבטא את הפונקציה כאינטגרל



```math
\zeta(s,a) = s \int_{-a}^\infty \frac{\lfloor x \rfloor - x + \frac{1}{2}}{(x+a)^{s+1}}\, dx
```



(עבור $`-1 < \operatorname{Re}(s) < 0`$ ו-$`0 < a \le 1`$), ולאחר מכן מפתחת את המונה ל[טור פורייה](https://he.wikipedia.org/wiki/%D7%98%D7%95%D7%A8_%D7%A4%D7%95%D7%A8%D7%99%D7%99%D7%94).[^12]

### משוואה פונקציונלית עבור a רציונלי

כאשר $`a`$ הוא [מספר רציונלי](https://he.wikipedia.org/wiki/%D7%9E%D7%A1%D7%A4%D7%A8_%D7%A8%D7%A6%D7%99%D7%95%D7%A0%D7%9C%D7%99), נובעת מנוסחת הורוויץ המשוואה הפונקציונלית הבאה: עבור שלמים $`1\leq m \leq n`$,



```math
\zeta\left(1-s, \frac{m}{n} \right) = \frac{2\Gamma(s)}{ \left(2\pi n\right)^s } \sum_{k=1}^n \cos \left( \frac {\pi s} {2} -\frac {2\pi k m} {n} \right) \zeta\left( s, \frac {k}{n} \right)
```



לכל ערך של $`s`$.[^13]

## ייצוג כטור

[הלמוט הסה](https://he.wikipedia.org/wiki/%D7%94%D7%9C%D7%9E%D7%95%D7%98_%D7%94%D7%A1%D7%94) נתן בשנת 1930 ייצוג כטור ניוטון מתכנס, התקף עבור $`a > 0`$ ממשי וכל $`s \ne 1`$ מרוכב:[^14]



```math
\zeta(s,a) = \frac{1}{s-1} \sum_{n=0}^\infty \frac{1}{n+1} \sum_{k=0}^n (-1)^k \binom{n}{k} (a+k)^{1-s}.
```



הטור מתכנס במידה שווה על [קבוצות קומפקטיות](https://he.wikipedia.org/wiki/%D7%A7%D7%91%D7%95%D7%A6%D7%94_%D7%A7%D7%95%D7%9E%D7%A4%D7%A7%D7%98%D7%99%D7%AA) של מישור ה-$`s`$ לפונקציה שלמה. ניתן לפרש את הסכום הפנימי כהפרש הקדמי ה-$`n`$-י של $`a^{1-s}`$.

## טור טיילור

הנגזרת החלקית לפי הארגומנט השני היא הזזה:



```math
\frac {\partial} {\partial a} \zeta (s,a) = -s\zeta(s+1,a).
```



לכן ניתן לכתוב את [טור טיילור](https://he.wikipedia.org/wiki/%D7%98%D7%95%D7%A8_%D7%98%D7%99%D7%99%D7%9C%D7%95%D7%A8) בצורה



```math
\zeta(s,x+y) = \sum_{k=0}^\infty \frac{y^k}{k!} \frac {\partial^k} {\partial x^k} \zeta (s,x) = \sum_{k=0}^\infty \binom{s+k-1}{s-1} \left(-y\right)^k \zeta (s+k,x).
```



לחלופין, עבור $`|q| < 1`$,



```math
\zeta(s, q) = \frac{1}{q^s} + \sum_{n=0}^{\infty} (-q)^n \binom{s + n - 1}{n} \zeta(s + n).
```

[^15]

קשורה לכך נוסחת סטארק-קייפר:



```math
\zeta(s,N) = \sum_{k=0}^\infty \left[ N+\frac {s-1}{k+1}\right] {s+k-1 \choose s-1} (-1)^k \zeta (s+k,N),
```



התקפה עבור $`N`$ שלם ו-$`s`$ כלשהו.

## טור לורן

פיתוח [טור לורן](https://he.wikipedia.org/wiki/%D7%98%D7%95%D7%A8_%D7%9C%D7%95%D7%A8%D7%9F) של הפונקציה סביב $`s=1`$ משמש להגדרת [קבועי סטילטיס](%D7%A7%D7%91%D7%95%D7%A2%D7%99%20%D7%A1%D7%98%D7%99%D7%9C%D7%98%D7%99%D7%A1.md) המוכללים:



```math
\zeta(s,a) = \frac{1}{s-1} + \sum_{n=0}^\infty \frac{(-1)^n}{n!} \gamma_n(a) (s-1)^n.
```



בפרט, האיבר הקבוע הוא



```math
\lim_{s\to 1} \left[ \zeta(s,a) - \frac{1}{s-1}\right] = \gamma_0(a) = \frac{-\Gamma'(a)}{\Gamma(a)} = -\psi(a),
```



כאשר $`\psi = \Gamma' / \Gamma`$ היא [פונקציית הדיגמא](https://he.wikipedia.org/wiki/%D7%A4%D7%95%D7%A0%D7%A7%D7%A6%D7%99%D7%99%D7%AA_%D7%93%D7%99%D7%92%D7%9E%D7%90). כמקרה פרטי, $`\gamma_0(1) = -\psi(1) = \gamma`$, [קבוע אוילר-מסקרוני](https://he.wikipedia.org/wiki/%D7%A7%D7%91%D7%95%D7%A2_%D7%90%D7%95%D7%99%D7%9C%D7%A8-%D7%9E%D7%A1%D7%A7%D7%A8%D7%95%D7%A0%D7%99).

## ערכים מיוחדים

### מספרים שלמים שליליים

הערכים של $`\zeta(s,a)`$ בנקודות $`s = 0, -1, -2, \ldots`$ קשורים לפולינומי ברנולי $`B_n(x)`$:[^16]



```math
\zeta(-n,a) = -\frac{B_{n+1}(a)}{n+1}.
```



למשל, עבור $`n=0`$ מתקבל $`\zeta(0,a) = \tfrac{1}{2} - a`$.

### הנגזרת לפי s

ה[נגזרת החלקית](https://he.wikipedia.org/wiki/%D7%A0%D7%92%D7%96%D7%A8%D7%AA_%D7%97%D7%9C%D7%A7%D7%99%D7%AA) לפי $`s`$ בנקודה $`s = 0`$ קשורה לפונקציית גמא:



```math
\left. \frac{\partial}{\partial s} \zeta(s,a) \right|_{s=0} = \log\Gamma(a) - \frac{1}{2} \log(2\pi).
```



בפרט, $`\zeta'(0) = -\tfrac{1}{2} \log(2\pi)`$. הנוסחה היא של מתיאס לרך.[^17][^18]

## קשר לפונקציית תטא של יעקובי

אם $`\vartheta (z,\tau)`$ היא [פונקציית התטא](https://he.wikipedia.org/wiki/%D7%A4%D7%95%D7%A0%D7%A7%D7%A6%D7%99%D7%99%D7%AA_%D7%AA%D7%98%D7%90) של יעקובי, אז



```math
\int_0^\infty \left[\vartheta (z,it) -1 \right] t^{s/2} \frac{dt}{t} = \pi^{-(1-s)/2} \Gamma\left( \frac {1-s}{2} \right) \left[ \zeta(1-s, z) + \zeta(1-s, 1-z) \right]
```



עבור $`\operatorname{Re}(s) > 0`$ ו-$`z`$ מרוכב שאינו שלם. עבור $`z = n`$ שלם, הביטוי מצטמצם ל־



```math
\int_0^\infty \left[\vartheta (n,it) -1 \right] t^{s/2} \frac{dt}{t} = 2 \pi^{-(1-s)/2} \Gamma\left( \frac {1-s}{2} \right) \zeta(1-s) = 2 \pi^{-s/2} \Gamma\left( \frac {s}{2} \right) \zeta(s),
```



וזוהי המשוואה הפונקציונלית של פונקציית זטא של רימן בצורה שבה נתן אותה רימן במקור. ההבחנה בין $`z`$ שלם ללא שלם נובעת מכך שכאשר $`t\to 0`$, פונקציית התטא של יעקובי מתכנסת ל[מסרק דיראק](https://he.wikipedia.org/wiki/%D7%9E%D7%A1%D7%A8%D7%A7_%D7%93%D7%99%D7%A8%D7%90%D7%A7) במשתנה $`z`$.

## קשר לפונקציות L של דיריכלה

בנקודות רציונליות ניתן לבטא את פונקציית זטא של הורוויץ כצירוף ליניארי של [פונקציות L של דיריכלה](https://he.wikipedia.org/wiki/%D7%A4%D7%95%D7%A0%D7%A7%D7%A6%D7%99%D7%99%D7%AA_L_%D7%A9%D7%9C_%D7%93%D7%99%D7%A8%D7%99%D7%9B%D7%9C%D7%94), ולהפך. עבור $`a=1`$ היא מתלכדת עם פונקציית זטא של רימן, עבור $`a=1/2`$ היא שווה ל-$`(2^s-1)\zeta(s)`$, ועבור $`a = n/k`$ עם $`k>2`$, $`\gcd(n,k)=1`$ ו-$`0<n<k`$ מתקיים[^19]



```math
\zeta(s,n/k) = \frac{k^s}{\varphi(k)} \sum_\chi \overline{\chi}(n)L(s,\chi),
```



כאשר הסכום עובר על כל [קרקטרי דיריכלה](https://he.wikipedia.org/wiki/%D7%A7%D7%A8%D7%A7%D7%98%D7%A8_%D7%93%D7%99%D7%A8%D7%99%D7%9B%D7%9C%D7%94) מודולו $`k`$ ו-$`\varphi`$ היא [פונקציית אוילר](https://he.wikipedia.org/wiki/%D7%A4%D7%95%D7%A0%D7%A7%D7%A6%D7%99%D7%99%D7%AA_%D7%90%D7%95%D7%99%D7%9C%D7%A8). בכיוון ההפוך מתקיים הצירוף הליניארי



```math
L(s,\chi) = \frac {1}{k^s} \sum_{n=1}^k \chi(n)\, \zeta\left(s,\frac{n}{k}\right).
```



כמו כן מתקיים משפט הכפל



```math
k^s\zeta(s) = \sum_{n=1}^k \zeta\left(s,\frac{n}{k}\right),
```



שהכללה שימושית שלו היא "יחס ההתפלגות"[^20]



```math
\sum_{p=0}^{q-1}\zeta(s,a+p/q)=q^s\,\zeta(s,qa),
```



התקף כאשר $`q`$ הוא [מספר טבעי](https://he.wikipedia.org/wiki/%D7%9E%D7%A1%D7%A4%D7%A8_%D7%98%D7%91%D7%A2%D7%99) ו-$`1-qa`$ אינו מספר טבעי.

## אפסים

כאשר $`a=1`$ הפונקציה היא פונקציית זטא של רימן עצמה, וכאשר $`a=1/2`$ היא פונקציית זטא של רימן כפול פונקציה פשוטה של $`s`$; בשני המקרים חקר האפסים מוביל לבעיה הקשה של אפסי פונקציית זטא של רימן, ובפרט אין אפסים שחלקם הממשי גדול או שווה ל-1. לעומת זאת, אם $`0<a<1`$ ו-$`a\ne 1/2`$, יש לפונקציה אפסים ברצועה $`1 < \operatorname{Re}(s) < 1 + \varepsilon`$ לכל $`\varepsilon>0`$. את זה הוכיחו [דבנפורט](%D7%94%D7%A8%D7%95%D7%9C%D7%93%20%D7%93%D7%91%D7%A0%D7%A4%D7%95%D7%A8%D7%98.md) והנס היילברון עבור $`a`$ רציונלי או אי-רציונלי [טרנסצנדנטי](https://he.wikipedia.org/wiki/%D7%9E%D7%A1%D7%A4%D7%A8_%D7%98%D7%A8%D7%A0%D7%A1%D7%A6%D7%A0%D7%93%D7%A0%D7%98%D7%99),[^21] וקאסלס עבור $`a`$ אי-רציונלי [אלגברי](https://he.wikipedia.org/wiki/%D7%9E%D7%A1%D7%A4%D7%A8_%D7%90%D7%9C%D7%92%D7%91%D7%A8%D7%99).[^22][^23]

## ערכים רציונליים

פונקציית זטא של הורוויץ מופיעה במספר זהויות בולטות בנקודות רציונליות.[^24] בפרט, את ערכי פולינומי אוילר $`E_n(x)`$ בנקודות רציונליות ניתן לבטא באמצעותה:



```math
E_{2n-1}\left(\frac{p}{q}\right) = \left(-1\right)^n \frac{4(2n-1)!}{(2\pi q)^{2n}} \sum_{k=1}^q \zeta\left(2n,\frac{2k-1}{2q}\right) \cos \frac{(2k-1)\pi p}{q}
```





```math
E_{2n}\left(\frac{p}{q}\right) = \left(-1\right)^n \frac{4(2n)!}{(2\pi q)^{2n+1}} \sum_{k=1}^q \zeta\left(2n+1,\frac{2k-1}{2q}\right) \sin \frac{(2k-1)\pi p}{q}.
```



## שימושים

פונקציית זטא של הורוויץ מופיעה בתחומים רבים. השכיח ביותר הוא [תורת המספרים](https://he.wikipedia.org/wiki/%D7%AA%D7%95%D7%A8%D7%AA_%D7%94%D7%9E%D7%A1%D7%A4%D7%A8%D7%99%D7%9D), שבה התאוריה שלה העמוקה והמפותחת ביותר. היא מופיעה גם בחקר [פרקטל](https://he.wikipedia.org/wiki/%D7%A4%D7%A8%D7%A7%D7%98%D7%9C)ים ו[מערכות דינמיות](https://he.wikipedia.org/wiki/%D7%9E%D7%A2%D7%A8%D7%9B%D7%AA_%D7%93%D7%99%D7%A0%D7%9E%D7%99%D7%AA). ב[סטטיסטיקה](https://he.wikipedia.org/wiki/%D7%A1%D7%98%D7%98%D7%99%D7%A1%D7%98%D7%99%D7%A7%D7%94) שימושית היא מופיעה בחוק זיפף ובחוק זיפף-מנדלברוט. ב[פיזיקת חלקיקים](https://he.wikipedia.org/wiki/%D7%A4%D7%99%D7%96%D7%99%D7%A7%D7%AA_%D7%97%D7%9C%D7%A7%D7%99%D7%A7%D7%99%D7%9D) היא מופיעה בנוסחה של [ג'וליאן שווינגר](https://he.wikipedia.org/wiki/%D7%92%27%D7%95%D7%9C%D7%99%D7%90%D7%9F_%D7%A9%D7%95%D7%95%D7%99%D7%A0%D7%92%D7%A8) הנותנת תוצאה מדויקת לקצב [יצירת הזוגות](https://he.wikipedia.org/wiki/%D7%99%D7%A6%D7%99%D7%A8%D7%AA_%D7%96%D7%95%D7%92) של [אלקטרוני](https://he.wikipedia.org/wiki/%D7%90%D7%9C%D7%A7%D7%98%D7%A8%D7%95%D7%9F) דיראק בשדה חשמלי אחיד.[^25]

## מקרים פרטיים והכללות

עבור $`m`$ שלם חיובי, פונקציית זטא של הורוויץ קשורה ל[פונקציית הפוליגמא](https://he.wikipedia.org/wiki/%D7%A4%D7%95%D7%A0%D7%A7%D7%A6%D7%99%D7%99%D7%AA_%D7%A4%D7%95%D7%9C%D7%99%D7%92%D7%9E%D7%90):



```math
\psi^{(m)}(z)= (-1)^{m+1} m!\, \zeta (m+1,z).
```



פונקציית זטא של בארנס מכלילה את פונקציית זטא של הורוויץ. גם הטרנסצנדנט של לרך מכליל אותה:



```math
\Phi(z, s, q) = \sum_{k=0}^\infty \frac{z^k}{(k+q)^s}, \qquad \zeta(s,a) = \Phi(1, s, a).
```



עבור $`s`$ טבעי ו-$`a`$ שאינו טבעי, ניתן לבטא אותה גם באמצעות [פונקציה היפרגאומטרית](https://he.wikipedia.org/wiki/%D7%A4%D7%95%D7%A0%D7%A7%D7%A6%D7%99%D7%94_%D7%94%D7%99%D7%A4%D7%A8%D7%92%D7%90%D7%95%D7%9E%D7%98%D7%A8%D7%99%D7%AA):



```math
\zeta(s,a)=a^{-s}\cdot{}_{s+1}F_s(1,a,\ldots, a;a+1,\ldots, a+1;1).
```
