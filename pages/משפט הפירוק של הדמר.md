# משפט הפירוק של הדמר

ב[מתמטיקה](https://he.wikipedia.org/wiki/%D7%9E%D7%AA%D7%9E%D7%98%D7%99%D7%A7%D7%94), ובפרט ב[אנליזה מרוכבת](https://he.wikipedia.org/wiki/%D7%90%D7%A0%D7%9C%D7%99%D7%96%D7%94_%D7%9E%D7%A8%D7%95%D7%9B%D7%91%D7%AA), **משפט הפירוק של הדמר** קובע שכל [פונקציה שלמה](https://he.wikipedia.org/wiki/%D7%A4%D7%95%D7%A0%D7%A7%D7%A6%D7%99%D7%94_%D7%A9%D7%9C%D7%9E%D7%94) מסדר סופי אפשר לייצג כמכפלה שכוללת את האפסים שלה ואת האקספוננט של פולינום. המשפט נקרא על שם [ז'אק הדמר](https://he.wikipedia.org/wiki/%D7%96%27%D7%90%D7%A7_%D7%90%D7%93%D7%9E%D7%A8) (אדמר), שהוכיח אותו ב-1893 כחלק מהעבודה שהובילה להוכחת [משפט המספרים הראשוניים](https://he.wikipedia.org/wiki/%D7%9E%D7%A9%D7%A4%D7%98_%D7%94%D7%9E%D7%A1%D7%A4%D7%A8%D7%99%D7%9D_%D7%94%D7%A8%D7%90%D7%A9%D7%95%D7%A0%D7%99%D7%99%D7%9D).

אפשר לראות במשפט הרחבה של [המשפט היסודי של האלגברה](https://he.wikipedia.org/wiki/%D7%94%D7%9E%D7%A9%D7%A4%D7%98_%D7%94%D7%99%D7%A1%D7%95%D7%93%D7%99_%D7%A9%D7%9C_%D7%94%D7%90%D7%9C%D7%92%D7%91%D7%A8%D7%94), שלפיו כל פולינום מתפרק לגורמים ליניאריים, אחד לכל שורש. הוא קשור קשר הדוק ל**משפט הפירוק של ויירשטראס**, שאינו מוגבל לפונקציות שלמות מסדר סופי.

## הניסוח הפורמלי

נגדיר את **הגורמים הקנוניים של הדמר**



```math
E_p(z) = (1-z) \prod_{k=1}^p e^{z^k/k}, \qquad E_0(z) = 1 - z.
```

 לפונקציות שלמות מ[סדר](https://he.wikipedia.org/wiki/%D7%A4%D7%95%D7%A0%D7%A7%D7%A6%D7%99%D7%94_%D7%A9%D7%9C%D7%9E%D7%94) סופי $`\rho`$ יש ההצגה הקנונית של הדמר:[^1]



```math
f(z)=z^me^{Q(z)}\prod_{n=1}^\infty E_p(z/a_n),
```

 כאשר $`a_n`$ הם השורשים של $`f`$ שאינם אפס (כל אחד לפי ריבויו), $`m`$ הוא סדר האפס של $`f`$ ב-$`z = 0`$ ($`m = 0`$ אם $`f(0) \neq 0`$), $`Q`$ פולינום (שאת מעלתו נסמן $`q`$), ו-$`p`$ הוא המספר השלם האי-שלילי הקטן ביותר שעבורו הטור



```math
\sum_{n=1}^\infty\frac{1}{|a_n|^{p+1} }
```

 מתכנס. המספר השלם האי-שלילי $`g=\max\{p,q\}`$ נקרא **הגנוס** של הפונקציה השלמה $`f`$, ומתקיים



```math
g \leq \rho \leq g + 1.
```

 במילים אחרות: אם הסדר $`\rho`$ אינו שלם, אז $`g = \lfloor \rho \rfloor`$. אם הסדר שלם חיובי, יש שתי אפשרויות: $`g = \rho-1`$ או $`g = \rho`$.

## דוגמאות

- $`\sin`$, $`\cos`$ ו-$`\exp`$ הן פונקציות שלמות מגנוס $`g = \rho = 1`$. למשל, ל-$`e^z`$ אין אפסים ($`p = 0`$), ו-$`Q(z) = z`$ ($`q = 1`$).
- **הסינוס.** האפסים של $`\sin \pi z`$ הם השלמים. $`\sum 1/|n|`$ מתבדר אבל $`\sum 1/n^2`$ מתכנס, ולכן $`p = 1`$. כשמזווגים את $`n`$ ו-$`-n`$, הגורמים $`e^{\pm z/n}`$ מצטמצמים, ומתקבלת נוסחת אוילר



```math
\sin \pi z = \pi z\prod_{n=1}^\infty\left(1 - \frac{z^2}{n^2}\right).
```



- **פונקציית גמא.** ל-$`1/\Gamma(z)`$ יש אפסים פשוטים ב-$`0, -1, -2, \ldots`$, היא מסדר 1, וההצגה הקנונית שלה היא נוסחת ויירשטראס



```math
\frac{1}{\Gamma(z)} = z\,e^{\gamma z}\prod_{n=1}^\infty\left(1 + \frac zn\right)e^{-z/n},
```



  
כאשר $`\gamma`$ [קבוע אוילר–מסקרוני](https://he.wikipedia.org/wiki/%D7%A7%D7%91%D7%95%D7%A2_%D7%90%D7%95%D7%99%D7%9C%D7%A8-%D7%9E%D7%A1%D7%A7%D7%A8%D7%95%D7%A0%D7%99); כאן $`Q(z) = \gamma z`$.

עבור $`z = 0.37`$, שני הצדדים בשתי הנוסחאות שווים: $`\sin(0.37\pi) = 0.917755\ldots`$ ו-$`1/\Gamma(0.37) = 0.416051\ldots`$. (בדקנו בחישוב.)

### דוגמה מלאה: פונקציית קסי של רימן

[פונקציית קסי של רימן](https://he.wikipedia.org/wiki/%D7%A4%D7%95%D7%A0%D7%A7%D7%A6%D7%99%D7%99%D7%AA_%D7%A7%D7%A1%D7%99_%D7%A9%D7%9C_%D7%A8%D7%99%D7%9E%D7%9F) $`\xi(s) = \tfrac12 s(s-1)\pi^{-s/2}\Gamma(s/2)\zeta(s)`$ היא פונקציה שלמה מסדר 1, והאפסים שלה הם בדיוק האפסים הלא טריוויאליים $`\rho`$ של [פונקציית זטא של רימן](https://he.wikipedia.org/wiki/%D7%A4%D7%95%D7%A0%D7%A7%D7%A6%D7%99%D7%99%D7%AA_%D7%96%D7%98%D7%90_%D7%A9%D7%9C_%D7%A8%D7%99%D7%9E%D7%9F). לכן לפי משפט הדמר



```math
\xi(s) = e^{A + Bs}\prod_\rho\left(1 - \frac s\rho\right)e^{s/\rho}.
```

 זו הייתה המטרה המקורית של הדמר: ההצגה הזו היא הבסיס ל[נוסחה המפורשת](%D7%A0%D7%95%D7%A1%D7%97%D7%90%D7%95%D7%AA%20%D7%9E%D7%A4%D7%95%D7%A8%D7%A9%D7%95%D7%AA%20%D7%9C%D7%A4%D7%95%D7%A0%D7%A7%D7%A6%D7%99%D7%95%D7%AA%20L.md) של רימן–פון מנגולדט, ומשם להוכחת משפט המספרים הראשוניים. את הקבועים מחשבים כך:

- $`e^A = \xi(0) = \tfrac12`$ (כי $`\zeta(0) = -\tfrac12`$).
- $`B = \xi'(0)/\xi(0) = -\tfrac{\gamma}{2} - 1 + \tfrac12\log 4\pi = -0.0230957\ldots`$
- מהסימטריה $`\xi(s) = \xi(1-s)`$ נובע ש-$`B = -\sum_\rho \mathrm{Re}\,\frac1\rho`$ (כשמזווגים את $`\rho`$ ו-$`\bar\rho`$), כלומר



```math
\sum_\rho \frac{1}{\rho} = 1 + \frac{\gamma}{2} - \frac12\log 4\pi = 0.0230957\ldots
```

 בדיקה מספרית: אם $`\rho = \tfrac12 + i\gamma_n`$ (בהנחת השערת רימן, שנבדקה לאפסים האלה), אז $`\rho^{-1} + \bar\rho^{-1} = \frac{1}{1/4 + \gamma_n^2}`$. הסכום על 200 האפסים הראשונים הוא $`0.021035`$, ותוספת הערכת הזנב $`\sum_{\gamma \gt T}\gamma^{-2} \approx \frac{\log(T/2\pi) + 1}{2\pi T}`$ (מצפיפות האפסים $`\frac{1}{2\pi}\log\frac{T}{2\pi}`$) נותנת $`0.023100`$, לעומת הערך המדויק $`0.0230957`$. (בדקנו בחישוב.) ההתכנסות האיטית של הסכום משקפת את העובדה ש-$`\sum 1/|\rho|`$ מתבדר: $`p = 1`$, והגורמים $`e^{s/\rho}`$ הכרחיים.

הסדר $`\rho = 1`$ והגנוס 1 של $`\xi`$ הם גם מה שמאפשר לנסח את השערת רימן כהשתייכות של $`\Xi(z) = \xi(\tfrac12 + iz)`$ ל[מחלקת לגר–פויה](%D7%9E%D7%97%D7%9C%D7%A7%D7%AA%20%D7%9C%D7%92%D7%A8%E2%80%93%D7%A4%D7%95%D7%99%D7%94.md).

## מעריך ההתכנסות

נגדיר את **מעריך ההתכנסות** של שורשי $`f`$:[^2]



```math
\alpha = \limsup_{r\to\infty} \frac{\log N(f, r)}{\log r},
```

 כאשר $`N(f, r)`$ מספר השורשים בערך מוחלט קטן מ-$`r`$. כלומר, לכל $`\varepsilon \gt 0`$ מתקיים $`N(f, r) \ll r^{\alpha + \varepsilon}`$, ויש סדרה $`r_k`$ עם $`N(f, r_k) \gt r_k^{\alpha - \varepsilon}`$. ברור ש-$`\alpha\geq 0`$.

**משפט.** אם ל-$`f`$ אינסוף שורשים, אז



```math
\alpha = \inf\left\{\beta : \sum_k |a_k|^{-\beta} \lt \infty\right\} = \limsup_{k\to\infty} \frac{\log k}{\log |a_k|}.
```

 (שני השוויונות האלה עוסקים רק בהתנהגות של סדרה ממשית $`|a_1| \le |a_2| \le \cdots`$ ששואפת לאינסוף, ואין בהם אנליזה מרוכבת.) בנוסף, לפי [נוסחת ינסן](https://he.wikipedia.org/wiki/%D7%A0%D7%95%D7%A1%D7%97%D7%AA_%D7%99%D7%A0%D7%A1%D7%9F), $`\alpha \le \rho`$.

לדוגמה, עבור $`\xi`$: מספר האפסים עם $`|\mathrm{Im}\,\rho| \le T`$ הוא $`N(T) \sim \frac{T}{2\pi}\log\frac{T}{2\pi}`$ ([נוסחת רימן–פון מנגולדט](%D7%A0%D7%95%D7%A1%D7%97%D7%AA%20%D7%A8%D7%99%D7%9E%D7%9F-%D7%A4%D7%95%D7%9F%20%D7%9E%D7%A0%D7%92%D7%95%D7%9C%D7%93%D7%98.md)), ולכן $`\alpha = 1 = \rho`$; וגם $`\sum|\rho|^{-1}`$ מתבדר בעוד ש-$`\sum|\rho|^{-1-\varepsilon}`$ מתכנס.

## שימושים

בעזרת פירוק הדמר אפשר להוכיח מקרים פרטיים של [משפט פיקאר הקטן](https://he.wikipedia.org/wiki/%D7%9E%D7%A9%D7%A4%D7%98_%D7%A4%D7%99%D7%A7%D7%90%D7%A8_%D7%94%D7%A7%D7%98%D7%9F).[^3]

**משפט.** אם $`f`$ פונקציה שלמה לא קבועה מסדר סופי, אז היא מקבלת או את כל המישור המרוכב, או את כל המישור פרט לנקודה אחת.

**הוכחה.** אם $`f`$ אינה מקבלת את הערך $`z_0`$, אז לפי פירוק הדמר $`f(z) - z_0 = e^{Q(z)}`$ עבור פולינום לא קבוע $`Q`$. לפי המשפט היסודי של האלגברה, $`Q`$ מקבל כל ערך, ולכן $`f(z) - z_0`$ מקבלת כל ערך שונה מאפס. ∎

**משפט.** אם $`f`$ פונקציה שלמה לא קבועה מסדר סופי $`\rho`$ שאינו שלם, אז היא מקבלת כל ערך מרוכב אינסוף פעמים.

**הוכחה.** לכל $`w\in \mathbb C`$ צריך להראות של-$`f(z) - w`$ יש אינסוף שורשים. נכתוב את פירוק הדמר $`f(z) - w = e^{Q(z)} z^m \prod_k E_p(z/a_k)`$. אילו המכפלה הייתה סופית, הסדר היה $`\deg Q`$, מספר שלם. ∎

## הוכחה

ההוכחה כאן הולכת לפי ההצגה של קונוויי.[^4]

תהי $`f`$ פונקציה שלמה מסדר סופי $`\rho`$. אם ל-$`f`$ יש אפס מסדר $`m`$ בראשית, נכתוב $`f(z)=z^m f_0(z)`$ עם $`f_0(0)\ne 0`$. כפל בקבוע שונה מאפס אינו משנה את הסדר, ולכן מספיק להוכיח את המשפט תחת הנרמול $`f(0)=1`$, ולהחזיר את $`z^m`$ בסוף.

יהיו $`a_1, a_2, \ldots`$ האפסים השונים מאפס של $`f`$, עם ריבויים, מסודרים כך ש-$`|a_1|\le |a_2|\le\cdots`$, ויהי $`p=\lfloor \rho\rfloor`$. השלב הראשון הוא להראות ש-$`\sum_n|a_n|^{-p-1}\lt\infty`$. יהי $`n(r)`$ מספר האפסים של $`f`$ בעיגול $`|z|\lt r`$. לפי נוסחת ינסן מתקבלת הערכה מהצורה



```math
n(r)\log 2\le \log M(2r), \qquad M(r)=\max_{|z|=r}|f(z)|.
```

 כיוון ש-$`f`$ מסדר $`\rho`$, לכל $`\varepsilon\gt 0`$ ולכל $`r`$ גדול מספיק $`\log M(r)\le r^{\rho+\varepsilon}`$. נבחר $`\varepsilon`$ קטן מספיק כך ש-$`\rho+\varepsilon\lt p+1`$; אז $`n(r)=O(r^{\rho+\varepsilon})`$. כיוון ש-$`k\le n(|a_k|)`$, נקבל $`|a_k|\ge C k^{1/(\rho+\varepsilon)}`$, ולכן $`|a_k|^{-p-1}\le C' k^{-(p+1)/(\rho+\varepsilon)}`$, והמעריך מימין גדול מ-1. לכן הטור מתכנס.

לכן המכפלה הקנונית $`P(z)=\prod_{n}E_p(z/a_n)`$ מתכנסת במידה שווה על קבוצות קומפקטיות, ומגדירה פונקציה שלמה שהאפסים שלה הם בדיוק $`a_n`$ עם אותם ריבויים. לכן $`F = f/P`$ פונקציה שלמה בלי אפסים, וכיוון שהמישור המרוכב [פשוט קשר](https://he.wikipedia.org/wiki/%D7%A7%D7%91%D7%95%D7%A6%D7%94_%D7%A4%D7%A9%D7%95%D7%98%D7%AA_%D7%A7%D7%A9%D7%A8) יש פונקציה שלמה $`g`$ עם $`F=e^{g}`$, כלומר $`f=e^{g}P`$.

נשאר להראות ש-$`g`$ פולינום ממעלה לכל היותר $`p`$. לשם כך משתמשים בלמה הבאה על הנגזרת הלוגריתמית.

**למה.** אם $`f`$ שלמה מסדר סופי $`\rho`$, $`f(0)\ne0`$, ו-$`p`$ שלם עם $`p\gt\rho-1`$, אז מחוץ לאפסים של $`f`$



```math
\frac{d^p}{dz^p}\left(\frac{f'(z)}{f(z)}\right) = -p!\sum_{n=1}^{\infty}\frac{1}{(a_n-z)^{p+1} }.
```



מצד שני, כיוון ש-$`f=e^gP`$, מתקיים $`\frac{f'}{f}=g'+\frac{P'}{P}`$. לגורם בודד,



```math
\frac{d}{dz}\log E_p(z/a) = -\frac{1}{a-z}+\sum_{j=1}^{p}\frac{z^{j-1} }{a^j},
```

 ואחרי $`p`$ גזירות החלק הפולינומי נעלם, ולכן $`\frac{d^p}{dz^p}\left(\frac{P'}{P}\right) = -p!\sum_{n}\frac{1}{(a_n-z)^{p+1} }`$. השוואת שתי הנוסחאות נותנת $`g^{(p+1)}\equiv 0`$, כלומר $`g`$ פולינום ממעלה לכל היותר $`p`$. כשמחזירים את האפס בראשית מתקבל $`f(z)=z^m e^{Q(z)}\prod_{n}E_p(z/a_n)`$ עם $`\deg Q\le p=\lfloor\rho\rfloor`$. ∎
