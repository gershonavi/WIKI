# נגזרת אריתמטית

ב[תורת המספרים](https://he.wikipedia.org/wiki/%D7%AA%D7%95%D7%A8%D7%AA_%D7%94%D7%9E%D7%A1%D7%A4%D7%A8%D7%99%D7%9D), **הנגזרת האריתמטית** (ב[אנגלית](https://he.wikipedia.org/wiki/%D7%90%D7%A0%D7%92%D7%9C%D7%99%D7%AA): arithmetic derivative או number derivative) היא [פונקציה](https://he.wikipedia.org/wiki/%D7%A4%D7%95%D7%A0%D7%A7%D7%A6%D7%99%D7%94) המוגדרת על [מספרים שלמים](https://he.wikipedia.org/wiki/%D7%9E%D7%A1%D7%A4%D7%A8_%D7%A9%D7%9C%D7%9D) על בסיס ה[פירוק לגורמים ראשוניים](https://he.wikipedia.org/wiki/%D7%94%D7%9E%D7%A9%D7%A4%D7%98_%D7%94%D7%99%D7%A1%D7%95%D7%93%D7%99_%D7%A9%D7%9C_%D7%94%D7%90%D7%A8%D7%99%D7%AA%D7%9E%D7%98%D7%99%D7%A7%D7%94), באנלוגיה ל[כלל המכפלה](https://he.wikipedia.org/wiki/%D7%9B%D7%9C%D7%9C_%D7%94%D7%9E%D7%9B%D7%A4%D7%9C%D7%94) של ה[נגזרת](https://he.wikipedia.org/wiki/%D7%A0%D7%92%D7%96%D7%A8%D7%AA) של פונקציה ב[אנליזה מתמטית](https://he.wikipedia.org/wiki/%D7%90%D7%A0%D7%9C%D7%99%D7%96%D7%94_%D7%9E%D7%AA%D7%9E%D7%98%D7%99%D7%AA).

יש גרסאות רבות של "נגזרות אריתמטיות". מלבד זו שבערך זה, יש למשל את הנגזרת האריתמטית של איהרה ואת הנגזרות האריתמטיות של בויום.

## היסטוריה מוקדמת

את הנגזרת האריתמטית הציג המתמטיקאי הספרדי חוסה מינגוט שלי ב-1911.[^1][^2] הנגזרת האריתמטית הופיעה גם בתחרות פטנם של 1950.[^3]

## הגדרה

עבור [מספרים טבעיים](https://he.wikipedia.org/wiki/%D7%9E%D7%A1%D7%A4%D7%A8_%D7%98%D7%91%D7%A2%D7%99) $`n`$, הנגזרת האריתמטית $`D(n)`$ מוגדרת כך:[^4]

- $`D(p) = 1`$ לכל [ראשוני](https://he.wikipedia.org/wiki/%D7%9E%D7%A1%D7%A4%D7%A8_%D7%A8%D7%90%D7%A9%D7%95%D7%A0%D7%99) $`p`$.
- $`D(mn) = D(m)n + mD(n)`$ לכל $`m, n \in \mathbb N`$ (כלל לייבניץ).

## הרחבות מעבר למספרים הטבעיים

אדוארד ברבו הרחיב את ה[תחום](https://he.wikipedia.org/wiki/%D7%AA%D7%97%D7%95%D7%9D_%D7%A9%D7%9C_%D7%A4%D7%95%D7%A0%D7%A7%D7%A6%D7%99%D7%94) לכל המספרים השלמים, והראה שהבחירה $`D(-n) = -D(n)`$ מרחיבה את התחום לשלמים באופן יחיד ועקבי עם נוסחת המכפלה. ברבו הרחיב את הנגזרת גם ל[מספרים הרציונליים](https://he.wikipedia.org/wiki/%D7%9E%D7%A1%D7%A4%D7%A8_%D7%A8%D7%A6%D7%99%D7%95%D7%A0%D7%9C%D7%99), והראה שכלל המנה המוכר נותן נגזרת מוגדרת היטב על $`\mathbb Q`$:



```math
D\left(\frac{m}{n}\right) = \frac{D(m)n-m D(n)}{n^2} .
```

[^5][^6]

ויקטור אופנרובסקי ובו אולנדר הרחיבו אותה למספרים [אי-רציונליים](https://he.wikipedia.org/wiki/%D7%9E%D7%A1%D7%A4%D7%A8_%D7%90%D7%99-%D7%A8%D7%A6%D7%99%D7%95%D7%A0%D7%9C%D7%99) שאפשר לכתוב כמכפלה של ראשוניים בחזקות רציונליות כלשהן, וכך אפשר לחשב ביטויים כמו $`D(\sqrt{3})`$.[^7]

אפשר להרחיב את הנגזרת האריתמטית גם לכל [תחום פריקות יחידה](https://he.wikipedia.org/wiki/%D7%AA%D7%97%D7%95%D7%9D_%D7%A4%D7%A8%D7%99%D7%A7%D7%95%D7%AA_%D7%99%D7%97%D7%99%D7%93%D7%94),[^8] כמו [השלמים של גאוס](https://he.wikipedia.org/wiki/%D7%97%D7%95%D7%92_%D7%94%D7%A9%D7%9C%D7%9E%D7%99%D7%9D_%D7%A9%D7%9C_%D7%92%D7%90%D7%95%D7%A1) והשלמים של אייזנשטיין, ולשדה השברים שלו. אם תחום פריקות היחידה הוא [חוג פולינומים](https://he.wikipedia.org/wiki/%D7%97%D7%95%D7%92_%D7%A4%D7%95%D7%9C%D7%99%D7%A0%D7%95%D7%9E%D7%99%D7%9D), הנגזרת האריתמטית מתלכדת עם הגזירה על חוג הפולינומים הזה. לדוגמה, הנגזרת הרגילה היא הנגזרת האריתמטית בחוגים של [פולינומים](https://he.wikipedia.org/wiki/%D7%A4%D7%95%D7%9C%D7%99%D7%A0%D7%95%D7%9D) ממשיים ומרוכבים במשתנה אחד ובשדות של [הפונקציות הרציונליות](https://he.wikipedia.org/wiki/%D7%A4%D7%95%D7%A0%D7%A7%D7%A6%D7%99%D7%94_%D7%A8%D7%A6%D7%99%D7%95%D7%A0%D7%9C%D7%99%D7%AA) המתאימות; אפשר להוכיח זאת בעזרת [המשפט היסודי של האלגברה](https://he.wikipedia.org/wiki/%D7%94%D7%9E%D7%A9%D7%A4%D7%98_%D7%94%D7%99%D7%A1%D7%95%D7%93%D7%99_%D7%A9%D7%9C_%D7%94%D7%90%D7%9C%D7%92%D7%91%D7%A8%D7%94).

הנגזרת האריתמטית הורחבה גם ל[חוג השלמים מודולו n](https://he.wikipedia.org/wiki/%D7%97%D7%A9%D7%91%D7%95%D7%9F_%D7%9E%D7%95%D7%93%D7%95%D7%9C%D7%A8%D7%99).[^9]

## תכונות בסיסיות

מכלל לייבניץ נובע ש-$`D(0) = 0`$ (מציבים $`m = n = 0`$) ו-$`D(1) = 0`$ (מציבים $`m = n = 1`$).

גם **כלל החזקה** תקף לנגזרת האריתמטית. לכל מספרים שלמים $`k`$ ו-$`n \ge 0`$:



```math
D(k^n) = nk^{n-1} D(k).
```

 מכאן אפשר לחשב את הנגזרת מתוך הפירוק לגורמים ראשוניים של מספר שלם $`x = \prod_{p \in \mathbb{P}} p^{n_p}`$ (כאן $`n_p = \nu_p(x)`$ היא ההערכה ה-$`p`$-אדית של $`x`$):



```math
D(x) = \sum_{p \in \mathbb{P}} \frac{x}{p^{n_p}} n_p \, p^{n_p-1} D(p) = \sum_{p \mid x,\ p \in \mathbb{P}} n_p \frac x p D(p) = x \sum_{p \mid x,\ p \in \mathbb{P}} \frac {n_p} {p} D(p).
```



נוסחה זו מראה שאם יודעים את הנגזרת של כל המספרים הראשוניים, הנגזרת ידועה לחלוטין. למעשה, משפחת הנגזרות החלקיות האריתמטיות $`\frac \partial {\partial p}`$ ביחס לראשוני $`p`$, המוגדרות על ידי $`\frac \partial {\partial p}(q)=0`$ לכל ראשוני $`q \ne p`$ ו-$`\frac \partial {\partial p}(p)=1`$, מאפשרת לכתוב כל נגזרת כסכום אינסופי (לא אמיתי). עבור נגזרת חלקית זו מתקיים $`\frac {\partial x}{\partial p} = n_p \frac x p`$.

בדרך כלל לוקחים את הנגזרת שבה $`D(p)=1`$ לכל ראשוני $`p`$, ואז



```math
D=\sum_{p \in \mathbb{P}}\frac \partial {\partial p}, \qquad D(x)= x \sum_{p \in \mathbb{P}} \frac {n_p} p.
```



עם נגזרת זו מתקבל, למשל,



```math
D(60) = D(2^2 \cdot 3 \cdot 5) = 60 \cdot \left(\frac{2}{2} + \frac{1}{3} + \frac{1}{5}\right) = 92,
```

 או



```math
D(81) = D(3^4) = 4\cdot 3^3\cdot D(3) = 4\cdot 27\cdot 1 = 108.
```

 סדרת הנגזרות של $`x = 0, 1, 2, \ldots`$ מתחילה כך (סדרה [A003415](https://oeis.org/A003415) ב-OEIS):



```math
0, 0, 1, 1, 4, 1, 5, 1, 12, 6, 7, 1, 16, 1, 9, \ldots
```



## פונקציות קשורות

**הנגזרת הלוגריתמית**



```math
\operatorname{ld}(x)=\frac{D(x)}{x} = \sum_{p \mid x,\ p \in \mathbb{P}} \frac {\nu_p(x)} {p}
```

 היא [פונקציה אדיטיבית לחלוטין](%D7%A4%D7%95%D7%A0%D7%A7%D7%A6%D7%99%D7%94%20%D7%90%D7%93%D7%99%D7%98%D7%99%D7%91%D7%99%D7%AA%20%28%D7%AA%D7%95%D7%A8%D7%AA%20%D7%94%D7%9E%D7%A1%D7%A4%D7%A8%D7%99%D7%9D%29.md): $`\operatorname{ld}(x \cdot y) = \operatorname{ld}(x)+\operatorname{ld}(y)`$.

יהי $`p`$ ראשוני. **הנגזרת החלקית האריתמטית** של $`x`$ ביחס ל-$`p`$ מוגדרת כ-$`D_p(x) = \frac {\nu_p(x)} {p} x`$. לכן הנגזרת האריתמטית של $`x`$ היא $`D(x) = \sum_{p \mid x} D_p(x)`$.

תהי $`S`$ קבוצה לא ריקה של ראשוניים. **תת-הנגזרת האריתמטית** של $`x`$ ביחס ל-$`S`$ מוגדרת כ-$`D_S(x) = \sum_{p \mid x,\ p \in S} D_p(x)`$. אם $`S`$ היא קבוצת כל הראשוניים, אז $`D_S(x) = D(x)`$, הנגזרת האריתמטית הרגילה. אם $`S=\{p\}`$, אז $`D_S(x) = D_p(x)`$, הנגזרת החלקית האריתמטית.

פונקציה אריתמטית $`f`$ נקראת **לייבניץ-אדיטיבית** אם יש [פונקציה כפלית לחלוטין](%D7%A4%D7%95%D7%A0%D7%A7%D7%A6%D7%99%D7%94%20%D7%9B%D7%A4%D7%9C%D7%99%D7%AA%20%D7%9C%D7%97%D7%9C%D7%95%D7%98%D7%99%D7%9F.md) $`h_f`$ כך ש-$`f(mn) = f(m)h_f(n)+f(n)h_f(m)`$ לכל מספרים שלמים חיוביים $`m`$ ו-$`n`$. מניע למושג זה הוא שפונקציות לייבניץ-אדיטיביות הן הכללות של הנגזרת האריתמטית $`D`$; כלומר, $`D`$ היא לייבניץ-אדיטיבית עם $`h_D(n)=n`$.

הפונקציה $`\delta`$ המופיעה בסעיף 3.5 של הספר של שנדור ואטנסוב היא בדיוק הנגזרת האריתמטית הרגילה $`D`$.

## אי-שוויונות וחסמים

ברבו בחן חסמים על הנגזרת האריתמטית[^10] ומצא ש-



```math
D(n) \leq \frac{n \log_2 n}{2}
```

 ו-



```math
D(n) \geq \Omega(n)\, n^{\frac{\Omega(n)-1}{\Omega(n)}},
```

 כאשר $`\Omega(n)`$, אחת מ[פונקציות האומגה הראשוניות](%D7%A4%D7%95%D7%A0%D7%A7%D7%A6%D7%99%D7%95%D7%AA%20%D7%90%D7%95%D7%9E%D7%92%D7%94%20%D7%A8%D7%90%D7%A9%D7%95%D7%A0%D7%99%D7%95%D7%AA.md), היא מספר הגורמים הראשוניים של $`n`$ (עם ריבוי). בשני החסמים יש שוויון כאשר $`n`$ הוא חזקה של 2.

דאל, אולסון ולויקו מצאו שהנגזרת האריתמטית של מספרים טבעיים חסומה על ידי[^11]



```math
D(n) \leq \frac{n \log_p n}{p},
```

 כאשר $`p`$ הוא הראשוני הקטן ביותר המחלק את $`n`$, ויש שוויון כאשר $`n`$ הוא חזקה של $`p`$.

לויקו, אולסון ודאל מצאו שאי אפשר למצוא חסמים דומים לנגזרת האריתמטית המורחבת למספרים הרציונליים: הם הוכיחו שבין כל שני מספרים רציונליים יש מספרים רציונליים אחרים עם נגזרות גדולות או קטנות כרצוננו. (פירוש הדבר שהנגזרת האריתמטית אינה [פונקציה רציפה](https://he.wikipedia.org/wiki/%D7%A4%D7%95%D7%A0%D7%A7%D7%A6%D7%99%D7%94_%D7%A8%D7%A6%D7%99%D7%A4%D7%94) מ-$`\mathbb{Q}`$ ל-$`\mathbb{Q}`$.)[^12]

## סדר הממוצע

מתקיים



```math
\sum_{n \le x} \frac{D(n)}{n} = T_0 x + O(\log x \log\log x)
```

 ו-



```math
\sum_{n \le x} D(n) = \frac{1}{2}T_0 x^2 + O(x^{1+\delta})
```

 לכל $`\delta > 0`$, כאשר



```math
T_0 = \sum_p \frac{1}{p(p-1)} \approx 0.7732 .
```

 (ראו גם [סדר ממוצע של פונקציה אריתמטית](%D7%A1%D7%93%D7%A8%20%D7%9E%D7%9E%D7%95%D7%A6%D7%A2%20%D7%A9%D7%9C%20%D7%A4%D7%95%D7%A0%D7%A7%D7%A6%D7%99%D7%94%20%D7%90%D7%A8%D7%99%D7%AA%D7%9E%D7%98%D7%99%D7%AA.md).)

## חשיבות לתורת המספרים

אופנרובסקי ואולנדר תיארו את הקשר של הפונקציה להשערות מפורסמות בתורת המספרים, כמו [השערת המספרים הראשוניים התאומים](https://he.wikipedia.org/wiki/%D7%94%D7%A9%D7%A2%D7%A8%D7%AA_%D7%94%D7%9E%D7%A1%D7%A4%D7%A8%D7%99%D7%9D_%D7%94%D7%A8%D7%90%D7%A9%D7%95%D7%A0%D7%99%D7%99%D7%9D_%D7%94%D7%AA%D7%90%D7%95%D7%9E%D7%99%D7%9D), השערת השלשות הראשוניות ו[השערת גולדבך](https://he.wikipedia.org/wiki/%D7%94%D7%A9%D7%A2%D7%A8%D7%AA_%D7%92%D7%95%D7%9C%D7%93%D7%91%D7%9A). לדוגמה, השערת גולדבך גוררת שלכל $`k > 1`$ יש $`n`$ כך ש-$`D(n) = 2k`$ (כי אם $`2k = p + q`$ עם $`p, q`$ ראשוניים, אז $`D(pq) = p + q`$). השערת הראשוניים התאומים גוררת שיש אינסוף $`k`$ שעבורם $`D^2(k) = 1`$ (אם $`p`$ ו-$`p+2`$ ראשוניים, אז $`D(2p) = p+2`$ ו-$`D(p+2) = 1`$).[^13]
