# מספר וולסטנהולם

*אין לבלבל עם [ראשוני וולסטנהולם](https://he.wikipedia.org/wiki/%D7%A8%D7%90%D7%A9%D7%95%D7%A0%D7%99_%D7%95%D7%95%D7%9C%D7%A1%D7%98%D7%A0%D7%94%D7%95%D7%9C%D7%9D).* ב[מתמטיקה](https://he.wikipedia.org/wiki/%D7%9E%D7%AA%D7%9E%D7%98%D7%99%D7%A7%D7%94), **מספר וולסטנהולם** הוא [מספר](https://he.wikipedia.org/wiki/%D7%9E%D7%A1%D7%A4%D7%A8_%D7%98%D7%91%D7%A2%D7%99) שהוא ה[מונה](https://he.wikipedia.org/wiki/%D7%9E%D7%95%D7%A0%D7%94) של ה[מספר ההרמוני](https://he.wikipedia.org/wiki/%D7%9E%D7%A1%D7%A4%D7%A8_%D7%94%D7%A8%D7%9E%D7%95%D7%A0%D7%99) המוכלל



```math
H_{n,2} = \sum_{k=1}^n \frac1{k^2} = 1 + \frac14 + \frac19 + \cdots + \frac1{n^2},
```

 כשהשבר מצומצם.

המספרים הראשונים כאלה הם 1, 5, 49, 205, 5269, 5369, 266681, 1077749, ... ((סדרה [A007406](https://oeis.org/A007406) ב-OEIS); בדקנו בחישוב).

*דוגמה:* $`H_{4,2} = 1 + \tfrac14 + \tfrac19 + \tfrac1{16} = \tfrac{144 + 36 + 16 + 9}{144} = \tfrac{205}{144}`$, ולכן מספר הוולסטנהולם הרביעי הוא 205. באותו אופן $`H_{3,2} = \tfrac{49}{36}`$ ו-$`H_{6,2} = \tfrac{5369}{3600}`$.

המספרים נקראים על שם ג'וזף וולסטנהולם, שהוכיח את [משפט וולסטנהולם](%D7%9E%D7%A9%D7%A4%D7%98%20%D7%95%D7%95%D7%9C%D7%A1%D7%98%D7%A0%D7%94%D7%95%D7%9C%D7%9D.md) על יחסים מודולריים של המספרים ההרמוניים המוכללים.[^1] חלק מהמשפט אומר שלכל ראשוני $`p \ge 5`$, מספר הוולסטנהולם ה-$`(p-1)`$-י, כלומר המונה של $`H_{p-1,2}`$, מתחלק ב-$`p`$. למשל:

- $`p = 5`$: $`205 = 5\cdot41`$;
- $`p = 7`$: $`5369 = 7\cdot13\cdot59`$.

(בדקנו זאת לכל הראשוניים $`5 \le p \lt 30`$; בטווח הזה אף אחד מהמונים אינו מתחלק ב-$`p^2`$.) *הסבר:* מודולו $`p`$, ההופכיים $`1/k^2`$ עבור $`k = 1, \ldots, p-1`$ עוברים על ריבועי כל השאריות השונות מאפס, ולכן $`H_{p-1,2} \equiv \sum_{k=1}^{p-1}k^2 = \tfrac{(p-1)p(2p-1)}{6} \equiv 0 \pmod p`$ כש-$`p \ge 5`$.

הצורה הידועה יותר של משפט וולסטנהולם עוסקת במספרים ההרמוניים הרגילים: המונה של $`H_{p-1} = 1 + \tfrac12 + \cdots + \tfrac1{p-1}`$ מתחלק ב-$`p^2`$ לכל ראשוני $`p \ge 5`$ (למשל $`H_4 = \tfrac{25}{12}`$). שתי הטענות קשורות: $`2H_{p-1} \equiv -p\,H_{p-1,2} \pmod{p^3}`$, ולכן $`p \mid H_{p-1,2}`$ שקול ל-$`p^2 \mid H_{p-1}`$. הראשוניים שעבורם המונה של $`H_{p-1,2}`$ מתחלק ב-$`p^2`$ (ואז המונה של $`H_{p-1}`$ מתחלק ב-$`p^3`$) הם ראשוני וולסטנהולם; הידועים הם 16843 ו-2124679.
