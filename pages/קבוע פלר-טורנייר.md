# קבוע פלר-טורנייר

ב[מתמטיקה](https://he.wikipedia.org/wiki/%D7%9E%D7%AA%D7%9E%D7%98%D7%99%D7%A7%D7%94), **קבוע פלר–טורנייר** $`C_\mathrm{FT}`$ (ב[אנגלית](https://he.wikipedia.org/wiki/%D7%90%D7%A0%D7%92%D7%9C%D7%99%D7%AA): Feller–Tornier constant) הוא ה[צפיפות](https://he.wikipedia.org/wiki/%D7%A6%D7%A4%D7%99%D7%A4%D7%95%D7%AA_%28%D7%AA%D7%95%D7%A8%D7%AA_%D7%94%D7%9E%D7%A1%D7%A4%D7%A8%D7%99%D7%9D%29) של קבוצת כל המספרים השלמים החיוביים שיש להם מספר זוגי של גורמים ראשוניים שונים המופיעים בחזקה גדולה מ-1 (תוך התעלמות מגורמים ראשוניים המופיעים בחזקה ראשונה בלבד).[^1] הקבוע קרוי על שם [ויליאם פלר](https://he.wikipedia.org/wiki/%D7%95%D7%99%D7%9C%D7%99%D7%90%D7%9D_%D7%A4%D7%9C%D7%A8) (1906–1970) ואֶרהרד טורנייר (1894–1982).[^2]



```math
\begin{align} C_\mathrm{FT} & ={1\over2}+\left( {1\over2} \prod_{n=1}^\infty \left(1-{2 \over p_n^2} \right) \right) \\ & = { {1}\over{2} }\left(1+ \prod_{n=1}^\infty \left(1 - { {2}\over{p_n^2} } \right) \right) \\ & = {1\over2}\left(1+{ {1}\over{\zeta(2)} } \prod_{n=1}^\infty \left( 1-{ {1}\over{p_n^2 -1} } \right) \right) \\ & = {1\over2}+{ {3}\over{\pi^2} } \prod_{n=1}^\infty \left( 1-{ {1} \over {p_n^2 -1} } \right)= 0.66131704946\ldots \end{align}
```

 (סדרה [A065493](https://oeis.org/A065493) ב-OEIS)

לדוגמה, ב-$`72 = 2^3 \cdot 3^2`$ שני גורמים ראשוניים מופיעים בחזקה גדולה מ-1 (מספר זוגי), ולכן 72 נספר; ב-$`12 = 2^2 \cdot 3`$ רק גורם אחד כזה, ולכן 12 אינו נספר; וכל מספר [חופשי מריבועים](https://he.wikipedia.org/wiki/%D7%97%D7%95%D7%A4%D7%A9%D7%99_%D7%9E%D7%A8%D7%99%D7%91%D7%95%D7%A2%D7%99%D7%9D) נספר (אפס גורמים כאלה).

## הסבר לנוסחה

נסמן ב-$`\omega_2(k)`$ את מספר הראשוניים $`p`$ כך ש-$`p^2 \mid k`$. ההסתברות ש-$`p^2`$ מחלק מספר "אקראי" היא $`1/p^2`$, והמאורעות עבור ראשוניים שונים בלתי תלויים במובן של צפיפות. לכן הצפיפות של $`\{k : (-1)^{\omega_2(k)} = 1\}`$ היא $`\tfrac12\left(1 + \mathbb E(-1)^{\omega_2}\right)`$, ו-



```math
\mathbb E (-1)^{\omega_2} = \prod_p \left(\left(1 - \frac{1}{p^2}\right) - \frac{1}{p^2}\right) = \prod_p\left(1 - \frac{2}{p^2}\right).
```

 השוויון השלישי נובע מ-$`1 - \frac{2}{p^2} = \left(1 - \frac{1}{p^2}\right)\left(1 - \frac{1}{p^2 - 1}\right)`$ ומ[מכפלת אוילר](https://he.wikipedia.org/wiki/%D7%9E%D7%9B%D7%A4%D7%9C%D7%AA_%D7%90%D7%95%D7%99%D7%9C%D7%A8) $`\prod_p (1 - p^{-2}) = 1/\zeta(2) = 6/\pi^2`$.

## ניסוח בעזרת סוגרי אייברסון

[סוגרי אייברסון](https://he.wikipedia.org/wiki/%D7%A1%D7%95%D7%92%D7%A8%D7%99_%D7%90%D7%99%D7%99%D7%91%D7%A8%D7%A1%D7%95%D7%9F) מוגדרים כך:



```math
[P] = \begin{cases} 1 & \text{if } P \text{ is true,} \\ 0 & \text{if } P \text{ is false.} \end{cases}
```

 בסימונים אלה,



```math
C_\mathrm{FT}= \lim_{n\to \infty} \frac{1}{n}\sum_{k=1}^n [\omega_2(k) \equiv 0 \bmod 2].
```

 (בערך האנגלי מופיעה כאן [פונקציית אומגה הגדולה](%D7%A4%D7%95%D7%A0%D7%A7%D7%A6%D7%99%D7%95%D7%AA%20%D7%90%D7%95%D7%9E%D7%92%D7%94%20%D7%A8%D7%90%D7%A9%D7%95%D7%A0%D7%99%D7%95%D7%AA.md) $`\Omega(k)`$, מספר הגורמים הראשוניים של $`k`$ עם ריבוי. זו טעות: הצפיפות של המספרים שבהם $`\Omega(k)`$ זוגי היא $`1/2`$, שקול ל[משפט המספרים הראשוניים](https://he.wikipedia.org/wiki/%D7%9E%D7%A9%D7%A4%D7%98_%D7%94%D7%9E%D7%A1%D7%A4%D7%A8%D7%99%D7%9D_%D7%94%D7%A8%D7%90%D7%A9%D7%95%D7%A0%D7%99%D7%99%D7%9D). בחישוב עד $`2 \cdot 10^6`$, שיעור המספרים שבהם $`\omega_2(k)`$ זוגי הוא 0.6614, ואילו שיעור המספרים שבהם $`\Omega(k)`$ זוגי הוא 0.4997.)

## פונקציית זטא הראשונית

[פונקציית זטא הראשונית](%D7%A4%D7%95%D7%A0%D7%A7%D7%A6%D7%99%D7%99%D7%AA%20%D7%96%D7%98%D7%90%20%D7%94%D7%A8%D7%90%D7%A9%D7%95%D7%A0%D7%99%D7%AA.md) $`P`$ מוגדרת כך:



```math
P(s) = \sum_{p \text{ prime} } \frac 1 {p^s}.
```

 קבוע פלר–טורנייר מקיים



```math
C_\mathrm{FT}= {1\over2} \left( 1+ \exp \left( -\sum_{n=1}^\infty {2^n P(2n) \over n} \right) \right).
```

 (זה נובע מלקיחת לוגריתם במכפלה: $`\log\left(1 - \frac{2}{p^2}\right) = -\sum_{n \ge 1}\frac{2^n}{n\,p^{2n} }`$.)
