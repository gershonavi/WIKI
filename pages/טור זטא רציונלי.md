# טור זטא רציונלי

ב[מתמטיקה](https://he.wikipedia.org/wiki/%D7%9E%D7%AA%D7%9E%D7%98%D7%99%D7%A7%D7%94), **טור זטא רציונלי** (ב[אנגלית](https://he.wikipedia.org/wiki/%D7%90%D7%A0%D7%92%D7%9C%D7%99%D7%AA): rational zeta series) הוא הצגה של [מספר ממשי](https://he.wikipedia.org/wiki/%D7%9E%D7%A1%D7%A4%D7%A8_%D7%9E%D7%9E%D7%A9%D7%99) כלשהו כטור המורכב מ[מספרים רציונליים](https://he.wikipedia.org/wiki/%D7%9E%D7%A1%D7%A4%D7%A8_%D7%A8%D7%A6%D7%99%D7%95%D7%A0%D7%9C%D7%99) ומערכים של [פונקציית זטא של רימן](https://he.wikipedia.org/wiki/%D7%A4%D7%95%D7%A0%D7%A7%D7%A6%D7%99%D7%99%D7%AA_%D7%96%D7%98%D7%90_%D7%A9%D7%9C_%D7%A8%D7%99%D7%9E%D7%9F) או של [פונקציית זטא של הורוויץ](%D7%A4%D7%95%D7%A0%D7%A7%D7%A6%D7%99%D7%99%D7%AA%20%D7%96%D7%98%D7%90%20%D7%A9%D7%9C%20%D7%94%D7%95%D7%A8%D7%95%D7%95%D7%99%D7%A5.md). ליתר דיוק, בהינתן מספר ממשי $`x`$, טור הזטא הרציונלי של $`x`$ נתון על ידי



```math
x=\sum_{n=2}^\infty q_n \zeta (n,m),
```

 כאשר כל $`q_n`$ מספר רציונלי, הערך $`m`$ קבוע, ו-$`\zeta(s, m)`$ היא פונקציית זטא של הורוויץ. לא קשה להראות שאפשר לפתח כל מספר ממשי $`x`$ בצורה כזו. (**רמז, נוסף בתרגום:** $`\zeta(n,m) \approx m^{-n}`$ קטן מאוד כש-$`n`$ גדל, ולכן אפשר לבחור את $`q_n`$ בזה אחר זה באלגוריתם חמדן, כך שהשארית תקטן לאפס.)

כל הזהויות במאמר זה נבדקו מספרית בדיוק של 15 ספרות לפחות. בשלוש מהן נמצאו טעויות בערך האנגלי, והן מתוקנות כאן ומסומנות.

## טורים אלמנטריים

עבור שלם $`m>1`$ מתקיים



```math
x=\sum_{n=2}^\infty q_n \left[\zeta(n)- \sum_{k=1}^{m-1} k^{-n}\right].
```

 עבור $`m=2`$, לכמה מספרים מעניינים יש הצגה פשוטה כטור זטא רציונלי:



```math
1=\sum_{n=2}^\infty \left[\zeta(n)-1\right]
```

 ו



```math
1-\gamma=\sum_{n=2}^\infty \frac{1}{n}\left[\zeta(n)-1\right],
```

 כאשר $`\gamma`$ הוא [קבוע אוילר–מסקרוני](https://he.wikipedia.org/wiki/%D7%A7%D7%91%D7%95%D7%A2_%D7%90%D7%95%D7%99%D7%9C%D7%A8-%D7%9E%D7%A1%D7%A7%D7%A8%D7%95%D7%A0%D7%99).

(**הוכחת הזהות הראשונה, נוסף בתרגום:** $`\zeta(n) - 1 = \sum_{k\ge2}k^{-n}`$. מחליפים את סדר הסכימה: $`\sum_{n\ge2}\sum_{k\ge2}k^{-n} = \sum_{k\ge2}\frac{k^{-2} }{1-k^{-1} } = \sum_{k\ge2}\frac{1}{k(k-1)} = \sum_{k\ge2}\Big(\frac{1}{k-1}-\frac1k\Big) = 1`$, [טור טלסקופי](https://he.wikipedia.org/wiki/%D7%98%D7%95%D7%A8_%D7%98%D7%9C%D7%A1%D7%A7%D7%95%D7%A4%D7%99).)

הטור



```math
\log 2 =\sum_{n=1}^\infty \frac{1}{n}\left[\zeta(2n)-1\right]
```

 נובע מסכימת התפלגות גאוס–קוזמין. יש גם טורים עבור $`\pi`$:



```math
\log \pi =\sum_{n=2}^\infty \frac{2(3/2)^n-3}{n}\left[\zeta(n)-1\right]
```

 ו



```math
\frac{13}{30} - \frac{\pi}{8} =\sum_{n=1}^\infty \frac{1}{4^{2n} }\left[\zeta(2n)-1\right],
```

 שבולט בזכות ההתכנסות המהירה שלו. הטור האחרון נובע מהזהות הכללית



```math
\sum_{n=1}^\infty (-1)^{n} t^{2n} \left[\zeta(2n)-1\right] =
\frac{t^2}{1+t^2} + \frac{1-\pi t}{2} - \frac {\pi t}{e^{2\pi t} -1},
```

 שנובעת בתורה מה[פונקציה היוצרת](https://he.wikipedia.org/wiki/%D7%A4%D7%95%D7%A0%D7%A7%D7%A6%D7%99%D7%94_%D7%99%D7%95%D7%A6%D7%A8%D7%AA) של [מספרי ברנולי](https://he.wikipedia.org/wiki/%D7%9E%D7%A1%D7%A4%D7%A8%D7%99_%D7%91%D7%A8%D7%A0%D7%95%D7%9C%D7%99)



```math
\frac{t}{e^t-1} = \sum_{n=0}^\infty B_n \frac{t^n}{n!}.
```

 אדמצ'יק וסריווסטבה נותנים טור דומה:



```math
\sum_{n=1}^\infty \frac{t^{2n} }{n} \zeta(2n) =
\log \left(\frac{\pi t} {\sin (\pi t)}\right).
```



## טורים הקשורים לפונקציות פוליגמא

אפשר לגזור כמה יחסים נוספים מ[טור טיילור](https://he.wikipedia.org/wiki/%D7%98%D7%95%D7%A8_%D7%98%D7%99%D7%99%D7%9C%D7%95%D7%A8) של [פונקציית פוליגמא](https://he.wikipedia.org/wiki/%D7%A4%D7%95%D7%A0%D7%A7%D7%A6%D7%99%D7%99%D7%AA_%D7%A4%D7%95%D7%9C%D7%99%D7%92%D7%9E%D7%90) בנקודה $`z=1`$, שהוא



```math
\psi^{(m)}(z+1)= \sum_{k=0}^\infty
(-1)^{m+k+1} (m+k)!\; \zeta (m+k+1)\; \frac {z^k}{k!}.
```

 הטור מתכנס עבור $`|z| \lt 1`$. מקרה פרטי הוא



```math
\sum_{n=2}^\infty t^n \left[\zeta(n)-1\right] =
-t\left[\gamma +\psi(1-t) +\frac{t}{1-t}\right],
```

 שמתקיים עבור $`|t| \lt 2`$. כאן $`\psi`$ היא [פונקציית הדיגמא](https://he.wikipedia.org/wiki/%D7%A4%D7%95%D7%A0%D7%A7%D7%A6%D7%99%D7%99%D7%AA_%D7%93%D7%99%D7%92%D7%9E%D7%90) ו-$`\psi^{(m)}`$ היא פונקציית הפוליגמא. (בערך האנגלי מופיע בטעות הסימן $`-\frac{t}{1-t}`$. **גזירה:** $`\sum_{n\ge2}t^n(\zeta(n)-1) = \sum_{k\ge2}\frac{t^2}{k(k-t)}`$, ואילו מהטור $`\psi(1-t) = -\gamma - \sum_{k\ge1}\frac{t}{k(k-t)}`$ מתקבל ש-$`-t[\gamma + \psi(1-t)]`$ כולל גם את האיבר $`k = 1`$, $`\frac{t^2}{1-t}`$, שיש להחסיר. למשל עבור $`t = 1/2`$ שני האגפים שווים ל-$`0.1931472\ldots = \log 2 - \tfrac12`$.)

אפשר לגזור טורים רבים המערבים את ה[מקדם הבינומי](https://he.wikipedia.org/wiki/%D7%9E%D7%A7%D7%93%D7%9D_%D7%91%D7%99%D7%A0%D7%95%D7%9E%D7%99):



```math
\sum_{k=0}^\infty {k+\nu+1 \choose k} \left[\zeta(k+\nu+2)-1\right]
= \zeta(\nu+2),
```

 כאשר $`\nu`$ הוא [מספר מרוכב](https://he.wikipedia.org/wiki/%D7%9E%D7%A1%D7%A4%D7%A8_%D7%9E%D7%A8%D7%95%D7%9B%D7%91). זה נובע מפיתוח הטור של פונקציית זטא של הורוויץ



```math
\zeta(s,x+y) =
\sum_{k=0}^\infty {s+k-1 \choose s-1} (-y)^k \zeta (s+k,x)
```

 בנקודה $`y = -1`$. טורים דומים אפשר לקבל באלגברה פשוטה:



```math
\sum_{k=0}^\infty {k+\nu+1 \choose k+1} \left[\zeta(k+\nu+2)-1\right]
= 1,
```





```math
\sum_{k=0}^\infty (-1)^k {k+\nu+1 \choose k+1} \left[\zeta(k+\nu+2)-1\right]
= 2^{-(\nu+1)},
```





```math
\sum_{k=0}^\infty (-1)^k {k+\nu+1 \choose k+2} \left[\zeta(k+\nu+2)-1\right]
= \nu \left[\zeta(\nu+1)-1\right] - 2^{-\nu},
```





```math
\sum_{k=0}^\infty (-1)^k {k+\nu+1 \choose k} \left[\zeta(k+\nu+2)-1\right]
= \zeta(\nu+2)-1 - 2^{-(\nu+2)}.
```



עבור שלם $`n \ge 0`$, את הטור



```math
S_n = \sum_{k=0}^\infty {k+n \choose k} \left[\zeta(k+n+2)-1\right]
```

 אפשר לכתוב כסכום סופי



```math
S_n=(-1)^n\left[1+\sum_{k=1}^n (-1)^k\zeta(k+1) \right].
```

 זה נובע מיחס הנסיגה הפשוט $`S_n + S_{n+1} = \zeta(n+2)`$. (בערך האנגלי חסר הגורם $`(-1)^k`$ בתוך הסכום. **בדיקה:** $`S_0 = 1`$ ו-$`S_1 = \zeta(2) - S_0 = \zeta(2) - 1`$, ואילו הנוסחה בערך האנגלי נותנת $`S_1 = -(1+\zeta(2))`$, שהוא שלילי, בעוד שכל איברי הטור חיוביים.) בהמשך, את הטור



```math
T_n = \sum_{k=0}^\infty {k+n-1 \choose k} \left[\zeta(k+n+2)-1\right]
```

 אפשר לכתוב כ



```math
T_n=(-1)^{n+1}\left[n+1-\zeta(2)+\sum_{k=1}^{n-1} (-1)^k (n-k) \zeta(k+1) \right]
```

 עבור שלם $`n \ge 1`$. זה נובע מהזהות $`T_n + T_{n+1} = S_n`$. אפשר להפעיל את התהליך הזה באופן רקורסיבי כדי לקבל טורים סופיים עבור ביטויים כלליים מהצורה



```math
\sum_{k=0}^\infty {k+n-m \choose k} \left[\zeta(k+n+2)-1\right]
```

 עבור שלמים חיוביים $`m`$.

## טורי חזקות של חצאי שלמים

טורים דומים אפשר לקבל בחקירת פונקציית זטא של הורוויץ בערכים של חצאי שלמים. כך, למשל, מתקיים



```math
\sum_{k=0}^\infty \frac {\zeta(k+n+2)-1}{2^k}
{ {n+k+1} \choose {n+1} }=\left(2^{n+2}-1\right)\left(\zeta(n+2)-1\right)-1.
```



## ביטויים בצורת טורי p

אדמצ'יק וסריווסטבה נותנים



```math
\sum_{n=2}^\infty n^m \left[\zeta(n)-1\right] =
1\, +
\sum_{k=1}^m k!\; S(m+1,k+1) \zeta(k+1)
```

 ו



```math
\sum_{n=2}^\infty (-1)^n n^m \left[\zeta(n)-1\right] =
-1\, +\, \frac {2^{m+1}-1}{m+1} B_{m+1}
\,- \sum_{k=1}^m (-1)^k k!\; S(m+1,k+1) \zeta(k+1),
```

 כאשר $`B_k`$ הם מספרי ברנולי ו-$`S(m,k)`$ הם [מספרי סטירלינג מהסוג השני](https://he.wikipedia.org/wiki/%D7%9E%D7%A1%D7%A4%D7%A8%D7%99_%D7%A1%D7%98%D7%99%D7%A8%D7%9C%D7%99%D7%A0%D7%92). (בערך האנגלי המקדם של $`B_{m+1}`$ מופיע עם סימן הפוך, $`\frac{1-2^{m+1} }{m+1}`$; הסימן הנכון נבדק מספרית עבור $`m = 1, \ldots, 5`$. למשל עבור $`m = 1`$: אגף שמאל הוא $`0.8949341\ldots = \zeta(2) - \tfrac34`$.)
