# השבר המשולב של רוג'רס–רמנוג'אן

**השבר המשולב של רוג'רס–רמנוג'אן** הוא [שבר משולב](https://he.wikipedia.org/wiki/%D7%A9%D7%91%D7%A8_%D7%9E%D7%A9%D7%95%D7%9C%D7%91) שגילה לאונרד ג'יימס רוג'רס ב-1894, ובאופן בלתי תלוי [סריניוואסה רמנוג'אן](https://he.wikipedia.org/wiki/%D7%A1%D7%A8%D7%99%D7%A0%D7%99%D7%95%D7%95%D7%90%D7%A1%D7%94_%D7%A8%D7%9E%D7%A0%D7%95%D7%92%27%D7%90%D7%9F), והוא קשור הדוק ל[זהויות רוג'רס–רמנוג'אן](%D7%96%D7%94%D7%95%D7%99%D7%95%D7%AA%20%D7%A8%D7%95%D7%92%27%D7%A8%D7%A1%E2%80%93%D7%A8%D7%9E%D7%A0%D7%95%D7%92%27%D7%90%D7%9F.md). אפשר לחשב אותו במפורש עבור משפחה רחבה של ערכי הארגומנט שלו.

## הגדרה

בהינתן הפונקציות $`G(q)`$ ו-$`H(q)`$ שמופיעות בזהויות רוג'רס–רמנוג'אן, ובהנחה ש-$`q = e^{2\pi i\tau}`$,



```math
\begin{align}
G(q) &= \sum_{n=0}^\infty\frac{q^{n^2} }{(1 - q)(1 - q^2)\cdots(1 - q^n)} = \sum_{n=0}^\infty\frac{q^{n^2} }{(q; q)_n} = \frac1{(q; q^5)_\infty(q^4; q^5)_\infty} = \prod_{n=1}^\infty\frac1{(1 - q^{5n-1})(1 - q^{5n-4})} \\
&= \sqrt[60]{q\,j}\ {}_2F_1\left(-\tfrac1{60}, \tfrac{19}{60}; \tfrac45; \tfrac{1728}j\right) = \sqrt[60]{q(j - 1728)}\ {}_2F_1\left(-\tfrac1{60}, \tfrac{29}{60}; \tfrac45; -\tfrac{1728}{j - 1728}\right) \\
&= 1 + q + q^2 + q^3 + 2q^4 + 2q^5 + 3q^6 + \cdots
\end{align}
```

 ו-



```math
\begin{align}
H(q) &= \sum_{n=0}^\infty\frac{q^{n^2+n} }{(q; q)_n} = \frac1{(q^2; q^5)_\infty(q^3; q^5)_\infty} = \prod_{n=1}^\infty\frac1{(1 - q^{5n-2})(1 - q^{5n-3})} \\
&= \frac1{\sqrt[60]{q^{11}j^{11} } }\ {}_2F_1\left(\tfrac{11}{60}, \tfrac{31}{60}; \tfrac65; \tfrac{1728}j\right) = \frac1{\sqrt[60]{q^{11}(j - 1728)^{11} } }\ {}_2F_1\left(\tfrac{11}{60}, \tfrac{41}{60}; \tfrac65; -\tfrac{1728}{j - 1728}\right) \\
&= 1 + q^2 + q^3 + q^4 + q^5 + 2q^6 + 2q^7 + \cdots
\end{align}
```

 כאשר מקדמי פיתוחי ה-$`q`$ הם הסדרות A003114 ו-A003106 ב-OEIS, $`(a; q)_\infty`$ הוא [סמל פוכהאמר $`q`$](https://he.wikipedia.org/wiki/%D7%A1%D7%9E%D7%9C_%D7%A4%D7%95%D7%9B%D7%94%D7%90%D7%9E%D7%A8_q) האינסופי, $`j`$ הוא [פונקציית $`j`$](%D7%90%D7%99%D7%A0%D7%95%D7%95%D7%A8%D7%99%D7%90%D7%A0%D7%98%20j.md), ו-$`{}_2F_1`$ היא [הפונקציה ההיפרגאומטרית](https://he.wikipedia.org/wiki/%D7%A4%D7%95%D7%A0%D7%A7%D7%A6%D7%99%D7%94_%D7%94%D7%99%D7%A4%D7%A8%D7%92%D7%90%D7%95%D7%9E%D7%98%D7%A8%D7%99%D7%AA). (את הביטויים ההיפרגאומטריים בדקנו בחישוב מספרי ב-$`\tau = 2i`$, שם $`j = 66^3`$.) השבר המשולב של רוג'רס–רמנוג'אן הוא אז



```math
R(q) = \frac{q^{\frac{11}{60} }H(q)}{q^{-\frac1{60} }G(q)} = q^{\frac15}\prod_{n=1}^\infty\frac{(1 - q^{5n-1})(1 - q^{5n-4})}{(1 - q^{5n-2})(1 - q^{5n-3})} = q^{1/5}\prod_{n=1}^\infty(1 - q^n)^{(n|5)} = \cfrac{q^{1/5} }{1 + \cfrac q{1 + \cfrac{q^2}{1 + \cfrac{q^3}{1 + \ddots} } } },
```

 כאשר $`(n \mid m)`$ הוא [סמל יעקובי](https://he.wikipedia.org/wiki/%D7%A1%D7%9E%D7%9C_%D7%99%D7%A2%D7%A7%D7%95%D7%91%D7%99).

צריך להיזהר בסימונים: הנוסחאות עם פונקציית $`j`$ עקביות עם האחרות רק אם משתמשים בסעיף הזה לכל אורכו ב-$`q = e^{2\pi i\tau}`$ (ריבוע ה[נום](https://he.wikipedia.org/wiki/%D7%A0%D7%95%D7%9D_%28%D7%9E%D7%AA%D7%9E%D7%98%D7%99%D7%A7%D7%94%29)), כי פיתוח ה-$`q`$ של פונקציית $`j`$ (ושל [פונקציית אטא של דדקינד](%D7%A4%D7%95%D7%A0%D7%A7%D7%A6%D7%99%D7%99%D7%AA%20%D7%90%D7%98%D7%90%20%D7%A9%D7%9C%20%D7%93%D7%93%D7%A7%D7%99%D7%A0%D7%93.md)) משתמש ב-$`q = e^{2\pi i\tau}`$. לעומת זאת, רמנוג'אן, בדוגמאות ששלח להרדי ושמובאות להלן, השתמש בנום $`q = e^{\pi i\tau}`$.

## ערכים מיוחדים

אם $`q`$ הוא הנום או ריבועו, אז $`q^{-\frac1{60} }G(q)`$ ו-$`q^{\frac{11}{60} }H(q)`$, וגם המנה שלהן $`R(q)`$, קשורות לפונקציות מודולריות של $`\tau`$. כיוון שיש להן מקדמים שלמים, תורת ה[כפל המרוכב](%D7%9B%D7%A4%D7%9C%20%D7%9E%D7%A8%D7%95%D7%9B%D7%91.md) גוררת שהערכים שלהן עבור $`\tau`$ בשדה ריבועי מדומה הם [מספרים אלגבריים](https://he.wikipedia.org/wiki/%D7%9E%D7%A1%D7%A4%D7%A8_%D7%90%D7%9C%D7%92%D7%91%D7%A8%D7%99) שאפשר לחשב במפורש.

### דוגמאות ל-R(q)

בצורה הכללית, כשרמנוג'אן השתמש בנום $`q = e^{\pi i\tau}`$,



```math
R(q) = \cfrac{q^{1/5} }{1 + \cfrac q{1 + \cfrac{q^2}{1 + \cfrac{q^3}{1 + \ddots} } } }.
```

 עם $`\varphi = \tfrac{1 + \sqrt5}2`$ [יחס הזהב](https://he.wikipedia.org/wiki/%D7%99%D7%97%D7%A1_%D7%94%D7%96%D7%94%D7%91):

- כאשר $`\tau = i`$: $`R(e^{-\pi}) = \tfrac12\varphi\left(\sqrt5 - \varphi^{3/2}\right)\left(\sqrt[4]5 + \varphi^{3/2}\right) = 0.511428\ldots`$
- כאשר $`\tau = 2i`$: $`R(e^{-2\pi}) = \sqrt[4]5\,\varphi^{1/2} - \varphi = 0.284079\ldots`$
- כאשר $`\tau = 4i`$: $`R(e^{-4\pi}) = \tfrac12\varphi\left(\sqrt5 - \varphi^{3/2}\right)\left(-\sqrt[4]5 + \varphi^{3/2}\right) = 0.081002\ldots`$
- כאשר $`\tau = 2\sqrt5\,i`$: $`R(e^{-2\sqrt5\pi}) = \frac{\sqrt5}{1 + \left(5^{3/4}(\varphi - 1)^{5/2} - 1\right)^{1/5} } - \varphi = 0.0602094\ldots`$
- כאשר $`\tau = 5i`$: $`R(e^{-5\pi}) = \frac{1 + \varphi^2}{\varphi + \left(\frac12\left(4 - \varphi - 3\sqrt{\varphi - 1}\right)\left(3\varphi^{3/2} - \sqrt[4]5\right)\right)^{1/5} } - \varphi = 0.0432139\ldots`$
- כאשר $`\tau = 10i`$: $`R(e^{-10\pi}) = \frac{1 + \varphi^2}{\varphi + \left(3\sqrt{1 + \varphi^2} - 4 - \varphi\right)^{1/5} } - \varphi = 0.00186744\ldots`$
- כאשר $`\tau = 20i`$: $`R(e^{-20\pi}) = \frac{1 + \varphi^2}{\varphi + \left(\frac12\left(4 - \varphi - 3\sqrt{\varphi - 1}\right)\left(3\varphi^{3/2} + \sqrt[4]5\right)\right)^{1/5} } - \varphi = 0.00000348734\ldots`$

(את שבעת הערכים בדקנו בחישוב מספרי מול המכפלה האינסופית.) $`R(e^{-2\pi})`$ הוא שורש חיובי של ה[משוואה ממעלה רביעית](https://he.wikipedia.org/wiki/%D7%9E%D7%A9%D7%95%D7%95%D7%90%D7%94_%D7%9E%D7%9E%D7%A2%D7%9C%D7%94_%D7%A8%D7%91%D7%99%D7%A2%D7%99%D7%AA)



```math
x^4 + 2x^3 - 6x^2 - 2x + 1 = 0,
```

 ואילו $`R(e^{-\pi})`$ ו-$`R(e^{-4\pi})`$ הם שני שורשים חיוביים של המשוואה



```math
y^4 + 2\varphi^4y^3 + 6\varphi^2y^2 - 2\varphi^4y + 1 = 0,
```

 שמקדמיה ב-$`\mathbb Q(\sqrt5)`$, כלומר של משוואה אחת ממעלה שמינית מעל $`\mathbb Q`$; זה מסביר את הדמיון בין שתי הצורות הסגורות. באופן כללי יותר, לכל $`m`$ שלם חיובי, $`R(e^{-2\pi/m})`$ ו-$`R(e^{-2\pi m})`$ הם שני שורשים של אותה משוואה, וגם



```math
\left[R(e^{-2\pi/m}) + \varphi\right]\left[R(e^{-2\pi m}) + \varphi\right] = \sqrt5\,\varphi.
```

 לפי OEIS (A082682), הדרגה האלגברית $`k`$ של $`R(e^{-\pi n})`$ עבור $`n = 1, 2, 3, 4, \dots`$ היא $`k = 8, 4, 32, 8, \dots`$.

אגב, אפשר להשתמש בשברים המשולבים האלה כדי לפתור כמה [משוואות ממעלה חמישית](https://he.wikipedia.org/wiki/%D7%9E%D7%A9%D7%95%D7%95%D7%90%D7%94_%D7%9E%D7%9E%D7%A2%D7%9C%D7%94_%D7%97%D7%9E%D7%99%D7%A9%D7%99%D7%AA), כפי שמוסבר בסעיף להלן.

### דוגמאות ל-G(q) ול-H(q)

יש נוסחאות מפורשות ל-$`G(q)`$ ול-$`H(q)`$ בעזרת פונקציית $`j(\tau)`$ והשבר המשולב $`R(q)`$. כיוון ש-$`j(\tau)`$ משתמשת בריבוע הנום $`q = e^{2\pi i\tau}`$, צריך להקפיד ש-$`j(\tau)`$, $`G(q)`$, $`H(q)`$ ו-$`r = R(q)`$ ישתמשו באותו $`q`$:



```math
G(q) = q^{1/60}\frac{j(\tau)^{1/60} }{(r^{20} - 228r^{15} + 494r^{10} + 228r^5 + 1)^{1/20} },
```





```math
H(q) = \frac{-1}{q^{11/60} }\,\frac{(r^{20} - 228r^{15} + 494r^{10} + 228r^5 + 1)^{11/20} }{j(\tau)^{11/60}(r^{10} + 11r^5 - 1)}.
```

 הנוסחאות האלה גוררות ש-$`q^{-1/60}G(q)`$ ו-$`q^{11/60}H(q)`$ הם [מספרים אלגבריים](https://he.wikipedia.org/wiki/%D7%9E%D7%A1%D7%A4%D7%A8_%D7%90%D7%9C%D7%92%D7%91%D7%A8%D7%99) (אם כי בדרך כלל מדרגה גבוהה) כאשר $`\tau`$ בשדה ריבועי מדומה. למשל, הן מתפשטות ל-



```math
G(e^{-2\pi}) = (e^{-2\pi})^{1/60}\frac1{(5\varphi)^{1/4} }\frac1{\sqrt{R(e^{-2\pi})} } = 1.00187093\ldots, \qquad H(e^{-2\pi}) = \frac1{(e^{-2\pi})^{11/60} }\frac1{(5\varphi)^{1/4} }\sqrt{R(e^{-2\pi})} = 1.00000349\ldots
```

 ול-



```math
G(e^{-4\pi}) = (e^{-4\pi})^{1/60}\frac1{(5\varphi^3)^{1/4}(\varphi + \sqrt[4]5)^{1/4} }\frac1{\sqrt{R(e^{-4\pi})} } = 1.000003487354\ldots,
```





```math
H(e^{-4\pi}) = \frac1{(e^{-4\pi})^{11/60} }\frac1{(5\varphi^3)^{1/4}(\varphi + \sqrt[4]5)^{1/4} }\sqrt{R(e^{-4\pi})} = 1.000000000012\ldots
```

 וכן הלאה. (כאן הארגומנטים $`e^{-2\pi}`$ ו-$`e^{-4\pi}`$ הם ערכים של $`q = e^{2\pi i\tau}`$, עם $`\tau = i`$ ו-$`\tau = 2i`$.)

## גזירת הערכים המיוחדים

### סכומים טנגנסיאליים

בסעיף הזה מנסחים את המשפטים העיקריים על השברים המשולבים $`R`$ ו-$`S`$ (השבר המשולב המתחלף, ראו [זהויות רוג'רס–רמנוג'אן](%D7%96%D7%94%D7%95%D7%99%D7%95%D7%AA%20%D7%A8%D7%95%D7%92%27%D7%A8%D7%A1%E2%80%93%D7%A8%D7%9E%D7%A0%D7%95%D7%92%27%D7%90%D7%9F.md)) בעזרת **סכומים והפרשים טנגנסיאליים**:



```math
a \oplus b = \tan\left[\arctan(a) + \arctan(b)\right] = \frac{a + b}{1 - ab}, \qquad c \ominus d = \tan\left[\arctan(c) - \arctan(d)\right] = \frac{c - d}{1 + cd}.
```

 הנום האליפטי $`q`$ ו**הנום המשלים** $`q_1`$ מקיימים



```math
\ln(q)\ln(q_1) = \pi^2,
```

 והנום המשלים של מודולוס $`k`$ שווה לנום של המודולוס המשלים הפיתגורי: $`q_1(k) = q(k') = q\left(\sqrt{1 - k^2}\right)`$. אלה **משפטי השיקוף** של השברים המשולבים:



```math
S(q) \oplus S(q_1) = \Phi, \qquad R(q^2) \oplus R(q_1^2) = \Phi^{-1},
```

 כאשר $`\Phi`$ הוא יחס הזהב:



```math
\Phi = \tfrac12(\sqrt5 + 1) = \cot\left[\tfrac12\arctan(2)\right] = 2\cos\left(\tfrac15\pi\right), \qquad \Phi^{-1} = \tfrac12(\sqrt5 - 1) = \tan\left[\tfrac12\arctan(2)\right] = 2\sin\left(\tfrac1{10}\pi\right).
```

 המשפטים לנום בריבוע:



```math
R(q)^2R(q^2)^{-1} \oplus R(q)R(q^2)^2 = 1, \qquad S(q)^2R(q^2)^{-1} \ominus S(q)R(q^2)^2 = 1.
```

 והקשרים לפונקציות התטא של יעקובי:



```math
S(q) \oplus R(q^2) = \frac{\vartheta_{00}(q^{1/5})^2 - \vartheta_{00}(q)^2}{5\vartheta_{00}(q^5)^2 - \vartheta_{00}(q)^2}, \qquad R(q) \ominus R(q^2) = \frac{\vartheta_{01}(q)^2 - \vartheta_{01}(q^{1/5})^2}{5\vartheta_{01}(q^5)^2 - \vartheta_{01}(q)^2}.
```

 (את כל המשפטים האלה בדקנו בחישוב מספרי.)

### ערכים למניסקטיים

נציב ערכים מסוימים במשפטים שלמעלה. עבור $`q = q_1 = e^{-\pi}`$:



```math
S(e^{-\pi}) \oplus S(e^{-\pi}) = \Phi,
```

 ולכן



```math
S(e^{-\pi}) = \tan\left[\tfrac12\arctan(\Phi)\right] = \tan\left[\tfrac14\pi - \tfrac14\arctan(2)\right].
```

 באותו אופן, $`R(e^{-2\pi}) \oplus R(e^{-2\pi}) = \Phi^{-1}`$, ולכן



```math
R(e^{-2\pi}) = \tan\left[\tfrac12\arctan(\Phi^{-1})\right] = \tan\left[\tfrac14\arctan(2)\right].
```

 את אותו קשר מקבלים גם מהמשפט על פונקציות התטא: ב-$`q = e^{-\pi}`$ מתקיים $`\vartheta_{00}(q^{1/5})^2 = 5\,\vartheta_{00}(q^5)^2`$ (לפי [נוסחת הסכימה של פואסון](https://he.wikipedia.org/wiki/%D7%A0%D7%95%D7%A1%D7%97%D7%AA_%D7%94%D7%A1%D7%9B%D7%99%D7%9E%D7%94_%D7%A9%D7%9C_%D7%A4%D7%95%D7%90%D7%A1%D7%95%D7%9F), כי $`\vartheta_{00}(e^{-\pi t}) = t^{-1/2}\vartheta_{00}(e^{-\pi/t})`$; כאן $`t = 1/5`$), ולכן



```math
S(e^{-\pi}) \oplus R(e^{-2\pi}) = 1,
```

 ומכאן $`R(e^{-2\pi}) = 1 \ominus S(e^{-\pi}) = 1 \ominus \tan\left[\tfrac14\pi - \tfrac14\arctan(2)\right] = \tan\left[\tfrac14\arctan(2)\right]`$.

המשפט השני על פונקציות התטא נותן ערך נוסף:



```math
R(e^{-\pi}) \ominus R(e^{-2\pi}) = \frac{\vartheta_{01}(q)^2 - \vartheta_{01}(q^{1/5})^2}{5\vartheta_{01}(q^5)^2 - \vartheta_{01}(q)^2}\Bigg|_{q = e^{-\pi} } = \frac{\sqrt[4]5 - 1}{\sqrt[4]5 + 1} = \sqrt[4]5 \ominus 1 = \tan\left[\arctan\left(\sqrt[4]5\right) - \tfrac14\pi\right],
```

 ולכן



```math
R(e^{-\pi}) = \tan\left[\tfrac14\arctan(2) + \arctan\left(\sqrt[4]5\right) - \tfrac14\pi\right].
```

 שימוש נוסף במשפט השיקוף, $`R(e^{-\pi}) \oplus R(e^{-4\pi}) = \Phi^{-1}`$, נותן



```math
R(e^{-4\pi}) = \tan\left[\tfrac14\arctan(2) - \arctan\left(\sqrt[4]5\right) + \tfrac14\pi\right].
```



### ערכים לא למניסקטיים

משפט השיקוף נותן גם



```math
R(e^{-\sqrt2\pi}) \oplus R(e^{-2\sqrt2\pi}) = \Phi^{-1},
```

 ומשפט התטא נותן קשר נוסף: עם $`c_0 = \tfrac13\sqrt5 - \tfrac13\sqrt[3]{6\sqrt{30} + 4\sqrt5} + \tfrac13\sqrt[3]{6\sqrt{30} - 4\sqrt5}`$,



```math
R(e^{-\sqrt2\pi}) \ominus R(e^{-2\sqrt2\pi}) = \tan\left[2\arctan(c_0) - \tfrac14\pi\right].
```

 חיבור והפרש טנגנסיאליים של שני הקשרים נותנים



```math
R(e^{-\sqrt2\pi}) = \tan\left[\arctan(c_0) - \tfrac14\mathrm{arccot}(2)\right], \qquad R(e^{-2\sqrt2\pi}) = \tan\left[\tfrac14\mathrm{arccot}(-2) - \arctan(c_0)\right],
```

 כאשר $`\mathrm{arccot}`$ מקבל ערכים ב-$`(0, \pi)`$. בדרך חלופית, אפשר להציב את משפט השיקוף, $`R(e^{-2\sqrt2\pi}) = \frac{1 - \Phi R(e^{-\sqrt2\pi})}{\Phi + R(e^{-\sqrt2\pi})}`$, במשפט לנום בריבוע (שאפשר לכתוב כ-$`\{R(q)^2R(q^2)^{-1} + 1\}\{R(q)R(q^2)^2 + 1\} = 2`$). אחרי ביטול המכנים מתקבלת, עבור $`x = R(e^{-\sqrt2\pi})`$, המשוואה ממעלה שישית



```math
x^6 + 2\Phi^{-2}x^5 - \sqrt5\,\Phi^{-1}x^4 + 2\sqrt5\,\Phi x^3 + \sqrt5\,\Phi^{-1}x^2 + 2\Phi^{-2}x - 1 = 0,
```

 והפתרון שלה הוא הערך שכבר נמצא, $`R(e^{-\sqrt2\pi}) \approx 0.406461`$.

## קשר לתבניות מודולריות

את $`R(q)`$ אפשר לקשר ל[פונקציית אטא של דדקינד](%D7%A4%D7%95%D7%A0%D7%A7%D7%A6%D7%99%D7%99%D7%AA%20%D7%90%D7%98%D7%90%20%D7%A9%D7%9C%20%D7%93%D7%93%D7%A7%D7%99%D7%A0%D7%93.md), [תבנית מודולרית](https://he.wikipedia.org/wiki/%D7%AA%D7%91%D7%A0%D7%99%D7%AA_%D7%9E%D7%95%D7%93%D7%95%D7%9C%D7%A8%D7%99%D7%AA) ממשקל $`\tfrac12`$, כך (עם $`q = e^{2\pi i\tau}`$):[^1]



```math
\frac1{R(q)} - R(q) = \frac{\eta(\frac\tau5)}{\eta(5\tau)} + 1, \qquad \frac1{R^5(q)} - R^5(q) = \left[\frac{\eta(\tau)}{\eta(5\tau)}\right]^6 + 11.
```

 אפשר לבטא את השבר המשולב גם בעזרת [פונקציות התטא של יעקובי](https://he.wikipedia.org/wiki/%D7%A4%D7%95%D7%A0%D7%A7%D7%A6%D7%99%D7%99%D7%AA_%D7%AA%D7%98%D7%90), בסימון



```math
\vartheta_{10}(0; \tau) = \theta_2(q) = \sum_{n=-\infty}^\infty q^{(n+1/2)^2}, \quad \vartheta_{00}(0; \tau) = \theta_3(q) = \sum_{n=-\infty}^\infty q^{n^2}, \quad \vartheta_{01}(0; \tau) = \theta_4(q) = \sum_{n=-\infty}^\infty(-1)^nq^{n^2}.
```

 (הסימון $`\theta_n`$ נוח לזכירה, כי $`\theta_2^4 + \theta_4^4 = \theta_3^4`$, עם אינדקסים זוגיים באגף שמאל.) כך:



```math
R(x) = \tan\left\{\frac12\mathrm{arccot}\left[\frac12 + \frac{\theta_4(x^{1/5})\left[5\theta_4(x^5)^2 - \theta_4(x)^2\right]}{2\theta_4(x^5)\left[\theta_4(x)^2 - \theta_4(x^{1/5})^2\right]}\right]\right\},
```





```math
R(x) = \tan\left\{\frac12\mathrm{arccot}\left[\frac12 + \left(\frac{\theta_2(x^{1/10})\theta_3(x^{1/10})\theta_4(x^{1/10})}{2^3\theta_2(x^{5/2})\theta_3(x^{5/2})\theta_4(x^{5/2})}\right)^{1/3}\right]\right\},
```





```math
R(x) = \tan\left\{\frac12\arctan\left[\frac12 - \frac{\theta_4(x)^2}{2\theta_4(x^5)^2}\right]\right\}^{1/5}\tan\left\{\frac12\mathrm{arccot}\left[\frac12 - \frac{\theta_4(x)^2}{2\theta_4(x^5)^2}\right]\right\}^{2/5},
```





```math
R(x) = \tan\left\{\frac12\arctan\left[\frac12 - \frac{\theta_4(x^{1/2})^2}{2\theta_4(x^{5/2})^2}\right]\right\}^{2/5}\cot\left\{\frac12\mathrm{arccot}\left[\frac12 - \frac{\theta_4(x^{1/2})^2}{2\theta_4(x^{5/2})^2}\right]\right\}^{1/5}.
```

 שימו לב שפונקציות התטא משתמשות בדרך כלל בנום $`q = e^{i\pi\tau}`$, ואילו פונקציית אטא של דדקינד משתמשת בריבוע שלו, $`q = e^{2i\pi\tau}`$; לכן משתמשים כאן במשתנה $`x`$ כדי לשמור על עקביות בין כל הפונקציות. למשל, עבור $`\tau = i`$, $`x = e^{-\pi}`$, ומקבלים את אותו ערך בכל ארבע הנוסחאות: $`R(e^{-\pi}) = 0.511428\ldots`$.

אפשר גם להגדיר את הנום האליפטי



```math
q(k) = \exp\left[-\pi K\left(\sqrt{1 - k^2}\right)/K(k)\right],
```

 כאשר $`k`$ המודולוס האליפטי ו-$`K`$ [האינטגרל האליפטי השלם מהסוג הראשון](https://he.wikipedia.org/wiki/%D7%90%D7%99%D7%A0%D7%98%D7%92%D7%A8%D7%9C_%D7%90%D7%9C%D7%99%D7%A4%D7%98%D7%99). אז אפשר לבטא את השבר המשולב בעזרת [הפונקציות האליפטיות של יעקובי](https://he.wikipedia.org/wiki/%D7%94%D7%A4%D7%95%D7%A0%D7%A7%D7%A6%D7%99%D7%95%D7%AA_%D7%94%D7%90%D7%9C%D7%99%D7%A4%D7%98%D7%99%D7%95%D7%AA_%D7%A9%D7%9C_%D7%99%D7%A2%D7%A7%D7%95%D7%91%D7%99):



```math
R\big(q(k)\big) = \tan\left\{\frac12\arctan y\right\}^{1/5}\tan\left\{\frac12\mathrm{arccot}y\right\}^{2/5} = \left\{\frac{\sqrt{y^2 + 1} - 1}y\right\}^{1/5}\left\{y\left[\sqrt{\frac1{y^2} + 1} - 1\right]\right\}^{2/5},
```

 עם



```math
y = \frac{2k^2\mathrm{sn}\left[\tfrac25K(k); k\right]^2\mathrm{sn}\left[\tfrac45K(k); k\right]^2}{5 - k^2\mathrm{sn}\left[\tfrac25K(k); k\right]^2\mathrm{sn}\left[\tfrac45K(k); k\right]^2}.
```



## קשר לפונקציית j

נוסחה אחת שמערבת את [פונקציית $`j`$](%D7%90%D7%99%D7%A0%D7%95%D7%95%D7%A8%D7%99%D7%90%D7%A0%D7%98%20j.md) ואת פונקציית אטא של דדקינד היא



```math
j(\tau) = \frac{(x^2 + 10x + 5)^3}x, \qquad x = \left[\frac{\sqrt5\,\eta(5\tau)}{\eta(\tau)}\right]^6.
```

 כיוון שגם $`\frac1{R^5(q)} - R^5(q) = \left[\frac{\eta(\tau)}{\eta(5\tau)}\right]^6 + 11`$, אפשר לסלק את מנת האטא $`x`$ בין שתי המשוואות ולבטא את $`j(\tau)`$ בעזרת $`r = R(q)`$:



```math
j(\tau) = -\frac{(r^{20} - 228r^{15} + 494r^{10} + 228r^5 + 1)^3}{r^5(r^{10} + 11r^5 - 1)^5}, \qquad j(\tau) - 1728 = -\frac{(r^{30} + 522r^{25} - 10005r^{20} - 10005r^{10} - 522r^5 + 1)^2}{r^5(r^{10} + 11r^5 - 1)^5},
```

 כאשר המונה והמכנה הם [אינווריאנטים פולינומיים](https://he.wikipedia.org/wiki/%D7%90%D7%99%D7%A0%D7%95%D7%95%D7%A8%D7%99%D7%90%D7%A0%D7%98_%D7%A4%D7%95%D7%9C%D7%99%D7%A0%D7%95%D7%9E%D7%99) של ה[איקוסהדרון](https://he.wikipedia.org/wiki/%D7%90%D7%99%D7%A7%D7%95%D7%A1%D7%94%D7%93%D7%A8%D7%95%D7%9F). בעזרת ה[משוואה המודולרית](%D7%9E%D7%A9%D7%95%D7%95%D7%90%D7%94%20%D7%9E%D7%95%D7%93%D7%95%D7%9C%D7%A8%D7%99%D7%AA.md) בין $`R(q)`$ ל-$`R(q^5)`$ מקבלים



```math
j(5\tau) = -\frac{(r^{20} + 12r^{15} + 14r^{10} - 12r^5 + 1)^3}{r^{25}(r^{10} + 11r^5 - 1)}, \qquad j(5\tau) - 1728 = -\frac{(r^{30} + 18r^{25} + 75r^{20} + 75r^{10} - 18r^5 + 1)^2}{r^{25}(r^{10} + 11r^5 - 1)}.
```

 אם $`z = r^5 - \frac1{r^5}`$, אז $`j(5\tau) = -\frac{(z^2 + 12z + 16)^3}{z + 11}`$, וששת השורשים של המשוואה הזו (כמשוואה ב-$`z`$) הם



```math
z_\infty = -\left[\frac{\sqrt5\,\eta(25\tau)}{\eta(5\tau)}\right]^6 - 11,\quad z_0 = -\left[\frac{\eta(\tau)}{\eta(5\tau)}\right]^6 - 11,\quad z_1 = \left[\frac{\eta(\frac{5\tau+2}5)}{\eta(5\tau)}\right]^6 - 11,
```





```math
z_2 = -\left[\frac{\eta(\frac{5\tau+4}5)}{\eta(5\tau)}\right]^6 - 11,\quad z_3 = \left[\frac{\eta(\frac{5\tau+6}5)}{\eta(5\tau)}\right]^6 - 11,\quad z_4 = -\left[\frac{\eta(\frac{5\tau+8}5)}{\eta(5\tau)}\right]^6 - 11.
```

 $`j(5\tau)`$ הוא למעשה אינווריאנט $`j`$ של ה[עקום אליפטי](https://he.wikipedia.org/wiki/%D7%A2%D7%A7%D7%95%D7%9D_%D7%90%D7%9C%D7%99%D7%A4%D7%98%D7%99)



```math
y^2 + (1 + r^5)xy + r^5y = x^3 + r^5x^2,
```

 שהוא צורת טייט הנורמלית של עקום עם נקודה מסדר 5 (הנקודה $`(0, 0)`$), ומפורמטר על ידי הנקודות שאינן חודים של [העקום המודולרי](%D7%A2%D7%A7%D7%95%D7%9D%20%D7%9E%D7%95%D7%93%D7%95%D7%9C%D7%A8%D7%99.md) $`X_1(5)`$. (את כל הנוסחאות בסעיף הזה, כולל ששת השורשים ואינווריאנט $`j`$ של העקום, בדקנו בחישוב מספרי.)

## משוואה פונקציונלית

לנוחות, נסמן $`r(\tau) = R(q)`$ כאשר $`q = e^{2\pi i\tau}`$ (ו-$`q^{1/5} = e^{2\pi i\tau/5}`$). בעוד שפונקציות מודולריות אחרות, כמו אינווריאנט $`j`$, מקיימות $`j(-\tfrac1\tau) = j(\tau)`$, ופונקציית אטא של דדקינד מקיימת $`\eta(-\tfrac1\tau) = \sqrt{-i\tau}\,\eta(\tau)`$, ה[משוואה הפונקציונלית](https://he.wikipedia.org/wiki/%D7%9E%D7%A9%D7%95%D7%95%D7%90%D7%94_%D7%A4%D7%95%D7%A0%D7%A7%D7%A6%D7%99%D7%95%D7%A0%D7%9C%D7%99%D7%AA) של השבר המשולב של רוג'רס–רמנוג'אן מערבת את [יחס הזהב](https://he.wikipedia.org/wiki/%D7%99%D7%97%D7%A1_%D7%94%D7%96%D7%94%D7%91) $`\varphi`$:[^2]



```math
r\left(-\tfrac1\tau\right) = \frac{1 - \varphi\,r(\tau)}{\varphi + r(\tau)}.
```

 אגב, $`r\left(\tfrac{7 + i}{10}\right) = i`$. (כאן חשוב לקחת $`q^{1/5} = e^{2\pi i\tau/5}`$ ולא את הענף הראשי של $`q^{1/5}`$; בענף הראשי מתקבל ערך שונה, $`e^{\pi i/10}`$.)

## משוואות מודולריות

יש [משוואות מודולריות](%D7%9E%D7%A9%D7%95%D7%95%D7%90%D7%94%20%D7%9E%D7%95%D7%93%D7%95%D7%9C%D7%A8%D7%99%D7%AA.md) בין $`R(q)`$ ל-$`R(q^n)`$. משוואות אלגנטיות עבור $`n`$ [ראשוני](https://he.wikipedia.org/wiki/%D7%9E%D7%A1%D7%A4%D7%A8_%D7%A8%D7%90%D7%A9%D7%95%D7%A0%D7%99) קטן הן:[^3]

- עבור $`n = 2`$, עם $`u = R(q)`$ ו-$`v = R(q^2)`$: $`v - u^2 = (v + u^2)uv^2`$.
- עבור $`n = 3`$, עם $`u = R(q)`$ ו-$`v = R(q^3)`$: $`(v - u^3)(1 + uv^3) = 3u^2v^2`$.
- עבור $`n = 5`$, עם $`u = R(q)`$ ו-$`v = R(q^5)`$: $`v(v^4 - 3v^3 + 4v^2 - 2v + 1) = (v^4 + 2v^3 + 4v^2 + 3v + 1)u^5`$; או באופן שקול, עם $`\varphi = \tfrac{1 + \sqrt5}2`$, $`u^5 = \frac{v(v^2 - \varphi^2v + \varphi^2)(v^2 - \varphi^{-2}v + \varphi^{-2})}{(v^2 + v + \varphi^2)(v^2 + v + \varphi^{-2})}`$.
- עבור $`n = 11`$, עם $`u = R(q)`$ ו-$`v = R(q^{11})`$: $`uv(u^{10} + 11u^5 - 1)(v^{10} + 11v^5 - 1) = (u - v)^{12}`$.

לגבי $`n = 5`$, שימו לב ש-$`v^{10} + 11v^5 - 1 = (v^2 + v - 1)(v^4 - 3v^3 + 4v^2 - 2v + 1)(v^4 + 2v^3 + 4v^2 + 3v + 1)`$.

## תוצאות נוספות

רמנוג'אן מצא עוד תוצאות מעניינות רבות על $`R(q)`$.[^4] יהיו $`a, b \in \mathbb R^+`$, ו-$`\varphi`$ יחס הזהב. אם $`ab = \pi^2`$, אז



```math
\left[R(e^{-2a}) + \varphi\right]\left[R(e^{-2b}) + \varphi\right] = \sqrt5\,\varphi.
```

 אם $`5ab = \pi^2`$, אז



```math
\left[R^5(e^{-2a}) + \varphi^5\right]\left[R^5(e^{-2b}) + \varphi^5\right] = 5\sqrt5\,\varphi^5.
```

 גם את החזקות של $`R(q)`$ אפשר לבטא בדרכים לא שגרתיות. עבור ה[חזקה שלישית](https://he.wikipedia.org/wiki/%D7%97%D7%96%D7%A7%D7%94_%D7%A9%D7%9C%D7%99%D7%A9%D7%99%D7%AA),



```math
R^3(q) = q^{3/5}\frac\alpha\beta,
```

 כאשר



```math
\alpha = \sum_{n=0}^\infty\frac{q^{2n} }{1 - q^{5n+2} } - \sum_{n=0}^\infty\frac{q^{3n+1} }{1 - q^{5n+3} }, \qquad \beta = \sum_{n=0}^\infty\frac{q^n}{1 - q^{5n+1} } - \sum_{n=0}^\infty\frac{q^{4n+3} }{1 - q^{5n+4} }.
```

 [^5] עבור החזקה החמישית, נסמן $`w = R(q)R^2(q^2)`$; אז



```math
R^5(q) = w\left(\frac{1 - w}{1 + w}\right)^2, \qquad R^5(q^2) = w^2\left(\frac{1 + w}{1 - w}\right).
```



## משוואות ממעלה חמישית

את המשוואה הכללית ממעלה חמישית בצורת ברינג–ג'רארד



```math
x^5 - 5x - 4a = 0
```

 אפשר לפתור, לכל $`a \gt 1`$ ממשי, בעזרת השבר המשולב של רוג'רס–רמנוג'אן $`R(q)`$ והנום האליפטי



```math
q(k) = \exp\left[-\pi K\left(\sqrt{1 - k^2}\right)/K(k)\right].
```

 כדי לפתור את המשוואה, קובעים תחילה את המודולוס האליפטי



```math
k = \tan\left[\tfrac14\pi - \tfrac14\mathrm{arccsc}(a^2)\right].
```

 אז הפתרון הממשי הוא



```math
x = \frac{2 - \{1 - R[q(k)]\}\{1 + R[q(k)^2]\} }{\sqrt{R[q(k)]\,R[q(k)^2]}\sqrt[4]{4\cot\langle4\arctan\{S\}\rangle - 3} } = \frac{2 - \{1 - R[q(k)]\}\{1 + R[q(k)^2]\} }{\sqrt{R[q(k)]R[q(k)^2]}\sqrt[4]{\frac2{S - 1} + \frac2{S + 1} + \frac1S - S - 3} },
```

 כאשר $`S = R[q(k)]\,R^2[q(k)^2]`$. כזכור מהסעיף הקודם, אפשר לבטא את החזקה החמישית של $`R(q)`$ בעזרת $`S`$: $`R^5[q(k)] = S\left(\frac{1 - S}{1 + S}\right)^2`$.

### דוגמה 1

את המשוואה $`x^5 - x - 1 = 0`$ מעבירים לצורה



```math
(\sqrt[4]5\,x)^5 - 5(\sqrt[4]5\,x) - 4\left(\tfrac54\sqrt[4]5\right) = 0,
```

 ולכן $`a = \tfrac54\sqrt[4]5`$, ו-



```math
k = \tan\left[\tfrac14\pi - \tfrac14\mathrm{arccsc}(a^2)\right] = \frac{5^{5/4} + \sqrt{25\sqrt5 - 16} }{5^{5/4} + \sqrt{25\sqrt5 + 16} }, \quad q(k) = 0.0851414716\ldots, \quad R[q(k)] = 0.5633613184\ldots, \quad R[q(k)^2] = 0.3706122329\ldots
```

 והפתרון הוא



```math
x = \frac{2 - \{1 - R[q(k)]\}\{1 + R[q(k)^2]\} }{\sqrt{R[q(k)]R[q(k)^2]}\sqrt[4]{20\cot\langle4\arctan\{R[q(k)]R[q(k)^2]^2\}\rangle - 15} } = 1.167303978\ldots,
```

 שאי אפשר לבטא אותו בשורשים אלמנטריים. (את $`k`$, $`q(k)`$, ערכי $`R`$ והפתרון בדקנו בחישוב מספרי, מול השורש הממשי של $`x^5 - x - 1`$.)

### דוגמה 2

עבור $`x^5 - 5x - 4\sqrt[4]{\tfrac{81}{32} } = 0`$, כלומר $`a = \sqrt[4]{\tfrac{81}{32} }`$, מתקבל $`k = \tfrac1{\sqrt2}`$ ו-$`q(k) = e^{-\pi}`$, והשברים המשולבים הם בעלי הצורות הסגורות



```math
r_1 = R(e^{-\pi}) = 0.511428\ldots, \qquad r_2 = R(e^{-2\pi}) = 0.284079\ldots, \qquad r_4 = R(e^{-4\pi}) = 0.081002\ldots
```

 מלמעלה. הפתרון מתפשט ל-



```math
x = \sqrt[4]5\,\frac{2 - \{1 - r_1\}\{1 + r_2\} }{\sqrt{r_1r_2}\sqrt[4]{20\cot\langle4\arctan\{r_1r_2^2\}\rangle - 15} } = \sqrt[4]5\,\frac{2 - \{1 - r_2\}\{1 + r_4\} }{\sqrt{r_2r_4}\sqrt[4]{20\cot\langle4\arctan\{r_2r_4^2\}\rangle - 15} } = \sqrt[4]8 = 1.681792\ldots
```

 ואכן $`(\sqrt[4]8)^5 - 5\sqrt[4]8 = 3\sqrt[4]8 = 4\sqrt[4]{81/32}`$.
