# ויקי תורת המספרים בעברית

אוסף ערכים בתורת המספרים, מתורגמים לעברית מוויקיפדיה האנגלית.
כל ערך מופיע פעמיים: כדף לקריאה בתיקייה `pages/`, וכקוד ויקי בתיקייה `wiki/` שאפשר להעתיק ישירות לוויקיפדיה.

**רישיון:** התוכן ברישיון [CC BY-SA 4.0](LICENSE-CONTENT.md), כמו ויקיפדיה, כך שכל אחד רשאי להעתיק אותו בחזרה לוויקיפדיה עם ציון המקור. הקוד (סקריפט ההמרה) ברישיון [MIT](LICENSE).

**הערה:** התרגומים נעשו בעזרת מכונה. כדאי לבדוק ולהגיה כל ערך לפני שמפרסמים אותו.
